# 网文断章技巧：13种章尾钩子怎么写、怎么选

网文断章是在本章结束时留下有分量的继续阅读理由。Oh Story 提供13种章尾和7种章首候选，按本章功能、情绪与下一章承接选择。高压章可留下紧迫问题，日常章可保留关系或情绪期待；不要求每章最强，也不机械轮换类型。

## 网文断章是什么意思？

网文断章，指作者在一章结尾留下尚待回应的行动、问题或情绪期待，让读者想继续读下一章。停在那里的收尾就是章尾钩子；它和章首钩子、段落里的小悬念合起来，统称[钩子](https://zenstory.ai/zh/glossary/gouzi)。

Oh Story 的悬念参考用炸弹打比方：炸弹突然炸开，读者吓一跳就过去了，那是意外；听见定时器在响、不知道哪一秒会炸，读者才会一直盯着，那是悬念。断章要留下的，就是那个还在走的定时器。Oh Story 的底线是：每一章读完最后一句，读者还想接着翻。

## 章尾钩子有哪些？13 种类型与例句

下表是 Oh Story 长篇和短篇写作参考共用的章尾钩子 13 式，例句均为原创。

| 类型 | 做法与原例 |
|---|---|
| 1. 突然揭示 | **做法:** 抛出一条改写局面的信息 **原创例句:** 仓库监控里签收那批货的人，穿着她那件旧雨衣。 |
| 2. 紧急危机 | **做法:** 留下下一章非回应不可的威胁 **原创例句:** 河水已经漫过第三级台阶，船还没修好。 |
| 3. 未完成动作 | **做法:** 动作做到一半，被新变量打断 **原创例句:** 她伸手去按门铃，指尖还没碰到，门铃先响了。 |
| 4. 身份反转 | **做法:** 某人的真实身份和读者以为的对不上 **原创例句:** 新来的账房递上荐书，落款的印章属于三年前被抄家的那一户。 |
| 5. 两难抉择 | **做法:** 逼人物在两个坏选项里挑一个 **原创例句:** 交出账本，师父能活；不交，整条街的铺子都保不住。 |
| 6. 神秘物品 | **做法:** 亮出一件重要却含义不明的东西 **原创例句:** 饭盒底下垫着一块红布，包着一颗乳牙，布角绣着她的生日。 |
| 7. 倒计时 | **做法:** 让时间明显不够用 **原创例句:** 离考试打铃还有十分钟，他的准考证落在了出租车上。 |
| 8. 承诺/威胁 | **做法:** 有人当面宣布接下来要做的事 **原创例句:** “天亮之前，我会把这间铺子连同你一起卖掉。” |
| 9. 离奇消失 | **做法:** 写一次按常理做不到的消失 **原创例句:** 雪地上只有一行脚印走进柴房，柴房里没有人。 |
| 10. 隐藏含义 | **做法:** 一句平常话里藏着破绽 **原创例句:** 表哥在电话里笑：“替我问候楼下那棵桂花。”桂花是昨天才种的。 |
| 11. 意象钩子 | **做法:** 反复出现的意象忽然变了 **原创例句:** 对面那扇每晚亮到十点的窗，今天八点就黑了。 |
| 12. 回声钩子 | **做法:** 章尾复述章首的句子，改掉关键细节 **原创例句:** 章首：“这条街他闭着眼都能走。”章尾：“这条街他闭着眼都能走。今晚他睁着眼，在路口站住了。” |
| 13. 留白钩子 | **做法:** 只写人物的反应，不交代发生了什么 **原创例句:** 她听完那通电话，把灶火关了，出门时没锁门。 |

## 章首钩子有哪些？7 种开章写法

断章把读者送到下一章，章首要马上接住。Oh Story 的章首钩子有 7 式：

| 类型 | 做法与原例 |
|---|---|
| 1. 悬念对话开局 | **做法:** 从一段话里有话的对白直接开场 **原创例句:** “人你见到了？”“见到了。”“他认出你没有？” |
| 2. 闪前碎片 | **做法:** 先给一块结果碎片，再回到正常叙事 **原创例句:** 警笛凌晨三点停在楼下。十二个小时前，她还在为一张水电单跟房东吵架。 |
| 3. 倒计时开局 | **做法:** 第一句就立起紧迫感 **原创例句:** 离搬迁队进村还剩四十个小时。 |
| 4. 神秘独白 | **做法:** 第一人称的古怪心里话 **原创例句:** 那天敲门的人一共敲了九下，我数过，可我只开了一次门。 |
| 5. 反差场景 | **做法:** 把两个截然相反的场面并排放 **原创例句:** 前院在摆寿宴，戏台刚开锣。后院井边，有人在洗一把带泥的铁锹。 |
| 6. 未完成动作开局 | **做法:** 开场的动作做到一半被截断 **原创例句:** 他刚把信封撕开一角，窗外有人喊了他的小名。 |
| 7. 意象预示 | **做法:** 用环境里的意象暗示要出事 **原创例句:** 河面漂下来一整排纸灯，一盏都没点着。她数完，起身去关窗。 |

选哪一式，看这一章想怎么开：要直接冲击，用未完成动作开局或倒计时开局；要制造好奇，用悬念对话、闪前碎片或神秘独白；要靠对比抓人，用反差场景或意象预示。

把章首与上一章留下的期待并排看：是继续行动、核对信息，还是承接情绪？长短篇都按本书需求判断，不把前百字或禁天气当统一规则。全书第一章的开法另见[小说开头怎么写](https://zenstory.ai/zh/oh-story/novel-opening)。

## 章尾钩子怎么写：按本章情绪和故事阶段选类型

先写本章实际完成了什么，再问下一章会接住什么，最后选类型。下表只是候选，不是题材或阶段的统一指令。

| 本章职责 | 落点与承接 |
|---|---|
| 查到异常 | **候选落点:** 物件、信息变化 **下一章应做什么:** 核对、排除或据此行动 |
| 压力将到 | **候选落点:** 倒计时、危机 **下一章应做什么:** 响应该压力，不另换问题 |
| 完成胜利 | **候选落点:** 新责任、关系或余味 **下一章应做什么:** 承认已经拿到的回报 |
| 关系变化 | **候选落点:** 请求、选择、情绪 **下一章应做什么:** 让对方响应或给关系进度 |
| 低压生活 | **候选落点:** 小目标、情绪停留 **下一章应做什么:** 可以自然推进，不强造秘密 |
| 全书结尾 | **候选落点:** 兑现与回声 **下一章应做什么:** 允许收束，不必开启新悬念 |

源文件的强中弱和相邻类型检查是排纲默认提醒。类型反复且作用相同就改；连续倒计时若因同一限时行动不断改变条件，也可以保留。不要为换类型把刚建立的目标丢掉。

钩子写到期待清楚即可。下一章若不接、只重复“以后再说”，类型再多也会拖延。

## 章尾钩子示例：把一段 AI 式结尾改成断章

原创设定：摆渡人失踪一年，女儿接手渡船。上一章倒计时说明汛期还有三天，本章已核对父亲账本，发现一笔预收船费；她暂时不知道用途。保留两种候选，但各自需要本章已经展示的事实。

**空泛预告**（Codex 里把开头的 `/` 换成 `$`）：

> 她合上账本，终于明白父亲的良苦用心。她不知道的是，这本账本将让她卷进巨大的漩涡。

本书若采用贴近女儿的有限视角，尚未懂的动机不该被宣布为真；“巨大漩涡”也没有给出可承接的问题。

**候选一：具体物件**。本章先写她翻到夹页、取出船票，核对“父亲的名字”和“下个月初三”，再停在：

> 她把船票放在那笔预收款旁边。乘客是父亲，日期却是下个月初三。

下一章先查票的预订记录与出具者；未来日期不证明父亲仍活着，更不直接说明他去了哪里。

**候选二：带问题的动作**。本章已让她看见预收款旁的“东岸旧栈桥”地点，并建立白天可以到达、船可用，再停在：

> 她圈住“东岸旧栈桥”，把账本包好。明早先去那里问。

下一章实际抵达并询问，交付一个回答或阻碍。这个版本给行动方向，不用让人物知道关键内容却对读者只说“她看了很久”。两版是备选，不并排塞进一章；长期失踪问题可以延后，但每次调查要有进度。

## 章尾钩子常见错误：AI 式章尾怎么改

先看结尾用了什么信息、是否有作用，不按某个句式自动判“AI”。对限知故事，未经建立的全知预告会越界；对本书允许的全知叙述，预告可以是选择，仍要看具体、有无重复。

| 问题 | 改法 |
|---|---|
| 人物还不知动机，旁白宣布懂了 | 保留未知，写已有事实支持的理解 |
| “更大漩涡”不说读者能等什么 | 给一个可核对的问题或行动 |
| 总结复述刚看过的变化 | 删重复；必要的直接感悟可以留 |
| 每章最高强度 | 依章节功能留高低与余味 |
| 钩子后连续解释同一件事 | 在期待已清楚的位置停笔 |
| 下章绕开钩子 | 先处理上一章留下的目标 |

动作、对白、直接感悟和叙述者评论都可按本书声音选择；不用机械把哲理或情绪全部换成微动作。整章修订见[去 AI 味](https://zenstory.ai/zh/oh-story/revise-ai-prose)。

## 下一章怎样接住：真正兑现钩子，不重复“还有秘密”

沿用上面的候选一，不把候选二同时塞进这一版。为写承接，作者选定这组原创后续事实：票面有编号，镇上票务处能按编号查当前预订，昨日值班员就在柜台。这些是明确设计的新一章内容，不是从父亲名字或未来日期自动推导的事实。

> 第二天，票务处刚开门，她就把票放到柜台上。“这张票，是这里出的？”
>
> 值班员按编号翻到登记页，指给她看。“昨天出的，订的是下个月初三。”
>
> “昨天？谁来订的？”
>
> “电话订的。名字是电话里报的，我没见着人。”
>
> 她看见登记页的乘客栏，也写着父亲的名字。父亲失踪一年，昨天有人用这个名字订票——两件事并不能直接合成“他回来了”。
>
> “通话是谁接的？”
>
> “我接的。”值班员说，“下午四点二十。”
>
> 她把时间记在自己账本的空白处，收回船票。“我先核这一通电话。票替我留着原预订，别改。”
>
> 值班员点头，她合上账本，带着原票离开柜台。

承接已经实际核到编号、出具时间与电话预订方式，未知收窄为是谁报这个名字；父亲仍未找到，也没有证明电话里就是他。值班员说接过电话是场内证词，票务登记则是眼前载体，不由此推出全部真相。

下一步查电话是她的计划，本段还没查到来电人。若正文只换一句“她不知道更大的秘密在等着”，这次核票就没有交付新增信息。失踪长线可以继续，但本章留的问题要先有实际进展；不必每次调查都抓到凶手或升成更大的危机。

## 常见问题

**章尾钩子写多少字？**

写到继续阅读的理由清楚即可，不固定百字。短篇和长篇都按本场信息复杂度、本书文风和下一节承接控制。

**网文每一章结尾都要写强钩子吗？**

每章都要有让读者往下看的理由，强弱按章节定位来定：高压章用强钩子，普通推进章用中钩子，低压生活章用弱钩子或情绪钩子，信息整理章给出下一段目标。
