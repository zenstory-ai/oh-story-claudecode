# 怎么拆解榜单爆款小说、学它的结构：扫榜和拆文的自动化做法

**一句话答案：** 先扫榜再拆文。扫榜看的是跨样本重复的模式，不是单本排名；拆文先拆黄金三章，再逐章摘要、聚合成"节奏"和"情绪模块"两份可复用的资产，最后从中提炼文风。Oh Story（`zenstory-ai/oh-story-claudecode`，开源 MIT）把这条线做成了三个 skill：`/story-long-scan`（扫榜）→ `/story-long-analyze`（拆文）→ `/story-long-write`（写作直接消费拆文产物）。短篇有对应的 `short-scan` / `short-analyze` / `short-write`。

这份文档讲扫榜和拆文各自产出什么、怎么衔接到写作。它拆的是用户合法持有的作品，性质是只读的结构分析，不复制原文。

## 第一步：扫榜，看模式不看排名

`story-long-scan` 的核心信念是一句话：**单本排名只提供线索，跨样本重复模式才算信号。** 一本书上榜只算个例；同类样本达到可比数量，才标记为趋势候选。

三个平台看的东西不同：

| 平台 | 成功标准 | 扫榜重点 |
|---|---|---|
| 番茄 | 流量、完读率 | 男频 / 女频阅读榜、新书榜，在读数为核心 |
| 起点 | 订阅、追读 | 月票榜、畅销榜、新人签约新书榜、公众作者新书榜 |
| 晋江 | 收藏、积分 | 收藏与积分榜 |

数据来源有两种：用户直接贴榜单截图或文字；或者用 skill 自带脚本采集（`scripts/qidian-rank-scraper.js`、`scripts/fanqie-rank-scraper.js`，番茄有字体反爬，脚本从详情页多策略解码）。产出是扫榜报告加一份 `选题决策.md`（2 到 3 个推荐选题：能爆的原因 → 市场验证 → 差异化定位 → 可行性、失败风险、验证动作），写进本次扫榜的输出目录，供开书时引用。

要提取的是反复出现的：题材、设定、套路、书名词、开篇卖点。

## 第二步：拆文，一条管道六个阶段

`story-long-analyze` 只有一条深度管道，跑到黄金三章后自动停靠，问你要不要继续：

| Stage | 做什么 | 产出 |
|---|---|---|
| 0 | 概要提取 + 章节边界表 | `概要.md`，`_progress.md` |
| 1 | 黄金三章深度拆解 | `章节/第1-3章_深度拆解.md` → 停靠，产出 `快速预览.md` |
| 2 | 逐章摘要（可并行） | `章节/*_摘要.md` |
| 3 | 聚合分析 | `剧情/节奏.md`、`剧情/情绪模块.md`、`剧情/故事线.md` |
| 4 | 设定 + 角色 + 关系 | `设定/*.md`、`角色/*.md` |
| 5 | 汇总报告 + 全书概要 | `拆文报告.md` |
| 6 | 文风 | `文风.md`（句长、标点、对话潜台词、情绪交替周期，附原文锚点片段） |

全部落盘到 `拆文库/{书名}/`。粗估耗时：50 章以内 30 到 60 分钟，50 到 200 章 1 到 3 小时，200 章以上需要多轮会话。

两份权威产物值得单独说：

- **`剧情/节奏.md`**：关键信息怎样被扩写、爽点 / 虐点 / 期待点的"铺垫 → 释放 → 余波"位置、小中大高潮位置、冲突升级路径、跨章伏笔地图。
- **`剧情/情绪模块.md`**：读者需求、情绪引擎、套路框架，沉淀成可复现的模块卡。写作 skill 消费的就是这两个文件，`拆文报告.md` 只是摘要投影。

Stage 3 还做角色合并（跨章去重、别名归一，置信度 ≥0.85 自动合并）、角色分级（主角 / 反派 / 核心配角 / 功能角色）和桥段打标。

## 第三步：写作时怎么用

`story-long-write` 的方法论第三条："用模块组装，不要重新发明。" 具体做法：把对标书的具体角色看成功能位（对手 / 盟友 / 催化剂），再映射到你自己的角色；用你的素材填充这些功能位。

拆文产物通过项目里的 `对标/{书名}/` 目录被写作 skill 读取（`剧情/`、`角色/`、`设定/`、`文风.md`），日更前会先读 `文风.md` 贴近对标书文风。写作时不复制原文句子，复制的是结构和节奏。

## 和"手工拆书"的差别

手工拆书通常停在"每章一句话摘要 + 情节标注字数"。这条管道多做了三件事：把爽点和伏笔按章号建索引；把重复出现的情绪套路抽成模块卡；把文风量化成句长和标点分布并附原文锚点。这三样是写作阶段真正能被程序读取的资产。

## 边界

- 扫榜数据取决于当时能访问的数据源；采集失败时会明确标注回退，不伪造数据。
- 拆文只做结构和技法分析，不复制原文用于发布，不替代作者的选题判断。
- 一本书的拆解结果只是假设，管道会在选题回填时标注"只拆了一本，不算坐实"。
