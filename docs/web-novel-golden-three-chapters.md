# 黄金三章怎么写：网文开头清单与改写示例

黄金三章是把前三章放在一起检查网文开头：读者能否认清主角的处境、目标、本书看点和继续阅读的理由。用具体任务让读者投入进去，让后续章节有进展与回报。Oh Story 的字数位置和数量是项目默认参照，按本书要求与题材调整，不以数字替代案例和阅读判断。

## 黄金三章指哪三章，要交代什么？

[黄金三章](https://zenstory.ai/zh/glossary/huangjinsanzhang)指网文连载的前三章，Oh Story 把它当作检查开头立不立得住的单元。三章之内要交代清楚：主角是谁、处境如何，第一个冲突是什么，他凭什么与众不同，读者为什么接着读。

本页讲长篇连载的开头，短篇开头看[短篇从灵感到成稿](https://zenstory.ai/zh/oh-story/short-story-from-idea)。长篇的第一个冲突要和主线强相关，它一解决，主线就跟着转起来。

## 黄金三章每章写什么：前三章必写清单

| 章 | 核对与收尾 |
|---|---|
| 第一章 | **核对**：谁在什么处境，要做什么，本书值得看什么；**收尾**：新发现、选择、关系或情绪期待 |
| 第二章 | **核对**：原目标怎样推进，阻碍或理解怎样变化；**收尾**：局部回报与未完事项 |
| 第三章 | **核对**：读者得到什么阶段进度，长期方向是否清楚；**收尾**：指向主线的行动或余味 |

用这张表检查前三章的分工，具体安排按本书目标调整。

- 主角与当前任务清楚，信息量能辨认
- 初始问题连着本书长期看点
- 必要背景按需要出现，没有压住正在发生的事
- 阶段性结果实际发生，旁人按自己的关切响应
- 下一章接住已留下的目标
- 书名、简介与正文承诺相容

参考文件有主角约300字内、期待约1000字内等快节奏默认检查；本书明确要求优先。天气、日常、回忆、多人或无超能力开局并非自动失败，关键是它们有没有让读者理解并投入眼前故事。

## 网文开头怎么写：人设、切入点、金手指三个基点

Oh Story 的开篇参考以人设、切入点和金手指组织商业网文开局。把它用于本书时，先确定作者的故事承诺；普通人物的关系故事并不需要超能力。

| 观察项 | 问题与表达 |
|---|---|
| 人物 | **问题**：他在意什么，眼前处境如何？；**表达**：一次取舍、请求或观察 |
| 切入点 | **问题**：从哪件事进入本书？；**表达**：冲突、机会、关系或值得亲历的日常 |
| 优势 | **问题**：若本书承诺独特本领，它是什么？；**表达**：一次有边界的使用；没有此承诺可略 |

困境起手可以先让读者理解人物，再展示他的应对；优势起手可以先展示本领，再让任务检验它。两种都是候选，不规定前三章必须翻盘、遭轻视或引来围观。

若写公开胜利，让相关人物的响应和实际奖励落地；若写私下成长或关系变化，确认、理解或合作也能形成回报。背景跟着当前需要分批进入，也可以在重氛围的作品里先建立环境。情绪、动机和信息差是检查期待的角度，分量和顺序服从本书。

## 黄金三章示例：把背景式开头改成冲突式开头

本页原创设定：学徒许青禾借用周建的铺面与维修台，约定月底到期。周建准备出售自己所有的设备；寄修表仍是顾客的。许青禾想处理完已接订单，并在月底前找到继续修表的地方。她拨回停表分针时能看到停下前戴表人的一段视野，只给片段，不给日期、全貌和动机。

**背景先行**可以有用，但这一版只列身世，当前任务太晚出现：

> 县城有一条河。许青禾从小跟师父学修表。师父去世后，她仍在原铺工作。她性格负责。月底她得搬走。

**放进任务的版本**：

> 周建把设备转让清单压在玻璃柜台上：“月底清空。你接的那七块寄修表，交得完吗？”
>
> “先交刘老板这块。”许青禾翻出收表当天拍的照片，旁边夹着检验记录：开盖当场发现进水，还没动手修。刘老板说好下午三点来取。
>
> 她把停住的分针往回拨。墙上的钟声淡下去，眼前出现一只戴方戒的手，把表按进浑水。片段到这儿就断了。她再看墙钟，一点五十一分，离三点还有六十九分钟。

清单定下月底这个期限，七块寄修表是她得担的责任和任务，照片和检验记录先把进水这件事钉在维修之前。方戒片段只提醒她接着问，还证明不了是谁弄坏的。

| 章节 | 设计与实际交付 |
|---|---|
| 第一章 | 月底要迁店，先处理刘老板那块进水的金表；拨针只看到方戒按表的片段，章尾刘老板上门取表 |
| 第二章 | 刘老板咬定是维修时进的水；许青禾摆出收表照片和检验记录，他核对后撤回这项索赔，接受八十元报价；表修好验收，钱付清 |
| 第三章 | 许青禾把这笔工钱留作搬店预算，联系前文提过的可租工位，约好去看；新顾客带来一块与师父旧事有关的停表 |

照片和记录只能说明进水早于维修，不能凭一枚戒指把全部责任算到谁头上。刘老板撤回索赔、掏钱付款，都要写成他实际做的事，只写一句“他被拆穿”不够。看工位是下一步，还没租到；新停表只打开师父这条线，旧案先不答。三章各有任务和进度，不用凑三次羞辱。

## 第二章怎样接住开头：核对之后有实际结果

沿用许青禾修表铺的前提。检验记录上写着进水，照片也在；方戒片段只能提示她接着问。下面展开第二章的核对和报价，维修过程略写，只留验收和付款。八十元是本例选定的报价。

> 刘老板一进门，指节就敲在玻璃柜台上：“我这表送来时好好的，怎么到你手里就进水了？”
>
> 许青禾把收表照片和检验记录并排推过去，镊子尖点着记录上写的进水位置：“收表时就有。您看这张，那会儿还没开始修。”
>
> 他拿起记录对着照片看了一遍，手从柜台上缩了回去：“行，这项不算你修坏的。修好要多少？”
>
> “八十。”她把数字写在记录下面，连笔一起推过去。
>
> 刘老板在旁边签了字：“修。”她这才把这块表记进待修单。
>
> 表修好后，刘老板贴在耳边听了一阵，没挑出毛病，数出八十块放在柜台上。许青禾在单子上划掉这一笔，把钱塞进搬店用的信封。柜台上还剩六块寄修表。

核对、撤回索赔、接受报价、修好付款，是四个不同的结果。争议怎么变化值得详写；维修过程可以略，验收和工钱去向要留。只写“他被打脸”，这串结果就都没了。

第三章接着看工位、接新停表，这笔工钱算进搬店预算。方戒还确定不了是谁弄坏的表，师父的旧事还要查，看了工位也还没租到。关系故事可以兑现理解、合作或决定，按本书承诺选择回报。

## 黄金三章自查评分表（可复制）

这张手写自查表帮助定位问题，不作平台成功预测。可记“清楚／需补／不适用”，分数只是整理手段。

| 维度 | 检查与信号 |
|---|---|
| 开篇吸引 | **检查**：有无具体想看下去的事；**信号**：只报资料，任务不清 |
| 主角 | **检查**：处境、在意与选择；**信号**：只贴性格标签 |
| 回报 | **检查**：已承诺的进度是否交付；**信号**：声称赢了，却没发生结果 |
| 信息 | **检查**：能否理解当前事件；**信号**：新概念压住任务 |
| 章尾 | **检查**：下章会接住什么；**信号**：空泛预告，无可回应事项 |
| 关系响应 | **检查**：相关人物怎么实际行动；**信号**：全员惊叹却无变化 |

慢热或低压故事可用情绪、关系和理解变化交付，不必凑“两个爽点”。先改最影响本书承诺的一项。

## 编辑说开头节奏太慢，先查这几处

找出哪几段没有产生预期作用，不因慢或长就删除。检查目标、信息、关系、风险、身份、资源和情绪立场的变化；有用的气氛与停留也要结合本书文风判断。

| 症状 | 判断与改法 |
|---|---|
| 主线迟迟不清 | **先查**：人物为什么在这里；**改法**：尽早建立当前任务与投入 |
| 对话反复同一内容 | **先查**：有没有回应和变化；**改法**：合并重复，留交锋与关系作用 |
| 背景压住事件 | **先查**：此刻是否需要全部资料；**改法**：先留理解任务所需内容 |
| 回忆停不下来 | **先查**：过去带回什么理解；**改法**：留新作用，压缩重复 |
| 后果全靠宣布 | **先查**：谁实际接受、拒绝或交付；**改法**：补有权限者的响应与结果 |

标题能表达任务，却不能替空章节制造进展。需要扩写已有冲突，就补选择与后果，不靠固定字数位置加事故。

## 网文开头常见问题和改法

- 优势突然出现：提前建立最小用法和边界；普通人的职业技能也可以承担看点。
- 人设只靠评价：让人物处理眼前任务，害怕或犹豫可以成立，只要动机和选择清楚。
- 视角与时间不清：明确本书叙述方式与切换位置，不把所有回忆或多视角一律禁掉。
- 承诺与正文错位：核对书名、简介和开头给的是同一种体验；不要为赶数字位置改变人物决定。

开篇方法是菜单。对同一题材选择不同人物、任务与信息顺序，避免每本都照同一骨架填空。
