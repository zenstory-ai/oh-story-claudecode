## 官方来源

- [帮助中心「作品信息要求」](https://fanqienovel.com/writer/zone/help/article?rank1=10006&rank2=10140&rank3=10144)（2026-10-29 读取）：长篇书名只支持中英文、阿拉伯数字和中文叹号、逗号、问号、中括号、冒号，须唯一，申请签约后不能改；封面 600×800、不超过 5MB、须含书名和笔名；简介 500 字以内。
- 短故事书名上限 25、半角算半个、不能有空格、书名号或 emoji 会提示无法签约：2026-10-29 读取短故事后台页面脚本，未实测；2022-12-14 的[旧公告](https://fanqienovel.com/writer/zone/article/7176894591558221861)写 30 字，已过时。
- [签约模式调整通知（2026-10-12）](https://fanqienovel.com/writer/zone/article/7695623157880733758)：新建作品 Lv.0/1 仅完本签约，Lv.2+ 可选连载或完本。
- [作品标签说明（2026-03-16）](https://fanqienovel.com/writer/zone/article/7617805652965982232)：阅读标签主分类必选。
- [写作编辑器说明](https://fanqienovel.com/writer/zone/article/7455639656860762137)：Web/App 有「先写章节」与「先创建书本」两种入口。
- 等级、额度、完本签约等公告见阶段报告「来源与后续证据」。
