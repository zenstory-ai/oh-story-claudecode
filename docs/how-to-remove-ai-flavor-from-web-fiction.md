# AI 写的小说 AI 味太重怎么办：去AI味的具体做法

**一句话答案：** AI 味不是语法错误，是"过度圆滑、过度工整、解释太满"。去 AI 味要改的是读感，改最少的字，保留剧情功能。Oh Story（`zenstory-ai/oh-story-claudecode`，开源 MIT）把这件事做成了一个可重复的写作 lint：`/story-deslop`（`/去AI味`），先用脚本确定性地检出已知句式，再按 7 个 Gate 分级改写，删除比例有上限，改完出报告。

这份文档说明 AI 味具体表现在哪里、怎么按等级处理，以及一个 skill 能自动化到什么程度。它不承诺任何 AI 检测器的分数。

## AI 味长什么样

`story-deslop` 用一张对照表定义"自然文本"和"AI 味文本"的差别（节选）：

| 维度 | 自然网文 | AI 味文本 |
|---|---|---|
| 段落长度 | 随节拍长短不一：爽点压短，情绪链放长 | 通篇同一长度，整齐均匀 |
| 对话标签 | 低频、不公式化，多用动作引出 | 几乎每句都有"说道 / 问道 / 笑道" |
| 情绪 | 直写且有后果 | 空转的情绪总结句，或每个情绪词配一个微动作 |
| 比喻 | 生活化（"像哈士奇护食"） | 文学化（"如寒冰般"） |
| 省略 | 大量留白，读者自己脑补 | 面面俱到，生怕读者不懂 |
| 排比 | 偶尔一两个 | 连续三到五个是标配 |
| 结尾 | 动作或对话收尾 | 总结、升华、感慨收尾 |

高频禁用词是最容易识别的一层："深吸一口气""眼中闪过一丝""嘴角勾起一抹""不禁""缓缓开口""仿佛……"。skill 自带 `references/banned-words.md`，并给每个词一个替换方向（"眼中闪过一丝"改成"他垂下眼"，"缓缓开口"直接用动作引出对话）。

## 7 个 Gate

检测报告按 Gate 归类，处理策略按等级决定跑哪些 Gate：

| Gate | 类型 | 例子 |
|---|---|---|
| A | 禁用词 | "眼中闪过一丝……" |
| B | 句式套路 | "……，带着……"；连续三句排比；"不是……而是……" |
| C | 情绪空转 | "一丝悲伤涌上心头" |
| D | 节奏均匀 | 段段 4 到 6 句、长度一样 |
| E | 对话腔调 | 所有人说话一个语气 |
| F | 结尾升华 | 每章以感慨收尾 |
| G | 解释腔 / 上帝感 | "她不知道的是……""之所以……是因为……" |

| 等级 | 判定 | 处理 |
|---|---|---|
| 轻度 | 禁用词 ≤5 处/千字，无连续 3+ 句式套路 | 只过 Gate A + B |
| 中度 | 6 到 15 处/千字，或有连续 3+ 套路 | Gate A + B + C + D + G |
| 重度 | >15 处/千字，或 7 个 Gate 里 4 个以上有问题 | 完整 7 Gate + 重点段落重写 |

## 流程

1. **确定性预检。** 输入是文件时，先跑 `node scripts/check-ai-patterns.js --check --fail-on=blocking <文件>`，只报告不修改。blocking 类别只限确定性的句式和标点问题（"不是……而是"对比、破折号、否定排比、预告式收尾等），其他提示按读感判断。
2. **AI 味扫描报告。** 输出等级、主要问题，和一张"位置 / 类型 / Gate / 原文 / 问题"表。
3. **三遍法改写**（`references/anti-ai-writing.md`）：
   - Pass 1 去泛化：禁用词、抽象情绪、工整对仗、解释腔。
   - Pass 2 去书面化：书面腔用词、句式套路。
   - Pass 3 回自然感：长短节奏、对话差异化、结尾去升华、补具体感官细节。
4. **改后报告**，标出 `[需复核]` 的位置。

## 三条保护规则

这是 skill 和"让模型随便重写一遍"的核心区别：

- **改最少。** 能改一个词就不改一句，能删一句就不重写一段。人名、地名、数字、专有名词优先保留。
- **删除有上限。** 轻度 ≤15%，中度 ≤25%，重度 ≤35%。不得整段删除正文；删除前要确认这段没有伏笔、钩子、角色特征、情节推进或因果锚点，会丢就改成"降 AI 重写"而不是删。
- **只改怎么说，不改说什么。** 不新增原文没有的情节、设定、关系或时间线。原文的逻辑问题不是去 AI 味的活。

## 关于 AI 检测器

去 AI 味治读感，不治检测器。朱雀之类的外部检测只作自测参考；skill 不写"0% AI"，不注水、不故意错字、不打乱标点。如果你贴了检测报告，它只会把能对应到正文的问题转成具体修改点。签约平台的规则请看平台自己的说明，这个 skill 不替你做合规判断。
