# AI 写的小说 AI 味太重怎么办：去AI味的具体做法

去 AI 味要看句子怎样组织、笔墨花在哪里，以及人物的行动是否有依据。Oh Story（`zenstory-ai/oh-story-claudecode`，开源 MIT）的 `/story-deslop`（`/去AI味`）默认完整检查这三层，再按作者授权改稿。可以单独使用，也可以承接长短篇写作流程中的定点修改。

处理前先读当前要求与本书文风。安静场景、短促台词、心理直写和叙述者评论，都要放回具体语境判断。

## 三层分别看什么

| 层 | 常见问题 | 改稿时看什么 |
|---|---|---|
| 表达 | 连续短碎句；长句里逐项播报；套词、套路句与所有人相同的声口 | 围绕行动组织信息，把条件和原因接入动作，恢复人物此刻的说话方式 |
| 叙事用笔 | 无关过程逐步拍出，关键交锋却一句带过；细节只重复命名情绪 | 场景要完成什么，读者需要经历哪个过程，哪些重复可以压缩 |
| 故事因果 | 人物突然改口，条件尚未成立就得到结果，角色知道了不该知道的信息 | 原文或已定设计能否支持选择、变化与结果；缺了什么依据 |

三层不一定同时出毛病：词句干净的稿子也可能详略失衡、因果断线，所以脚本零命中不能代替通读全文。方法分别见 [表达](../skills/story-deslop/references/expression.md)、[用笔](../skills/story-deslop/references/narrative-focus.md)与[故事](../skills/story-deslop/references/story-logic.md)。

## 先治理电报体，再看套词

电报体既包括每个动作单独成句，也包括把位置、责任、条件用逗号挨个排开的长句。光补主语、换标点或把几句硬拼成一句，往往只是把短清单换成长清单。改稿要分出信息主次，让读者跟着人物把行动走完；紧张处的短句和人物有意的停顿照常保留。

长期积累的“深吸一口气”“眼中闪过一丝”“嘴角勾起一抹”“不禁”“仿佛……”以及句式、整段样本收在[词句信号索引](../skills/story-deslop/references/banned-words.md)。这些只是定位线索，命中后还要放回上下文看是否重复、空泛或与本书口吻不合。别把每个情绪词都改成垂眼、攥拳等微动作，也别删掉区分事物和承接前后的必要修饰。

## 实际流程

1. **读原文与依据。** 通读本次正文，按需查相关前文、设定与设计，完整检查三层。本地文件先做句式预检，提示只供定位。
2. **找出读着卡壳的地方。** 每项问题记下原文位置、具体断点和最小改法，区分可直接改、资料不足、需要重排剧情三类。先核对故事成立条件，再调详略与词句。
3. **按授权改稿。** 普通去味直接修表达、补回原本就有的承接、调整已定内容的详略；需要新增事件、动机、成立条件，或改动结果与揭露顺序时，先给最小方案等作者拍板。已获授权的重写直接完成。
4. **回读与复扫。** 对照原文和授权回读完整场景，核对事实、选择、因果、情绪与空间方向，再跑一遍文件扫描。如果读起来还像对白提纲或逐条报账，说明表达还没改顺。

作者只要检测时，只交诊断，不改动正文。指定某段或某类问题时只改该范围，范围外的问题顺带提醒即可。也可按检测类别或问题名（套词句式、情绪、节奏、对话、收尾、解释与安排感）指定检查项，对应关系见[范围接口](../skills/story-deslop/references/deslop-gates.md)，范围大小不代表轻重程度。

## 删除与保留怎样判断

没有叙事作用的段落可以整段删掉，不设固定删减率。伏笔、因果、人物选择、情绪体验和揭露顺序要保住；关键过程写得太略时，也要把原本就有的交锋或铺垫展开写足。总字数仍按作者定的范围走。

逻辑漏洞一并纳入诊断：原文或已定设计里本就有的承接直接补回；资料不够时注明未知，要动剧情时列出备选方案及对后文的影响，绝不凭空编证据、冲突或人物经历来强行圆场。

## 脚本能做什么

本地预检从 `story-deslop` 技能目录执行，文件参数使用绝对路径：

```bash
node scripts/check-ai-patterns.js --check --fail-on=review_required <正文文件绝对路径>
```

检测器判断不了整篇故事立不立得住。句式规则分 `review_required` 与 `advisory` 两档（严格拦截须传 `--fail-on=review_required`，`--fail-on=blocking` 对纯句式命中返回 exit 0）；表达提示要放回上下文复核。写作流程里的 `review_required` 命中优先保住原意改顺后再复扫；作者明确想留、确实起作用的原句，长篇可通过 `storyctl.js` 的 `--ack <rule-id>:<reason>` 或 `--ack-all <reason>` 附简短理由放行，也可记入书级白名单长期保留。

外部 AI 检测报告也只能帮助定位可对应到正文的问题。skill 不承诺检测分数，不靠注水、故意错字或打乱标点改分。
