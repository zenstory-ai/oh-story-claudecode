# 网文大纲怎么写：长篇小说大纲模板与分卷范例

网文大纲不要从第一章一路顺写。先用一句话定下主角要完成的事，再确定结局和各卷高潮，倒推每卷必须改变的局面；最后才安排可调整的场景。全书方向要稳定，分卷路径可修，具体对白和小场面留到写作时决定。

## 长篇大纲先写哪一层？

大纲帮助长篇维持方向，无需预写正文。可分三层，具体名称随作者习惯：

| 层级 | 用途与调整范围 |
|---|---|
| 全书骨架 | 主角最终要完成什么，为什么与他有关；作为方向，改变时检查已写内容与读者期待。 |
| 分卷路线 | 这一卷改变哪种局面，高潮如何证明改变；可以调整路径，保留已经建立的原因。 |
| 场景备忘 | 哪个场景、线索或对话可能完成节点；随写随改，不把新点子自动当作已经发生的事实。 |

这与[细纲模板](https://zenstory.ai/zh/oh-story/chapter-outline-template)不同：全书大纲管方向，细纲管近期章节怎样落地。先定高潮再倒推，是本文推荐的起草方法；作者也可以从人物或开场试写起步，再整理终点。不要为填完整结构而制造不需要的秘密、能力或支线。

## 可复制的长篇小说大纲模板

按下面顺序填，不必一次填满所有支线（Codex 里把开头的 `/` 换成 `$`）：

> **核心卖点**：读者持续来看哪种独特体验？
>
> **主角起点**：他缺什么、受什么限制、最怕失去什么？
>
> **全书目标**：他要完成的一件可判断成败的事。
>
> **终局选择**：高潮时他必须在什么之间作选择？选择会证明怎样的成长？
>
> **结局状态**：外部局面、核心关系、主角认知分别变成什么？
>
> **分卷卡**：本卷目标｜主要障碍｜新策略｜高潮对决｜局部兑现｜遗留压力。
>
> **跨卷线**：主线怎样升级；哪条关系或秘密在哪卷推进、在哪卷兑现。
>
> **当前写作窗口**：只细化接下来一段的目标、阻力、结果和下一步期待。

先写终局选择与每卷高潮，再倒推需要提前建立的人物、能力、关系和证据。这样伏笔来自结局需要，避免写到哪儿临时塞到哪儿。

## 原创分卷范例：《潮汐修复师》

**原创设定《潮汐修复师》**：许澄能从接触过的旧机械听见故障前后的声音，不能直接知道谁换了零件或为何换件。沿海城市的大潮将至，她想修复主闸并查清连环故障的换件经过。维修组负责施工资格、配件与停闸安排；档案管理员提供已登记记录；市政议事会决定采用怎样的维护办法。许澄不能靠能力自行取得这些权限。

下面是待写的四卷设计。先定最终需要完成的动作，再把条件分到前卷：

| 卷 | 目标、高潮与下卷承接 |
|---|---|
| 盐湾旧闸 | 取得参与维修的资格。许澄指出支闸异常，维修组核查并同意由她参与；按既定程序修好后，组长批准她进入后续项目。拆下的零件编号与登记不符，把任务送往泵站记录。 |
| 城南泵站 | 找到换件经过。她与档案管理员对照借出、采购和实际装配记录，请维修组复核；证实这批更换未按记录安装，尚不能直接确定幕后动机。承包方实际撤回原有推荐，主闸旧图又缺一页，下一卷需要补齐来源。 |
| 退潮档案 | 取得缺页和当年处置记录。同伴说明自己保留过缺页，并实际交给管理员核入；许澄得知父亲曾按临时防线安排承担了被误解的维修责任，但还需完整记录支持后续追查。两人约定以后共同核对资料，能否恢复信任留给行动检验。大潮提前，使施工时间更紧。 |
| 封潮之夜 | 维修组已经备齐匹配配件，并批准停闸窗口；许澄选择先参加抢修，保留完整记录供会后公开核对。完成维修、试闸和撤离安排后，再由议事会接收说明，讨论并通过公开维护记录的办法；结尾展示下一次检修实际登记。提交材料不直接等于所有责任已被裁定。 |

父亲经历、配件、施工时间和谁有权采用新办法，都应在相应卷里建立。机械声音只是找线索的起点，不能替代装配记录、核验或他人的回应。终局同时使用手艺、记录与合作关系，但不在最后一场免费补出权限和资源。

当前只继续细化第一卷的“申请参与—核查误判—拆件发现—支闸抢修”。后续对白、现场动作和小失误留到近期细纲，不必现在写满第四卷。

## 从空白到可写：从结局倒推关键情节

先写主角的起点与终点，使变化可见；再写最大冲突中的选择，而不只是“大决战”。接着问：主角凭什么做出这个选择？缺少的能力、关系和证据，就成为前面各卷的节点。

每卷也用同一方法：先定卷末高潮，再给卷初一个可理解的阶段目标；在两者之间安排会迫使主角换策略的障碍。支线只有在帮助主线、制造代价或最终与主线汇合时才保留。写到一半偏航时，先检查当前行动是否仍服务阶段目标，无需立刻推倒全部内容。

## 长篇大纲常见失败与改法

| 问题 | 检查与修正 |
|---|---|
| 把“升级变强”当主线 | 为什么会卡：它是行动，不是可完成的事情 改法：改成“为了什么而变强” |
| 从开头顺推到哪算哪 | 为什么会卡：后段高潮没有前置条件 改法：先写高潮选择，再倒推铺垫 |
| 每卷只是换地图重来 | 为什么会卡：局面没有积累性变化 改法：让上一卷结果制造下一卷问题 |
| 支线很多但彼此不碰 | 为什么会卡：篇幅增加，主线不前进 改法：写清支线最终帮助、阻碍或改写什么 |
| 大纲写成场景全文 | 为什么会卡：新发现无法进入故事 改法：上层固定，细节层保留调整空间 |

判断大纲是否够用，只需看你能否回答：下一阶段追求什么、谁在阻挡、失败会失去什么、高潮将改变什么。

## 常见问题

**细纲和章纲有什么区别？**

细纲把每章要交付的目的、效果和可执行情节点写清，是 Oh Story 正文写作的章节蓝图；章纲是分配近期关键事件、伏笔与章末期待的粗纲。已有大纲和细纲足够时，可以省略额外的章纲，不能用分卷路线代替所需细纲。

**长篇大纲写完还能改吗？**

可以。具体路径和场景应随正文修订，但核心卖点、全书目标和已建立的因果不能无代价改掉。先判断变化发生在哪一层，只改必要层。
