# 规则怪谈怎么写：规则开始冲突才可怕

规则怪谈先建立看得见的限制，再让人物在信息不足、时间紧或规则互相打架时做选择。线索、试探和结果要一一对得上，代价随情节累积，不必每发现一条规则就丢一件东西。动笔前先定四件事：规则从哪来、哪条路走得通、判断错了会怎样、这一轮人物实际能完成什么。

## 规则怪谈副本怎么设计：四步搭建顺序

Oh Story 的题材库把副本式规则怪谈拆成：背景故事、规则包装、通关线和死路、破局与揭露真相。这是一种结构选择，不要求每个故事都安排别人死给主角看，也不要求结尾都要升华。

1. **背景**：先写这个地方原来做什么、人物为什么必须留下。
2. **规则包装**：把规则落到纸条、交班时的叮嘱或已经发生的事件上。作者要清楚每条限制管到哪里；人物可以只知道一部分，读者也可以暂时不知道来历。
3. **通关线和死路**：至少安排一条走得通的路线，并给判断失误一个可信的后果。危险可以消耗时间、信任、可用位置或认知。
4. **例外**：例外要在前文立住，不能到结尾才替主角临时豁免。

## 规则之间怎么冲突：把恐惧落在具体条件上

两条规则可以在同一时刻要求相反的动作，逼人物在信息不全时选一边；也可以让纸条、叮嘱和亲眼所见对不上，逼他判断该信哪条。

| 条件 | 落在什么东西上 | 给人物的压力 |
|---|---|---|
| 通路 | 楼层牌、地面标线 | 某段路暂时不能走 |
| 时间与光 | 钟表、手电余量 | 调查要花时间，暗处难判断 |
| 人与信息 | 登记本、证词、录音 | 来源互相矛盾，信任要重新确认 |

一处水渍、多出来的一口呼吸，先只是异常，不自动证明谁来过。给每条信息标上是亲眼所见、听人转述还是自己推断；一次试探只能证明它实际检验过的那部分。主角保护别人，可以付出等待、暴露位置或分出资源的代价，也可以暂时不付代价，但背上一份新的责任。

摸清一条限制、避开一次风险、争到一条通路，都算这一轮的回报。下一轮从这次的结果接着写，不让资源偷偷复位，也不临时加规则。

## 规则怪谈每章怎么推进：前中后期写法

Oh Story 悬疑灵异题材卡给的每章顺序是：异常出现，试探规则，付出小代价，得到一条更危险的信息。连载中遇到整理线索、处理人物关系的章节，这四步可以分散在相邻几个场景里，不用为了凑格式再硬造一场事故。

- **前期**：建立一个能被感知的异常和少量线索。
- **中期**：让调查改变人物的判断或可走的路。
- **后期**：用前文出现过的细节，处理已经立下的限制。

偏惊吓的段落要留下读者能理解的依据，偏解谜的段落要保留眼前的危险。章尾可以落在一个发现、一次做完的试验、一条路线的变化或下一个选择上：先兑现这一章的内容，再抛新问题。需要逐章排节点时，可以用[小说细纲模板](novel-chapter-outline-template.md)。

## 规则怪谈守则示例：一张会互相打架的规则表

下面是原创的车库夜班故事，不是现实守则。收费亭的纸条写着：

```text
1. 零点后只留在有光的区域。
2. 无牌车开到杆前，不抬杆，不对视。
3. 巡查时手电只照脚下。
4. 交班前如果实际车辆比登记多，找出多出的车位，在空栏画叉，回亭合上本子；不能擦掉原有登记。
5. 后窗有人敲，不要应。窗外是墙。
```

上一班的老贺交班时说一共三十一辆。主角注意到 B-17 那辆灰车干得反常，但没有核对整页登记。后来一辆无牌面包车在杆前停了一会儿，又退走了。主角守住了第 2 条，只说明他没有抬杆，并不能证明违反规则就一定会死；旧值班表上被划掉的名字，也只是一条待查的线索。

主角巡查时数到三十二辆，B-17 的登记栏是空的，其余车位都和登记对得上。停电后只剩手电，照车位既费时间又费电。光贴着地面照过去，能看到 B-17 的轮胎悬着，白线从轮胎下面完整地穿过：这说明它异常；要说明它就是多出来的那辆，靠的是登记核对。

主角在空栏画叉，回亭合上本子，没有回应后窗那个熟悉的声音。天亮后 B-17 空了，实际车辆和登记重新一致，这一轮交班才算完成。值班表上老贺的名字被划掉，原因仍然没查清。发现、推断、执行和实际结果各写各的，剩下的谜继续给人物施压。

### 写成正文：观察、核对和执行

下面用第一人称把这次巡查和回亭写成正文。停电后主角还要走到 B-17，所以本例在设定时就把第 1 条的有光区域定为当前光源照亮的范围，手电照亮的脚下也算；如果你的设定只承认固定灯光，就要另安排一条路线。

> 我巡到最后一格，数到三十二。老贺交班时说三十一，那辆无牌面包车已经退走，杆没有抬过。
>
> 回到亭里，我把登记本翻到今晚这一页。占着车的格子一项项对下来，只有B-17空着。那辆灰车的车身干得反常，可干净不等于多出来；现在空栏和车位才对上。
>
> 亭灯灭了。我带上登记本，留着手电的光，把脚落在照亮的地方，沿白线往B-17走，没有把光抬到驾驶窗。
>
> 到车位边，光贴着地面过去。白线从轮胎下完整露出来，轮胎没有压在地上。我停了一下，想再照照车里，却把手电留在脚下。这里异常；它为什么悬着，我还不知道。
>
> 我在照亮的地上摊开本子，在B-17的空栏画叉，旁边已有登记没有擦。带它回亭，整页合上时，后窗响了两下。
>
> “开一下，是我。”声音熟得像老贺。
>
> 我看着前窗，没有回话。后窗外是墙；声音像他，也不能替我证明他站在那里。
>
> 天亮再巡，B-17空了。其余车位与登记对应，我重新数过，三十一辆。回亭翻到旧值班表，老贺的名字被划去，划线的人没有留名。

这段完成了四件事：清点数目、在空栏画叉、合上本子、天亮后复核。原因仍然未知。轮胎悬空不能单独证明它是多出来的车，熟悉的声音不能证明窗外是谁，老贺的名字被划掉也不等于他已经死了。手电一直在用，消耗掉的时间和电量到下一章不会自动恢复。

## 中式恐怖小说怎么写：民俗怪谈和规则怪谈的区别

民俗怪谈可以把限制放进地方生活、宗族和行当里，异象沿着同一条禁忌和一笔旧账逐步加深。帮手收不收钱、谁先破戒、用什么时辰倒计时，都看这一篇的人物和处境，不是固定配件。

用到现实中的民俗传统，先核实出处；用虚构的地方规矩，要让读者知道它是虚构的。不要把各地的民俗名词混在一起当成万能解法。

## 规则怪谈写成长篇：怎么用无限流串起副本

长篇可以由多个各自成篇的副本组成，再用一条现实主线把人物的目标和后果连起来。题材库里的副本章数只是默认参考，实际写多长，看这个副本的问题有多复杂、回报和连载节奏怎么安排。

光源、伤势、人数、掌握的知识和道具消耗都要跨章继承；副本结束时，也要写清哪些代价还留着。新副本应该让旧经验用得上、但不够用，避免每次从头教学。怎么记录这些状态，见 [AI 写长篇小说怎么不崩人设](ai-long-novel-character-consistency.md)。

## 规则怪谈常见写崩点和改法

| 写偏 | 改法 |
|---|---|
| 只靠更黑、更吵来升级 | 改变通路、认知、时间或人物关系 |
| 不断宣读新规则 | 让已有规则进入人物的选择和检验 |
| 剧情需要时就改限制 | 提前立好例外和适用范围 |
| 旁白直接宣布答案 | 写出观察、比对、行动和结果 |
| 为了制造危险让人物变笨 | 冒险要有前文立住的目标、信息和代价 |
| 资源和伤势悄悄复位 | 下一场接着上一场的实际状态写 |

每写完一轮，问自己三个问题：人物现在知道了什么，能做什么，还不能确定什么。回报可以小，依据要清楚。

## 用本仓库的 skill 怎么做

装好本仓库后，用 [story-long-write](../skills/story-long-write/SKILL.md) 规划第一个副本：Claude Code 里输入 `/story-long-write`，Codex 里输入 `$story-long-write`，然后告诉它你要写规则怪谈，请它先出副本大纲和状态表。大纲里列出背景、规则的适用范围、线索来源、走得通的路线、人物的选择、风险和实际结果，并把观察、推断和执行分开写。不要预先规定章数，也不要求每次试探都扣一份资源。

## 常见问题

**规则怪谈的规则怎么写才吓人？**

让每条规则有稳定的适用范围和看得见的后果，再把互相矛盾的要求或信息放进人物的选择里。读者可以暂时不知道规则的来历，人物也不必逐条做实验。

**规则怪谈开头怎么写？**

开头可以用一件怪事、一张现场规则或人物遇到的阻碍，把当下的行动带出来。被划掉的名字是线索；要证明违反规则的后果，得有对应的事件，不能只凭一行字宣布死因。

**规则怪谈一个副本写多少章？**

没有固定章数。看副本的问题、人物的变化、回报和连载节奏；题材库的默认长度只作规划参考。
