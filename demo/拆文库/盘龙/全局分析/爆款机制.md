# 爆款机制：盘龙（开篇 1-23 章）

## HM-001 天花板先行的成长纵深

- 表层表现：导师、魔法师、魔兽与圣域战斗分层展示力量上限。
- 因果链：建立弱小基线 → 看见可信上限 → 角色产生身体/行为反应 → 主动选择新目标 → 新门槛出现。
- 心理机制：让读者先相信“值得追赶”，再投资主角的努力过程。
- 证据：第 1、8-15、20-23 章（A）。
- 可替换：职业体系、展示场景、上限人物、第一步任务。
- 迁移条件：强者展示必须改变主角的选择或行动。
- 误用风险：只炫设定而不回到主角，会夺走主角代理权。

## HM-002 低估物件的延迟功能跃迁

- 表层表现：盘龙戒指先被当作廉价饰物，灾难中才显露真正身份。
- 因果链：普通用途 → 可信低估 → 中途微回扣 → 选择/危机触发 → 身份与功能翻面 → 新责任。
- 心理机制：共同低估制造认知落差，跨章回扣让早期细节产生复利。
- 证据：第 6-7、17-19 章（A）。
- 可替换：载体、普通用途、触发条件、揭示者、回报方向。
- 迁移条件：延迟期至少有一次可复盘但不泄底的回扣。
- 误用风险：提示过重会泄底；间隔过长且无回扣会被遗忘。

## HM-003 高成本选择触发因果型机缘

- 表层表现：林雷先护弟受伤，鲜血才触发早已埋下的戒指。
- 因果链：资源预埋 → 不可回避的选择 → 主角主动承担 → 可见代价 → 资源触发 → 回报附带新门槛。
- 心理机制：读者把回报视为人物品质与行动的结果，而非随机送挂。
- 证据：第 16-21 章（A）。
- 可替换：危机、保护对象、代价、资源载体、回报类型。
- 迁移条件：代价必须在回报前真实落下，回报后立即建立任务或限制。
- 误用风险：虚假代价或即时超额回报会显得功利机械。

## 跨机制组合

HM-001 提供远景，HM-002 承担长延迟，HM-003 把人物选择与机缘连接；三者共同完成“想变强—值得等—回报有因”的开篇追读结构。
