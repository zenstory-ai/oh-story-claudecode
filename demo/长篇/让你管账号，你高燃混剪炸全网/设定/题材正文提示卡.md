# 题材正文提示卡

> 来源：`设定/题材定位.md` ＋ 题材卡「都市脑洞」（主，高置信）＋「星光璀璨/文娱」（辅，高置信）。只管正文层题材味，不覆盖细纲与 `设定/文风.md`。

- 题材边界：都市系统文娱（军事主旋律）。系统只出题和结算，作品落地全靠江晨的创作与执行；军宣内容受组织审核与领导决策约束，绕流程要有说明。
- 核心逻辑：现实身份被看轻或指标被认为不可能 ＋ 地球神作介入 ＋ 旁人误判 → 当场翻盘。系统面板只给目标、奖励、限制三件事，立刻回到江晨的反应。
- 读者期待：每章有一次看得见的阶段小成果（新技能用上、作品剪出成品或播放数据跳涨）和一次外部反馈（围观者、领导、网友、老兵）；才华必须通过公开场面被看见，不能只写网友震惊。
- 核心爽点/情绪：小爽是技能或收益到账并被人看见；中爽是围观者态度反转（从质疑到「对不起」）；大爽是作品改写旧秩序（热搜、官方背书、国运结算）。主旋律泪目叠在爽点之上，热血与鼻酸交替。
- 正文落点：开场落到系统提示、手机消息、领导召见或公开评价；冲突落到硬指标、审核边界、舆论误判；结尾落到新任务、倒计时、热搜发酵或陌生来信。
- 前中后期写法：本卷后段——围绕任务时限、审核边界、领导预期与公开反馈推进，规则越爽越给限制；把奖励异常、热搜发酵与身份线合并，结尾留新任务或更大舆论风险。
- 节奏密度：番茄短平快；高压/推进章每章至少推进两环（被质疑 → 展示 → 反响 → 资源变化）；关系章可弱爽点但要有往下看的理由。
- 场景颗粒：系统【】播报、手机私信、热搜截图、团部办公室、排练厅、录音棚、训练场、老兵客厅、弹幕评论区。
- 对话与声线：系统冷、人热；领导画饼、江晨面上立正心里吐槽；网友情绪化、军迷科普腔；老兵原话短而实。
- 禁止漂移：不连续贴面板、不罗列奖励；不让江晨没有主动选择；不写空泛口号，主旋律靠老兵原话与作品台词撑；歌词不整段引用；不把军宣写成娱乐圈换皮。
