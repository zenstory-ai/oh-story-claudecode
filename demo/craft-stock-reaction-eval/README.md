# 固定身体微动作收敛实验

## 结论

`72c39e1` 的“写法八问”能把技法变成交付问题，但单独使用没有稳定收敛“指尖/指节/喉结/声音放轻”这类库存反应。它仍保留“扫描情绪词逐个替换”“反应 = 具体身体动作”的上游规则：A→B 后身体部位提及为 `27→28`，严格套式命中为 `1→7`，双盲语义计数只从 `6.67→6.33`，不足以视为直接修复。

候选规则把 C/D 两组合并后，相对 A/B 两组合并：

- 身体部位提及：`55→19`，下降 65.5%；
- 严格套式命中：`8→2`，下降 75%；
- 双盲非功能反应均值：`6.50→5.17`，下降 20.5%；
- 新 hook 触发篇数：`4/6→2/6`；
- 八个情节点覆盖率都为 `8/8`，综合质量均值由 `3.92→4.17`，没有用漏情节或降质换指标。

因此实现采用两层防线：先修生成规则，不再把身体微动作设为情绪的默认译法；再吸收八问的“必须举证”机制，要求交付摘要逐处说明删除/保留理由。正则 hook 只做保守 advisory，用于召回候选，不把身体描写设为禁区。

## 设计

测试对象是《让你管账号，你高燃混剪炸全网》第 20 章《老兵的礼物》。该章同时包含老兵落泪、家属致谢、主角收礼等高情绪节点，容易诱发通用身体反应。固定输入为第 19 章、同一份第 20 章细纲、文风、题材、关系、角色卡与世界观。

四组各独立生成 3 次，共 12 篇：

| 组 | 写法规则 | 用途 |
|---|---|---|
| A | `590d10e` 中的 `writing-craft.md` | `72c39e1` 的父提交基线 |
| B | `72c39e1` 中的 `writing-craft.md` | 隔离八问内容增量 |
| C | 本 PR 的 `writing-craft.md` | 反库存反应规则 |
| D | C + `72c39e1` 的八问作为显式交付文件 | 检验两者兼容性与交付 wiring |

A→B 只回答八问内容在原规则上的增量；C→D 回答显式自检能否继续改善候选规则。A/B 与 C/D 的跨组比较是方向性证据，因为候选规则基于更新后的主分支。

所有生成统一使用：

```text
codex-cli 0.148.0
model: gpt-5.4
codex exec --ephemeral --ignore-user-config --ignore-rules \
  --skip-git-repo-check -s workspace-write -m gpt-5.4
```

实际生成 prompt 见 [PROMPT.md](PROMPT.md)。12 次都是独立临时会话，输出未经人工润色。两篇略低于 2200 字下限（分别少 18、31 个非空白字符），但仍完整覆盖 8 个情节点；没有样本新增越界事件。

## 预注册指标

主要指标：

1. 双盲评审统计的非功能性身体/声线反应：只标注上下文已经明确的情绪，没有新增信息、选择、关系变化、物件状态或动作后果。
2. 固定短语簇命中：部位与“轻轻、微微、一下、攥紧、泛白”等弱反应，以及固定声线比喻。
3. `stock-reaction-tic` 是否触发。

功能性反应不算问题，例如“手抖险些摔手机”产生了物理后果，“信封被攥皱”改变物件状态，获得钢琴技能后活动手指是在验证能力。

次要指标是 8 个情节点覆盖、是否越界、自然度、场景具体度与综合可读性。两个额外的 Codex 临时会话只看到随机编号 S01—S12，不知道组别；每处语义计数必须附原文引用与理由。两名评审虽绝对计数尺度不同，但组间方向一致：

| 评审 | A | B | C | D |
|---|---:|---:|---:|---:|
| blind judge 1 | 8.00 | 8.00 | 6.33 | 5.67 |
| blind judge 2 | 5.33 | 4.67 | 4.67 | 4.00 |
| 平均 | 6.67 | 6.33 | 5.50 | 4.83 |

## 限制

这是单章、单模型、每组 3 次的探索性实验，不声称统计显著性。语义盲评仍由同一模型家族完成，绝对计数存在尺度差异；因此结论同时要求两名评审方向一致、机械指标下降、情节覆盖不降。hook 是保守召回器，不应自动删除命中；最终判定仍是“删掉后是否损失叙事功能”。
