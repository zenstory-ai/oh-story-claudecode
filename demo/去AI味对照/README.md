# 去AI味对照 — `/story-deslop` 的确定性检查

[English](README_EN.md)

`story-deslop` 的本地检查是**写作 lint**：逐条匹配已知的 AI 句式模板，给出行号、命中片段和改写方向。
blocking 项阻断，advisory 项交人工判断。

本目录三个文件：

| 文件 | 说明 |
|---|---|
| [`改前.md`](改前.md) | **人工构造**的 AI 腔样例，用来展示检查器能抓到什么。不是 skill 的输出。 |
| [`改后.md`](改后.md) | 同一场戏（排练厅第一次弹琴）的正文原样，取自 [`第021章_离别怎么会开花`](../长篇/让你管账号，你高燃混剪炸全网/正文/第021章_离别怎么会开花.md)——那是 `/story-long-write` 在一次真实会话里写出来的，之后人工合并过段落。 |
| 本文件 | 两次真实扫描的完整输出。 |

复现命令：

```bash
node skills/story-deslop/scripts/check-ai-patterns.js --check --fail-on=blocking demo/去AI味对照/改前.md
```

两段写的是同一件事。差别在于改前用抽象判词替读者定性，改后把同一件事交给可见的动作和物件。

> 检查器只处理确定性的句式与标点问题，读感仍需人工判断；朱雀等外部 AI 检测只作自测参考，不是本检查的目标。
