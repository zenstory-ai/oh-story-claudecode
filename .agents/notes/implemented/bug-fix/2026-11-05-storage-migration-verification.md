# Agent Note: 正文布局迁移与关联资料验收

Status: implemented

## Problem

本地人工测试发现：小样本分卷转平铺只移动正文，测试说明仍记录旧结构；大样本把“分卷”误解为多本作品，只改大纲并报告完成，167 章正文仍平铺。现有工具只支持登记布局，缺少实际迁移和验收。

## Decision

提供冻结计划、正文与配置及关联资料备份、实际移动、正文哈希验收和旧路径复扫。全文扫描书目录的说明文件，精确路径可以同步替换，目录树和自由描述留给 Agent 同轮核对，存在待核对项时不能报告全部完成。分卷默认指同一本书，不拆书、不重排剧情或改动大纲；只有请求含义不清时才提问。测试仅在副本执行，不修改作者正在使用的项目。

## Alternatives considered

仅靠流程提醒不增加代码，但已出现只改规划就报告完成的问题；采用可核验的迁移工具。盲目替换所有卷名最省事，但会误改故事卷名和历史叙事，因此只自动替换精确路径，其余登记待核对。

## Consequences

迁移结束须分别报告正文布局与关联资料完成情况，备份固定在书目录 `.backup/`。真实小说与日志不入库，只记录去除私人内容的事实、数量与验证结果。
