# Agent Note: 消除 skill 与案例中的晦涩术语、电报体和公文腔，补齐网文质感

Status: implemented
Date: 2026-11-05
Related: [写手热路径技法与去味方法对齐](2026-10-17-writer-hot-path-align-deslop.md)

## Problem

创作类 skill、`demo/` 和 `docs/` 的示范文字里有四类读感问题。模型和作者都会照着示范写，所以这些问题会传到正文里：

1. **自造词与等号公式句**：「二级结构化装逼技法」「任务战果量化器」「三轨叠加」「正向/反向势能」「意难平模因」「赌代入复利」「三级功能跃迁」「W 形局部震荡」以及 `A = B`、`A -> B`、`beat` 这类公式化写法，作者看不懂，模型照抄后还会写进给作者的汇报。
2. **碎句与失真示例**：第 21 章 92 个自然段平均每段 22 字，叙述也一句一行；`dialogue-mastery.md`、`long-suspense.md`、`long-reversal.md`、`villain-and-reveal.md`、`style-combat-face.md`、`genre-writing-formulas.md` 的部分内联示例偏口号化或带有因果与常识漏洞（如假金锁刻「金包铜」、假画印「中国制造」、揭发自家公司违法骗保），缺少网文场景里动作、物件和话锋落点的真实质感。
3. **公文腔与文档错位**：`docs/` 的部分示范读起来像办事流程，且存在误挂的括号说明（在非命令示例前挂了 Codex 斜杠替换提示）与过期的 skill 数量。
4. **模板套话**：细纲第 001–020 章的辅线、感情线和下一章推动力三个字段，20 章逐字相同；事件线只是把本章结构公式套进同一个句式。这些行没有提供这一章的任何信息。

## Decision

- **自造词、英文行话与等号公式换成自然中文，把只描写成品特点的抽象标签改为具体可下笔的步骤，删去跨文件重复表格与冲突口径**。`banned-words.md` 的「二修伪自然」改为「二次改稿假自然」，`style-combat-face.md` 的「二级结构化」改为「让震惊变成利益反应」，`format-and-structure.md`、`scene-craft.md` 等文件中的 `beat` 统一改为「小节/节拍/节点」，`character-basics.md` 删去动机链的 `Cause/Intent/Constraint/Risk` 英文注脚并将反派「优势即致命缺陷 / 破得高级智慧 / 敏感性 / 逃避 / 降调不降人 / 超额收获法 / 配角衬配角 / 新地图衬托旧角色含金量」改写为可直接排戏的具体动作与限制做法，`long-genre-mechanics.md` 将「界限感扩容技术 / 自爆类金手指 / 迪化流」改写为「跨题材元素缝合三步法 / 出糗换奖励类 / 旁人脑补拔高」，`plot-core-methods.md` 与 `outline-methods.md` 将「交叉死磕 / 激励 vs 逆转 vs 转折 / 以小博大 / 歪打正着」改写为具体分镜与排纲做法，`long-genre-catalog.md` 与 `genre-prose-cards/流派兜底.md` 将「加工成情绪缺口 / 多角度循环 / 设定扩展循环 / 回调必须升级 / 来自虚假自信 / 服务尊严与社会质感 / 逼近 vs 扭曲 / 节能原则 / 救赎文零和博弈与连锁效应」改写为白话操作步骤，`short-craft.md`、`scene-craft.md` 与 `流派兜底.md` 将内部术语「任务卡点」改为「主角眼下急事受阻」，`genre-styles/` 补齐 `世情打脸.md` 漏字并将 `代位受难 / 双 A / 骨科` 改为直白说明，`workflow-draft.md` 与 `genre-styles/*.md` 的「场景引擎 / 主引擎 / 慢推引擎 / 爽感引擎」、`stage3-plot-rhythm.md` 的「核心叙事引擎」及 `long-suspense.md` 的「道具变化可视化」改为白话说明，各 skill reference（含 `workflow-setup.md`、`workflow-outline.md`、`workflow-chapter.md`、`long-suspense.md`）、卷纲、细纲与拆文报告中的 `A = B` / `A -> B` 公式句及失效引用（「先于下方反应式加载」）改为完整中文陈述；删去 `style-combat-face.md` 与 `long-suspense.md` 重复的「上瘾模型」四要素表、`long-suspense.md`「期待接力法」三小节重复的并行期待线说明、`dialogue-mastery.md` 重复的科普与问答自查条目及 `emotional-methods.md` 文末第 4 次重复的「三板斧位置」表；修正 `long-chapter-quality.md` 将「日常开场」一刀切禁掉、与 `opening-design.md` 慢热/日常切口相冲突的表述，规则要点全部保留。
- **内联教学示例与案例引文补齐完整上下文、因果链、改前改后对比与题材区分，使技巧说明与案例互相印证，并通过新上下文盲读试写消除跨文件误读与题材同质化，同时守住「不添新事实」的规则示例边界**。回查经授权的网文小说库原文（含《怜春娇》《资本家小姐重生七零，不嫁竹马去下乡》《结婚后，日日想他死》《刺激！我成了对家的地下情人》《情人节的第二束花》《替身退位后，顾总跪地轻哄求原谅》《迟来的深情谁稀罕？总裁，你只是替身》《柔弱医修今天也在背地里暴打魔尊》《阴魂不散，我给媳妇烧纸钱》《职业舔狗是万人迷，大佬跪求翻牌》《重生1975，把妻女宠上天》《五一姐夫捎我十公里路，反手要我八百奶粉钱》《皇弟欺负我的幼子，我上去就是一闷棍》《准儿媳爱给人打分，我有样学样，她却不乐意了》《完美凶杀》《妹妹发高烧痊愈之后，真正的她不见了》《我的女儿在吃掉我》《阴缘》《头七夜，我把全家称给了爷爷》《侯府全员都在演戏？身为乖乖女的我当真了》《人间渡》《便宜男友桌下爱》等 34 部原章上下文），把 `writing-craft.md`（修正数字叙事表中「姐夫转一块钱」乱码例与无上下文台词，补齐道具四类实例，将「二次锚定」改为「折算成切身用度」，重写「在场者的账」去掉数学术语并补演武堂三方见证示例）、`dialogue-mastery.md`（为权力博弈压制、反转、心死三模式补齐说话人身份、利害筹码与动作结果；在「潜台词与说话目的」区分「对手交锋套话博弈」与「同立场日常/暧昧升温借公事嫌弃递台阶」，消除与感情线「试探期」同名撞车，并补酒杯倒影与保送名额/熬药对比示例）、长短篇 `emotional-methods.md` 与 `villain-and-reveal.md`（在「第一斧：羁绊铺设」补入《柔弱医修今天也在背地里暴打魔尊》同门护短正向示例，写明温情日常写到护短与回馈即可收住、不必硬立悲情遗物或死亡预兆，修正《刺激！我成了对家的地下情人》剪发忆亡母前情，补齐金锁、旧木马、打分本因果闭环，重写「弱者获援」与「情感拉扯节奏设计」改前改后对比，重写证物、证人、偷听三类揭露）、`character-relations.md`（在「感情线阶段」区分跨章推拉与单场破例照拂，将女频「深化连接」拆解为看穿表象、例外护短、舍利托底三步事件台阶，重写「感情线单元模板」）、`genre-prose-cards/古风世情.md` 与 `东方仙侠.md`（补齐日常起居照拂与休整过渡章切入点及轻巧章尾落点，不再要求低压章也必须有人重新站队、亮物证或押命牌劫兆）、`long-suspense.md` 与 `long-chapter-hooks.md`（重写「触发型钩子」单章炼丹四层加码示例，在「悬念强度分级」补齐 1-5 级赌注与停顿点写法，为章首/章尾钩子表补齐 7 处截断引文的前情处境）、`long-reversal.md` 与 `short-reversal.md`（将身份、视角、动机、认知反转表与五种误导技巧重写为闭环案例，把「加法路径/减法路径」改为「借真动作套假原因/只露半截实情」并补虐恋悬疑与甜宠轻喜双画风示范，将「信息分层」重复的抚养遗孤例统一改为《怜春娇》冷面世子挪耳房箱笼回主屋的温情错位例，在「反转自检清单」为无反转甜宠/轻喜留出心动试探与反差笑点口径）、`hooks-chapter.md` 与 `genre-styles/*.md`（为节尾与段落钩子补入甜宠「悬着的糖」与轻喜心思错位收节示例，在 `甜宠.md` 与 `沙雕脑洞.md` 补齐钝感吐槽与心动慢镜头切换指引，并为各题材包截断引文补齐人物关系与现场处境）、`style-combat-face.md`、`genre-writing-formulas.md` 及 `demo/` 拆文报告与卷纲中的缩写行话，替换为零背景作者一眼能看懂的具体写法；而 `writing-craft.md` 的林父写字示例与 `story-deslop` 的「保留既有事实」正反例严格保持原有事实边界，不为读感额外添加原文没有的情节。
- **第 21 章只合并段落，用词不动**。段落由 92 个合并为 59 个，只动换行和分句标点，爆点、钩子和系统播报仍独立成行，`visible_chars_v1` 仍为 2068。`demo/` 的说明写明段落是人工合并的，`去AI味对照/改后.md` 与对照表同步。
- **长篇连续性规则与逐章事务示例对齐（不新增记忆系统或改写历史基线）**。按职责分别在 `plot-core-methods.md`（「过渡章与衔接」跨章承接处：前章承诺或打算后章先兑现或交代受阻原因、人物改主意须有新阻碍或新信息触发）、`outline-methods.md`（「高潮与对手梯队」倒推目标链处：角色只凭眼下所知行动、不拿结局倒灌立场）与 `long-genre-mechanics.md`（「防战力崩坏」处：已亮明的能力上限、冷却与代价跨章一致）补齐连续性底线；同步修正 `tracking-transaction.md` 第 10 章事务示例中时间线事件 ID（对齐 `追踪/时间线/作者真相.md` 的 `E005`）并补齐江晨首章已解锁的「天王级唱功」能力项。
- **短篇完整结构、题材风格卡对齐与去数字配方**。在 `workflow-design.md` 与 `emotional-methods.md` 明确开头承诺、中段升级、反转与结尾须围绕同一矛盾闭环；在 `short-reversal.md` 与 `long-reversal.md` 规定动机反转须从开篇即支配角色行动（不中途偷换动机）、认知反转前期冷硬须为隐情下的必要隔离（不靠事后补设定强行洗白，将「冷漠不管家」改为可隔离连带债务的「冷漠提分居」），并在 `villain-and-reveal.md` 将延迟剥洋葱示例改为三步因果递进链；消除 `short-craft.md` 与 `workflow-draft.md` 同 `genre-styles/*.md` 题材卡的冲突（明确「受虐宣泄→心死开关→冷静审判」专用于虐爽类，允许悬疑调查链与豪门物证慢推在冲突拉扯中分节推进，开头氛围豁免补入民俗怪谈与规矩炸弹）；去掉 `emotional-methods.md`、`workflow-draft.md`、`workflow-design.md`、`short-craft.md`、`short-reversal.md`、`long-reversal.md`、`villain-and-reveal.md`、`genre-writing-formulas.md` 中的固定百分比与凑数阈值（如 `60-70%`、`虐30%→觉醒15%`、`至少相隔 3 节`、`前 100 字 ≥ 3 个事件`、`至少埋 3 处暗示`），改为按因果与功能定位。
- **`docs/` 示范换句子、清错位括号，不换情节**。人物、证据、时间和数字沿用原设定，只加了柜台、镊子这类不影响判断的动作细节；去掉非命令引用块前误挂的 Codex 替换说明，统一中英文文档的 14 个 skill 计数。
- **细纲四个字段逐章写实**。内容取自该章和下一章细纲已有的事实，没有支线或感情戏时直接写没有。每章重复的「预算说明」和「（沿用现有细纲）」删掉，不为单个情节点拆字数的规则仍在 `outline-methods.md`。
- **《曾将爱意私藏》原文只改四句翻译腔**，这是作者自己的作品。`demo/短篇-曾将爱意私藏.txt` 补上书名，与 `原文/原文.txt` 保持同一份文本；情节节点的引文，以及 `story-short-analyze` 引用旧句的白描正例同步。
- **模板规定的取值不改**。拆文报告的功能标签（情绪承载者、压迫源、反转触发器、道德锚点、对照组）和写作手法的「信息操控」来自 `story-short-analyze` 的输出模板，读起来再硬也保留，否则样例和模板对不上。
- **写法规则不为读感让步**。`writing-craft.md` 的林父写字示例和 deslop 三份 reference 的示例保留原有事实，「不得为连贯添姿态、感官、动机或观察时点」这类约束不删；`expression.md` 里只把「已有语义关系」写成具体的因果、转折、条件、先后。

## Alternatives considered

1. **把示范改得更有戏，加入原文没有的细节和冲突**
   - **最强理由**：单看一段更抓人，更像连载正文。
   - **弃用原因**：这些示范多数在演示「不新增事实」「证据只证明这一步」。加了「差三十两」「吃回扣毁堤」这类新情节，示例就和紧邻的规则矛盾；俗套表情和程度副词也会一起带进来，等于用一种 AI 味换另一种。
2. **把细纲四个字段直接删掉**
   - **最强理由**：改动最小，空话也一起没了。
   - **弃用原因**：第 21 章的细纲有这些字段，第 001–020 章是它的前文样例。逐章写实后，字段才对续写有用。
3. **第 21 章同时润色用词**
   - **最强理由**：还能顺手去掉几处重复的「半分」「半拍」。
   - **弃用原因**：这一章是 `/story-long-write` 真实会话的产出，README 引用它的字数和检查结果。改用词后，样例就不再代表 skill 的实际输出。

## Consequences

- **收益**：示范文字的自造词和跨章复制的套话清掉了，事实和原有规则没有丢。
- **收益**：第 21 章仍能作为真实产出引用，字数口径不变。
- **代价**：第 21 章仍留着模型原稿的少量口癖，比如「半分」「半拍」。
- **代价**：拆文报告保留了模板术语，读起来比正文硬。改这些词要先改模板，不在这次范围内。
- **代价**：`docs/` 示范的写法和 `demo/` 正文的事实，现有守卫只查结构和字数，读感靠评审守住，以后改写仍可能带进新事实。
- **代价**：`demo/拆文库/曾将爱意私藏/拆文报告.md` 仍有早于本次的模板差异（缺主结构、投稿层小节，保留旧阈值，部分引文不逐字），本次未补。
