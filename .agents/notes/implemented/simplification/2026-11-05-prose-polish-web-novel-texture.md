# Agent Note: 消除 skill 与案例中的晦涩术语、电报体和公文腔，补齐网文质感

Status: implemented
Date: 2026-11-05
Related: [写手热路径技法与去味方法对齐](2026-10-17-writer-hot-path-align-deslop.md)

## Problem

创作类 skill、`demo/` 和 `docs/` 的示范文字里有四类读感问题。模型和作者都会照着示范写，所以这些问题会传到正文里：

1. **自造词与等号公式句**：「二级结构化装逼技法」「任务战果量化器」「三轨叠加」「正向/反向势能」「意难平模因」「赌代入复利」「三级功能跃迁」「W 形局部震荡」以及 `A = B`、`A -> B`、`beat` 这类公式化写法，作者看不懂，模型照抄后还会写进给作者的汇报。
2. **碎句与失真示例**：第 21 章 92 个自然段平均每段 22 字，叙述也一句一行；`dialogue-mastery.md`、`long-suspense.md`、`long-reversal.md`、`villain-and-reveal.md`、`style-combat-face.md`、`genre-writing-formulas.md` 的部分内联示例偏口号化或带有因果与常识漏洞（如假金锁刻「金包铜」、假画印「中国制造」、揭发自家公司违法骗保），缺少网文场景里动作、物件和话锋落点的真实质感。
3. **公文腔与文档错位**：`docs/` 的部分示范读起来像办事流程，且存在误挂的括号说明（在非命令示例前挂了 Codex 斜杠替换提示）与过期的 skill 数量。
4. **模板套话**：细纲第 001–020 章的辅线、感情线和下一章推动力三个字段，20 章逐字相同；事件线只是把本章结构公式套进同一个句式。这些行没有提供这一章的任何信息。

## Alternatives considered

1. **把示范改得更有戏，加入原文没有的细节和冲突**
   - **最强理由**：单看一段更抓人，更像连载正文。
   - **弃用原因**：这些示范多数在演示「不新增事实」「证据只证明这一步」。加了「差三十两」「吃回扣毁堤」这类新情节，示例就和紧邻的规则矛盾；俗套表情和程度副词也会一起带进来，等于用一种 AI 味换另一种。
2. **把细纲四个字段直接删掉**
   - **最强理由**：改动最小，空话也一起没了。
   - **弃用原因**：第 21 章的细纲有这些字段，第 001–020 章是它的前文样例。逐章写实后，字段才对续写有用。
3. **第 21 章同时润色用词**
   - **最强理由**：还能顺手去掉几处重复的「半分」「半拍」。
   - **弃用原因**：这一章是 `/story-long-write` 真实会话的产出，README 引用它的字数和检查结果。改用词后，样例就不再代表 skill 的实际输出。

## Consequences

- **收益**：示范文字的自造词和跨章复制的套话清掉了，事实和原有规则没有丢。
- **收益**：第 21 章仍能作为真实产出引用，字数口径不变。
- **代价**：第 21 章仍留着模型原稿的少量口癖，比如「半分」「半拍」。
- **代价**：拆文报告保留了模板术语，读起来比正文硬。改这些词要先改模板，不在这次范围内。
- **代价**：`docs/` 示范的写法和 `demo/` 正文的事实，现有守卫只查结构和字数，读感靠评审守住，以后改写仍可能带进新事实。
- **代价**：`demo/拆文库/曾将爱意私藏/拆文报告.md` 仍有早于本次的模板差异（缺主结构、投稿层小节，保留旧阈值，部分引文不逐字），本次未补。
- **代价**：单条技巧与案例虽已全部改写为白话并补齐因果，但作者自己动手翻阅时，长篇单章仍需跨多份参考文件拼合（松紧档位、主角选择、悬念分级、钩子、对话、文风），鲜活案例客观上仍有被直接照搬表面道具（如铜胎假金锁、木马、手炉炭账）的锚定风险，且长篇中盘连载疲劳期救场与西幻、赛博朋克等次要赛道受 35K 热路径预算所限，颗粒度仍不及主力赛道。
