# Agent Note: 写手不再交时空表、不再默认交错，自检只核情节点覆盖

Status: implemented

## Problem

narrative-writer 交付时要附一张时空表（按时间连续、地点相同分块，标 `点N(跨度)`、`点N(前半/后半)`），铁律 2 和 writing-craft 还要求同一时空内的情节点默认交错落地、逐对自问「插进去坏不坏」。这一套是为反「平推」加的，每章都要写手多想一轮、多交一张表，主会话再核一遍。

2026-08-26 的反平推对照（两本书四章，60 次真实写作）里，四种改顺序的做法（时空表默认交错、块内自由织写、无编号场景卡、每场一条贯穿动作）都没跑赢基线；得分最高那一臂的成稿交错数恒为 0。PR #373 随后的预注册重复实验也没能确证「具体度」提示的收益。也就是说，交错偏好和时空表都没有证据撑腰。

写手另有两段重复：「写前静默预检」六条大多和铁律、prompt 槽位重叠；对话自检的「九症状」清单与写手本来就读的 dialogue-mastery 各管一份。

## Decision

- 铁律 2 与 writing-craft「从细纲到正文」只说同一场戏的几个点可以互相打断、不必排成逐点清单，因果或节拍需要时串行；删掉「默认交错」和逐对判据。
- 写完后自检第 1 条改为覆盖自检：细纲每个情节点至少落地一次，逐点记下落在哪一场。交付附件的「时空表」改为「情节点落点」（`点N：哪一场`，一行一点），workflow-chapter 步骤 8 改为核情节点落点。
- 删掉「写前静默预检」，只留原第 5 条作为「开局」规则（接上一章最后的动作/台词/现场）。
- 对话九症状并进 dialogue-mastery「绝对禁止」表，写手对话自检改为按该表逐句过。
- 质检侧的三套删除测试（反套话四问、三维遮盖法、质检八问）收成两块：writing-craft 第 1 节「套式反应删除测试」和自检方法里的「写法抽查」表；去味审查 prompt 只引用这两个名字。

## Alternatives considered

- **保留时空表，只删默认交错**：最强理由是时空表让主会话不读全文也能核覆盖，并能暴露「同一场戏被切成清单」。否：覆盖只需要「点 N 落在哪一场」，分块和跨度标记是为交错服务的；实验里交错度和读感无关，保留整张表的成本没有回报。
- **连覆盖清单也删掉，全交给检测器**：最强理由是 bench 的 coverage 评测里两版都接近 1.00，漏点很少见。否：细纲照搬检测只看词面，查不出漏点；落点清单几乎不占 token，是主会话唯一便宜的漏点证据。

## Consequences

- **收益**：写手指令和交付都变短，写手不再为交错去重排本该顺叙的戏；对话规则只有一份。
- **代价**：「同一场戏被机械切成逐点清单」不再有专门的交付物暴露，只能靠写手自己和审稿发现。
- **重访条件**：若后续有预注册实验证明某种编排约束能稳定改善读感，另开笔记并与本篇互链。
