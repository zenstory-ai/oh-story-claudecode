# Agent Note: 开书确认正文布局与阿拉伯数字卷号

Status: implemented

## Problem

开书确认表未列正文存储方式，作者已给选题时模型可能跳过布局选择。中文卷号不便目录排序，新项目需要统一使用卷1、卷2等阿拉伯数字。

## Decision

正式开书先确认正文平铺或分卷，作者已明确就沿用，不推迟到写第一章。新分卷目录使用 `卷1_卷名`，配置按卷号数值排序并拒绝重复卷号。已有中文卷目录兼容读取和缺配置时自动登记，不自动改名。分卷范围尚未规划时，已选方式先记题材定位「作者已定」，出卷纲后补齐配置，不虚构范围。

## Alternatives considered

统一重命名旧卷可让所有书完全一致，但会影响既有路径引用和作者改稿，因此仅约束新建。要求三位零填充方便纯字符串排序，但用户希望卷1、卷2形式；工具按数值排序，不依赖文件名补零。

## Consequences

开书时确定正文存法，新卷配置中的卷2先于卷10。系统文件管理器的排序仍由其设置决定。尚未规划的卷范围不伪造；这段时间保留已确认的方式，写正文前补齐配置。
