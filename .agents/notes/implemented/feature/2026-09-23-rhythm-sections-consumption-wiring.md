# Agent Note: 节奏.md 四个无消费小节接入写作管道

Status: implemented

## Problem

`剧情/节奏.md` 八个小节中只有四个（关键信息推进表、爽点循环、触动点、爆发节奏总结）被写作管道消费；「全书情绪节奏总览」与「循环单元」自 main 契约时代起就只进拆文报告摘要，新格式新增的「关键双时间线（EV/RV）」「三维节奏表（AX）」同样零消费。同时新版逐章摘要不再携带扩写技法表，benchmark-recall (e) 主会话路径对新格式书会「必读摘要却无技法可读」——explorer 模板已有新旧分叉，主会话路径没有。

## Decision

新消费全部挂在建纲一次性固化点，逐章热路径零新增读取；新增节缺失一律跳过、不记 gap、不扩大 `missing_primary_contract` 语义；细纲/正文仍只消费剧情单元卡。

- 总览 → 全书阶段边界按情绪折线/高潮分布校准比例（workflow-setup Phase 2）；对标节奏迁移「标关键点」以高潮分布＋冲突升级路径为首选锚，摘要转折点＋基调突变降为校验锚（总览缺失回退纯摘要扫描——旧书兼容闭环）；爽点频率作章节定位高低压参考。
- 循环单元 → 剧情批召回提炼 5-8 拍以中/大循环为骨架；细纲钩子链可参考小循环形态（可选不阻塞）。
- AX 三维节奏表 → 剧情批召回取同区间篇幅展开度与展开/压缩手法，写入单元卡章功能分配的展开取舍（唯一讲字数分配的对标数据）。
- EV/RV 双时间线 → 仅信息揭示类单元条件消费：回查同区间披露路径写入单元卡揭示/伏笔规划。
- benchmark-recall (e) 补新旧分叉：新版摘要读 信息变化/状态变化/章尾钩子/三维节奏 字段，旧摘要读扩写技法表——与 explorer 模板既有口径对齐。

改动仅四份写作侧文档（workflow-setup / outline-structure-theory / benchmark-recall / doc-budget），不动 explorer 模板与适配层。

## Alternatives considered

- **EV/RV、AX 进逐章写前召回**：最强理由是写正文时信息最鲜活；但逐章已有 rhythm_reference 与匹配章章级三维节奏字段，再读宏观表是热路径预算膨胀且逐章重复，价值在建卡时一次性固化，弃用。
- **总览锚完全替换摘要转折点锚**：最强理由是省一遍摘要扫描；但旧书总览粒度参差、新书摘要锚已稀，两锚互验比单锚可靠，改为首选＋校验分层。
- **新增节缺失记 gap**：最强理由是可观测；但会给旧书制造常态噪音 gap，且这些消费全是增益型参考，静默跳过即可。

## Consequences

收益：新格式增量产出（EV/RV、AX）从「只进报告」变为建纲实际输入；关键点标定从逐摘要扫描降为一处集中读取，新格式书摘要情节点变稀后的锚缺口被总览补上；(e) 对新旧两代摘要都有明确取用路径。

代价：剧情批召回单次工作量增加（多读节奏.md 三个小节）；五条路径预算显式上调（+30~+150，why 已记）；总览质量参差的旧书上首选锚可能弱于摘要锚，靠校验锚兜底。
