# Agent Note: 正文分卷路径与宿主守卫

Status: implemented

## Problem

长篇正文按卷存放在 `正文/卷目录/第N章*.md` 时，章节查找与各宿主写前、写后守卫的路径口径不一致。缺细纲的章节可被放行，占位正文也可能绕过兜底检测。

## Decision

同时支持直属 `正文/第N章*.md` 和一层分卷目录 `正文/卷目录/第N章*.md`。书目录始终由 `正文/` 定位；细纲、追踪检查点、上一章欠账、写后内容网与连续性检查使用同一书目录和全书章节集合。更深层目录、原稿备份和非正文章节不纳入。三份 Python 字数核心、写作 prompt、共享 JS 核及其宿主副本、Codex Python hook、Claude Bash hook 同步该路径契约，回归测试固定缺细纲、跨卷欠账、占位正文、重复章号与过深目录边界。

## Alternatives considered

- 无限制递归扫描最容易适配任意目录结构，但会把备份、临时稿和嵌套项目混入正文集合；采用一层分卷目录，路径契约可核验。
- 仅修复 JS/Codex 能解决已复现漏洞，但 Claude 和共享 Python 工具仍会与其分歧；同步所有实际写作入口。

## Consequences

分卷章节获得与直属章节相同的写前和写后保护，跨卷连续性提示也能覆盖这些章节；代价是多个宿主的路径识别与回归测试必须保持一致。既有直属章节路径继续有效。2026-10-30 起写作 prompt 的新章落点由书级配置确定，缺配置停止组装；见 [书级存储配置](2026-10-30-book-storage-config.md)。宿主 hooks 的配置位置校验仍待后续接入。
