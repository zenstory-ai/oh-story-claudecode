# Agent Note: story-publish 发布资料准备

Status: implemented

## Problem

作者写完设定和大纲后，要去平台后台填书名、简介、签约模式、标签、封面。模型凭经验填这些字段时会编标签、把某个入口的必填要求套到所有阶段，也会把作者没确认的候选当定稿。写作工程里已有的事实（题材定位、角色卡、大纲）没被复用，作者要重复回答。

## Decision

- 新增 `story-publish`，只做发布资料准备：读书目录里的已有产物，只把作者确认的值写进字段，保存为书目录下的 `发布资料-<平台>.md`。不替作者登录、填表或发布。当前只适配番茄长篇与短故事，其他平台说明未适配。
- 发布资料文件是给以后自动填表用的契约（格式版本 1）：开头每行一项元信息（格式版本、目标平台、作品类型、核验），文件名里的平台名取平台参考的 `platform` 原文；字段值只有三种——已确认的值、`（不填）`（作者决定不填）、留空（还没定，列进「待作者确认」），建议和占位词不进字段值。发布资料是平台填写值的依据，书名与写作设定不一致时提醒作者，由写作 skill 改设定和书目录。
- 运行时参考只放可执行的规则：`references/fanqie.md`（核验范围与长篇字段规则）、男/女频阅读标签、内容标签、短故事分类四个候选文件。取证过程（截图、核查报告 V1.2、来源清单）放在 `docs/evidence/fanqie/`，不随技能包分发。参考文件名不带日期，核验日期写在元信息里。
- 番茄书名规则以作家帮助中心「作品信息要求」为准（2026-10-29 读取）：长篇最多 15 字，只能用中英文、阿拉伯数字和全角 `！，？：【】`，不能有空格；短故事上限 25、半角算半个。格式检查对书名只给 WARN，作者定的书名由作者决定。
- 书名和简介确认后，请作者在“直接生成”“仅提示词”“暂缓”中选封面模式，交给 `story-cover`；`story-cover` 新增仅提示词模式（只做 Step 1-3）。完整提示词写进资料的「封面」小节。
- 平台规则写在参考文件开头：每种作品类型一行 JSON（基础字段、选项、长度上限、书名规则、标签小节和候选文件），标签候选与上限在候选文件里。`skills/story-publish/scripts/check-publish-format.py` 按元信息里的平台和作品类型找到这份规则，脚本里不写平台名；契约不合或填了平台没有的选项算失败，已确认的值可能被平台拒收（书名、长度）只提醒。`scripts/test-publish-format.py` 接入三平台 CI。
- 路由：明确要填建书资料时走 `story-publish`；只说“开书”仍进 `story-long-write`。ClawHub 暂不单独发行 `story-publish`。

## Alternatives considered

- **把平台字段加进 `story-long-write`**：能直接接上规划产物。不用：短篇和导入作品也要建书资料，平台表单的更新节奏和写作流程无关。
- **“开书”先问是规划故事还是填建书资料**：能分流两种意图。不用：作者说开书绝大多数是要开写，多一次追问拖慢最常见的入口。
- **取证记录留在运行时参考里**：维护者核对来源方便。不用：证据分级、缺口表、额度表每次调用都要读，约占必读内容的一半，却不改变模型怎么填表；截图 1.2MB 还会被复制进每个用户项目。
- **书名不合规时检查直接失败**：番茄后台本来就会拒收。不用：失败会推着模型改作者定下的书名；改成 WARN 后由模型转告作者。
- **在 Markdown 之外另存一份 JSON 给程序读**：解析最省事。不用：两份内容要保持同步，作者手改 Markdown 后 JSON 就过期；固定 Markdown 的字段行和三种取值，程序照样能可靠解析。
- **平台规则写在检查脚本里**：一处集中、改起来直观。不用：加第二个平台要同时改 SKILL 模板、脚本和测试，数字还会和参考文件各写一份。

## Consequences

2026-10-29 复数截图时发现内容标签人设组漏了「皇叔」（截图 94 个，快照 93 个），已补；其余 16 组与截图一致。

收益：每次调用必读的内容约 4.4K 字（原 13.4K），最重的叠加组合约 21.7K 字（原 32.7K）；标签和分类有截图核验，书名、封面规格有官方帮助中心依据。代价：截图只代表 2026-10-25/28 那个入口和账号条件，App、其他等级、留空拦截和提交结果都没核验，平台改版后要按 `docs/evidence/fanqie/README.md` 复核。描述里“正文约 2 万字时也适用”只是触发说明，写作流程不会主动统计字数提醒。

其他平台书名规则调研（2026-10-29，未适配，供以后扩展）：七猫后台脚本只放行中英文、数字、罗马数字和全角 `，：！？`；起点官方文章写“请勿使用标点符号”，上限 15；纵横、晋江、知乎盐言没找到符号规则。
