# Agent Note: 老书自动登记正文布局

Status: implemented

## Problem

更新 skill 后老书没有 `.story/storage.json`，即使正文布局清楚，续写也会要求作者再次手工登记。

## Decision

首次需要写作落点时，根据已有正式章节自动登记唯一可判断的 flat 或 volumes 布局。分卷范围仅登记已存在章节的最小和最大章号，不猜未来章节所属卷。混合布局、重复章号、交错卷范围或不合规范的卷目录交给作者确认，既有配置损坏不自动覆盖。

## Alternatives considered

要求所有老书手工初始化最保守，但会让升级用户重复回答已有目录能确定的信息；仅在结构有歧义时提问。按最后一卷无限延伸可直接续写，但会擅自决定未规划章节的归属，因此不采用。

## Consequences

升级用户能复用已有布局且正文不被移动。无法推断的卷范围仍需作者决定。此决定替代 [书级存储配置](2026-10-30-book-storage-config.md) 中老书必须手工登记的要求。
