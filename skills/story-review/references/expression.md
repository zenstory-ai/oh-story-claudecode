# 表达：让语言服从叙述

本文件只处理同一事实怎样说。先按 [style-resolution.md](style-resolution.md) 裁决；作者明确采用且有功能的长句、情绪直写、排比、评论与停顿标点可以保留。词表是检索入口，不是逐词删除令，也不能凭措辞判断文本来自谁。

## 先治电报体与短碎句

先连读普通叙述，找动作、思路和因果被割断的地方。电报体也会藏在长句里：位置、原因、动作各占一个独立分句，只用逗号或连词串起来，仍是逐项播报。信息和主谓宾齐全不代表叙述连贯。

先确定本段在写哪次行动或变化，再确定每句的主干。围绕主干分出主次：行动承接上一句，背景、条件和缘由嵌进需要它的动作中；用状语、定语、复句或适当概述组织，不让每个事实另起一个陈述。不必逐项照搬原句顺序，须保住事件因果、人物所知与揭露边界。

“货车在南门，她在北门，地址是她发错的。司机打来电话，问能不能把车开到北门。可北门正在修路，车开不过来，她让司机在原地等，抱起纸箱往南门跑。”信息没缺，却像念工单。可以改为：“司机照着她发错的地址开到了南门，打电话过来时，她还在北门。北门这边正在修路，货车没法过来，她只好让司机留在南门，自己抱起纸箱跑过去。”地址错误成为司机走错门的缘由，电话内容概述为人物应对，方位随行动交代。

同一行动、思路或因果链的碎句合并后，每句仍围绕一个重心，完整意思走完再断；补回必要主语、对象和原文已有的因果、转折、条件、先后关系，不靠合句数量或补虚词达标。不得为连贯添姿态、感官、动机或观察时点。

最后连读：每到一个分句都在重报一项状态，就重组句段，别再局部添字。对白也不能把每项条件拆成一行问答，让人物照提纲对信息；叙述、对白和心理的分工见 [narrative-focus.md](narrative-focus.md)。

短对白、新线索、判断变化、爆点与有意留白保留分步呈现。普通过渡恢复连贯叙述，不靠整齐长短交替达标。

## 用词与句式的风险在语境里

套词往往代替了本该说清的内容，或在不同场面机械复现。圈出原句，说明它模糊了什么、重复了什么，再决定删、压或重写。准确的普通词无须换成新鲜说法，同义词轮换也消除不了模板。

| 风险模式 | 判断与处理 |
|---|---|
| 否定铺垫后肯定翻转 | “不是 A，而是 B”“没有 X，没有 Y，只有 Z”若先否定无人在意的靶子，直接表达 B；若在纠错、辩解、排除猜测或改变判断，保留必要对比。省掉“而”不改变判断 |
| 工整并列 | 同句式、同长度、同分量铺陈，若只重复同一个结论就合并。承担情绪递进、人物声线或清晰比较时可留，不按项数删到一条。“至于 X 不 X”“不 V A，不 V B”和台词也按功能判断 |
| 万能状语与套式声线 | “带着一丝……”“声音不大，却不容置疑”“平静得像在念……”若给任何人都能用，只留可辨的语气或必要信息。普通“说”是中性标签，不必每次都用微动作替换 |
| 引号强调 | 普通名词被包装成“机会”“答案”“蜕变”而无特殊含义，去掉引号。对话、逐字引用、代号、场内消息、术语首次定义及说话者明确的反讽可留 |
| 模板比喻与抽象大词 | “潮水般涌来”“命运的齿轮”若只抬高语气，压回准确描述。能带来角色特有感受、空间关系或新认识的比喻保留，不换成另一批比喻 |
| 公文腔与故作高深 | 本可说清的事却绕成“基于当前情况推进后续事项”，按人物身份改准确。条文、职业对话、历史称谓和系统公告有自己的语域，不一律改成聊天腔 |

“很、才、连、还、又、只、仿佛、似乎、原来”可能承担程度、时间、反讽、视角不确定性或发现过程。“才二十三天”删掉“才”，评价可能已变。修饰也有区分功能，白色药片、那截链子不能仅因有定语就删掉颜色或指示关系。

## 声口来自人物此刻怎样说话

把台词放回对象、场合和意图里读：他在求助、敷衍、试探，还是公开表态？敬语、术语、绕话、重复和沉默都可能是选择。所有人都用同样完整的解释、同样漂亮的反问时，按已有身份、语言档案和上下文恢复差异，不靠人人加俚语、粗话、口误或口头禅。

润色保留原有交际目的与信息，不把解释改成挑衅、请求改成命令、克制改成失控。人物为何这样说、对方为何接受，若缺依据，转 [story-logic.md](story-logic.md)。关键交锋是否被概括、应写几轮，转 [narrative-focus.md](narrative-focus.md)。

## 情绪可以直写，动作不负责翻译情绪词

一句“他很紧张”若准确、合乎声口且让下一步成立，可以保留。心理段落也能呈现误判、矛盾、回忆和决定；长度、内心独白或“她感到／意识到”的形式都不是删除依据。上下文已表达同一情绪，补一句命名没有新作用时才删；需要读者经历的心理转变，交 narrative-focus 判断。

身体反应逐处做删除测试：删后是否损失感受、人物特点、关系含义、动作条件或后果？只有重复标注情绪的“指尖轻叩、指节泛白、目光移开”就删，不换身体部位。伤势让人握不住笔、习惯动作被对方识破等有作用的细节保留。不为显得自然新增摔杯、攥袖、锁门、录音或旁人吃惊。

## 解释与叙述者要看贡献

按本书视角区分角色当时的认识、叙述者按视角能给的信息和越过边界的预告。有限全知、作者评论、第一人称回顾都能成立；“她不知道的是”“多年以后”不能脱离叙述姿态单判。句式允许也不能提前泄露尚须保密的事实。

解释若补足新名词用途、因果衔接、记忆触发或情绪来由，应保留到足以理解。若只是把刚看到的行为再翻译成结论，或以“真正重要的是”“这意味着”把意义说满，删重复部分。不要删尽“原来”“因为”，让读者猜缺失的原因；也不要把正常说明一律转成对话。

已有手机、规则牌、信件、账单等场内载体，保留角色实际读到的信息与展示方式，语域问题先在载体内部处理。不为承载解释凭空发明表单或手续。句子通顺却仍讲不清人物为什么改变，转 story-logic；解释过多而关键过程太少，转 narrative-focus。

## 同一事实的不同表达

以下按语境判断，不作套写答案。

| 已知事实与原句 | 可采用的表达 | 看似去味却改坏了 |
|---|---|---|
| 钥匙忘在家里，明天归还；无人指责她拒还。“她不是不肯还钥匙，而是忘在家里了。‘我明天带来。’她说。” | “她把钥匙忘在家里了。‘我明天带来。’她说。”删无用靶子；若在回应拒还指责，保留纠错功能，原句保留按 [style-resolution.md](style-resolution.md) 登记白名单 | “‘爱等就等。’她说。”改变承诺与态度 |
| 她进了没开灯的屋子，摸到桌边拿药盒。“她推门。屋里没开灯。她摸到桌边。把药盒拿起来。” | “进屋后，她摸黑走到桌边，拿起药盒。”将光线嵌入行动；紧张镜头若原断句有效也可留 | “她摸黑吞了两片药。”从取药改成服药，新增数量与后果 |

## 脚本提示怎样进入语义判断

检测器是定位工具。密度提示不是词频配额，advisory 不作完成门槛。表达有功能不等于 blocking 可以不改：作者已明确选择的原句按白名单保留；其余保留叙事功能自然改写，由调用方复扫，不能以保留说明代替验收。指定原句不能改又不在白名单时报告剩余阻塞。不靠错字或拆句躲检测；确定性的事实、字数、截断与占位问题仍交调用方验收，不能靠文风豁免。

下表索引检测器全部提示类别，加粗的是 blocking。

| 提示 | 人工判断对象 |
|---|---|
| **`not-is-comparison`**、**`reverse-not-is`**、**`negation-parade`**、`negation-pair-tic` | 见上文「否定铺垫后肯定翻转」 |
| **`voice-contrast`** | 见上文「万能状语与套式声线」 |
| **`em-dash`** | 按功能改成动作、停顿或完整句，不只换符号 |
| **`trailer-ending`**、**`trailer-summary`** | 章末预告与状态总结，见上文「解释与叙述者」；收尾分量转 narrative-focus |
| `formulaic-parallelism`、`quote-emphasis-tic` | 对比与强调是否有真实意义，是否机械复述 |
| `cliche-density-tic`、`metaphor-density-tic` | 套词与比喻是否聚成同一腔调，功能是否重复 |
| `stock-reaction-tic`、`micro-action-tic`、`action-list-tic` | 反应与动作是否只是标注或清单；用笔分配转 narrative-focus |
| `period-stutter`、`overcompressed-prose-tic`、`low-connective-density-tic` | 是否真缺连接、对象和连续思路，不按计数拉长 |
| `long-paragraph` | 一段是否跨了几个镜头，按镜头断开 |
| `abstract-summary-tic`、`reasoning-chain-tic` | 总结是否重复，解释是否必要；因果缺口转 story-logic |
| `system-notice-formality-tic` | 语域是否合乎载体，角色能否理解其当下作用 |

无标记也可能机械，零命中不证明用笔与故事合格。
