# 网文去 AI 味三层指南与定点范围

> 谁读：去味、审稿或写手做三层诊断改稿时读；表达先按 [style-resolution.md](style-resolution.md) 裁决，短篇必叠读 [short-deslop.md](short-deslop.md) 以其规则为准。

核心原则：**保留竖屏节奏、直给情绪与爽虐张力，只清真 AI 腔（公文推导、翻译腔、套词比喻堆砌、空泛说教、同义复述与因果断层）**，不求严肃文学或合长句。

## 一、表达层：保竖屏节奏，清真 AI 腔

1. **竖屏短段 vs 剧本摄像头电报体**：竖屏短段靠**对白净白短打**拉轻版面，纯叙述须保留主角内心盘算与口语因果连接（`因为/可是/偏偏/省得/哪知道`），**禁抽干内心、把动作切碎成「放下茶杯/愣在原地/十分钟后」式机械电报段**，也不给每句台词捆绑道具微动作。
2. **用词与句式按语境判**：词表（[banned-words.md](banned-words.md)）仅作线索，不逐词照删。
   - **优先改写（Tier 1 真 AI 腔）**：无靶子「不是 A，而是 B」及**句号/跨行三段式否定**（`不是A。/ 不是B。/ 是C。`）；「没有 X，没有 Y，只有 Z」；公文推导与**台词 PPT 名词串烧**；万能声线、滥加引号、抽象大词、模板比喻及**正文 `**` 粗体**。
   - **语境保留**：有明确纠错对象的对比、递进排比、角色口语/术语、直写情绪、利害算账与**女频正常语感 `轻笑/低笑`（严禁误杀）**。
3. **刀子物件原则、闲笔贴纸与女频去油**：只留能改局、露破绽、割伤人的**刀子物件**；**凡无功能材质定语（骨瓷/紫檀/黄铜/磨砂/胡桃木）、熨帖穿搭、天气光影与环境音效贴纸（咖啡机嗡鸣/秋风掠幕墙/淅淅沥沥）及纯标情绪的微动作一律删**；砍**全知路人点名册**，留 1 器物后果 + 1 利害者失态；**女频去油**：删壁咚、物化称呼（小女人/小白兔）与油腻/变体氛围词（眸色一暗/宠溺/喉结轻滚/空气发烫/声音又冷又哑），改尊重边界与体面认错。
4. **声口与叙述者**：对白按身份与意图区分；直球摊牌、狠话与吐槽保留，删脱离视角的解说；短篇审判与剧透按 `short-deslop.md` 留。

## 二、用笔层：篇幅落在爽点、交锋与关键变化上

通读一场戏，先定它要让读者体验什么（打脸、反制、升温、立钩、破局或关系翻转），再按重心调详略：

| 问题 | 看什么 | 怎么处理 |
|---|---|---|
| 过场水戏占篇幅 | 赶路、寒暄、美妆穿搭清单、开篇元声明与简历墙占前 500 字 | 删前言与目录流水账，压成 1–2 句直落当下危机 |
| 关键交锋被概述 | 中段数百字无对白总结报告/相机清单/上帝读心、换场复述刚演对话，或短篇导语原句倒带 | 拆回现场交锋与具体物证；导语后零秒接不可逆动作，禁原句倒带 |
| 情绪原地打转 | 连续复述同一委屈/愤怒，或**「张嘴想说A/B/C却没说」转超长心理辩证说明书** | 删心理剖析与复述，把筹码数字拍上桌，用一句掀桌台词或改局动作推进 |
| 只见结果与空洞打卡 | 态度突兀翻转、天降降神解围，或**反派降智递话筒/零阻力套路打卡** | 补真实私心反咬、意外阻滞或前文筹码；缺依据转故事层提方案 |

**网文前后对照**：
- **断句否定+粗体**：❌ `**第二声异响。**座钟停了。不是没电。是底层协议重绘。` → ✅ `挂钟停在两点一刻。方敬凑近油灯：“老钱别碰门栓，有人拿钟摆压气口。”`
- **多人点名册**：❌ `赵大牛掉水囊，孙二狗摘帽，钱三娘发白，李四海渗冷汗。` → ✅ `剑气削过，铜香炉无声滑成两半。押韩越必败的宋师叔瓜子撒了一领口：“他真是筑基初期？”`
- **心理说明书→掀桌**：❌ `唐棠张嘴想说六年付出，委屈像落叶压心头。` → ✅ `我拿笔在协议签名栏画叉塞回他兜里：“结清上月四十二万，明早十点搬家。”`
- **PPT 台词+复述**：❌ `“把评估培训风控落地。”（换场原样复述两百万工期）` → ✅ `他圈出报价单：“德国阀换国产。”出门发老魏：“两百万四十天，敢赌翻新吗？”`
- **电报残句+闲笔贴纸**：❌ `门开了。/ 不是三叔。/ 他端骨瓷杯，秋风掠过玻璃幕墙。` → ✅ `三婶挤进院攥着借条笑：“差八万彩礼先垫上。”罗成亮手机：“去年借我爸三万还差两万八呢。”`
- **女频油腻→克制苏感**：❌ `祝衡眸色一暗，喉结轻滚低哑道：“小女人还想跑？”空气发烫。` → ✅ `雨檐下祝衡递干毛巾：“上车，顺路。”舒禾拆台：“上周不是说别太熟？”他避开视线轻声认错：“那句不算。”`

## 三、故事层与改稿权限

沿事件核对行为依据、因果承接、人物立场、解法支撑、场后变化与知情顺序。**短篇引擎（偷听、自爆、围观打脸、明确触发后快速决裂）与长篇金手指爽点属题材约定，不按刑侦或现实主义判假。**

| 普通去味直接落改 | 须作者授权（未授权只列最小方案） |
|---|---|
| 修表达、删水戏复述、恢复已有前情承接 | 新增动机、证据、身份、能力或事件 |
| 展开已定交锋与反馈、修指代/时序笔误 | 改人物决定、胜负、关系走向、揭露时机或结局 |

审稿只报不改；改后回读核对事实承接与字数下限，不凑字不砍穿。

## 按检测类别或问题限定范围

未限范围三层全检；指定类别只修该范围（范围外设计缺口单列提示）：

| 问题名 | 检查重点 |
|---|---|
| 套词、句式 | Tier 1 句式与套词判断 |
| 情绪 | 去复述 + 直写与删除测试 |
| 节奏 | 压过场、展交锋 + 短段 |
| 对话 | 筹码交锋 + 声口差异 |
| 收尾 | 兑现/卡点 + 去空泛总结 |
| 解释与安排感 | 删推导腔 + 因果知情边界 |

## 脚本提示怎样进入语义判断

脚本仅作线索，`advisory` 非硬门槛；`review_required` 优先改写，确有功能可留或登 `.deslop-whitelist`（加粗项高频 `review_required`，短篇按 `short-deslop.md`）：

| 脚本提示类别 | 语义判断重点 |
|---|---|
| **`not-is-comparison`**、**`reverse-not-is`**、**`negation-parade`**、`negation-pair-tic` | 无靶子否定铺垫；明确纠错/辩解可留 |
| **`voice-contrast`** | 「声音不大…却」；删铺垫写台词分量 |
| **`em-dash`**、`ellipsis-density-tic`、`exclamation-density-tic` | `——` 过密改标点；禁省略号刷屏；`！` 留峰拍 |
| **`trailer-ending`**、**`trailer-summary`** | 删命运/注定/鸡汤升华；短篇信息差预告留 |
| `formulaic-parallelism`、`quote-emphasis-tic` | 工整栏目与滥加引号是否机械 |
| `cliche-density-tic`、`metaphor-density-tic`、`dramatic-cliche-tic`、`romance-cliche-tic` | 套词/比喻/戏剧/女频油腻词（豁免 `轻笑/低笑`）扎堆 |
| `stock-reaction-tic`、`micro-action-tic`、`action-list-tic`、`short-plastic-reaction-tic`、`idle-prop-decoration-tic` | 微动作、塑料反应与无功能材质穿搭光影贴纸只装饰不改局就删 |
| `period-stutter`、`overcompressed-prose-tic`、`low-connective-density-tic`、`staccato-paragraph-tic` | 缺口语因果/抽干内心成摄像头电报才改；正常短段不合 |
| `long-paragraph` | 过长按镜头/对话断段 |
| `abstract-summary-tic`、`reasoning-chain-tic` | 删推导盖章，留利害算账 |
| `system-notice-formality-tic` | 面板语域是否符合载体 |

零命中不代表无问题；改后回读验爽感流畅。
