# story-review：solo 模式

当前会话直接审查，不 spawn Agent。按 Phase 1 加载通用 rubric 并叠加平台表（不可读用内置基准包）。

逐项完成基础检查：
1. **格式可读性**：短对话快推、纯叙述保口语因果与盘算（长篇禁整块文字墙、一行一句均匀碎短句与纯动作碎句；短篇禁强拆连续动作）、无空行；核叙述感叹号过密、满篇咆哮与长段单人演讲。
2. **设定一致性**：grep 角色名、属性、设定与伏笔词 + 核规则边界、跨章因果、物件流转、数值账目、时间线、线索前置与时代/行业常识。
3. **三层 AI 味与硬红线**：读 `deslop-guide.md`、`banned-words.md`（短篇叠 `short-deslop.md`）；严查**反派降智送人头/零阻力走过场**、**无功能材质穿搭空镜摆设**、**旁白人设标签与连刷因果说明句**、**纯动作碎句**与**油腻氛围词**——命中直判 S2。只报不改。
4. **内容评估**：按通用 rubric 与叠加的平台表逐维评估。
5. **追踪提醒**：长篇工程里若正文证据显示 `追踪/` 有错漏，不改 `追踪/`，把待修事实写进「需要你决定」，提示装好审稿助手后跑 `/story-review lean` 或在 `/story-long-write` 改该章时提交。
6. 按统一 Findings Schema 整理，转写为下方白话报告。
