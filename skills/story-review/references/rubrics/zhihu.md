# 短篇 Quality Rubric

## 评分标准

叠加在通用 rubric 上，用于所有短篇（知乎盐言、番茄、七猫、黑岩、红果、小程序及未定平台）。各平台的格式、引号和导语要求以 `设定.md`「平台基调」为准。

| 指标 | PASS 标准 | FAIL 标准 |
|------|----------|----------|
| 第一人称 | 采用「我」视角时，所知信息与叙述姿态一致 | 已定第一人称却无依据换视角；明确采用其他视角不据此判错 |
| 情绪拉扯 | 关键场景有期待→失望→惊喜等情绪变化，承接段服务于变化 | 连续几段重复同一情绪且无新信息或行动 |
| 反转设计 | 有反转的篇目，反转前文有伏笔 | 反转无伏笔支撑；本篇设计为无反转的，看报应或关系兑现是否落地 |
| 结尾余韵 | 兑现本篇情绪目标，收口有具体后果或情感余韵 | 只有空泛总结，或承诺的情绪没有落点 |
| 格式合规 | 段落以短为主（有长短/疏密变化）、无空行、对话格式符合平台基调 | 通篇同长度或连续超长段落/空行/对话标签 |
| 开头钩子 | 第一句用动作、冲突或悬念建立阅读理由 | 第一句纯描写/背景；跳失率须用实际数据验证 |
| 字数控制 | 全文在本次锁定的字数范围内，并符合已核实的投稿要求 | 超出或不足，且作者未变更范围 |
