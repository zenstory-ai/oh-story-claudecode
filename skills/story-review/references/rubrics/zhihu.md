# 知乎盐言短篇 Quality Rubric

## 评分标准

叠加在通用 rubric 上，用于知乎盐言（盐选）短篇。格式、引号（默认 `「」`）与导语以 `设定.md`「平台基调」为准；同时遵循 `short-deslop.md` 规则覆盖，不因竖屏单句成段或口语网感扣分。

| 指标 | PASS 标准 | FAIL 标准 |
|------|----------|----------|
| 导语紧度与入局 | 150–300 字高密度导语（人设反差、违和细节、弹幕/脑洞或致命钩子），前 100 字直入异常或对话，零纯景物开场 | 开头纯景物、空泛背景铺垫，或导语平铺直叙缺少点开理由 |
| 第一人称与网感 | 默认第一人称「我」强代入，允许口语吐槽、主观审判、剧透预告与信息差推进（另有设定照设定） | 无依据乱切视角，或通篇端着写书面散文腔、缺乏在场声线 |
| 付费折页张力 | 约 30%–40% 免费末节卡在认知翻转、高张力台词、身份危机或关键爆料上，拉住解锁欲 | 折页前情绪平直、底牌漏光，或断点无悬念拉扯 |
| 竖屏节奏与对话 | 单句成段与紧凑短段交织（中位约 20 字）、无空行、对话独立成行；不因一句一段判「通篇同长度」 | 连续 >80 字大段堆砌、多余空行、对话标签机械或原地空转复述 |
| 反转与落点兑现 | 约 40% 后持续给反转、反差爽点或剥洋葱兑现（悬疑类线索可回溯）；收口落在痛快翻盘、明账清算或强后劲反转 | 反转无铺垫、中后段塌陷，或结尾只剩空泛哲理总结 |
| 字数控制 | 全文在本次锁定字数范围内（常规 10000–13000 字），小节标记（常规 `1.`）全篇统一 | 明显超欠且作者未变更范围，或标记与引号混用 |
