# 知乎盐言短篇 Quality Rubric

叠加在通用 rubric 上，用于知乎盐言（盐选）短篇。格式、引号（默认 `「」`）与导语以 `设定.md`「平台基调」为准；同时遵循 `short-deslop.md` 规则覆盖，不因竖屏单句成段或口语网感扣分。

| 指标 | PASS 标准 | FAIL 标准 |
|------|----------|----------|
| 导语紧度与入局 | 150–300 字高密度导语（反差/脑洞/违和细节/割席回访），开头一两段直入异常或对话，零纯景物；`1.` 后直接续接现场 | 纯景物/背景铺垫、平淡无点开欲、`1.` 后重述导语梗概，或导语诈骗 |
| 第一人称与网感 | 默认第一人称「我」强代入，允许口语吐槽、主观审判与信息差（允许火葬场/死人线约四成处切 1 节施害者或末附番外、甜宠男主补糖番外） | 无依据乱切视角，或通篇端着写书面散文腔、缺第一人称口语感 |
| 付费折页张力 | **32%–44%**（约四成处）免费末节卡在认知翻转/刚掀底牌，付费后立刻兑现 | 折页前平直、断点无拉扯，或刚过半就把大招放完导致后半段发水 |
| 竖屏节奏与对话 | 竖屏短段（动作台词分行、狠话独行、叙述两三句换气）、无空行、对话独立成行（吐槽/悬疑可偏独白；禁抽干内心的纯动作碎行） | 连续大段文字墙堆砌、多余空行、间接引语代交锋或中段车轱辘复述 |
| 分题材反转与收尾 | 兼容不同题材节奏（打脸/脑洞吐槽甜宠/死人追夫 50%–55% 蓄压/悬疑公平线索）；收尾痛快翻盘、首尾呼应（开篇已埋）或强后劲反转 | 反转无铺垫、中后段塌陷、用新闻播报或判决书草草收尾、结尾硬塞呼应或哲理尾 |
| 字数控制 | 全文在锁定字数范围内（常规 10000–13000 字），小节标记（常规 `1.`）与引号全篇统一 | 明显超欠且作者未变更范围，或标记与引号混用 |
