# 女频长篇（晋江 / 番茄女频 / 七猫女频）Quality Rubric

叠加在通用 rubric 上，用于晋江全部长篇，以及番茄/七猫女频长篇（番茄/七猫女频与 `fanqie.md` 并叠）。按本书已定感情线/无 CP 定位与排雷口径审视，不拿男频单线打脸或低质霸总套路误判。短篇女频或双男主复用本表时，忽略「Ch30+」章节编号而改查中后段（40%+）主线与人设不崩；双男主重点核双强平等、去油边界与微物件张力。
