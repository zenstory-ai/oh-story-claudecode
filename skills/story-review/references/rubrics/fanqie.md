# 番茄长篇 Quality Rubric

## 评分标准

叠加在通用 rubric 上，只用于番茄长篇。下列数字是快节奏、强情绪写法的参考，不代表平台算法；先对照本书题材与已定节奏。

| 指标 | PASS 标准 | FAIL 标准 |
|------|----------|----------|
| 开头吸引力（开篇/前 3 章） | 前 3 段包含冲突/异常/利害切口，前 3 章节奏不拖 | 前 3 段纯景物/空泛背景介绍，或前 3 章连续拖沓；完读率须用实际数据验证 |
| 读者留存 | 每章结尾有"翻页动力"（悬念/反转/新信息） | 连续几章结尾都没有翻页动力 |
| 题材匹配 | 内容符合标签类型（如甜宠/逆袭/重生） | 长时间偏离标签类型 |
| 阅读节奏 | 段落便于手机阅读，节奏和信息量支撑核心卖点 | 机械切段或拖沓，信息不足以支撑阅读期待 |
| 情绪节点 | 情绪起伏密，读者隔不久就有反馈（参考：约每千字一次） | 大段情绪平直，读者等不到反馈 |
