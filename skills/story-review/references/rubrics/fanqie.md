# 番茄 / 七猫长篇 Quality Rubric

叠加在通用 rubric 上，用于番茄、七猫等快节奏长篇；先对照本书题材与既定节奏。

| 指标 | PASS 标准 | FAIL 标准 |
|---|---|---|
| 开篇抓力（前 3 章） | 首章开头快见对话并落进简介核心场景（不照抄简介，广播/奇观独白开场可稍晚）、前几百字立核心矛盾与卖点，前 3 章连环推进 | 前 3 段纯景物/百科灌水、开头塞「大脑寄存处/求好评/境界表」、照抄简介，或首章迟迟无冲突 |
| 竖屏分段与可读性 | 短对话快推独立成行，纯叙述保留主角内心盘算与口语因果连接（行文自然，无整块文字墙），只留关键改局道具 | 抽干内心因果的纯动作碎句（连发短叙述碎行）、没用的材质/穿搭/空镜摆设过载，或大段文字墙 |
| 爽点与情绪反馈 | 情绪起伏密集，爽点经对手私心反咬、意外阻滞与反预期实招赢来，每隔几段就有实利或信息推进 | 反派降智送人头、精准踩点走过场，或大段平直流水账与长期憋屈 |
| 章尾钩子与留存 | 每章结尾留明确翻页动力（悬念、反杀倒计时、新利益或身份暴露前夜） | 连续多章平淡收尾，没有让读者点下一章的理由 |
| 题材与卖点匹配 | 紧扣标签核心卖点，设定融进冲突与对话，理解门槛低 | 长时间偏离标签卖点，或大段术语/科普堆砌拖高门槛 |
