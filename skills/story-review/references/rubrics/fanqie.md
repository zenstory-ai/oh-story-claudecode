# 番茄 / 七猫长篇 Quality Rubric

叠加在通用 rubric 上，用于番茄、七猫等快节奏长篇。数字来自头部快节奏网文实证参考，先对照本书题材与既定节奏，不代表平台算法。

| 指标 | PASS 标准 | FAIL 标准 |
|---|---|---|
| 开篇抓力（前 3 章） | 首章 ≤300 字见对话、≤400 字入冲突，第 1 章亮核心困境或金手指，前 3 章连环推进不拖沓 | 前 3 段纯景物或百科设定灌水，首章迟迟无冲突/卖点，或前 3 章连续慢热 |
| 竖屏分段与可读性 | 手机竖屏短段（参考段长中位约 22–26 字），对话独立成行，视觉轻快 | 频繁出现 >100 字大段文字墙，或机械三字电报碎句影响顺读 |
| 爽点与情绪反馈 | 情绪起伏密集，约每千字有一次小反馈/信息差/打脸进展，爽感兑现痛快 | 大段平直流水账或长期压抑憋屈，读者等不到情绪回馈 |
| 章尾钩子与留存 | 每章结尾留明确翻页动力（悬念、反杀倒计时、新利益或身份暴露前夜） | 连续多章平淡收尾，没有让读者点下一章的理由 |
| 题材与卖点匹配 | 紧扣标签核心卖点，设定融进冲突与对话，理解门槛低 | 长时间偏离标签卖点，或大段术语/科普堆砌拖高门槛 |
