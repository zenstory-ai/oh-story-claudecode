# 商业短篇 Quality Rubric

## 评分标准

叠加在通用 rubric 上，用于番茄短故事、七猫、黑岩、点众、小程序及未定平台短篇。格式、引号与导语以 `设定.md`「平台基调」为准；同时遵循 `short-deslop.md` 规则覆盖，不以长篇慢热或严肃文学标准扣分。

| 指标 | PASS 标准 | FAIL 标准 |
|------|----------|----------|
| 导语与冷开场 | 150–300 字导语冷开场，前 100 字直入核心冲突/异常/对话，零纯景物；`……`/`1.` 后零秒续接下一拍现场 | 纯景物/背景说明、超 300 字未立矛盾、导语后重述梗概，或导语诈骗 |
| 竖屏短段与对话 | 对白短打独行（常规 25%–35%，吐槽/悬疑 15%–22%），连续动作因果自然并段（中位 ~20 字、无空行），只留改局刀子物件 | >80 字砖块、空行、连发纯叙述电报碎行、无功能材质穿搭氛围贴纸、间接引语或说明书 |
| 付费强卡点 | **32%–44%** 节末卡在未落巴掌/刚掀底牌，付费后首拍立刻兑现（反抗→实锤→倒戈→新赌注） | 付费点拖至 70% 后、平淡收尾，或 45% 提前清仓水尾 |
| 分轨推进与爽虐 | 按四轨验收（打脸 40%+ 反击；脑洞/甜宠靠反差糖点；死人/追夫许 50%–55% 蓄压）；反派须有真实阻滞与反咬 | 前段拖沓、车轱辘复述、反派无脑送头套路打卡过场，或公文查证稀释爽感 |
| 明账清算收尾 | 反派付实质代价、主角高位退场或迟来崩溃；用开篇已埋原物/原词打**真回旋镖**（世情可克制回甘，悬疑可留白） | 非悬疑洗白/欠账未清、用新闻播报/判决书转述水尾、空降假回旋镖或空泛哲理尾 |
| 人称与字数控制 | 默认第一人称「我」（另有设定照设定；允许火葬场/死人线单节切施害者或末附番外、甜宠末附男主补糖番外），字数、标记、引号统一 | 无依据乱切视角、明显超欠且未变更范围，或标记混用 |

> **分轨提醒**：悬疑侧重公平线索与留白，甜宠/脑洞轻喜不强造恶毒反派，不拿单一打脸公式误判。
