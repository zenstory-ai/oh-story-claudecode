# 起点长篇 Quality Rubric

叠加在通用 rubric 上，仅用于起点长篇。升级与金手指项适用于对应题材，无等级/金手指作品不据此判缺失，按本书节奏选用。

| 指标 | PASS 标准 | FAIL 标准 |
|---|---|---|
| 设定融入与可读性 | 世界观、体系与规则通过冲突和行动自然带出，手机阅读分段清爽、无大段文字墙 | 开篇或行文中大段百科说明书灌水，或长段堆砌拖垮手机读感 |
| 爽点密度 | 突破、破局、打脸、获益或揭秘等反馈间隔贴合本书节奏（参考每 1–2 章至少一次明显推进或小爽点） | 连续长段无进展与情绪反馈，读者等不到阶段兑现 |
| 升级与成长路径 | 实力/地位/认知推进有清晰台阶与代价，符合本书成长线与逻辑自洽 | 长期原地踏步，或无铺垫数值膨胀破坏体系可信度 |
| 金手指使用 | 金手指/核心依仗在关键推进中起作用，边界清晰且出场有理由 | 长期遗忘搁置，或强行降智/每章机械打卡 |
| 追读钩子与主角存在感 | 章尾有悬念或长线期待支撑追读；主角持续主导推进（群像偶切配角服务主线可接受） | 连续多章平收断期待，或主角长时间掉线旁观 |
