# 起点长篇 Quality Rubric

## 评分标准

叠加在通用 rubric 上，只用于起点长篇。成长与金手指项用于对应题材；没有等级或金手指的作品不据此判缺失。数字是参考，按本书节奏选用。

| 指标 | PASS 标准 | FAIL 标准 |
|------|----------|----------|
| 爽点密度 | 情绪或收获节点（突破/破局/打脸/获益/揭秘等）间隔与本书节奏相符（参考：约每 3000 字一次） | 长段落没有进展或情绪反馈，读者等不到兑现 |
| 升级节奏 | 实力突破的间隔与本书成长线一致 | 长期没有任何成长或突破 |
| 金手指使用 | 金手指在推进中起作用，出场有理由 | 长期搁置到读者忘了它，或每章硬提一句 |
| 追读钩子 | 章尾有悬念或钩子，情绪连续支撑后续期待 | 连续几章结尾无钩子或情绪断裂；追读比须用实际数据验证 |
| 角色存在感 | 主角持续主导推进（群像/多线偶有单章切配角或对手视角服务主线可接受） | 连续多章主角掉线或被动旁观无推进 |
