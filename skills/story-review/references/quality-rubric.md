# 通用网文内容审查 Rubric

> 每次审查均用本表评估故事质量并叠加平台表；表达默认值按 `style-resolution.md` 与本书文风裁决。短篇同时按 `short-deslop.md` 规则覆盖执行，不以慢热或严肃文学标准扣分。

## 评分方法

每项先标 PASS / WARN / FAIL，再按实际影响转成统一 Findings Schema：
- 破坏主线、角色动机、世界规则或读者信任 → S1
- 明显影响留存、节奏、章节效果或人物可信度 → S2
- 局部质量、格式、措辞、轻微节奏问题 → S3
- 风格建议或可选增强 → S4

## 核心维度

| 维度 | PASS | WARN | FAIL |
|---|---|---|---|
| 核心卖点 | 围绕明确卖点推进，读者知道为什么继续看 | 卖点存在但表达弱或被支线稀释 | 看不出本章服务什么卖点或主线 |
| 冲突推进 | 有真实阻碍、私心反咬、代价或信息推进（日常/过渡章按章定位判） | 推进偏弱，反制偏轻 | 解释/闲聊，或反派降智递话筒、零阻力套路打卡过场（机械三检 0/0/0 亦不放行） |
| 任务卡点 | 办事受阻并卡出意外变数、关系/代价或伏笔变化 | 有卡点但变化偏弱 | 纯流程水戏或单线送头打卡，删掉不影响故事 |
| 情绪曲线 | 有铺垫、升温、释放或反转 | 情绪有变化但节点不清 | 情绪平直或突兀转向 |
| 钩子与期待 | 开头/结尾至少一处建立期待 | 钩子弱但仍有后续问题 | 无悬念、目标或未完成期待 |
| 开头新鲜度（仅开篇/前 3 章） | 开局用具体人物、处境与赌注抓人；商业爆款/经典开局范式（含强动作独狼与穿书快切）有具体冲突与钩子即通过 | 有钩子但切口偏平，人物或赌注立得慢 | 空泛灌水、长篇首章对白 `<12%` 且前 500 字缺危机动作/抉择（静态简历/设定墙），或短篇导语后第 1 节原句倒带复述 |
| 角色动机 | 行为符合私心、处境与利害压力（女频守主体性与平视边界） | 局部缺铺垫 | 角色失真、反派当递话筒纸片人，或女频恋爱脑/雌竞/爹味强压 |
| 对话质量 | 有信息控制与角色差异、来回短打（长篇重潜台词；短篇强冲突场允许直球摊牌、狠话与围观烘托） | 信息略堆叠、声音略同质或偶现单轮长演讲 | 像说明书、人人同腔，或频繁 ≥60 字单人演讲 |
| 设定一致性 | 守住规则、时间线、人设及常识（线索前置、冷静期/担保；连载核搬家后物位、钱粮/余额加减、跨章倒推相对日历） | 轻微模糊需补证据 | 与设定冲突、异姓漂移（顾席→蒋席）、搬家物位/钱粮余额/相对日历穿帮、无铺垫破顶、线索未前置或违法律常识 |
| 文字自然度 | 刀子物件与直写情绪/内心盘算配合自然（短篇留反应词，女频留 `轻笑/低笑`） | 偶有微动作代偿或复读 | AI 腔、日志腔、油腻/变体氛围词（空气发烫/声音又冷又哑）或无功能材质穿搭光影音效贴纸过载（0/0/0 亦判 S2） |
| 句长节奏 | 对白净白短打，纯叙述保留口语因果与盘算呼吸感（长篇禁文字墙） | 局部碎句或臃肿长句 | 抽干内心因果的剧本摄像头电报体（连发短叙述碎行）、动作链强拆，或百字墙段（0/0/0 亦判 S2） |
| 标点节奏 | 叙述默认 `。`，`！`/`？` 服务真正峰拍（对话内 `——`、有节制 `……` 与旁白关键转折 `——` 可用；克制流派如甜宠/双男主/悬疑/校园按对应流派包） | 局部单调、`！` 略密或旁白 `——` 偏多 | 通篇句号化、叙述旁白 `！` 过密（参考 ≥10/千字）或非热血/吐槽题材全文咆哮刷屏（参考长篇 ≥22/千字、短篇 ≥21/千字）、旁白 `——`/`……` 刷屏或畸形破折号 |
| 具体字数表达校验 | 「这五个字」类表达属实且必要 | 属实但换「那几个字」更自然 | 字数不符或难核口径 |
| 格式可读性 | 段落按戏剧单元/镜头自然断开（手机竖屏适读），对话独立、无多余空行、主语节奏自然 | 局部偏长/偏碎或主语略重复 | 大段堆叠、机械切段、对话/叙述难读、主语过密或正文残留 `**` 等 Markdown 装饰符 |
| 剧情循环 | 紧章目标→真实阻滞→反咬博弈→代价/反馈→新期待；松章交代状态变化 | 缺一环或反馈弱 | 无目标/无反馈，或靠天降降神、精准踩点送头、零阻力套路打卡强推局势 |
| 高潮构建 | 高潮章蓄能、落差与兑现有层次（强反转可用蓄能→假胜→崩解→反转/兑现）；松章完成蓄力或日常兑现 | 有爆点但铺垫或兑现不足 | 应有高潮却缺铺垫、无兑现或情绪落空 |
| 关系进展 | 互动尺度匹配关系阶段，越界有铺垫（短篇有明确触发即可快速心死/翻脸/结盟） | 推进略快但可补证据 | 无触发突然亲密/信任/敌对，或女频真出轨/暴力强行洗白 HE、下药失身强绑 CP |
| 伏笔状态 | 埋设、状态与回收路径可追踪 | 偏密/偏疏但不影响理解 | 与设定冲突、断线或造成主线理解混乱 |

## 黄金三问与发布门槛

1. **读者为什么翻下一页？** 答不出至少 S2。
2. **本章改变了什么？** 情节/关系/信息/情绪至少变一项，否则至少 S2。
3. **证据在哪？** 无原文证据不出 finding，标「证据不足」。

| 综合情况 | Verdict | 报告「总体判断」 |
|---|---|---|
| 无 S1/S2，S3 可快速处理 | APPROVE | 可以发 |
| 有 S2，或 S3 过多影响阅读 | CONCERNS | 改完下面几处再发 |
| 有 S1，或卖点/动机/规则崩坏 | REJECT | 局部能修写「改完下面几处再发」，整体崩坏写「这一章/这几节需要重写」 |

输出须含 severity、category、location、evidence、issue、fix，按 S1/S2 → S3/S4 排序；事实/一致性类 fix 只写统一方向。
