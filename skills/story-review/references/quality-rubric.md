# 通用网文内容审查 Rubric

> 每次审查均用本表评估故事质量并叠加平台表；表达默认值按 `style-resolution.md` 与本书文风裁决。短篇同时按 `short-deslop.md` 规则覆盖执行，不以慢热或严肃文学标准扣分。

## 评分方法

每项先标 PASS / WARN / FAIL，再按实际影响转成统一 Findings Schema：
- 破坏主线、角色动机、世界规则或读者信任 → S1
- 明显影响留存、节奏、章节效果或人物可信度 → S2
- 局部质量、格式、措辞、轻微节奏问题 → S3
- 风格建议或可选增强 → S4

## 核心维度

| 维度 | PASS | WARN | FAIL |
|---|---|---|---|
| 核心卖点 | 围绕明确卖点推进，读者知道为什么继续看 | 卖点存在但表达弱或被支线稀释 | 看不出本章服务什么卖点或主线 |
| 冲突推进 | 有明确冲突、阻碍、选择、代价或关系/信息推进（日常/过渡章按章定位判断） | 推进偏弱，信息或关系变化小 | 主要是解释/闲聊/总结，无实际推进 |
| 任务卡点 | 办事受阻并卡出信息、关系、代价、选择或伏笔变化 | 有卡点但变化偏弱，可压缩 | 纯流程细节，删掉不影响故事 |
| 情绪曲线 | 有铺垫、升温、释放或反转 | 情绪有变化但节点不清 | 情绪平直或突兀转向 |
| 钩子与期待 | 开头/结尾至少一处建立期待 | 钩子弱但仍有后续问题 | 无悬念、目标或未完成期待 |
| 开头新鲜度（仅开篇/前 3 章） | 开局用具体人物、处境与赌注抓人；商业爆款/品类经典开局范式（长短篇通用）有具体冲突与钩子即通过 | 有钩子但开局切口偏平，人物或赌注立得偏慢 | 开局空泛、纯背景/景物灌水，或只有空壳套话缺少具体赌注与钩子 |
| 角色动机 | 行为符合目标、性格、处境和关系压力 | 局部行为缺铺垫 | 角色为推剧情而失真 |
| 对话质量 | 有信息控制与角色差异（长篇重潜台词；短篇强冲突场允许直球摊牌、狠话与围观烘托） | 信息略堆叠或声音略同质 | 像说明书，人人同腔 |
| 设定一致性 | 不违背既有规则、时间线和角色属性 | 轻微模糊需补证据 | 与已写设定或前文事实冲突 |
| 文字自然度 | 具体可感，直写情绪、判断算账、台词与有后果动作配合自然（短篇常见反应短语、旁白剧透与主观审判按 `short-deslop.md` 保留） | 偶有套话、抽象总结或手眼/道具微动作代偿情绪 | AI 腔、陈词滥调、总结体或微动作套路明显 |
| 句长节奏 | 贴合本书文风与手机阅读节奏（短篇允许竖屏一句一段与短句快切，长篇避免大段文字墙） | 局部三五字机械碎句，或偶发臃肿长句 | 连串电报残句切碎动作链、通篇提纲，或超长句/墙段拖垮节奏 |
| 标点节奏 | 匹配语气、声线与情绪功能（对话内 `——`、有节制 `……`、旁白关键转折 `——` 及短篇高频 `！`/`？` 均可用） | 局部单调或略堆砌 | 通篇句号化、随机堆问叹号，或旁白 `——`/`……` 刷屏、出现畸形破折号 |
| 具体字数表达校验 | 「这五个字」「短短四字」类表达经核对属实且有叙事必要 | 属实但换「那几个字」更自然 | 字数不符，或无法确认统计口径 |
| 格式可读性 | 段落按戏剧单元/镜头自然断开（手机竖屏适读），对话独立、无多余空行、主语节奏自然 | 局部偏长/偏碎或主语略重复 | 大段堆叠、机械切段、对话/叙述难读、主语过密 |
| 剧情循环 | 紧章目标→阻碍→行动→代价/反馈→新期待清晰；松章交代目标、行动与状态变化 | 有推进但缺一环或反馈弱 | 无目标、无行动反馈，看不出局势或关系变化 |
| 高潮构建 | 高潮章蓄能、落差与兑现有层次（强反转可用蓄能→假胜→崩解→反转/兑现）；松章完成蓄力或日常兑现 | 有爆点但铺垫或兑现不足 | 应有高潮却缺铺垫、无兑现或情绪落空 |
| 关系进展 | 互动尺度匹配关系阶段，越界有铺垫（短篇有明确触发即可快速心死/翻脸/结盟） | 推进略快但可补证据 | 无触发突然亲密/信任/敌对，关系跳变 |
| 伏笔状态 | 埋设、状态与回收路径可追踪 | 偏密/偏疏但不影响理解 | 与设定冲突、断线或造成主线理解混乱 |

## 黄金三问与发布门槛

1. **读者为什么翻下一页？** 答不出至少 S2。
2. **本章改变了什么？** 情节/关系/信息/情绪至少变一项，否则至少 S2。
3. **证据在哪？** 无原文证据不出 finding，标「证据不足」。

| 综合情况 | Verdict | 报告「总体判断」 |
|---|---|---|
| 无 S1/S2，S3 可快速处理 | APPROVE | 可以发 |
| 有 S2，或 S3 过多影响阅读 | CONCERNS | 改完下面几处再发 |
| 有 S1，或卖点/动机/规则崩坏 | REJECT | 局部能修写「改完下面几处再发」，整体崩坏写「这一章需要重写」 |

输出须含 severity、category、location、evidence、issue、fix，按 S1/S2 → S3/S4 排序；事实/一致性类 fix 只写统一方向。
