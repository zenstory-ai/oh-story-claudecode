# AI 味词句信号索引（分级版）

> 谁读：去味、审稿、改写时查信号用；表达服从作者要求、本书文风及短篇 `short-deslop.md` 覆盖，不逐词照删，不以清零为目标。

## Tier 1：真·AI 公文 / 翻译 / 抽象总结腔（优先改写）

以下形态在正常网文叙述中信息密度低、机器味重，命中后优先回到具体动作、对话、筹码或角色直白算账：

| 类别 | 典型形式 | 判断与改法 |
|---|---|---|
| 无靶子否定翻转 | 不是 A，（而）是 B；**句号/跨行 `不是A。/ 不是B。/ 是C。`**；没有 X，没有 Y，只有 Z；伪精确感官对比与心理临床拆解 | 无人误解 A 时直写 B；正当纠错可留 |
| 万能状语与人设标签 | 带着一丝不易察觉；声音不大却不容置疑；旁白直贴人设标签或替读者划重点 | 删旁白贴标签与划重点，靠台词与行动演 |
| 公文与推导链 | 这意味着；真正重要的是；由此可见；综上所述；**台词 PPT 串烧（第一/二/三+评估/风控）** | 删报告与 PPT 腔（❌`典型的习得性无助` → ✅`连骂的力气都没了，只觉得这五年像笑话`），留口语算账 |
| 抽象收束与大词 | 命运的齿轮；这一夜注定无人入眠；新的人生刚刚开始；**鸡汤作文尾（这就是X的意义/花了N年才明白/光芒万丈/余生皆坦途）** | 删作者盖章与读后感升华，收在最后一个具体动作、台词或后果上 |
| 模板比喻与虚饰 | 如潮水般涌来；**女频油腻/爹味套词（指节泛白、宠溺、眸色一暗、喉结轻滚、声音低哑、耳尖泛红、骨节分明大手、空气发烫、小女人、小白兔、女人你）**；静得掉针可闻；无功能材质与空镜摆设（骨瓷/紫檀/黄铜/磨砂/咖啡机嗡鸣/淅淅沥沥） | 删空比喻、油腻标签与空镜摆设，换具体画面、边界尊重或改局物件 |
| 滥用引号强调 | 给普通名词反复加引号（「机会」「答案」「蜕变」） | 无反讽或引用意图就去引号直写 |
| 机械工整与提纲 | 至于 X 不 X；连串三五字极碎电报段或连三段同主语排比（`她说我…`）；流水账动作链 | 恢复自然主干与长短呼吸；正常竖屏短段不据此合长句 |
| 高频 AI 套名与跳戏前言 | 开篇跳戏前言（大脑寄存处/求好评/境界表）；高频套名（陆砚深/周砚深/周砚礼/沈砚/林砚/林知微/温知微/林晚/林婉清/苏婉清/苏晚晴/顾沉舟/陆沉舟/周明远/陈默/苏晚） | 删开篇跳戏前言；起名避开高频套名扎堆（作者指定除外） |

## Tier 2：网文通用短语（单用合法，仅连刷扎堆或脱离语境才改）

以下词句在真人爆款中高频出现，**单用偶发贴合现场不判错**；仅同场成串刷屏或代替交锋时压缩：

| 类别 | 常见短语 | 保留边界 |
|---|---|---|
| 情绪与反应短语 | 脸色一变、心口一沉、眼皮一跳、背脊一凉、倒吸冷气、心里咯噔、呼吸一滞、半寸/手停半空/绷紧/唇角极淡弧度；**`轻笑/低笑`禁误杀** | 贴合节拍偶用可留；禁危机成串刷生理模板或跨章复读同一尺度/微动作 |
| 程度与口语过渡 | 微微、淡淡、缓缓、轻轻、突然、瞬间、猛地、仿佛、好家伙、偏偏、因为/毕竟/所以 | 承担节奏可留；禁连刷「因为/毕竟/所以」说明文解释句或 `好家伙/瞬间` 刷屏 |
| 短篇与爽文叙事 | 他/她不知道的是、殊不知、没人知道、演得真好、谁都看得出他在撒谎、所有人都震惊了 | 短篇信息差预告（限导语或关键转折偶用，勿每节刷屏）、第一人称审判与分层围观按 `short-deslop.md` 保留；禁空预告与千人一腔假震惊 |
| 情绪直写与心理 | 他感到愤怒、她终于明白、心中暗道、心里某个地方软了 | 承接判断、转折或下步行动时可留；上下文已演足且无新信息才删 |
