# 番茄小说发布资料

元信息里的 `长篇` 是保存文件时的字段、选项和上限，格式检查直接读它；短故事的同类规则在 `fanqie-short.md` 开头。

## 核验范围

- 长篇阅读标签、内容标签：2026-10-25 对照 Web「作品管理 > 小说 > 创建作品」男/女频弹窗截图。
- 短故事分类与发布设置：2026-10-28 对照 Web 短故事管理页截图（Lv.2 账号、未发布草稿）。
- 书名、封面、简介要求：番茄作家帮助中心「作品信息要求」，2026-10-29 读取。
- 这些是核验日期，不是平台更新时间。App、其他账号等级、留空拦截和提交结果都没核验；当前界面与本资料冲突时以界面为准，差异记进「待平台核实」。

## 先分作品类型

长篇和短故事字段不同，候选不能互用。

- 长篇：先定目标读者，再读 `fanqie-reading-male.md` 或 `fanqie-reading-female.md`（阅读标签），内容标签读 `fanqie-content-tags.md`。目标读者没定就不选阅读标签。
- 短故事：只读 `fanqie-short.md`。

## 长篇字段

| 字段 | 规则 |
| --- | --- |
| 书名 | 必填。只能用中英文、阿拉伯数字和元信息列出的全角符号，不能有空格，汉字、字母、数字、符号各算 1 个字；不能与番茄其他原创作品重名；申请签约后不能改。 |
| 签约模式 | 必填。2026-10-12 起新建作品 Lv.0/1 只能完本，Lv.2+ 可选；创建后不能改。作者说了账号等级且只剩一个选项时直接填，并在回复里说明依据；不从更新节奏推断。它不是连载状态或更新安排。 |
| 目标读者 | 男频/女频，可暂不填；不从主角性别或文风推断。写作设定里的“目标读者”是读者画像，不是这个字段。 |
| 主角1、主角2 | 可暂不填。 |
| 作品简介 | 下限 50 字来自旧资料，未核实；不得有导流信息。 |
| 阅读标签 | 填写时主分类必选且只选 1 个，其余各组上限见候选文件。签约后不能修改。 |
| 内容标签 | 上限见候选文件，没有最低数，不要凑满。 |
| 封面 | 可暂不填。600×800 像素、不超过 5MB，图上必须有正确的书名和笔名；改书名或笔名后要手动换封面。 |

作者/笔名不是番茄建书字段，写进资料方便封面和以后填表，但不说平台要求填。

番茄有两种建书入口：独立建书表单要求填书名和签约模式；「先写章节」入口会自动起名「作者ID的新书」并默认连载，这些默认值不算作者定稿。之后补资料、提交章节时还要填哪些，目前没有核实。

签约字数（连载 2 万字起可申请）和每日新建、更新额度是签约与发文规则，不是建书门槛；作者问起时，请其以后台显示为准。
