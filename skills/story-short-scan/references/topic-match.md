# 短篇扫榜结论：落盘与交接

结论写进本次输出目录的 `短篇扫榜结论.md`：出报告时写文件头和「扫榜结论」，选题时写「选题匹配」。`/story-short-write` 定目标情绪时读这份文件的「选题匹配」和「复扫日期」，接上选题结果。

## 短篇扫榜结论.md 模板

```md
# 短篇扫榜结论：{平台/方向}
- 扫榜日期：{YYYYMMDD}
- 复扫日期：{YYYYMMDD}
- 数据来源：{榜单文件名 / 作者提供 / 内置知识}
- 聚合表：{扫榜聚合.md，内置知识模式写「无」}

{扫榜报告全文，从「## 扫榜结论：{平台名称}」那一行起}

## 选题匹配

### 方向 1：{一句话方向}
- 目标情绪：{意难平 / 反转震撼 / 爽感释放 / 治愈温暖 / 细思极恐 / 共鸣感动，选一}
- 题材与设定：{题材 + 核心设定}
- 差异化：{同方向样本都在写什么，这个方向换了哪一处}
- 开头钩子：{前 3 句建立的冲突、身份差或情绪钩子}
- 传播引擎：{反转 / 强共鸣 / 强话题 / 强余韵}
- 写作难度：{低/中/高，照扫榜情绪表的难度}
- 可行性：{高/中/低} — {同方向样本几篇 + 趋势 + 作者素材能否撑住}
- 失败风险：{最可能写砸或撞车的地方}
- 篇幅/平台：{建议字数 + 目标平台，平台名按下方对照表写}
- 验证动作：{开写前怎么低成本验证，见下}

### 方向 2 ...
```

给出 2-3 个方向，按可行性从高到低排列。

## 目标平台怎么写

写作流程只接受下表右列平台名，目标平台照右列写：

| 扫榜平台 | 写作目标平台 |
|---|---|
| 知乎盐言 | 知乎盐言 |
| 番茄短篇 | 番茄 |
| 七猫短篇 | 七猫 |
| 黑岩 | 黑岩 |
| 点众 | 小程序 |
| 其他/未定 | 未定 |

## 低成本验证

- 导语试写：按目标平台写 150-300 字导语，自测或请两三个读者试读，看是否想点开正文。
- 同一脑洞两版开头：换一种情绪或平台基调各写前 500 字，比较哪版更抓人。
- 投编辑试稿：有征稿渠道时先发导语和大纲问编辑，再写全文。

## 规则

- 复扫日期：短篇风口有效期短，一般定在扫榜后 2-4 周；过了这天结论只当参考。
- 可行性上限：聚合表标「少」、样本不到 10 篇或只有作者给的故事名列表时，不许给「高」；内置知识模式最高给「中」；作者素材或条件撑不住，或不符合征稿要求时给「低」。
- 重跑时分别替换「扫榜结论」和「选题匹配」，保留文件头，不追加重复小节。
- 交付时告诉作者路径：「开写时把小说项目建在扫榜时的文件夹里或和它同级，`/story-short-write` 会自动找到；隔得远就把 `短篇扫榜结论.md` 复制到项目根。」
