# 没有采集脚本的平台：作者提供榜单

知乎盐言、番茄短篇、七猫短篇等平台没有采集脚本，需要作者提供榜单。作者选了这些平台才读本文。

## 向作者要什么

「请发榜单截图、文字或链接，尽量带上书名、作者、题材、字数和热度，并注明是赞同、收藏还是在读。能提供简介也一起发来。手里有编辑的征稿或约稿要求，也一起发来。」

- 链接 → 能打开就读；打不开就请作者改发截图或文字
- 只有故事名列表 → 可以直接分析，但报告的可信度写低一档

## 整理成文件再聚合

把作者给的榜单整理成下面的格式，存进本次输出目录（文件名 `{平台}{榜单}_{YYYYMMDD}.md`），再和脚本采集的榜单一起聚合：

```markdown
# 知乎盐言 · 热门榜

- 抓取时间：{榜单截图或页面的日期，YYYY-MM-DD}
- 数据质量：作者提供

### #1 {书名}
*{作者} · {题材} · {状态} · {字数}字 · {热度数字}{口径}*
**标签：** {标签1}、{标签2}

> {简介}
```

- 聚合脚本按位置识别字段：第一格是作者，第二格是题材。截图没有作者就用 `佚名` 占位，作者和题材的顺序不能变；不能写「未知」，聚合会按空值跳过，导致题材被错认成作者。
- 热度写成「数字 + 口径」（如 `2.3万收藏`、`8000赞同`），聚合才认得。一份文件只用一种口径，口径不同的榜分文件存。
- 状态、字数、标签、简介缺了直接省略，不要编。
