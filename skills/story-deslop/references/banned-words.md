# AI 味词句信号索引（分级版）

> 谁读：去味、审稿、改写时查信号用；表达服从作者要求、本书文风及短篇 `short-deslop.md` 覆盖，不逐词照删，不以清零为目标。

## Tier 1：真·AI 公文 / 翻译 / 抽象总结腔（优先改写）

以下形态在正常网文叙述中信息密度低、机器味重，命中后优先回到具体动作、对话、筹码或角色直白算账：

| 类别 | 典型形式 | 判断与改法 |
|---|---|---|
| 无靶子否定翻转 | 不是 A，（而）是 B；没有 X，没有 Y，只有 Z；是 A，不是 B | 无人误解 A 时直接写 B；有明确纠错、辩解或强烈情绪反差可留 |
| 万能状语与声线 | 带着一丝不易察觉；声音不大，却不容置疑；语气平静无波；平静得像在念/宣判 | 删空泛态度标签，直接写台词内容、筹码压迫或在场反应 |
| 公文与推导链 | 这意味着；真正重要的是；由此可见；不难看出；综上所述；按照这个逻辑；基于当前；进一步推进落实；诚然 | 删报告腔，保留角色当下口语化利害盘算（职业条文/系统公告除外） |
| 抽象收束与大词 | 命运的齿轮；这一夜注定无人入眠；新的人生/反击才刚刚开始；意义深远；前所未有的决意；一切都结束了 | 删作者盖章与空泛升华，收在最后一个具体动作、台词或后果上 |
| 模板比喻与虚饰 | 如潮水般涌来；犹如疾风骤雨；仿佛整个世界失去了颜色；散发着一股生人勿近的气息；眼里淬了毒 | 删掉或换成贴合角色手边处境的短促画面，不同义轮换 |
| 滥用引号强调 | 给普通名词反复加引号（「机会」「答案」「蜕变」） | 无反讽或引用意图就去掉引号直写 |
| 机械工整与提纲 | 至于 X 不 X，怎么 X；连续三五字残句缺主语；同段连串「抬手、拿起、放下、转身」流水账 | 恢复自然主干与先后关系；短篇与手机竖屏正常短段不据此合长句 |

## Tier 2：网文通用短语（单用合法，仅连刷扎堆或脱离语境才改）

以下词句在真人爆款网文中高频出现，**单用、偶发且贴合现场时不判错**；仅在同场扎堆连刷或代替本该演出的交锋时压缩：

| 类别 | 常见短语 | 保留边界 |
|---|---|---|
| 情绪与反应短语 | 脸色一变、心口一沉、眼皮一跳、瞳孔一缩、眼眶一红、浑身发抖、深吸一口气、心头一震、嘴角勾起、眉头微皱 | 贴合情绪起伏与打脸节拍可留；禁每句情绪后机械挂同一微动作尾巴 |
| 程度与过渡词 | 微微、淡淡、缓缓、轻轻、一丝、一抹、突然、瞬间、猛地、仿佛、似乎、只见 | 承担节奏、突发或视角不确定性时可留；成片堆砌时减密度 |
| 短篇与爽文叙事 | 他/她不知道的是、殊不知、没人知道、演得真好、谁都看得出他在撒谎、所有人都震惊了 | 短篇信息差预告、第一人称审判与分层围观按 `short-deslop.md` 保留；禁无具体后事的空预告或千人一腔的假震惊 |
| 情绪直写与心理 | 他感到愤怒、她终于明白、心中暗道、心里某个地方软了 | 承接判断、转折或下步行动时可留；上下文已演足且无新信息才删 |
