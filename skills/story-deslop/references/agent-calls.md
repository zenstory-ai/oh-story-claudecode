# 交给 narrative-writer 去味

仅在交给写手时读取。本次任务、范围与裁决原样传递；方法由写手按部署读取表加载，不在 prompt 再抄规则正文。

```text
项目目录：{绝对路径}
任务描述：审查+去AI味
正文文件：{本次这一章或这一篇的绝对路径}
已读依据：{相关前文、设定与设计文件路径；缺失写明}
检查范围：{默认完整三层诊断；或作者/调用方指定段落、问题、检测类别}
本次诊断：{表达、用笔、故事各自的实际问题及原文位置；可写无/资料不足}
执行授权：{允许直接修改的范围；已授权的剧情重写及必须保留的事实、结果、揭露时机}
文风路径：{本书文风全文路径；无则写无}
style_resolution：{生效要求及来源、覆盖的默认条款、事实与信息边界}
作者偏好：{调用方已有的偏好；无则写无}
篇幅与格式：{长篇/短篇、字数范围及本次格式要求}
检查分工：你只负责本次语义改稿，不按细纲补写情节；父流程负责最终文件扫描，按每条 severity 分流。
返回：按授权直接改正文；只回路径、实际修改与未解决项、必要的设计方案，不返回全文。
```
