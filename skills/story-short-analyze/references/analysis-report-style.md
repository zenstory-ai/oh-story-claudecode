# 拆文报告表达规范

> **用途**：只约束 `拆文报告.md` 中分析师自己写的文字，不用于改写或过滤源文。
> 源文中的套话、AI 腔、毒点都是可报告的观察对象；引用源文时保留原貌并标明位置。

## 核心原则

拆文报告按判断、文本证据、位置和作用组织，供读者回到源文复核；分析师不替源文补戏。

每个重要判断至少包含三项：

1. **结论**：使用了什么结构、技巧或失败模式。
2. **证据**：原句短引、情节点或可定位的位置。
3. **作用**：它改变了读者知道什么、期待什么或感受什么。

证据不足时写“证据不足 / 待复核”，不要用笃定语气补全作者意图。

## 报告自身的高风险表达

以下模式出现在分析师措辞中时必须复核；源文直接引用不计：

- “不是 A，而是 B”“不是 A，不是 B，只是 C”等先否定再翻转的模板句。
- “不难发现”“显而易见”“毋庸置疑”“值得注意的是”等空转提示语。
- “命运的齿轮”“更大的风暴”“故事才刚刚开始”等正文式升华或预告。
- “淋漓尽致”“层层递进”“环环相扣”“令人窒息”等没有证据支撑的万能评价。
- 连续用“首先 / 其次 / 再次 / 最后”切碎本可直接陈述的观察。
- 只贴“节奏紧凑、人物立体、情绪饱满”等标签，不说明具体文本机制。
- 猜测作者心理：“作者想告诉我们”“作者显然意识到”。应改为可观察的文本效果。

## 推荐句型

- `第 3 节先让读者知道证据存在，但隐去持有人；第 5 节才揭示持有人，因此形成两拍信息差。`
- `该段被归为关系反转，证据是母亲在前文始终回避称谓，而此处第一次直呼姓名。`
- `未发现足够铺垫：反转前只有结果提示，没有可回溯的行为线索。`
