# 短篇源文悬念分析标尺

> 观察短篇如何分配问题、信息、证据与答案。只描述源文内的即时、小节间和全文悬念，不调用卷级、全书或连载钩子模型。

## 悬念对象

悬念由尚未解决的具体问题支撑，未知可关乎结果、原因、身份或代价。记录问题何时建立、如何延迟回答，以及等待期间的推进。

分析前先写清：

```markdown
主问题：{全文最终必须回答的问题}
副问题：{服务主问题的证据、关系或动机问题；没有则写无}
读者先知道：{位置与信息}
角色先知道：{位置与信息}
最终答案：{位置与改变的判断}
```

## 三种观察尺度

| 尺度 | 观察对象 | 回收判断 |
|---|---|---|
| 即时 | 一场对话、动作或取证中的未完成目标 | 本场是否产生结果、阻力或选择 |
| 小节间 | 节尾留下的证据异常、关系疑点或未完成动作 | 后续是否回应，并改变下一步行动 |
| 全文 | 主问题及其责任、身份或情绪答案 | 结尾是否完成事实与后果结算 |

三种尺度不要求同时存在。短篇可以只靠一个强主问题推进；副问题过多且不能回到主问题时，应报告为支线扩张。

## 信息差类型

| 类型 | 识别方式 | 需要检查 |
|---|---|---|
| 读者领先 | 读者已见到危险或证据，角色尚未发现 | 领先是否制造担忧或等待，而非泄底 |
| 角色领先 | 角色隐瞒计划、证据或动机 | 隐瞒是否公平，叙述是否刻意撒谎 |
| 角色之间 | 不同角色掌握不同证据或解释 | 信息交换是否改变关系和行动 |
| 共同误判 | 读者与主角依据真实证据得出错误解释 | 后续答案是否保留旧事实并修正解释 |

## 证据释放链

对每笔关键证据记录：

| 位置 | 新信息 | 当时解释 | 谁取得/验证 | 引发的行动 | 后续如何重读 |
|---|---|---|---|---|---|

有效释放必须至少改变信息、嫌疑判断、关系立场、风险或下一步行动之一。只重复问题、增加形容或换角色口供，不算推进。

## 阶段答案

阶段答案是角色可以据此采取真实行动的暂时结论。检查：

- 它由哪些已经出现的证据支持。
- 角色是否真的依据它作出选择。
- 后续揭示推翻的是解释还是事实。
- 错误行动造成了什么代价或新局面。

若阶段答案刚说出口就被下一句推翻，它只是连续揭晓，不构成悬念层级。

## 延迟期间交付了什么

每次主问题被推迟时，记录文本交付了什么：

- 可验证的新证据。
- 对旧证据的新解释。
- 关系或证据所有权变化。
- 主角的主动选择及其代价。
- 局部问题的真实答案。

如果连续延迟只增加“还有更大秘密”的表述，应报告空转，并指出未改变的读者问题。

## 回收质量

| 检查项 | 成立表现 | 失败表现 |
|---|---|---|
| 事实回收 | 主问题得到可复核答案 | 靠新人物或新设定补答案 |
| 公平性 | 旧证据在新解释下仍为真 | 早期叙述为误导而撒谎 |
| 行动后果 | 揭示改变选择、关系或责任 | 角色听完解释后一切照旧 |
| 情绪回收 | 最终判断回收了前文投入 | 只结案，不处理关系和代价 |
| 主角的主动选择 | 关键选择或旁观限制与本篇体验相符 | 外援代办消解了前文承诺的选择与代价 |

## 报告格式

```markdown
主悬念：{问题、建立位置、最终回收}
副悬念：{与主问题的服务关系；无则写无}
信息差：{类型、双方知道什么、位置}
证据释放：{按位置列新信息、解释和行动变化}
阶段答案：{支持证据、触发行动、后续修正}
延迟期间的交付：{每次推迟具体交付什么}
回收评价：{事实、公平性、行动、情绪、主动选择}
证据不足：{无法从源文确认的项}
```
