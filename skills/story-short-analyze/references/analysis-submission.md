# 短篇源文投稿层观察标尺

> 拆人物与首尾、综合评估时读本文件，记录源文在投稿层的呈现：导语、付费断点、书名与简介、平台写法。只报告源文怎么做，平台归属优先采用来源信息，不推测实际收费位置或流量。

## 导语

导语是第一个小节标记之前的几段。先定边界：源文没有导语、或分不清导语与第 1 节时，照实写。

| 看什么 | 记录 |
|---|---|
| 四个要素 | 起因、核心冲突、人物底色（是否显出主角有后手）、情绪转折各落在哪一句 |
| 抓人的东西 | 有冲击力的物件、读者知道而施害者不知道的信息、留白的最后半句 |
| 停在哪 | 停在正在发生的一刻，还是已经写到结局或后果 |
| 和第 1 节怎么接 | 顺着往下写，还是倒回事情开头讲到导语那一刻；有没有重演导语 |
| 亮了多少底牌 | 底牌是否留给正文兑现 |

## 付费断点

付费断点已在拆文报告「情感线与爆点分析」一节按钩子标尺记下，这里只引用它的位置与结论，不重判。

## 书名与简介

| 简介类型 | 结构 | 给读者的承诺 |
|---|---|---|
| 成功型 | 情境 → 冲突 → 行动 → 成功 | 安全感，确定会赢 |
| 行动型 | 情境 → 冲突 → 行动，停在行动上 | 悬念 |
| 悬疑型 | 情境 → 一个反转或疑点 | 好奇 |
| 失败型 | 情境 → 冲突 → 行动 → 失败 | 虐感与愤怒 |
| 简短成功型 | 情境 → 转折 → 成功 | 轻快、甜 |

对照书名、简介和正文是否交付同一种核心体验；书名靠身份反差、正反词、悬念还是情绪承诺抓人，照实记录。没有书名或简介资料时写「源文未提供」。

## 平台写法

平台集合：知乎盐言、小程序（点众等）、黑岩、番茄、七猫。只在来源信息给出平台、或作者要比较平台时填写。

| 平台 | 常见视角与冲突 | 常见格式 |
|---|---|---|
| 知乎盐言 | 第一人称沉浸，生活化的违和细节切入，心理战与信息差，结局重余韵 | `1.` 分节，弯引号 `“…”` 或直角引号 `「」` |
| 小程序（点众等）、黑岩 | 强情绪第一人称或第三人称，冲突外化到对白和动作，当众打脸、反派付出实质代价 | `###1.` 分节，弯引号 `“…”`，黑岩常见短段快切、小节偏短 |
| 番茄、七猫 | 流畅的第一或第三人称，目标清晰，反派挑衅很快转成主角的垫脚石，结局圆满 | 常用 `###第N章` 或 `1.`，弯引号 `“…”` |

记录源文实际用的视角、分节与引号、冲突外化程度和结局质感，与上表比较接近或偏离了哪一种，不按上表判合格。

## 报告格式

```markdown
导语：{边界、四要素位置、停在哪、和第 1 节怎么接}
付费断点：{引用钩子一节的结论}
书名与简介：{类型、承诺、与正文是否一致；或 源文未提供}
平台写法：{来源平台与观察到的写法；无平台信息写 未知}
```
