# 短篇源文投稿层观察标尺

> 拆人物与首尾、综合评估时读本文件，记录网络短篇在投稿层的呈现：导语、30–40% 付费断点、书名与简介、平台写法。只报告源文实况，不推测实际流量。

## 导语

导语是第一个小节标记之前的冷开场段落（常见 150–300 字）。源文没有独立导语、或第 1 节直接冷开场时照实记。

| 看什么 | 记录 |
|---|---|
| 四要素落点 | 命级/利益级起因、核心压迫冲突、主角清醒底色或底牌暗示、末尾钩子各落在哪句 |
| 抓人手法 | 倒序结果剧透、高仇恨对话炸弹、具体金额/年限反差、超自然/外挂实锤 |
| 停在哪 | 停在正在发生的冲突瞬间，还是剧透到火葬场/反杀后果 |
| 与第 1 节承接 | 顺着往下演，还是倒回事情起点补对话与经过；有无重复复演导语 |
| 底牌保留度 | 底牌是否只亮一角，留给 40% 后正文兑现 |

## 付费断点

直接引用拆文报告「钩子与付费断点」一节的 30–40% 断点位置、卡点手法与付费后承接结论，不重判。

## 书名与简介

| 简介/书名类型 | 结构 | 读者预期 |
|---|---|---|
| 爽感反杀型 | 极端作践 → 亮底牌/重生反常 → 当众清算 | 确定会赢的解气感 |
| 悬念卡点型 | 异常现场/矛盾事件 → 停在行动或反问处 | 强好奇与追读欲 |
| 虐爽火葬场型 | 多年付出被踩踏 → 决裂离场 → 他后来疯了 | 心疼代入+等渣男崩溃 |
| 脑洞高概念型 | 一句话离谱设定（弹幕/系统/错位身份）→ 反差笑点 | 新鲜感与轻喜爽感 |

对照书名、导语与正文是否交付同一种核心卖点；缺书名/简介时写「源文未提供」。

## 平台写法

平台集合：知乎盐言、七猫、番茄、黑岩、点众（小程序）。只在有来源平台或需要对比平台时填写。

| 平台 | 常见视角、节奏与冲突 | 常见排版与收尾 |
|---|---|---|
| 知乎盐言 | 第一人称沉浸主导，生活化违和/大女主反杀/脑洞吐槽高频；极短段（中位约 20 字），高密心理吐槽与情绪拉扯，30–40% 会员卡点 | `1.` 分节，`「」` 或 `“…”`，单句成段密集；收尾按题材走清算、火葬场或脑洞闭环（仅悬疑留白） |
| 七猫、点众（小程序） | 第一人称绝对主流，开局百字直抛强矛盾与对话，首章偏长（约 1400–1500 字），30–40% 强卡点，40% 起连环打脸，对话占比约 30–40% | `###第N章` 或 `###1.`，`“…”`，单句成段主导；普遍走明账清算（反派入狱/破产/社死/跪求+主角高位） |
| 黑岩 | 强情绪第一人称（含大量男频都市反杀），极短句快切、小节偏短，冲突全外化到对白与当众打脸 | `###1.`，`“…”`，一句一段高频换行；直白彻底清算，不留憋屈 |
| 番茄 | 流畅第一人称，目标清晰、金手指或爽点直白，反派挑衅很快转成打脸垫脚石，试读末节（约 30%）设强卡点 | `###第N章` 或 `1.`，`“…”`，短段交织高密对话；爽感圆满、坏人实罚 |

## 报告格式

```markdown
导语：{边界、四要素位置、停在哪、与第 1 节承接}
付费断点：{引用钩子一节结论}
书名与简介：{类型、承诺与正文是否一致；或 源文未提供}
平台写法：{来源平台与源文排版/节奏特征；无平台信息写 未知}
```
