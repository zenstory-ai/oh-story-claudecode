# 输出契约、验收清单与报告表达规范

> `story-short-analyze` 落盘与验收唯一真源。两个时刻均读本文件；下游 `story-short-write` 按固定文件名读取 `拆文报告.md`、`情节节点.md`、`写作手法.md`、`_meta.json` 与 `原文/`，不可重命名。

## 输出目录与 Stage → 文件映射

```
拆文库/{书名}/
├── 原文/          # 源文件备份（覆盖重拆时保留不动）
├── 拆文报告.md     # Stage 2–6 按阶段追加的综合报告
├── 情节节点.md     # Stage 2 完整情节节点清单（只存这一份）
├── 写作手法.md     # Stage 4 产出（必含：实测 9 项体检表 + 3 段语感切片 + 核心手法）
└── _meta.json     # 元数据 + Stage 6 结构计数与网感摘要（v2.1）
```

| Stage | 名称 | 落地文件 | 核心产物 |
|---|---|---|---|
| 2 | 结构与情节节点 | `拆文报告.md` + `情节节点.md` | 题材、故事核、梗概、五段结构、时间线、完整节点清单与摘要 |
| 3 | 情感线与爆点 | `拆文报告.md` | 情感曲线、爆点分析（含前 40% vs 后 60% 分布）、期待感、钩子与付费断点 |
| 4 | 反转与写作手法 | `拆文报告.md` + `写作手法.md` | 前置反转与反转/报应机制；`写作手法.md` 实测体检表 + 3 段 150–250 字切片 + 核心手法 |
| 5 | 人物与首尾 | `拆文报告.md` | 人物分类与反差/功能、导语与首百字入局、收尾清算与首尾回旋镖、钩子回收 |
| 6 | 综合评估与写计数 | `拆文报告.md` + `_meta.json` | 五维评分、爆点/话题/共鸣、主结构、投稿层、源文短板、可复用结构、节奏速报与计数回填 |

## `_meta.json` schema

```jsonc
{
  "version": "2.1",
  "word_count": 10240,                  // measure-short-metrics.js 实测 total_chars
  "genre_detected": "追妻火葬场",        // analysis-short-genres.md 枚举之一或「通用短篇」
  "created_at": "{ISO8601 UTC}",
  "stages_completed": [2, 3, 4, 5],
  "last_stage_in_progress": null,
  "structure_counts": {                 // Stage 6 一次性写入；照实填，可为 0
    "beats": 5,                         // 五段结构实际段数（≥1）
    "hooks": 6,                         // 成立的钩子数（Stage 3）
    "setup_clues": 3,                   // 反转铺垫线索数（Stage 4；无反转填 0）
    "character_archetypes": 2,          // 有反差人物数（Stage 5）
    "reusable_structures": 2,           // 可复用结构条数（Stage 6）
    "reversal_type": "视角反转"          // 视角反转/身份反转/动机反转/时间线反转/信息反转/认知反转/无反转
  },
  "voice_metrics": {                    // Stage 6 写入，与 写作手法.md「量化网感体检表」一致
    "median_para_chars": 20,            // 脚本实测段长中位（字）
    "single_sentence_para_rate": 0.85,  // 脚本实测单句成段率（0~1）
    "dialogue_ratio": 0.32,             // 脚本实测对话占比（0~1）
    "first_conflict_char": 65,          // 首冲突出现字位
    "hook_rate": 0.75,                  // 非末节节尾卡点率（0~1）
    "ending_type": "明账清算"            // 明账清算/火葬场追悔/HE发糖/细思极恐留白/克制回甘/开放式
  }
}
```

> `version: "2.1"` 约定：新增 `voice_metrics` 在 2.1 为必填阻断项，下游读旧 2.0 产出视为可选兼容；字段改名或破坏性变更才升 major。

## 写入顺序与 Resume 协议

1. **开始前**：写入 `last_stage_in_progress = N`。
2. **写完后**：核验文件非空且新增合理（如 `拆文报告.md` 本阶段 ≥200 字；Stage 4 确认 `写作手法.md` 含体检表与 3 段切片）。
3. **提交进度**：Stage 2–5 清空 `last_stage_in_progress` 并追加 `N` 至 `stages_completed[]`；Stage 6 须先写入 `structure_counts` 与 `voice_metrics` 并跑通下方三道验收，全过才清空 `last_stage_in_progress` 并追加 `6`。失败则保留 `last_stage_in_progress = N`。
4. **续跑与覆盖**：
   - `last_stage_in_progress` 非空 → 该阶段半成品不可信，截断已追加半截后**从头重跑**（仅 Stage 6 验收未过则只补漏重验）。
   - `last_stage_in_progress` 为空且未含 `6` → 从 `max(stages_completed)+1` 续跑（空数组从 Stage 2 起）。
   - 已含 `6` → 只提供覆盖或取消；覆盖时先归档旧产出至 `拆文库/{书名}/_archive_{时间戳}/`（保留 `原文/` 不动）。

## Stage 6 三道验收接入点

1. **报告表达自检**：只扫 `拆文报告.md` 中分析师本人文字，跳过源文引用（`>` 行、表格原文引号、语感切片），不改源文也不评源文是否 AI 写。
   - **三要素**：每个核心判断写清「结论 + 原文证据/位置 + 读者效果」；证据不足写「证据不足/待复核」。
   - **高风险措辞（命中须修订）**：先否定再翻转套句（「不是 A，而是 B」）、空转提示语（「不难发现/显而易见/值得注意的是」）、正文式预告（「命运的齿轮/才刚刚开始」）、无证据万能赞词（「淋漓尽致/层层递进/节奏紧凑」）、机械切碎（「首先/其次/再次/最后」）、猜测作者心理（「作者想告诉我们」）。
2. **`_meta.json` 校验**：`beats ≥ 1`；其余计数为非负整数且与报告一致；`reversal_type` 与 `genre_detected` 落在合法枚举内；`voice_metrics` 6 项齐全并与 `写作手法.md` 实测体检表一致。
3. **`[BLOCK]` 项扫描**：核查下表全部 `[BLOCK]` 项。源文确实没有的项写明「源文没有」并附依据即算通过；缺项阻断回补。`[WARN]` 缺项不阻断，记入 `拆文报告.md` 末尾「待补」清单。

## 质量检查清单

- **Stage 2**：`[BLOCK]` 题材在标尺枚举内或「通用短篇」；一句话故事核；五段结构含字数范围、占比与功能（半成品实录已有段）；情节节点覆盖真实变化、保留关键原话且每条带节号、字位与情绪值。`[WARN]` 结局类型、视角与时间线。
- **Stage 3**：`[BLOCK]` 情感曲线含首尾及每次立场/压力变化（字位 + `-9~+9`）；曲线 5 特征齐全；爆点 6 维度与前 40% vs 后 60% 分布；钩子与付费断点（含非末节卡点率）。`[WARN]` 每点钩子标注、期待感表。
- **Stage 4**：`[BLOCK]` 反转类型与铺垫线索（无反转写明）；`写作手法.md` 含 **9 项量化网感体检表**（由 `measure-short-metrics.js` 实测填入，禁估猜）+ **3 段 150–250 字原样语感切片**（导语冷开场 / 对话交锋或压迫 / 高潮打脸或清算；甜宠取互动拉扯与高糖兑现，篇幅过短照实注明取最长可用段）+ ≥5 项核心手法维度。`[WARN]` 前置反转、误导方向与对话模式。
- **Stage 5**：`[BLOCK]` 全部有名人物（分类、人设反差标签与拉仇恨/共情点）；人物功能评估；导语/前 3 句原引、首冲突字位与首百字入局检查。`[WARN]` 有反差人物行为对照、关系演变、首尾情绪强度（1–10）、收尾清算与回旋镖、全部钩子回收状态。
- **Stage 6**：`[BLOCK]` 五维评分每项附说明；爆点性、话题性与共鸣分析；主结构观察表；可复用结构每条含适用流派、失败条件与不能照搬；`_meta.json` 的 `structure_counts` 与 `voice_metrics` 合法落盘。`[WARN]` 具体机制一句话评价、投稿层、源文短板、节奏速报。
