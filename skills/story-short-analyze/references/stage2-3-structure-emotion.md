# Stage 2–3：结构、情节节点、情感线与爆点

Stage 2–3 时刻读本文件。方法在前，输出模板在后；每个 Stage 写完按 [quality-checklist.md](quality-checklist.md) 对应小节自检。题材、钩子、悬念、核心机制各有观察标尺，所读文件以入口「按时刻读」为准。

## 方法

### Stage 2：结构分析 + 情节节点提取

- **结构分析**：识别章节/小节分隔符（`###01`、`第一章`、`01` 等；若仅 2-3 章但内含编号小节则以叙事功能单元为准；对话体/聊天记录/帖子体/书信体按时间、说话人切换或信息揭示点分段，不机械按自然段切分），提取标题、每节字数、**故事核**（设定+主题+核心行动合并为一句）、**故事梗概**（200-500字）、POV、叙事时间线与功能分段（至少含开端/发展/高潮/结局，格式见下方「全篇结构」）。
- **情节节点提取**：以语义变化（风险、信息、关系、资源、决定、行动或读者理解变化）为边界提取关键事件或信息释放；同一动作链连续完成多个功能记为一个节点，不按字数或小节配额拆分，不为凑数重复记录。位置标明所在节号与约在全文第几字（如「第3节，约3200字」）。

### Stage 3：情感线 + 爆点分析

- **A. 情感曲线**：只在情绪立场、期待或压力实际变化处取点（开头和结尾各取一点，无独立情绪转折的推理/任务/等待链不硬补点），提取起始、走向、极值、方向差与翻转次数。
- **B. 爆点与期待感**：拆解爆点的铺垫、积累、延迟、爆发点、余波与印象；区分**叠加爆点**（表层爆点余波中引爆深层认知颠覆，写明 1+1>2 增效点）与**多爆点串联**（多个独立爆点递进或并列及间隔合理性）；逐节追踪期待的制造、满足/升级/悬置与剩余期待。

## 情节节点与情感线标尺

### 节点功能（6 种枚举，禁自创）

| 功能类型 | 定义 | 判定标准 |
|----------|------|----------|
| 情绪节点 | 引发读者或角色情绪变化 | 角色内在情绪发生明显转变 |
| 信息节点 | 向读者释放新信息（铺垫/揭示） | 读者或角色获得新认知 |
| 冲突节点 | 人物之间的对抗、矛盾激化 | 至少两个角色发生正面对抗/拒绝/威胁 |
| 转折节点 | 剧情方向发生改变 | 故事走向与之前不同 |
| 对话节点 | 通过关键对话推动剧情或塑造人物 | 对话本身传递了关键信息或潜台词改变关系 |
| 氛围节点 | 改变故事节奏或情绪氛围 | 场景切换/时间跳跃/环境氛围发生重大转变 |

- **节点质量要求**：① **客观白描**（只记“发生了什么”，禁主观评价：❌「女主心碎地听到了真相」→ ✅「女主听到门内丈夫说"私生子而已"，推门的手停在半空」；❌「通过这段对话展现了她的坚强」→ ✅「她直视丈夫说"我没有义务配合你演戏"」；❌「气氛变得紧张」→ ✅「丈夫的眼神一下子冷了」）；② **叙述顺序与保真**（按文本出现顺序排列，不把倒叙改排成故事内时间线，不漏改变上下文的关键细节，一节点一句话高度浓缩）；③ **复合合并**（同一目的连续微动作合并为一个 N 编号，节点数按最终 N 编号总数计）。

### 情绪类型与情绪强度量表（-9~+9 奇数值，用于情感曲线；开头/结尾分析单用 1-10 绝对量表）

| 类型 | 信号词 |
|------|--------|
| 心疼 | 行为细节、隐忍描写 |
| 愤怒 | 反派行为、不公待遇 |
| 震惊 | 反转、真相揭示 |
| 满足 | 爽点释放、恶人受罚 |
| 紧张 | 悬念、危机 |
| 心酸 | 放手、遗憾、成长 |
| 治愈 | 关怀、团聚、被理解 |
| 压抑 | 委曲求全、隐忍 |

| 分值 | 含义 | 典型场景 |
|------|------|----------|
| +9 | 极致爽感 | 当众打脸成功 / 终极反转揭晓 / 恶人受到严惩 |
| +7 | 强烈满足 | 关键反击得手 / 重要真相公开 / 身份揭露 |
| +5 | 明显正面 | 小胜 / 温暖瞬间 / 获得助力 / 小爽点 |
| +3 | 轻微正面 | 希望萌芽 / 善意举动 / 小确幸 |
| 0 | 中性 | 信息交代 / 场景过渡 / 平静叙事 |
| -3 | 轻微不适 | 小委屈 / 被忽视 / 隐忧浮现 |
| -5 | 明显负面 | 被羞辱 / 不公对待 / 误解加深 / 威胁逼近 |
| -7 | 强烈虐感 | 被重要之人抛弃 / 关键背叛 / 重大损失 |
| -9 | 极致虐感 | 生死威胁 / 尊严粉碎 / 信仰崩塌 / 至亲离世 |

### 情感曲线形态

| 形态 | 特征 | 适用题材 | 典型效果 |
|------|------|----------|----------|
| V形 | 先虐后爽，谷底反转 | 打脸爽文、复仇文 | 极致反差 |
| 倒V | 先甜后虐，高处崩塌 | BE虐文、悲剧 | 遗憾意难平 |
| 波浪 | 正负交替，多次拉扯 | 追妻火葬场、虐恋 | 情绪拉扯 |
| 阶梯上升 | 逐步升级，爽感递进（甜宠/反差萌可全程正值 `+3→+5→+7→+9`） | 升级爽文、甜宠、逆袭文 | 节奏感强 |
| 断崖下跌 | 平静/微甜后突然反转直坠 | 悬疑反转、死人文学 | 震惊 |
| 压缩弹簧 | 长期压抑，最后一次释放 | 隐忍复仇、世情文 | 极致释放 |
| 双峰 | 两个高潮峰（同质双峰如两次告别，或先虐峰后爽峰） | 复杂短篇 | 层次丰富 |
| **混合型** | 上述形态的组合 | 视组合而定 | 需标注主要形态和次要形态 |

### A. 情感曲线

取点落在情绪立场、期待或压力实际变化处，开头、结尾各一点，中间按源文实际变化增减行；每个点标钩子功能类型：

| 位置 | 字数 | 节点序号 | 情绪 | 强度与方向 | 触发事件 | 钩子类型 |
|------|------|----------|------|------------|----------|----------|
| 开头 | {X} | N{N} | {好奇/心酸/震惊} | {虐-9~爽+9} | {事件} | {analysis-short-hooks.md 的功能类型/无} |
| {低谷/反转点/高潮等} | {X} | N{N} | {情绪} | {虐-9~爽+9} | {事件} | {钩子类型} |
| 结尾 | {X} | N{N} | {满足/意难平/治愈} | {虐-9~爽+9} | {事件} | {钩子类型} |

曲线特征：起始{...} | 走向{上行/下行/波浪/V形/倒V/阶梯/断崖/压缩弹簧} | 极值{最高%X 最低%Y} | 方向差{从X到Y} | 翻转次数{N}

### B. 爆点分析

| 维度 | 分析 |
|------|------|
| 铺垫 | {什么让读者开始在意}，前{X}字完成 |
| 积累 | {什么在积累情绪势能}，积累{X}字 |
| 延迟 | {延迟释放机制：信息差/误解/悬念} |
| 爆发点 | {哪个瞬间释放全部情绪}，精确到句子："{引用}" |
| 余波 | {释放后的余震：角色反应} |
| 印象 | {情绪释放后留下什么，读者记住什么} |

**叠加爆点**（如适用）：表层爆点{X}→深层爆点{Y}→叠加效果{1+1>2在哪}

**多爆点串联**（如适用）：爆点①{事件+位置} | 爆点②{事件+位置} | 爆点③{事件+位置} → 串联方式{递进/并列}

### C. 期待感分析

逐节追踪读者的期待状态：

| 节 | 制造的期待 | 满足/升级/悬置 | 剩余期待 |
|----|-----------|---------------|---------|
| 1 | {期待A} | {制造} | {A} |
| 2 | {期待B} | {升级A} | {A+, B} |
| ... | | | |

期待检查：说明每次悬置期间交付了什么，以及后续如何回应核心期待。
