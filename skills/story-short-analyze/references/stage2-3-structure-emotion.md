# Stage 2–3：五段结构、情节节点、情感线与爆点

Stage 2–3 时刻读本文件。方法在前，输出模板在后；每个 Stage 写完按 [quality-checklist.md](quality-checklist.md) 对应小节自检。

## 方法

### Stage 2：五段结构分析 + 情节节点提取

- **结构分析**：识别小节分隔符（`###1.`、`###第一章`、`1.` 等；对话体/帖子体按说话人切换或信息揭示点分段），统计标题、总字数、每节字数（重点对比第 1 节与后续节体量）、**故事核**（设定+冲突+核心行动合为一句）、**故事梗概**（200–400 字）、POV、时间线，并按网短篇五段功能划分：**导语冷开场 / 免费建压 / 30–40% 付费强卡点 / 40–85% 连环反击反转 / 85–100% 明账清算收尾**（半成品按已有段实录）。
- **情节节点提取**：以真实状态变化（风险、信息、关系、资源、决定、打脸或读者认知变化）为边界提取关键事件；同一动作链连续完成多项功能合记一个节点，不为凑数拆分。每节点标明节号与约在全文第几字（如「第3节，约3200字」）。

### Stage 3：情感线 + 付费卡点 + 爆点分析

- **A. 情感曲线**：只在情绪立场、期待或压力实际变化处取点（首尾各一点），记录起始、走向、极值、方向差、翻转次数，并核查**首冲突字位 / 首对白字位**及**前 40% vs 后 60% 爽点分布**（是否 40% 起持续发力而非拖到 80% 才动）。
- **B. 爆点与期待感**：拆解铺垫、积累、延迟、爆发点、余波与记忆点；区分**叠加爆点**与**连环打脸串联**；逐节追踪期待的制造、兑现、升级与剩余期待。

## 情节节点与情感线标尺

### 节点功能（6 种枚举，禁自创）

| 功能类型 | 定义 | 判定标准 |
|----------|------|----------|
| 情绪节点 | 引发读者或角色明显情绪切换 | 受辱心死、委屈爆发、爽感释放等情绪转折 |
| 信息节点 | 向读者释放新事实、底牌或证据 | 读者或角色获得改写判断的新信息 |
| 冲突节点 | 人物间正面压迫、对峙或打脸 | 至少两方发生交锋、羞辱、拒绝或反杀 |
| 转折节点 | 局势、权力或行动方向翻转 | 主动权易手或故事走向改道 |
| 对话节点 | 靠关键台词推进剧情或拉高仇恨 | 道德绑架金句、软刀挑衅、一句封死反杀 |
| 氛围节点 | 场景切换、时间跳跃或悬疑异象 | 时空快切或诡异规则氛围突变 |

- **节点质量要求**：① **事实保真+保留原话锋芒**（记清发生了什么，关键狠话、心死宣告或打脸金句直接原样短引，不用抽象评价替代现场：❌「展现了她的坚强」→ ✅「她摔下离婚协议：“这八万账单谁住谁付”」）；② **按原文顺序记录**（不把倒叙导语改排成顺叙）；③ **复合合并**（同一目标的连续微动作合为一个 N 编号）。

### 情绪类型与情绪强度量表（-9~+9；首尾分析单用 1-10 绝对量表）

| 类型 | 典型信号 |
|------|----------|
| 愤怒/憋屈 | 道德绑架、偏心双标、不公羞辱、隐忍受压 |
| 心碎/心死 | 撞破背叛、至亲算计、彻底断念 |
| 震惊/反转 | 亮底牌、证据翻面、全员破防 |
| 爽感/解气 | 当众打脸、回旋镖反杀、恶人内讧与明账报应 |
| 紧张/诡异 | 付费卡点、倒计时、规则违背、异常逼近 |
| 心动/高甜 | 例外偏爱、嘴硬心软、吃醋修罗场 |
| 好笑/荒诞 | 弹幕系统吐槽、规则错位、反套路翻车 |

| 分值 | 含义 | 典型场景 |
|------|------|----------|
| +9 | 极致正向峰值 | 当众亮牌碾压 / 终极清算 / 双向高甜确认 |
| +7 | 强烈正向 | 关键反击得手 / 证据公开倒戈 / 爆笑名场面 |
| +5 | 明显正面 | 小反制得手 / 阶段甜头 / 拿回筹码 |
| +3 | 轻微正面 | 暗牌备好 / 反常冷静 / 希望萌芽 |
| 0 | 中性 | 必要过场 / 时间跳跃 |
| -3 | 轻微负面/紧绷 | 日常违和 / 小委屈 / 异常端倪 |
| -5 | 明显负面/高危 | 公开羞辱 / 财产掠夺 / 误解升级 |
| -7 | 强烈虐感/惊惧 | 撞破致命背叛 / 灾难求救被辱 / 诡异逼近 |
| -9 | 极致谷底/绝境 | 尊严粉碎 / 命级赌注 / 死遁惨死 |

### 情感曲线形态

| 形态 | 特征 | 适用题材 |
|------|------|----------|
| V形 | 先压后扬，卡点翻盘 | 复仇打脸、男频都市反杀、年代重生 |
| 阶梯上升 | 连环小爽→大爽，40% 起持续兑现 | 打脸爽文、甜宠、脑洞设定流 |
| 波浪 | 压迫与反击/虐与甜多轮拉扯 | 追妻火葬场、总裁豪门、双男主 |
| 压缩弹簧 | 前段蓄压取证，中后段集中清算 | 世情打脸、宅斗宫斗 |
| 断崖下跌 | 平静或微甜后骤然崩塌/惊悚 | 悬疑、死人文学、BE虐恋 |
| 混合型 | 标注主形态与次形态 | 复合题材 |
