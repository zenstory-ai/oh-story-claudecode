# Stage 2–3：五段结构、情节节点、情感线、爆点与钩子

Stage 2–3 时刻读本文件。方法与标尺在前，输出模板在后；每阶段写完按 [output-contract.md](output-contract.md)「质量检查清单」自检。

## 方法

### Stage 2：五段结构 + 情节节点

- **结构分析**：以 `measure-short-metrics.js` 实测的总字数、分节方式（兼容 `###第N章`、`###1.`、`###01`、`第N章`、`1.` 及黑岩双编号）与首/后续节体量为底稿；提取**故事核**（设定 + 冲突 + 核心行动合一句）、**故事梗概**（200–400 字）、POV 与时间线，并按网短篇五段实录：**导语冷开场 / 免费建压 / 付费强卡点 / 中后段反击反转或主推演 / 收尾清算或回甘**（半成品只写已有段）。
- **分轨识别（不拿单一打脸公式硬套）**：
  - **打脸爽文轨**：通常 35%–45% 卡点启动连环反击，85%–100% 明账清算。
  - **死人文学 / 追夫火葬场 / 男频出轨反杀轨**：合理蓄压至 **50%–55%** 才核爆，重不可逆代价或集中掀桌。
  - **知乎脑洞吐槽 / 甜宠轻喜轨**：前 40% 可零苦大仇深，靠高概念喜剧错位、反差人设与高密度吐槽/糖点推进。
  - **悬疑推理 / 世情现实轨**：悬疑看线索与规则；世情允许「克制边界 + 微光回甘」收口。
- **情节节点**：以真实状态变化（风险、信息、关系、筹码、决定或认知变化）切分，同一动作链合记 1 条，不为凑数拆分。每条带节号、约字位、6 种功能枚举之一、情绪值与关键原话短引（按原文顺序记录，不改排倒叙导语）。

### Stage 3：情感曲线、爆点与钩子卡点

- **情感曲线**：在情绪立场、期待或压力实际变化处取点（首尾必取），记起始、走向、极值、方向差、翻转次数、首冲突/首对话字位及前 40% vs 后 60% 爽点/高能分布。
- **爆点与期待感**：拆解铺垫、积累、延迟、爆发点、余波与记忆点，区分连环串联与叠加爆发；逐节核查期待制造、兑现、升级与剩余。
- **钩子与 32%–44% 付费断点**：判断边界是否制造具体追读问题（下一秒怎么反杀/真相是什么），统计**非末节节尾卡点率** `带硬钩子的非末节数 / (总节数 - 1)`，重点查 **32%–44%**（知乎中位 38%，脑洞/纯爱 ~37%、言情/大女主 ~40%–41%，分章平台多在第 3–4 节末）是否悬停强卡点、**付费后首拍是否四连兑现**（先反抗/甩旧账→实锤→倒戈→新赌注），并警惕 **45% 提前清仓透支**（中段演完大戏致后半水尾）；火葬场/死人文学若在 **38%–45% 切 1 节施害者视角**，单评其对比增压效果。无平台断点标注时报告「候选强付费断点」及占比。

## 标尺速查

### 节点功能（6 种枚举，禁自创）

| 功能 | 判定标准 |
|---|---|
| 情绪节点 | 受辱心死、委屈爆发、爽感释放等明显情绪切换 |
| 信息节点 | 释放新事实、底牌或证据，改写角色/读者判断 |
| 冲突节点 | 两方正面压迫、羞辱、拒绝或当众反杀 |
| 转折节点 | 主动权易手、关系断裂或故事走向改道 |
| 对话节点 | 靠道德绑架金句、软刀挑衅或一句封死推剧情 |
| 氛围节点 | 时空快切、场景切换或悬疑异常突变 |

### 情绪类型与强度（`-9~+9`；首尾单用 `1–10` 绝对量表）

- **类型**：`愤怒/憋屈`、`心碎/心死`、`震惊/反转`、`爽感/解气`、`紧张/诡异`、`心动/高甜`、`好笑/荒诞`。
- **刻度**：`+9` 极致爽点/总清算/高甜确认；`+7` 关键反击得手/爆笑名场面；`+5` 局部反制/阶段甜头；`+3` 暗牌备好/冷静觉醒；`0` 必要过场；`-3` 违和/小委屈；`-5` 公开羞辱/掠夺；`-7` 撞破背叛/高危逼近；`-9` 尊严粉碎/命级绝境/死亡。
- **曲线形态**：`V形`（先压后扬）、`阶梯上升`（40% 起持续小爽→大爽或轻喜递进）、`波浪`（多轮虐甜/拉扯）、`压缩弹簧`（蓄压至 45%–55% 集中爆发）、`断崖下跌`（骤然崩塌/死人文学/悬疑惊悚）、`混合型`（标主次）。

### 钩子功能类型（`structure_counts.hooks` 按成立数照实计，可为 0）

| 类型 | 成立信号 | 常见假阳性 |
|---|---|---|
| 未完成动作 | 巴掌将落、门被踹开、协议刚掏出留到下节 | 只写「他决定了」下节无行动 |
| 狠话与条件压迫 | 甩出升级赌注或离谱条件逼主角表态 | 重复同一句骂词，筹码未升级 |
| 底牌/身份预告 | 亮暗牌一角、剧透反杀或火葬场后果 | 空喊「一切才刚开始」无具体事实 |
| 证据/真相露一角 | 监控/录音/报告刚翻开关键处或偷听撞破 | 只补一条背景设定 |
| 围观震惊与当众反转 | 公开场身份/证据翻转引发称呼或立场倒戈 | 路人干喊震惊却无新事实或地位变化 |
| 关系转向与心死 | 撞破背叛后心死定格、断供离场 | 只吵架不改站位与选择 |
| 风险/倒计时落地 | 明确期限、命级/财产级赌注逼近 | 只堆形容词不改行动条件 |
| 后果反打 | 刚落地的恶行或反制立刻触发连锁反噬 | 天降无关新危机 |

> 连续多节只压迫不给反制或暗牌记「纯虐空转」；另起无关问题记「链条断开」。
