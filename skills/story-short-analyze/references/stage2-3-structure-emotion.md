# Stage 2–3：结构、情节节点、情感线与爆点

Stage 2–3 时刻读本文件。方法在前，输出模板在后；每个 Stage 写完按 [quality-checklist.md](quality-checklist.md) 对应小节自检。题材、钩子、悬念、核心机制各有观察标尺，所读文件以入口「按时刻读」为准。

## 短篇与长篇的分析侧重

下表概括常见差异，具体篇幅、人物数和结构以源文为准。

| 维度 | 长篇 | 短篇 |
|------|------|------|
| 篇幅 | 可跨数十万字、数百章 | 在有限全文内完成主要冲突 |
| 弧线 | 可有多线、多卷 | 通常集中于少量弧线 |
| 人物 | 可容纳较大群像 | 角色功能相对集中 |
| 世界观 | 可逐步展开复杂设定 | 设定围绕当前冲突展开 |
| 核心驱动 | 可持续循环、升级 | 一次完整的情绪或认知变化 |
| 读者粘性 | 追更驱动 | 一口气读完 |
| 分析重心 | 结构完整性、伏笔管理 | 情感设计、写作手法、节奏 |

**核心：短篇靠共鸣和爆点驱动。拆文就是看它用什么故事核、怎么铺垫、在哪里引爆。**

## 方法

### Stage 2：结构分析 + 情节节点提取

- 识别章节/小节分隔符（###01、第一章、01 等）
- 提取标题，记录每节字数
- 提取**故事核**（分三层概括）：
  - **设定**：故事的前提/触发条件（如"重生三次被母弟杀害"）
  - **主题**：核心矛盾/价值观冲突（如"极端重男轻女"）
  - **核心行动**：主角做了什么（如"放任母弟自毁"）
  - 合并为一句：如"重生三次被母弟杀害的女孩，第四世放任她们自毁"
- 写**故事梗概**（200-500字概括）
- 识别 POV（第一/第三人称、全知视角）
- 识别叙事时间线（线性/插叙/倒叙/双线交叉）
- 将全文按功能分段，至少含开端/发展/高潮/结局，源文确有转折或过渡段时再加，标注每段字数范围和占比

> **灵活分节**：部分故事只有2-3章但内含数字编号小节，此时"节"应以叙事功能单元为准，而非物理章节。章节过少时以小节/编号段为分析单位。

**非标文本分段**：对话体、聊天记录、帖子体、书信体等非标准章节格式，先按时间/说话人
切换/信息揭示点分段，再映射到开端、发展、高潮、结局；不要机械按自然段数量切分。

#### 情节节点提取

情节节点 = 推动故事发展的关键事件或信息释放。

提取以语义变化为边界：风险、信息、关系、资源、决定、行动或读者理解发生变化时记一个节点；同一动作链连续完成多个功能时可记为一个节点并在描述中说明，不按字数或小节配额拆分。覆盖全文真实变化，不为达到目标数量重复记录同一事件。

每个节点提取：

| 字段 | 说明 |
|------|------|
| 序号 | 按事件在文本中的出现顺序排列；倒叙中的故事内时间另行标注 |
| 位置 | 所在节号 + 约在全文第几字（如「第3节，约3200字」），下游据此安排新故事节奏 |
| 功能 | 情绪节点/信息节点/冲突节点/转折节点/对话节点/氛围节点 |
| 描述 | 客观白描，只记录发生了什么（禁止叙事框架词） |
| 原文引用 | ≤300 字直接引用 |
| 情绪标记 | 情绪类型 + 强度（-9 到 +9） |
| 涉及人物 | 全名 |
| 手法标记 | 使用了什么手法（如有时） |

### Stage 3：情感线 + 爆点分析

#### A. 情感曲线

从情节节点数据生成情感曲线。只在情绪立场、期待或压力实际变化处取点，开头和结尾各取一点；完整任务、推理、手艺或等待链没有独立情绪转折时无需为该节补点，不为凑点数补点。

曲线特征提取：
- 起始情绪
- 走向模式（上行/下行/波浪/V形/倒V/阶梯/断崖/压缩弹簧）
- 极值（最高点、最低点及其位置百分比）
- 方向差（起始到结尾的净变化）
- 翻转次数（正负交替次数）

#### B. 爆点分析

分析故事的情感爆发设计：

| 维度 | 问题 |
|------|------|
| 铺垫 | 什么让读者开始在意？前多少字完成？ |
| 积累 | 什么在积累情绪势能？积累多久？ |
| 延迟 | 有没有延迟释放？信息差/误解/悬念？ |
| 爆发点 | 哪个瞬间释放全部情绪？精确到句子 |
| 余波 | 释放后有没有余震？多个角色反应？ |
| 印象 | 情绪释放后留下什么？读者记住什么？ |

**叠加爆点**：有些故事的爆点是分层的——表层爆点（如死亡/分离）刚引爆，深层爆点（如真相揭示/认知颠覆）在前一个余波中二次爆发。分析时需标注：
- 是否存在叠加爆点？
- 表层爆点和深层爆点分别是什么？
- 叠加效果（1+1>2 的增效在哪里？）

**多爆点串联**：部分故事（豪门复仇、舆论反转）有多个独立爆点逐个引爆，每个爆点自成一体但互相呼应。分析时需标注：
- 有几个独立爆点？分别是什么？
- 爆点之间是递进（一个比一个爽）还是并列（不同维度的满足）？
- 爆点间隔是否合理（间隔太远=情绪断裂，太近=疲劳）？

#### C. 期待感分析

逐节追踪期待状态，表模板见下方输出模板「C. 期待感分析」。

记录新期待何时建立、核心期待何时推进；停顿是否有效，结合期间的选择、信息与后果判断。

## 情节节点提取规则

### 节点功能（6 种，不得自创）

| 功能 | 定义 | 识别特征 |
|------|------|----------|
| 情绪节点 | 角色内在情绪发生明显转变 | 情绪词、行为变化、内心独白 |
| 信息节点 | 新信息被释放（读者或角色获得新认知） | 揭示、发现、被告知 |
| 冲突节点 | 人物间产生正面对抗 | 直接对抗、拒绝、威胁 |
| 转折节点 | 故事方向发生偏转 | 剧情方向改变 |
| 对话节点 | 包含关键信息的对话或潜台词 | 传递新信息或改变关系 |
| 氛围节点 | 环境/氛围的重大转变 | 场景切换、时间跳跃、季节变化 |

### 质量要求

1. **客观白描**：只记录"发生了什么"，禁止主观评价
   - 禁止：「沈暮月心碎地听到了真相」
   - 正确：「沈暮月听到"私生子而已"，手停在半空」
2. **叙述顺序**：按事件在文本中的出现顺序排列，不把倒叙改排成故事内时间线
3. **情绪标记精确**：每个节点标注情绪类型和强度值
4. **信息保真**：不遗漏改变上下文的关键细节
5. **高度浓缩**：一个节点一句话概括
6. **复合合并**：为同一情绪/叙事目的服务的连续微动作合并为一个节点，共用一个 N 编号；统计「节点数」时按最终 N 编号总数计

### 白描 vs 评价

- 禁止：「通过这段对话展现了她的坚强」
- 正确：「她直视霍庭煜说"我没有义务配合你"」
- 禁止：「气氛变得紧张」
- 正确：「霍庭煜的眼神一下子冷了」

## 情感线分析

### 情绪类型

| 类型 | 信号词 |
|------|--------|
| 心疼 | 行为细节、隐忍描写 |
| 愤怒 | 反派行为、不公待遇 |
| 震惊 | 反转、真相揭示 |
| 满足 | 爽点释放、恶人受罚 |
| 紧张 | 悬念、危机 |
| 心酸 | 放手、遗憾、成长 |
| 治愈 | 关怀、团聚、被理解 |
| 压抑 | 委曲求全、隐忍 |

### 情绪强度量表

| 值 | 对应 | 描述 |
|----|------|------|
| +9 | 极致爽感 | 打脸、碾压、终极反转、恶人伏法 |
| +7 | 强烈满足 | 关键证据揭露、期待满足 |
| +5 | 明显正面 | 小胜利、温情时刻 |
| +3 | 轻微正面 | 小进展、日常温馨 |
| 0 | 中性 | 过渡、铺垫 |
| -3 | 轻微不适 | 小挫折、小委屈 |
| -5 | 明显负面 | 被羞辱、被误解、被威胁 |
| -7 | 强烈虐感 | 被抛弃、被背叛、孩子受委屈 |
| -9 | 极致虐感 | 生死威胁、灵魂碾压、信仰崩塌 |

> **量表说明**：本量表用于情感曲线，区分方向（虐/爽）和强度，范围 -9~+9（仅使用奇数值：±9, ±7, ±5, ±3 和 0）。开头/结尾分析使用独立的 1-10 绝对强度量表（只看强弱，不看正负）。

### 情感曲线形态

| 形态 | 特征 | 适用题材 | 典型效果 |
|------|------|----------|----------|
| V形 | 先虐后爽 | 打脸/复仇 | 极致反差 |
| 倒V | 先甜后虐 | BE虐文 | 遗憾意难平 |
| 波浪 | 正负交替 | 追妻火葬场 | 情绪拉扯 |
| 阶梯上升 | 逐步升级 | 爽文/打脸 | 节奏感强 |
| 断崖下跌 | 突然反转 | 死人文学/反转 | 震惊 |
| 压缩弹簧 | 长期压抑后一次释放 | 隐忍布局 | 极致释放 |
| 双峰 | 两个高潮 | 复杂短篇 | 层次丰富。两个高潮可以都是虐的（如两次告别），也可以是不同性质的（先解脱后通透） |
| **混合型** | 上述形态的组合 | 视组合而定 | 需标注主要形态和次要形态。甜宠/喜剧类可能全程正值不经历负值，属于阶梯上升的变体 |
