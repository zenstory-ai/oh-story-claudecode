# 短篇源文题材识别指南

> 根据网络短篇源文的读者承诺、冲突载体与清算方式识别题材，与 14 类短篇流派一一对齐。

## 使用方式

先根据全文证据给出一个主类型，必要时再加副类型或元素标签。题材名称不能只由时代背景或单个桥段决定。

`_meta.json.genre_detected` 只取下表「类型」列的 **13 个题材名**之一；证据不足或均不匹配时写 **`通用短篇`**（合共 14 类枚举）。小三/死人文学/意难平归入 `追妻火葬场` 并标副标签；民俗怪谈/规则怪谈/叙诡归入 `悬疑` 并标对应副标签；双女主、民国旧影、体育电竞、娱乐圈、器物视角等元素落入 `通用短篇` 或按主线归入对应主类型并写进副标签。

每个题材判断都要回答：

1. 源文持续交付的核心情绪/爽点是什么？
2. 哪些可定位情节承担了这个承诺？
3. 结尾实际清算或兑现了什么？
4. 若存在混合题材，哪个拥有主线高潮，哪个只提供手段或外壳？

## 混合题材判定

按证据优先级区分主次：
1. **主线所有权**：删掉该类型后，核心冲突与因果链是否仍成立？
2. **高潮所有权**：终局清算在结算哪一种矛盾？
3. **情绪所有权**：读者最终消费的是爽打脸、虐追悔、甜互动、脑洞反差、青春救赎、超凡反杀还是悬疑战栗？
4. **手段与目的**：系统/重生/悬疑/超凡是核心卖点，还是服务另一条主线的工具？

证据不足时归 `通用短篇` + 元素标签，并注明不确定项。

## 报告格式

```markdown
主类型：{13 个类型名之一，或 通用短篇}
副类型/元素标签：{可选，如 民俗怪谈 / 叙诡 / 死人文学 / ABO / 双女主 / 穿书}
定位证据：{节次/原句/情节点}
主线所有权：{哪类冲突拥有高潮与清算}
符合常见模式：{观察到的功能，不写合格/不合格}
偏离或改造：{源文如何改变常见模式}
不确定项：{证据不足/待复核}
```
