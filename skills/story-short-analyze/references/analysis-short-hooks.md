# 短篇源文钩子与付费卡点分析标尺

> 观察网络短篇在导语、节尾和 30–40% 付费断点处如何吊住追读。只报告源文实际出现的钩子、卡点与回应，不套长篇连载模型。

## 钩子成立条件

判断边界是否形成有效钩子，看它是否制造了具体的「下一秒会发生什么 / 对方怎么死 / 真相是什么」追读牵引。每个候选点记录：

```markdown
位置：{导语/第N节末/付费断点}
边界前已知：{局势与认知}
边界新增：{狠话条件、动作打断、底牌预告、来人来电或围观反转}
读者新问题：{具体追读问题}
后续回应：{位置与兑现}
```

## 功能类型

| 类型 | 可观察变化 | 常见假阳性 |
|---|---|---|
| 未完成动作 | 巴掌将落、协议刚掏出、门被踹开，结果留到下节 | 只写「他决定了」，下节没行动 |
| 狠话与条件压迫 | 反派甩出离谱条件或当众羞辱，逼主角表态 | 重复同一句骂词，筹码未升级 |
| 底牌/身份预告 | 亮出暗牌一角、剧透「他们不知道我已是XX」或火葬场预告 | 只写「一切才刚开始」无具体事实 |
| 证据/真相露一角 | 监控/录音/血缘报告刚翻开最扎眼一处，或偷听撞破真心话 | 只补一条背景设定 |
| 围观震惊与当众反转 | 公开场合身份/证据翻转引爆全场倒戈、称呼突变 | 路人干喊震惊却无新事实或地位变化 |
| 关系转向与心死 | 撞破背叛后心死定格、递离婚书、断供翻脸 | 只吵架不改变站位与选择 |
| 风险/倒计时落地 | 明确期限、命级/财产级赌注逼近 | 只堆形容词不改行动条件 |
| 后果反打 | 刚落地的恶行或反制立刻触发连锁反噬 | 天降无关新危机 |

## 强度与卡点率统计

1. **预测更新**：边界是否立刻改写读者对胜负、身份或报应的预期。
2. **下节承接**：下一节首句是否直接接住这个动作或问题，不另起话头。
3. **非末节节尾卡点率**：统计 `带硬钩子的非末节数 / (总节数 - 1)`，客观记录是否形成高频追读节奏（商业网短篇常见约 70% 及以上）。

## 钩子链

| 起点位置 | 追读问题 | 回应位置 | 回应兑现 | 如何甩出下一钩 |
|---|---|---|---|---|

连续多节只压迫不给反击或暗牌，报告为「纯虐空转」；另起无关问题报告为「链条断开」。

## 30–40% 付费断点检查

付费断点是商业转化的核心位置，重点核查：
- 断点是否落在全文约 **30%–40%**（常见第 3–4 节末）的强卡点上（未完成动作、底牌将亮、身份揭穿前半拍、忍无可忍准备反杀）。
- 付费后第一拍是否立刻兑现断点承诺，不靠灌水拖延。
- 核心连环打脸与最终清算是否保留在付费段（40%–90%）持续释放，未在免费段提前泄光。
- 无平台标注时报告「候选强付费断点」及具体字数占比。

## 报告格式

```markdown
关键钩子：{位置、类型、边界变化}
非末节节尾卡点率：{M}/{N-1}（{X}%）
钩子链：{因果接力或断裂}
付费断点：{位置与字数占比、卡点手法、付费后承接}
弱边界或假钩子：{位置与原因}
```

## 边界

- `structure_counts.hooks` 统计上表成立的钩子数，按实记录，可为 0。
- 围观震惊只要伴随身份翻转、证据曝光或地位逆转即计为有效钩子。
