# 短篇源文结构模式标尺

> 对照网络短篇源文，观察冷开场、付费卡点、反击打脸与明账清算如何推进。按源文实际节奏记录，不套传统文学慢热框架。

## 识别原则

先按网短篇五段功能（导语冷开场 / 免费建压 / 付费强卡点 / 连环反击反转 / 明账清算收尾）划分源文，再判断其接近哪种高频爆款结构。模式成立看三类证据：开局赌注与压迫、30–40% 卡点转折、40% 后持续兑现与彻底清算。

## 常见网短篇结构模式

| 模式 | 可观察功能链 | 成立证据 | 常见失败 |
|---|---|---|---|
| 冷开入局—卡点建压—连环打脸清算 | 导语抛狠赌注 → 1–3 节反派步步加码 → 付费卡点亮反击信号 → 40% 起连环打脸与明账清算 | 压迫、反击与反派实质下场一一对应 | 前 70% 纯受气，末尾两句草草清算 |
| 公开场—底牌亮牌—全场倒戈审判 | 私下或宴席/股东会被羞辱 → 主角当众甩铁证或碾压级身份 → 围观倒戈、反派跪求破防 | 权力与称呼当场翻转，围观有效放大出气感 | 只靠口水互骂，缺硬底牌或围观见证 |
| 偷听心死—决裂离场—火葬场追悔 | 付出被踩踏 → 门外撞破真相一瞬心死 → 签协议/断供/改嫁离场 → 渣方迟来疯找被冷拒 | 心死切换干脆，渣方追悔写足反差 | 心软回头原谅，或前 1/3 慢热铺垫太长 |
| 前世惨死—重生让坑—看极品自毁 | 导语写透前世死法 → 再睁眼主动把烂亲事/巨坑让给反派 → 顺水推舟收网清算 | 今生第一步即反常，报应全是反派自找 | 重生后还在原路忍气吞声 |
| 外挂上线—脑洞升级—双向反转收口 | 导语演示弹幕/系统/心声 → 玩法逐节变离谱 → 中段情报翻面或梗后翻真 → 爽点闭环 | 设定每次用出新反差，口语吐槽密 | 设定只用一次，中段退回流水账 |
| 恶行累积—暗中蓄证—记账式总清算 | 身边亲戚/婆媳细碎盘剥+帮凶和稀泥 → 主角不动声色留证记账 → 当众逐笔算清+恶人内讧 | 金额物件精确，恶人互咬与听说体下场解气 | 恶人无生活糖衣，或没用规则证据落地 |
| 异常规则—破戒应验—反转或留白（悬疑/民俗） | 立规矩/抛不可能细节 → 破戒遭报或假底被推翻 → 微物证回溯或细思极恐收尾 | 线索可回溯，规则边界稳定 | 临时改规则或凭空掏新证据 |
| 误会同框—例外投喂—高糖确认（甜宠/双男主） | 错位开局强制同框 → 嘴硬心软/温差拉扯递进 → 短吃醋或视差揭穿 → HE 发糖 | 糖点高频推进，虐钩短用且能洗白 | 误会拖半篇、虐大过甜 |
| 死亡缺席—灵魂旁观—迟来崩溃 | 开局已死制造信息差 → 生者继续羞辱 → 遗物/监控揭穿真相 → 渣方带悔恨度余生 | 不可逆的「来不及」压强拉满 | 用一封遗书一次性讲完，缺过程刺痛 |

## 比较原则

- 用实际节次与字数占比描述结构，重点核查首冲突是否 ≤100 字、付费卡点是否在 30–40%、爽点是否在 40% 后持续释放。
- 复数模式并存时，指明主模式拥有终局清算权；可复用结构必须连同失败条件交付，不复制源文人名、物件与具体桥段。
