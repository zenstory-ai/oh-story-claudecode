# 短篇源文结构模式标尺

> 对照源文，观察压力、信息、关系如何推进并兑现。模式用于比较实际结构，章位、比例和线索数按源文记录。

## 识别原则

先按源文实际功能分段，再判断它接近哪种模式。一个模式成立需要三类证据：前置条件、改变读者判断或情绪的转折、转折后的行动或关系后果。

## 常见模式

| 模式 | 可观察功能链 | 成立证据 | 常见失败 |
|---|---|---|---|
| 建压—反击—结算 | 不公变得具体 → 主角取得行动条件 → 后果落到责任方 | 压力、主动选择和结算属于同一因果链 | 反击靠外援代办，主角只旁观 |
| 异常—取证—改判 | 小异常出现 → 多个解释竞争 → 新证据改变责任判断 | 每笔证据都改变下一步行动 | 线索只添气氛，揭示靠口供补完 |
| 阶段答案—再审—终局 | 一个可信答案暂时成立 → 基于答案产生新行动 → 再审推翻解释但保留事实 | 后一层能解释前一层为何可信 | 连续翻口供，没有中间行动后果 |
| 盟友—依赖—重估 | 关系提供资源或安全感 → 帮助中出现裂缝 → 主角重新判断关系 | 早期行为在揭示后获得新含义 | 盟友到结尾突然换立场 |
| 前世信息—不同选择—新代价 | 旧信息改变当下选择 → 优势产生未见过的反作用 → 新人生得到结算 | 今生关键因果确实不同 | 只复述前世，今生仍走原路线 |
| 恶行—对应反制—可见后果 | 每项伤害建立责任 → 反制使用相关证据或资源 → 后果与恶行相呼应 | 报应不是巧合，且由角色选择触发 | 只罗列惨状和下场，没有因果桥 |
| 规则—验证—付价 | 异常规则被观察 → 角色试用或误判 → 限制与代价改变解法 | 规则边界前后一致 | 临时新增能力解决当前困境 |
| 能力体验—证据推进—能力放弃 | 特殊能力解决局部问题 → 能力不足迫使角色承担现实代价 → 终局选择定义胜利 | 能力服务主线且不能替代最终选择 | 奖励不断升级，短篇主线变成能力说明书 |
| 关系靠近—受阻—确认 | 互动建立特殊性 → 外部或内部阻力检验关系 → 选择给关系定性 | 推进来自共同经历和选择 | 只用身体接触或误会机械升级 |
| 死亡/缺席—重读—余波 | 缺席制造信息缺口 → 生者重读旧行为 → 不可逆事实改变关系判断 | 旧细节可回看，结尾承担失去 | 用遗书一次解释全部真相 |
| 公开场—证据归属变化—审判 | 私下矛盾进入公开空间 → 证据持有人或解释权变化 → 角色承担社会/关系后果 | 公开不是围观，而是改变权力 | 群众反应替代事实证明 |
| 单一目标—代价升级—克制收束 | 目标保持不变 → 每次推进要求更难的选择 → 结尾只结算主要欠账 | 代价与目标直接相关 | 后段另开更大的故事抢走高潮 |

## 结构观察表

```markdown
实际功能段：{按源文列出，不预设数量}
最接近模式：{名称}
前置条件证据：{位置}
关键转折证据：{位置}
行动/关系后果：{位置}
源文的偏离：{增加、删去或重排了什么功能}
偏离效果：{改善/削弱了哪种期待，附证据}
```

## 比较常见模式时

- 用实际段落和节次描述结构，可以报告源文各段占全文的实际比例，但不拿推荐比例判合格；“更早/更晚”相对源文的铺垫是否充足、揭示后是否有后果空间判断。
- 线索数量只记录观察结果；公平性取决于线索是否可回溯、是否进入过角色判断。
- 一篇源文可混合多个模式，需指出主模式承接哪一次高潮和最终结算。
- 可复用结构必须连同失败条件交付，不能把原故事的具体身份、物件和台词当模板复制；默认只说明观察、效果和失败模式，不输出改纲方案。
