# Stage 4–6：反转与写作手法、人物与首尾、综合评估

Stage 4–6 时刻读本文件。方法在前，输出模板在后；每个 Stage 写完按 [quality-checklist.md](quality-checklist.md) 对应小节自检。结构模式、人物关系、投稿层、源文短板的判断方法在各自的观察标尺里，所读文件以入口「按时刻读」为准。

## 方法

### Stage 4：反转设计 + 写作手法

#### A. 反转分析

- **前置反转检查**：是否有在故事时间线之前就已存在的谎言/误判。
- **无反转型/报应型**：无传统反转、靠因果报应逐步兑现的故事（复仇爽文、重生文等），跳过反转机制拆解，改用下方「报应设计」表（区分主角设局触发后果与反派内讧自招损失，结合因果铺垫与情绪兑现说明效果）。
- **反转机制拆解**（存在反转时执行，输出格式见下方「A. 反转分析」）：
  - 逐项拆解铺垫线索（按原文列出位置，数量照实，不凑数）、误导方向、真相揭示、回看合理性、位置百分比及铺垫:释放篇幅比。
  - **反转链**（多反转故事）：按顺序列出每个反转的类型、触发事件、读者认知变化及与前层的因果关系（删除一层后其他层的因果、解释和情绪效果均不变才判冗余）；`reversal_type` 只填对结局影响最大的一层。
  - **伏笔式反转**：开头早就给过的信息在真相揭示后含义完全改变时，记录原文位置、初读理解与回看理解。

#### B. 写作手法分析

逐项分析以下维度的使用情况（每项标注使用位置、效果评价、可复用条件）：

| 维度 | 分析内容 |
|------|----------|
| POV策略 | 人称选择的效果、叙事距离、可靠性 |
| 对话手法 | 密度比、潜台词率、模式识别 |
| 时间操控 | 时间跳跃、场景压缩、平行剪辑 |
| 信息控制 | 读者知道 vs 角色知道、隐瞒/揭示时机 |
| 感官锚定 | 五感分布、主导感官、感官切换 |
| 句式节奏 | 长短句交替、节奏加速/减速、关键句位置 |
| 对比设计 | 角色对比、前后对比、环境对比 |
| 意象/物件 | 重复出现的物件、意象、象征 |
| 留白手法 | 不写之写、省略的艺术、暗示 |
| 专业技能武器化 | 职业特长如何改变对抗手段，操作是否符合已交代的能力与限制 |
| 倒计时框架 | 明确时限如何限制选择、提高损失或改变行动 |
| 双视角叙事 | 同一事件在两个角色视角中提供哪些不同信息，是否改变读者的情感判断 |
| 弹幕/评论互动 | 故事内的"读者评论"成为角色——提供任务、吐槽、剧情预告。弹幕本身可以有变化弧线（从自信到崩溃） |
| 反差萌 | 角色想装一种人却总是暴露本性，每次"装失败"都让对方更喜欢。注意识别重复升级的模式 |

### Stage 5：人物分析 + 开头结尾

- **人物提取范围**：逐一提取有名有姓（≥2字符且有台词或推动剧情）或反复出现（≥2节且承担叙事功能）的人物；不提取群体称呼、无名路人及亲属/身份泛称（除非原文固定指代某角色）。
- **二维分类与功能标签**：
  - **叙事角色**：主人公（第一视角或核心焦点；两人均有完整情感弧线、分驱动 A/B 段且读者强共情时均标主人公并注各自驱动节次）/ 重要配角（有独立弧线）/ 功能人物（催化剂、对照组等）。
  - **行动角色**：主动型（主动推动、做关键选择）/ 被动型（被动承受）/ 转变型（从被动转主动或反之）。
  - **功能标签**（可多选）：情绪承载者、压迫源、反转触发器、道德锚点、对照组、催化剂、自毁型。
  - **有反差人物**（计入 `character_archetypes`）：外界身份 / 展现行为 / 真实内核三层中至少一层与另两层相反且有一处原文行为对照为证（细拆时读 analysis-characters.md）。
  - **内在矛盾、功能评估与关系**：内在矛盾写核心心理冲突（如「渴望被爱却学会在不爱中生存」），不写外部遭遇；功能评估看出场效率、功能密度、可删除性与对话贡献；人物关系对保留最终状态，历史变化写入演变轨迹并注转折位置与触发原因。
- **开头、结尾、首尾呼应与钩子回收**：按下方输出模板「B. 开头分析」至「E. 钩子回收检查」填写（开头/结尾情绪强度均用 1-10 绝对量表；未回收钩子标「留白」或「遗漏」）。

### Stage 6：综合评估报告

按下方输出模板「综合评估」输出故事核评价、五维评分（源文主打甜宠/喜剧/反差萌且无传统反转时，可用“反差萌浓度”替换“反转设计”、“甜度曲线”替换“情感拉扯力”，不因缺反转扣分）、爆点性、话题性、共鸣层次、主结构（对照 analysis-short-patterns.md）、投稿层（对照 analysis-submission.md）、可复用结构及节奏速报（判断源文好坏时加源文短板）。

## 写作手法、人物与共鸣要点

- **POV 策略**：
  - 分析 POV 内信息操控（不可靠叙述者/选择性回忆/隐瞒）及 POV 切换时机；当 POV 角色无法直接推动剧情（灵魂旁观、昏迷旁观）时，核查活人代理人的出场时机与行动力。

| POV 类型 | 好处 | 代价 |
|----------|------|------|
| 第一人称 | 亲密感强、天然制造信息限制 | 无法展示主角不知道的事 |
| 第三人称限制 | 聚焦主角同时保持一点距离 | 比第一人称少一层亲密感 |
| 全知视角 | 可自由切换、制造戏剧反讽 | 容易破坏悬念 |
| 第二人称 | 强代入感、实验性 | 长篇幅容易疲劳 |
| 非人视角（宠物/物品/亡魂） | 天然陌生化+情绪降维打击，信息差自然成立 | 视野受限，需借他人对话补全剧情 |

- **对话手法**：统计对话占比（对话字数/全文字数，与同题材同平台样本对照，不设通用合格线）与潜台词率（含潜台词条数/总条数，结合告知/求救/试探/回避场景评价，不以越高越好）；追踪称呼变化轨迹及触发事件。

| 对话模式 | 机制与特征 |
|----------|------------|
| 审判式 | 主角提问→对方被迫自爆，每轮追问剥掉一层伪装 |
| 压制式 | 短促紧逼或礼貌沉默制造权力压迫；越界常按「陈述事实→加建议→指责→指责加命令→贬低对方抬高自己」递进 |
| 信息差式 | 双方基于不同认知对话，读者看清错位或反转后回看恍然 |
| 推拉式 | 情绪试探与防御拉扯，拉近与推开交替 |

- **时间操控**：

| 手法 | 定义 | 识别特征 |
|------|------|----------|
| 时间跳跃 | 略过无戏剧性时段，省字数/制造变化感 | 「三年后」「五年后」 |
| 场景压缩 | 用几句话概括长时间过程，加速推进 | 概述性段落 |
| 平行剪辑 | 两条时间线交替展示，制造张力/对比 | A线/B线交替出现 |
| 倒叙 | 先展示结果再追溯原因，制造悬念 | 结果先行，回溯原因 |
| 闪回 | 打断主线穿插回忆片段，补充动机/制造反差 | 突然插入过去场景 |
| 实时展开 | 逐秒展开关键时刻，放大高潮张力 | 关键场景慢动作 |

- **信息控制、留白与意象追踪**：
  - **信息控制**：按开头/中段（反转前）/结尾（反转后）对比读者、主角、对手所知及信息差。
  - **留白手法**：区分结局留白（不交代最终结果，制造余韵）、情绪留白（最痛处用克制动作替代哭喊）、信息留白（暗示而不说破，让读者自己拼出真相）。
  - **主题意象群**：多个物件/意象指向同一主题时归为主题意象群（标注共同主题、各物件角度与整体效果）。
- **爆点性与话题性分析维度**：
  - **爆点性**：核查核心爆点是什么、铺垫是否充分、释放是否到位、传播性如何（读者能否一句话转述给别人）。
  - **话题性**：核查争议点（评论区会吵什么）、代入式自省（读者会不会联想到自己的处境）、"如果是我会怎样"的选择题空间。
- **人物内在矛盾（写心理冲突，不写外部遭遇）**：

| ❌ 错误（外部遭遇/行为描述） | ✅ 正确（内在矛盾） |
|------|------|
| 她被丈夫抛弃了 | 她渴望被爱但学会了在不爱中生存 |
| 他对她不好 | 他习惯了掌控一切却无法掌控自己的感情 |

- **人物功能标签（7 种，可多选）**：

| 标签 | 定义 | 示例 |
|------|------|------|
| 情绪承载者 | 承载读者共情的主要载体 | 第一人称主角 |
| 压迫源 | 制造负面情绪的角色 | 冷漠/控制的男主 |
| 反转触发器 | 触发关键反转的角色 | 绑架事件中的第三方 |
| 道德锚点 | 代表正常价值观的角色 | 关心/担忧主角的长辈 |
| 对照组 | 与主角形成对比的角色 | 温和的配角 vs 冷酷的主角 |
| 催化剂 | 推动剧情但不直接参与核心冲突 | 连接/温暖型角色 |
| 自毁型 | 自身行为导致自我毁灭的角色 | 重男轻女的母亲、偏执的家属 |

- **人物功能评估**：

| 指标 | 评估问题 |
|------|----------|
| 出场效率 | 第一次出场就完成定位了吗？ |
| 功能密度 | 承担了多少叙事功能？ |
| 可删除性 | 删除后，因果、情绪或关系理解会损失什么？主线仍成立不等于人物多余 |
| 对话贡献 | 每次对话都推动剧情或情绪吗？ |

- **共鸣层次（7 层，每层标 强/中/弱/无 并附触发证据，至少分析 3 层；无读者反馈时为分析判断，不断言传播效果）**：

| 层次 | 定义与易混淆区分 |
|------|------|
| 情感共鸣 | 对角色当下情绪的即时共情（心疼、愤怒）——区别于「情感深度共鸣」 |
| 价值观共鸣 | 对故事传达的具体观点的认同（如"女性不该被定义"）——区别于「普世价值共鸣」 |
| 经历共鸣 | 与读者自身经历的相似性 |
| 社会现象共鸣 | 与社会热点/普遍现象的关联 |
| 普世价值共鸣 | 对自由、尊严、爱等人类共同追求的宏观认同 |
| 情感深度共鸣 | 情绪体验留下的持久影响（读完几天后还在想） |
| 人物深度共鸣 | 对人物复杂性的理解和认同 |

## 节奏分析

### 节奏指标

| 维度 | 计算方式 | 对照方式 | 说明 |
|------|----------|----------|------|
| 事件密度 | 节点数 / 全文字数 × 1000 | 同题材、同平台样本及本文前后分布 | 结合节点是否真实改变状态判断，不用数量直接判水或赶 |
| 对话密度 | 对话字数 / 全文字数 × 100% | 同题材、同平台样本 | 只描述文本倾向；对白功能与无对白场景的推进方式另行判断 |
| 冲突密度 | 冲突节点数 / 总节点数 × 100% | 同题材、同平台样本及本文压力来源 | 任务、证据、等待、空间和关系压力须另行记录，不用直接冲突占比代替张力判断 |
| 信息密度 | 信息节点数 / 总节点数 × 100% | 本文读者判断的变化与后果篇幅 | 判断新信息是否可理解、会改写判断并得到消化，不设通用比例 |

### 节奏异常检测

| 异常模式 | 文本信号 | 复核问题 |
|----------|----------|----------|
| 节奏塌陷 | 连续叙事单元没有状态变化、因果后果或读者判断的更新 | 场景是在蓄力、完成任务，还是原地复述？ |
| 压力过载 | 多次升级之间没有选择、损失、反应或后果 | 读者是否来得及理解每次升级改变了什么？ |
| 信息洪峰 | 新事实连续出现，却没有查证、定位、行动或旧线索改义 | 哪些信息真正改变判断，哪些只是清单？ |
| 对白失效 | 对话可整段删除，或只剩问答、复述和设定讲解 | 每轮是否改变信息、策略、权力、关系或行动？ |
| 对白挤压场景 | 人物只说不做，空间、任务和后果消失 | 是否需要动作或留白承接，而不是按占比截断？ |
| 反转过载 | 新反转在上一层尚未产生选择或后果时就将其抹掉 | 每层是否有证据、读者判断的变化和可感后果？ |
