# Stage 4–6：反转与写作手法、人物与首尾、结构投稿与综合评估

Stage 4–6 时刻读本文件。方法与速查在前，输出模板在后；每阶段写完按 [output-contract.md](output-contract.md)「质量检查清单」自检。

## 方法

### Stage 4：反转/报应 + 实测网感与写作手法

- **反转与报应**：先查开场前是否存在隐瞒/底牌/前世记忆（前置反转）。无反转时：报应型（打脸/重生让坑/男频反杀）改填「报应设计」表；非报应型（甜宠/轻喜吐槽）注明推进方式。有反转时列铺垫线索（原位置）、误导方向、揭示现场与位置占比，`reversal_type` 取影响终局最大一层。
- **写作手法（落盘 `写作手法.md`）**：
  1. **量化网感体检表（`[BLOCK]`）**：直接运行 `node scripts/measure-short-metrics.js --markdown 拆文库/{书名}/原文/{原文文件}` 获取实测骨架，补全「首冲突位置 / 节尾卡点率 / 收尾类型」三项语义结论，**严禁目测编造数字**。
  2. **3 段原文语感切片（`[BLOCK]`）**：原文一字不改摘录 3 段各 150–250 字连续段落——① 开门见山导语、② 对话交锋或压迫（甜宠取互动拉扯）、③ 高潮打脸或清算（甜宠取高糖兑现），每段只配 1 句节奏注。
  3. **核心手法拆解（≥5 项）**：覆盖视角与在场吐槽/剧透口吻、对话交锋与一问一答反杀（对方长骂→主角一句封死）、竖屏句段与标点（`！`/`？`/`——`）、信息差与层层施压、围观放大与恶人互咬、时间压缩与快切、特殊机制（弹幕/系统/心声）；仅 `悬疑` 主类型另拆公平线索与留白。

### Stage 5：人物与首尾呼应

- **人物提取**：提取有名有姓（≥2 字且有行动/台词）或出场 ≥2 节担功能的人物。标二维角色（叙事：主人公/重要配角/功能人物；行动：主动/被动/转变）、功能标签（情绪承载者/压迫源/软刀情敌/和稀泥帮凶/反转触发器/围观放大器/自毁型）与人设反差/拉仇恨点。**有反差人物**（计入 `character_archetypes`）须在身份/表象/真实底牌间有行为对照。细拆动机链、三层反差或感情线阶段时加读 [analysis-characters.md](analysis-characters.md)。
- **导语与开头**：同时识别**独立导语**（知乎盐言 `1.` 前，常见 150–300 字）与**首节内嵌导语**（七猫/黑岩/点众/番茄首章开头至 `……`/`1.` 前，常复用作简介），辨识开篇引擎（含知乎高频两式：**荒诞现况→信息差→1 句具体动作或画面反差定格**、**极简割席→跨年回访**）；核查四要素、**是否直接续接**（禁 `……`/`1.` 后原地复述导语梗概）及正文现场兑现。
- **收尾清算与首尾呼应**：按流派检查收尾——打脸/复仇/男频看实质代价与高位落点；死人文学/火葬场看迟来崩溃或日记反转（可带简短渣方后劲番外）；世情允许「克制边界 + 微光回甘」；核查**首尾呼应**（开篇已埋原物/原话结局反扣，区别于结尾硬塞呼应）与**禁新闻播报/法院判决书式转述水尾**。

### Stage 6：结构模式、投稿层、短板检测与综合评估

对照下方三张速查表完成主结构、投稿层、源文短板、五维评估与可复用结构，并将 `structure_counts` 与 `voice_metrics` 一次性写入 `_meta.json`。

## 判定速查

### 1. 常见短篇结构模式（主结构对照）

| 模式 | 功能链 | 成立证据 |
|---|---|---|
| 开门入局—卡点建压—连环打脸清算 | 导语抛赌注→1–3 节加压→卡点亮信号→40% 起连环反杀清算 | 压迫、反击与实质下场一一对应 |
| 公开场—亮底牌—全场倒戈审判 | 宴席/股东会受辱→甩铁证或碾压身份→围观倒戈反派破防 | 称呼与权力当场翻转 |
| 偷听心死—决裂离场—火葬场追悔 | 付出被踩踏→撞破真相心死→断供离场→渣方迟来疯找被拒 | 心死干脆、追悔反差足 |
| 重生让坑—反常择路—极品自毁 | 写透前世死法→睁眼把烂亲事/巨坑让给反派→看其自毁 | 今生第一步即反常 |
| 外挂上线—高概念反差—吐槽/反转收束 | 导语演示弹幕/系统/心声/反套路人设→玩法逐节升级→反转或甜爽收尾 | 设定反复出新反差，不退回流水账 |
| 恶行累积—暗中蓄证—记账式清算/回甘 | 亲缘/婚恋双标盘剥→不动声色留证→50%–55% 掀桌算账+回甘或互咬 | 金额物件精准、边界清晰 |
| 异常规则—破戒应验—反转或留白（悬疑） | 立规矩/抛不可能细节→层层查证翻底→微物证回溯或留白 | 旧事实在新解释下仍为真 |
| 错位同框—例外投喂—高糖确认（甜宠/双男主） | 强制同框→嘴硬心软/温差拉扯→视差揭穿→HE 发糖 | 糖点高频推进，虐因可洗白 |
| 死亡缺席—旁观/日记反转—迟来崩溃 | 蓄压至 50% 死亡/离场→遗物/日记/监控揭真相→生者失声崩溃 | 不可逆「来不及」压强拉满 |

### 2. 投稿层与跨平台特征

| 平台 | 书名与导语规格 | 排版、对话与收尾特征 |
|---|---|---|
| 知乎盐言 | 书名多为短意象或脑洞句（4–8 字为主）；`1.` 前独立导语（常见 150–300 字） | `1.` 分节，`「」`/`“”`，短段明快；吐槽/大女主偏重内心独白；脑洞/双男主/病娇/学霸爆发强 |
| 七猫 / 点众 | 两段式第一人称长标题（约 13–18 字，多含逗号）；第 1 章开头内嵌导语（后接 `……`/`1.`）常复用为简介 | `第N章`/`###第N章`，`“”`，首章略长，叙事与对话均衡；偏明账清算、死人文学或世情回甘 |
| 黑岩 | 两段式强情绪长标题（约 13–18 字）；`###第1章` 开头内嵌导语（后接 `1.`/`……`），常用 `###第N章`（常带内层数字双编号） | `“”`，短段快切，对话偏密；男频多为第一人称世情/出轨反杀/追夫 |
| 番茄短故事 | 钩子句或反差概念标题；首节前或首章开头内嵌导语，约三成试读末强卡点 | `###第N章`/`1.`，`“”`，目标直白、爽点外化，坏人实罚 |

> 书名/简介四型：爽感反杀型、悬念卡点型、虐爽火葬场型、脑洞高概念型；须核对书名、导语承诺与正文是否一致（缺资料写「源文未提供」）。

### 3. 节奏异常检测与短板速查（合并「源文短板」用，每条必附位置与原句）

| 异常/短板项 | 判定信号与复核点 |
|---|---|
| 导语诈骗/兑现不足 | 导语承诺「亲手反杀/血债血偿」，正文却无现场反制，仅用「听说他破产了」敷衍 |
| 导语后复读重演 | `……`/`1.` 后不是直接续接现场动作，而是重述导语里的人物背景与梗概 |
| 开篇慢热/前 3 节纯回忆 | 开篇大段纯景物履历，或第 1–3 节连篇纯回忆流水账拖慢入局 |
| 车轱辘回放/节奏塌陷 | 连续多节原地重复「偏心→隐忍→发火」，无筹码、信息、关系或认知升级 |
| 间接引语替代对白 | 核心交锋满篇「他说…她说…」概括转述，不演现场对话（常规短篇对话 <20%，吐槽/悬疑独白除外） |
| 大段文字墙/书面腔 | 大量 >80 字大段文字墙、公文/散文腔，或旁白高频破折号（短篇旁白极少用破折号） |
| 爽点滞后/卡点失力 | 打脸篇前 70%–80% 无暗牌反制、32%–44% 卡点平淡（死人文学/追夫蓄压至 50%–55% 除外） |
| 空降底牌/圣母清算失血 | 中后段无铺垫空降巨额身份，或恶行极狠却心软原谅、强行鸡汤拔高、结局强换赛道 |
| 新闻播报式水尾/假呼应 | 结尾用新闻播报/法院判决书转述敷衍清算，或临时空降开篇未埋物件凑呼应 |
| 跨节人名/姓氏/规则漂移 | 前后姓氏写错（如林家变沈家）、金额/称呼穿帮，或设定规则临时改口、钩子遗漏 |
