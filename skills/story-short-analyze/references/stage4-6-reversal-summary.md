# Stage 4–6：反转与写作手法、人物与首尾、综合评估

Stage 4–6 时刻读本文件。方法在前，输出模板在后；每个 Stage 写完按 [quality-checklist.md](quality-checklist.md) 对应小节自检。

## 方法

### Stage 4：反转/报应设计 + 网感体检与写作手法

#### A. 反转与报应分析

- **前置反转检查**：是否存在故事开场前已埋下的隐瞒、身份底牌或前世记忆。
- **无反转型**：因果报应型（打脸爽文、重生让坑、男频反杀）跳过传统反转拆解，改填「报应设计」表（记录反派恶行→主角反制/自食恶果→当众清算爽感）；纯甜宠、轻喜吐槽等非报应型注明「无反转（非报应型）」并简述核心推进力。
- **反转机制拆解**（存在反转时）：记录铺垫线索（原文位置照实）、误导方向、真相揭示（偷听撞破、证物当众亮牌、剥洋葱均可，不拿悬疑公平标准否决爽文揭露）、位置百分比；多反转填「反转链」，`reversal_type` 取对终局影响最大的一层。

#### B. 写作手法与竖屏网感提取（写入 `写作手法.md`）

1. **量化网感体检表（`[BLOCK]` 必出）**：基于原文实测 9 项客观指标——总字数、节数（附第 1 节 vs 后续节均字）、段长中位、单句成段率、对话占比、叙述人称、首冲突字位（附首对话字位）、非末节节尾卡点率、收尾类型。不靠主观估猜。
2. **3 段原文语感切片（`[BLOCK]` 必出）**：从原文一字不改摘录 3 段各 **150–250 字** 的连续段落，分别覆盖 ① 导语冷开场、② 对话交锋或反派压迫、③ 高潮打脸或明账清算，供下游 `story-short-write` 直接校准竖屏断段、口语节奏与情绪落点（每段只配 1 句节奏注，不扩写赏析）。
3. **核心手法拆解（≥5 项）**：聚焦网短篇实战维度：

| 维度 | 观察重点 |
|------|----------|
| POV与在场声线 | 第一人称代入感、主观审判/吐槽、前瞻剧透（「他不知道」「后来他疯了」） |
| 对话交锋与权力翻转 | 对话密度、直球施压与道德绑架话术、前后话轮长短翻转（对方长篇叫嚣→主角一句封死） |
| 竖屏句段节奏 | 单句成段密度、短句冲击、动作—对话—心理短吐槽交替、标点张力（`！`/`？`/`——`） |
| 信息差与压迫升级 | 读者领先对手的暗牌、小恶→中恶→大恶阶梯、限时倒计时 |
| 围观与情绪放大 | 公开场合见证、围观者分层震惊、恶人内讧互咬、直给情绪词落点 |
| 时间压缩与快切 | 导语倒叙、过场一句带过、关键打脸现场实时慢放 |
| 特殊设定/弹幕/系统 | 弹幕/系统/心声人格化吐槽、规则反杀、职业技能武器化、反差萌 |
| 公平线索与留白（仅悬疑） | 仅当主类型为 `悬疑` 时拆解微物证回溯、假底翻真底与细思极恐留白 |

### Stage 5：人物标签 + 导语冷开场与清算收尾

- **人物提取**：提取有名有姓（≥2 字且有台词/行动）或反复出场（≥2 节且担功能）的人物，不提无名路人群像。
- **标签化定位**：
  - **叙事角色**：主人公 / 重要配角 / 功能人物；**行动角色**：主动型 / 被动型 / 转变型。
  - **功能标签**（可多选）：情绪承载者、压迫源、软刀情敌、和稀泥帮凶、反转触发器、围观放大器、自毁型。
  - **人设标签与拉仇恨/共情点**：直接写清读者一眼认出的人设反差标签与踩雷/共情触发点（如「隐忍清醒豪门主母 / 嘴硬舔狗秒觉醒 / 理直气壮道德绑架婆婆」），不硬套文学心理剖白。
  - **有反差人物**（计入 `character_archetypes`）：外界身份 / 表面行为 / 真实底牌至少一层反转且有原文行为对照。
- **首尾与钩子回收**：检查导语冷开场（首冲突与首对话字位、有无纯景物拖沓、核心赌注量化）、收尾清算（明账清算/火葬场/HE发糖/悬疑留白，反派实质代价是否写足、主角是否站上高位）及全部钩子回收状态。

### Stage 6：综合评估报告

输出一句话爆款机制评价、**网短篇五维评分**（导语钩子与首百字入局 / 付费卡点张力 / 情绪爽虐浓度与推进 / 反派压迫与打脸清算 / 竖屏网感与对话节奏；纯甜宠/轻喜可将第 4 维微调为「关系拉扯与高糖兑现」）、爆点性、话题性、4 层读者共鸣、主结构（对照 analysis-short-patterns.md）、投稿层（对照 analysis-submission.md）、可复用结构与节奏速报，并同步写入 `_meta.json`。

## 节奏异常检测

| 异常模式 | 文本信号 | 复核问题 |
|----------|----------|----------|
| 开篇慢热 | 前 300 字仍未抛核心冲突或对话，纯景物/背景铺陈 | 导语是否直接进了最狠现场？ |
| 砖块长段 | 连续出现 >80 字大段叙述，竖屏压迫感重 | 是否把多拍动作/对白揉成一段？ |
| 爽点滞后 | 前 70%–80% 纯憋屈无局部反制，爽点堆在末尾匆匆收场 | 40% 付费卡点后是否立刻启动反击？ |
| 节奏塌陷 | 连续小节无风险、筹码、关系或认知变化 | 是否原地复述同一情绪？ |
| 对白失效 | 对话可整段删除，或全篇靠旁白概括不演现场 | 冲突交锋是否放进实时对白？ |
| 清算失血 | 反派恶行写很狠，结局却两句带过或强行原谅 | 恶行与报应是否对等写足？ |
