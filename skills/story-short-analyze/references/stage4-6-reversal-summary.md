# Stage 4–6：反转与写作手法、人物与首尾、综合评估

Stage 4–6 时刻读本文件。方法在前，输出模板在后；每个 Stage 写完按 [quality-checklist.md](quality-checklist.md) 对应小节自检。结构模式、人物关系、投稿层、源文短板的判断方法在各自的观察标尺里，所读文件以入口「按时刻读」为准。

## 方法

### Stage 4：反转设计 + 写作手法

#### A. 反转分析

**前置反转检查**：是否有在故事时间线之前就已存在的谎言/误判。

> **无反转型/报应型**：有些故事（复仇爽文、重生文）没有传统反转，爽感来自看反派因果报应逐步兑现。遇到此类故事，跳过反转机制拆解，改为分析"报应设计"——反派如何一步步走向毁灭，每一步的铺垫和满足感。使用报应设计表：每条恶行→对应的报应→爽感来源。理想情况下每条报应与恶行形成精确对应（"以彼之道还施彼身"）。
>
> **主动报应与反派自毁**：区分主角设局触发后果与反派内部反目、自招损失。结合因果铺垫和情绪兑现说明效果，不预设哪一种更真实或更爽。

**反转机制拆解**（存在反转时执行，输出格式见下方「A. 反转分析」）：
- 逐项拆解铺垫线索（按原文列出位置，数量照实，不为凑数补线索）、误导方向、真相揭示、回看合理性、位置百分比及铺垫:释放篇幅比。
- **反转链**（舆论反转、套娃反转等多反转故事）：按顺序列出每个反转的类型、触发事件、读者认知变化及与前层的因果关系；检查后一层如何重释前一层的证据、前一层引发的行动如何促成后一层（删除一层后其他层的因果、解释和情绪效果均不变，才判冗余）。`reversal_type` 只填一个：取对结局影响最大的那一层。
- **伏笔式反转**：开头早就给过的信息在真相揭示后含义完全改变时，记录原文位置、初读理解与回看理解。

#### B. 写作手法分析

逐项分析以下维度的使用情况：

| 维度 | 分析内容 |
|------|----------|
| POV策略 | 人称选择的效果、叙事距离、可靠性 |
| 对话手法 | 密度比、潜台词率、模式识别 |
| 时间操控 | 时间跳跃、场景压缩、平行剪辑 |
| 信息控制 | 读者知道 vs 角色知道、隐瞒/揭示时机 |
| 感官锚定 | 五感分布、主导感官、感官切换 |
| 句式节奏 | 长短句交替、节奏加速/减速、关键句位置 |
| 对比设计 | 角色对比、前后对比、环境对比 |
| 意象/物件 | 重复出现的物件、意象、象征 |
| 留白手法 | 不写之写、省略的艺术、暗示 |
| 专业技能武器化 | 职业特长如何改变对抗手段，操作是否符合已交代的能力与限制 |
| 倒计时框架 | 明确时限如何限制选择、提高损失或改变行动 |
| 双视角叙事 | 同一事件在两个角色视角中提供哪些不同信息，是否改变读者的情感判断 |
| 弹幕/评论互动 | 故事内的"读者评论"成为角色——提供任务、吐槽、剧情预告。弹幕本身可以有变化弧线（从自信到崩溃） |
| 反差萌 | 角色想装一种人却总是暴露本性，每次"装失败"都让对方更喜欢。注意识别重复升级的模式 |

每项手法标注：使用位置、效果评价、可复用条件。

### Stage 5：人物分析 + 开头结尾

#### A. 人物提取

按源文逐一提取人物，记录其实际承担的功能，不预设人数。

**人物分类**（二维体系）：

维度一 — 叙事角色（这人在故事里的位置）：
- **主人公**：故事的第一视角人物或核心焦点人物
- **重要配角**：戏份重、有独立弧线的人物
- **功能人物**：承担特定叙事功能（催化剂/对照组等）

维度二 — 行动角色（这人在故事里怎么动）：
- **主动型**：主动推动剧情发展、做出关键选择
- **被动型**：被剧情推着走、被动承受
- **转变型**：从被动转为主动（或反过来）

> 同一人物可以同时是“主人公”与“被动型”，也可以随剧情转变行动方式。两个维度独立标注。

**双主人公结构**：部分故事（BE虐文、双向视角文）存在两个主人公，各自驱动故事的不同阶段。识别标准：①两人都有完整的情感弧线（不是扁平的）②故事分为明显的"A段"和"B段"，各自以不同角色为中心③读者对两人都有强烈的共情。标注时两人都标为"主人公"，并注明各自主驱动的章节范围。

人物总览表字段见下方输出模板「A. 人物分析」：人物性格从行为归纳，不从标签推导；内在矛盾写核心心理冲突而非外部遭遇；无明显弧线标"扁平"。

**人物功能标签**（7 种）：

| 标签 | 定义 | 示例 |
|------|------|------|
| 情绪承载者 | 承载读者共情的主要载体 | 第一人称主角 |
| 压迫源 | 制造负面情绪的角色 | 冷漠/控制的男主 |
| 反转触发器 | 触发关键反转的角色 | 绑架事件中的第三方 |
| 道德锚点 | 代表正常价值观的角色 | 关心/担忧主角的长辈 |
| 对照组 | 与主角形成对比的角色 | 温和的配角 vs 冷酷的主角 |
| 催化剂 | 推动剧情但不直接参与核心冲突 | 连接/温暖型角色 |
| 自毁型 | 自身行为导致自我毁灭的角色 | 重男轻女的母亲、偏执的家属 |

一个人物可以有多个标签。

**有反差人物**（计入 `character_archetypes`）：给人物填三层标签——身份（外界看到的身份）、表现（他展现给人的行为）、内核（真实内心）；至少一层与另两层相反，且原文有一处行为对照为证（如表面逆来顺受、暗中录音收证据），算一个。只有标签没有行为对照、或三层一致的不算。要细拆反差、动机、反派或关系时读 analysis-characters.md，数人数不必读。

#### A2. 人物关系

从情节节点中提取有直接互动或明确情感描述的人物对（表格式见输出模板「A. 人物分析」）：同一对人物保留最终状态，历史变化写入演变轨迹，注明关系转折的位置和触发原因。

#### B–C. 开头与结尾

按下方输出模板「B. 开头分析」「C. 结尾分析」逐项分析；两处情绪强度都用 1-10 绝对量表（只看强弱），不用情感曲线的 -9~+9。

#### D. 首尾呼应

对比开头和结尾的元素呼应与重读发现，表见输出模板「D. 首尾呼应分析」。

#### E. 钩子回收检查

列出全文埋设的所有钩子及其回收状态（表见输出模板「E. 钩子回收检查」），未回收的钩子标注为「留白」或「遗漏」。

### Stage 6：综合评估报告

综合所有阶段数据，输出评估报告：
- 故事核评价；五维评分（开头吸引力、情感拉扯力、反转设计、节奏控制、结尾余韵）；爆点性 + 话题性；共鸣层次；主结构（对照 analysis-short-patterns.md）；投稿层（对照 analysis-submission.md）；可复用结构（每条含适用场景、失败条件与不能照搬，数量照实）；判断源文短板时加源文短板。模板见下方输出模板「综合评估」。

> **甜宠/喜剧类替代维度**：源文主要交付甜宠、喜剧或反差萌且无传统反转时，可用“反差萌浓度”替换“反转设计”，用“甜度曲线”替换“情感拉扯力”。不因缺少反转直接扣分。

## 写作手法分析

### POV 策略

| POV 类型 | 效果 | 适用情绪 |
|----------|------|----------|
| 第一人称 | 亲密感、代入感强、可操控信息 | 虐恋、自省、内心戏 |
| 第三人称限制 | 兼顾代入和观察距离 | 通用 |
| 第三人称全知 | 上帝视角、多线并进 | 群像、悬疑 |
| 第二人称 | 极度沉浸 | 实验性、心理恐怖 |
| 非人视角 | 新奇感、陌生化 | 系统/鬼/动物视角 |

分析要点：
- 选择这个 POV 的好处和代价
- 有没有 POV 内的信息操控（如不可靠叙述者）
- POV 切换（如有）的时机和效果
- **代理人问题**：当POV角色无法直接推动剧情时（如灵魂旁观、昏迷旁观），需依赖"活人代理人"来执行行动。代理人的出场时机和行动力直接影响剧情可信度

### 对话手法

| 指标 | 计算方式 | 说明 |
|------|----------|------|
| 对话占比 | 对话字数 / 全文字数 | 描述该文本，并与同题材、同平台样本对照；不作通用合格线 |
| 潜台词率 | 含潜台词对话条数 / 总对话条数 | 描述人物回避与信息控制；直说在告知、求救、立规矩等场景也可成立，不把越高当越好 |
| 审判式对话 | 主角提问→对方自曝的数量 | 记录提问是否迫使选择、暴露矛盾或改变关系，不设最低处数 |
| 信息差对话 | 读者知道但角色不知道的对话 | 虐文/反转文核心 |

**对话模式识别**：
- 审判式：主角提问 → 对方被迫自爆
- 压制式：台词短促强硬、句句紧逼 → 对方歇斯底里。对白越界常按「陈述事实 → 加建议 → 指责 → 指责加命令 → 指责并贬低对方抬高自己」逐级升高；礼貌、沉默或克制也可能形成强压迫，结合现场权力判断
- 信息差式：双方信息不对称，读者在中间
- 推拉式：靠近又推开，反复循环
- 称呼变化追踪：不同角色对同一人用不同称呼（如早年叫小名、决裂后改叫全名或职务称呼），称呼的变化反映了关系和身份认同的变化。分析时追踪称呼变化轨迹，标注转变的触发事件

### 时间操控

| 手法 | 定义 | 识别特征 |
|------|------|----------|
| 时间跳跃 | 跳过一段时间 | 「三年后」「五年后」 |
| 场景压缩 | 用几句话概括长时间 | 概述性段落 |
| 平行剪辑 | 两条时间线交替 | A线/B线交替出现 |
| 倒叙 | 先说结果再说过程 | 结果先行，回溯原因 |
| 闪回 | 穿插回忆片段 | 突然插入过去场景 |
| 实时展开 | 逐秒展开关键时刻 | 关键场景慢动作 |

### 信息控制

按开头、反转前、反转后（或中段、结尾）逐时刻对比读者、主角、对手各知道什么及信息差，表见输出模板「信息控制」。

### 意象/物件追踪

表见输出模板「意象/物件追踪」。**主题意象群**：当多个物件/意象都指向同一个主题时，不应单独分析每个物件，而应识别它们的关联。如断弦旧琴（被夺走的署名）+地下隔音室（替人代弹的处境）+止痛药瓶（长期透支的手伤）都指向"被冒名榨干的才华"这个主题。分析时标注：共同主题、各物件的角度、整体效果。

### 留白手法

识别文本刻意留白的内容：
- 省略的背景（留给读者想象）
- 未说出口的话（对话中的停顿/省略号）
- 跳过的过程（直接给结果）
- 留白的结尾（不交代后续）

## 人物提取规则

### 提取标准（短篇特化）

提取所有有名有姓或有叙事功能的人物。

**必须提取**：
- 有名字（≥2字符）且有台词或推动剧情的人物
- 虽无明确名字但反复出现（≥2节）且承担叙事功能的人物

**不提取**：
- 群体称呼（"旁人""大家"）
- 无名路人（"一个中年人""助理"——除非有关键台词）
- 通用称呼泛称（如大哥、掌柜、老师、小伙子等亲属、社交、身份或年龄泛称，除非原文固定用它指代某一个承担叙事功能的角色）

### 人物内在矛盾提取

短篇人物的核心在于内在矛盾，不是外部遭遇：

| 错误 | 正确 |
|------|------|
| 她被丈夫抛弃了（外部遭遇） | 她渴望被爱但学会了在不爱中生存（内在矛盾） |
| 他对她不好（行为描述） | 他习惯了掌控一切却无法掌控自己的感情（内在矛盾） |

### 人物功能评估

结合各人物对情节、关系、氛围和读者理解的作用评估：

| 指标 | 问题 |
|------|------|
| 出场效率 | 第一次出场就完成定位了吗？ |
| 功能密度 | 承担了多少叙事功能？ |
| 可删除性 | 删除后，因果、情绪或关系理解会损失什么？主线仍成立不等于人物多余 |
| 对话贡献 | 每次对话都推动剧情或情绪吗？ |

## 共鸣分析

### 共鸣层次（7 层）

| 层次 | 定义 | 分析要点 |
|------|------|----------|
| 情感共鸣 | 读者对角色当下情绪的即时共情（如心疼、愤怒） | 共情点在哪里 |
| 价值观共鸣 | 对故事传达的具体价值观的认同（如"女性不该被定义"） | 传达了什么价值观 |
| 经历共鸣 | 与读者自身经历的相似性 | 哪些经历容易产生代入 |
| 社会现象共鸣 | 与社会热点/普遍现象的关联 | 映射了什么社会现象 |
| 普世价值共鸣 | 对人类共同追求的宏观认同（如自由、尊严、爱） | 触及了什么普世主题 |
| 情感深度共鸣 | 情绪体验留下的持久影响（读完几天后还在想） | 情绪是否深入持久 |
| 人物深度共鸣 | 对人物复杂性的理解和认同 | 人物是否有深度 |

每层共鸣标注强度：强 / 中 / 弱 / 无，并附触发证据。至少分析 3 层；没有读者反馈时，强度是分析判断，不能据此断言实际传播效果。

> **易混淆区分**：情感共鸣（与角色当下情绪的即时共情）vs 情感深度共鸣（读完几天后还在想的持久影响）；价值观共鸣（对故事传达的具体价值观的认同）vs 普世价值共鸣（对自由、尊严、爱等人类共同追求的宏观认同）。

### 爆点性分析

评估故事的爆点（容易引发传播/讨论的关键点）：
- 核心爆点是什么？
- 爆点的铺垫是否充分？
- 爆点的释放是否到位？
- 爆点是否具有传播性？

### 话题性分析

评估故事的话题性：
- 读者读完会讨论什么？
- 是否有争议点？
- 是否有代入式的自省？
- 是否有"如果是我会怎样"的讨论空间？

## 节奏分析

### 节奏指标

| 维度 | 计算方式 | 对照方式 | 说明 |
|------|----------|----------|------|
| 事件密度 | 节点数 / 全文字数 × 1000 | 同题材、同平台样本及本文前后分布 | 结合节点是否真实改变状态判断，不用数量直接判水或赶 |
| 对话密度 | 对话字数 / 全文字数 × 100% | 同题材、同平台样本 | 只描述文本倾向；对白功能与无对白场景的推进方式另行判断 |
| 冲突密度 | 冲突节点数 / 总节点数 × 100% | 同题材、同平台样本及本文压力来源 | 任务、证据、等待、空间和关系压力须另行记录，不用直接冲突占比代替张力判断 |
| 信息密度 | 信息节点数 / 总节点数 × 100% | 本文读者判断的变化与后果篇幅 | 判断新信息是否可理解、会改写判断并得到消化，不设通用比例 |

### 节奏异常检测

| 异常模式 | 文本信号 | 复核问题 |
|----------|----------|----------|
| 节奏塌陷 | 连续叙事单元没有状态变化、因果后果或读者判断的更新 | 场景是在蓄力、完成任务，还是原地复述？ |
| 压力过载 | 多次升级之间没有选择、损失、反应或后果 | 读者是否来得及理解每次升级改变了什么？ |
| 信息洪峰 | 新事实连续出现，却没有查证、定位、行动或旧线索改义 | 哪些信息真正改变判断，哪些只是清单？ |
| 对白失效 | 对话可整段删除，或只剩问答、复述和设定讲解 | 每轮是否改变信息、策略、权力、关系或行动？ |
| 对白挤压场景 | 人物只说不做，空间、任务和后果消失 | 是否需要动作或留白承接，而不是按占比截断？ |
| 反转过载 | 新反转在上一层尚未产生选择或后果时就将其抹掉 | 每层是否有证据、读者判断的变化和可感后果？ |

### A. 反转分析

> 是否有在故事时间线之前就已存在的谎言/误判？
