# 源文短板与毒点

> 只有综合评估需要判断源文优缺点时才读本文件，重点核查网短篇的开局速度、虐爽节奏、竖屏可读性、对白、证据链与清算力度。只评源文，每条附位置与证据，结论写进拆文报告「源文短板」。

## 虐爽与反击节奏

对承诺虐爽/打脸/反杀的源文，核查是否 40% 起持续兑现（纯甜宠、轻喜或纯悬疑按本流派节奏判）：

```
理想分布：冷开炸弹 → 压1 → 压2（卡点亮反击信号） → 爽1 → 反扑 → 爽2 → 总清算
禁忌分布：压1 → 压2 → 压3 → 压4 → 末尾匆匆收场（前 75% 无反制，读者流失）
禁忌分布：开篇 500 字慢热铺背景/纯景物（滑走率极高）
```

分析规则：
- 标出每节是否推进了风险、筹码、关系、打脸或认知变化，识别空转水节。
- 核查最大爽点是否由前因、暗牌与公开场汇合引爆，且 40%–85% 持续有小反制衔接。
- 核查收尾是否把反派实质代价与主角高位写足（非悬疑篇避免无力留白）。

## 竖屏网感与对白检查

| 分析项 | 记录内容 | 常见短板 |
|---|---|---|
| 竖屏段长 | 段长中位、单句成段率、>80 字砖块段占比 | 连续大段密集叙述，手机阅读喘不过气 |
| 对白驱动 | 对话占比与冲突是否放进实时交锋 | 冲突全靠旁白概括，对话占比 <20%（纯独白悬疑/死人视角除外） |
| 权力话轮 | 对话长短是否体现压制与反杀翻转 | 主角跟反派长篇讲道理对骂，失掉冷怼爽感 |
| 口语声线 | 叙述与对白是否自然带网感、口语感 | 书面公文腔、翻译腔、散文腔或高频空洞成语 |

## 主角筹码与证据链（打脸/复仇/世情）

| 分析项 | 检查标准 |
|---|---|
| 冷静与主动权 | 靠取证、断供、亮底牌或顺水推舟落地，不靠全员降智或天降神援替主角包办 |
| 证据/底牌释放 | 每次亮牌是否当场改写局势或引发围观倒戈；关键底牌前文是否有埋点或身份伏笔 |
| 反派压迫逻辑 | 恶行是否逐级升级且拉足仇恨，反应是否随筹码丧失逐级破防 |

## 网短篇高频毒点速查

毒点判断必须引用源文位置与原句，不替源文改写。

| 毒点项 | 判定标准 |
|---|---|
| 开篇慢热/纯景物 | 前 100–300 字未抛冲突或对话，拿天气环境、人物履历开场 |
| 砖块长段/书面腔 | 大段 >80 字叙述堆砌，满篇散文腔或公文汇报体 |
| 爽文不爽/圣母原谅 | 反派作践极狠，主角却心软原谅、放弃追责或两句草草清算 |
| 爽点严重滞后 | 前 70%–80% 全程受虐无暗牌无反击，高潮挤在最后几百字 |
| 付费卡点失力 | 30–40% 处平淡收尾无悬停钩子，或把全部大爽点提前放完 |
| 围观反应失真 | 公开场打脸却无见证者反应，或路人只干喊无实质立场倒戈 |
| 钩子烂尾不回收 | 埋下的底牌、倒计时或伏笔到结尾遗漏未兑现 |
| 设定/规则自相矛盾 | 脑洞/重生/悬疑规则前后打架，临时加功能强行圆场 |
| 强行拔高说教 | 结尾突然跳出人生哲理鸡汤（「人生就是这样」「终于明白真谛」） |
| 彻底清算缺失 | 虐爽/复仇/世情/男频篇未落实反派代价与主角翻身（仅悬疑允许细思极恐留白） |
