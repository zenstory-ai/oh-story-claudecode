# 篇幅分流判断规则

Phase 1「基本信息确认」按以下优先级判定导入书是长篇还是短篇（结果写入 `{书目录}/.story/work/导入记录.md` 的「篇幅」，后续时刻不再重判）：

1. **优先级 1：用户显式声明**：用户明确回答长篇或短篇时直接锁定；但若与结构/字数信号明显矛盾（如说「短篇」却检测到 20 章，或说「长篇」却无章节分隔且 < 30000 字），在 Phase 1 复述检测结果请用户拍板。
2. **优先级 2：结构信号 + 字数校验**（识别 `第X章/回/节`、`Chapter X`、`1. 标题` 等分隔符）：
   - 有明确章节分隔符且章节数 ≥ 5：总字数 ≥ 30000 初判**长篇**；总字数 < 20000 且单章均长 < 2500 字初判**短篇**（常见 8-12 节分章短篇，提示用户确认是分章短篇还是长篇开头残稿）；其余 < 30000 字情形不锁死，复述章数与总字数请用户拍板。
   - 全文无章节分隔符、单文件单篇且 < 20000 字 → **短篇**。
   - 全文无章节分隔符、单文件单篇且 20000 ≤ 总字数 < 30000 → 初判**短篇**，告知已超短篇拆解建议上界（20000 字）并请用户确认。
   - 全文无章节分隔符、单文件单篇但 ≥ 30000 字 → 结构与字数信号相反，不自动判定，复述两项信号请用户拍板。
3. **优先级 3：字数兜底**（仅在章节数 < 5 或分隔符模糊时启用）：总字数 < 30000 初判**短篇**，≥ 30000 初判**长篇**，统一在 Phase 1 确认。
