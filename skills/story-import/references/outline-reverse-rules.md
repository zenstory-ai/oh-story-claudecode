# 细纲反推规则与模板（长篇导入）

本文件是逐批反推细纲任务包的正文，由 `build_outline_brief.py` 整份放进任务包，不单独加载。

## 反推原则

- 对本批每一章，从任务包里该章的摘要要点反推 `大纲/细纲_第XXX章.md`；要点写「摘要未写」又必须写实际内容时，回看该章正文相关段落补证据，不改正文。
- 字数目标写任务包里测好的历史长度（`visible_chars_v1` 下的实际长度），不是重新决定创作目标，不自己估算。
- 「属于哪段剧情」取包里「卷纲剧情单元」中章节范围覆盖本章的那张卡：写这段剧情的名字和这章在段里做什么，不写编号；段内第几步判断不出写 `[待补充]`。
- 钩子、人物关系变化、辅线/感情线、行动成本/收益归属等无法由原文摘要稳定判断的字段统一标 `[待补充]`；只反推有证据的蓝图，不为补齐字段编造关系或副线。已写成的历史章不写「这章不能说破」；目标情绪与主角目标/关键选择不接受 `[待补充]`。

## 字段映射

| 摘要字段 | 细纲字段 | 转换方式 |
|---------|---------|---------|
| 关键事件 + 局面结果 | 核心事件 | 合并为“谁采取什么行动 → 局面如何变化”；旧摘要没有 `局面结果` 时只用 `关键事件` |
| 章节字数 | 字数目标 | 写任务包里测好的 `actual`（字数口径不用写） |
| `基调：` + 状态变化 | 目标情绪 | 结合各情节点基调（紧张/轻松/悲伤/热血/爽/甜/温馨/恐怖/压抑/其他）与状态变化，归纳为「前状态→后状态」；必须写实际内容 |
| 关键事件 + 主角行动 | 主角目标/关键选择 | 原文里主角本章要什么、做了什么判断或选择；必须写实际内容 |
| 所属剧情单元 | 属于哪段剧情 | 取章节范围包含本章的那张卡，写段名和这章在段里做什么（对照卡里的「这段怎么排」）；判断不出写 `[待补充]` |
| 上一章的章尾钩子 | 章首钩子 | 上一章结尾留下、本章开头接住的等待；本批第一章用包里给的上一章章尾钩子，第 1 章或没有证据写 `[待补充]` |
| 爽点类情节点 | 爽点 | 从情节点类型推断；本章没有爽点类情节点写「无显性爽点」 |
| 情节点起承转合 + 因果 | 这章怎么走（起因/发展/转折/高潮/结尾） | 按情节点顺序归纳，用因果链校正起因与转折；证据不足写 `[待补充]` |
| 主线/支线/任务线索 | 情节安排（主线/辅线/事件线/感情线/逻辑线） | 从剧情单元索引与摘要反推；无证据的辅线/感情线写“无”或 `[待补充]`，不得杜撰 |
| 涉及 + 状态变化 | 人物关系和出场顺序 | `涉及` 给出候选人物，`状态变化` 只写有证据的“前 → 后”；关键物件从证据或旧情节点补充，缺失写 `[待补充]` |
| 全部情节点 | 情节细化 / 情节点序列 | 按任务包中的「标题｜类型｜基调」逐点归纳并填表（# / 情节点 / 作用）；保持原顺序，未知写 `[待补充]`，不反推逐点字数配额 |
| 胜负/反转/收益损失 | 行动成本（可无）/收益归属 | 有明确证据才填写；行动成本可无、不硬造；否则 `[待补充]` |
| 章尾钩子 + 局面结果 | 结尾设定和钩子 | 结尾设定写原文落到最后的具体动作或画面；章尾钩子写本章结尾已经留下的等待，摘要没写才标 `[待补充]` |

## 细纲模板

反推版：字段名与长篇写作出细纲用的模板一一对应（字段说明、哪些字段被脚本按名读取，以长篇那份为准），只把填法换成「从摘要反推、没证据写 [待补充]」；改字段名两边一起改，细纲检查脚本两边共用。

```markdown
## 细纲（第 N 章）

### 第 N 章：{章名}
- 核心事件：{从摘要中提取}
- 字数目标：{任务包里的 actual} 字
- 属于哪段剧情：{本章所属那段剧情的名字；这章在段里做什么，判断不出写 [待补充]}
- 目标情绪：{前状态→后状态，从基调与状态变化归纳，不只写一个情绪词；必须写实际内容}
- 主角目标/关键选择：{原文里主角本章要什么、做了什么判断或选择；必须写实际内容}
- 章首钩子：{上一章结尾留下、本章开头接住的等待；第 1 章或没有证据写 [待补充]}
- 爽点：{从情节点推断；本章没有爽点类情节点写「无显性爽点」}

#### 这章怎么走
- 起因：{从情节点归纳；未知写 [待补充]}
- 发展：{从情节点归纳；未知写 [待补充]}
- 转折：{从情节点归纳；未知写 [待补充]}
- 高潮：{从情节点归纳；未知写 [待补充]}
- 结尾：{原文最后落在什么动作/画面/台词上；未知写 [待补充]}

#### 情节安排（多线）
- 主线推进：{从剧情单元索引/摘要反推}
- 辅线推进：{无证据写“无”或 [待补充]}
- 事件线 / 任务线：{外部事件链}
- 感情线 / 关系线：{有证据才写；否则“无显性”或 [待补充]}
- 逻辑线：原因 → 行动 → 结果 → 后果/新问题

#### 人物关系和出场顺序
- 出场顺序：{摘要中角色/势力/关键物件出现顺序}
- 人物关系变化：{本章前 → 本章后；未知写 [待补充]}
- 视角/信息差：{谁知道什么；读者知道什么；主角误判什么；未知写 [待补充]}

#### 情节细化
- 情节点序列（逐行填下表；从摘要情节点反推）：

| # | 情节点（谁做了什么） | 作用 |
|---|---|---|
| 1 | {} | {作用不明写 [待补充]} |
- 行动成本（可无）/收益归属：{有证据才写；行动成本可无、不硬造；未知写 [待补充]}

#### 结尾设定和钩子
- 结尾设定：{原文落到最后的具体动作或画面；未解决问题；下一章推动力；未知写 [待补充]}
- 章尾钩子：{本章结尾已经留下的等待；摘要没写写 [待补充]}
```

每章一个文件，文件名 `大纲/细纲_第XXX章.md`（三位补零，与 `正文/第XXX章_*.md` 同号）。
