# 结构迁移映射规则（长篇）

本文件定义 `拆文库/{导入书名}/` 的 story-long-analyze schema v4 如何迁移为可由 story-long-write 继续使用的长篇写作工程；外部参考作品始终使用独立 `{对标书名}`，不得混同。

核心边界：`chapter_index.csv` 只有五列机械定位；`structure_blocks.csv` 才提供块级语义候选。反推角色、细纲、追踪或世界规则时，必须按结构块/全局证据选范围，再用索引映射 locator 并回读原文。

---

## 映射总览

| 拆文库来源 | 项目目标 | 转换规则 |
|---|---|---|
| `原文/` | `正文/第XXX章_章名.md` | 切章、规范命名，不改正文内容 |
| `概要.md` | `设定/题材定位.md`、`大纲/大纲.md` | 只作基本信息和章节边界参考 |
| `章节/第1-3章_深度拆解.md` | 不直接复制到本书工程 | 黄金三章用于校验开篇承诺；外部对标才复制到 `对标/` |
| `chapter_index.csv` | 大纲、历史细纲、追踪的定位入口 | 只把章号映射到 `source_locator`；没有人物、事件、强度或钩子字段 |
| `structure_blocks.csv` | 卷纲、剧情单元、原文候选范围 | 用块级循环和三维强度选范围；不能替代章内事实 |
| `全局分析/六维拆书.md` | 角色、世界观、卷纲、题材定位、`追踪/时间线/`、`设定/关系.md` | 人物关系图谱保留有向关系与变化；双时间线区分客观事件与披露；三维节奏保留峰谷规律；其余维度提供题材与冲突 |
| `全局分析/爆款机制.md` | `设定/题材定位.md`、卷纲机制基线 | 只迁移机制与条件，不复制原书桥段 |
| `全局分析/证据与边界.md` | 所有迁移步骤的证据门禁 | A 级可写事实；B 级标注；C 级或越界项写 `[待补充]` 或排除 |

旧 schema v2/v3 目录可作为只读历史材料，但不得与 v4 混合写入同一轮新产物。

## 正文标准化规则

### 命名格式

目标：`正文/第XXX章_章名.md`。

- 章号三位补零；超过 999 章按实际位数。
- 无标题时使用 `第XXX章.md`，不得臆造标题。
- 原文内容、段落顺序和措辞保持不变；只允许统一文件边界、编码和标题行。

### 章节分隔识别

优先级：独立卷/章标题 > 源目录单章文件名 > `概要.md` 章节边界 > 稳定正则。边界不确定时停止对应章节迁移并报告，不按字数硬切。

## 角色文件迁移模板

角色候选来自 `六维拆书.md` 的人物维度与“人物关系图谱”章节；出场范围先取全局证据章节/结构块。五列索引只能把这些章号映射到原文，具体属性与当前状态必须由原文核证。

```markdown
# {角色名}

## 基本信息
- 身份：{原文可证}
- 阵营/势力：{原文可证；未知写 [待补充]}
- 首次出场：第 {N} 章（`{source_locator}`）
- 角色等级：主角 / 反派 / 核心配角 / 功能角色

## 外在表现
- 外貌/标志：{原文可证}
- 说话与行为习惯：{原文可证}

## 内在分析
- 公开目标：{原文可证}
- 深层需求：{B 级推断必须标注}
- 核心矛盾：{人物维度 + 原文证据}
- 已发生变化：{起始状态 → 导入截止章状态}

## 出场记录
| 章节 | 作用/变化 | 原文定位 | 证据等级 |
|---|---|---|---|
| 第N章 | {作用} | `{source_locator}` | A/B |

## 别名
- {别名}：{证据章节}
```

角色分级以叙事功能优先，出场比例仅作辅助。别名自动合并须有 A 级明确称谓或至少两处相互印证的 B 级证据；否则分开并标 `[待确认同一人]`。

## 关系文件转换规则

来源以 `六维拆书.md` 的“人物关系图谱”章节为主，其他人物维度为交叉验证，原文为最终证据。关系必须有方向，禁止把“甲保护乙”和“乙依赖甲”合并成无向的“关系亲密”。

```markdown
# 角色关系图

## 关系总览
| 主体 | 关系动词 | 客体 | 当前状态 | 最近变化章 | 证据等级 |
|---|---|---|---|---:|---|
| {甲} | {保护/利用/畏惧/依赖/竞争…} | {乙} | {状态} | {N} | A/B |

## 关系演变
### {甲} → {乙}
- 起点：{状态 + 证据章节}
- 转折：{变化 + 证据章节}
- 截止导入章：{当前状态}
- 未证实推断：{无则写“无”}

## 核心冲突关系
- {冲突双方}：{利益/目标冲突及当前未决问题}
```

## 世界观与势力反推

拆文库不再输出可直接复制的世界观子目录。迁移时从 `六维拆书.md` 提取候选规则，依 `证据与边界.md` 过滤，再通过索引定位原文核证：

- `设定/世界观/背景设定.md`：时代、社会结构、公开规则、主要空间。
- `设定/世界观/力量体系.md`：只有存在稳定等级/能力规则时创建。
- `设定/世界观/地理.md`：只有空间关系影响剧情时创建。
- `设定/世界观/金手指.md`：只有原文明确机制、限制和代价时创建。
- `设定/势力/{势力名}.md`：目标、资源、成员、关系和已知边界。

A 级事实可直接写入；B 级写 `推定/待核证`；C 级不进入确定性设定。不得为了凑齐目录编造力量体系或势力层级。

## 大纲反推规则

### 大纲.md（卷级结构）与卷划分

1. 原文有明确卷标题：按原文卷界。
2. 无明确卷界：结合 `structure_blocks.csv` 的状态变化/块边界，以及 `六维拆书.md` 中“双时间线与信息差”的大型时间跳跃、“三维节奏”的阶段转折和主要冲突检测候选边界。
3. 向用户展示候选章节范围、边界证据和备选方案；用户确认后才写定卷纲。
4. 禁止按固定 20-40 章机械切卷。

候选边界信号：主要场景迁移、时间跨度突变、核心目标完成或替换、关系网重组、主冲突结算、三轴同时进入新阶段。单次小高潮或普通转场不足以独立成卷。

### 卷纲反推模板

```markdown
# {卷名} 卷纲

## 核心信息
- 章节范围：第 {A}-{B} 章
- 卷功能：{建立/升级/反转/结算}
- 起始状态 → 结束状态：{原文可证}

## 核心矛盾
- 主角目标：{目标}
- 阻力：{人物/制度/资源/认知}
- 关键选择与结算归属：{原文可证}

## 情绪与节奏
| 阶段 | 章节范围 | 剧情强度 | 情绪类型/强度 | 描写密度 | 峰谷作用 |
|---|---|---:|---|---:|---|
| {RH-ID} | {范围} | 1-5 | {类型}/1-5 | 1-3 | {蓄力/爆发/冷却} |

## 已兑现机制
| 机制 ID | 本卷表现 | 读者需求 | 迁移边界 |
|---|---|---|---|
| HM-001 | {已发生事实} | {需求} | {不可照搬项} |

## 剧情单元（反推）
- 单元 ID / 范围 / 触发 → 蓄力 → 转折 → 兑现 → 冷却

## 人物弧线
- {角色}：{卷初 → 关键选择 → 卷末}

## 本卷伏笔
- 已埋 / 已回收 / 未决；每项附证据章节，不把未来计划写成已发生事实。
```

### 细纲反推

每章处理固定为：

1. 读取五列 `chapter_index.csv` 对应行，只拿到 `source_locator`、标题和机械字符数。
2. 回读该 `source_locator` 原文；所有核心事件、人物、节点、信息差、强度、钩子、五段式、多线推进、关系变化、因果链与结尾画面都从原文反推。
3. 使用 story-long-write Wordcount Core 对原文章节测量 `visible_chars_v1`，把实际值记录为历史长度目标。
4. 无法由原文确定的字段写 `[待补充]`，不从索引短句外推新事实。

索引只提供定位，结构块提供跨章候选，原文提供细纲事实。定位错误先修索引，再继续迁移。

## 角色状态反推

执行细节见 `character-state-reverse.md`。简要顺序：从全局文件识别核心角色 → 用证据章节/结构块找候选范围 → 五列索引映射 locator → 回读最近有效原文 → 生成截至最后完整章的快照。

## 伏笔与时间线提取

### 伏笔

候选来自 `六维拆书.md`“双时间线与信息差”章节的信息差与悬念，以及结构块的剩余阅读债；五列索引没有 hidden/revealed 字段。是否实际埋设、何时回收必须回读原文。

- `open`：已在正文出现，截止导入章未回收。
- `resolved`：正文已有明确结算。
- `uncertain`：只存在 B/C 级推断，不写入确定性追踪，转入 `continuity_risks`。

### 时间线

- 客观事实顺序来自 `六维拆书.md`“双时间线与信息差”章节的故事时间线，并由原文核证。
- 读者已知顺序来自叙事时间线；尚未揭示的作者事实不得进入读者视图。
- 同一事件用稳定 ID 同时记录 truth、reader_known 与 reveal_status，交给 tracking transaction 生成双视图。

## 题材定位生成

```markdown
# 题材定位

## 基本信息
- 题材类型：{概要 + 六维题材维度}
- 目标平台：{用户提供；无则 [待补充]}
- 体量与阶段：{六维题材/规模维度}

## 核心梗三分法
- 表层吸引力：{爆款机制的表层表现}
- 底层读者需求：{爆款机制的心理机制}
- 长线承诺：{六维冲突 + 双时间线未决线}

## 本书已写机制基线
| 机制 ID | 因果链 | 读者需求 | 已验证范围 | 误用风险 |
|---|---|---|---|---|
| HM-001 | {链} | {需求} | {章节范围} | {风险} |

## 本书已写节奏基线
| RH-ID | 章节范围 | 剧情强度 | 情绪类型/强度 | 描写密度 | 作用 |
|---|---|---:|---|---:|---|
| RH-001 | {范围} | 1-5 | {类型}/1-5 | 1-3 | {作用} |

## 证据边界
- A 级结论：{摘要}
- 待核证：{B/C 级结论}
- 禁止外推：{边界}

## 对标书清单（可选）
- 主对标书：{外部书名；最多 1 本}
- 对标书列表：{外部主/副/参考；不得包含导入书本身}
```

字段来源：题材和规模、时间承诺、三维节奏都取 `六维拆书.md` 的对应章节；读者需求和可迁移机制取 `爆款机制.md`；不建议模仿与证据强弱取 `证据与边界.md`。

## 对标引用视图同步规则

本节只适用于用户显式绑定的**外部对标书**。不得把正在导入的本书复制到自己的 `对标/`。

| 来源 | 目标 | 用途 |
|---|---|---|
| `拆文库/{对标书}/概要.md` | `对标/{对标书}/概要.md` | 基本信息 |
| `拆文库/{对标书}/章节/第1-3章_深度拆解.md` | `对标/{对标书}/章节/` | 黄金三章参考 |
| `拆文库/{对标书}/快速预览.md` | `对标/{对标书}/快速预览.md` | 快速浏览 |
| `拆文库/{对标书}/chapter_index.csv` | `对标/{对标书}/chapter_index.csv` | 章节定位与主对标原文选择 |
| `拆文库/{对标书}/structure_blocks.csv` | `对标/{对标书}/structure_blocks.csv` | 按剧情功能/情绪/强度选择候选范围 |
| `拆文库/{对标书}/全局分析/*.md` | `对标/{对标书}/全局分析/*.md` | 三个当前全局分析文件；旧拆分文件不复制 |
| `拆文库/{对标书}/原文/` | `对标/{对标书}/原文/` | 仅主对标按索引定位后读取；副对标不得读原文 |

登记前必须验证：三个全局文件和 `structure_blocks.csv` 非空、五列 `chapter_index.csv` 行数与章节数一致、每个 locator 位于 `原文/` 内。主产物缺失时不生成半套引用视图。

拆文阶段不再同步 `文风.md`。自定义 `设定/文风.md` 最高优先；否则 story-long-write 从主对标命中原文章节即时提炼临时风格指令。

## 质量检查清单

- [ ] 正文章数与五列 `chapter_index.csv` 数据行数一致。
- [ ] 每个索引 `source_locator` 可回读且没有越出本书 `原文/`。
- [ ] 黄金三章只保留第 1-3 章深度拆解，没有生成非黄金章详细拆解或逐章摘要。
- [ ] `structure_blocks.csv` 与三个 `全局分析/*.md` 均非空，且主要结论有原文定位。
- [ ] 角色、关系、世界观和历史细纲由原文核证，不只依赖 CSV 概述。
- [ ] B/C 级结论没有被写成无条件事实。
- [ ] 原文无明确卷界时，卷划分已由用户确认。
- [ ] `tracking_commit.py check` 通过；核心角色有独立快照，作者真相未泄露到读者已知。
- [ ] 导入书本身未登记为自身对标。
- [ ] 外部对标引用视图包含全局分析、索引、黄金三章和原文，且主/副对标读取权限符合契约。
- [ ] 未创建或依赖历史 `剧情/`、`角色/`、拆文 `设定/`、`拆文报告.md`、拆文 `文风.md`、`章节/第N章_摘要.md`。
