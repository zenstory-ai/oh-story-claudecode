# 结构迁移（长篇）

把 `拆文库/{导入书名}/` 转成长篇工程 `{导入书名}/`（书目录名须与拆文目录同名，写正文守卫据此放行）。外部对标、目标平台与作者交代取自 `{书目录}/.story/work/导入记录.md`；本时刻只建 `追踪/` 骨架，状态由 Phase 4 初始化，细纲随后分批反推。

## 迁移步骤

1. **建项目骨架**：`{导入书名}/` 下建 `设定/{世界观,角色,势力}/`、`大纲/`、`正文/`、`追踪/逐章记录/`、`参考资料/`；仅绑定外部对标时建 `对标/`。
2. **正文标准化**：原文按 `第X章/回/节`、`Chapter X`、`1. 标题` 切分，UTF-8 存为 `正文/第{三位补零}章_{章名}.md`（无章名用 `无题`），不改剧情措辞，仅清可确认的下载广告；若有作者决定「接着残章写」的末尾残稿（第 N+1 章），先暂存为 `.story/work/第{三位补零}章_残稿.md`，待 Phase 4 追踪初始化完成后在 `/story-long-write` 中补全入库。
3. **角色迁移**：`拆文库/.../角色/{名}.md` 按下方模板迁入 `设定/角色/{名}.md`。主角、反派、核心配角（有独立立场/弧线）完整迁移；单次功能角色只填标「功能角色也填」的项。
4. **关系迁移**：`角色/角色关系.md` 合并同对角色为一行转入 `设定/关系.md`（规则见下），**表面与真实不同者必须保留进「表面与真实」**防续写泄底。
5. **世界观与势力**：原样同步 `设定/世界观/*.md`（必有 `背景设定.md`）与 `设定/势力/*.md`；旧扁平设定按实际可读内容转换并标注来源，不回写拆文库。
6. **题材定位**：从拆文报告与 `剧情/{情绪模块,节奏}.md` 生成 `设定/题材定位.md`（模板见下），写入导入记录的「作者交代」，**严禁**把 `{导入书名}` 填进对标。
7. **外部对标（仅绑定外部 `{对标书名}` 时）**：按下方「外部对标接入」追加对标登记并同步 `对标/{对标书名}/`；未绑定跳过。
8. **本书文风**：若无 `设定/文风.md` 而 `拆文库/{导入书名}/文风.md` 存在，问作者要不要存成本书文风；同意则复制并首行注 `> 来源：导入时从本书已写章节整理（拆文库/{导入书名}/文风.md）`，不复制进 `对标/`。
9. **大纲与卷纲（作者确认点）**：原文有卷界直用；无卷界时依新地图/新阵营/大时间跳跃/阶段目标完成生成候选卷划分，**等作者确认**后才写定 `大纲/大纲.md` 与 `大纲/卷纲_第X卷.md`（`散落情节.md` 并入相关卷纲或附录），确认结果写回导入记录。每份卷纲须跑 `node {story-import skill 根}/scripts/outline_view.js --check --strict {书目录}/大纲/卷纲_第X卷.md` 归零通过。
10. **交接细纲**：文末清单通过后勾「结构迁移」，按 [outline-reverse.md](outline-reverse.md) 逐批反推细纲，建议新开对话说「继续导入」。

> 旧拆文缺 `剧情/节奏.md` 或 `剧情/情绪模块.md` 时，对应摘要写「未知/待增强」照常迁移；若需新对标召回再回 `story-long-analyze` 按需增强。
