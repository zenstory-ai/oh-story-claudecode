# 结构迁移（长篇）

把 `拆文库/{导入书名}/` 转成 `{导入书名}/`（书目录须与拆文目录同名，写正文守卫据此放行）。外部对标、目标平台与作者交代取自 `{书目录}/.story/work/导入记录.md`；`追踪/` 留待 Phase 4 由脚本初始化，细纲随后分批反推。

## 迁移步骤

1. **建骨架**：`{导入书名}/` 下建 `设定/{世界观,角色,势力}/`、`大纲/`、`正文/`、`参考资料/`；仅绑定外部对标时建 `对标/`（勿提前空建 `追踪/` 子目录，以免 `tracking_commit.js init` 误归档）。
2. **正文标准化**：按 `第X章/回/节`、`Chapter X`、`1. 标题` 切分，UTF-8 存为 `正文/第{三位补零}章_{章名}.md`（无章名用 `无题`），不改剧情措辞；**剥离章首/章尾可确认的 `【作者有话说】`、`作者说：`、`PS：求票/求书架` 块与下载广告**，将 `<br>` 规范为单换行 `\n`；若末章有明显人名同音笔误（如厉/历混写），原文不改，记入 `作者已定` 与 `long_term_constraints` 防续写沿错。末尾残稿（第 N+1 章，作者决定接着写）暂存 `.story/work/第{三位补零}章_残稿.md`，Phase 4 后进 `/story-long-write` 补全。
3. **角色迁移**：`拆文库/.../角色/{名}.md` 按下方模板迁入 `设定/角色/{名}.md`；单次功能角色只填标「功能角色也填」的项。
4. **关系迁移**：`角色/角色关系.md` 同对角色合并转入 `设定/关系.md`，**表里不一关系必入「表面与真实」**防续写泄底。
5. **世界观与势力**：同步 `设定/世界观/*.md`（必有 `背景设定.md`）与 `设定/势力/*.md`；旧扁平设定按可读内容转换并标来源，不回写拆文库。
6. **题材定位**：从拆文报告与 `剧情/{情绪模块,节奏}.md` 生成 `设定/题材定位.md`（写进「作者已定」，必含 `书名` 与 `## 对标登记`），**严禁**把 `{导入书名}` 填进对标。
7. **外部对标（仅绑定外部 `{对标书名}` 时）**：按文末「外部对标接入」替换对标登记并同步 `对标/{对标书名}/`；未绑定保留 `- 主对标书：无`。
8. **本书文风**：无 `设定/文风.md` 且 `拆文库/{导入书名}/文风.md` 存在时，问作者要不要存成本书文风；同意则复制并首行注 `> 来源：导入时从本书已写章节整理（拆文库/{导入书名}/文风.md）`，不入 `对标/`。
9. **大纲与卷纲（作者确认点）**：原文有卷界直用；无卷界依新地图/阵营/时间跳跃/阶段完成生成候选卷划分，**等作者确认**后写定 `大纲/大纲.md` 与 `大纲/卷纲_第X卷.md`（并入 `散落情节.md`），写回导入记录。每卷必过 `node {story-import skill 根}/scripts/outline_view.js --check --strict {书目录}/大纲/卷纲_第X卷.md`。
10. **交接细纲**：文末清单通过后勾「结构迁移」，按 [outline-reverse.md](outline-reverse.md) 逐批反推细纲。

> 旧拆文缺 `剧情/节奏.md` 或 `剧情/情绪模块.md` 时对应项写「未知/待增强」照常迁移。
