# 结构迁移（短篇）

按本文件把 `拆文库/{导入书名}/` 迁成 `{导入书名}/`。书目录名与拆文目录名相同，写正文守卫据此放行正文迁移。

外部对标、目标平台、完本与否和作者交代取自导入记录。`设定.md` 和 `小节大纲.md` 按短篇写作的白话模板写，续写时直接过它的构思检查；原文证据不够、要等构思时定的项写 `[待补充]`，汇报时列给作者。

## 迁移步骤

目标工程只有 `{导入书名}/设定.md`、`小节大纲.md`、`正文.md` 三个单文件，外加可选的 `对标/{对标书名}/`（仅外部对标引用视图）。正文是单文件、不切章，**不产** `追踪/`、`大纲/`、`正文/` 等长篇目录，迁移时严禁误建。

1. **正文迁移**：把 `拆文库/{导入书名}/原文/` 的全文迁成单文件 `{导入书名}/正文.md`，只按下方「正文.md 外壳整理」改格式。原文是作者的成稿，分段、引号、措辞一律不改。
2. **设定生成**：从 `拆文报告.md`（故事核/题材/人物分析/情感曲线/反转分析/爆点分析）、`写作手法.md`（量化网感体检表与语感切片）、`情节节点.md` 反推 `{导入书名}/设定.md`，按下方「设定.md 模板」写；不继承报告中可能存在的自对标登记。
3. **小节大纲生成**：以 `拆文报告.md`「结构划分」确定各段功能，再从 `情节节点.md` 按每节 2–3 个微节拍提取事件，反推 `{导入书名}/小节大纲.md`，填法见下方「小节大纲.md 反推规则」。
4. **外部对标引用视图（可选）**：仅当导入记录已显式绑定外部 `{对标书名}` 时，按下方「外部对标引用视图」同步；没有绑定则跳过。不得把 `拆文库/{导入书名}/` 整体复制进 `对标/`。

迁完按文末质量检查清单自检，在导入记录勾「结构迁移」，直接进入 Phase 5 汇报。

|---------|------------|---------|

## 设定.md 模板

小节和字段名与短篇写作构思时的 `设定.md` 一致，续写构思只补缺项、不重写。目标平台优先采用导入记录；反转类型沿用拆文结果，无反转时不补造反转。不套默认三次象征物件或四行文学情绪表，直写读者最在意的卖点、卡点与清算落点。

```markdown
## 短篇核心框架

### 基本信息
- 标题（暂定）：{导入书名}
- 目标字数：{完本：各节字数之和；半成品：作者定的全篇字数，没定写 [待补充]} 字
- 目标平台：{导入记录里的平台，知乎盐言 / 番茄 / 七猫 / 黑岩 / 点众·小程序 / 未定 选一}
- 平台基调：{原文实际用的小节标记、引号、段长与对话习惯，原样记下，续写沿用；视角、节尾卡点与收尾方式从原文归纳}
- 目标情绪：{从拆文报告「情感曲线」「爆点分析」提取读者读完的核心爽/虐/笑/悬念感}

### 一句话梗概
{开局爆点 + 核心拉扯 + 付费钩子 + 最终清算（从拆文报告「故事核」提取）}

### 导语草稿
{摘录原文导语（约 150–300 字冷开场）；原文没有独立导语时写 [待补充]}

### 这篇靠什么撑住
- 类型：{沿用拆文结果：身份/视角/动机/时间线/信息/认知反转，或无反转}
- 情绪走势：{一句白话写全篇怎么走，如「先压到卡点，40% 起连环反杀到彻底清算」}
- 最终清算或兑现：{反派实质下场与主角高位落点；半成品未写到写 [待补充]}
- 前面怎么埋：{从拆文报告「反转分析」和情节节点回查，有几条写几条}

### 人设速写
- {主角}：{一句话身份反差标签}；说话方式：{从对白归纳}；禁忌：{原文能看出的，没有写 [待补充]}
- {反派/关键配角}：{拉仇恨或共情标签}；说话方式：{代表话术}；下场/功能：{如写到实填，未写到写 [待补充]}
- 关系：{人物间的核心压迫与反转关系}

### 这篇用的套路
- {原文已经在用的套路：落在哪几节；续写构思时按流派包核对，补到 2-3 条}

### 文风约定
- {从写作手法.md「量化网感体检表」摘录原文中位段长、单句成段率、对话占比、人称、标点与口语习惯；没有写「无」}

### 作者已定
- {导入记录「作者交代」里的偏好、红线、残稿决定，一条一行；没有写「无」}

### 语感参考切片（可选）
- {仅当绑定外部对标时，从对标 写作手法.md 摘录 2–3 段 150–250 字原文切片（注：只学断段节奏与口语感，不抄人名情节）；无外部对标写「无」}

### 反转与揭露（有反转时）
- 揭露方式：{偷听撞破/证物当众亮牌/证人/剥洋葱，原文怎么揭的；还没写到写 [待补充]}
- 关键线索：第 {X} 节 {线索或误导}（原文有几条写几条）

## 已写部分的写法
- 已写到：第 {N} 节，{完本 | 半成品}
- 故事结构：{从拆文报告「结构划分」概述已写各段功能}
- 节奏与网感：{首冲突字位、对话密度、情绪峰值在第几节}

## 构思要点
- 题材：[待补充]
- 反派：没有（{原因}）
- 反转类型：{身份/视角/动机/时间线/信息/认知/无反转}
- 反转在：第 {X} 节（共 {Y} 节）
- 付费点：第 {N} 节末
```

- 「题材」导入一律写 `[待补充]`：流派包由续写构思时选，原文已用的套路先记在「这篇用的套路」。
- 有反派时按拆文报告「人物分析」把「反派：没有」换成身份、动机、作恶方式、致命弱点、报应五行（一字段一行）；原文证据不够的字段写 `[待补充]`。
- 无反转篇写 `反转类型：无反转` 和 `反转在：不适用（{报应兑现/甜度递进等原因}）`。有反转但半成品还没写到，写 `反转在：[待补充]`。
- 付费点能从原文认出来（常见全文 30%–40% 处的节末）时写节号，并在小节大纲同一节的「节尾停在哪」标「付费点」；认不出写 `付费点：[待补充]`。
- 绑定了外部对标时，在「作者已定」之后加一节 `### 参考的书（有对标时）`，表头 `| 书名 | 主要参考 / 顺带参考 | 同题材 / 不同题材 | 能学的写法 |`。
- 证据不够的字段写 `[待补充]`，不留空、不留 `{}`。

## 小节大纲.md 反推规则

以拆文报告「结构划分」为依据，结合情节节点和原文分节映射到各小节；行数等于原文小节数，一节一行；半成品只写已写的节，剩下的节由续写构思排。

### 段级映射

| 短篇段名 | 对应网短篇功能段 | 说明 |
|---------|----------------|------|
| 开局入局 | 导语冷开场 + 第 1 节入局 | 第 1 节常偏长，迅速抛核心矛盾与赌注 |
| 免费升级 | 免费建压（约 15%–30%） | 反派步步加码，主角暗埋后手或情绪推至临界 |
| 付费卡点 | 30%–40% 付费强卡点 | 停在未完成动作、底牌将亮或决定反杀瞬间 |
| 连环反击 | 40%–85% 连环反击/反转 | 持续打脸、亮证据、身份翻转或爽点递进 |
| 清算收尾 | 85%–100% 明账清算收尾 | 反派实质下场写足，主角高位落定或火葬场收口 |

### 小节大纲表格

用短篇写作的五列表格，列名和顺序不改；`这节发生的事` 按每节 **2–3 个具体微节拍（`A → B → C`）** 写清推进，避免笼统概括：

```markdown
| 在全篇哪一段 | 这节发生的事 | 情绪 | 节尾停在哪 | 目标字数 |
|---|---|---|---|---|
| 开局入局 | 节拍A（抛冲突）→ 节拍B（反派施压/对话交锋）→ 节拍C（暗牌或心死） | 前状态→后状态 | 原文这节停在哪（含付费点标记） | 按原文该节实际字数 |
```

- `在全篇哪一段` 填 开局入局/免费升级/付费卡点/连环反击/清算收尾。
- `这节发生的事` 按原文实际发生的微节拍写，不为凑数拆分；判断不出的格子写 `[待补充]`，不写 `{}` 占位。
- `目标字数` 写原文该节的字数（阿拉伯数字）；完本时各节之和就是 `设定.md` 的目标字数。

## 正文.md 外壳整理

导入的是作者自己的成稿，只整理下表所列格式，供后续交付检查识别小节：

| 项 | 怎么处理 |
|----|---------|
| 小节标记 | 原文已用 `###1.`、`###第N章` 或 `1.` 之一，原样保留；用别的分节写法（如「一、」「（1）」「* * *」）时，全文换成目标平台的标记：知乎盐言 `1.`，番茄、七猫 `###第N章`，其余 `###1.`；原文没有分节时按转场补标记 |
| 段间空行 | 相邻段落之间只留一个换行，删掉空行；段落边界不动 |
| 缩进 | 去掉段首的全角/半角空格 |
| Markdown | 去掉正文里的 `**`、`*`、`---` 等标记（小节标记除外） |
| 分段、引号、标点、措辞 | 原样保留，不合并、不拆分、不统一引号 |

原文用的标记、引号和分段习惯记进 `设定.md`「平台基调」，续写照这个写。

## 外部对标引用视图（可选）

仅当用户显式绑定独立外部 `{对标书名}` 时，将 `拆文库/{对标书名}/` 复制为 `{导入书名}/对标/{对标书名}/`（跳过 `_archive_*/`，归档快照不进对标视图），供续写阶段加载：

```
{导入书名}/对标/{对标书名}/
├── 原文/
├── 拆文报告.md
├── 情节节点.md
├── 写作手法.md
└── _meta.json
```

此视图为可选项，没有外部对标时不创建。复制前必须确认来源是 `拆文库/{对标书名}/`，不得使用 `拆文库/{导入书名}/` 或本篇 `设定.md` 填充。

## 质量检查清单

迁移完成后执行（不念给作者，没通过先修）：

- [ ] `正文.md` 单文件存在；小节标记是 `###1.`、`###第N章`、`1.` 之一且全文统一；段间没有空行；分段和引号与原文一致
- [ ] `设定.md` 含上方模板全部小节；`[待补充]` 只出现在证据不够或要等构思时定的项，没有 `{}` 占位
- [ ] `小节大纲.md` 数据行数与 `正文.md` 的小节数一致，每行含 2–3 个微节拍；完本时各节目标字数之和等于设定的目标字数
- [ ] 未误建 `追踪/`、`大纲/`、`正文/` 等长篇专属目录
- [ ] `拆文库/{导入书名}/` 未被复制到本篇 `对标/`；若绑定外部对标，来源与 `对标/{对标书名}/` 目录名一致
