# 结构迁移（短篇）

按本文件把 `拆文库/{导入书名}/` 迁成 `{导入书名}/`。书目录名与拆文目录名相同，写正文守卫据此放行正文迁移。

外部对标、目标平台、完本与否和作者交代取自导入记录。`设定.md` 和 `小节大纲.md` 按短篇写作的构思模板写，续写时直接过它的构思检查；原文证据不够、要等构思时定的项写 `[待补充]`，汇报时列给作者。

## 迁移步骤

目标工程只有 `{导入书名}/设定.md`、`小节大纲.md`、`正文.md` 三个单文件，外加可选的 `对标/{对标书名}/`（仅外部对标引用视图）。正文是单文件、不切章，**不产** `追踪/`、`大纲/`、`正文/` 等长篇目录，迁移时严禁误建。

1. **正文迁移**：把 `拆文库/{导入书名}/原文/` 的全文迁成单文件 `{导入书名}/正文.md`，只按下方「正文.md 外壳整理」改格式。原文是作者的成稿，分段、引号、措辞一律不改。
2. **设定生成**：从 `拆文报告.md`（故事核/题材/人物/情感曲线/反转）、`写作手法.md`、`情节节点.md` 反推 `{导入书名}/设定.md`，按下方「设定.md 模板」写；不继承报告中可能存在的自对标登记。
3. **小节大纲生成**：以 `拆文报告.md`「结构划分」确定各段功能，再从 `情节节点.md` 提取事件，反推 `{导入书名}/小节大纲.md`，填法见下方「小节大纲.md 反推规则」。
4. **外部对标引用视图（可选）**：仅当导入记录已显式绑定外部 `{对标书名}` 时，按下方「外部对标引用视图」同步；没有绑定则跳过。不得把 `拆文库/{导入书名}/` 整体复制进 `对标/`。

迁完按文末质量检查清单自检，在导入记录勾「结构迁移」，直接进入 Phase 5 汇报。

## 映射总览

| 拆书产物 | 短篇工程文件 | 转换方式 |
|---------|------------|---------|
| 原文全文（`拆文库/{导入书名}/原文/`） | `{导入书名}/正文.md` | 单文件迁移，只整理格式 |
| `拆文报告.md`「故事核」「题材」「人物分析」「情感曲线」「反转分析」 | `{导入书名}/设定.md` | 反推本书核心框架；不继承报告中可能存在的自对标登记 |
| `拆文报告.md`「结构划分」 + `情节节点.md` | `{导入书名}/小节大纲.md` | 按结构功能组织事件，无法确认的格子写 `[待补充]` |
| `写作手法.md` | `{导入书名}/设定.md`「文风约定」「已写部分的写法」 | 记下原文已经在用的写法 |
| `拆文库/{对标书名}/` | `{导入书名}/对标/{对标书名}/` | 可选：仅同步用户显式绑定的外部参考作品 |

## 设定.md 模板

小节和字段名与短篇写作构思时的 `设定.md` 一致，续写构思只补缺项、不重写。目标平台优先采用导入记录；反转类型沿用拆文结果，无反转时不补造反转。情绪取自拆文报告「情感曲线」，每处只写读者此时什么感觉，不照抄曲线的分值。

```markdown
## 短篇核心框架

### 基本信息
- 标题（暂定）：{导入书名}
- 目标字数：{完本：各节字数之和；半成品：作者定的全篇字数，没定写 [待补充]} 字
- 目标平台：{导入记录里的平台，知乎盐言 / 番茄 / 七猫 / 黑岩 / 小程序 / 未定 选一}
- 平台基调：{原文实际用的小节标记、引号和分段习惯，原样记下，续写沿用；视角、节尾钩子、结局质感从原文归纳}
- 目标情绪：{从拆文报告「情感曲线」「爆点分析」提取读者读完的感受}

### 一句话梗概
{主角 + 困境 + 反转 + 情绪落点（从拆文报告「故事核」提取）}

### 这篇靠什么撑住
- 类型：{沿用拆文结果：身份/视角/动机/时间线/信息/认知反转，或无反转}
- 最后兑现什么：{一句话写主揭示；无反转时写报应或关系兑现}
- 前面怎么埋：{从拆文报告「反转分析」和情节节点回查，有几个写几个}

### 情绪设计
- 整体走向：{从情感曲线归纳读者的感觉怎么走}
- 开头：{情感曲线第一个节点，读者此时什么感觉}
- 中段：{中段情感节点}
- 反转处：{反转节的情感峰值}
- 结尾：{结尾节情感；半成品还没写到写 [待补充]}

### 人设速写
- {角色}：{一句话人设}；说话方式：{从对白归纳}；口头禅：{原文原句，没有写「无」}；禁忌：{原文能看出的，没有写 [待补充]}（每人一行）
- 关系：{他们之间的关系}

### 这篇用的套路
- {原文已经在用的套路：落在哪几节；续写构思时按题材包核对，补到 2-3 条}

### 文风约定
- {原文明显的句子、标点、用词习惯，从写作手法.md 提取；没有写「无」}

### 作者已定
- {导入记录「作者交代」里的偏好、红线、残稿决定，一条一行；没有写「无」}

### 反转与揭露
- 揭露方式：{证物/证人/偷听撞见/一层层揭开，原文怎么揭的；还没写到写 [待补充]}
- 真线索：第 {X} 节 {线索}；假线索：第 {X} 节 {误导}（原文有几条写几条）

## 已写部分的写法
- 已写到：第 {N} 节，{完本 | 半成品}
- 故事结构：{从拆文报告「结构划分」概述各段功能}
- 情绪节奏：{情绪走势与峰值在第几节}

## 构思要点
- 题材：[待补充]
- 反派：没有（{原因}）
- 反转类型：{身份/视角/动机/时间线/信息/认知/无反转}
- 反转在：第 {X} 节（共 {Y} 节）
- 付费点：第 {N} 节末
```

- 「题材」导入一律写 `[待补充]`：题材包由续写构思时选，原文已用的套路先记在「这篇用的套路」。
- 有反派时按拆文报告「人物分析」把「反派：没有」换成身份、动机、作恶方式、致命弱点、报应五行（一字段一行）；原文证据不够的字段写 `[待补充]`。
- 无反转篇写 `反转类型：无反转` 和 `反转在：不适用（{报应兑现/甜度递进等原因}）`。有反转但半成品还没写到，写 `反转在：[待补充]`。
- 付费点能从原文认出来（知乎盐言多在全文三到四成处的节末）时写节号，并在小节大纲同一节的「节尾停在哪」标「付费点」；认不出写 `付费点：[待补充]`。
- 绑定了外部对标时，在「作者已定」之后加一节 `### 参考的书（有对标时）`，表头 `| 书名 | 主要参考 / 顺带参考 | 同题材 / 不同题材 | 能学的写法 |`。
- 证据不够的字段写 `[待补充]`，不留空、不留 `{}`。

## 小节大纲.md 反推规则

以拆文报告「结构划分」为依据，结合情节节点和原文分节映射到各小节；结构段可包含多个小节，不与自然段混同。行数等于原文小节数，一节一行；半成品只写已写的节，剩下的节由续写构思排。

### 段级映射

| 短篇段名 | 对应情节节点功能段 | 说明 |
|---------|----------------|------|
| 开头段 | 开端（引入主角/世界/困境） | 通常 1-2 个小节 |
| 铺垫段 | 发展前期（冲突积累/伏笔布置） | 通常 2-4 个小节 |
| 升级段 | 发展后期（冲突升级/误解加深） | 通常 2-3 个小节 |
| 反转段 | 高潮（核心反转引爆） | 通常 1-2 个小节，情绪峰值 |
| 结尾段 | 结局（收束/情绪落点） | 通常 1-2 个小节 |

### 小节大纲表格

用短篇写作的五列表格，列名和顺序不改：

```markdown
| 在全篇哪一段 | 这节发生的事 | 情绪 | 节尾停在哪 | 目标字数 |
|---|---|---|---|---|
| 开头 | 一句话写原文这节实际发生了什么 | 前状态→后状态 | 原文这节停在哪 | 按原文该节实际字数 |
```

- `在全篇哪一段` 填 开头/铺垫/升级/反转/结尾。
- `这节发生的事` 按原文实际发生的写，不为凑数拆分；从原文判断不出的格子写 `[待补充]`，不写 `{}` 模板占位。
- `目标字数` 写原文该节的字数（阿拉伯数字）；完本时各节之和就是 `设定.md` 的目标字数。

## 正文.md 外壳整理

导入的是作者自己的成稿，只整理下表所列格式，供后续交付检查识别小节：

| 项 | 怎么处理 |
|----|---------|
| 小节标记 | 原文已用 `###1.`、`###第N章` 或 `1.` 之一，原样保留；用别的分节写法（如「一、」「（1）」「* * *」）时，全文换成目标平台的标记：知乎盐言 `1.`，番茄、七猫 `###第N章`，其余 `###1.`；原文没有分节时按转场补标记 |
| 段间空行 | 相邻段落之间只留一个换行，删掉空行；段落边界不动 |
| 缩进 | 去掉段首的全角/半角空格 |
| Markdown | 去掉正文里的 `**`、`*`、`---` 等标记（小节标记除外） |
| 分段、引号、标点、措辞 | 原样保留，不合并、不拆分、不统一引号 |

原文用的标记、引号和分段习惯记进 `设定.md`「平台基调」，续写照这个写。

## 外部对标引用视图（可选）

仅当用户显式绑定独立外部 `{对标书名}` 时，将 `拆文库/{对标书名}/` 复制为 `{导入书名}/对标/{对标书名}/`（跳过 `_archive_*/`，归档快照不进对标视图），供续写阶段加载：

```
{导入书名}/对标/{对标书名}/
├── 原文/
├── 拆文报告.md
├── 情节节点.md
├── 写作手法.md
└── _meta.json
```

此视图为可选项，没有外部对标时不创建。复制前必须确认来源是 `拆文库/{对标书名}/`，不得使用 `拆文库/{导入书名}/` 或本篇 `设定.md` 填充。

## 质量检查清单

迁移完成后执行（不念给作者，没通过先修）：

- [ ] `正文.md` 单文件存在；小节标记是 `###1.`、`###第N章`、`1.` 之一且全文统一；段间没有空行；分段和引号与原文一致
- [ ] `设定.md` 含上方模板全部小节；`[待补充]` 只出现在证据不够或要等构思时定的项，没有 `{}` 占位
- [ ] `小节大纲.md` 数据行数与 `正文.md` 的小节数一致；完本时各节目标字数之和等于设定的目标字数
- [ ] 未误建 `追踪/`、`大纲/`、`正文/` 等长篇专属目录
- [ ] `拆文库/{导入书名}/` 未被复制到本篇 `对标/`；若绑定外部对标，来源与 `对标/{对标书名}/` 目录名一致
