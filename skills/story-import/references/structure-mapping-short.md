# 结构迁移（短篇）

把 `拆文库/{导入书名}/` 迁成单文件短篇工程 `{导入书名}/`（`设定.md`、`小节大纲.md`、`正文.md`，可选 `对标/{对标书名}/`；**严禁**建 `追踪/`、`大纲/`、`正文/` 等长篇目录）。目录名须与拆文目录同名。缺原文证据的项填 `[待补充]`，不留空、不留 `{}`。

## 迁移步骤

1. **正文迁移**：将 `拆文库/{导入书名}/原文/` 迁成单文件 `{导入书名}/正文.md`：保留原文分段、引号、标点与措辞，只整理外壳——小节标记已有 `###1.`/`###第N章`/`1.` 则保留，否则按平台换（盐言 `1.`，番茄/七猫 `###第N章`，其余 `###1.`）；删段间空行（相邻段只留一个换行）、去段首缩进与正文 Markdown 符号。
2. **设定生成**：从 `拆文报告.md`（故事核/题材/人物分析/情感曲线/反转分析/爆点分析）、`写作手法.md`（量化网感体检表与语感切片）、`情节节点.md` 反推 `设定.md`；不继承自对标登记。
3. **小节大纲生成**：按 `拆文报告.md`「结构划分」与 `情节节点.md` 反推 `小节大纲.md`，一节一行，每节写 2–3 个微节拍（`A → B → C`）；半成品只写已写节。
4. **外部对标（可选）**：仅当导入记录显式绑定独立外部 `{对标书名}` 时，将 `拆文库/{对标书名}/`（`原文/`、`拆文报告.md`、`情节节点.md`、`写作手法.md`、`_meta.json`，跳过 `_archive_*/`）复制到 `{导入书名}/对标/{对标书名}/`；严禁复制 `拆文库/{导入书名}/`。

迁完过文末清单，勾「结构迁移」，直跳 Phase 5。

## 设定.md 模板

字段名与短篇写作一致，续写构思只补缺项、不重写；不套默认三次象征物件或四行文学情绪表，直写卖点、卡点与清算落点。

```markdown
## 短篇核心框架

### 基本信息
- 标题（暂定）：{导入书名}
- 目标字数：{完本填各节之和；半成品优先填作者所定全篇字数或估算整数（如 10000），未定写 [待补充]} 字
- 目标平台：{知乎盐言 / 番茄 / 七猫 / 黑岩 / 点众 / 小程序 / 未定}
- 平台基调：{原文实际小节标记、引号、中位段长与对话习惯；视角、卡点与收尾方式}
- 目标情绪：{从拆文报告「情感曲线」「爆点分析」提炼核心爽/虐/笑/悬念感}

### 一句话梗概
{开局爆点 + 核心拉扯 + 付费钩子 + 最终清算（取自拆文报告「故事核」）}

### 导语草稿
{摘录原文冷开场导语（150–300 字）；无独立导语写 [待补充]}

### 这篇靠什么撑住
- 类型：{身份/视角/动机/时间线/信息/认知反转，或无反转}
- 情绪走势：{一句白话写全篇节奏，如「前压到卡点，40% 起连环反杀清算」}
- 最终清算或兑现：{反派实质下场与主角高位落点；未写到写 [待补充]}
- 前面怎么埋：{从拆文报告「反转分析」和情节节点回查，有几条写几条}

### 人设速写
- {主角}：{身份反差标签}；说话方式：{对白特征}；禁忌：{没有写 [待补充]}
- {反派/配角}：{拉仇恨或共情标签}；代表话术：{原话特征}；下场/功能：{未写到写 [待补充]}
- 关系：{核心压迫与反转关系}

### 这篇用的套路
- {原文已在用的套路与所在节；续写构思按流派包补到 2-3 条}

### 文风约定
- {从写作手法.md「量化网感体检表」记下原文中位段长、单句成段率、对话占比、人称与标点习惯；无则写「无」}

### 作者已定
- {导入记录「作者交代」的偏好、红线与残稿决定；没有写「无」}

### 语感参考切片（可选）
- {仅绑定外部对标时，从对标 写作手法.md 摘录 2–3 段 150–250 字原文切片（只学节奏语感，不抄人名情节）；无对标写「无」}

### 反转与揭露（有反转时）
- 揭露方式：{偷听撞破/证物亮牌/证人/剥洋葱；未写到写 [待补充]}
- 关键线索：第 {X} 节 {线索或误导}

## 已写部分的写法
- 已写到：第 {N} 节，{完本 | 半成品}
- 故事结构：{从拆文报告「结构划分」概述已写各段}
- 节奏与网感：{首冲突字位、对话占比、峰值所在节}

## 构思要点
- 题材：{优先填 _meta.json.genre_detected 对应 14 流派名；未命中写 [待补充]}
- 反派：没有（{原因}）
- 反转类型：{身份/视角/动机/时间线/信息/认知/无反转}
- 反转在：第 {X} 节（共 {Y} 节）
- 付费点：第 {N} 节末
```

- 「题材」优先按 `_meta.json.genre_detected` 预填对应 14 流派名（并在导入报告请作者核对），未命中再填 `[待补充]`；有反派时按拆文报告「人物分析」将「反派：没有」替换为身份、动机、作恶方式、致命弱点、报应五行（缺填 `[待补充]`）。
- 无反转写 `反转类型：无反转` 与 `反转在：不适用（{原因}）`；有反转未写到填 `[待补充]`。
- 付费点可识别（常见 32%–44% 节末）时写节号并在大纲对应行标「付费点」，否则写 `[待补充]`；绑定外部对标时在「作者已定」后加 `### 参考的书（有对标时）`（表头 `| 书名 | 主要参考 / 顺带参考 | 同题材 / 不同题材 | 能学的写法 |`）。

## 小节大纲.md 反推规则

五列表头列名与顺序不改；`在全篇哪一段` 填网短篇五段：**开局入局**（导语+第1节入局）、**免费升级**（15%–32%建压）、**付费卡点**（32%–44%强悬停）、**连环反击**（40%–85%按四轨推进：打脸/反转/脑洞甜宠/死人追夫蓄压爆发）、**清算收尾**（85%–100%实质代价/真回旋镖/回甘或悬疑留白）。`这节发生的事` 写 **2–3 个具体微节拍（`A → B → C`）**，`目标字数` 填原文该节阿拉伯数字字数。

```markdown
| 在全篇哪一段 | 这节发生的事 | 情绪 | 节尾停在哪 | 目标字数 |
|---|---|---|---|---|
| 开局入局 | 节拍A（抛冲突）→ 节拍B（对话交锋/施压）→ 节拍C（暗牌或心死） | 前状态→后状态 | 停在哪（含付费点标记） | 原文该节字数 |
```
