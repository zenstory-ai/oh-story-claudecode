## 第1节：主角卡

### 填空模板

```text template=主角卡
姓名：
性别：
角色定位：（一句话说清主角在故事中的功能）
身份标签：（如：废柴大学生、前特种兵、落魄皇子）
外貌特征：（3-5 个关键词，要有记忆点）
  例：瘦高、总穿旧夹克、左手有疤、眼神懒散
性格关键词：（3-5 个，必须有矛盾面）
  例：嘴毒心软、看似冷漠实则护短、冲动但有底线
核心目标：（全书终点想达成什么）
核心动机：（必须达成的理由——情感驱动，非理性驱动）
致命弱点：（让角色犯错的性格缺陷，非能力缺陷）
说话习惯/标志动作：（贴合身份的语气节奏或习惯动作；口头禅有来由才配，可选）
```

### 设计要点

- 动机落在具体情感上——"为母亲复仇"优于"要成为最强"
- 弱点会在关键情节导致犯错，否则不算弱点
- 外貌辨识点与说话口气是读者认人的锚点（口头禅不强求，忌人人硬塞）；影响剧情走向的设定（实力、钱、人脉、背景）至少 3 项，爱好只做记忆点
- 起名贴合时代、地域和文化，别用与设定冲突的现代或政治化名字；写同人或既有世界观时，原著角色沿用官方名，新角色顺原著同地域命名风格，同一地域不混语系

## 第2节：配角卡

### 填空模板

```text template=配角卡
姓名：
性别：
角色功能：（导师/盟友/情报源/牺牲品/镜像对照）
与主角关系：
核心特质：（1-2 个关键词）
标志性特征：（一句话让读者记住）
退场方式：（何时/如何退出故事）
```

### 设计要点

- 每个配角有明确功能——没功能的角色不出场
- 配角退场主动规划，不写着写着忘掉
- 常规场有重点台词的配角控制在 2-3 人；朝堂、宗门大比、家宴等群像场按地位分主次发言，其余同立场人合并反应，不平摊台词

## 第3节：反派设计

### 3.1 反派层级表

按反派要撑多长的剧情选层级：

| 层级 | 功能与篇幅 | 动机与手段 | 交锋与退场 |
|------|------------|------------|------------|
| 小反派 | 单剧情单元障碍 | 1-2 个鲜明特征（嚣张/贪财/欺软怕硬） | 被打败或揭穿，干脆利落退场 |
| 中等反派 | 一卷的主对手 | 有明确作对动机（非纯粹的坏），靠武力/权谋/资源施压 | 先压服旁人或赢主角半招立住逼格，最终被正面击败出爽感 |
| 大弧Boss | 一卷或数卷的核心矛盾 | 有独立目标、过往成因、处事逻辑及一个让读者恨不起来的侧面，与主角有理念冲突 | 至少一场让主角或己方陷入重压，有仪式感的终战与余味落幕 |
| 最终Boss | 全书核心矛盾具象化（宿命复仇线宜首卷埋草蛇灰线；换地图升级流随高阶世界自然引出） | 有信念（非纯疯子/怪物），与主角目标和故事主题直接对立 | 实力或权势远压主角，逼主角突破底牌或上限才能赢 |

### 3.2 反派建立四要素与性格确立四步法

**中大反派建立四要素**（小反派与无敌流炮灰从简）：1. **实力展示**（出场就展示实力或手段）；2. **动机可信**（从反派视角看行为说得通）；3. **真实威胁**（赢主角一局，或先挫败强力配角、拿捏关键软肋立住压迫感）；4. **终极意图时机**（真实目的留到关键反转点揭晓）。

| 性格确立步骤 | 怎么写 |
|------|------|
| 1. 立反派自己的目标 | 在反派眼里他是做正事的人，写清他要保住什么利益或秩序 |
| 2. 补一笔过往成因 | 交代他吃过什么亏、怕掉进什么处境，让狠辣有来处 |
| 3. 让依仗或性格缺陷成死穴 | 顺境靠什么压人（权势、规矩、算计），逆境就因迷信这一招或放大多疑自负而踩空 |
| 4. 与主角形成对照 | 反派精算计或守旧规，刚好撞上主角重情或破局的底线 |

### 3.3 反派分量怎么写出来

- 阻碍顺着反派职位和利益长出来（如掌管考评的人顺手卡资格），别让他干损人不利己的蠢事。
- 先让反派做成一件事（压服旁人或赢主角一局），再让主角抓他赖以压人的规矩、底牌漏洞或内部矛盾反制，不靠反派降智送赢。
- 给核心反派单列目标与筹划，不让他只在主角出场时才动。
- **先让配角试出深浅**：主角对上反派前，先写有本事的配角全力出手仍落败，立实压迫感。
- **换地图不贬旧角色**：进高级地图时，让旧前辈留下的信物、名号或招式依然管用，别靠把旧角色写成废物来抬新地图。

## 第4节：动机设计

### 4.1 动机链模板与要点

```
起因 → 角色经历了什么（如：母亲被仇家杀害）
意图 → 角色想做什么（如：找到凶手并复仇）
约束 → 什么在阻碍他（如：凶手是当朝权臣，主角只是平民）
风险 → 失败的代价是什么（如：败则被灭门，成则失去现有生活）
```

- 起因必须落到具体事件（“众目睽睽下被打耳光”而非笼统“被欺负”），从世界压迫、金手指利益、亲友遭遇三处找；约束必须有力、风险必须真实，动机随剧情演变须有铺垫。
- 外力动机外再给一个贴合身份的内在梦想（宗门圣女想救宗门可信，杂役弟子想救宗门缺说服力）。

### 4.2 动机冲突类型

| 类型 | 定义 | 示例 |
|------|------|------|
| 目标 vs 道德 | 想做的事和应该做的事冲突 | 复仇但不想伤及无辜 |
| 情感 vs 利益 | 感性和理性的拉扯 | 知道对方不可靠但放不下 |
| 短期 vs 长期 | 眼前利益和远大目标的矛盾 | 妥协保命 vs 坚持原则赌未来 |
| 自我 vs 他人 | 个人需求和他人期望的冲突 | 想过平静生活但背负家族使命 |

## 第5节：角色塑造方法速查

### 5.1 核心原则与反差设计

- **主角行为三必须**：1. **可理解**（读者明白他为什么这么做）；2. **可共鸣**（他的盘算和情绪读者能代入）；3. **可接受**（他的底线读者能接受）。
- **展示优于告知**：目的靠行动展示（不靠旁白解释），行动写具体动作和决定（不堆形容词），态度靠对话和反应体现（不靠独白说明）。
- **三层反差标签**：给每个重要角色填三层标签，至少一层与另两层相反：

| 层 | 含义 | 例 |
|----|------|-----|
| 身份 | 外界看到的身份 | 豪门弃妇 |
| 表现 | 他展现给外界的行为 | 被骂不还口，被赶不反抗 |
| 内核 | 真实的打算和性格 | 悄悄录音、收证据、提前转走财产 |

  - 反差用行为对照写出来，不靠旁白点明；内核留到关键抉择时亮出来，亮得越晚越震撼。
  - 让外表、身份、爱好、性格两两错位（看着凶实际心软、杀手擅长插花、豪门子弟住地下室）。主角和核心配角给一层强反差；功能性配角贴一两个标签即可，要保持神秘压迫感的高手可留扁平。

### 5.2 展示人物特质的方法

| 方法 | 怎么写 | 示例 |
|------|------|------|
| 碰痛处看反应 | 旁人提到痛处时，写他打岔、背身或动作骤停 | 被问脸上巴掌印，少年背过身攥紧课本说“走路摔的” |
| 写他刻意回避什么 | 写他宁可绕远路或说冷话推开好意，也绝不碰某事 | 宁可打黑拳也不让父亲低头求人，立住护短与自尊 |
| 先立闪光点再露短板 | 先写一件让人佩服或心疼的事，再露性格毛病 | 先写深夜苦练护家，再写嘴硬不肯服软 |

### 5.3 配角用法、记忆点与事件驱动

- **嘴替与以旧带新**：主角不便说的话、不便发的狠、不便吃的瘪交给忠心配角，保住主角逼格；新配角优先从已有角色的亲友、同门或宿敌关系里顺势带出，阶段功能走完及时退场。
- **支线配角执念法**：给支线配角一个执念，言行围着它转并在关键时刻亮出；执念过狠时补一处家常喜好或软肋（如满脑子复仇的刀客路过栗子摊必买一包）。
- **行为重复点**：给主角、配角和反派各留专属标志性举动，在办正事时顺手带出；若某段剧情逼角色干出违背人设的事，先改剧情，不硬掰人设。
- **人推事件 vs 事件推人**（两种推进方式交替配合）：

| 方式 | 怎么用 | 示例 |
|------|--------|------|
| 人推事件 | 让角色顺着性格去惹事、定计划 | 主角护短、贪财或记仇，主动接下烫手差事、上门讨债，把剧情拱出去 |
| 事件推人 | 让天降变故或强敌逼上门，堵死退路 | 仇家查封铺子、大限将至，逼平时藏拙或隐忍的主角亮出底线与真本事 |

## 第6节：主角特殊问题

### 6.1 主角逼格与红线

被挑衅时的反应随实力和阅历变：实力高就轻描淡写，实力不够就隐忍蓄力；气急败坏地反击、降智内心戏和无端爆粗口是毒点。以下类型的主角绝对不要写：

| 禁止 | 说明 |
|------|------|
| 圣母型主角 | 以德报怨、拿自己人的利益换好名声，读者要的是痛快；守底线、行善后有回报不算圣母 |
| 无脑战斗机器 | 难以产生情感共鸣 |
| 内核邪恶 | 读者无法代入 |
| 因蠢、圣母心或与实力不符的低级失误犯错 | 读者无法原谅；因不可抗力或信息差犯错可以 |
| 自暴自弃 | 比被欺负更让读者厌恶 |

### 6.2 主角调子起太高怎么办

**危害信号**：能力或地位过早到顶，变成机械秒杀，失去悬念。

**化解方法**：
- **用软肋或规矩束手脚（降调不降人）**——不削战力和尊严，改用亲友安危、身份保密或出手代价限制他，不能无脑平推。
- **错开短板维度**——武力无敌就卡情报、财力或名分，逼他在短板处动脑破局。
- **明面小赚、暗地大赚**——旁人以为给的是寻常赔礼，主角到手却触发独有用途，实际大赚。
- 紧张题材（极道、末世、悬疑）别给随时兜底的靠山，免得消掉危机。

### 6.3 主角开篇立人设与目标独立性

- **人设靠选择立**：开篇让主角做一次选择，读者从选择里看出他是什么人；无敌流、认知差这类开局，靠主角怎么用力量的选择立人设，不靠战力展示本身。
- **行动力从三处显**：做别人不敢做的事、做别人做不到的事、做别人没想到能这样做的事。
- 主角有不讨喜的一面（好色、贪财、记仇）要在开头亮明，后面别突然转性。
- 爽文与升级文开场立住核心人设，全书变化主要放在实力、地位、筹码和关系上，不硬套性格蜕变；追妻、复仇、虐恋等靠关系翻盘的题材，可在关键变故处写出清晰的态度决裂与立场转向。
- 主角的目标得是自己的，不能只替别人办事当工具人。就算接别人的差事也要转成自身利益，比如平叛是为了自保、拿认可或资源。

### 6.4 穿书、穿游戏的角色选择

- 主角对原世界要相当熟悉，这是最核心的期待感来源；穿进哪个世界一两句交代清楚，不能过了一章还不知道身在何处。
- 选穿越后有强戏剧性、强矛盾的身份（如恶毒女配）；在原世界基础上留信息差给主角探索，可以用原世界知识卡 bug 拿超额收益。
- **穿主角**（好代入但改剧情易受原轨迹束缚）、**穿反派**（有求生紧迫感，洗白与立场转换要给够理由）、**穿路人或新角色**（既有先知优势，又不被原书固定命运绑死）。
