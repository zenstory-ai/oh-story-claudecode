# 长篇对标发现与写前召回（benchmark-recall）

> 谁读：项目有 `对标/`、`拆文库/`，或 `build_writer_prompt.js` 报「召回降档不成立」时整份读；无对标且不需要查对标切片时不读。

---

## 一、开书对标发现（Phase 1）

1. **列候选并排除本书**：扫描项目根 `拆文库/` 与本书 `对标/`，排除与本书目录名、`.active-book` 或 `设定/题材定位.md`「书名」同名的拆文目录（导入生成的本书拆文不是对标候选，不得复制进 `对标/`）。
2. **选样标准**：优先同平台、同题材、框架清晰的中层精品（避开强品牌头部书、盲目跟风书或个人怪癖极强的书）。主对标只选 **1 本**负责文风与节奏，其余（最多 2 本）记为副对标只借局部功能位。
3. **落盘复制**：作者选定后写入 `设定/题材定位.md`「对标登记」，首次引用时将 `拆文库/{书}/` 下的 `章节/`、`角色/`、`剧情/`、`设定/`、`文风.md`、`拆文报告.md` 复制到 `{书目录}/对标/{书}/`。作者不要对标则写「主对标书：无」。

## 二、写前召回与降档规则（正文前）

- **路径优先级**：先查 `{书目录}/对标/{书名}/`，不存在回退 `拆文库/{书名}/`。
- **无对标判定**（唯一口径）：「对标登记」写了「主对标书：无」，或未登记且排除本书后无可用候选。此时跳过对标节奏/模块抽取，直接用本书 `设定/文风.md`（若无则用本书流派包内置原文切片）。
- **权威顺序**：`剧情/情绪模块.md` 管读者需求与情绪引擎，`剧情/节奏.md` 管信息推进与爆发；`文风.md` 只管句法、段长、对话与原文锚点；本书 `设定/文风.md` 高于对标文风。

### 召回降档与必传原文语感切片

- **降档成立条件**：本书有自定义文风（或无对标）、题材流派包已命中，且细纲「目标情绪」与卷纲本段「这段让读者图什么 / 这段怎么排」有效。
- **降档动作**：跳过主会话手工检索全套拆文，**但 `build_writer_prompt.js` 仍会自动注入主对标的核心写作养分**——按本章基调匹配的 1–2 段 `文风.md` 原文锚点、主对标 `不建议模仿` 与 `分层模仿建议` 避坑要点，以及 `剧情/情绪模块.md` / `剧情/节奏.md` 中最贴合本章的 1 张参考情绪卡与爽点循环（只借情绪链与功能位，严禁照抄专名、台词或桥段）！

### 全量召回（降档不成立时执行）

1. **情绪模块**：读主对标 `剧情/情绪模块.md`，选 1 张最贴合本章目标情绪的 `selected_emotion_module`（读者想看什么、情绪链、戏剧单元、可替换项、不可照搬）；缺失则停止并提示用 `/story-long-analyze` 补拆 Stage 3。
2. **节奏**：读主对标 `剧情/节奏.md`，选 1 条匹配 `rhythm_reference`（关键信息 → 扩写方式 → 推进功能 → 节奏效果）；缺失同上。
3. **流派包与文风**：流派包由 `build_writer_prompt.js` 自动匹配 `genre-styles/{流派}.md`；文风优先本书 `设定/文风.md`，否则读主对标 `文风.md`（缺则提示 `/story-long-analyze` 补拆 Stage 6，不当场现编）。
4. **匹配章节与原文切片**：从主对标 `章节/*_摘要.md` 按 `基调：` 挑最贴合的 1 章摘要，连同 `文风.md` 中 1–2 段 200–300 字「原文锚点片段」一并送入正文阶段（**只学断行、句长、口语节奏与对话推进，严禁复用专名、独特物件、台词或桥段**）。

## 三、多本对标预算（≥2 本时）

- **主对标**独占文风、原文锚点与主节奏；**副对标**（按「引用强度」辅 ＞ 参考 排序）不读其 `文风.md` 与原文，每本仅取一两条结构/情绪功能位或单章钩子灵感，简短并入「情绪与节奏召回」槽位。
- 已部署 `story-explorer` 时可按子代理派发手册一次召回 `benchmark_style_load`；遇 `missing_primary_contract` 停下补拆，遇 `benchmark_book_missing` 核对书名不私自换书。
