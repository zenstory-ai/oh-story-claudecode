# 短篇钩子：节尾、节首、段落与全文悬念

> 谁读：构思时付费点断点或节尾落点拿不准，主会话只读「2. 节尾」；story-architect 辅助构思时读副本。写正文不读，按小节大纲「节尾停在哪」执行。

> 节尾怎么停、要不要每节都下强钩子，只在「2. 节尾」定，别的文件只指到这里。其余各节在设计对应写法时按需查。示例取自七猫短篇原文，按《书名》标出处，标点照原文；写正文时标点按本篇的格式规范改写。

---

## 1. 全文悬念的承接与收束

先确定全文最终要回答的核心问题。副悬念为它提供证据、误导或情绪代价，不另开独立支线。

局部问题揭晓后，让答案改变下一步行动、关系立场或读者对核心问题的判断。延迟揭晓时，也要交付新证据、误判修正或局部反击，避免一直抬问题。

舒缓的小节可用局部兑现和明确行动承接。进入终局时回答核心问题，不用无关的新谜题延长故事。

---

## 2. 节尾：停在答案出来之前

七猫七十多篇完结短篇的非末节节尾里，约三成停在一句对白上，多是施害者的狠话、开出的条件或新人物开口；其余常见的是动作做到一半、有人到场、东西刚被打开的那一刻。很少用总结句或抒情句收住。

| 落点 | 怎么停 | 原文 |
|---|---|---|
| 动作被打断 | 关键动作做到一半，结果放到下一节 | 《妹妹成为偶像练习生后，我拦下了红旗车》眼看刀就要刺中我腹部的瞬间，房间门被打开了。 |
| 来人或来电 | 关键人物到场，或电话那头换了人 | 《回乡祭祖，老公嫌我买太多纸钱》正在我犹豫的时候，孙虎竟然给我来了电话。但是接电话的却不是他，而是派出所的民警！ |
| 证据只亮一处 | 文件、物件刚翻开，只亮最扎眼的一处 | 《恶有恶报》我往下翻，在鉴定人签名的地方，看到了一个熟悉的名字。沈妤。 |
| 狠话或条件落尾 | 对方把话说绝或开出条件，主角怎么回应留到下一节 | 《双胞胎变成一胎后，金丝雀杀疯了》她说：“把你的身体给我。”“把你的孩子，也给我。” |
| 身份将揭 | 有人问出关键问题，或说漏一句 | 《未婚妻将我丢在黄金岛抵债，可岛主是我姐》楚涵伊的脚步顿住了，语气冷了下来：“这里面关着的到底是谁？！” |
| 主角留了后手 | 读者看见主角的准备，对手还不知道 | 《白许空诺爱成沫》医生将镇定剂注射进肌肤时，我不动声色的按下录音键。 |
| 后果预告 | 叙述者提前说这一步会出事，或谁后来会后悔 | 《吃了三年地沟油油条，老板让我补齐塑料袋钱》可我不知道，就是这句话导致我们家陷入舆论的风波。 |
| 心死定格 | 一句话把主角从忍让切到决裂 | 《我从来没被爱过》少年意气终究是消散无踪。而我心里最后的一束光，也熄灭了。 |
| 异常出现 | 悬疑、民俗里不该动的东西动了 | 《我的女儿在吃掉我》就在这时，阿布的头，突然咔哒一声转向了我。 |

- 付费点所在的那一节，停在答案还没出来的落点上，如动作被打断、来人、证据只亮一处、狠话或条件。语料里标了付费点的两处都停在来人：《我谈业务被杀，未婚夫却向白月光求婚》「灵车到公司时，许江也刚好下车。」、《妹妹夜店登记被害后，我砸了唯一的证据》「他来了。」
- 非终局节尾让读者知道为什么要往下看；过渡节可以用局部兑现或明确的下一步收住，不必每节都下强钩子。
- 相邻几节换着用不同落点，同一种接连用，读者会提前猜到。
- 别用「或许」「她知道，明天会是新的开始」这类总结或抒情句收节。

## 3. 节首：接住上一节

同一批语料的节首不到一成用对白开场。另抽查 40 个非对白节首，约七成直接写上一节尾的结果或接下来那一拍，其余先用一句话交代时间或地点变化（如「没过几天」「再次听到苏嘉沫的消息，是在三年后」），再进事件。

- 第一句接住上一节留下的问题：写那一下的结果、谁的反应，或对白的回应。
  - 《回乡祭祖，老公嫌我买太多纸钱》上一节停在「我抬手，当着孙家列祖列宗的面，狠狠地给了婆婆一耳光！」，下一节开头是「这一耳光让祠堂里的声音迅速安静了下来。」
- 要跳时间或换地点，一句交代完就进事件，不用风景、天气开场，也不用不带事件的抒情独白开场；接住上一节或带出新信息的独白可以。
- 全文第一节的开头不受本条限制，按题材的开篇写法，第一句就是事件。

## 4. 段落钩子：节内的期待

节内也要让读者等着看点什么。下面几种在短篇里最常见：

| 名称 | 做法 | 原文 |
|---|---|---|
| 信息差 | 读者知道、对手不知道的事，写成一句具体事实 | 《乞丐妹妹夺我夫君，和离后我成了国公夫人》他满是微笑：“如今我已是吏部尚书。你若肯低头认错，我可再纳你为妾，允你重回裴府。”他不知道，我早成了国公夫人。 |
| 暗牌 | 主角悄悄留证据，读者等亮牌 | 《未婚妻将我的心脏换给白月光》至于周炎，看着他脸上的笑意，我便知道来者不善，默默地打开了手机录音。 |
| 假意顺从 | 主角主动让出对方想要的东西，读者知道她另有打算 | 《我毫不犹豫剖出肾给未婚妻师兄后，她疯了》我看着他们亲密的模样，心痛地闭上了眼：“好，既然你想要，那我让出来就是了。”反正答应陈伯父的两年之约快到了，我也该走了。 |
| 倒计时 | 给出到期的日子，到期必须兑现 | 《念念不相忆》这是我的催命符。熬过最后两天，我就要死了。 |
| 灵魂旁观 | 主角已死，看得见改变不了 | 《念念不相忆》我飘在空中想继续没说完的真相，声音却只能被风吹散，他什么都听不到。 |
| 异常物件 | 不该出现的东西出现在这里 | 《我的女儿在吃掉我》掰开娃娃的手掌后，里面还攥着张字条。「妈妈，为什么把我塞进填充棉里？」 |
| 弱者一句话 | 孩子或弱者一句话戳穿施害者 | 《周年纪念日时，老公拿我和女儿灌水泥》女儿像失了魂一样盯着不远处立起来的桥梁。“妈妈不是刚被你扔下去打生桩吗？” |

- 「他不知道」后面必须跟一件具体的事；只写「他不知道的是，一切才刚刚开始」没有信息，删掉。
- 信息差悬着的时候，持续给新证据、局部答案或行动后果；暗牌在能改变局势时亮。
- 倒计时一旦设下，到期必须兑现。灵魂视角只能看、不能动，全篇守住。
- 代价要真影响选择；最后躲过损失，也写清付出了什么。弱者要有影响主线的行动或选择，不只当受害道具。
- 常见组合：信息差加暗牌（读者知道主角在憋大招，复仇、世情）、倒计时加代价（选哪个都亏，悬疑、婚恋）、暗牌加打脸（复仇、逆袭）、弱者加代价（追妻、世情、死人文学）。组合里每种都要带来信息、选择或情绪变化，没用的去掉。

## 5. 伤害与围观

- **不公平的伤害最拉仇恨**：主角无辜，伤害落在身上也落在心上。「不患寡而患不均」：月例大家都减是公平，唯独主角的药材降了一等才是不公平。伤害可以是掠夺逼迫（反派不想自己吃亏）、嫁祸顶罪（反派把惩罚推给主角）、陷害算计（主角打破了反派的秩序）。
- **围观要选人**：围观者用判断说明对手多强，结果出来后改变立场。熟人震惊比陌生人有力，懂行的人能说出赢在哪里，比只会惊叫的路人有用；多种身份、多个层级各有不同反应，比一群人同声惊叹好。围观只放大结果，不替主角的行动出力。

## 6. 钩子禁忌

| 禁忌 | 说明 |
|---|---|
| 假悬念 | 威胁不存在或下一节开头立刻解除，读者被骗一次就不再信 |
| 巧合解围 | 节尾抛出危机，下一节靠巧合解决 |
| 过度留白 | 连续几节不揭示任何信息 |
| 低风险钩 | 用无关紧要的事制造悬念 |
| 机械复用 | 连续用同一种手法问同一个问题，没有新信息或局部兑现 |

---

## 7. 质量检查

- [ ] 非终局节尾停在答案出来之前（未完成动作、新信息、关系变化、局部兑现或明确下一步），读者知道为什么往下看
- [ ] 节首第一句接住上一节，不用风景、天气或空转的抒情独白开场
- [ ] 延迟的答案已有阶段收益，副悬念服务全文核心问题
- [ ] 终局兑现此前承诺，不靠新增无关困境延长故事
