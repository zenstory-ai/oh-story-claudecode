# AI 味词句信号索引

> 谁读：去味、审稿、改写时读（写手去味审查、去味与审稿 skill、短篇精修各有副本）；长篇写正文由检测器定位，拿不准某条时只查对应一节。

> 这里列的是需回到上下文判断的信号，不是出现即错的禁词。表达服从作者这次的要求与本书文风；不据词频判断作者身份，不以清零为目标。修法按调用方的流程。

## 句式与组织信号

| 信号 | 可检索形式 | 需确认的语义问题 |
|---|---|---|
| 否定翻转 | 不是 A，（而）是 B；不是 A，不是 B，（而）是 C／只是 C；没有 X，没有 Y，只有 Z | 是否先否定无人在意的靶子，再宣布结论？纠错、辩解和排除猜测也可能需要对比 |
| 工整并列 | 跨段“不是／也不是／只是”；有的……有的……；一边……一边……；至于 X 不 X，怎么 X；不 V A，不 V B | 是否重复同一意思或照抄提纲字段？排比也可承担递进与人物声线 |
| 万能状语、声线 | ，带着……／带着一丝……；声音不大，却带着……；语气毫无波澜；平静无波；声音平直／平平／听不出情绪；平静得像在念…… | 是否只贴抽象态度，没有可辨的说话内容或声音信息？ |
| 引号强调 | “机会”“答案”“蜕变”等普通词反复加引号 | 是否虚造术语或替读者划重点？引用、代号、场内消息与反讽另判 |
| 解释结论链 | 这意味着；真正重要的是；之所以……是因为；正是因为；由此可见；他／她终于明白；他／她这才意识到；此刻，他／她……；这是最好的选择；所有人都会记住这一刻 | 是否重复读者已得到的意思，或把必要过程概括掉？ |
| 意义膨胀、万能结论 | 意义深远；可谓；未来可期；前途无量；充满希望；一切……都……；这就是…… | 是否只扩大分量、宣布前景，没有具体影响或下一步？ |
| 抽象收束、预告 | 命运／宿命／注定＋齿轮／棋局／獠牙／改写／安排；这一刻终于明白；从这一刻开始；属于 X 的反击／复仇／故事才刚刚开始；他／她不知道的是；殊不知；多年以后；冥冥之中；仿佛预示着 | 是否只宣告分量，或越过本次揭露边界？回顾、全知与题材承诺按文风判断 |
| 隐性盖章、点破潜台词 | 关切得恰到好处；笑得恰如其分；不多不少；那点笑她看得分明；谁都看得出他在撒谎；演得真好；这出戏她看过一遍；他就是这样薄情的人；像在宣判一件早已定好的事；像看一件死物 | 是否替读者把伪装、潜台词或人物性质提前判定？区分角色带偏见的认识与叙述者断言 |
| 告知与气场模板 | 他／她知道……；他／她感到……；他／她意识到……；显得（有些）X；淬了／淬着 X；心底／心里某个地方＋软；（浑身）散发着一股 X 气息／气场 | 是否只贴感受与人物标签？准确直写、有来源的认知和角色特有感受可留 |
| 电报体、动作清单 | 连续孤立短句；抬手、取过、放下、转身；动作后反复“了下／了一下” | 是否丢失动作方向、对象和连接，或把无关步骤全部拍出？ |
| 论述腔、公文腔 | 不难看出、事实上、综上所述、于是乎、与此同时、因而、然而、此刻、机制、结构、逻辑、体系、基于、当前、进一步、深入、推进、落实、从而、诚然、不得、须、未、已然 | 是否与人物、年代和载体语域不合，或每段都先总结再解释？公告、规则和职业表达可有意采用 |

## 套词与套式反应信号

以下组合在跨场景机械复现、成片堆叠或只替情绪贴标签时优先复核；孤立出现不判错。

| 类别 | 检索词例 |
|---|---|
| 弱化与装饰 | 微微、淡淡、缓缓、轻轻、一丝、一抹、些许、几分、隐约、微不可察、几不可闻、毫无征兆 |
| 通用反应 | 深吸一口气、不禁、眼中闪过、嘴角勾起、嘴角微扬、脸色一变、眉头微皱、眉眼低垂、瞳孔微缩、瞳孔收缩、瞳孔一缩、指节泛白、指尖轻叩、攥紧袖口、袖口里攥紧、目光移开、眼神锐利、目光锐利、目光如炬、头皮发紧、眼皮一跳、心口一沉、胃里翻涌 |
| 通用心理 | 心头一震、心中一动、心下了然、心中暗道、心底泛起、心中一凛、不由得、心中涌起一股暖流、心中涌起一股难以名状的情感、心里某个地方软得一塌糊涂 |
| 空泛定性 | 不容置疑、不容置喙、不易察觉、显而易见、毫无疑问、不可否认、前所未有、坚定、闪烁着光芒、狡黠、深邃、凛冽、冰冷、散发着一股生人勿近的气息 |
| 模板比喻 | 仿佛／犹如／宛若……一般；仿佛、犹如、宛若、宛如、如同、如潮水般、像潮水般、如闪电般、仿佛春风、犹如疾风骤雨、仿佛能穿透一切一般、像命运的齿轮、像上辈子的尘埃、像在宣判、眼里淬了毒、梨花带雨、如沐春风 |
| 自动过渡与书面表达 | 映入眼帘、只见、此时此刻、不由自主、情不自禁、自然而然、话锋一转、取而代之的是、瓦解、无名火、往我心上捅刀子 |
| 语境敏感词 | 突然、陡然、骤然、猛然、瞬间、猛地、死死地、好像、似乎；沉声道、淡淡地说；扯了下、停了一下、拍了两下、松了半圈 |

“她感到”“意识到”“知道”“原来”可以准确表达感受、判断和发现；“仿佛／好像／似乎”可以限定视角置信度；“坚定／冰冷／深邃”可以是准确描述。“突然／瞬间／猛地”也可能承担真实突发或时间压缩。只凭这些词不能认定告知式心理、模板比喻或偷懒。

## 复合样本

例句展示组合风险，不是合格与不合格的标准答案；判断及改法按调用方的流程，不能照例句新增动作、改变人物态度或一律拆短。

| 观察对象 | 例句或模板 | 回到语境核对 |
|---|---|---|
| 否定、状语与声线 | “他不是冷漠，而是绝望”“他笑了一下，带着一丝不易察觉的嘲讽”“他说，带着一丝无奈”“她声音不大，却带着不容置疑的力量”“好的，他说道” | 对比是否有纠错对象，状语与标签是否机械复现；普通“说”不用替换成动作 |
| 跨段铺排与预告 | “不是嚎啕大哭。／也不是扯着嗓子喊不舍。／只是一个人走远了……”“他不知道的是，更大的风暴即将来临”“命运终于露出獠牙；属于他的反击才刚刚开始”“早已布好的棋局” | 是否反复铺垫同一意思、空泛宣告或越过揭露边界；排除猜测与题材承诺另判 |
| 告知、反应与过渡 | “他知道这一切都来不及了”“她感到一丝失落”“他感到愤怒”“他意识到事情不对”“眼中闪过一丝悲伤”“嘴角勾起一抹冷笑”“他显得有些兴奋”“浑身散发着一股生人勿近的气息”“笑容消失，取而代之的是冰冷” | 判断是否需要直写，反应与新状态是否已经由上下文表达 |
| 反复呈现同一瞬间 | “林父低着头，左手把文书压住，右手拿笔，往纸上落。”／“手从肘到腕都在抖。”／“笔尖在纸上停了停，写了一横，又停。那个"林"字的撇写歪了。” | 多段是否反复重拍同一动作；手抖、落笔失败也可能是必要体验，不能只留动作梗概 |
| 场景氛围 | “阳光透过窗帘的缝隙洒进来，在地板上投下斑驳的光影。空气中弥漫着淡淡的花香，仿佛整个世界都沉浸在一片宁静祥和的氛围中。” | 景物是否与此刻行动、视角或情绪有关，还是可移到任意场景 |
| 天气套写 | “天空阴沉沉的，乌云密布，仿佛随时都会下起倾盆大雨。凛冽的寒风呼啸而过，带着一丝刺骨的寒意。” | 是否叠加同一寒冷、阴沉信息；天气也可能改变行动条件 |
| 打斗套写 | “他的拳头犹如疾风骤雨般猛烈，每一击都蕴含着不容置疑的力量。对手的瞳孔微微收缩，显然没有预料到如此凌厉的攻势。” | 力量与反应是否只被定性，攻防过程、失误与后果是否缺失 |
| 哲理、翻页与感慨收尾 | “他站在窗前，望着远方的天际线，终于明白了生活的真谛：有时候，放手才是最好的选择。”“这一刻，一切都变了。她知道，从今以后，她的人生将翻开崭新的一页。”“这一夜，注定无人入眠”“人生就是这样……”“岁月如流水般悄然流逝……” | 是否重复总结，或确实呈现本书允许的新认识、时间变化与余韵 |
| 修饰、排比与意义尾巴 | “他看着她的眼睛，看着她的嘴唇，看着她微微颤动的睫毛，心中涌起一股难以名状的情感。”“当他终于推开那扇沉重的木门时，映入眼帘的是一间昏暗的房间，空气中弥漫着陈旧的气息，墙角堆满了落满灰尘的箱子。”“她喜欢春天的花朵，喜欢夏天的阳光，喜欢秋天的落叶，喜欢冬天的白雪。每一个季节都有它独特的美。” | 信息是否重复，末句是否替读者点题；不要因长句、修饰或排比形式本身删掉有效感受 |
| 温和请求、完整解释与笼统反应 | “我觉得你这样做不太合适，能不能考虑一下我的感受？”“其实我这样做是有原因的，因为当时的情况非常复杂……”“所有人都震惊了，不敢相信自己的耳朵。”“她很害怕，不知道该怎么办，只能等着事情过去。” | 是否所有人都用同一套说法，关键交锋或选择是否被概括；不能把请求改辱骂、解释改挑衅，或凭空补锁门、录音与群体动作 |
| 比喻的功能边界 | “像一头被抛弃的野狗”“像一把刀”“脸色惨白得像这漫天的雪”“力道大得像是要把骨头捏碎” | 生活化、物品、环境与身体感知比喻均可能有效；看是否传递角色特有信息，不按类别全删 |
| 二修伪自然 | “手里拿着刀，他冲了上去”；连续“伸手拿起、取过、挑开、放下、转身”；强加口误、脏话、每句换行或对话占比 | 一次伴随动作前置不等于油腻；检查是否机械套用另一种句法、流程或格式 |
| 替换的误改风险 | “美丽动人的笑容”“白色的药片”“手里那截链子”“飞驰的汽车”“他因为害怕而……”；垂下眼、目光微沉、攥拳 | 修饰、指示与原因可能承担区分、承接或动作条件；不能仅为去词删成信息残缺，也不能把每个情绪词换成同一微动作 |

## 使用边界

脚本提示只供定位，不能替代语义结论。是否构成问题、如何修复及能否保留，由调用方的流程与本书文风确定。

标点、句长、段落疏密和对话占比均不在此设置统一指标。不通过同义词轮换、错误用字、英文点省略号或机械补动作规避提示。
