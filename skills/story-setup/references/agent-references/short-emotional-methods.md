## 情感虐心三板斧

### 第一斧：羁绊铺设（前 1/3）

用具体数字立时间（「相恋八年」「七年质子」）、具体物件承感情、重复动作立习惯，少写「他们很相爱」空话（温情甜宠写到偏爱与回馈即可，虐心向靠羁绊为撕裂蓄力）：

- **旧衣与金锁立讨好执念**（《五一姐夫捎我十公里路》）：女大生穿姐姐旧衣二十年，家教费只留三百、省一千贴补家里，把十岁时妈送的金锁贴身戴十年当偏爱证据。
- **佛前苦求立痴情**：未婚夫抗旨出家后，女主连着三年除夕跪佛前掷圣杯求他还俗，绣荷包扎破十几次手，后面撞破假出家才立得住心死。
- **旧木马立护犊情**（《皇弟欺负我的幼子》）：废太子当七年质子归朝，见幼子被皇弟折辱得痴傻怕人，退回父皇赏的金玉麒麟，亲手给儿子磨了匹摔不坏的木马。

---

### 第二斧：情感撕裂（中后段）

借反差（先暖后冷）、错位（以为是爱实则是算计）或延迟揭底，颠覆前文认知：

- **信物翻面揭穿假慈母**（《五一姐夫捎我十公里路》）：她被姐姐推伤住院、金锁被外甥扯走，病床前听见装软弱的妈劝姐：「这金锁就是个金包铜的垃圾，最多值五十。等她醒了道个歉，她毕业每月不得给你三四千！」她抠破金箔露出黑铜胎，回家脱下旧衣还清八万抚养账。
- **温柔表象下藏真凶**（《皇弟欺负我的幼子》）：继后从前常给先皇后送手炉汤药，实则长年下慢毒逼疯先皇后吊死冷宫，如今又纵容新太子把主角幼子当狗折辱。
- **深情伪装下是杀猪盘**：弟弟为女友掏空家底、深信对方有孕，被骗进境外园区才知孕检单全是诱饵。

---

### 第三斧：余韵钝痛（结尾）

不用大哭大闹，把留白落在日常动作和前文物件上，写人物做了什么，不替读者解释：

- **孩童攥紧旧木马反衬迟来的讨好**（《皇弟欺负我的幼子》）：悔恨的父皇捧桂花糕哄孙子，孩子躲在父亲身后不接；夜里「他睡得很沉，手里还攥着那匹被我磨得很光滑的木头小马」，父皇在门外吹了一夜冷风。
- **断联后的平静日常**（《五一姐夫捎我十公里路》）：拉黑母姐办好留学后，只写花一百块买新行李箱、五十块买新短袖，「我的手机清净了不少。那些困扰我很久的麻烦，在一瞬间变得很小」。
- **把爱转给值得的人**（《准儿媳爱给人打分》）：老两口被怀孕准儿媳按条扣分索要百万彩礼、又被亲儿赶出家门；起诉收回婚房、逆子入狱后，去福利院收养了被嫌笨拙的小女孩，「她会每天笑着迎接我们回家，问我累不累、渴不渴。我知道，这一次我没选错」。

## 情感拉扯节奏设计

### 基本节奏曲线

```
温暖 → 残忍 → 善意 → 真相 → 原谅 → 来不及 → 释然 → 细节暴击
```

按本篇题材的节奏骨架，只选用曲线中需要的转折。

### 拉扯原则

1. **情绪、期待或压力要持续变化**；连续多个小节不变时检查停滞。甜宠可沿甜度递进，报应型可沿反制升级，不强行插入负向回落
2. **每次转向都要有触发事件**（不能无理由地改变情绪）
3. **最后一次转向决定结尾余韵的基调**
4. **爽文允许快速反弹，虐文需要更长铺垫**

### 整篇弧线与转折位置

| 走向（设定.md 写左列的说法） | 适合 | 转折与兑现怎么落 |
|---|---|---|
| 先压后扬（V形） | 虐后翻盘、破镜重圆 | 压到退无可退再翻盘，留足反击与结算 |
| 先甜后崩（倒V形） | BE、信任崩塌 | 甜到信任最满处崩塌，跌比升快，结尾不加糖 |
| 几起几落（W形） | 追妻拉扯、多反转 | 两三次起伏，峰逐次加重，终峰落在总清算处 |
| 一路上扬（渐进形） | 打脸爽文、层层揭秘 | 借阶段反制一路推高，大底牌留在终局亮出 |
| 憋到最后爆（延迟满足形） | 隐忍复仇、身份揭秘 | 前段蓄压攒证据，终局集中引爆 |
| 最后急转（急转弯形） | 细思极恐、动机反转 | 前段按常规推进，终局前亮出反常急转 |

反转或兑现节是全篇的峰（倒V形在中段）；各节按所选走向起落，不要求逐节递增。

## 常见失败模式

| 失败模式 | 识别方法 | 修正方向 |
|----------|----------|----------|
| **太平** | 连续多节无情绪、期待或压力变化 | 检查事件是否带来新信息、选择或后果 |
| **太赶** | 重大转折缺铺垫 | 补清关系积累与触发事件 |
| **假虐** | 读者不心疼，只是看着难受 | 检查羁绊铺设是否具体 |
| **割裂** | 开头承诺、中段升级与结尾脱节 | 让升级、反转和结局回答开头同一困境 |
| **烂尾** | 反转后还在补交代、新开事件 | 反转后只写兑现与余韵 |
| **人设崩** | 关键时刻行为不合前面人设 | 回顾人设，确保行为逻辑一致 |
