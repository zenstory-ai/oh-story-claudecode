# 长篇题材框架速查

> 谁读：定方向没方向时主会话读（特殊题材只读对应一节）；story-architect 题材定位读副本。

> **用途**：长篇选题和排大纲时对照男频题材框架，每个框架按读者期待、长线骨架、单元循环、卷级升级轴、前三章写法五栏写；男频分题材的单元循环以这里为准。女频框架在 `female-audience-writing.md`；短篇结构转交 `story-short-write`。

---

## 题材选择路由

先按故事核心判断大类，再查具体变体。

| 如果故事核心是... | 走这个框架 | 备注 |
|---|---|---|
| 底层崛起，升级打怪（都市+武道） | **都市高武** | 金钱驱动+分层地图 |
| 废材或落魄天才，修仙世界登顶 | **仙侠/玄幻** | 力量体系必须清晰 |
| 主角无天赋，靠谨慎算计生存（修仙） | **凡人流** | 利弊权衡是核心模式 |
| 穿越或重生到历史节点改变命运 | **历史/架空历史** | 信息差是最大金手指 |
| 娱乐圈才华展示+围观震惊 | **文娱/娱乐圈** | 反应落在关键人物身上 |
| 用户明确目标 IP、平台允许且近期样本有效 | **同人流派** | 只抽「已知世界+新变量+名场面改写」结构 |
| 独特金手指或创意设定是核心卖点 | **脑洞文** | 核心梗决定赛道 |
| 模拟、种田领主、规则怪谈、长生、西幻、搞笑、无限流、悬疑、后悔流 | **其他题材速查** | 按需取用 |
| 女频长篇 | `female-audience-writing.md`「女频题材框架」 | 女频长篇只读那份，不读本文件 |

## 仙侠/玄幻

- **读者期待**：遭重大打击的废材或落魄天才从低谷崛起。代入感：王朝身份关系比赛博设定好懂，贴身搏杀的拳拳到肉比隔空对轰更好写痛感和力量差距；期待感：眼前目标接上后续升级，持续兑现又不断更新；认同感：主角的选择守住大义，小德可缺，大义不能失。
- **长线骨架**：反派按维度递升：同辈→长辈→宗门 Boss→天道；地图逐层展开。导师阶段性出现，不能太强也不能太弱。
- **单元循环**：一个眼前目标（夺宝、比试、救人或复仇），金手指配合策略解决，收获后引出下一个更大的目标。战斗靠策略，不比纯数值。
- **卷级升级轴**：力量体系清晰不崩，升级节奏均匀；金手指独特、有限制、随境界成长。
- **前三章写法**：开局类型和三基点章位按 opening-design「开篇规划」选；低位起步的走环境开局，金手指在前 3 章内起作用即可。

## 都市高武

- **读者期待**：底层穷学生或武者靠打怪挣钱一路往上爬，钱是核心驱动，没钱寸步难行，有钱打遍天下。
- **长线骨架**：学校→武馆→武道厅→军部→星际；反派层随地图升级：校霸→地下势力→邪魔→跨国势力→外星。换地图用过渡人物连接。
- **单元循环**：每个目标都挂到钱上（换房子、给亲人治病、考军校、拿修炼资源），挣钱→变强→过一关→下一个更贵的目标。
- **卷级升级轴**：一张地图一卷，事件池随地图升级：

| 地图 | 可用事件 |
|------|----------|
| 学校 | 天才班、月考、联考、高考、校霸对决、助学金 |
| 武馆 | 获赏识、传承武学、师兄对决、市/省/国联赛 |
| 治安局 | 劫匪、邪魔、副本、城内 Boss |
| 大学、武道厅、军部 | 上一层事件的升级版 |
| 星际 | 全国事件升级版加世界观扩张 |

- **前三章写法**：底层处境→金手指→第一次展示。

## 凡人流

- **读者期待**：主角没有特殊天赋和背景，靠谨慎、机智、利弊权衡在残酷的修仙世界活下去；爽点靠智商和准备碾压，不拼硬实力。和传统升级流相反：金手指微弱或没有，逃跑优先于越级挑战，节奏慢热、伏笔多。
- **长线骨架**：配角各有独立的利益考量，伏笔埋得早、回收精巧。
- **单元循环**：副本切入：小配角出场→小配角的故事→透露副本信息→主角权衡后决定进入。
- **卷级升级轴**：每次突破都要付出资源和风险，谨慎必须落在行为上，不能嘴上说谨慎、行为疯狂。
- **前三章写法**：金手指可以晚出、可以很弱，先用处境和一次谨慎的选择立住人设。

## 历史/架空历史

- **读者期待**：穿越或重生到历史节点，用现代知识和信息差改变命运；现代认知就是最大的金手指。
- **长线骨架**：按子类型走：科举文（诗词装逼、仕途攀升、权谋）；军史文（练兵、装备改革、以少胜多）；经营种田（技术引进、商业帝国、改善民生）；国潮非遗（盘点式装逼、民族自豪感）。
- **单元循环**：一个历史困局，用现代认知破局，旁人震惊，主角的地位或势力上一个台阶。
- **卷级升级轴**：家族或势力升级不能太快，前期太快后面难以为继。走仁义换忠诚路线时，主角施惠于人，受惠者因此效忠，人物立场前后一致。
- **红线**：历史网文以读者为先，不以还原史实为先，架空能降低门槛；历史人物的评价跟随当代权威共识。
- **前三章写法**：第一章交代穿越和所处的历史节点、身份困境；面向不熟背景的读者，先交代读懂剧情所需的历史处境。

## 文娱/娱乐圈

- **读者期待**：主角在娱乐圈发展，核心爽点是才华展示加围观者震惊。华娱是主流；架空文娱虚构明星，避开真人争议，自由度更高。
- **长线骨架**：作品一部比一部大，舞台从小节目走到顶级舞台；可以结合盘点文模式。
- **单元循环**：一次才艺展示就是一个单元。反应落在评委、对手这几个关键人物的态度变化上，不铺大段群体惊叹。
- **卷级升级轴**：金手指模糊处理，先知类能力后期会和现实冲突，用梦之类的方式自洽。主线之间用配角情景剧填充。
- **前三章写法**：第一章就进舞台或节目现场，交代金手指。角色可以高高在上，但都要带一份普通人的特质，不让读者有距离感。

## 同人流派

- **读者期待**：借用已有 IP 的世界观和角色写新故事，核心卖点是「这个世界里多了主角会怎样」。用户明确目标 IP、平台允许且近期样本有效时才用，只抽「已知世界+新主角变量+名场面改写」的结构。
- **长线骨架**：沿原作的时间线和名场面推进，主角在关键节点改写结局。改写悲剧命运时，选好悲剧原型和主角介入的时间点，常驻核心配角宜精不宜滥，悲剧变喜剧后给主角收获并引出下一个故事。
- **单元循环**：一个名场面一个单元；震惊之下加更深的情绪（亲情、救赎、遗憾弥补），原著人物的反应不止「太强了」，还有激动、后悔、释然；震惊熟人比震惊陌生人更有力。
- **卷级升级轴**：书名对准某个经典人物时，支线不喧宾夺主，主线始终围着该人物与核心变局转。爽感优先，不为还原原著牺牲爽感；时代设定可以简化。
- **前三章写法**：第一章交代穿进哪个世界、哪个时间点和金手指；面向没看过原著的读者补足读懂当前剧情所需的背景。
- **命名**：原著角色用官方本名或译名；新角色顺着原著地域的命名风格，不混语系。

## 脑洞文

- **核心机制**：独特金手指或创意设定是核心卖点，题材只是外壳；必须把创意落成主角眼下的委屈或急迫困境（条件→反馈的分档见 `long-genre-mechanics.md`「金手指」）。
- **错位系统**：让系统绑错时间、环境或对象，用系统指令与主角真实处境的反差出戏。时间错位（人都无敌了，新手逆袭系统才来）；环境错位（和平日常觉醒末世求生系统）；对象错位（帝王系统绑在皇后身上）。
- **写长**：长线靠主线与剧情段的因果过渡撑起。先定主角初始状态，每段剧情接住上一段的结果，并把下一段的导火索提前埋进当前段：
  - 换视角展开（多角度循环）：围绕同一个核心设定换切入面，每个切入面写一两卷（如先写主角靠能力破局，再写搭档或对手撞上这项能力后的连锁反应）。
  - 扩场景升级（设定扩展循环）：顺着脑洞设定从小场景往大场面扩出新玩法（如听懂小动物说话，先抓出租屋隔墙凶手，再扩到搜寻地下赃物、追查跨城积案）。
  - 反面一：只拿同一招换名字重复打怪收小弟，写到二十万字左右读者就腻。
  - 反面二：纯靠一次比一次惨、对手一次比一次坏硬拔情绪，读者很快麻木。
- **脑洞四类**：金手指类（聊天群、系统、随身前辈）、剧情类（反转、错位设定）、世界设定类（特殊规则、修行体系）、角色类（反差身份、特殊人设）。单书叠加两到三类即可，不必四类全创。

## 其他题材速查

### 模拟文
单元：先在模拟里演一遍不插手的惨败下场（立下危机与憋屈）→模拟结算拿到破局奖励或情报（形成信息差）→回到现实提前反杀兑现。卷：模拟得知大危机→多轮「模拟、得奖励、现实推进」→解决核心危机。小模拟给资源，大模拟给关键信息；模拟不全知，要留未知变量。

### 种田/领主/门派建设
写强主角方：领民、弟子、学生出彩，就是主角出彩，爽点随之扩充；配角各自出风头却和主角无关，读者不爽。

### 规则怪谈
类似无限流，玩家被抽入规则副本冒险求生。副本构建：背景故事→规则包装→通关线和死路→别人死、主角破局、揭露真相、升华。爽文路线用智斗和金手指解释通关，规则和限制要撑得起翻盘。

### 长生流
核心卖点是时移世易，主角长生，看别人浴血搏杀，凡俗时期最好看。天然缺陷：修仙后实力增长，身边出现同级别的人，「熬时间」就失去意义。延续方向：保持时间碾压感、写代际传承、分层世界、把凡俗时期充分展开。

### 西幻/骑士文
魔法、种族、神权和契约要影响人物选择，不能只替换东方玄幻的名词。骑士晋升可以做力量体系骨架。开篇从低位开始（马奴、铁匠学徒），凿壁偷光式地努力。

### 搞笑文
搞笑要符合逻辑，在规则之内出人预料；玩梗化用内核，不照搬。主角身边人无条件护短或配合捧哏。

### 无限流
游戏副本式结构，每个副本自成一个故事，用现实主线串起副本。

### 悬疑
靠铺垫和氛围营造悬疑感，不靠血腥暴力；控好信息释放的节奏。

### 后悔流
避开退婚这类老套外衣，换个包装：后悔的对象可以从爱情换成事业选择或人生抉择。

## 质量检查清单

| # | 检查项 | 通过标准 |
|---|--------|----------|
| 1 | **题材定位正确** | 已按路由表确认框架，女频转到 female-audience-writing.md |
| 2 | **五栏齐全** | 读者期待、长线骨架、单元循环、卷级升级轴、前三章写法都能说清 |
| 3 | **人设与反派立住** | 主角人设稳定、目标清晰；反派有独立动机，不是工具人 |
| 4 | **金手指自洽** | 规则明确、有限制，后期不崩 |
| 5 | **信息差到位** | 有读者知道而角色不知道、或角色知道而对手不知道的信息差 |
| 6 | **结局情绪对位** | 结尾情绪和题材核心匹配（爽文释放，虐文留余韵） |
