> 谁读：主会话出/补细纲整份读，配题材包 **1–3 节（故事线/常见剧情/人物设计）**；`story-architect` 任务包带入「排纲方法」及以下与题材包 1–3 节。

## 主会话：出细纲步骤与汇报

1. **只取本段卷纲**：跑 `{skill 根}` 脚本目录 `outline_view.js --unit {单元编号} {卷纲路径}`（先 `--toc`），不整读卷纲；按需定点读 `设定/` 与 `追踪/上下文.md`。
2. **派发或自排**：已部署 `story-architect` 时跑 `build_architect_brief.js --project {书目录} --task outline --chapters {A-B}`（单批 ≤10 章，见子代理派发手册）；无子代理先给本批提案，作者确认后落盘。
3. **收回验收**：每章写入后跑 `check-outline-contract.js --json --project {书目录} --chapter {N}`。exit 1（`hard_failures`：可读、字数目标、`目标情绪`/`主角目标/关键选择`实质内容）补齐重验（≤2 轮）；`soft_warnings` 按需修补。
4. **中途补纲/扩纲**：只补点名范围，**已写正文细纲锁定不改**。新剧情段按 `flow-opening-plan.md` 往卷尾追加新卡，规划事件不进 `追踪/`。
5. **向作者汇报**（开书/大纲/卷纲/细纲通用；只用故事话）：

## 排纲方法

### 黄金三章规划（含第 1–3 章必读）

**番茄/七猫禁慢热**（仅起点/晋江指定才缓铺）。底线：第 1 章首段短脆直入困局、开头一两段禁纯景物、开头很快见对话（独白/奇观开场可稍晚）并入核心冲突、核心出场人物精简（路人不堆全名）；前 3 章**章末全强钩**；站队前不把对手写可怜。**三条黄金三章防写僵铁律**：① **单章不塞双满配大场**（避免初稿爆字或把长线冲突挤爆在开篇）；② **落真切痛处或活人烟火反差**，禁写成冷硬机械走流程的工具人；③ **女频言情前 3 章让男女主正面同框或有直接交集**，反派与前任留出后续反击与收账空间。选 1 种开篇套路跑透：

| 开篇套路 | 第 1 章 | 第 2–3 章推进 | 适用题材 |
|---|---|---|---|
| **打脸翻盘** | 直抛羞辱/死局并亮底牌，给小反馈+强卡点 | 当面正面交锋+切身赌注 → Ch3 首轮打脸、实利落袋+大舞台钩子 | 传统玄幻、高武、宅斗、历史爽文 |
| **三章蓄力+逐级垫脚石** | 播报/奇观立压迫+选反常识底牌但蓄而不发 | 普通人→天才逐级衬托压迫感 → Ch3 末出招瞬间卡断、Ch4 初爆 | 序列高武、玄幻脑洞、末世升级 |
| **真实痛点+小步数值养成+死党对照** | 现实窘境/亲情牵挂+系统小步数值正反馈（零反派亦可） | 高频小步数值成长+同桌/青梅/死党对照稳留存+阶段小目标 | 都市日常、听劝养成、校园/种田 |
| **强概念+双视角脑补/弹幕** | 直抛高辨识奇观/职业现场/穿书反差，即刻入局 | 场景级切对手/恋人/大人物视角脑补震撼，或用弹幕剧透+吐槽调频 | 甜宠脑洞、双男主、谍战、悬疑、迪化 |

### 批次边界与写纲前查缺

- 未指定范围时一批 ≈ 一段剧情（≤10 章；开书默认前 10 章）；指定范围不擅扩批。
- 每批前查 5 项记进 `.story/排纲笔记/{剧情段编号}.md`：① 本批对手（对抗段保持对手压迫不断档）；② 未来 3 章新角色卡；③ 能力/金手指规则一致；④ 物价、等级等刻度有据（缺则按「新增物三级」补档或问作者）；⑤ 禁连两段同场景/同对手/同破局手段。
- **细纲后补档**：新出现会复用的角色/势力/跨章规矩，及时建 `设定/角色/`、`设定/势力/` 或 `设定/世界观/`（一次性路人不建）。

### 爽点倒推与高潮构建（写足阻力，禁降智送脸）

- **立真冲突，禁走过场**：围绕六类爽点（破局碾压/达成/实利变现/利害改口/掉马/破例护短），**先定各方真实私心与底牌，再推碰撞与反咬——禁倒推送脸、反派无逻辑自爆或违背自身利益主动送把柄、巧合天降及外援代打核心局**。
- **单章容量与阻力并重**：**2,200 字单章聚焦 1 场主重戏、最多配 1 场短过场或收尾钩子（3,000 字章 2 场主戏），大高潮多回合直接拆成上下两章写透，外部视角切入保持克制**，给足对话拉扯、生活烟火与情绪缓冲，严禁塞双满配大场致初稿超字后再被压成碎句；每章设真实对手反咬、意外阻滞或主角代价，**高潮翻盘底牌须在前置章由主角主动设局夺得（禁临场外援递底牌或巧合天降）**，轻松过渡章放开写松弛对话与关系推进，无阻力水过场直接并章。
- **多线期待接力**：短、中、长线期待接棒，旧期待兑现前先让下条线拱半步，**严防断期待**。

### 高频章首 / 章尾硬钩子（日更多数章末带钩，黄金三章章章带钩）

| 位置 | 实战钩子类型 | 停在哪一拍（写场面落点与意图，不写类型名） |
|---|---|---|
| **章首** | 承接炸点 / 冲突对话 / 反常动作 / 倒计时 | 紧接上章尾结果或一句直切新麻烦，禁天气空景开章 |
| **章尾·危机打断** | 突发危机 / 动作截断 / 来人来电 | 刀将落、门刚推开、系统急报、大敌/权贵突降 |
| **章尾·亮牌反转** | 身份揭露 / 奖励超预期 / 信息差落子 | 测力碑炸裂、隐藏大奖刷出、对手得意却不知底牌已落（可切视角交代幕后） |
| **章尾·选择逼迫** | 两难抉择 / 期限倒计时 / 宣战赌约 | 必须二选一、限时三日、当众立对赌或退婚誓言 |
| **章尾·女频情绪悬崖** | 关键证物斩断 / 破例偏爱 / 退路试探 | ① 改局实证一拍斩断（退还婚书/账册压桌，不堆器物装饰）；② 高位者暗中破例偏爱；③ 信息差误解或递退路卡点（「现在后悔还来得及」） |

- 细纲钩子优先写功能意图与落点，少填整段台词原话，留给正文现场发挥（确须逐字进正文的原话另填「原样出现的原话」）。

### 感情线五阶段与女频 CP 四拍推拉（有感情线时对照）

| 阶段 | 允许互动 | 节奏与 CP 四拍（试探→克制→破防→上位者低头） |
|---|---|---|
| 相识 | 初印象反差、利益交锋、看穿表象 | 首段出场；先立双方对等筹码与不卑不亢立场 |
| 试探 | 行动护短、嘴硬心软、跨章推拉 | 男频借危局同行升温；女频走**试探→克制**（人前克制人后破例） |
| 确认 | 破防认错、递退路托举、吃醋护短 | 踩事业/高潮节点兑现**破防→上位者低头**（给足选择权） |
| 考验 | 联手抗外阻、舍利托底 | 虐点不过度拖长、必有反制或高糖，禁真出轨/暴力强行洗白 HE |
| 定局 | 默契对外、日常发糖 | 落定后不硬塞烂俗情敌水字数 |

- 章节标题：简短抓冲突或梗，禁「开始/觉醒」空词，不剧透。

### 中后期换卷与长跑红线（≥50 章或跨卷必查）

- **百章四件套**：① 换图回扣旧敌旧账、带老熟人升级目标（禁清零重开）；② 特色配角扛喜剧/潜伏高光破疲劳；③ 轻松章用互损带实账、章末挂旧危机或硬锚；④ 切大格局时借具体人物互动或生活烟火减压，不悬浮说教。
- **战力与财富四阀**：定体系硬顶、旧技二创破局、补支出代价、用物价刻度保实感（禁百亿失感）；连写几章紧冲突后穿插轻松过渡章。
  - ❌ 飞升上界旧友清零，又从杂役被骂起。→ ✅ 携旧部旧账闯上界，落地即遭前卷死敌通缉堵门，直接转猎杀反杀。

## 细纲与排纲笔记白话模板

<!-- 脚本按名读取勿改名：「字数目标」「字数范围」「目标情绪」「主角目标/关键选择」「原样出现的原话」「### 第 N 章：章名」；「核心事件」「属于哪段剧情」「章首钩子」「爽点」及四小节（这章怎么走/情节安排/人物关系和出场顺序/情节细化）、五行（起因/发展/转折/高潮/结尾）、三列表头由 check-outline-contract.js 核对。 -->

作者直接打开细纲，**只写故事里的人和事**；单章细纲精炼控制在几百字内，各块分工不重复抄同一段梗概。

### 大纲/细纲_第XXX章.md

```markdown template=细纲
## 细纲（第 N 章）

### 第 N 章：{章名}
- 核心事件：{一句话说清本章事件}
- 字数目标：{2200 或 3000} 字
- 属于哪段剧情：{如「第一段剧情：退婚风波」}
- 目标情绪：{读者情绪走向与可见结果}
- 主角目标/关键选择：{本章要拿什么+关键取舍}
- 章首钩子：{承接上章或直切冲突的落点意图}
- 爽点：{痛快点与外部变化；松章写功能}

#### 这章怎么走（每行一短句，只标转折骨架）
- 起因：{一句}
- 发展：{一句}
- 转折：{一句}
- 高潮：{一句；松章写功能}
- 结尾：{停在什么动作/悬念，禁总结判词}

#### 分场
- 第一场：{地点、人物、戏眼与活人烟火细节}
- 第二场：{地点、人物、情绪拐点}

#### 情节安排
- 主线推进：{推进结果}
- 辅线/关系线：{推进或「无」}

#### 人物关系和出场顺序
- 出场顺序：{人物与关键改局道具，无闲笔不填}
- 关系与信息差：{谁知/误判什么、各自私心与变化}

#### 情节细化（按关键博弈步拆分，不写整句台词原话）
| # | 情节点（谁做了什么） | 作用 |
|---|---|---|
| 1 | {动作/对手反咬/意外阻滞或情绪拐点，忌走过场清单} | {钩/阻滞/反咬/反预期破局/代价/卡点} |

#### 结尾设定和钩子
- 结尾设定：{停在哪个具体场面/动作/悬念，以及推向下一章的力}

#### 可选：需要时再写
- 字数范围：{作者给上下限时写}
- 这章不能说破：{本章压住的秘密}
- 原样出现的原话：{须逐字进正文的原话}
- 账目与常理核对：{涉及数值守恒、时间跨度、物件流转或行业常识时简记依据，无则不写}
```
