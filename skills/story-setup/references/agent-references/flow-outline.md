> 谁读：主会话出细纲、补纲或写指定章前缺细纲时整份读；同时读本书 `genre-styles/{流派}.md`。`story-architect` 出细纲任务包带入「排纲方法」及以下全部内容。

## 主会话：出细纲步骤与汇报

1. **只取本段卷纲**：在 `{skill 根}` 的脚本目录跑 `outline_view.js --unit {单元编号} {卷纲路径}`（先 `--toc` 找编号），绝不整读卷纲；按需定点读 `设定/` 与 `追踪/上下文.md`。
2. **派发或自排**：已部署 `story-architect` 时跑 `build_architect_brief.js --project {书目录} --task outline --chapters {A-B}`（单批最多 10 章，见子代理派发手册）；无子代理时主会话先给本批走向提案，作者确认后落盘。
3. **收回验收**：每章写入后跑 `check-outline-contract.js --json --project {书目录} --chapter {N}`。exit 1（`hard_failures`：可读、字数目标、`目标情绪`/`主角目标·关键选择`实质内容）按点名字段补齐重验（最多两轮）；`soft_warnings` 复核后按需修补。
4. **中途补纲/扩纲**：只补点名范围，**已写正文的章细纲锁定不改**。确需新剧情段时按 `flow-opening-plan.md` 往卷尾追加新卡（不改锁定部分），规划事件不写进 `追踪/`。
5. **向作者汇报**（开书、大纲、卷纲、细纲、补纲通用；只用故事话）：

## 排纲方法

### 黄金三章规划（含第 1–3 章必读）

节奏原则：**番茄/七猫长篇严禁慢热开局**；只有目标平台明确为 **起点/晋江慢热向** 且作者指定时，才允许第 1 章缓铺处境、第 2–3 章亮底牌。

- **第 1 章（生死线）**：首段 ≤45 字直接抛反常、羞辱、危机或金手指异动；**≤300 字见首句对话，≤400 字进入核心冲突**，前 100 字零纯景物铺垫；出场主要人物 ≤3 人；脑洞/系统/重生/高武/打脸题材 **第 1 章必须亮出金手指或核心底牌** 并立刻给出看得见的小反馈，章末强卡点断章。
- **第 2 章**：兑现第 1 章章尾钩子，立刻把矛盾推升一级，安排主角与对手**当面正面交锋**（有来有回，不靠旁人转述），押上切身赌注（性命/家产/婚约/前程/生计）。
- **第 3 章**：完成首轮小高潮打脸或翻盘收获（旁人态度反转 + 实利到手），同时甩出指向整卷主线的更大麻烦或更高舞台钩子，锁死追读。
- **第 1–3 章三章章末必须 3/3 强钩子**；读者站队主角前，不把对手写得可怜。

### 批次边界与写纲前查缺

- 未指定范围时一批 ≈ 一段剧情（≤10 章；完整开书默认前 10 章）；指定范围不擅自扩批。
- 每批前快速查 5 项并记进 `.story/排纲笔记/{剧情段编号}.md`：① 本批对手是谁（对抗段别隔 2 章以上没对手）；② 未来 3 章新出场角色卡是否补齐；③ 能力/金手指规则与已有设定是否一致；④ 物价、等级、距离等刻度在设定里有没有依据（没有则按「新增物三级」补档或问作者）；⑤ 避免连续两段重复同场景、同对手、同破局手段。
- **细纲后设定补全**：本批新出现的会复用角色/势力/跨章规矩，及时建 `设定/角色/{名}.md`、`设定/势力/{名}.md` 或 `设定/世界观/{主题}.md`（一次性路人不建）。

### 爽点倒推与高潮构建

- **六类爽点**：能力碾压（先压低再横推）、目标达成（先立难度再拿下）、收获盘点（具体数值/品级+立刻变现）、态度转变（当众从轻视变震惊改口）、掉马甲（身份反差掀牌）、情感圆满（破例护短/关系跃迁）。先定本章爽点，再倒推需要谁来轻视或阻拦。
- **每章必有追读理由**：高潮/爽文兑现要干脆碾压不憋屈；强压迫/以弱胜强高潮可用「蓄能 → 假胜/受挫 → 破局反杀 → 余波断章」；松章/日常章也须留进度钩、关系钩或下一步明确目标，无信息过场直接并章。
- **三线期待接力**：同时跑短弧（2–3 章小冲突）、中弧（5–8 章阶段目标）、长弧（整卷主线），旧期待兑现前先让下一条线拱半步接棒，**严防断期待**。

### 高频章首 / 章尾硬钩子（日更 ≥70% 章末带钩，黄金三章 100%）

| 位置 | 实战钩子类型 | 停在哪一拍（细纲只写具体场面/台词，不写类型名） |
|---|---|---|
| **章首** | 承接炸点 / 冲突对话 / 反常动作 / 倒计时 | 直接接上章尾悬念结果，或一句话直切新麻烦，禁天气空景开章 |
| **章尾·危机打断** | 突发危机 / 动作截断 / 来人来电 | 刀将落、门刚推开、系统急报、大敌/权贵突降 |
| **章尾·亮牌反转** | 身份揭露 / 奖励超预期 / 信息差落子 | 测力碑炸裂、面板刷出隐藏大奖、对手刚得意却不知主角底牌已落（允许用直接动作或第三人称切镜交代对手/幕后动向） |
| **章尾·选择逼迫** | 两难抉择 / 期限倒计时 / 宣战赌约 | 必须二选一、限时三日、当众立下对赌或退婚誓言 |
| **章尾·情绪拉扯** | 态度突变 / 秘密露半角 / 狠话落尾 | 一句戳心反问、旧物露破绽、冷漠者破例护短 |

### 感情线五阶段（有感情线时对照）

| 阶段 | 好感门槛 | 允许互动 | 节奏提示 |
|---|---|---|---|
| 相识 | 零或负 | 初印象反差、利益交锋、看穿表象 | 感情线对象宜在首段剧情出场 |
| 试探 | 单方半好感 | 破例护短、嘴硬心软、跨章推拉 | 男频借事业/危局同行升温，女频重偏爱细节 |
| 确认 | 双方半好感+ | 交底、吃醋护食、借势撑腰 | 踩在事业/高潮节点同场兑现（先婚后爱可名分先行） |
| 考验 | 双方满好感 | 联手抗外部阻力、舍利托底 | 虐后必跟反转或糖，不原地重复吵架 |
| 定局 | 满 | 默契对外、日常发糖 | 落定后不硬塞烂俗情敌水字数 |

- 章节标题：12 字内取本章最有冲突或最有梗的一点，不用「开始」「觉醒」等空词，不剧透结局。
