# 故事成立与变化：诊断因果，按授权修复

本文件检查事件、行为、信息和结果的关系。句段表达见 [expression.md](expression.md)，既有内容的详略见 [narrative-focus.md](narrative-focus.md)。执行范围由调用方确定，审稿只报告。

## 沿事件检查，不套冲突公式

先从原文和已有设计确认人物处境、所知信息、本场作用及结果，再追问结果怎样发生。人物可以被动、冲动、犯错、忍让；日常、舒缓和氛围场景也有价值。不要求每场戏都有对手、反转、代价或胜负。

| 检查对象 | 可执行的问题 | 需要定位的缺口 |
|---|---|---|
| 行为依据 | 他根据当时所知，为什么会选这一步？害怕、习惯、误判有无文本支持？ | 只因作者需要就突然信任、反抗、原谅；人物为结果临时变性格 |
| 因果承接 | 后件由前件的哪个条件触发？中间条件已经写过，还是根本不存在？ | “然后”连接一串事件，解释句宣称成功却没有成立过程 |
| 他人立场 | 对方想保住什么，有什么限制？他为什么接受或改变策略？ | 所有人只负责帮忙、送线索、惊讶或认错，没有自己的理由 |
| 办法与结果 | 解法、失误、收益是否有前文支撑？结果的分量与准备是否相称？ | 临时出现的证据或能力解决问题；一句请求就越过已建立的阻力 |
| 变化与承接 | 经历之后，关系、认知、资源、期待、情绪或行动空间有什么变化？后文是否接住？ | 连续场景重置到原状，同一种办法反复奏效，已发生的事没有影响 |
| 信息与时序 | 谁在何时知道什么，从何得知？读者何时获知？ | 人物提前知道答案、把回忆当现场、剧透尚未揭露的因果 |

逐项有问题才记录，正常项可以略过，不为填满检查表回头加戏。判断“过平”要指出原文中的重复或缺失：例如连续求助被拒却从未调整办法，或已经设计的关系变化没有影响后来行为。一次没有冲突的照料不能据此判平。

## 缺的是写法，还是成立条件

遇到转变突兀，先检索本次提供的前文、设定与大纲。结论分三种：

- **依据已有，正文没接上**：按既定信息边界恢复承接，避免重复解释。若已定承诺只在前文出现，可以让角色在当前交涉中使用它。
- **资料不足，暂时不能判断**：明确哪一项未知，继续有依据的改稿；不能因为没给全书就判全书无铺垫，也不能替作者补出前情。
- **当前设计确实缺条件**：说明原文的哪次选择或结果缺少什么支持，给最小设计方案及影响。增加“他终于被打动”这类解释不能补足对方立场。

区分信息缺口与悬念：门外留下湿脚印，尚不知道谁来过，构成一个明确的问题；不应替作者猜出答案。读者连人物为何守着这扇门、当下要做什么都无从理解时，才回查并补已有的必要背景。

## 诊断深度与执行权限分别确定

| 可以在普通去味中落改 | 需要剧情设计授权的改动 |
|---|---|
| 修正可核实的指代、主体、时序笔误 | 多种解释均成立，需要替作者选定真实动机 |
| 恢复已有因果、条件和信息来源的承接 | 新增承诺、证据、人物身份、能力、事件或信息来源 |
| 展开已定交锋、权衡和反馈，调整同场详略 | 改变人物决定、胜负、关系走向、代价或事件顺序 |
| 在既定揭露边界内呈现已知信息 | 提前揭底、搬动伏笔，或改变读者与人物获知顺序 |

对白措辞和必要微连接可以为既定内容服务；不能借一句台词或一个顺带动作新增威胁、承诺、拿到证据或改变人物策略。改换视角时只叙述该视角有依据的感知与认知，不能添加“进门时发现”“后来听说”等新经历来保留信息。

作者已明确要求重写或允许调整剧情时，直接执行被授权部分，保留其余已定事实；不用再次请求同一授权。仍缺少关键选择依据时，提出可审阅的最小选项。修法要写到哪次行为、什么条件或什么结果上，说明会牵动哪些后文，不只说“加强冲突”。建议与推测放在报告，不悄悄成为正文事实。

## 成组示例：结果需要可成立的过程

以下为合成示例。

**原文**：掌柜指认学徒改了账。学徒拿出一张抄本，众人立刻相信他，掌柜当众认错。

**可定位的诊断**：抄本由谁保存、为何可信、众人凭什么有能力和立场核对，都未交代。仅仅有人拿出纸，不能证明其上内容成立；也不能靠增加旁人惊讶来补足。

**普通去味**：清理空泛修饰，保留已定的澄清结果；查前文有无验账惯例、独立底稿或见证条件。当前资料没有时，把未修的缺口列入报告，提出最小方案及需要新增的条件，不把方案当作发生过的事。

**已有前情且作者授权演出**：此前三位伙计各自封存过底稿，掌柜允许众人当面核账。

> 学徒把自己的底稿放在柜上，请另两人拆开封存的那两页。三份末行都是同一个数，和掌柜手中的新账对不上。
>
> 掌柜拿着那几页纸，承认这一笔不是学徒改的。

证据的分量来自各自封存的底稿和当面核对，没有临时加秘密证人。前情写足时直接写核对，不必再造一次失败来“增加波折”。

**会改坏的方向**：突然增加录音、权势亲戚或暗中交易，让结果更热闹却改掉故事依据；或未经授权把澄清改为失败，以“增加代价”替作者决定后果。

## 修后回读

把本次修改前后放回事件链，核对人物知情顺序、选择依据、结果及下一场承接。报告区分已修的缺口、仍需设计的部分和因资料不足未作结论的部分。表达顺了不代表故事缺口已经消失。
