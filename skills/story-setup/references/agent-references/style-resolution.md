# 文风与参考冲突裁决

写正文、改写、去 AI 味和审稿前，先确定本次生效的文风要求，主会话与子代理共用。

## 优先级与边界

- **表达优先级**：**当前请求 > 本书文风/设定 > 写作流程传入偏好 > 主对标文风 > 题材包与通用默认值**。句长、视角、标点、对话落法、情绪直写、修辞与收尾均按此取舍；默认规则不压过作者明确选择。
- **事实与表达分开**：文风不改变既定事件、已知事实、信息揭露边界、字数范围、文件结构或追踪协议。转限知时不补编新观察经历。

## 加载与白名单

1. 定位书目录（长篇为 `正文/` 父目录，短篇为 `正文.md` 所在目录），读 `设定/文风.md`（短篇读 `设定.md`「文风约定」）；无文件照常继续，摘要与全文冲突以全文为准。
2. 复用调用方传入的偏好与 `style_resolution`（生效要求、覆盖条款、事实边界），原样传给写手与文字 reviewer，并附文风全文路径。
3. **书级白名单 `.deslop-whitelist`**：UTF-8，一行一个原文字面片段（`#` 开头注释，不支持正则，不向父目录继承），每项上一行注明 `# 来源：…；用途：…`。只登记作者明确采用的原句/写法（对话与面板 `……`、对话内与长短篇旁白标准 `——` 默认保留，不登记泛词关闭整类检查）；白名单只豁免对应片段的风格提示，事实、字数、工程词与截断照查。
