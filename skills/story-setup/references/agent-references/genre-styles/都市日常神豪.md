# 长篇题材包：都市日常神豪

> **核心卖点与底线**：覆盖都市高手/下山神医与都市日常/奶爸/学霸科研双轨，靠真实生活账单、身份掉马称呼三级跳与权威失态抢人出爽。

## 1. 故事线设计

- **双轨核心主轴**：
  - **都市高手 / 下山神医 / 赘婿神豪**：满级底牌藏于寻常身份下，护妻宠妹、当众治病或亮人脉碾压势利权贵，借「称呼三级跳」（泥腿子 → 先生 → 神医/老板）交付阶层反转爽。
  - **都市日常 / 奶爸经营 / 学霸科研**：凭过硬手艺、真实毛利账单与熟客口碑反杀黑心同行；或底层烟火亲情铺底，切顶尖院士教授争论难题视角，少年极简破题引发权威失态抢人。
- **卷级推进与防崩**：家庭与熟人圈（岳家、街坊、旧同学）→ 市级商圈与名流医疗/学术圈 → 省城乃至顶层世家与行业格局。百章防注水靠死党互损对白带出具体变现数字，章末抛旧危机锚点收紧节奏。

## 2. 常见剧情设计

- **黄金三章切口**：高手流走极速短剧感开篇，快速进尖锐对话冲突（退婚羞辱、孤品被扔垃圾桶、老爷子危症），当章亮首缕本事或贵客失态伏笔；日常流切入急迫生计或带娃窘境（老店被涨租逼退、摆摊缺本金），当章凭硬手艺赚到第一笔踏实钱。第 2 章正面兑现（一针救命、大人物敬茶、回头客排队拆穿造谣）；第 3 章收下千万诊金、核心铺面或合伙大单，引出更高层世家旧怨或商业对手。
- **循环节奏与章末断章**：高手流走「日常低调护短 ↔ 宴会/病房/拍卖会当众掉马」交替；日常流走「买菜算账/亲子暖萌 ↔ 手艺破圈/反杀眼红同行」。高频断章：① 豪门首富余光扫到垃圾桶里的旧木盒，骤然变色喝止；② 专家束手无策，主角推门而入；③ 萌娃一句话拆穿同行演戏，食客齐刷刷掏手机录屏；④ 仇家放封杀令，门外已停满省城贵客牌照车。
- **毒点红线**：① 禁把官场仕途、乡村打猎混塞本包；② 高手流禁藏底牌憋屈挨骂超两章；③ 日常流禁流水账记做菜进货而不连着账面收益或人情冲突。

## 3. 人物设计

- **主角反差与底线**：平时随和低调、爱惜羽毛，碰及妻女与生计底线立刻冷硬果决；高手绝不窝囊受气，日常主角精于算账不圣母，学霸科研线保持平淡克制、让权威替自己震惊。
- **反派梯队（势利务实、手握实权筹码）**：卡着婚约或房租的拜金岳家与黑心房东 → 懂断供冷链、联合同行压价的商界对手（会拿行业渠道施压，而非单纯骂街）→ 地方豪门与幕后财团。
- **关系与对话声线**：高手流口语短硬带压迫，大人物改口称呼干脆利落；日常流烟火气浓、亲子与死党对白鲜活克制，少用浮夸叹号。

## 4. 正文技巧

- **视角与切镜**：默认第三人称贴身主角限知；学霸科研与神医掉马高潮**善切权威教授或势利亲戚的旁观视角**当「翻译官」，用对方失态反衬主角平淡，零咆哮炸场。
- **对白短打与叙述呼吸**：对话干脆推进冲突，纯叙述保留主角算实账与拆局的口语因果，杜绝干硬分镜报幕与无脑炫富演讲。
- **刀子物件原则**：每场抓牢 1 件实打实改输赢的硬筹码（整层承租新约、论文草稿、真实诊单或孤品旧木盒），删去悬浮「百亿黑卡」「酒杯砸碎全场针落可闻」与无功能豪宅穿搭贴纸。
- ❌ 烂写法：`尤松随手甩出一张百亿黑卡，厉副总酒杯砸碎在地，全场针落可闻。`（悬浮塑料豪门）
- ✅ 高分改写法：`厉副总拿断供冷链威胁压价：“不按六折签，明天全市场没一家敢接你家菜！”尤松顺手把农贸市场整层承租新约转给他看：“厉总，原房东昨儿把整层转签给我了，你家档口租约还有三天到期，按原价续还是现在清场？”厉副总张嘴想拖，旁边几个商户已先围上来问尤松新租价。`

### 切片 A（都市日常 / 学霸科研）：权威教授双视角降维震撼

```text
李长青盯着那张纸，眼睛越睁越大。
他嘴唇无声地翕动，手指跟着纸上的箭头移动，突然猛地倒抽一口凉气：“曲率变量的补充……对啊！我怎么没想到用微分形式重新表述约束条件！”
张秉文则死死盯着右边那个构造思路，脸色从疑惑变成震惊，又从震惊变成狂喜。
“这个双曲旋转的构造……老天，这么简单！它完美避开了复杂的矩阵运算，直接生成反例！这、这简直……”
两人几乎同时抬头，灼热的目光钉在肖宿脸上。
“孩子，你叫什么名字？”李长青的声音因激动而发颤，“你……你怎么会想到这些？你看得懂这篇论文？”
肖宿这才抬起眼，目光平静：“没看过，引理3的漏洞很明显。三维能锁死的结构，四维多了一个活动维度，原证明强行忽略了这个自由度。”
```

- **学什么**：借两位教授惊骇反应当翻译官，少年平淡破题，零咆哮炸场。

### 切片 B（都市高手 / 归来反差）：豪门势利盘算与冷眼局

```text
就在两人愁眉不展时，叶家管家走了进来。
“老爷，楚少爷回来了。”
谢雨珊皱眉，“哪个楚少爷？”
叶天成也皱着眉，但紧接着似是想起什么。
管家解释道：“老爷，就是三年前那位入狱的叶楚少爷。”
两人一脸恍然，想起了叶楚是谁。
三年多没有出现，两人都快忘记还有这么个儿子了。
两人眼神齐齐一亮，谢雨珊笑道：“天成，咱们可以让叶楚入赘姜家。”
叶天成赞同点头，“很不错，劳改犯配植物人，天作之合。”
谢雨珊又有些担忧，“叶楚毕竟是私生子，还坐过牢，姜家那边会不会有意见？”
```

- **学什么**：用「劳改犯配植物人」冷血算计速立豪门嘴脸，为出狱反杀攒势。
