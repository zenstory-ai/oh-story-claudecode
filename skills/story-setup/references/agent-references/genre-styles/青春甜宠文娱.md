# 长篇题材包：青春甜宠文娱

> **核心卖点与底线**：主打正向治愈与明朗糖感（校园纯甜、娱乐圈恋综翻红与沙雕团宠），严守 HE 与虐不过夜、反低级雌竞，不靠狗血苦情注水。

## 1. 故事线设计

- **核心爽点路线**：看的就是「明朗轻快、甜而不腻、憋屈不过夜」——高冷学神唯独对她破例、全网黑艺人凭真性情在恋综翻红获顶流护短，或全员大佬装穷争宠的爆笑反差，一口接一口给足治愈甜与利落打脸。
- **三大主流写法**：
  - **校园 / 都市纯甜（例外偏爱 + 自我攻略）**：借强制同框或校园小物件和小契机（拼桌借伞、旧校卡、双暗恋错位搭子）拉扯；或社恐作精「保命式对你好」反被冷面男主温柔接住、自我攻略沦陷。
  - **娱乐圈 / 恋综实力翻红**：全网黑低开 → 直播间真性情反杀绿茶或专业惊艳 → 弹幕逆转热搜爆榜 → 顶流镜头前自然护短。
  - **沙雕反派家庭团宠**：远离偏心养家投奔表面穷苦实则全员大佬的亲生家庭，主打「对外狠戾、对内争宠」的轻喜反差。
- **分卷换地图与中后期防崩**：破冰试探 → 双向心动与实力掉马 → 公开偏爱破阻拦 → 圆满 HE，靠舞台学业推节奏不注水。

## 2. 常见剧情设计

### （一）黄金三章怎么写

- **第 1 章**
  - **路子一（校园高甜破例）**：切进雪天借伞、自习室拼桌或错拿校卡现场，高冷学神破例替她拎包递温饮；章末论坛偷拍贴刷爆高楼，室友冲门尖叫。
  - **路子二（恋综反杀 / 团宠开局）**：全网黑艺人空降恋综，两句吐槽把绿茶和副导的坑反扣回去，弹幕笑疯；或离养家投奔装穷大佬亲家，老爸一句反常识叮嘱炸出反差。
- **第 2 章**
  - **路子一（日常糖与自我攻略）**：借食堂并桌或「保命式讨好」撞出密集笑点与心动瞬间，冷面男主嘴上嫌麻烦却悄悄把例外全给了她。
  - **路子二（随机分组 / 家宴露馅）**：恋综抽签把她和顶流拴成搭档接梗默契；团宠「穷酸家宴」露出一角真豪门手笔，笑点期待齐足。
- **第 3 章**
  - **路子一（公开高光与七年伏笔）**：月考逆袭、才艺惊艳或口碑翻红冲热搜第一，男主镜头前护短；章末旧书滑出七年前旧照，埋双向暗恋长线。
  - **路子二（碾压养家与事业起飞）**：养家前任跑来羞辱落魄，当场被装穷亲哥买楼打脸，或被名导递来女一剧本，抛出事业冲顶期待。

### （二）常见剧情类型库

#### 第一组：校园纯甜与例外偏爱

1. **高冷学神破例偏爱引爆校园热帖**
   - **起局与赌注**：男主是生人勿近的学神，女主只当普通同学；雨天或寒夜偶遇，按常理他只会擦肩而过。
   - **铺垫与拉扯**：自习室占座、递伞或顺手接过她手里重物，男主一句情话没讲，动作却全是只给她的破例。

### （三）高频断章钩子

- 休息室直播麦忘了关，影帝把她挡门后哑声发问到底何时给名分。
- 对家刚发通稿吹内定女一，官博下一秒艾特女主官宣空降主演。
- 三哥刚电话哭穷吃泡面，挂断转身买下欺负妹妹的整栋写字楼。
- 旧笔记滑出七年前照片，背面工整写着她的名字日期。

- 绿茶笑递坑人任务卡，女主干脆接过反手抛出一句直球反问，直播间弹幕瞬间炸锅。

### （四）常见毒点 / 劝退点

- **违背 HE 与虐过夜**：严禁车祸失忆、真出轨、血海深仇或小误会拖十章，必须「虐不过夜」，一两章化为更浓的糖。
- **低级雌竞扯头花**：禁泼咖啡、抓头发、羞辱女配衬女主，善写清醒对账与女性互助。
- **文娱缺活人感**：综艺死板没真实接梗和热搜舆论反差，显得悬浮。
- **男主抢光女主主线**：女主沦为等砸钱解围的花瓶，丢掉学业或事业成长。

## 3. 人物设计

- **主角反差与底线**：女主明媚直球、有自己的学业或作品主线；男主带少年锐气或外冷内乖的醋意反差；团宠家人对外狠戾对内争宠。
- **反派梯队**：争镜头抢资源的绿茶女配与势利副导（善借剪辑与通稿抢先甩锅）→ 偏心势利的养父母与爱面子前任（前期高频打脸靶）。
- **关系拉扯与说话语气**：轻快俏皮、精准接梗，多用反问与短台词拉心跳感；前 3 章事业和甜度均衡推进（别只顾算账忘了发糖），娱乐圈善用爱歪楼、会玩梗的活人 `【弹幕】` 与校园热帖放大嗑糖气氛。

## 4. 正文技巧

- **野生弹幕与校园热帖**：善借热帖与 `【】` 弹幕放大反差，弹幕混入歪楼玩梗感，禁解说腔、替旁白译潜台词或套话起哄。
- **例外动作出糖**：靠轻巧问答与具体破例小动作出糖，不堆空话甜词；文娱制作与直播流程须合行业常理。
- **❌ 烂写法（油腻糖精 + 低级雌竞）**：`录恋综刚抽签，顶流程放满眼宠溺地盯着甘棠：“别怕，有我护着你。”女配杜安琪嫉妒得冲上来泼咖啡扯头发。`
- **✅ 高分改写法（松弛接梗 + 例外偏爱）**：`恋综直播间，杜安琪笑着把劈柴任务卡推过来：“甘棠平时在剧组肯定干惯杂活了吧？”弹幕刚冒嘲讽，甘棠接卡挑眉笑：“正好，省得你喊手疼拖进度。”镜头一转，少言顶流程放直接抽走半捆柴：“我搭档的活，不劳隔壁组操心。”【弹幕：卧槽他主动拎柴！】`

### 切片 A：沙雕反派家庭团宠（杀手老爸的反常识叮嘱）

```text
女孩‘诶’了一声，下意识仰头，一头小卷毛，可爱的要命，“会很久吗？”

再度说，“大概一个月时间。”
“你三哥这几天也会来家里住。”
“你……”提起三儿子，沈思行难得有些词穷，“尽量离他远点。”
沈衣恍然大悟：“因为三哥身体不好，所以怕我会伤害他吗？”

```

- **学什么**：小卷毛乖巧保证听哥哥话，爸爸却神色奇异地叫她别顺从，温情日常里藏着反派家族的反差萌。
