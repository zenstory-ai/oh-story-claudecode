# 长篇题材包：青春甜宠文娱

> **核心卖点与底线**：主打正向治愈与明朗糖感（校园纯甜、娱乐圈恋综翻红与沙雕团宠），严守 HE 与虐不过夜、反低级雌竞。

## 1. 故事线设计

- **三条高热主轴**：
  - **校园 / 都市纯甜（例外偏爱 + 自我攻略）**：借强制同框或校园小装置（同电量破冰、旧校卡、双暗恋错位搭子）展开拉扯；或恶女/社恐作精「保命式对你好」反被高智商冷面男主温柔接住并自我攻略沦陷。
  - **娱乐圈 / 恋综实力翻红**：全网黑低开 → 直播间真性情反杀绿茶或专业惊艳 → 弹幕逆转热搜爆榜 → 顶流镜头前自然护短。
  - **沙雕反派家庭团宠**：远离偏心养家投奔表面穷苦实则全员大佬的亲生家庭，靠「对外冷酷、对内争宠」制造轻喜温差。
- **卷级推进与防崩**：破冰试探（初遇、首期直播或刚进新家）→ 双向心动与实力掉马（情敌吃醋、事业爆火、旧家悔青肠）→ 公开偏爱与破除阻拦 → 圆满 HE。中后期靠舞台/学业/家庭身份逐层揭晓推节奏，绝不靠强行失忆或恶毒误会注水。

## 2. 常见剧情设计

- **黄金三章切口**：第 1 章直接切进高甜误会、恋综交锋或离豪门现场，快速进对白并给首颗反差糖或反杀小爽点，章末卡在男主破例、家人护短或弹幕炸屏；第 2 章借一顿饭、分组或团宠日常撞出高频笑点与糖点；第 3 章落地首个公开小高潮（才艺惊艳、月考逆袭或旧家找茬反被碾压），埋下「早暗恋她」或「家人藏身份」长线钩。
- **循环节奏与章末断章**：正向阶梯推高（**虐不过夜，误会 1–2 章内化成更浓的糖**），每 2–3 章至少一颗具体心动糖配一次事业或护短进展。高频断章：① 直播麦忘了关，影帝把人挡在门后低声问名分；② 情敌炫耀女一，导演官宣女主空降；③ 亲哥刚说家里穷，转身买下欺负妹妹的整栋写字楼；④ 女主翻出男主藏了七年的旧照。
- **毒点红线**：① **HE 铁律**，严禁车祸失忆、真出轨或恶毒第三方拖十章不解；② **反低级雌竞**：不靠泼咖啡扯头花或羞辱女配衬托女主，善写清醒对账与女性互助；③ 不写血海深仇毁掉明朗基调。

## 3. 人物设计

- **主角反差与底线**：女主明媚鲜活、嘴贫直球、有独立真本事；男主外冷内热、对旁人惜字如金唯独对她纵容低头；团宠家人主打「对外狠戾、对内争宠」的反差萌。
- **反派梯队（轻量有私心、不搞无脑送脸）**：争镜头抢资源的绿茶女配与势利副导（会借剪辑、通稿或规则先手甩锅）→ 偏心势利的养父母与爱面子前任（前期高频打脸靶）。
- **关系与对话声线**：轻快俏皮、精准接梗，多用反问、停顿与短台词拉心跳感；娱乐圈善用 `【弹幕】` 与校园吃瓜热帖放大嗑糖气氛。

## 4. 正文技巧

- **视角与切镜**：第三人称贴身女主限知，适当借校园论坛刷楼、直播间 `【弹幕】` 或旁观室友起哄切出外部吃瓜视角，轻快放大高冷男主反差。
- **对白短打与叙述呼吸**：靠轻巧问答与例外细节出糖，纯叙述保活人吐槽与口语因果，严禁「满眼宠溺」「心跳漏拍」等油腻空话与大声呐喊。
- **刀子物件原则**：心动瞬间只放大 1 个具体破例动作或物件（递温饮、偏伞挡风、副卡流水、任务卡、旧校卡），删掉无功能咖啡杯、衣饰材质与光影贴纸。
- ❌ 烂写法（低级雌竞）：`发现未婚夫给学妹杜安琪买包，甘棠冲进咖啡厅泼咖啡大骂绿茶，又扯袖哭求：“你爱过我吗？”`
- ✅ 高分改写法（清醒互助）：`甘棠把副卡消费流水推过桌面，指尖点在奢品店那行：“这只包刷的是我副卡，连他说的婚房首付，七成也是我家垫的。”杜安琪翻完聊天记录里伪造的单身证明，拿起笔刷刷签下证词，把包往中间一推：“走，挂二手平台变现，姐姐挑家贵的火锅店，烂黄瓜谁爱捡谁捡！”`

### 切片 A：沙雕反派家庭团宠（杀手老爸的反常识叮嘱）

```text
女孩‘诶’了一声，下意识仰头，一头小卷毛，可爱的要命，“会很久吗？”
沈思行心被击中了瞬，忍不住捏了捏她小脸蛋。
再度说，“大概一个月时间。”
“你三哥这几天也会来家里住。”
“你……”提起三儿子，沈思行难得有些词穷，“尽量离他远点。”
沈衣恍然大悟：“因为三哥身体不好，所以怕我会伤害他吗？”
“放心吧爸爸。”她连忙保证：“我一定乖乖的，听哥哥的话。”
“不。”沈思行低头直直望着她，略带几分奇异的神色，“你不需要乖乖的，更不需要顺从他、听他的话，小衣。”
```

- **学什么**：小卷毛乖巧保证听哥哥话，爸爸却眼神奇异地叫她别顺从，温情日常里藏反派家族的反差萌。
