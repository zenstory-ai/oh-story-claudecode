# 长篇题材包：历史架空 / 权谋军史 / 历史脑洞与谍战

> 穿越架空王朝、历史节点或民国谍战暗线，凭反骨掀桌胆魄、科技情报优势、天幕脑洞或深潜智谋绝境翻盘；底线是行军原料与程序严密、敌人不降智、朝堂文斗短台词见血。

## 1. 故事线设计

- **核心爽点**：绝不窝囊受气的当场掀桌爽 + 科技或情报优势碾压古人的智斗爽 + 帝王、权臣或敌酋自我脑补吓出冷汗的掌控感。
- **四大主流写法**：
  - **杀伐即刻掀桌型**：反骨主角绝不忍气吞声，恶兄欺仆、假道学亲爹设套或世家逼杀时当场翻脸算血账，先把血性和狠劲打出来，再入朝堂或军营争霸。
  - **历史脑洞 / 天幕 / 错位帝王系统**：空中光幕曝光历代真相（善用反系统推荐的高难选题把情绪拔高）、老迈帝王绑定幼崽成长系统造反差笑点，或一步步攀工业科技树让帝王将相集体重塑认知。
  - **朝堂老六要兵权与民生基建**：老六主角拿忠义大话反绑帝王要兵权要实职，写到百章靠宿敌事后复盘吓出冷汗保鲜；慢热长青路线则踏实写赋税户籍改革、铁匠铺基建与克制的居家烟火。
  - **民国 / 抗战谍战潜伏**：金手指必须压成弱辅助，绝不给超能武力、绝不让敌人降智；靠职业规矩打欲擒故纵（海关账目、双人签字、货单暗号留接头空窗），让多方阵营按利益理性互相试探。
- **换地图与中后期防崩**：按「绝境保命翻案 → 执掌一县 / 封地或潜伏站稳 → 朝堂清君侧 / 敌后大案反杀 → 拓土兴国或决战收网」稳步推开。卷内紧战事/政局（6–15 章）间必插 3–5 章封赏变现、工坊日常、练兵或损友互坑的换气养成段，忌连排同类朝斗；千万别前期升级太快（比如二十章就登基称帝），后面直接无戏可写。

## 2. 常见剧情设计

### （一）黄金三章怎么写
- **第 1 章**：**路子 A（古代绝境掀桌）**：直接扔进死局——忠烈孤子遭逼产退婚、庶子顶罪或皇子遭弹劾流放；三两笔立清朝局（禁史书科普），亮反杀实证与血性，卡圣旨突降或权贵压境。**路子 B（天幕 / 谍战撞密）**：光幕突现长安引发骇然，或沦陷区医院、海关撞见军火密单且敌特堵门，卡逼问或血字浮现。
- **第 2 章**：**路子 A（当殿反将 / 验账钉贪）**：靠当殿求死把皇帝架上火堆，或甩军饷花名册配税银封条逼知府画押，按翻中层对手赢侧目。**路子 B（职业边界反拿 / 奇物显威）**：谍战拿免责签字单或海关查验单反吓退敌特，基建线亮改良细盐或土火器震勋贵。
- **第 3 章**：**路子 A（拿实权切高位复盘）**：获兵符、盐铁契或县令实职，切帝王或奸相密室复盘吓出冷汗，开整卷大棋。**路子 B（稳潜伏 / 借天幕布局）**：将疑心引向敌副手打通上线，或借光幕风向抢结忠良改命。
- **节奏与痛感**：前 3 章每章只演透 1–2 场戏（2,200 字忌塞赶集）；立 1 个扎心委屈（如逼产打老仆）或掀桌高能画面，忌干算账。

### （二）常见剧情类型库（排大纲 / 细纲直接选用）

#### 一、开局起势与立威

1. **恶宗亲 / 奸佞逼产退婚、当场掀桌算血账**
   - 起局：穿成忠烈遗孤或庶子，恶族叔恶兄勾结恶仆逼签卖产文书、退婚并毒打老仆，欲吃干抹净。
   - 铺垫：恶兄假道学说代管家业，恶仆伸手抢地契与军功牌，宗亲冷眼看戏；主角冷问靠山绝不忍让。
   - 爆发：掀桌抄佩刀血溅当场，亮军功诰命与县衙贪墨把柄扭送府衙；切恶亲戚屁滚尿流、百姓叫好视角，立血性保家产。
   - 变体：每步卡「忠烈护遗」律条不落把柄；恶叔投靠知府把家仇升成官场博弈。

2. **当殿主动求死反将满朝文武**
   - 起局：奸相外戚齐奏贬主角为庶人流放，皇帝冷眼看戏借机敲打；顺着辩解必掉连环陷阱。
   - 铺垫：御史轮番扣罪，奸相暗喜胜券在握，宗亲低头叹气；主角一声不辩摘冠重重叩首。
   - 爆发：高呼罪孽深重求父皇即刻赐死，把冤杀忠良/亲子骂名架上龙椅；切满殿哑火、奸相僵脸视角，皇帝忌史笔改赐边关实职或封地。
   - 变体：退朝切皇帝与老太监密谈，点破皇帝看出做戏却更想借刀咬奸相，君臣博弈更深。

3. **验账查盐一纸钉死地方贪官**
   - 起局：新官上任一府，知府盐运使与豪绅拿旧例敷衍，企图把亏空烂账推给主角签字背锅。
   - 铺垫：接风宴塞银票试探，遭拒后搬京中靠山施压，认定寒门新官只敢睁眼闭眼。
   - 爆发：大堂不讲空话，推官盐折色册指朱批缺口与差银去向，摆好印泥逼选「今日画押补账还是明日递京」；切知府冷汗吐钱粮暗桩视角。
   - 变体：暗桩直指京中户部侍郎，主角留一半实证当护身符为进京埋线。

#### 二、中期核心大高潮与副本

4. **边军亮改良军械以少胜多、当场斩监军**
   - 起局：胡骑压境，奸党克扣粮饷并派监军掣肘，摆明借胡人坑死主角再定丧师罪。
   - 铺垫：军中士气低迷，监军扣求援军报；主角把攒齐硝石硫磺改良震天雷与连弩密运隘口，算轻骑脚程设伏。
   - 爆发：胡骑入狭谷划火折引爆震天雷、连弩齐发大捷；捷报入京皇帝端茶手抖，主角大营当众斩通敌监军立军威。
   - 变体：交代行军日程、火药来源与阴雨受潮局限经得起推敲；斩监军引朝堂风暴。

5. **朝堂老六拿忠义大话反绑帝王要兵权**
   - 起局：剿匪赈灾成烫手烂摊子，皇帝听挑拨甩给主角当弃子，既省心又耗其家底。
   - 铺垫：权臣假捧国之栋梁，皇帝画大饼却不提给兵给银，满朝暗笑主角倾家荡产。
   - 爆发：主角含泪表忠心，话锋一转当众要户部现银、调兵虎符与先斩后奏旗牌；皇帝保颜面咬牙全批，切宿敌复盘背脊发凉视角。
   - 变体：真把灾民安顿好、土匪剿净练出铁杆精兵，民心兵权双收让皇帝挑不出毛病。

6. **天幕曝光未来真相、君臣格局一夜剧变**
   - 起局：高空巨幕突现盘点后世功过或王朝隐秘，主角手握选题权或唯一听懂现代词借风向改命。
   - 铺垫：标榜忠义的权臣刚慷慨痛斥政敌，主角放弃平淡科普，反选最戳心窝的「十大隐秘背叛者」或「百年铁血山河」。
   - 爆发：光幕点名该权臣三年后谋反，或映出高产粮种与钢铁舰队；切满殿骇然、皇帝眼神骤冷、权臣跪地视角，朝局洗牌顺势除敌。
   - 变体：每次盘点直戳当下储位、兵权或边患痛点，让古人按真实性格滚出蝴蝶效应。

#### 三、节奏调剂与副线爽点

7. **攀工业科技树、奇物进献重塑古人认知**
   - 起局：执掌贫瘠封地遭勋贵嗤笑早晚饿死，主角从细盐提纯、土水泥、曲辕犁或肥皂起步攒家底。
   - 铺垫：老工匠质疑、勋贵看简陋窑炉大笑并封锁原料；主角蹲铁匠铺调炉温算损耗烧出成品。
   - 爆发：雪白细盐、坚硬水泥路或晶莹琉璃呈御案，世家瞬间红眼抢着捧金求入股分销；切帝王震动、国公低声求牌照视角，财源基建双收。
   - 变体：科技树循序渐进绝不三天手搓冲锋枪，新财源引窥伺倒逼同步练兵。

8. **谍战借职业边界欲擒故纵、稳住接头空窗**
   - 起局：敌特便衣强闯医院或海关，要带走术后联络员或翻绝密货箱；主角无超能力，硬拦暴露、放手害同志。
   - 铺垫：特务亮枪施压，便衣死盯微表情；主角摘血手套或合账本，神色冷淡公事公办。
   - 爆发：按规章递术后免责签字单或双人提单放话「签字人货带走，死伤少件概不负责」；敌特忌惮担责不敢轻动，主角稳出接头空窗并栽疑敌副手。
   - 变体：敌探长绝不降智，事后很快起疑却苦无实证，猫鼠试探窒息感贯穿全卷。

9. **错位帝王系统 / 铁匠铺民生烟火调剂节奏**
   - 起局：杀伐太紧时穿插轻喜或烟火副线——七旬老帝绑幼崽成长系统，或边帅微服蹲铁匠铺喝粗茶查户籍。
   - 铺垫：老帝憋老脸背三字经吓坏大太监；县令跟街坊唠家常算春耕，实则摸清恶绅欺民底细。
   - 爆发：老帝领良种强体丹震慑藩王，微服县令次日升堂端恶霸收万民伞；切朝局撞人情的反差感，缓节奏扎民心。
   - 变体：烟火日常顺手发掘忠心民间神匠或老账房，纳入后期核心班底。

#### 四、换地图与中后期破局

10. **清君侧 / 敌后连环假情报反杀大案**
    - 起局：携封地实力回京或潜入敌伪中高层，面对奸相派或老辣特高课，硬拼伤亡大须内部瓦解。
    - 铺垫：摸清敌方争功旧隙，用缴获密电码与真假书信分别投喂敌方两实权派，自己退幕后当透明人。
    - 爆发：奸相与大将、或站长与宪兵队顺「严丝合缝」实证血腥内斗，主角趁两败俱伤亮铁证收网；切敌酋临灭盯破译密电冷汗湿背视角。
    - 变体：机警敌副官临死传半句预警露出一角马甲，倒逼主角抢先决战。

11. **封地变强藩或决战收网、迫最高权势重坐谈判桌**
    - 起局：中后期手握铁血边军、粮仓火器或地下网，老帝联合旧世家外敌设削藩死局，或敌国倾巢压境一战定生死。
    - 铺垫：满朝观望交权还是谋反；主角不急称帝，先稳民心粮道再把精锐无声开赴京郊或边关要冲。
    - 爆发：亮百姓请愿与权臣通敌铁证，不流多余血逼老帝与敌使重坐谈判桌签新律新政；切顶级权贵俯首、盛世开启的厚重格局。
    - 变体：收网时让老仆、铁匠、老兵与同志各有交代，托住全书血性大义。

### （三）高频断章钩子
- **火器发威**：漫山胡骑压到坡下，主角面无表情划亮火折子凑向震天雷引线。
- **天幕点名**：光幕渗出血字点名殿上高谈忠义的开国功臣三年后谋反，满殿鸦雀无声。
- **御案惊茶**：八百里边关捷报递上御案，皇帝扫完第一行，端茶的手猛地一抖。
- **谍战反咬**：老辣探长死盯截获的密码电文，脸色越冷，目光缓缓转向身旁副手。
- **掀桌求死**：奸相奏请贬庶人流放，主角叩首大喝：「儿臣罪该万死，求父皇赐死！」
- **账册亮刀**：知府拿旧例敷衍，主角合上兵部勘合，把拆开的税银封条推到他鼻尖底下。

### （四）常见毒点 / 劝退点
- **前期升级过快**：二十章拜相、五十章登基，中后期直接失去权谋博弈空间。
- **朝堂变掉书袋**：把句句见血的短台词交锋写成大段背史书、搬现代名词演讲。
- **全员降智衬主角**：帝王昏庸、奸相草包、敌特瞎眼，智斗像欺负傻子。
- **硬伤穿帮串味**：行军脚程、硝石来源胡编，或同章串名、抗战谍战写串成宅斗。
- **史书灌水烂梗**：开篇贴大段地理年号表或滥用「大脑寄存处」，首章劝退。

## 3. 人物设计

- **主角人设与底线**：表面纨绔、落魄或温良守规矩，骨子里杀伐果断、懂算政治大账；对忠良袍泽护短重义，对奸佞贪官和汉奸斩草除根，绝不圣母手软。
- **反派梯队**：每层反派都要按真实利益和权谋逻辑行动，绝不做无脑送脸的工具人反派。
  - **初阶**：贪婪宗亲、恶仆县令、疑心重的底层特务——懂得拿律法条文、盘查程序和人情规矩卡死主角。
  - **中阶**：骄横勋贵、克扣军饷的监军、敌伪情报站长——有派系靠山，输了一局还能反咬一口。
  - **高阶**：权倾朝野的奸相、老谋深算的帝王、胡虏可汗与敌方最高情报头子——真正能跟主角棋逢对手。
- **配角与说话语气**：台词半白半古、铿锵短促，别堆生僻文言，也别蹦现代网络热词出戏；谍战台词要冷峻克制、字字藏双关，让人听出弦外之音。主角留点小毛病与吐槽欲，配 1 个油滑老仆或毒舌幕僚当活宝调剂，避免全员板脸背书。

## 4. 正文技巧

- **视角与震惊视角**：默认跟着第三人称主角视角写，权谋和谍战最出彩的写法是「整段切到反派、帝王或敌酋的视角」，看着聪明对手顺着主角留的线索一步步理性脑补、把自己吓出一身冷汗，压迫感和爽感都极强。
- **对话与叙述写法**：朝堂文斗与审讯走短对话快推、句句见血，少塞拂袖、冷笑之类多余动作；长篇叙述 1–3 句自然成段与短句/对白错落呼吸，动作和台词分行；叙述带出筹码盘算与口语转折，谍战潜伏写透心理博弈，**禁每场危机成串刷「背脊一凉/倒吸冷气/心里咯噔」生理模板**。行军脚程、硝石来源、银两加减守恒、墨迹干涸与民国药械/日军编制地名断代（1939 写磺胺/奎宁忌早刷盘尼西林，撬痕封签同源）必验。
- **关键道具与实证**：只细写军饷花名册、兵部勘合、密电底稿、税银封条这类能直接改局的实证（举例物件每次另起新物件，别照抄模具）；砍家具材质、庭院空景，但留住立活人、出轻喜的烟火细节；盐政军械术语翻成大白话。
- **❌ 烂写法**：`他引经据典讲了三百字明朝盐法制度，又喊出“王侯将相宁有种乎”，满堂文官震惊跪服。`
- **✅ 高分改写法**：`韩伯庸把州府盐课折色册往樊知府案前一推，指节敲在朱批缺口上：“去岁官盐少报三万引，差银全进了盐运司私库。”樊知府茶盏微晃，韩伯庸已掏出印泥放好：“大人，这笔亏空您现在画押补账，还是我明日递京？”`

## 5. 案例片段

### 切片 A（抗战谍战）：职业边界欲擒故纵

```text
“谁是家属？”
“我！我兄弟怎么样了？”一个满脸横肉、穿着灰色长衫的中年男人立刻上前。
林言扫了他一眼，目光掠过对方腰间不自然的隆起，又瞥见走廊里或站或坐、同样装束的另外七个人。
党务调查处。
他们连装都懒得装了。
“命保住了。”林言语气平淡，“识字吗？这里有一份术后注意事项，看完签字。之后若因你们照看不周导致伤势恶化，医院概不负责。”
男人一把抓过那张纸，扫了两眼，勃然变色：
“不能随意移动？那他妈不就是得在你们这儿躺着？老子今天偏要带他走！”
“请便。”林言脱下沾血的手套，递给一旁的护士，“签完字，人你就可以带走。他的死活，与我无关。”
说完，他转身就走。
这叫欲擒故纵。
你越拦，他们越疑心。
你放手，他们反而不敢动了。
```
- **学什么**：拿外科医生冷漠公事公办的规矩打欲擒故纵，不跟特务硬碰硬，几句话反向抓回主动权；忌照搬末尾三句旁白裁判总结。

### 切片 B（朝堂老六权谋）：当殿主动求死镇群臣

```text
云铮将这帮混蛋记在心中的小本本上，又向文帝躬身，大声道：“儿臣自知罪孽深重，请父皇赐罪！”
“赐罪？”
文帝眼中寒芒闪烁，“那你倒是说说，你该当何罪？”
“死罪！”
云铮不假思索，躬身道：“求父皇赐儿臣一死！”
轰！
随着云铮的话音落下，殿内顿时鸦雀无声……
赐死？
云铮竟然主动要求文帝将他赐死？
这是把脑袋吓坏了吧？
所有人的脑袋发懵的看着云铮。
谁都没想到，云铮竟然开口就是求死。
连徐实甫和淑妃兄妹俩都被彻底搞懵了。
```
- **学什么**：反派齐奏贬庶人，老六皇子掀桌求赐死，反常理重注打乱满朝节奏；忌照搬「顿时鸦雀无声」与连串围观补白。
