# 长篇题材包：官场仕途 / 商战做局与职场升迁

> 在体制基层或商场低谷遭排挤背锅，靠识人站队、危机处置、程序博弈与信息差做局步步突围；底线是公私红线清、职务层级准、合规合法把对手将死。

## 1. 故事线设计

- **核心爽点主轴**：听得懂人情世故与潜台词的智商爽 + 「小人物精准押对领导或风口、当众抢下关键岗位或标书」的翻身爽 + 走程序按规矩把对手将死的痛快。
- **双轨核心引擎**：
  - **仕途破局流**：`四重绝境叠满（靠山骤调/停职/情变/信访）或隐匿高层渊源/绝活的先倨后恭开局 → 守公私红线、拒接烂摊子先逼对手吐筹码再救场 → 用硬核群众工作法或真政绩赢上级青眼 → 抢缺提拔、借酒桌政治学破局`。
  - **商战职场流**：`被抢功踢局、底层隐忍取证摸清利益网，或重生年代白手起家 → 凭产业风口、专利卡脖子或资本反做空在竞标会、董事会翻盘`（年代商战前期可用扎实家庭救赎与人情立住人物）。
- **卷级升级与中后期防崩**：乡镇/科员或部门主管（破冰拿首个实权位）→ 县区/地市或区域掌舵（主导大项目、清地方利益链）→ 省部级棋局或行业资本巨头（定规则、成支柱）。每升一级须换更复杂的派系利益均衡，严防爽点降格成低级扯皮。

## 2. 常见剧情设计

- **黄金三章切口**：
  - **第 1 章**：极速切入高危局面（领导落马被隔离问话、功劳被抢面临下放、女友上岸提分手同时遭人下绊子、公司资金链明天断裂），开口即锋利对话交锋，当章抛出出人意料的筹码或破局判断稳住局势，章末卡在对手变色或高层留意。
  - **第 2 章**：第一轮实操落地，在会议室、调研现场或谈判桌上借程序规则与硬数据反将一军，让准备拿捏主角的中层主管当场下不来台。
  - **第 3 章**：拿到第一份实质跃迁（调任关键岗位、拿下首单大合同、搭上重量级贵人线），同时亮出把主角当挡路石的更高层派系对手。
- **卷内博弈与高频断章**：按 `岗位空缺/大单竞标 → 对手用关系压人设陷阱 → 摸清利益链找准靠山与硬数据 → 公开场合合规反杀 → 提拔扩盘落袋 → 新地盘迎来更大派系博弈` 推进。高频章末断章：① 审查组长刚拍桌威吓，主角报出录像或原始账本；② 常委会表决前，上级一通意外电话打到一把手桌上；③ 对手拆开标书，核心条款竟分毫不差；④ 提拔公示贴出，旧上司呆立原地。
- **核心毒点雷区**：① 防标签漂移——挂官场却前三十章纯写彩票泡妞不入体制；② 禁硬塞叮咚系统、靠拳脚解决体制商战难题，也禁抄公文开会流水账；③ 禁把上级写成傻白甜或纯脸谱反派。

## 3. 人物设计

- **主角人设与底线**：表面沉稳谦和、懂礼数守规矩，骨子里极度清醒狠辣；看得清谁是真靠山、谁在画大饼，绝不在情绪上吃闷亏，动手走程序、留证据、一击必中。
- **反派梯队（各自私心与有效反制）**：抢功甩锅的股长/部门总监（借参谋名义摸底、卡审批拖延，绝非无脑咆哮）→ 勾结地头蛇的副职领导/黑心竞争对手（用人脉封杀与程序挑刺反咬）→ 地方利益集团与资本寡头（懂政绩与大局权衡）。
- **关系张力与说话声口**：句句藏机锋、表面客气内里见血，多用短问句敲打和留白试探，少喊空口号；官场称呼、职务层级与商战账目务必准确自然。

## 4. 正文技巧

- **视角与潜台词交锋**：默认第三人称贴身限知，必要时独立切镜展露上级权衡或对手惊疑；对话净白短打、藏锋留白，纯叙述保留主角对人情站队与筹码交换的口语盘算（因为/偏偏/怪不得/说白了），忌抽干内心写成干硬会议纪要。
- **专属场景技法**：博弈必落「公私红线 + 筹码交换 + 合规程序」；善写酒桌政治学（让主位、敬酒顺位、酒过三巡摊牌），杜绝悬浮喊口号。
- **刀子物件原则**：只细写验收表、签字栏、原始账本、标书底价与红蓝铅笔批注等改局实证；严禁堆砌茶盏材质、西装熨帖、玻璃幕墙与咖啡机嗡鸣等无功能闲笔贴纸，亦禁反复刷「拍了拍/跳了一下」。
- **❌ 烂写法**：`彭远拍案怒吼：“你们官官相护，我今天就要替老百姓讨个公道！”领导羞愧低头。`
- **✅ 高分改写法**：`彭远没跟人争辩，只把村级水利验收表摊在会议桌正中，拿红蓝铅笔在三处虚报管径上重重划了圈：“廖科长，市水利局明天上午下来抽查，这几段水泥管现场一量就穿帮。您看这签字栏是您补签担责，还是我照实填了往上报？”`

## 5. 案例片段

### 切片 A：官场隔离审查 · 极低感叹反将一军

```text
“你确定要知道他们的名字？”
宋思铭笑了。
“当然！”
王振回答得毫不犹豫，这可是立功的大好机会。
“那我就不卖关子了。”
宋思铭清了清嗓子，郑重其事地说道：“那个女人名叫陈秋霞，至于他丈夫，正是现任青山市纪委副书记，王振！”
王振的表情瞬间僵住。
愣了足足有十秒钟，王振“腾”地站了起来，“宋思铭，你不要血口喷人！”
“我血口喷人？”
“你打电话问问你老婆，就知道我是不是血口喷人了。”
“当了十年的监察一室主任，突然就成副书记了，你真以为是自己干得好？错，是你老婆干得好！”
```
- **学什么**：顺着对手邀功贪心步步递饵，报出名字后用十秒停顿与职位年限补刀，审讯弱势瞬间反客为主。

### 切片 B：职场博弈 · 探口风电话将计就计反套筹码

```text
他直接接通，电话里响起了曹强的笑声：“林超啊，方案策划得怎么样了，要不把初稿发过来，我帮你参谋一下？”
林超刚想答应，可是想起刚才那条短信，林超心思一转，顿时明白，曹秃头明显是来打听他工作进度的，要是知道自己已经做好策划方案，这次就算收回了狗牙，以后肯定还不会放过自己，不如趁这一次机会，狠狠捅他一刀！
所以话到嘴边又改了口，叹息一声说道：
“曹部长，怪不得张组长几次策划效果都不好，我现在才明白，这事太难搞了，到现在还没一点头绪，要不你帮我出个主意？”
“你可是我们市场部的金牌策划师，让我给你出主意，这不是开玩笑嘛！”曹强呵呵笑着说道：“我相信你的能力，努力加油哟！”
“曹部长，不过我这一次万一要做出来了，你准备给我什么奖励？”林超眼珠一转，就像开玩笑一样，问了一句。
```
- **学什么**：看穿上司借「参谋」摸底的算盘，话到嘴边临时转弯装难示弱，反手用玩笑口吻套住公开奖励筹码。
