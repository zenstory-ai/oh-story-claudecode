# 长篇题材包：官场仕途 / 商战做局与职场升迁

> 在体制基层或商场低谷遭排挤背锅，靠识人站队、危机处置、程序博弈与信息差做局步步突围；底线是公私红线清、职务层级准、合规合法把对手将死。

## 1. 故事线设计

- **核心爽点**：听得懂人情世故和潜台词的智商爽 + 「小人物精准押对领导或产业风口、当众抢下关键岗位或大标书」的翻身爽 + 走正规程序、按明面规矩把对手将死的痛快。
- **两大主流写法**：
  - **仕途破局流**：多重现实危机叠加开局（如靠山调离叠加问责背锅或基层突发危机），或隐匿高层渊源与独门绝活走先倨后恭路线；死守公私红线，遇到烂摊子绝不傻接，先逼对手吐出筹码再出手救场，凭扎实群众工作和真政绩赢取上级青眼，抢缺提拔、借酒桌政治学步步破局。
  - **商战职场流**：被上司抢功踢出局后隐忍取证摸清利益网，或重生回年代风口白手起家；靠产业趋势、核心专利卡脖子或资本反做空，在竞标会与董事会上掀翻对手（年代商战前期善用扎实的家庭救赎与真挚人情打底，让读者先爱上主角）。
- **换地图与中后期防崩**：按「乡镇 / 科员或部门主管（破冰拿到第一个实权位）→ 县区 / 地市或区域掌舵（主导大项目、清理地方利益链）→ 省部级棋局或行业资本巨头（制定规则、成为支柱）」逐卷升级。每升一级都要换成更复杂的派系利益均衡，绝不能升到高层还写低级办公室扯皮。

## 2. 常见剧情设计

### 黄金三章怎么写
- **第 1 章（两条开局）**：
  - *体制四重绝境*：靠山调离、隔离问话背锅、女友上岸分手叠加基层信访，开口即锋利潜台词；当章抛留痕底牌或人名，章末卡审查者变色。
  - *职场抢功 / 商战危机*：心血方案被截胡临裁员，或重生回资金链断档前夜；看穿探口风将计就计，章末卡对手踩圈套。
- **第 2 章（会议与现场反制）**：
  - *合规将死小人*：拿拨款审批单、审计底稿与明文规矩，会议室让拿捏主角的中层下不来台。
  - *救火入高层眼*：接手烂摊子三步稳局或递硬核调研数据，赢得大领导青眼。
- **第 3 章（破格提拔与派系大局）**：
  - *抢缺提拔 / 签大标*：任前公示贴出或竞标定音，拿首实权位或大标，旧上司前任呆立当场。
  - *高层对手浮出*：触动地方利益网或行业寡头蛋糕，饭局人事会亮杀招，整卷铺开。

### 常见剧情类型库（排大纲 / 细纲直接挑选组合）

#### 一、开局起势与立威

1. **隔离问责背锅、凭原始留痕反将一军**
   - **起局与赌注**：靠山变动或项目出事，调查组副手扣住主角拍桌逼签字背锅，签字即仕途断送甚至担责。
   - **铺垫与拉扯**：对方软硬兼施画饼施压，料定基层不敢顶嘴；主角不争态度，只平淡核对签批流转链与经手人留痕。
   - **爆发与爽点落地**：当场亮出合规留档或原始签批记录，把违规源头直接指回副手所在阵营；对方瞬间僵住反客为主，主角脱身并反握筹码。
   - **防俗变体与承接**：副手强压慌乱休会急电幕后靠山，主角刚出门接高层试探来电。

2. **上司试探抢功、留痕反套公开承诺**
   - **起局与赌注**：核心方案或大单将成，惯于抢功的上司假借把关名义摸底，企图截胡成果换亲信署名；硬顶得罪上司，交出白干一场。
   - **铺垫与拉扯**：主角识破意图不露锋芒，顺着装难示弱把难题抛回对方，借势当着众人或工作群套出奖惩与晋升条件。
   - **爆发与爽点落地**：上司笃定啃不下来随口立下公开承诺；例会或高层复盘时主角直接亮出完整成稿与客户意向，逼上司骑虎难下当场兑现。
   - **防俗变体与承接**：升职后部长把最难啃的欠款僵尸大客户塞给主角，引出下场硬仗。

3. **工程验收抽查逼贪官签字担责**
   - **起局与赌注**：水利修路偷工减料，科长拿「顾大局」逼新来主角签造假验收表背锅，硬吵即被边缘化。
   - **铺垫与拉扯**：施工方塞信封被拒，科长拍桌训斥老油条装哑；主角不喊口号，拎卷尺亲自下村量现场拍照留证。
   - **爆发与爽点落地**：碰头会摊开原始实测台账标出虚报缺口，点明上级明早抽查必穿帮，请科长在「补签担责」与「照实上报」间二选一；科长冷汗认栽返工。
   - **防俗变体与承接**：施工方背后连分管副职干股，一纸复核单撕开地方利益链。

#### 二、中期核心大高潮与硬仗

4. **竞标泄密做局坑杀内鬼与同行**
   - **起局与赌注**：开标前夜察觉副手被同行买通卖底价，临时改方案来不及，落败即现金流断档。
   - **铺垫与拉扯**：按兵不动故意透低于成本线的假底价，暗签上游稀缺原料独家锁价协议；对手得意递标看笑话。
   - **爆发与爽点落地**：对手低一丝中标欲庆祝，主角递原料涨价公函——履约要赔半家公司、弃标扣保证金进黑名单；清内鬼并低价并购对手渠道。
   - **防俗变体与承接**：内鬼咬出幕后牵头的是盯上专利的省城资本大鳄，战场升级。

5. **危机救火立功常委会逆转提拔**
   - **起局与赌注**：实权位空缺，对手欲发配主角冷衙门，表决前三天辖区爆欠薪信访，对手扣锅给主角。
   - **铺垫与拉扯**：旧上司假安慰，对手暗拖拨款等闹大；主角扎现场理台账，合规连夜查封企业隐匿资产协调垫付，两天平息。
   - **爆发与爽点落地**：表决前五分钟红色座机骤响，上级点名表扬；次日公示首行惊呆旧上司对手，实现逆风跳级提拔。
   - **防俗变体与承接**：查封流水现给市常委亲属输血暗账，新官上任即踩暗流。

6. **暗查假账工程链扳倒地头蛇靠山**
   - **起局与赌注**：推实事处处卡壳，背后是盘踞十几年副职与地头蛇把持，无铁证动不得，打草惊蛇反遭做局。
   - **铺垫与拉扯**：对手激怒主角，主角反笑脸放缓改革，暗从退税单安置名册切入，借审计轮查拼齐七家空壳假账。
   - **爆发与爽点落地**：联席会对手正发难罢免，主角亮股权图、原始转账流水与录音笔；纪检当场带人，切靠山瘫坐椅背，连根拔毒瘤。
   - **防俗变体与承接**：旧势力垮留一堆烂摊子，主角扛整顿大旗立稳威信。

#### 三、节奏调剂与副线爽点

7. **酒局看座次听潜台词递调研破冰**
   - **起局与赌注**：考察审批前饭局，竞争对手挤包厢，资历浅的主角被按门边末位，失声即成背景板。
   - **铺垫与拉扯**：对手抢敬酒挤兑不懂世故；主角少言观察主陪座次微调与领导随口问话，听出真正头疼的小微电费卡点。
   - **爆发与爽点落地**：酒过三巡趁走廊透气两分钟递三页一手电价减负调研；散局大领导点名交督办专班，切对手端杯愣住。
   - **防俗变体与承接**：领导赏识同时敲打「步子稳别抓小辫」，显高层平衡预警举报。

8. **空降遭派系架空借力收服老油条**
   - **起局与赌注**：空降新部门，老油条科长早被对头打招呼，卡文件推诿企图逼成光杆请辞。
   - **铺垫与拉扯**：副手装病、科员丢台账，对头等发火；主角连夜摸清老油条私心软肋——谁卡职称、谁干实活被抢功。
   - **爆发与爽点落地**：跳过装病副手提拔受压骨干主持急活、批盼五年评优，收回副手肥差预算集体审；三天老油条排队汇报，切对头架空失灵反丢班底。
   - **防俗变体与承接**：刻意留一名精明副手专去对接难缠外部门，真实立得住。

#### 四、换地图与中后期破局

9. **价格战断供借专利标准商战翻盘**
   - **起局与赌注**：实业刚冒头遭行业巨头腰斩价倾销、逼上游断供加银行抽贷，眼看撑不过发薪日。
   - **铺垫与拉扯**：高管劝认输，巨头论坛嘲笑活不过本季；主角抓对方低价货能耗超标，抵押联高校抢注省能耗工艺专利，绑二线代工。
   - **爆发与爽点落地**：行业新节能准入标准公示，专利成必过门槛；峰会公开授权价，巨头满仓成废品反爆资金链，切董事长登门求授权。
   - **防俗变体与承接**：海外跨国资本随即盯上核心技术，发起国际专利诉讼。

10. **调任烂摊子新区抢下省里大项目**
    - **起局与赌注**：升迁换地图被政敌塞进全省垫底债台高筑问题新区当主官，明升暗降欲困死三五年。
    - **铺垫与拉扯**：财政发不出薪，大厂拿搬厂威胁，省里十亿新能源大单被三富裕地市盯着；主角挖冷门矿运与政策洼地，携分厘成本表游说省厅。
    - **爆发与爽点落地**：评审会富裕地市放花哨宣传片，主角亮铁路专线协议、当天拿地开工承诺与环保投名状；专家倒戈十亿爆冷花落新区，政敌摔杯。
    - **防俗变体与承接**：大项目落地引各方资本派系分羹，高层博弈顺势铺开。

11. **省部级大局或董事会合规摊牌**
    - **起局与赌注**：步入省部棋局或千亿董事会摊牌，寡头派系借改革阻力与金融做空发难，欲踢主角出核心层。
    - **铺垫与拉扯**：对手握舆论、做空资金与投票权，元老观望；主角把数卷民生政绩、上下游盟友与无瑕合规底账逐一落子。
    - **爆发与爽点落地**：终局摊牌弹劾做空被反制条款与国家政策击穿，元老倒向；按章程程序落槌，对手出局落马，主角稳坐全局新台阶。
    - **防俗变体与承接**：巅峰后不喊口号，收在老茶馆听百姓一句「这两年日子敞亮了」，余味十足。

### 高频断章钩子
- 审查组长拍桌威吓，主角平静抽出录音笔与泛黄原始账本。
- 常委会举手前一秒，一把手桌上红色座机骤然铃响。
- 对手竞标会得意拆标，脸色刷白——核心报价分毫不差。
- 任前公示贴出，昔日旧上司盯着首行名字僵在原地。
- 散场大领导走廊叫住末位主角：「明早八点，来我办公室。」
- 董事会弹劾刚过半，大门推开，缺席二股东拄拐笑走进来。

### 常见毒点 / 劝退点
- **跑偏不进体制**：挂官场仕途前三十章全写赌石泡妞不干正事。
- **硬塞系统或拳脚**：拿叮咚系统或打架解体制商战，毁现实厚重感。
- **抄公文开会流水账**：照抄空洞纪要，主角拍桌怒吼领导羞愧低头。
- **上级反派降智**：高层写傻白甜，老狐狸写成办公室咆哮蠢货。
- **常识层级乱编**：职务级别、部门职能、礼仪或财务招标常识出错。

## 3. 人物设计

- **主角人设与底线**：表面沉稳谦和、懂礼数守规矩，骨子里极度清醒狠辣；一眼看清谁是真靠山、谁在画大饼，绝不在情绪上吃闷亏，动起手来死守合规程序、提前留证据，不出手则已，一出手必把对手钉死。
- **反派梯队**：
  - **初阶**：抢功甩锅的股长、部门总监——擅长假借统筹把关名义抢功摸底、卡审批流程拖死你，表面笑呵呵背后下绊子。
  - **中阶**：勾结地头蛇的副职领导、黑心同行——懂用圈子人脉封杀，擅长在合规程序里挑刺反咬一口。
  - **高阶**：盘踞一方的利益集团、资本寡头——真正懂政绩交换与大局权衡的顶级对手。
- **配角与说话语气**：对话句句藏机锋，表面客气周全、内里字字见血，多用短问句敲打和留白试探，少喊假大空口号；官场称呼、职务层级与商战账目必须准确自然。

## 4. 正文技巧

- **专属场景与博弈视角**：所有博弈落到「公私红线、筹码交换、合规程序」三件事；关键处可经独立场景切大领导利害权衡或对手起疑视角，善写酒桌顺位与留白试探，杜绝拍桌喊口号。
- **体制与财经常识**：职务层级配置、任免审计流程、招投标底价与拨款审批等实务须严谨合常理。
- **❌ 烂写法**：`彭远拍案怒吼：“你们官官相护，我今天就要替老百姓讨个公道！”领导羞愧低头。`
- **✅ 高分改写法**：`彭远没跟人争辩，只把村级水利验收表摊在会议桌正中，拿红蓝铅笔在三处虚报管径上重重划了圈：“廖科长，市水利局明天上午下来抽查，这几段水泥管现场一量就穿帮。您看这签字栏是您补签担责，还是我照实填了往上报？”`

## 5. 案例片段

### 切片 A：官场隔离审查 · 不动声色反将一军

```text
“你确定要知道他们的名字？”
宋思铭笑了。
“当然！”
王振回答得毫不犹豫，这可是立功的大好机会。
“那我就不卖关子了。”
宋思铭清了清嗓子，郑重其事地说道：“那个女人名叫陈秋霞，至于他丈夫，正是现任青山市纪委副书记，王振！”
王振的表情瞬间僵住。
愣了足足有十秒钟，王振“腾”地站了起来，“宋思铭，你不要血口喷人！”
“我血口喷人？”
“你打电话问问你老婆，就知道我是不是血口喷人了。”
“当了十年的监察一室主任，突然就成副书记了，你真以为是自己干得好？错，是你老婆干得好！”
```
- **学什么**：顺着对手想立功的贪心一步步递饵，报出名字后用足足十秒僵住再拿职位年限补刀，审讯弱势瞬间反客为主。

```text
他直接接通，电话里响起了曹强的笑声：“林超啊，方案策划得怎么样了，要不把初稿发过来，我帮你参谋一下？”

所以话到嘴边又改了口，叹息一声说道：
“曹部长，怪不得张组长几次策划效果都不好，我现在才明白，这事太难搞了，到现在还没一点头绪，要不你帮我出个主意？”
“你可是我们市场部的金牌策划师，让我给你出主意，这不是开玩笑嘛！”曹强呵呵笑着说道：“我相信你的能力，努力加油哟！”
```
