# 长篇题材包：悬疑灵异 / 民俗怪谈与推理破案

> 长篇唯一放开使用「公平线索回溯」「剥洋葱多层反转」「冷静报告腔」与「细思极恐留白」的专属题材；底线是绝不对读者撒谎、关键线索提前露面、禁天降神兵与无意义血浆堆砌。

## 1. 故事线设计

- **核心爽点**：「差一秒就要出事」的窒息压迫感 + 「原来前面全埋好了伏笔」的剥洋葱智力快感 + 破戒恶人遭报或真凶伏法的解气感。
- **三大主流写法**：
  - **民俗 / 灵异规则**：先亮清楚老行当的核心铁规，再让贪财或不信邪的蠢人破戒，异象一步步应验，主角翻旧账查清源头，最后卡准时辰（子时、头七、鸡鸣）破局；现代公门驱邪善用现实里的穷困挫败、地方方言烟火气和毒舌搭档调剂气氛，避免全篇沉闷。
  - **女频无 CP 悬疑脑洞 / 灵异直播**：坚持真惊悚底色（深夜门禁、密室尸案），警方必须保持专业与合理怀疑（会反查主角消息来源，绝不把警察写成盲信主角的工具人），再用轻巧的生活反差冲淡压抑，在闲常细节里翻出凶案铁证。
  - **公平推理 / 规则怪谈**：先抛出一个看似不可能的诡异细节，让主角或警方推出一个看似合理的假结论，再用前面埋下的小物证（门禁记录、钥匙划痕、习惯动作）一举掀翻假底，一层层剥出幕后黑手；硬核法医线则先用尸检体征数据坐实人为作案，再切进超自然规则。
- **换地图与中后期防崩**：走单元奇案串联，底层用跨卷暗线（至亲失踪、十年旧案或邪教）串起拼图，忌一卷乱换怪物废掉铁规。

## 2. 常见剧情设计

### 黄金三章怎么写
- **第 1 章（两条开局）**：
  - *日常现诡证*：从夜班、戏台或停电医院切入（禁堆阴森空景），速抛违背常识的铁证（挂号单现已故病人名、门禁多刷卡），章末卡熟人微笑说出瘆人实话。
  - *铁规遭破戒*：亮清走阴抬棺几条死规矩，雇主出高价隐瞒实情甚至当场违规，退路封死，章末卡首个异象准点应验。
- **第 2 章（砸假底压窒息）**：
  - *假底先立再塌*：主角或警方先推出合理意外结论，刚松半口气，第二条死证或监控盲区砸碎假底。
  - *异象逐条逼近*：贪财配角连踩雷，井水变味敲门踩点逼近，主角从异常看出人为手脚。
- **第 3 章（职业破局勾暗网）**：
  - *卡时辰 / 物证反杀*：凭民俗行规、法医体征或前文小物证锁死首个破绽脱险擒凶。
  - *旧账引主线*：结案翻出与十年前至亲失踪同款暗记，不降智冷面刑警盯上主角。

### 常见剧情类型库（排大纲 / 细纲直接挑选组合）

#### 一、开局破冰与立威

1. **民俗行规破戒与异象应验**
   - **起局与赌注**：接老宅守灵或夜台唱戏高价单，明示核心铁规（子时不回头、不碰陪葬器、敲门不答）；雇主隐瞒横死真相，破戒即陪命。
   - **铺垫与拉扯**：贪财亲戚笑主角装神弄鬼，半夜偷供桌铜钱或撬棺；烛火转绿、狗群哑声、屋檐异响按规矩逐条应验，退路全断。
   - **爆发与爽点落地**：破戒者涕泪求救，主角踩子时三刻封门稳阵，拿沾煞赃物作饵引开邪祟；切嚣张雇主跪地磕头，尾款翻倍。
   - **防俗变体与承接**：破戒者实为筹重病医药费铤而走险，供出背后教唆的阴行同行。

2. **深夜值班签字本现已故之人**
   - **起局与赌注**：夜班值守、医院或停尸间照常交接，登记簿或门禁日志偏偏冒出绝不可能出现的人名，查不清下个出事就是主角。
   - **铺垫与拉扯**：搭档随口夸字迹工整；主角合本轻声点破此人上周已身亡下葬，空气骤冷。
   - **爆发与爽点落地**：主角不尖叫，倒查门禁时间差与监控盲区，顺现场遗留痕迹揪出冒名顶替者或隐藏证物；切搭档毛骨悚然的惊悚反应。
   - **防俗变体与承接**：抓完借死人身份掩凶的活人，回头见纸页上死人本尊笔迹真多了一笔。

3. **真假熟人渗透试探与破绽反杀**
   - **起局与赌注**：封闭空间或深夜独处时，身边至亲、室友或搭档出现细微反常，一旦顺着应答或开门放行便会触死规。
   - **铺垫与拉扯**：对方言行亲切熟稔却总绕开关键细节，越像熟人越让人背脊发凉；主角不动声色，故意抛出一条编造的旧事试探。
   - **爆发与爽点落地**：对方竟顺口接住「假记忆」瞬间露馅；主角趁其未发难前卡死规则或封锁退路反杀逃生。
   - **防俗变体与承接**：识破替身后不动声色周旋，借机摸清真家人被关押的暗处地点。

#### 二、中期核心大高潮与破局

4. **法医物证推翻完美不在场证明**
   - **起局与赌注**：密室案头号嫌疑人有监控证人担保，警方险些结案放人；放走不仅真凶逍遥，今晚再死一人。
   - **铺垫与拉扯**：嫌疑人审讯室喝茶讥讽警方、律师施压道歉；主角复盘前文露面的鞋底石灰、读卡器两分钟误差、尸斑时间差与左手握杯。
   - **爆发与爽点落地**：放人前摊开尸检报告与物证袋，拆穿监控系预录替身影像；切嫌疑人端茶手僵防线崩溃，撬出神秘中间人。
   - **防俗变体与承接**：认罪却冷笑自己只是「收尾七号」，留一句精准预言拉出更大连环案。

5. **规则怪谈找矛盾卡出真生路**
   - **起局与赌注**：误入诡异动物园、夜班公交或公寓，七条保命纸条藏两条矛盾且背面有指甲涂改痕，信错即成怪物口粮。
   - **铺垫与拉扯**：自大同伴盲信字面还想阴主角抢名额；主角靠墙钟停点、胸牌颜色等物理细节低成本试错，筛出假守则。
   - **爆发与爽点落地**：午夜同伴陷死局，主角借真规则反制怪物，大步走进「禁入」真安全屋并借管理员反杀恶毒同伴；切同伴惊恐瞪眼，带走信物。
   - **防俗变体与承接**：信物背面刻着下处怪谈门牌号，把零散怪谈串成严密世界观。

6. **老宅古墓连环机关与内鬼现形**
   - **起局与赌注**：深山古宅或水下地宫，雇主请来各路行家，刚进二道门机关频发，每死一人都在替队里内鬼清障。
   - **铺垫与拉扯**：最老实向导或老教授频荐「稳妥近路」；主角对墓砖风化与罗盘微偏识破全是杀局，顺势配合并暗调压石记号。
   - **爆发与爽点落地**：主墓石门落下，内鬼撕脸抢冥器欲毒杀全队；主角按暗扣让内鬼踩进自设翻板陷坑；切余众改听号令，起出古籍真相。
   - **防俗变体与承接**：打开主棺里面躺的不是古人，而是失踪多年当代同行，手里死攥主角旧照。

   - **防俗变体与承接**：警方拉警戒线，从直播无意扫到的一只旧鞋直接破获五年失踪悬案。

   - **防俗变体与承接**：搭档笔记本角落仍记主角疑点，为后期立场撕裂埋足张力。

### 高频断章钩子
- 监控放大角落，空无一人的玻璃倒影多出一张冲镜头笑的脸。
- 昨夜锁进证物柜的旧木梳，次日一早齐整摆在主角枕边。
- 翻开急诊体温表或尸检报告尾页，赫然出现最信任熟人笔迹。
- 热心邻居走进暗巷，路灯打墙上，他的影子却原地没动。
- 嫌疑人听完时间线轻笑：「你真以为，刚才进门的法医是老陈？」
- 泛黄旧档滑出合照，站在凶手身旁勾肩搭背的竟是主角自己。

### 常见毒点 / 劝退点
- **天降神兵背刺**：结局空降零铺垫凶手或法宝，毁掉公平推理体验。
- **规则朝令夕改**：一卷乱换七八种新怪物，随手扔掉定死的行规守则。
- **廉价血浆硬吓**：泼血浆残肢硬凑恐怖，掉价又易踩审核红线。
- **警方工具人化**：把警察写成盲信玄学、全靠嘴炮破案的降智配角。

## 3. 人物设计

- **主角人设与底线**：民俗与刑侦线主角极度冷静、观察入微、死守行规（主角越沉得住气，周围的诡异就越瘆人）；悬疑脑洞线主角外松内敏，搭档一位不降智的冷面刑警或法医，两人形成温差互补。
- **反派梯队**：
  - **初阶**：贪财破戒的雇主或蠢人——为了私利隐瞒关键时间线，无意间把主角往死路上带。
  - **中阶**：藏在熟人圈里的真凶、会伪装家常话的邪祟——懂做不在场证明，擅长拿亲情和秘密诱人破戒。
  - **高阶**：操控连环旧案的幕后黑手、邪派掌舵人——深藏暗处，每起单元案都只是他棋盘上的一颗子。
- **配角与说话语气**：整体克制平实、信息密度高、短句多；行家告诫永远留半句让人心里发毛，邪祟开口越像过日子拉家常越让人起鸡皮疙瘩；若定了具体地域，可偶用易懂的乡土口语给街坊老行家添烟火气，防写成标准播音腔。

## 4. 正文技巧

- **视角与公平反转四条**：民俗恐怖常用第一人称增代入，推理与脑洞多用第三人称跟主角写。写反转守死四条底线：① 不对读者撒谎（误导只靠视角局限或真动作套假原因）；② 摊牌只收旧账（关键物证提前露过面且名字一致）；③ 假结论先促成行动再推翻，忌空口猜完即否；④ 干扰线索顺手带出真支线或隐情。
- **对话与叙述写法**：推理氛围章对话可少，叙述带推演因果禁流水账；对质与盘问拆成一问一答逐条抛物证；时间线、物理与安防常识必验。
- **关键道具与实证**：只细写门禁记录、挂号单、体温表、钥匙划痕这类前后呼应的伏笔物证。
- **❌ 烂写法**：`走廊里阴风阵阵，我吓得尖叫起来：“啊！有鬼啊！这里太恐怖了！”`
- **✅ 高分改写法**：`保安室日光灯嗡嗡发响，我把值班签字本翻回昨夜那一页，指尖按在还没卷边的纸角上：“老周，昨夜替我盯后门监控的是谁？”老周凑过来看了一眼，手里的保温杯晃出几滴茶水：“这不是老侯亲笔签的名么，墨迹都干透了。”我慢慢合上本子，声音发轻：“可后勤处三天前就贴了通知，老侯上周五已经办完退休回老家了。”`

```text
“我扒着门缝往外看，就看见一个红影站在你家店门口，头发很长，遮着脸，看不清模样。我喊了一声，她就飘着走了。没错，是飘着的！”
```
- **学什么**：弄堂里拉到角落压低声音，配上吴语「哈宁」的真实市井气，慢节奏敲门最后收在「没错，是飘着的」，寒意一层层往上漫。

### 切片 B：规则怪谈压迫（凌晨假奶奶诱开门）

```text
半夜，敲门声将她吵醒。
苏青鱼睁开眼睛，低声道：“双喜，你在吗？”
“主人，我在的。”双喜的声音传来，“现在是凌晨一点十五分。”
门是反锁的，卧室暂时安全。
苏青鱼听那敲门声，不做任何回应。
“好孙女，开开门，我是奶奶……咔咔咔……我知道你没有睡着，要不要来阳台和奶奶谈谈心？奶奶有好东西要给你看……咔咔咔……”
“咚咚咚——”敲门声持续着。
门外那东西，绝对不是白天的奶奶。
“开门呀，不要躲着奶奶，……再不开门，奶奶就把你的秘密告诉爸爸妈妈……咔咔咔……奶奶知道，你房间里偷偷养了只猫……”
```
- **学什么**：只隔一道反锁房门，精确点出凌晨一点十五分，配上「咔咔咔」的怪响和熟人口吻拿秘密威胁，一滴血不写也能逼出窒息感。
