# 长篇题材包：悬疑灵异 / 民俗怪谈与推理破案

> 长篇唯一授权使用「公平线索回溯」「剥洋葱多层反转」「冷静报告腔」与「细思极恐留白」的专属题材；底线是绝不对读者撒谎、线索提前露面、禁机械降神与无意义血浆堆砌。

## 1. 故事线设计

- **核心爽点主轴**：「差一秒出事」的窒息压迫感 + 「前文全埋好了」的剥洋葱智力快感 + 破戒恶人遭报或真凶伏法的解气。
- **三轨引擎选型**：
  - **民俗 / 灵异规则**：`行当铁规矩（3 条明示禁忌）→ 蠢人破戒 → 异象渐进应验 → 翻旧账查源头 → 卡时辰（子时/头七/鸡鸣）破局`；现代公门驱邪善用现实挫败、地域方言烟火与毒舌搭档泄压。
  - **女频无 CP 悬疑脑洞 / 灵异直播**：`真惊悚底色（深夜门禁/密室尸案）+ 警方合理怀疑不降智（反查主角信息来源，不写工具人警察）+ 轻巧反差冲淡沉闷`，在日常闲处翻出凶案实锤。
  - **公平推理 / 规则怪谈**：`不可能细节落地 → 假结论自圆其说 → 微物证（读卡日志/鞋底石灰/习惯动作）掀翻假底 → 剥洋葱揪出幕后黑手`；硬核法医线先用物理医学参数证死人为，再切超自然规则。
- **卷级升级与中后期防崩**：单元奇案串联（每 8–15 章结一案），底层由跨卷暗线（失踪至亲、十年旧案或源头组织）串起，每结一案撕开一块主线拼图；绝不一卷换八种怪物作废既定铁规。

## 2. 常见剧情设计

- **黄金三章切口**：
  - **第 1 章**：首段直砸「正常日常 + 不可能的诡异细节」或「行当铁规 + 违规一单」（散场戏台收到亡故班主点戏单、停电夜门禁凭空多出刷卡），速立悚然钩子，绝不堆阴森环境废话；章末卡在首个无法解释的异象或熟人名字。
  - **第 2 章**：展开首轮查证或规矩应验（破戒者出事、证人口径诡异一致），把第一个「合理解释」当场砸碎。
  - **第 3 章**：主角凭职业本事（民俗行规、物证比对）锁死首个破绽化险为夷，同时发现诡事直指身世或更大暗网。
- **卷内博弈与高频断章**：按 `异常入局 → 查证碰壁/口径矛盾 → 假底成立（松半拍）→ 微物证反杀翻盘 → 凶手破防/邪祟伏诛 → 留下指向旧案的新疑点` 推进。高频章末断章：① 监控或旧照角落多出不该存在的脸；② 刚锁进证物柜的东西换了位置；③ 签字本或尸检报告出现熟人名字；④ 热心熟人转身，影子却没动。
- **核心毒点雷区**：① 严禁机械降神（结尾空降未铺垫凶手或法宝）；② 严禁一卷频换怪物作废铁规；③ 严禁无意义血浆堆砌；④ 番茄女频无 CP 探案须简介首行标 `【无CP】` 对冲父标签。

## 3. 人物设计

- **主角人设与底线**：民俗与刑侦线极度冷静、观察入微、恪守行规（人越稳越衬得诡异瘆人）；脑洞线外松内敏，搭档冷面刑警或法医形成温差互补。
- **反派梯队（各自私心与有效反制）**：贪财破戒的蠢人（因利益隐瞒关键时间线误导查案）→ 藏在熟人里的真凶或伪装邪祟（善做不在场证明、用家常话诱人破戒，绝不傻愣自爆）→ 操控连环旧案的幕后黑手。
- **关系张力与说话声口**：克制平实、信息密度高、短句多；行家告诫留半句，邪祟开口越家常越让人发凉，弄堂烟火与方言细节极易拉满代入感。

## 4. 正文技巧

- **视角与公平反转四条**：民俗恐怖常用第一人称亲历，推理与脑洞多用第三人称限知；严守公平反转四条——① 绝不对读者撒谎（误导来自视角局限或真动作套假原因）；② 摊牌只收旧账（微物证摊牌前须露过面、名称前后统一）；③ 假底先促成行动再被推翻；④ 红鲱鱼须带出真支线。
- **叙述呼吸与对白短打**：推理与氛围章允许偏低对话，但纯叙述须保留主角推演盘算与口语因果，禁抽干思绪写成冷硬摄像头报幕；对白克制短打，留白收拍。
- **刀子物件原则**：只细写值班签字本、精确时刻、异常声响、鞋底石灰等可回溯物证；严禁堆砌「阴风阵阵/走廊灯光惨白」空景废话，亦禁以「呼吸一滞/脊背发凉」生理套反应替代具体物证与时间差。
- **❌ 烂写法**：`走廊里阴风阵阵，我吓得尖叫起来：“啊！有鬼啊！这里太恐怖了！”`
- **✅ 高分改写法**：`保安室日光灯嗡嗡发响，我把值班签字本翻回昨夜那一页，指尖按在还没卷边的纸角上：“老周，昨夜替我盯后门监控的是谁？”老周凑过来看了一眼，手里的保温杯晃出几滴茶水：“这不是老侯亲笔签的名么，墨迹都干透了。”我慢慢合上本子，声音发轻：“可后勤处三天前就贴了通知，老侯上周五已经办完退休回老家了。”`

## 5. 案例片段

### 切片 A：民俗弄堂怪谈（方言压低声音讲半夜红衣敲门）

```text
“张阿姨，你发现爷爷的时候，店里有没有什么异常？”
张阿姨眼神闪烁了一下，左右看了看，拉着钟默走到店门口的角落，压低声音说：
“小默，有些话我不知道该不该说......你爷爷走之前那几晚，弄堂里好多人都听见了，有个穿红衣服的女人，天天半夜来敲你家店门。”
“红衣女人？”
钟默瞳孔一缩。
“是啊，穿得一身红，看着就哈宁。”
“那几天夜里，我起夜的时候总能听见‘咚咚咚’的敲门声，敲得很慢，很有节奏。”
“我扒着门缝往外看，就看见一个红影站在你家店门口，头发很长，遮着脸，看不清模样。我喊了一声，她就飘着走了。没错，是飘着的！”
```

- **学什么**：弄堂压低声音配吴语“哈宁”落地烟火，慢节奏敲门收在“是飘着的”，寒意递进。

### 切片 B：规则怪谈压迫（凌晨假奶奶诱开门）

```text
半夜，敲门声将她吵醒。
苏青鱼睁开眼睛，低声道：“双喜，你在吗？”
“主人，我在的。”双喜的声音传来，“现在是凌晨一点十五分。”
门是反锁的，卧室暂时安全。
苏青鱼听那敲门声，不做任何回应。
“好孙女，开开门，我是奶奶……咔咔咔……我知道你没有睡着，要不要来阳台和奶奶谈谈心？奶奶有好东西要给你看……咔咔咔……”
“咚咚咚——”敲门声持续着。
门外那东西，绝对不是白天的奶奶。
“开门呀，不要躲着奶奶，……再不开门，奶奶就把你的秘密告诉爸爸妈妈……咔咔咔……奶奶知道，你房间里偷偷养了只猫……”
```

- **学什么**：反锁一门之隔，精准时刻加“咔咔咔”怪响与熟人秘密威胁，无血浆拉满窒息感。
