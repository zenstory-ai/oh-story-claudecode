# 长篇题材包：女频末世天灾囤货

> **核心卖点与分流**：专攻女频重生囤货、多轮天灾、居家美食反差、无 CP 双女主基建及星际向哨/未来科幻；男频战力与规则副本用 `末世规则科幻.md`。

## 1. 故事线设计

- **核心爽点路线**：看的不是男频升级打丧尸，而是「倒计时买空冷库超市的安全感」+「窗外零下四十度暴雪、屋里暖气吃羊排火锅的极致反差」+「白眼狼跪门外讨饭却被掐断对讲机的解气感」。
- **四大主流写法**：
  - **倒计时狂囤 + 精准验真双女主**：变现房产退婚追债狂囤衣食医油与防爆改装；无 CP 双女主可用「一小时后盛夏降雪」等精准预言验真，拉过命闺蜜合体扫货。
  - **多轮天灾 + 雇团队建城基建**：极寒 → 洪涝 → 极热 → 酸雨接力；中后期跳出单人囤货上限，雇工程、农学与安保团队建基地护城，匿名易物换硬通货。
  - **领地种田 / 空间通末世**：天灾后期藏锋借势拿下低污染宝地开荒；或现代空间连通末世以食药换黄金双线暴富。
  - **女频星际向哨 / 未来科幻**：穿成低级向导遭压制或流放荒星，借精神海疏导破狂化危机，与高冷哨兵强强互托、零低级雌竞。
- **分卷换地图与中后期防崩**：变现狂囤建安全屋或荒星脱险 → 极寒反杀白眼狼 → 灾变建基地或星际破局 → 灾后安居。

## 2. 常见剧情设计

### （一）黄金三章怎么写

- **第 1 章**
  - **路子一（重生倒计时变现）**：切前世冻死惨局，回灾前七天速开空间、退婚卖房逼渣前任吐首付；章末百万货款到账，推开冷库或改装车行大门。
  - **路子二（双女主验真 / 星际向哨）**：双女主拿「一小时后盛夏降冰雹」验真，拉闺蜜合体扫货；星际向哨切低级向导发配荒星，高阶哨兵狂化逼近红线闯门。
- **第 2 章**
  - **路子一（实数狂囤筑安全屋）**：按吨按箱囤现炖牛腩、五百袋大米、退烧药、女性用品、柴油机与防爆门（忌光列采购清单），顺手给极品埋烂坑。
  - **路子二（改装越野 / 首轮疏导）**：落地载具与安全屋暗防改装；向哨线稳住狂化哨兵，对方嘴硬立旗放狠话，埋下日后真香反差。
- **第 3 章**
  - **路子一（灾前嘲讽暴雪骤降）**：安全屋与太阳能板完工，渣前任嘲笑她发疯；章末警报拉响，盛夏骤降暴雪或黑雨。
  - **路子二（首灾反差空间进阶）**：封城断水电业主群哀嚎，女主吹暖气吃火锅；章末空间黑土冒活水泉，抛长期自给盼头。

## 4. 正文技巧

- **室内外反差与群压迫**：每轮新灾必写「窗外酷烈 ↔ 室内暖食」反差，善借业主群短消息推进楼栋恐慌。
- **实数囤货与空间上限**：囤货与求生交涉落到实在计量与门道（斤两箱数、保暖供能配置、向哨指标）；空间容量、取用限制与灾前变现工期须前后一致，避免物资凭空无限膨胀。
- **❌ 烂写法（错套男频壳）**：`极寒降临，宁霜觉醒 SSS 级冰系异能，一拳轰碎十米冰墙，系统喊：“战力暴涨十万点！”她杀去北方基地称王称霸。`
- **✅ 高分改写法**：`零下四十二度，宁霜刚夹起一筷子涮羊肉，防盗门外砸得震天响。对讲屏里贪心表哥嘶喊：“宁霜快开门！一家人你还看我们冻死？把大米分我一半！”宁霜吹了吹碗面热气：“上月催我还房款时您说跟我断得干干净净，可别为半袋米折了骨气。”她啪地掐断电源，转身从空间摸出颗冰镇荔枝慢慢吃。`

### 切片 A：末世前车行改装（加固越野与百万预算盘算）

```text
末世之后虽然是零元购的天堂，但是大多数的车子都是没有进行过改装的，更何况大部分车进口国内都会进行一些功能上的阉割版，去4S店一百万远远不够，但是去二手车行就不一定了。
顾瓷一到车行，车行老板迎了上来，“小姑娘要修车啊？”
顾瓷摇头，“我想买台越野，价格在50万左右，车架还有车身做加固。”
“这是要改装车啊？”老板有些惊讶，“这可是要报备的。”
顾瓷微笑，“当然，下个星期就去报备。所以你们这里有这种车吗？”
“有一辆，”老板皱起了眉，“但是价格可能比你预期的要贵点，阿尔法罗密欧Stelvio售价一百万，改装费也是不小一笔钱，保守估计也是十万起步。”
```

- **学什么**：从「进口阉割」「车架车身加固」「报备」到一百万售价加十万改装费，用行话和实数写出末世囤货的踏实安全感。
