# 长篇题材包：年代种田经商

> **核心卖点与分流（仅古代，文件名系历史兼容）**：专攻古代抄家流放、荒年逃荒、分家立户、美食经商与农门基建；六七八零年代军婚用 `女频年代军婚.md`，男频赶山打猎用 `男频年代乡村.md`。

## 1. 故事线设计

- **核心爽点路线**：古代种田经商最抓人的，是「啃野菜 → 吃杂粮 → 炖大肉 → 置红契良田、盖青砖瓦房」的踏实致富感，配上全家齐心不内耗的暖意，以及把吸血宗族和仇家馋哭踩死的解气感。
- **两大主流写法**：
  - **抄家流放 / 荒年逃荒 / 反夺空间**：大旱断粮或满门流放北疆，写全家零内耗极寒互助（挡风刨冻土分食）；或土著重生反夺仇敌空间连夜搬空库房再体面流放，路上炖肉气哭仇家官差，落户改良农具建富庶坞堡。
  - **农门断亲 / 破窑带崽美食经商**：偏心宗族逼卖妹或吃绝户，可借官府分户律例反制极品；出户后靠采草药、橡子凉粉与秘制酱料攒铜钱，盘铺子签酒楼供货契。
- **分卷换地图与中后期防崩**：分家逃荒活命 → 县城盘铺置红契 → 跨州府建作坊赈粮立功。

## 2. 常见剧情设计

### （一）黄金三章怎么写

- **第 1 章**
  - **路子一（农门分家）**：直接切荒年卖女、伯母抢粮或吃绝户现场，女主不哭求宗族，搬本朝律例请里正作保逼出红手印分家文书；章末离老宅摸到溪坡草药或破窑。
  - **路子二（抄家流放）**：卡抄家前夜或重生反夺空间，连夜搬空仇家贪墨私库与自家暗窖；章末戴枷上路，仇家笑她必死北疆，她摸着满仓物资冷定。
- **第 2 章**
  - **路子一（首口热食进账）**：山坡采野生药材换米或卖橡子凉粉，点两步去涩窍门，热食飘香数进第一把铜钱，馋哭隔壁极品。
  - **路子二（流放炖肉收心）**：大雪破庙遭恶差克扣干粮，女主支锅炖肉偏分讲规矩的领队一碗热汤；官差倒戈护着，仇家啃霉馍馋红眼。
- **第 3 章**
  - **路子一（立威护财签单）**：族亲地痞抢钱袋偷方子，女主亮官契加护短帮手镇场，酒楼管事捧定银签供货契，抛买荒地盼头。
  - **路子二（逃荒破局立威）**：荒路断水或恶差设伏，女主实用土法找水净水或抓恶差把柄挣话语权，抛北疆建坞堡盼头。

### （二）常见剧情类型库

#### 第一组：分家断亲与护财立威

1. **红手印分家文书反杀抢钱**
   - **起局与赌注**：码头早市刚收二百文，大伯母带壮汉抢钱袋拿孝道压人，想把女主当长期血包；今天退一文，往后赚多少都得被吸干。
   - **铺垫与拉扯**：路人指点，大伯母坐地哭嚎不孝，壮汉趁乱掀摊抢钱罐，憋屈顶脑门。
   - **爆发与爽点落地**：女主抖开里正红手印官契，点破本朝律例抢分户孤女钱须受官罚，护短男主提柴刀立定；酒楼管事恰好捧五十两定银迎签契，气疯极品。
   - **防俗变体与承接**：叫差役备案逼老宅领头人画押永不滋扰；定银顺势切进县城供货线。

2. **私逐未过户反逼极品交重税**
   - **起局与赌注**：老宅赶人图省事未报官过户，收税日爷奶还想把丁税摊派给女主，等看她交不起税被抓抵债。
   - **铺垫与拉扯**：前夜二房媳妇登门嘲讽，税吏敲锣进村时老宅抱臂站门外看笑话，全村替她捏汗。
   - **爆发与爽点落地**：官府户籍仍按同户核产，女主干脆报出老宅地窖余粮与私房田亩；税吏把重税单直接拍到老宅门板，爷奶嚎哭跳脚。
   - **防俗变体与承接**：借官府律例坑回极品比骂街解气；事后立正式红契官户彻底断攀扯。

3. **偷方仿冒砸招牌的反手做局**
   - **起局与赌注**：女主秘制卤味卖爆，恶邻半夜偷看配料花老本在隔壁开山寨摊降价抢客，妄图挤垮生计。
   - **铺垫与拉扯**：头两天贪便宜熟客流失大半，恶邻敲锣炫耀，弟妹急坏，女主却照常熬汤。
   - **爆发与爽点落地**：对方漏掉去涩火候，第三天卤味发酸发苦，食客吃坏肚子砸摊退钱；女主推试吃新品客人全涌回还涨价，恶邻赔光家底。
   - **防俗变体与承接**：提前故意漏少一味料的假方子送对方入坑；县城大商号主动递合作帖。

#### 第二组：流放逃荒与绝境活命

4. **抄家前夜搬空仇家暗库**
   - **起局与赌注**：满门遭诬流放，仇家独吞家产买通差役要他们死在半道；女主趁圣旨将落最后半宿孤注一掷，输了全家冻饿死北疆。
   - **铺垫与拉扯**：仇家正堂摆酒巡夜严密，女主先收空自家暗窖，再摸进仇家赃银军粮密室，巡卫脚步擦门而过。
   - **爆发与爽点落地**：一夜搬空数十年赃银粮草棉衣只留石头；次日官兵扑空还撞破仇家藏禁物遭弹劾，女主一家满仓底气体面登程。
   - **防俗变体与承接**：专搬脏库并留贪墨账册在明面，让仇家自顾不暇无力半道派杀手。

5. **流放路上炖肉收买官差**
   - **起局与赌注**：北疆风雪断粮，仇家买通副头目克扣水食、关烂柴房，想生生冻病老弱。
   - **铺垫与拉扯**：连赶三日风雪，仇家亲眷捧热茶耀武扬威，副头目把霉馍扔进雪泥羞辱众人。
   - **爆发与爽点落地**：破庙支锅炖滚烫大肉，女主不理哀求仇家，只给讲规矩有老母的领队盛大海碗热汤并塞寒腿草药；领队倒戈喝止副头目，赶仇家啃冰碴。
   - **防俗变体与承接**：不砸金银，改抓领队孝心与寒腿痛点收心；到边疆还帮挑肥沃荒地。

6. **荒旱土法找水净水惊动流民**
   - **起局与赌注**：大旱逃荒断水多日，官驿存水被权贵霸占，流民红眼眼看哗变。
   - **铺垫与拉扯**：女主看植被辨水脉带家人挖沙找水，旁人笑她发疯，挖出浑浊泥水仍遭嗤笑喝不得。
   - **爆发与爽点落地**：架炭灰细沙简易滤桶澄出清冽甘水，流民与差役瞬间改观尊为领头人，权贵被迫让出落脚院。
   - **防俗变体与承接**：不凭空变水，写实辨水脉与炭沙过滤两步土法，顺势引出边疆改农具线。

#### 第三组：种田开荒与美食经商

7. **买荒坡遭群嘲，头茬菜引抢货**
   - **起局与赌注**：女主低价买十亩盐碱荒坡办红契，族叔和村妇笑掉大牙，赌她秋后赔光哭回老宅借粮。
   - **铺垫与拉扯**：寒冬全村地光秃，女主全家筛草木灰、堆肥搭油纸暖棚，外人嘲笑声越传越响。
   - **爆发与爽点落地**：腊月绿菜贵过猪肉，头茬反季青菜出棚，大酒楼掌柜驾三辆马车堵地头加价包圆现付银锭；极品照搬冻烂地里，女主盖青砖大瓦房。
   - **防俗变体与承接**：只点草木灰改碱与暖棚两窍门，放大抢货反差；名声顺势传进州府。

8. **摆摊攒铜钱到盘铺立字号**
   - **起局与赌注**：早市常遇地痞，女主攒钱去牙行盘铺，好门面却被恶商抬价垄断，牙人领看漏雨死角废铺想骗定银。
   - **铺垫与拉扯**：恶商正街开大食肆放话挤死野摊，女主本钱吃紧，牙人劝她回码头蹲街口。
   - **爆发与爽点落地**：女主低价买带水井的偏巷旧铺，开业在正街派试吃小碗并卖干料包；食客顺香排满窄巷，恶商门可罗雀，女主挂匾立字号。
   - **防俗变体与承接**：不靠贵人白送铺，靠偏巷省租加试吃引流破局，顺势引出建作坊线。

9. **寒门采药压掌柜，顺手救贵人**
   - **起局与赌注**：荒年断粮，女主带弟妹山坡采野生药材进药堂换粮，势利掌柜把上等货压三成贱价想白捡便宜。
   - **铺垫与拉扯**：掌柜冷脸轰人、伙计嘲讽，弟妹攥空粮袋红眼，路人都觉这亏吃定了。
   - **爆发与爽点落地**：女主当众拆解炮制成色并点破药堂掺次货，转身要去州府分号；里间重伤边军将领高价包圆，女主又凭土方止血稳伤，赚厚利加救命人情。
   - **防俗变体与承接**：靠懂行话掀底牌赢高价；贵人不包办一切，留作跨州府与边疆硬门路。

#### 第四组：基建升级与灾年封赏

10. **边疆荒原筑坞堡，改农具立威**
    - **起局与赌注**：落户北疆苦寒荒原，官府只发钝锄烂种，冬春缺粮还遭马匪劫掠，流户撑不过头年便溃散。
    - **铺垫与拉扯**：流户各自为政有人偷菜苗，马匪探子摸村口放狠话，人心惶惶随时散伙。
    - **爆发与爽点落地**：女主立出工分粮铁规，改曲辕犁、搭水车、烧青砖筑箭楼坞堡；马匪夜袭跌陷马坑挨滚油溃逃，边军上报，流民奉她为主心骨。
    - **防俗变体与承接**：写实分粮规矩与一砖一瓦，不搞现代城；坞堡富庶后供军需也招贪官觊觎。

11. **荒年赈粮砸穿黑市，送免税牌**
    - **起局与赌注**：大灾颗粒无收，恶商勾结县丞囤粮抬天价，断女主作坊原料逼交秘方地契，全县濒临断粮。
    - **铺垫与拉扯**：县丞查封铺子，恶商守高价粮冷笑等她求饶，街头饥民怨气冲天。
    - **爆发与爽点落地**：女主密状递巡按，城门口开仓放出高产余粮平价限购砸崩黑市；巡按锁拿贪官恶商，县衙敲锣送御赐赏银与免税大匾，作坊跨州府通行。
    - **防俗变体与承接**：平价限购兼以工代赈修渠，不散尽家财当圣母，保本还赢免税金招牌。

### （四）常见毒点 / 劝退点

- **空间变无限印钞机**：挥手变十万斤精白米、现代零食，三天成首富，毁掉踏实攒家业感。
- **古今穿帮**：禁粮票、供销社、缝纫机、现代电商、**公制单位（米/公斤）**与现代网络词出戏。
- **心软贴补吸血族亲**：分完家又给极品送粮送银，极劝退。
- **写成枯燥农技百科**：大段抄种植公式，忘了吃肉攒钱和踩死极品。
- **自家人没完内耗**：家人扯后腿吵架，或极品几十章只会原地撒泼。

## 3. 人物设计

- **主角反差与底线**：女主泼辣务实会算账，绝不向吸血族亲心软贴补；男主可写踏实护短的农门帮手或落难贵人（亦可无 CP）。
- **反派梯队**：借孝道宗族压人抢粮的伯母族老 → 偷配方抢生意的恶邻与恶商 → 贪墨赈灾粮的县丞与地方豪绅。
- **关系拉扯与说话语气**：地道古代市井白话（文钱、吊、两银子、粗面馍、红契、里正、牙行、茶棚），带真实铜钱物价烟火气。

## 4. 正文技巧

- **烟火围观反应**：热食出锅、开荒见效或集市抢购时，借乡邻、官差或掌柜三两句直白惊呼放大解气感。
- **土法窍门与物价落地**：靠真实物价和生活变化落爽感（野菜糊 → 杂粮饭 → 炖肉 → 青砖瓦房加红契）；手艺变现点出关键土法窍门（去涩、过滤、发酵等）即止，不写长篇农技说明。
- **❌ 烂写法（失真悬浮）**：`戚满姑凭空间瞬间变出十万斤精白米，全县富商跪求合作，三天成了大周首富。`
- **✅ 高分改写法**：`码头早市刚收完三百文铜钱，二房婆子便领着牙行恶霸扑过来掀坛子：“分出去也是戚家丫头，赚了银子该孝敬老宅！”戚满姑退后半步，抖开里正按过朱印的官户红契：“大周律白纸黑字，抢单立户孤女钱财送官打二十板。”话音未落，邵重山提着柴刀站到酱菜摊前，巷口聚福轩管事已捧着银锭笑迎上来：“戚娘子，这批秘制辣酱契书今日可签？”`

## 5. 案例片段

### 切片 A：流放驿站基建（手搓压水井与碎石过滤）

```text
“娘嘞！真出活了！”
“神仙下凡了！”
“咋整的？土里真能挖出水！”
整个驿站瞬间炸了锅，无数人被这“神迹”吸引过来。
张寻挤开人群冲过来，看着那不停涌出的浑水，眼珠子瞪得铜铃大：“沈姑娘，神仙奶奶！您真是救苦救难的活菩萨转世啊！”
沈桃桃累得小脸发白，却咧开嘴露出个畅快的大笑，朝沈小川一挥手：“二哥，把提前做好的那层碎石头的‘过滤层’倒旁边那个备好的木槽里，水流进去，澄一澄就能喝。”
她指着压把解释：“这叫压水井。压几下，下面阀门吃劲儿，就把深点的地下水抽上来了，比砸冰快多了，力气小的姑娘家都能压出水。”
```

- **学什么**：三句短呼炸出围观震惊，顺手交代碎石过滤与压水井阀门原理，把古代基建写得扎实解气。

### 切片 B：荒年母子采药（溪坡认出川芎换粮钱）

```text
“娘在找一样可以换钱的草药。”舒纭失落地说，“可惜找了半天都没找到。”
叶长安一听可以换钱，就来劲了，有了钱就可以买粮食了，忙问道：“那草药长什么样，我帮着娘一起找。”
“那草药叫川芎，它的叶子长得很像水芹菜，但又略微细窄些。”
叶长安思考了一会儿，走到溪流旁边的斜坡上，在一块岩石边拔了一棵草给舒纭。
“娘，你说的这个小水芹吗？”
舒纭接过一看，惊喜地问：“你在哪里找到的？”
叶长安用手指了指，“那边。”
舒纭顺着叶长安的指尖小跑过去，蹲在地上，折了一根树枝小心的把川穹的全根挖了起来。
```
