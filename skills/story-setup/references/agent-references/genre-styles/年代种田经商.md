# 长篇题材包：年代种田经商

> **核心卖点与分流（仅古代，文件名系历史兼容）**：专攻古代抄家流放、荒年逃荒、分家立户、美食经商与农门基建；六七八零年代军婚用 `女频年代军婚.md`，男频赶山打猎用 `男频年代乡村.md`。

## 1. 故事线设计

- **两大核心主轴**：
  - **抄家流放 / 荒年逃荒 / 反夺空间**：大旱断粮或满门流放北疆，写全家零内耗极寒互助（挡风刨冻土分食）或土著重生反夺仇敌空间连夜搬空库房再体面流放；路上肉汤气哭仇家官差，落户改良农具建富庶坞堡。
  - **农门断亲 / 破窑带崽美食经商**：偏心宗族逼卖妹或吃绝户，可走先签文书再借分户律程序漏洞（未满三年且非耆老所写仍算同户）在官差收税日反逼极品交税；出户后靠橡子凉粉、秘制酱料与药材攒铜钱，盘铺子签酒楼供货契。
- **卷级推进与换图**：分家逃荒活命（挣第一吊钱、修遮风屋）→ 县城集市站稳脚跟（盘门面、置荒地红契、按死吸血族亲）→ 跨州府建作坊供官商军需（荒年赈粮立功、科举或边疆封赏）。

## 2. 常见剧情设计

- **黄金三章切口**：第 1 章对话冷开场直砸荒年卖女、伯母抢粮或流放克扣干粮现场，女主不哭求宗族，搬官府户籍、里正作保或流放律例当场立分家文书，章末拿到红手印或摸出破局食材；第 2 章兑现第一口热食与进账（采药换米、凉粉卖爆、挖暗泉），肉香馋哭隔壁极品；第 3 章吸血族亲或地痞上门抢配方赖账，女主亮官印定契与里正见证打脸，数清第一贯铜钱，抛出置荒地或签酒楼大单的卷级目标。
- **循环节奏与章末断章**：`极品族亲/恶商阻挠 → 女主靠农商巧思闷声出货 → 集市排队、酒楼掌柜加价抢货 → 数铜钱买良田盖青砖房 → 极品偷师翻车 → 围炉吃肉`。高频断章：① 伯母嘲荒地不长苗，次日大酒楼掌柜驾车收头茬菜；② 逃荒断水三日，乱石坡下挖出甘泉；③ 县衙敲锣送来高产种赏银与免税牌。
- **毒点红线**：① 禁空间开局变无限银子或现代成品零食失真；② 禁女主心软回头给吸血族亲送粮送银；③ **严禁穿帮 1970s 粮票/供销社/缝纫机、现代电商与古今割裂头衔（米其林等）及腻词（满脸宠溺/小手手/旋而）**；④ 禁连章憋屈受气不反制。

## 3. 人物设计

- **主角反差与底线**：女主泼辣爽利、精明会算铜钱账，对自家人大方，对吸血族亲一文不让；男主为寡言能打的流放边军/猎户或腹黑病弱书生，对外冷硬、在家劈柴交银全包（亦可写无 CP 姐妹搭档搞钱）。
- **反派梯队（贪财惜命、借礼法施压）**：借孝道与宗族辈分压人抢粮的伯母族老（会堵门闹孝道或扣分家程序）→ 抢生意恶商与偷配方恶邻 → 贪墨赈灾粮的县丞与地方豪绅。
- **关系与对话声线**：地道古代市井白话（文钱、吊、两银子、粗面馍、红契、里正、牙行、茶棚），带真实铜钱物价烟火气。

## 4. 正文技巧

- **视角与切镜**：第三人称贴身女主限知，热食出锅、压水井出水或集市抢购时借围观乡邻、官差或掌柜的直白呼声放大解气感。
- **对白短打与叙述呼吸**：种田爽感靠真实物价与生活阶跃落地（野菜糊 → 杂粮饭 → 炖肉 → 青砖瓦房加红契）；手艺变现只点出一两步去苦、过滤或发酵实操，纯叙述保女主算账的口语因果，忌写成枯燥农技百科或干硬报幕。
- **刀子物件原则**：聚焦真正改命与定输赢的硬物（红手印分家文书、官印田契、川芎草药、压水井木槽、五十两定银），删无功能风物静物贴纸。
- ❌ 烂写法：`戚满姑凭空间瞬间变出十万斤精白米，全县富商跪求合作，三天成了大周首富。`（失真悬浮）
- ✅ 高分改写法：`码头早市刚收完二百文铜钱，大伯母褚氏便扑过来扯钱袋：“分了家你也是戚家丫头，赚了银子该孝敬长辈！”戚满姑退后半步，抖开里正按过红手印的分家文书：“大周律白纸黑字，抢分户孤女钱财送官打二十板。”话音未落，邵重山提着柴刀站到凉粉摊前，巷口聚福轩管事已捧着五十两定银笑迎上来：“戚娘子，这凉粉契书今日可签？”`

## 5. 案例片段

### 切片 A：流放驿站基建（手搓压水井与碎石过滤）

```text
“娘嘞！真出活了！”
“神仙下凡了！”
“咋整的？土里真能挖出水！”
整个驿站瞬间炸了锅，无数人被这“神迹”吸引过来。
张寻挤开人群冲过来，看着那不停涌出的浑水，眼珠子瞪得铜铃大：“沈姑娘，神仙奶奶！您真是救苦救难的活菩萨转世啊！”
沈桃桃累得小脸发白，却咧开嘴露出个畅快的大笑，朝沈小川一挥手：“二哥，把提前做好的那层碎石头的‘过滤层’倒旁边那个备好的木槽里，水流进去，澄一澄就能喝。”
她指着压把解释：“这叫压水井。压几下，下面阀门吃劲儿，就把深点的地下水抽上来了，比砸冰快多了，力气小的姑娘家都能压出水。”
```

- **学什么**：三句短呼炸出围观震惊，顺手交代碎石过滤与压水井阀门原理，把古代基建写得扎实解气。

### 切片 B：荒年母子采药（溪坡认出川芎换粮钱）

```text
“娘在找一样可以换钱的草药。”舒纭失落地说，“可惜找了半天都没找到。”
叶长安一听可以换钱，就来劲了，有了钱就可以买粮食了，忙问道：“那草药长什么样，我帮着娘一起找。”
“那草药叫川芎，它的叶子长得很像水芹菜，但又略微细窄些。”
叶长安思考了一会儿，走到溪流旁边的斜坡上，在一块岩石边拔了一棵草给舒纭。
“娘，你说的这个小水芹吗？”
舒纭接过一看，惊喜地问：“你在哪里找到的？”
叶长安用手指了指，“那边。”
舒纭顺着叶长安的指尖小跑过去，蹲在地上，折了一根树枝小心的把川穹的全根挖了起来。
```

- **学什么**：从“换钱买粮”的实在盼头切入，借水芹与川芎外形辨认和树枝挖根细节，写出农家发家烟火气。
