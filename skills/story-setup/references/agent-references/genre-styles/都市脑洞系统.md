# 长篇题材包：都市脑洞 / 听劝养成与规则返利流

> 普通打工族或学生身陷现实窘境，绑定规则极简、反馈高频的脑洞系统，靠小数点微量化成长与算清回报账降维破局；底线是生活颗粒真实、成长克制不通胀、绝不套 4S 店装逼老模板。

## 1. 故事线设计

- **核心爽点主轴**：现实窘境立得住的代入感 + 小数点式每天变好的稳步正反馈 + 死党吃瘪对照组与卡规则漏洞的惊喜爽感。
- **三大高热引擎**：
  - **真实痛点 + 微量化日常 / 毒舌体检面板**：开篇扎进真实生活颗粒，前 3 章可无反派叫嚣，靠 `颜值 52.0 → 56.1`、毒舌评语与肉眼可见的状态回春稳抓留存。
  - **死党对照 / 亲子反向催卷（啃老系统）**：热心死党同场吃瘪对照释爽；或逼窝囊老爹内卷刷气血触发高位迪化，第 2 章必插老爹自责真亲情防人设招恨。
  - **算账返利 / 止损换攻略**：花钱先算投入产出比，用极小额试水即刻正反馈；开局果断止损拜金对象，借系统按对方潜意识生成任务反推出冰山搭档隐秘偏爱。
- **卷级升级与中后期防崩**：个体脱困（清债/改善家境/校园职场逆袭）→ 行业破圈（盘店/创业/资本博弈）→ 规则升级撬动更大商圈。严禁开局把数值拉满导致中后段丧失成长空间。

## 2. 常见剧情设计

- **黄金三章切口**：
  - **第 1 章**：极简首段切入真实窘境，立住亲情或生存锚点；快速绑定系统，亮 3 行极简规则并兑现首笔当场验证小回报，章末卡在首次肉眼变化或奇葩新任务。
  - **第 2 章**：社交镜像首反馈，借青梅、同桌、死党或同事的细微态度转变（偷瞄、改口、递资料）验证变强，顺手算清下一笔大账。
  - **第 3 章**：拿到首份阶段硬收益（改善家境的第一笔钱、业绩或体测甩开众人、卡出规则新用法），甩出高倍率任务或新对手卡点。
- **卷内博弈与高频断章**：每 2–3 章一次微量化提升或死党对照小爽，每 8–12 章一次公开破圈中爽（竞赛、路演、抢单、返利暴击）。高频章末断章：① 死党刚吹完牛就吃瘪，转头众人围上主角；② 面板弹出高倍率限时任务；③ 手机入账短信与榜单热搜同时炸屏；④ 曾看低主角的甲方或校花主动找上门。
- **核心毒点雷区**：① 禁套咖啡厅甩账单、4S 店刷卡旧模板；② 禁连贴大段系统说明书；③ 禁开局数值通胀导致中后期失感；④ 禁低俗擦边与踩审风险。

## 3. 人物设计

- **主角人设与底线**：接地气、会算账、对父母死党重情义，拿了挂也不悬浮炫富，每分钱都花在刀刃上。
- **反派梯队（各自私心与有效反制）**：势利熟人、拒报差旅的抠门主管（用职场规则卡报销、抢功甩锅，而非无脑嘶吼）→ 行业地头蛇与资源垄断富二代（用渠道压价截单）→ 资本操盘手。
- **关系张力与说话声口**：日常口语短促带梗，死党捧哏鲜活，系统提示冷幽默毒舌，自然撑起轻喜网感。

## 4. 正文技巧

- **视角与落地体感**：默认第三人称贴身限知，把抽象属性翻译成具体生活体感（跑完不喘、同桌主动递题、家里添硬菜）；善用死党同场试错造喜感对比。
- **叙述呼吸与对白短打**：对话净白短打自然拉快节奏，纯叙述必须保留主角算账盘算与口语因果连接（因为/偏偏/省得/说白了），忌干硬摄像头报幕，也禁系统面板报菜名。
- **刀子物件原则**：只细写直接兑现回报或卡住人情的账单、发票、入账短信与日常小物件，严禁堆砌无功能名牌穿搭、咖啡机嗡鸣与装修材质贴纸。
- **❌ 烂写法**：`【叮！消费返现系统绑定！力量+100，魅力+100，神级格斗术+100，恭喜宿主成为世界首富！】`
- **✅ 高分改写法**：`钟浩攥着二手电瓶车钥匙盯着手机短信：帮邓主管垫付的八百块团建餐费刚被拒报，系统却按十倍赔付到账八千。邓主管端着茶缸探头问：“小钟，下周客户接待费……”钟浩把发票往兜里一揣，笑得殷勤：“放心主管，全组垫资我包了。”`

## 5. 案例片段

### 切片 A：毒舌系统微量化自律正反馈

```text
就在他意识快要模糊的时候，一道只有他能看见的淡蓝色光幕在眼前展开。
【每日任务：慢跑五公里（已完成）】
【结算中……】
【奖励下发：颜值+0.1，皮肤通透度微量提升，下颌线清晰度+1%】
苏白甚至没力气抬头，只能盯着光幕上的字大口喘气。
【宿主：苏白】
【颜值：56.0（平庸路人）】
【系统评语：恭喜你，终于摆脱了那种一眼看去就很虚的颓废感。虽然目前的你依然属于丢进人堆里就找不出来的背景板，但至少，你已经是一块干净的背景板了。】
这破系统嘴还是这么毒。
苏白扯起衣领擦了把脸，看着那行56.0，紧绷的小腿肌肉才慢慢松弛下来。
```
- **学什么**：用「+0.1颜值」微量化回报叠加系统冷幽默毒舌评语，再接扯衣领擦汗的肌肉体感，把挂落回日常。

### 切片 B：春运大巴极小额十元返利试水

```text
“大哥。”
称呼已经从“大叔”变成了“大哥”。
陈婷婷纹着花臂的胳膊抱胸，大咧咧的说道：
“我们没钱吃饭了，你看能不能……”
她的话没说完，但意思已经很明显。
换做半小时前，白离只会觉得她们是麻烦，根本不会搭理她。
但现在他心中一动，一个大胆的测试计划浮现出来。
他看着眼前这个画着烟熏妆，故作成熟的红发女孩，平静地拿出手机，打开了微信的收款码。
“要多少？”
他的声音很平淡，却让三个女孩都呆住了。
她们原本以为，能被骂一顿然后要到几口泡面汤喝就不错了，根本没想过对方会直接给钱。
陈婷婷和两个姐妹对视一眼，凑在一起小声商量了半天，像是在讨论一个天大的数字。
最后，陈婷婷小心翼翼地伸出一根手指。
“十……十块钱，我们买一包泡面分着吃就行。”
```
- **学什么**：抛弃「开局刷一百万」，用春运大巴称呼微变与十元分泡面的极小额人情切入返利测试。
