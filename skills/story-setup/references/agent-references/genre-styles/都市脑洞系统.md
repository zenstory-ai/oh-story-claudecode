# 长篇流派包：都市脑洞 / 系统规则流

## 1. 定位、平台与读者期待

- **一句话定位**：普通人陷入真实可感的都市窘境（欠债/被裁/被甩/亲戚看轻），绑定一个规则极简、反差极强的脑洞系统（听劝/吹牛成真/消费返利/词条改造/异常职业），用新规则把现实世界按在地上摩擦。
- **平台倾向**：番茄男频头部主力赛道，默认第三人称贴身限知，单章 2150–2400 字，段中位约 22 字，强噱头、强节奏、首章必亮金手指。
- **读者期待**：现实憋屈立刻破局的解压感 + 「规则还能这么卡 bug」的惊喜感 + 旁人按常识误判后集体打脸的爽感。

## 2. 核心梗 / 金手指公式与卷级升级轴

- **金手指公式**：`反直觉触发条件（花钱/听劝/摸鱼/给差评）+ 即时现实变现（现金/神级技能/稀有词条）+ 明确小限制（防无脑印钞）`。面板只亮目标、奖励、限制三行，不写说明书。
- **卷级升级轴**：
  - 卷1（个体破局）：清债/租房/前任与势利亲戚打脸，积累第一桶金与神级单技能；
  - 卷2（行业降维）：开店/进公司/直播破圈，用规则横扫同行与资本打压；
  - 卷3（资本/国际舞台）：规则升级解锁新词条或跨领域联动，影响城市格局乃至海外巨头。
- **写长引擎**：每段剧情围绕「同一套规则的新应用场景」展开，换对手层级和卡 bug 方式，不重复同一招刷钱。

## 3. 黄金三章打法

- **第 1 章**：首段 ≤30 字直抛现实暴击（分手账单/被裁通知/相亲被羞辱），300 字内进尖锐对话，800 字内系统叮声绑定并给出一项**当场可验证的现实小收益**（如一笔立刻到账的返利或当场见效的技能），章末卡在对手即将撞枪口或新任务弹窗。
- **第 2 章**：兑现首轮当众打脸（刷卡/露一手/手机到账截图），旁人从嘲讽变懵逼，随即冒出更有权势的新误判者。
- **第 3 章**：拿下首个阶段大收获（买车/盘店/夺回项目），甩出指向本卷主线的重磅系统任务或大资本盯上主角的强卡点。

## 4. 卷内爽点循环与高频章末断章

- **循环节奏**：每 2–3 章一次小爽（现实收益到账+路人/熟人改口），每 8–12 章一次中爽（公开场合规则翻盘+内行拆解分量）。每次奖励必须落到手机通知、合同、直播间弹幕、门禁或银行余额等现实载体上。
- **高频章末断章**：① 系统突然弹出离谱高额任务；② 手机热搜/转账短信炸屏；③ 势力更大的新对手上门放狠话，却不知主角刚解锁天克技能；④ 检测结果/底牌刚亮出一半。

## 5. 人设反差、反派梯队与对话声线

- **主角人设**：接地气、懂算账、嘴里带点冷吐槽，得了挂也不装圣人，该收钱收钱、该打脸绝不手软。
- **反派梯队**：势利前任/奇葩亲戚（小反派，2–3 章干脆打穿）→ 职场恶上司/行业地头蛇（中反派，靠规则和资源压人）→ 资本财阀/海外巨头（大反派）。
- **对话声线**：生活化口语，短促带刺；系统提示冰冷机械，主角心里吐槽鲜活热辣，形成冷热反差。

## 7. 流派专属技法与毒点红线

- **专属技法**：把抽象系统词条翻译成切身金额与现实便利；善用直播间弹幕、公司群消息、银行短信三件套放大外部见证。
- **毒点红线**：① 严禁连续两段贴面板写系统说明书；② 严禁主角拿了百亿神豪挂还窝囊受气、不敢花钱；③ 严禁奖励只停在主角一个人暗爽，没有外部现实反馈与旁人态度反转。
