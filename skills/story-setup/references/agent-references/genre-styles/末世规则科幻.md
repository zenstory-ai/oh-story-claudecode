# 长篇流派包：科幻末世 / 第四天灾与无限规则流

## 1. 定位、平台与读者期待

- **一句话定位**：三大高粘性分支共用「秩序崩塌 + 规则求生/掌控」内核——① **末世重生囤货**：灾变前重生，手握无限空间疯狂囤货、打造堡垒，末日降临后看着仇人冻饿求生、自己吃火锅吹空调；② **第四天灾**：异界/废土召唤沙雕地球玩家当不死劳工与战力，靠玩家整活横推世界；③ **无限流/规则副本**：在致命规则副本里找生路、卡规则 bug 通关拿积分。
- **平台倾向**：番茄/七猫/起点稳定受众，默认第三人称贴身限知，单章 2150–2500 字，危机紧迫感强、物资清单/规则条款极度具体。
- **读者期待**：消解生存焦虑的**绝对掌控感**（囤货安全屋）+ 恶邻/背叛者遭反噬的痛快 + 沙雕玩家整活或硬核破局的脑洞爽。

## 2. 核心梗 / 金手指公式与卷级升级轴

- **分支引擎**：
  - 末世囤货：`倒计时（距极寒/丧尸还剩7天）+ 储物空间/安全屋升级 + 前世背叛仇人对照`。
  - 第四天灾：`召唤玩家面板（发任务/抠门给经验/看论坛吹捧）+ 玩家视死如归的沙雕整活 ↔ 土著震撼恐惧`。
  - 无限规则：`明确规则清单（3-5条，必有死路与隐藏生路）+ 积分强化/稀有道具 + 现实主线秘密`。
- **卷级升级轴**：极寒/丧尸单灾（小区/城市）→ 异能觉醒与基地争霸 → 变异兽潮/外星或高维真相 → 重建新世界秩序。

## 3. 黄金三章打法

- **第 1 章**：首段直接砸下前世惨死画面（被白眼狼邻居分食/被女友出卖）+「再睁眼回到末世前七天」倒计时，或直接甩出天灾降临/副本倒计时！400 字内亮出空间/召唤系统/规则纸条并开始行动（套现搞钱/改造防弹门/召唤首批玩家），章末卡在首笔巨额物资落地或首个异常征兆提前爆发。
- **第 2 章**：高效推完筹备或首战（买空仓储超市/玩家首战全灭反派探子/副本首名违规者惨死），把物资数字、安全感或规则杀伤力立到极致。
- **第 3 章**：末日正式降临或副本开启决胜阶段，曾经嘲讽/背叛主角的人陷入绝境疯狂敲门，主角隔着防弹玻璃喝着热汤冷眼旁观，引出首轮强对抗。

## 4. 卷内爽点循环与高频章末断章

- **循环节奏**：`新灾变/新副本倒计时 → 物资/能力针对性升级 → 恶人逼上门或副本死局 → 降维反杀/卡规则 bug 满分通关 → 盘点战利品与基地扩张 → 更高层天灾预警`。
- **高频章末断章**：① 室外气温骤降零下六十度，物业群彻底炸锅；② 极品邻居拿大锤砸防弹门，门后伸出黑洞洞的枪口；③ 玩家论坛热帖冲上第一，幕后大 Boss 却连夜跑路；④ 副本广播突然响起「隐藏规则第 5 条已解锁」。

## 5. 人设反差、反派梯队与对话声线

- **主角人设**：冷静理性、狠辣果决、极度护短自己人，绝不发善心救白眼狼；第四天灾主角偏「黑心策划」腔调，抠门画饼让玩家倒贴干活。
- **反派梯队**：道德绑架邻居/绿茶前任（开局必打脸）→ 暴力帮派/黑心基地首领（中段争夺）→ 进化体兽王/高维规则主宰（终局 Boss）。
- **对话声线**：冷硬干脆、数字精确（吨/度/积分/血条）；第四天灾可穿插鲜活玩家吐槽与论坛体，形成强烈喜感反差。

## 7. 流派专属技法与毒点红线

- **专属技法**：囤货清单写具体品类与反差享乐（恒温/热汤/手枪/发电机），不写流水账记一千件日用品；规则副本保证规则前后一致，主角靠抓字面漏洞或前置道具破局。
- **毒点红线**：① 严禁末世降临后主角突然圣母收留背叛过自己的白眼狼；② 严禁空间无限大后忘记制造新压力（要靠极寒升级、变异体、势力围攻推高紧张度）；③ 第四天灾严禁只写玩家自嗨不写土著震撼反应。
