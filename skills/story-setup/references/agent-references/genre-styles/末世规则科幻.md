# 长篇题材包：科幻末世 / 全民载具求生与第四天灾

> 专攻男频硬核末世求生、载具改装、晶核博弈、规则副本与第四天灾（女频天灾空间囤货安全屋请走 `女频末世天灾囤货.md`）；底线是绝不圣母救白眼狼、规则严守不临时改口、绝不科普开篇。

## 1. 故事线设计

- **核心爽点**：手握武装安全屋或顶配改装载具消除生存焦虑的掌控感 + 道德绑架的恶邻与前世仇人遭反噬的痛快 + 沙雕玩家整活或卡死规则漏洞的脑洞爽。
- **三大主流写法**：
  - **全民 / 班级 / 载具求生**：开局抢占顶级载具或觉醒媒介拿到唯一天赋，结合安全区禁杀规则与区域聊天频道的惨状对比，靠车内吃热锅、出租暖座、晶核信息差做空交易滚雪球，顺手反杀车外道德绑架的熟人。
  - **重生囤货安全屋**：给足紧迫倒计时（如极寒、酸雨 7 天后降临），凭无限储物空间与前世记忆精准搬空核心物资、加固堡垒，跟楼道里前世背叛过自己的仇人形成冷酷对照。
  - **第四天灾 / 无限规则副本**：把异界战场或生存危机包装成全息游戏招募玩家，适时切玩家视角，靠不怕死的奇葩操作制造与异界土著的认知反差；或在致命规则副本里卡出隐藏生路拿最高评级。
- **换地图与中后期防崩**：按「单灾存活（小区 / 新手公路 / 初阶基地）→ 载具与异能成体系、区域榜登顶 → 跨区域争霸与高阶变异兽潮 → 揭开灾变真相、重建新秩序」逐卷升级。空间物资充裕后必须持续抬高外部危机（极寒升级、酸雨腐蚀、武装车队围猎），绝不能窝在屋里无压力水日常。

## 2. 常见剧情设计

### 黄金三章怎么写
- **第 1 章（两条开局）**：
  - *重生囤货*：砸下极寒/酸雨 7 天倒计时，两句点明前世血仇（禁病毒科普）；当章开空间搬冷库、焊防弹门，章末卡恶邻笑主角疯了。
  - *载具 / 第四天灾*：极短全服广播宣告规则，主角抢唯一载具或母巢天赋，当场首升或招玩家，章末卡区域频道首声惨叫。
- **第 2 章（对照组与变现）**：
  - *安全屋对照*：业主群抢水骂娘，主角恒温屋涮热锅，顺手完成首笔交易并布门外暗防。
  - *公路 / 副本首杀*：凭先知或玩家冲锋拿首杀、低价横扫防冻液与晶核，甩开挑事班长。
- **第 3 章（反噬与危机抬头）**：
  - *道德绑架反杀*：寒潮降临，恶邻仇人绝境砸门逼分粮，主角借机关武器干脆反杀立威。
  - *榜首引大敌*：做空晶核登顶区域榜收核心图纸，章末抛暴力车队盯梢或高阶巨兽提前苏醒。

### 常见剧情类型库（排大纲 / 细纲直接挑选组合）

#### 一、开局起势与立威

1. **灾前囤货与反差吃热锅**
   - **起局与赌注**：极寒剩两天，主角卖房囤保温帐篷、冻肉与钢板焊门，遭物业恶邻嘲笑；算错即冻死烂尾房。
   - **铺垫与拉扯**：恶邻在业主群偷拍讽刺劝人别囤粮；主角不辩，悄悄搬空药店抗生素与净水滤芯。
   - **爆发与爽点落地**：零下五十度断电，群里求半块饼干；主角恒温屋涮肥牛发照，切恶邻啃冻萝卜破防，两袋泡面换走整楼金饰钥匙。
   - **防俗变体与承接**：恶邻拉总闸逼出门反被独立储能回路打脸，监控角落现变异野犬。

2. **区域频道对比与倒卖晶核**
   - **起局与赌注**：全民空降公路开破车、油表见底；主角预知三小时后暴雪封路，押家底做空，赌错即断油冻死。
   - **铺垫与拉扯**：频道低价扫棉袄盐砖与破晶核遭群嘲，黑商抬价坑人；主角照收并连夜升暖风。
   - **爆发与爽点落地**：暴雪封路频道惨叫刷屏，主角挂热汤暖座换三颗晶核，切黑商颤抖加价求上车，一晚登顶区域榜。
   - **防俗变体与承接**：赖账刺头想白嫖暖座，主角开冷风锁门逼吐图纸；榜首飘红惹暴力车队盯梢。

3. **恶邻或班长道德绑架反杀**
   - **起局与赌注**：灾变头三天物资见底，恶邻或势利班长拉互助组逼主角房车存粮充公，不交就踢群孤立。
   - **铺垫与拉扯**：先捧杀施压，见主角拒不配合便煽动饿红眼熟人拎消防斧堵门；主角暗扣防卫开关与安全区倒计时。
   - **爆发与爽点落地**：对方破门或出区劫道瞬间，高压喷口与射钉枪放倒领头恶霸，切墙头草惨白退群求饶，缴获油料药箱。
   - **防俗变体与承接**：反派临死供出已把坐标卖给隔壁强盗团，恩怨升格为跨区攻防。

- **圣母救白眼狼**：收留前世害死或背叛自己的恶邻、绿茶与亲戚，瞬间弃书。

- **低俗擦边**：班级载具或末世求生塞擦边工具人，拉低格局且易踩审核。

## 3. 人物设计

- **主角人设与底线**：冷静理性、狠辣护短，绝不救白眼狼；**强载具与金手指必绑高油耗、电量或冷却硬约束**（防数值失重），第四天灾主角带点黑心游戏策划的冷幽默，忽悠玩家冲锋时一本正经。
- **反派梯队**：
  - **初阶**：道德绑架的邻居、抢物资的班长、囤积居奇的黑商——懂抱团施压、趁灾压价，见风使舵极快。
  - **中阶**：武装暴力车队、黑心基地首领——懂卡水源、封高速、设卡收过路费，有成建制武装。
  - **高阶**：高阶变异体领主、跨区霸主与灾变幕后操控者——逼迫主角持续升级科技与战力。
- **配角与说话语气**：主角与硬核同伴说话冷硬干脆、数字精确（吨、公里、零下温度、耐久）；穿插区域频道或玩家弹幕放大见证反差。

## 4. 正文技巧

- **反差视角与灾变扩散**：第四天灾经独立场景切玩家视角制造「当打游戏 ↔ 土著震骇」的认知错位；写灾变降临由近及远逐层扩散人群反应，放大临场压迫。
- **生存硬约束与频道对照**：交易对峙穿插区域频道惨状对比；极端环境、载具负重、油电消耗与保命硬物资（滤芯、抗生素、防冻液等）来源须合常识且提前交代。
- **规则广播语气**：**规则广播与系统禁行政法条词（不得/应当/处罚/计入），改用短狠死刑句，金手指只标红线不吐答案**。
- **❌ 烂写法**：`病毒起源于公元二〇三五年实验室泄漏，经过三次变异形成五级丧尸体系……【本公告不可撤回，违者计入优先惩罚】`
- **✅ 高分改写法**：`“零下四十度，你拿半箱头孢换三颗一阶晶核？”仓库门口，黑商老周把防寒手套往铁门上一拍，冷笑出声。鲁征没抬头，只把车载蓄电池电量表往外一偏，露出满格绿灯：“半小时后暴雪封路，供暖站铁定停机。现在换是三颗，天黑以后，你拎十颗晶核也买不到我半度电。”`
