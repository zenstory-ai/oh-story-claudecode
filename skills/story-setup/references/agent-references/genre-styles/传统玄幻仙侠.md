# 长篇题材包：传统玄幻 / 东方仙侠与凡人修仙

> 遭退婚、夺骨、废灵根或身处底层杂役散修，凭独门机缘与稳健狠劲夺资源、破境界、越级斩敌；底线是战力有参照、破境有实感、绝不无成本越级导致战力崩盘。

## 1. 故事线设计

- **核心爽点**：「莫欺少年穷」的逆袭痛快 + 破境升级与越级反杀的畅快感 + 斗法算计的想象力与高手逼格。
- **三大主流写法**：
  - **传统废柴大比流**：低谷受辱起手，靠成长型至宝或古法传承翻身，走「夺宝 / 宗门大比 / 秘境历练 → 破境越级反杀 → 换更高阶地图」的经典爽点循环，每一轮都让曾经看不起主角的人当众打脸。
  - **凡人稳健算账流**：灵根平庸、资源紧缺，主角极度谨慎且暗藏底牌，遇事先算清利弊和后患（打得过必须补刀绝户，打不过果断遁走），靠时间差、阵法、丹药或催熟灵草的随身小鼎以弱胜强，主打步步为营的求生感。
  - **宗门/家族群像经营流**：靠培育族人、经营灵脉与合纵连横在宗门乱局中壮大，既有个体破境也有群体荣辱。
- **换地图与中后期防崩**：按「家族 / 小城（炼气 / 淬体）→ 宗门外门与内门（筑基 / 灵境）→ 州府王朝与古秘境（金丹 / 宗师）→ 中州圣地与上界飞升」逐卷推进。每卷紧扣一次关键破境与核心资源争夺，换图后旧功法体系与前期战力参照必须延续，严防后期战力崩盘。

## 2. 常见剧情设计

### （一）黄金三章怎么写
- **第 1 章**：**路子 A（退婚夺基）**：未婚妻携大宗靠山退婚，或族叔强抢父母遗留灵药；当章立期限赌约，残玉/黑鼎苏醒完成暗中反击，卡更大打压。**路子 B（凡人求生）**：采药遭坑或杂役被逼交苛刻药额，立冷静算账心性，绝境激活随身奇物或古法传承，卡追兵逼近或验货期限。
- **第 2 章**：**路子 A（荒野首杀）**：借同阶散修面对妖兽劫修的狼狈做参照，再凭新法或催熟符丹干脆首杀，拿第一笔灵石残页。**路子 B（药园立威）**：面对抢田狗腿先示弱套靠山再一招放倒，反摸出管事贪墨账本。
- **第 3 章**：**路子 A（半露锋芒）**：演武场露一半实力藏一半底牌，按翻首个挑事对手，借长老惊疑引出外门大比。**路子 B（借规矩反杀）**：借宗门律条当众反咬克扣月例的管事，换进优质资源位并惹来真传盯梢。

### （二）常见剧情类型库（排大纲 / 细纲直接选用）

#### 一、开局起势与立威

1. **退婚夺基立期限约**
   - 起局：未婚妻入大宗后携护道者退婚，或长老借废灵根强夺父母灵物，想彻底甩开累赘；输了便成笑柄、断掉修炼本钱。
   - 铺垫：族老齐劝识相，护道者放威压逼签字；主角不哭闹，把打发人的下品灵石原样推回，越平静越激怒反派。
   - 爆发：指血改退婚为休书并立三月/一年之约放话登门清算；切护道者微惊、女方恼羞视角，讨回旧物并立骨气。
   - 变体：给女方留宗门逼婚苦衷而非纯蠢货，但傲慢依旧；期限逼主角冒险闯禁地夺机缘。

2. **外门药园 / 月例克扣反坑**
   - 起局：管事分毒虫废田还克扣月例，限月底交三株血灵芝否则逐门，实则把好田转租关系户并拿主角顶私库亏空。
   - 铺垫：主角装老实挑水任狗腿嘲讽，暗借残玉灵泉催熟灵草，摸清管事半夜偷运公田灵药的时辰与接头人。
   - 爆发：验货日交出极品灵芝，并在执法执事在场时甩出私运账页与留影石；切管事面如死灰视角，拿双倍补偿并接管肥田。
   - 变体：用宗门律条反杀而非莽撞杀人，立稳健人设；管事倒台牵出吃回扣的内门执事。

3. **坊市捡漏与出城反杀黑吃黑**
   - 起局：坊市凭至宝感应低价买下蒙尘残器或废丹方，被眼尖摊主或劫修盯上，对方算准出城十里杀人越货。
   - 铺垫：故意露囊中羞涩之态，大张旗鼓买低阶防御符麻痹对手，暗换隐匿阵盘与毒烟弹，出城专挑退路唯一的乱石谷。
   - 爆发：三名劫修合围即踏困阵，毒烟遮眼剑光断喉；切领头者临死惊骇视角，摸尸得灵石、法器与古修洞府玉简。
   - 变体：让一名劫修先伪装和善老散修帮赶毛贼博信任，临动手被早识破反杀；玉简开启古修秘境线。

#### 二、中期核心大高潮与秘境

4. **宗门大比 / 登天梯扮猪吃虎**
   - 起局：大比关乎内门名额与筑基丹，收钱执事暗箱抽签把主角首轮排给炼气圆满强敌，欲借擂台废其经脉。
   - 铺垫：全宗赔率一面倒，看台打赌撑几息；上台后主角压低灵力只守不攻，逼傲慢对手烦躁使出耗尽灵力的绝招。
   - 爆发：敌方旧力刚去一瞬，主角以巧破力挑飞法器、一剑轰下擂台；切长老捏碎扶手、执事脸青视角，稳拿内门名额与重奖。
   - 变体：前两轮故意「侥幸险胜」诱决赛真传轻敌；夺魁后惹来败者背后护短峰主盯梢。

5. **古宗秘境探宝反坑黄雀**
   - 起局：古宗秘境开启，正魔天骄争核心灵泉与传承；主角修为偏低硬拼必死，唯独握着识破残阵生门的古图。
   - 铺垫：混外围帮大宗指认外围机关换信任，冷看两天骄为破守护傀儡打得两败俱伤，暗处魔修摩拳擦掌想当黄雀。
   - 爆发：主角借生门暗道绕后端走传承玉盒与泉眼，扔引兽香反手合阵门坑杀黄雀与追兵；切魔修暴怒视角，满载而归。
   - 变体：秘境中与伪装落难的敌宗圣女短暂合作各留后手；出秘境各宗通缉黑衣人。

6. **绝境破境渡劫震动老祖**
   - 起局：仇敌探明主角冲筑基/金丹当口，串通敌对长老堵洞府强破护阵，高层旁观；破境一断轻则道基尽毁、重则陨落。
   - 铺垫：护阵光幕寸寸龟裂，门外叫骂必死；洞府内主角强忍剧痛压上全部灵液保命丹，卡大阵崩碎最后一息引爆突破。
   - 爆发：灵气倒灌、紫黑雷云压顶，主角逆雷踏出借劫威一剑斩碎敌宝劈飞长老；切闭关老祖睁眼破关问话视角，跻身权力核心。
   - 变体：故意把天劫往敌阵引逼长老帮抗天雷；异象传遍一州引来敌宗老祖窥探。

#### 三、节奏调剂与副线爽点

7. **拍卖会抬价坑死仇家**
   - 起局：州府拍卖会，仇家急需保命灵药在前、主角想要的残缺古宝在后；主角灵石有限，硬拼不过世家须先榨干对方钱包。
   - 铺垫：匿进角落包厢，卡在仇家咬牙能承的边线几轮跟价，放风声称该药有隐藏奇效，把仇家逼红眼上头。
   - 爆发：价抬至市价两倍果断松手，看仇家掏空家底接盘；后头古宝上场仇家无力竞价，主角底价捡漏；切仇家拍桌破防视角。
   - 变体：暗联女掌柜互换消息帮抬抽成，换拍卖行贵宾庇护与高阶人脉。

8. **炼丹 / 炼器 / 布阵副职业惊艳打脸**
   - 起局：丹堂或器阁考核，主角被嫡传嘲是只会蛮干的散修，堂主放话炼不出上品成丹便扫炉灰，实则想把名额给侄子。
   - 铺垫：嫡传按部就班出香赢得喝彩，主角却搬二手黑炉同时投三味相冲灵草，众人纷纷断定必炸炉。
   - 爆发：炉盖剧颤之际主角拍炉底以古法逆转药性，开炉丹霞冲顶出九颗极品丹；切长老捧丹发颤视角，拿客卿令牌与灵草分成。
   - 变体：只精一门且专攻修古阵或解奇毒，让全宗大佬排队上门求合作，滚出长线人脉网。

9. **野外伏击灭口补刀绝户**
   - 起局：荒野反杀偷袭的世家子弟，对方先搬金丹族叔威吓，见吓不住便跪献储物袋发誓求饶；心软放虎归山必招灭门追杀。
   - 铺垫：收剑半寸装动心，逐句套出储物袋口诀、家族暗桩与同伙人数，诱对方放松戒备暗捏传讯符。
   - 爆发：情报问清先斩传讯符，干脆补刀绝户、火焚尸身抹平灵气痕迹；切万里外祠堂魂灯骤灭、长老震怒无从查起视角。
   - 变体：储物袋底层翻出自家宗门高层的魔道血令，主角瞬间变被动为主动拿把柄布局。

#### 四、换地图与中后期破局

10. **护短救师门 / 单刀赴鸿门宴**
    - 起局：外域成名后惊闻早年破落旧宗或恩师遭邻宗逼债吞并，对方设鸿门宴限三日交灵脉，厅内暗布绝杀大阵。
    - 铺垫：切旧宗视角写老掌门苦撑绝望，敌宗少主宴上嚣张撕盟约逼下跪交令牌；千钧一发山门外响起平静敲门声。
    - 爆发：提旧剑独入宴厅，一剑破护殿阵将少主钉柱，连本带利算清三年血账；切敌长老冷汗湿袍、老掌门落泪视角。
    - 变体：请来早年欠恩师人情的州府修士压阵显人情厚度；敌宗背后牵出中州圣地。

11. **换地图初入遭盘剥与靠山上门问罪**
    - 起局：破境初入州府或中州大城，因出身小宗遭城门执事、商会盘剥，偏巧前期旧敌靠山寻仇上门，新旧危机撞在一处。
    - 铺垫：不跟守门小卒硬扛，凭副职业结交中立大商会，同时查清旧敌靠山在城内的死对头，暗中把水搅浑。
    - 爆发：靠山封锁客栈拿人时，亮出死者魔道密令与商会客卿玉牌，借死对头之势反咬勾结邪修并一战斩敌立威；切全城惊叹过江龙视角站稳脚跟。
    - 变体：让一路跟来的旧灵宠或早年搭救师妹递关键一刀，守住人情连续感接入圣地主线。

### （三）高频断章钩子
- **破境震宗**：洞府上空劫云骤聚九雷劈山，闭关甲子的老祖猛然睁眼望向废峰。
- **绝境撞脸**：仇敌带筑基长老轰开山门，烟尘散去，主角恰好破境推门迎面撞上。
- **秘境异变**：千年石门洞开，众天骄未撼动的石台古玉，骤然化光朝角落主角飞来。
- **摸尸惊变**：补刀灭口翻开储物袋最底层，摸出一枚刻着自家峰主私印的血色密令。
- **打脸前夜**：全宗嘲笑炼气废柴找死，主角拔出锈剑，看台首席长老茶杯啪地裂开细缝。
- **旧账追来**：初踏中州客栈还没坐稳，门外落下三道金丹威压，冷声索要半年前秘境黑衣人。

### （四）常见毒点 / 劝退点
- **开篇灌水说教**：前两章大段科普境界表与编年史，或关门打坐签到，毫无贴身危机。
- **圣母留患与木桩挨打**：仇敌求饶就心软放走，或站原地等反派念完大招才还手。
- **无成本越级战力崩盘**：刚立森严境界铁律便毫发无伤连越两三大境乱杀，前期参照失效。
- **破境废旧法**：每换一境便随手弃掉前期苦修功法与本命法器，体系彻底失真。
- **后期变单机打怪**：修为高了只剩换副本堆数字，丢掉底层算账求生感与师门牵绊。

## 3. 人物设计

- **主角人设与底线**：小毛病可以有（记仇、爱财、护短、该补刀绝不心软），大是大非守得住；凡人流讲究「嘴上低调、出手绝户」，每次进秘境或遇伏击先算退路、底牌和灭口成本，不拿命去赌运气。
- **反派梯队**：
  - **初阶**：势利同辈、外门管事——贪扣灵石药材，懂得拿宗门律条、抽签暗箱和信息差堵死主角退路。
  - **中阶**：傲慢真传、偏心长老——护短抢名额，借大比规矩、执事权柄名正言顺压人。
  - **高阶**：敌宗老祖、幕后魔修——布长线杀局、编织利益网，不到万不得已不亲自露面。
- **配角与说话语气**：配角要有自己的算盘和喜怒，别围着主角空喊「恐怖如斯」。台词带克制古韵，不堆生僻文言；长辈惜字如金、天骄张扬傲慢、主角出手前话少且句句见锋，底层杂役散修带实在的市井算账味。

## 4. 正文技巧

- **战力与资源自洽**：境界压制、灵石/寿元消耗与功法代价前后一致，斗法不无成本越级；聚焦改局的法器、灵草与令牌。
- **战斗描写三板斧**：
  - **标准爽战顺序**：气势对拼 → 一句硬话 → 敌人出绝招做战力参照 → 主角破招碾压 → 懂行长老或强敌失态点破分量。
  - **写出高手逼格的四招**：用时间衬托（苦修一甲子）、用具体规模衬托（一剑断三里江）、把无形剑意写实（抽剑意凝雷）、借典故起好招名。
  - **以巧破力**：多用物极必反、借力反噬、逆捅阵眼破局，压箱底大招首次亮相详写，后续重复使出一笔带过。
- **❌ 烂写法**：`演武场一片死寂，长老捏碎茶杯怒喝：“炼气三层的废物！”少年突然黑鼎一震，太古剑气破体而出！`
- **✅ 高分改写法**：`青石台前，赵管事把茶碗往案上一顿：“炼气三层也配领丙字药田？滚去挑水！”程远没争辩，只从袖里摸出执法堂朱漆腰牌往案角一压，抬眼道：“上月失踪的三株血灵芝，王执事让我顺路查账，管事现在带路，还是我请堂里来人？”`

## 5. 案例片段

### 切片 A：道心反诘与古典重走（连续短问立格局）

```text
“南赡部洲众生苦难，佛祖念诸众生皆是其子，这是菩萨亲口所言。”
“佛祖神通无量，既有真经妙法，又视众生为子，为何不派菩萨送经东来？为何不亲自传法度人？”
“跋涉十万八千里，历经千难万险，去'求'取真经？”
“皆因法不可轻传乎？”
“众生愚昧，便应受苦吗？”
“若贫僧取不回真经，那南赡部洲便永无正法吗？”
“为佛岂可端坐莲台之上，任世人受苦？”
玄奘的声音陡然拔高：
“这是度人，还是戏人？”
“这是慈悲，还是傲慢？”
```
- **学什么**：不用挥拳也不用旁白解说，连续短问直戳神佛潜规则，一个动作不写也能压出顶级高手逼格。

```text
他赶紧拿着钱跑到隔壁李叔叔家。
此刻，李民正在教训李月月，“你个小屁孩，还知道偷钱了！谁教你的！”
“没人教，我就是不想平安哥挨打。”李月月小手攥在一起，泪水汪汪。
“你……”李民拿起棍子想打，但见李月月可怜兮兮的样子，最终没下去手。
同时，他也看到了门口的江平安。
李民冷声道：“滚。”
江平安赶忙说道：“李叔叔，我是来还钱的。”
“不用，赶紧滚。”李民继续呵斥。
他家里不富裕，被搜刮了几次，没剩下多少东西，可是他知道江平安更穷。
李民既可怜对方，又不想与对方有太多联系，承担更多责任。
江平安没有离开，反而摊开手，里面出现五枚铜币。
“一枚还你们，剩下四枚，我想买四个馒头。”
李民愣住，“你怎么会有这么多钱？”
```
