# 长篇流派包：双男主 / 宿敌救赎与强强权谋

## 1. 定位、平台与读者期待

- **一句话定位**：两位魅力旗鼓相当的男性主角在宿敌对峙、契约绑定、重生救赎、无限流闯关或朝堂权谋中极限拉扯，依靠**一冷一热的性格温差、口是心非的暗恋视差与生死相托的宿命羁绊**推动长线剧情。
- **平台倾向**：番茄核心高粘性赛道 + 晋江主力。第三人称主受或主攻视角均可（亦允许关键节点切另一方短视角释放暗恋视差），单章 2150–3000 字，重人设张力、对话机锋与情绪爆发。
- **读者期待**：「嘴上势不两立、底下把命都交出去」的错位快感 + 双强并肩破局的燃感 + 隐藏多年深情曝光那一刻的极致破防。

## 2. 核心梗 / 情绪引擎与卷级升级轴

- **三大高频模式**：
  - **宿敌强强 / 掉马真香**：表面死对头（正邪双骄/同朝政敌/异能搭档/电竞宿敌），因契约、任务或同命蛊被迫绑定同行，互怼互坑中屡屡替对方挡死劫，发现昔日宿敌竟是暗恋/救赎自己多年之人。
  - **穿书重生 / 拯救反派**：主角穿成把反派逼到黑化的炮灰师尊/恶毒兄长/质子监护人，拼命改剧本送温暖，嘴上装严厉冷酷、暗地疯狂护短，却把原本阴郁的反派养成了只黏他一人的偏执粘人精。
  - **亏欠追夫火葬场**：前期一方冷漠漠视把对方当工具或白月光替身，被弃者彻底死心带底牌抽身离去，高位者得知隐秘付出后疯魔追回。
- **卷级升级轴**：被迫绑定与互试底线（卷1：立敌意与温差）→ 并肩破局与隐秘付出曝光（卷2：视差破防、生死相托）→ 立场冲突与共同揭穿幕后黑手（卷3：宿命考验）→ 并肩登顶与圆满相守（卷4）。

## 3. 黄金三章打法

- **第 1 章**：首段直接砸下两人极强戏剧张力的初遇或重逢现场（死对头重伤倒在自己门前、穿书醒来正举着鞭子要抽未来黑化暴君、合约到期递出解约书），300 字内进锋利对白，立住**两人的身份反差与冷热温差**，章末卡在被迫强绑定（同命契/赐婚/共处一室）或一方露出反常执念。
- **第 2 章**：展开首轮互动拉扯与共同小危机！嘴上互损毫不留情，危急关头却默契配合或一方下意识护短，埋下第一个让读者尖叫的「他怎么这么了解他」的暗恋伏笔。
- **第 3 章**：携手打脸挑衅反派或破掉首轮死局，外人震惊于两人截然不同的强悍，同时抛开第一层身世/宿命旧怨钩子。

## 4. 卷内爽点循环与高频章末断章

- **循环节奏**：`外部危机/主线任务推进（双强并肩爽）+ 内部冷热推拉/吃醋试探（关系张力）+ 暗恋视差逐层曝光（偷记的本子/旧伤疤/透支灵力换来的巧合）`。**事业主线与感情线必须死死咬合**，不孤立谈恋爱。
- **高频章末断章**：① 冷面一方替对方硬接致命一击倒进怀里，锁骨下露出早已单方面解开的痛觉共享印记；② 整理对方遗物/书房时翻出写满自己名字的泛黄信笺；③ 嘴硬攻/受终于破防，声音发哑把人扣在门后吐出忍了三年的执念。

## 5. 人设反差、反派梯队与对话声线

- **双主角原则**：**两人都必须有独立闪光点、核心目标与高光时刻**，绝不写一方沦为毫无主见的挂件。常见黄金组合：清冷嘴硬美人 × 偏执黏人忠犬、疯批权臣 × 冷静克制谋士、傲娇死对头 × 腹黑笑面虎。
- **反派梯队**：挑拨离间的势利炮灰 → 代表旧秩序或血海深仇的幕后权贵/魔尊（逼迫双主角立场对撞并最终联手击碎的催化剂）。
- **对话声线**：唇枪舌剑、带刺带钩，嘴上越刻薄、动作越护短；关键破防处一句滚烫直球台词独立成段，形成极强冷热冲击。

## 6. 真·网文原文语感切片（动笔前校准段长、口语与标点）

### 切片 A：黄金开篇（第 1 章前 230 字，宿敌重逢 + 强绑定张力）

```text
暴雨夜，谢清晏推开别院大门，正看见斗了五年的死对头浑身是血倒在石阶上。
堂堂北境少帅萧凛，手里死死攥着半截断刀，玄色战袍被血浸透。
听见脚步声，萧凛艰难抬起眼皮，看清来人竟嗤笑一声。
“真是冤家路窄。谢督主，趁我没力气，动手吧。”
谢清晏撑着黑伞俯视他，神色冷淡：“杀了你，谁查军饷失窃案？”
话音未落，他弯腰扣住萧凛滚烫的手腕，硬生生把人拖进门内。
萧凛闷哼一声，触到谢清晏微凉指尖的一瞬，眼神骤然幽暗。
“谢清晏，你手在抖。”
“闭嘴！”谢清晏甩开他，“再多说一字，我把你扔回雨里！”
```

## 7. 流派专属技法与毒点红线

- **专属技法**：善用「冷叙述并置滚烫细节」制造反差痛；允许在关键高潮后插 1 段简短的另一方视角（或日记/旧物揭秘）把暗恋视差彻底炸开。
- **毒点红线**：① 严禁把其中一方写得软弱无能、全靠另一方包办主线；② 严禁感情线脱离主线任务原地无病呻吟；③ 严禁写无底线伤害后不给足够追悔与补偿就强行和好。
