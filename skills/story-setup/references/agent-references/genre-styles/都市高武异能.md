# 长篇题材包：都市高武 / 灵气复苏与序列异能

> 凶兽与灾变序列降临现代都市，底层学生或边缘武者凭唯一隐藏序列、气血加点面板或词条掠夺，从武考擂台杀穿荒野禁区；底线是战力刻度清晰、数值前后严密、绝不灌百年科普。

## 1. 故事线设计

- **核心爽点主轴**：「选了全校嘲讽的冷门序列 / 穷学生买不起药 → 借旁人立清战力标尺后降维击穿」的炸裂爽感 + 清晰可数的变强进度条。
- **三大验证引擎**：
  - **三章压弹簧 + 阶梯标尺**：不急于第 1 章廉价放招，先由普通同窗、死党与 A 级尖子立清三级战力刻度，压满质疑后主角一招击穿全场。
  - **缺钱驱动 + 数值闭环**：气血值、序列等阶与药费、奖学金绑死，每涨一档都兑现可见破坏力与真金白银回报。
  - **双面灾厄马甲流**：暗拥非人/灭世级序列反杀怪物 ↔ 日常装柔弱高中生或英烈遗孤，配亲友追查自己马甲的错位张力。
- **卷级地图阶梯与防崩**：高中武科班/觉醒基地（测力/实战武考/特招名额）→ 顶级武大/序列学府（新生大比/荒野试炼/百强榜）→ 治安局/异能军部（城外兽潮/秘境清剿）→ 全球与异族战场。换武大或军部地图时回扣旧死党、老教官与世家旧账，绝不写没。

## 2. 常见剧情设计

- **黄金三章切口**：
  - **第 1 章（速建危机 + 反常识抉择 + 蓄而不发）**：用极短新闻广播或警报速立世界危局（禁百年史科普）；切入觉醒反常识抉择（选冷门唯一序列或暗吞猎杀怪），激活面板拿首招后被实战集合或盘查打断，把首秀炸场压到公开考场。
  - **第 2 章（垫脚石标尺压满情绪）**：拉出真凶兽或实战靶场，死党拼尽全力只伤皮毛、多名学生惨败、傲慢天才轰出高分直录名校，全场目光齐压主角。
  - **第 3 章（降维击穿 + 名校/强敌盯上）**：主角上场念诀或一拳轰爆标尺，总教官与招生官失态拍案，拿走特招名额与重奖，引出暗中下手的世家或高阶荒野危机。
- **卷内博弈与高频断章**：按 `危机升级或大比开启 → 竞争对手苦战立高难标尺 → 主角轻描淡写降维破局 → 高层破格加赛或抢人 → 词条与奖金落袋 → 更凶异变逼近` 推进。高频章末断章：① 主角抬手蓄诀、总教官脸色骤变截断在出招前一瞬；② 测力屏冒烟爆表警报响彻全厅；③ 考官临时加赛越阶凶兽后点名「下一个，到你了」；④ 暗巷路灯齐灭，仇家买凶截杀。
- **核心毒点雷区**：① 严禁前两章铺陈全球灵气复苏百年编年史；② 严禁气血与等阶数值前后打架；③ 严禁换图后把旧死党与老教官直接写失踪。

## 3. 人物设计

- **主角人设与底线**：务实缺钱、记账精确、面对嘲讽情绪极稳，出手狠辣绝不留活口；懂护短，跟死党插科打诨接地气。
- **反派梯队（各自私心与有效反制）**：抢资源名额的富家校霸与偏心教导主任（用规则卡报名、买通测评或施压停药，绝非无脑骂街）→ 傲慢世家天才与黑心药商（垄断补剂渠道、暗中设局）→ 邪教高层、人奸与异族统领。
- **关系张力与说话声口**：热血直白、报数干脆（「气血 215，二阶！」），道术/序列咒诀与现代口语交错，拉满反差燃度。

## 4. 正文技巧

- **视角与三级标尺技法**：默认第三人称贴身限知，公开考场与抢人戏可切总教官或招生官视角放大分量；善用「惨败 → 苦战高分 → 主角秒破」三级标尺对照，比直接秒无名怪爽三倍。
- **叙述呼吸与对白短打**：纯叙述揉入主角缺钱算账、临战判断与口语因果，禁抽干心理写摄像头动作清单；考场交锋与死党互动走净白短打对白，不句句捆绑微动作。
- **刀子物件原则**：所有变强与冲突落到气血监测环、序列阶位、缴费单与奖学金三件套，严禁堆砌无功能穿搭材质、教室光影与空洞围观尖叫（禁反复刷「死寂一片、椅子翻倒」）。
- **❌ 烂写法**：`他摩挲着口袋里的缴费单，一拳打出，大厅鸦雀无声、死寂一片，椅子翻倒在地！`
- **✅ 高分改写法**：`石磊摘掉护腕扣上气血监测环，屏幕读数连跳三档拉响过载蜂鸣。范教官捏着钢笔的手悬在记分栏半空，瞪大眼问：“你真是昨天才报名的武科旁听生？”石磊拍拍袖口灰，朝缴费窗口一指：“教官，破纪录的五万奖学金，能现结吗？”`

## 5. 案例片段

### 切片 A：弃版本T0选未知序列 · 校长拍桌冲突

```text
许易无奈地抬起头。
他的对面，校长正怒捶着桌子。
“火属序列！你刚才明明已经觉醒了火属序列！为什么你选择放弃它！”
“你这是犯罪！”
“你知不知道，火属性序列有多珍贵！它是为数不多可以极大克制僵尸的序列！”
“整个学校，觉醒的31个人里，包括你在内才两个火属序列！”
面对劈头盖脸的唾沫星子，许易抹了把脸，有些叹气。
“校长，我说过了，我觉醒的这个序列真的比火属序列更有用……”
“放屁！你觉醒的这序列之前从来没出现过，你怎么知道它有用！就凭一个序列名字？”
```
- **学什么**：直切校长拍桌喷唾沫的高压现场，用「全校31人仅两个火属」立死稀缺价值，借信息差拉满选冷门序列悬念。

### 切片 B：死亡禁区跨线破限 · 绝境反杀

```text
“慌什么！不过是个将死之人！”
为首者强压下心中的忌惮，眼神阴狠：“对不住了，白决首席！”
“多谢你们……废话这么久。”
林沐终于用尽最后一丝力气，将左脚迈到了禁区之外！
“白决首席可曾想过，有朝一日会命丧我等之手！”
为首者五阶觉醒者的气息与身后数十道身影在这一刻同时杀向林沐。
当右脚落地的瞬间，林沐体内一股熊熊火焰之力冲天而起！
赤红色的烈焰如同来自地狱的审判之火，顷刻间，数十道黑衣身影便化为灰烬。
而他残破的躯体在火焰包裹下竟开始以肉眼可见的速度愈合，伤口处的血肉如同重生般生长。
“冰与火，倒是不错。”
```
- **学什么**：拿「迈出禁区线」做倒计时标尺，先借反派轻敌废话压满危机，落地一瞬赤焰反杀兼伤势愈合。
