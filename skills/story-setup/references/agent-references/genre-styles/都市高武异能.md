# 长篇流派包：都市高武 / 灵气复苏与序列异能

## 1. 定位、平台与读者期待

- **一句话定位**：灵气复苏、凶兽肆虐、武道为尊的现代都市，底层穷学生/边缘武者靠外挂面板（气血加点/词条掠夺/异能进化/杀怪爆属性）一路杀穿武考、武馆、城外荒野与异族战场。
- **平台倾向**：七猫男频与番茄男频热门高武赛道，默认第三人称贴身限知，单章 2150–2400 字，极致快节奏、数值清晰、拳拳到肉。
- **读者期待**：「没钱买不起气血丹 → 靠挂疯狂爆数值 → 武考/擂台一拳轰爆测力仪」的暴爽跨阶感 + 清晰可数的变强进度条。

## 2. 核心梗 / 金手指公式与卷级升级轴

- **驱动公式**：`穷（缺气血丹/功法/学费）+ 清晰境界数值（气血值/战力指数/异能评级 F→SSS）+ 高效变强挂（肝熟练度/杀妖爆属性/每日词条）`。**钱和资源是前半段最直白的冲突引擎。**
- **卷级地图阶梯**：高中武科班（月考/武考/助学金/天才班）→ 顶级武大/武馆（新生赛/荒野试炼/百强榜）→ 治安局/异能军部（城外兽潮/邪教秘境）→ 全球/星际万族战场。
- **境界锚点**：开书定清 6–9 个清晰大境界（如一阶到九阶/宗师/武圣），前期每提升 10 点气血都给看得见的战力反差。

## 3. 黄金三章打法

- **第 1 章**：首段直接切入觉醒仪式、气血测试或家徒四壁买不起药剂的紧迫时刻（如妹妹高烧缺钱、校霸抢助学金、测出 F 级废物异能遭全班嘲笑），400 字内冲突爆发，第 1 章必激活气血面板/异能隐藏词条并完成首次数值暴涨，章末卡在明早实战考核或仇家堵门。
- **第 2 章**：实战试刀！面对嘲讽过自己的同学或荒野低阶妖兽，当众一拳打出越级数值，测力仪爆表或一击秒杀，收割第一批震撼与奖金。
- **第 3 章**：拿奖金解决家庭燃眉之急并兑换高级功法，同时被武馆教官/强力反派盯上，甩出全校武考或秘境名额的对赌卡点。

## 4. 卷内爽点循环与高频章末断章

- **循环节奏**：`缺钱买资源 → 刷怪/肝数值破境 → 公开场合（测力/擂台/荒野营救）越级碾压 → 领悬赏/破格录取 → 引出更高阶对手或异兽潮`。每 2–3 章一次数值跳升或小打脸，每 10 章一次大型赛事/秘境收割。
- **高频章末断章**：① 测力碑/气血仪冒烟爆表，教官失声尖叫；② 荒野禁区警报拉响，高阶凶兽降临；③ 面板刷出 SSS 级隐藏词条；④ 死敌动用家族底牌下死手，主角刚好突破新境界。

## 5. 人设反差、反派梯队与对话声线

- **主角人设**：务实、狠辣、护短、极度缺钱（前期算账精确到百元），对敌杀伐果断绝不圣母留活口。
- **反派梯队**：富家子弟校霸/偏心班主任（学校卷）→ 傲慢世家天才/黑心药商（武大/武馆卷）→ 邪教高层/人奸/异族统领（军部/荒野卷）。
- **对话声线**：热血直白带点现代校园/职场吐槽，数据报数干脆（「气血 180，一阶巅峰！」），打斗间台词短硬不啰嗦。

## 7. 流派专属技法与毒点红线

- **专属技法**：所有修炼成果都换成「气血值 / 拳力公斤数 / 奖金数额」三件套直观呈现；打斗强调贴身爆发感（音爆/碎石/倒飞），一回合一招利落分胜负。
- **毒点红线**：① 严禁前期大段科普全球灵气复苏百年编年史；② 严禁战力数字前后打架（昨天 200 打不赢今天突然秒 500 却不给原因）；③ 严禁换地图时把旧武馆/老教官写成毫无用处的纯背景板。
