# 题材正文提示词卡索引

> 谁读：新书写第 1 章前，主会话生成全书题材正文提示卡时读「全书题材正文提示卡」一节和核对报告点名的卡；写手 prompt 没附题材条目时读副本。

> 按题材查阅 `genre-prose-cards/` 中的单卡；全书题材正文提示卡的字段、生成时机和每章抽取只在下方「全书题材正文提示卡」定义。

---

## 使用原则

正文写作采用三件套：**通用正文要求 + 题材正文提示卡 + 本书文风**。

- 题材卡只管题材层稳定核心：世界观/生活逻辑、读者期待、核心爽点/情绪、常见场面、常见钩子和禁止漂移。
- 本书文风管句长、标点、潜台词和笔调；事件、连续性与信息边界服从章节细纲和权威召回。写法冲突时作者这次说的＞本书文风＞对标文风＞题材卡默认。

## 全书题材正文提示卡

题材正文提示卡只在这里定义，全书一份，落盘为 `设定/题材正文提示卡.md`。

1. **生成时机**：写第 1 章前生成一次，之后每章直接读，不重做；作者改了题材定位或换了主对标才重生成。组装脚本的核对报告会给出按「题材类型」匹配到的主辅卡路径，手动查卡时读 `设定/题材定位.md` 确认主题材、平台、主对标和核心梗。
2. **来源**：主题材读 1 张完整单卡；辅题材只摘 1-2 条「常见场面/禁止漂移」，不把两套节奏并行堆满。高置信卡可直接用；中置信卡对照本书对标和细纲；低置信卡只能兜底并标注低置信，优先补同题材对标。「题材类型」匹配不到任何卡时，组装脚本报出的是下方「兜底卡」，照同一流程用：从最接近的流派一节抽 3-5 条，按低置信处理。
3. **字段**（全书通用，不含任何一章的取舍）：

```markdown template=题材正文提示卡
## 题材正文提示卡

- 主题材 / 平台：{如 番茄男频·都市高武}
- 题材边界：{读起来必须是什么味，不能串到什么味}
- 核心逻辑：{世界观/社会关系/生活压力/能力规则如何驱动冲突}
- 读者期待：{读者进来等什么}
- 核心爽点 / 情绪：{最稳定的 1-3 个释放方式}
- 正文落点：{开场、冲突、结尾常落在哪些物件和场面}
- 前中后期写法：{各阶段主要怎么写}
- 场景颗粒：{账单/门店/宗门规矩/弹幕/案件线索等具体载体}
- 对话与人物声线：{台词承担什么功能，哪些角色不能说成同一种腔}
- 禁止漂移：{不能变成说明文、纯设定、纯撒糖、纯战报等}
- 卡片置信度：{高/中/低}
```

4. **每章抽取**：每章传给写手的 `genre_prose_card` 从全书卡里抽本章相关条目，120-300 字，按单卡「取舍原则」决定留哪几条；本章怎么取舍只进这一章的任务包，不写回全书文件。
5. **题材卡只在写手内部校准题材味，正文只输出故事**：不写卡名、题材标签、置信度、条目编号、「证据摘要」数据，或「已按题材卡/满足字数/零违规」等过程自评。题材卡不改剧情顺序、不替换人设、不覆盖 `剧情/情绪模块.md` / `剧情/节奏.md` 的权威召回。

## 题材卡写法原则

每张题材卡必须回答九件事：题材核心、主线目标、冲突发动机、爽点定位、常见情绪转化、场景颗粒、正文落点、前中后期写法和禁止漂移。以“都市日常”为例：先给生活目标，再说明低烈度冲突如何改变关系或处境，把开场、冲突和结尾落到具体物件与场面，写出细小但实在的爽点。各题材保留自己的冲突和释放方式。

## 不要把这些写成硬规则

本地长篇样本不支持固定 50-60 字行宽、固定 50%-60% 对话占比、全局替换“地/得/很/像/顿号”、随机倒装、三胺八情或三翻四震等机械模板。题材卡只给“该题材更常用的场面和情绪落点”，具体段落仍按细纲、文风和当前场景处理。

## 低置信题材卡

当前无低置信单卡。新增低置信卡时，只能作为初稿方向；写作前必须优先读取同题材对标书、用户设定和最新扫榜结果。

---

## 低置信题材使用提示

低置信卡不能单独决定正文。写作前补三件事：

1. 同题材对标书的 `剧情/情绪模块.md` 与 `剧情/节奏.md`。
2. `设定/文风.md` 或对标 `文风.md`，确认句长、声线和段落节奏。
3. 本章细纲里的目标情绪、出场顺序、信息差和章尾钩子。

若三件事缺两件以上，只生成临时提示卡并标注“低置信”，不要让题材卡压过细纲。
