## 人物关系类型

查表确定角色间的关系类型，然后按原则执行。

| 关系类型 | 定义 | 功能 | 示例 |
|---------|------|------|------|
| 冲突型 | 双方利益/理念对立 | 制造张力，推动情节 | 宿敌、竞争对手 |
| 联盟型 | 双方有共同目标 | 提供助力，制造羁绊 | 战友、师徒 |
| 亲密型 | 情感纽带连接 | 制造软肋，提供情感支点 | 恋人、家人、兄弟 |
| 权威型 | 上下级/支配关系 | 制造压力，限制主角行动 | 师父、老板、监管者 |

**执行规则**：
- 重要关系要有演进弧线：可以是共同扛事后从生疏客套到默契托底，也可以是经历分歧、误解或背叛后改写位置，不为凑戏剧性给稳定亲友硬塞背叛
- 禁止所有关系从头到尾停在表面客套、毫无推进
- 关系的功能必须服务于情节，不能只为甜/虐而存在

## 感情流人设核心法

感情流中剧情为人设服务——每次剧情都要丰满人物或推动感情发展，否则就是无效剧情。

### 构建步骤

1. **确定人设核心**：定下最鲜明的身份或处境标签（如“想夺嫡的病弱皇子”“外冷内热的掌印女官”）。
2. **围绕核心发散**：回查这个核心由哪些经历、环境影响与性格成因形成。
3. **延伸剧情线**：核心自带的剧情必须写（有目标→目标线；有伤痛→治愈线）

### 执行规则

- 两个主角都必须有闪光点和独立变化路线，不能一个人出彩另一个人黯淡
- 高光不等于装逼——所有让读者对角色印象深刻的时刻都是高光，包括痛彻心扉的时刻
- 生命不止恋爱——角色心里希望恋爱，但生命里不能只有恋爱，只有恋爱的角色立不住、很单薄
- 先把角色当人写：做决定时性别身份的成分不压过人本身；写不出两人的互动，先按挚友来写，再往里加心动和在意

## 感情线阶段

全书只用这套阶段名。好感和关系阶段取低的那个；CP 行为超出所在阶段就突兀，好感不够写肢体亲密就油腻。

| 阶段 | 好感门槛 | 可写的 CP 行为（含前段） | 卷级位置 |
|---|---|---|---|
| 相识 | 零或负 | 第一印象、旁人评价有落差、互相设防 | 感情线入场的单元 |
| 试探 | 至少一方半好感 | 特殊待遇、察觉情绪并安抚；单方付出要有回响。跨章推拉交替（靠心结或误会拉开，不分手），单场只写好一次破例照拂或分寸松动，不硬塞误会 | 最长一段，跨多个单元，可整卷停在此 |
| 确认 | 双方半好感以上 | 交底、护短、吃醋宣示主权、决定先想着对方；捅破窗户纸后才写肢体亲密 | 某卷高潮单元，和事业线大事件同场兑现 |
| 考验 | 双方满好感 | 牺牲、并肩、不用商量的默契 | 确认之后的卷；阻碍取身份差距、家族反对、误会或使命冲突，没阻碍就白给；虐要分散，每段后给反转或糖 |
| 定局 | 满 | 日常糖、一起对外 | 最大阻碍解决后，即题材定位里「核心情感确定」那一卷；只发糖，不造新的感情矛盾 |

- 阶段可跳可退，要有触发事件。
- 社会关系和好感别同步：表面夫妻好感为零，或好感拉满嘴上不认，错位就是戏。
- 事业为主：感情戏最多占一成，每次升级踩在主角的事业成就上，可以停在试探或确认、结局再定。感情为主：事业线情节都要促成相识、关系变化或考验。女频长篇：升级踩在女主的事业进展或成长上，前慢后快。
- 后宫：逐个暧昧、结局再确认，不能确认一个再攻略下一个。

## 男频与女频感情线

**先确定目标读者群，再选择对应逻辑。两者不可混淆，否则读者会觉得"不对味"。**

### 先定感情线靠什么撑

从两种里选一种撑全书感情线：一是有戏剧性的过程（禁忌之恋、追妻火葬场），每个阶段有不同的情绪链；二是有戏剧性的人设组合，全书观感来自两人的互动模式。互动模式一旦建立就保持到结尾，改了等于换掉读者追书的理由。

### 男频：展示优秀

| 维度 | 说明 |
|------|------|
| 核心 | 借优秀伴侣的认可与倾心侧面印证主角的价值与魅力，感情推进与主线破局互为助力 |
| 吸引逻辑 | 因主角在关键选择、能力或担当上的不可替代而产生吸引，有来有往，不当单向卑微讨好者 |
| 围观者反应 | 从质疑或看轻，转为羡慕并认可两人的实力与默契 |

写法要点：

- 把感情推进融进事件：靠共同破局、化解危机、利益交锋和彼此兜底让好感自然升温（阶段名仍用上面那套）：路人 → 产生好感（随手解围或合作顺畅）→ 认可为人（危局中挺身而出）→ 信任盟友（理解彼此底线与难处）→ 心照不宣（看到对方只向自己展露的一面）。
- 有来有往，不卑微讨好也不写盲目倒贴：主角重事业与目标，不靠放下尊严讨好换感情；女方的主动与偏爱要建立在共同经历和真实利益/情感触动之上，铺垫够了才不是白给。
- 极简构型：破局结缘（共同面对困境或主角出手破局，建立初始信任）→ 主线同行（在主线舞台上各自发挥不可替代的作用，互为见证与后盾）→ 外压催化（共同对抗强敌或外部阻碍，事业突破与关系升温同步兑现）。
- 女主有自己的事业线和目标，和主角有交叉但独立；感情节奏跟着主线走，低谷时彼此托底，高峰时共享成果。

写女主对主角好：

| 女主类型 | 付出方式 |
|---------|---------|
| 自卑社恐 | 偷偷帮忙塞东西但害怕被发现 |
| 傲娇型 | 用心做便当但嘴硬"做多了顺便带的" |
| 直率泼辣 | 大大方方送礼物或直球表白 |

善用对比：

| 对比类型 | 操作 |
|---------|------|
| 时间线对比 | 女主刚认识主角时 vs 熟悉后的态度变化 |
| 双标 | 不允许别人摸头但主角可以 → 凸显特殊地位 |
| 信息差 | 男女主双重身份（网上vs现实）→ 期待揭穿时反应 |

两线融合检查：删掉感情线后，事业线失去了哪些动机、资源或选择？删掉事业线后，感情线失去了哪些相识、考验或关系变化？若毫无影响或只剩孤立糖点，补两线的因果联系。

### 女频：深化连接

| 维度 | 说明 |
|------|------|
| 核心 | 不可替代的偏爱与相知——哪怕剥去家世、财富或名分，对方仍是唯一坚定选择的人 |
| 双方底色 | 优先双洁或身心唯一，重点写出「只对彼此敞开软肋、只给彼此例外」 |
| 围观者反应 | 从看轻或唱衰，变成看出两人之间旁人插不进脚的默契与护短 |

怎么设计「深化连接」的事件台阶（忌一上来就深情表白）：

- **看穿表象（相识）**：旁人只看到他的权势或她的顺从名分，唯独对方看穿底下的隐疾、委屈或真本事（如满座宾客都在奉承权贵，唯独女主看出他指尖发白是在强忍旧疾，不动声色递去温茶与伤药）。
- **例外护短（试探）**：对旁人冷淡守规矩，唯独在她受刁难时破例撑腰，且尊重她的意愿（替她镇住场子，把讨回公道的刀递到她自己手里）。
- **舍利托底（确认与考验）**：当婚约名分、家族利益或前途与对方冲突时，宁可舍掉外在筹码也先护住对方，用行动坐实「看重的是你这个人」。

## 感情线单元模板

| 模板 | 怎么搭这一小段剧情 |
|------|------|
| 好感度变化 | 借一件具体事让一方改观（升温：撞见对方背地里替自己挡了难处；降温：误以为对方接近自己是另有所图），结尾落在态度松动或冷淡下来的一个日常动作上 |
| 借势撑腰 | 伴侣当众给排面、替主角压住势利眼配角，让主角借伴侣的势痛快打脸 |
| 争风吃醋 | 优质配角主动示好引出伴侣危机感（重点写伴侣吃醋护食，不写主角卑微吃醋） |
| 跨过阻碍 | 外部阻碍（长辈棒打鸳鸯、流言构陷、异地调任）卡住两人 → 双方各自行动破局而非干坐着哭 → 联手闯过去后关系更进一步 |
| 狗粮日常 | 把稳定的人设反差放进新日常里（如高冷权臣笨拙帮女主剥虾、算家用），升温靠共渡难关与彼此懂得，不靠机械堆叠亲吻牵手 |

### 人设改变的双向翻转

- **靠事件推进的感情线（两人都变、位置对调）**：前期她仰望追随、他冷淡疏离，历经生死或误会解开后，变成她冷静退后、他反过来患得患失处处迁就。
- **靠日常互动撑的感情线（模式不变、谁先低头对调）**：比如欢喜冤家，升级后两人照样拌嘴互损，只是从前是她闯祸求他兜底，现在变成他先替她把事扛了、嘴上还得找借口要她领情。
- 无论哪种翻转，都要从人物原有的性格长出来（高冷的人动心后是笨拙护短，不是突然变话痨），避免像换了个人。

## 多角关系：修罗场与后宫

修罗场本质是一种矛盾，控制对抗烈度，不能让爱情线对象之间出现不可调和的矛盾。

| 收场方法 | 操作 |
|---------|------|
| 关联回事业线 | 让爱情线对象们把争风吃醋转化为"比谁对主角事业线贡献更大" |
| 插入事业线突发事件 | 对抗进入白热化时，用突发事件让所有人从内斗切换成一致对外 |
| 一笔带过 | 最多两人互相看不惯、说两句嘲讽话就过去，非常克制 |

后宫文要弱化男主"主动渣"的感觉，让女主自身的设定推动后宫；开书前定好每个女主的核心特质，价值观和背景各不相同。

## 配角与关系推进

### 配角从隔阂到改观的台阶（缓冲区）

配角对主角从轻视、设防到服气的态度转变，本身就是一条好看的拉扯线。想让这条线撑得住，两人之间要先留一层**隔阂或信息差（缓冲区）**——比如只在网上交手没见过真人、只听过外人传的恶名、身份悬殊看不起主角，或者一方瞒着真实马甲。

怎么排这条改观线：

1. **先立住初始距离或隔阂**：出场时写清两人卡在哪一层（如只在网上交手不知真人身份、因门第立场互相设防，或名门师姐只听说主角是走后门进来的废柴）。
2. **在卷纲里排 5~7 个接触拐点**：每次事件拉近一层距离或打掉一层偏见，别让配角一章之内就彻底交底或死心塌地。
3. **每次拐点写出具体的态度变化**：从「公事公办/当面冷嘲」到「暗中留心/顺手解围」，再到「听说主角遇险主动相帮」，最后在掉马或大高潮时彻底改观。
4. **留一点未捅破的窗户纸**：比如配角已经佩服主角的化名身份，却还不知道那就是平时被自己嫌弃的同门，等掉马那一刻爽感翻倍。

执行规则：

- 配角不能像NPC一样站着等主角触发
- 配角要有自己的行动，由配角观点引出事件
- 正面角色也一样：和主角立场相同的人也应有自己的行动和动机

### 竞争者与亲友阻力

竞争者（鲶鱼效应）：

- 定位：给男主/女主增加紧迫感与压力，推动关系确认
- 重点放在高潮节点之前，作为升温铺垫
- 等关系确认或高潮过后再硬塞情敌作用不大，不拿来水字数续命

亲友态度（助力与阻力）：

- 双方长辈或亲友的态度可做关系试金石：高潮前可提供资源、情报或退路兜底；转折节点可因门第、立场或旧怨设障，逼主角拿出实力或决断赢得认可。

---

### 身份认知差

同一个人在世俗、本人、恋人、情敌、路人眼里的身价各不相同，这种评价差就是现成的冲突来源，也是恋爱文的核心爽点之一。

### 亦敌亦友

最有魅力的人物关系类型。

- 前提：两个角色本身都要有魅力，否则只是强行五五开的狗皮膏药
- 核心：彼此高度认可，立场却绝对冲突，由此生出惺惺相惜；少了一头魅力全无
- 真正的宿敌必须双方打心底相互认可，旁人起哄盖章不算

## 质量检查清单

每次完成角色关系/感情线设计后，逐项核查：

- [ ] **关系类型明确**：每个重要关系已归类为冲突/联盟/亲密/权威之一
- [ ] **关系有弧线**：每个重要关系至少经历一次考验或变化
- [ ] **人设有核心**：主角人设有明确的核心特征和发散依据
- [ ] **CP 行为不越阶段**：好感和关系阶段取低的那个，没捅破窗户纸不写肢体亲密
- [ ] **感情线支撑已二选一**：靠过程撑还是靠人设互动撑已定；靠人设撑的，核心互动模式全书不变
- [ ] **读者群对味**：男频围绕"展示优秀"设计事件，女频围绕"深化连接"设计事件
- [ ] **配角有行动**：配角不是NPC式站桩等待触发，有自己的行动和动机
- [ ] **修罗场可控**：多角关系中对象之间无不可调和的矛盾
- [ ] **定局后不造新矛盾**：最大阻碍解决后只发实在的 CP 行为糖
- [ ] **角色不止恋爱**：角色生命中有恋爱之外的内容，不是单薄的情感工具人
