## 人物关系类型

查表确定角色间的关系类型，然后按原则执行。

| 关系类型 | 定义 | 功能 | 示例 |
|---------|------|------|------|
| 冲突型 | 双方利益/理念对立 | 制造张力，推动情节 | 宿敌、竞争对手 |
| 联盟型 | 双方有共同目标 | 提供助力，制造羁绊 | 战友、师徒 |
| 亲密型 | 情感纽带连接 | 制造软肋，提供情感支点 | 恋人、家人、兄弟 |
| 权威型 | 上下级/支配关系 | 制造压力，限制主角行动 | 师父、老板、监管者 |

**执行规则**：
- 每个重要关系至少安排一次考验（背叛/牺牲/误解）
- 关系必须有变化弧线（敌人变盟友、盟友变对手）
- 禁止所有关系都是"你好我好"的铁板一块
- 关系的功能必须服务于情节，不能只为甜/虐而存在

## 感情流人设核心法

感情流中剧情为人设服务——每次剧情都要丰满人物或推动感情发展，否则就是无效剧情。

### 构建步骤

1. **确定人设核心**：写下最初出现在脑海里的角色特征（如"想登上皇位的皇子""病弱皇子"）
2. **围绕核心发散**：回查这个核心由哪些经历、环境影响与性格成因形成。
3. **延伸剧情线**：核心自带的剧情必须写（有目标→目标线；有伤痛→治愈线）

### 执行规则

- 俗套剧情配上丰满人设也能脱离套路感
- 两个主角都必须有闪光点和独立变化路线，不能一个人出彩另一个人黯淡
- 高光不等于装逼——所有让读者对角色印象深刻的时刻都是高光，包括痛彻心扉的时刻
- 生命不止恋爱——角色心里希望恋爱，但生命里不能只有恋爱，只有恋爱的角色立不住、很单薄
- 先把角色当人写：做决定时性别身份的成分不压过人本身；写不出两人的互动，先按挚友来写，再往里加心动和在意

## 感情线阶段

全书只用这套阶段名。好感和关系阶段取低的那个；CP 行为超出所在阶段就突兀，好感不够写肢体亲密就油腻。

| 阶段 | 好感门槛 | 可写的 CP 行为（含前段） | 卷级位置 |
|---|---|---|---|
| 相识 | 零或负 | 第一印象、旁人评价有落差、互相设防 | 感情线入场的单元 |
| 试探 | 至少一方半好感 | 特殊待遇、察觉情绪并安抚；单方先做要给回报，否则像舔狗。推拉交替，拉开靠心结、冷静期或误会，不分手；每次互动有甜有酸 | 感情戏最长的一段，跨多个单元，可以整卷停在这里 |
| 确认 | 双方半好感以上 | 交底、护短、吃醋宣示主权、决定先想着对方；捅破窗户纸后才写肢体亲密 | 某卷高潮单元，和事业线大事件同场兑现 |
| 考验 | 双方满好感 | 牺牲、并肩、不用商量的默契 | 确认之后的卷；阻碍取身份差距、家族反对、误会或使命冲突，没阻碍就白给；虐要分散，每段后给反转或糖 |
| 定局 | 满 | 日常糖、一起对外 | 最大阻碍解决后，即题材定位里「核心情感确定」那一卷；只发糖，不造新的感情矛盾 |

- 阶段可跳可退，要有触发事件。
- 社会关系和好感别同步：表面夫妻好感为零，或好感拉满嘴上不认，错位就是戏。
- 事业为主：感情戏最多占一成，每次升级踩在主角的事业成就上，可以停在试探或确认、结局再定。感情为主：事业线情节都要促成相识、关系变化或考验。女频长篇：升级踩在女主的事业进展或成长上，前慢后快。
- 后宫：逐个暧昧、结局再确认，不能确认一个再攻略下一个。

## 男频与女频感情线

**先确定目标读者群，再选择对应逻辑。两者不可混淆，否则读者会觉得"不对味"。**

### 先定感情线靠什么撑

从两种里选一种撑全书感情线：一是有戏剧性的过程（禁忌之恋、追妻火葬场），每个阶段有不同的情绪链；二是有戏剧性的人设组合，全书观感来自两人的互动模式。互动模式一旦建立就保持到结尾，改了等于换掉读者追书的理由。

### 男频：展示优秀

| 维度 | 说明 |
|------|------|
| 核心 | "外在因素展示"——主角和对象在一起体现两人的外在因素多优秀 |
| 三种核心逻辑 | "她要是我的该多好" → "这么优秀的人是我的了" → "这么优秀的人都喜欢我，我更优秀" |
| 围观者想法 | "能得到这么优秀的人，我好羡慕"（非"恋爱好甜"） |
| 认可 | 被优秀的人认可，等于证明主角优秀 |

读者要的是被需要、被在乎的情绪价值，加上女主条件好、配角羡慕带来的面子。写法要点：

- 把恋爱当升级文写：每个事件是一次升级，靠冲突、化解、理解和共鸣让好感往上走。好感在相识、试探、确认三段里可以这样一步步升（只是好感变化的例子，阶段名仍用上面那套）：路人 → 好人（随手帮了忙）→ 正直勇敢（挺身而出）→ 朋友（理解对方的家庭难处）→ 喜欢但不自知（看到彼此不为人知的一面）。
- 主角不主动追求：读者反感舔狗。主角追事业，帮女主是举手之劳，女主因此记住他、倒追；倒追和白给的区别在于铺垫有没有说服力。
- 极简构型：英雄救美（女主陷入困境，主角用金手指或实力解决，建立初始好感）→ 事业舞台（主角在事业上展示，女主在场作为重要观众）→ 对手衬托（情敌同时是事业对手，打败他事业和感情双重爽）。
- 女主有自己的事业线和目标，和主角有交叉但独立；感情节奏跟着事业走，事业低谷时感情拉扯，事业高峰时感情升温。

写女主对主角好：

| 女主类型 | 付出方式 |
|---------|---------|
| 自卑社恐 | 偷偷帮忙塞东西但害怕被发现 |
| 傲娇型 | 用心做便当但嘴硬"做多了顺便带的" |
| 直率泼辣 | 大大方方送礼物或直球表白 |

善用对比：

| 对比类型 | 操作 |
|---------|------|
| 时间线对比 | 女主刚认识主角时 vs 熟悉后的态度变化 |
| 双标 | 不允许别人摸头但主角可以 → 凸显特殊地位 |
| 信息差 | 男女主双重身份（网上vs现实）→ 期待揭穿时反应 |

两线融合检查：删掉感情线后，事业线失去了哪些动机、资源或选择？删掉事业线后，感情线失去了哪些相识、考验或关系变化？若毫无影响或只剩孤立糖点，补两线的因果联系。

### 女频：深化连接

| 维度 | 说明 |
|------|------|
| 核心 | "连接"——两人之间唯一、坚不可摧、最优先的情感连接 |
| 连接要求 | "我爱的是你这个人，外貌、财富、才华都不能替代这份连接" |
| 纯洁性 | 连接形成后应逐渐舍去外在因素影响 |
| 双方 | 最好初恋+双洁——保障连接的纯洁性和唯一性 |
| 围观者想法 | "他们的恋爱好甜，我好羡慕" |

写女频感情线时，围绕"深化连接"设计事件。

## 感情线单元模板

| 模板 | 核心 |
|------|------|
| 好感度变化 | 可能升/降/已降 → 各自处理路径 → 余韵 |
| 受益 | 享受伴侣带来的好处 = 爱情线装逼核心 |
| 争风吃醋 | 多角色为主角争风，不是主角吃别人醋 |
| 发展受阻 | 阻碍→试图解决→解决→余韵 |
| 狗粮 | CP 日常互动。稳定的人设组合放进变化的情境，循环可以一直用；升温靠共同困境、互相理解、意外发现，不靠身体接触一级级升，牵手、接吻都是一次性的 |

### 人设改变的双向翻转

- 靠过程撑的感情线，关系升级时最好两个人都变，变完恰好和之前两人的对应关系反过来
- 靠人设组合撑的，翻的只是表面位置（谁求谁、谁护谁），谁主导、怎么斗嘴这套互动模式不变
- 改变基于原人设局部调整，和原人设保持密切联系，避免随意改造

## 多角关系：修罗场与后宫

修罗场本质是一种矛盾，控制对抗烈度，不能让爱情线对象之间出现不可调和的矛盾。

| 收场方法 | 操作 |
|---------|------|
| 关联回事业线 | 让爱情线对象们把争风吃醋转化为"比谁对主角事业线贡献更大" |
| 插入事业线突发事件 | 对抗进入白热化时，用突发事件让所有人从内斗切换成一致对外 |
| 一笔带过 | 最多两人互相看不惯、说两句嘲讽话就过去，非常克制 |

后宫文要弱化男主"主动渣"的感觉，让女主自身的设定推动后宫；开书前定好每个女主的核心特质，价值观和背景各不相同。

## 配角与关系推进

### 配角攻略缓冲区

配角对主角态度的变化过程 = 主角攻略配角的过程，伴随巨大的期待感和爽点。

缓冲区类型：线上线下、背后议论、异地相处、地位差距、亲密度差距、信任程度、信息差等。

操作步骤：

1. 始终保持缓冲区存在
2. 在卷纲中挑出事件拐点（5~7个）
3. 在每个拐点处标注配角状态和对主角的态度变化
4. 每次攻略到关键点位时，配角的态度变化必须写清楚
5. 态度变化本身就产生情绪波动和期待感

执行规则：

- 配角不能像NPC一样站着等主角触发
- 配角要有自己的行动，由配角观点引出事件
- 正面角色也一样：和主角立场相同的人也应有自己的行动和动机

### 竞争者与亲情线

竞争者（鲶鱼效应）：

- 定位：给男主/女主增加紧张感上压力 → 推动攻略进度
- 剧情设置重点在"高潮节点前" → 属于铺垫环节
- 对高潮后续写剧情作用不大 → 不是续命手段

亲情线的四个方向：

| 方向 | 作用 | 使用时机 |
|------|------|---------|
| 男方助力 | 提供金钱地位权力 | 高潮前发挥 |
| 男方阻力 | 设置障碍让主角得到认可 | 节点前后都能用 |
| 女方助力 | 温柔乡感情补给站 | 高潮前发挥 |
| 女方阻力 | 父母不同意→为了认可去努力 | 节点前后都能用 |

助力主要在高潮前，阻力节点前后都能用，阻力更好发挥。

### 身份认知差

同一个人在世俗、本人、恋人、情敌、路人眼里的身价各不相同，这种评价差就是现成的冲突来源，也是恋爱文的核心爽点之一。

### 亦敌亦友

最有魅力的人物关系类型。

- 前提：两个角色本身都要有魅力，否则只是强行五五开的狗皮膏药
- 核心：高度认可 + 绝对冲突 → 惺惺相惜 → 缺一魅力全无
- 真正的宿敌 = 双方相互认可，外人盖章不算

### 绿茶/负面角色

- 可以推动剧情但要谨慎使用
- 确认该角色是否有不可替代性
- 主角强势时任何角色都能变正反馈
- 主角弱势时负面角色会被读者恨

## 质量检查清单

每次完成角色关系/感情线设计后，逐项核查：

- [ ] **关系类型明确**：每个重要关系已归类为冲突/联盟/亲密/权威之一
- [ ] **关系有弧线**：每个重要关系至少经历一次考验或变化
- [ ] **人设有核心**：主角人设有明确的核心特征和发散依据
- [ ] **CP 行为不越阶段**：好感和关系阶段取低的那个，没捅破窗户纸不写肢体亲密
- [ ] **感情线支撑已二选一**：靠过程撑还是靠人设互动撑已定；靠人设撑的，核心互动模式全书不变
- [ ] **读者群对味**：男频围绕"展示优秀"设计事件，女频围绕"深化连接"设计事件
- [ ] **配角有行动**：配角不是NPC式站桩等待触发，有自己的行动和动机
- [ ] **修罗场可控**：多角关系中对象之间无不可调和的矛盾
- [ ] **定局后不造新矛盾**：最大阻碍解决后只发实在的 CP 行为糖
- [ ] **角色不止恋爱**：角色生命中有恋爱之外的内容，不是单薄的情感工具人
