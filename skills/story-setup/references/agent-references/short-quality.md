# 短篇质量覆盖

> 与 `agent-quality.md` 配套，仅在 `short` profile 加载；同时遵循 `short-deslop.md` 卖点保护。按网络短篇全篇与小节审查，长篇黄金三章、慢热铺垫与卷级周期不适用。

## 开门见山导语

- [ ] 导语 150–300 字直接抛核心冲突、人设反差、高能奇观或底牌信息差，不写「导语」二字；知乎盐言置 `1.` 前，七猫/黑岩/点众/番茄允许首章开头内嵌导语（后接 `……`/`1.` 切入正文）。
- [ ] 开头一两段直入冲突、异常或对话，零纯景物/背景说明书铺垫；免费段（1–3 节）控制体量避免撑爆付费线；导语承诺必须在正文现场兑现，严禁导语诈骗。
- [ ] 商业爆款开局范式只要赌注具体、人设鲜明即不因「套路化」扣分。

## 付费卡点与分题材节奏

- [ ] 全文约 32%–44%（约三四成处）免费末节卡在未完成动作、底牌将亮、身份将揭、高张力台词或两难危机上，核心大爽点不在免费段放完。
- [ ] 每节有明确的冲突动作、对白刺点或局势翻转（不硬凑事件条数），非末节节尾有明确勾手，禁前段纯回忆流水账或原地车轱辘重复。
- [ ] 按题材走四种常见节奏，不拿单一模板误杀：①打脸爽文（35%–45% 起连环反击/打脸）；②知乎脑洞吐槽/甜宠（高密度反差/笑点/糖点推进，前 40% 不强求苦大仇深）；③意难平/死人文学/男频追夫（允许蓄压至 50%–55% 爆发，靠迟来崩溃或日记/证据反转兑现）；④悬疑（公平线索与留白）。

## 人设、对话与竖屏网感

- [ ] 默认第一人称「我」在场叙述（含男频世情/追夫反杀；幻想/仙侠或另有设定可第三人称），允许口语吐槽、主观审判与极少使用的剧透句（如 `他们不知道…`，通常仅放导语末或关键转折）。
- [ ] 竖屏短段（动作台词分行、狠话独行、叙述一两三句换气）为主，对话独立成行并担主推力（知乎吐槽/悬疑可多写内心独白），核心交锋直进引号（禁「他说…」间接引语概括），避免连续大段文字墙与跨节人名/姓氏/金额漂移。
- [ ] 高辨识度标签人设、直球交锋、围观震惊、反派自爆与明确触发下的快速心死/翻脸属短篇常见桥段；仅悬疑推理题材按公平线索与逻辑链严审。

## 清算收尾与审查要点

- [ ] 终局按题材兑现：爽文反派付实质代价、主角高位退场，善用**首尾物件/台词呼应**反扣开篇；现实世情允许「克制边界 + 微光回甘」收尾；悬疑允许留白；禁强行洗白与空泛哲理尾。
- [ ] 阻断项和高风险项须给出可定位原文、阅读后果与最小修法（改哪一节、补哪拍冲突或前移卡点），同类症状合并根因、不重复计数。
