# 短篇质量覆盖

> 与 `agent-quality.md` 配套，仅在 `short` profile 加载；同时遵循 `short-deslop.md` 卖点保护。按网络短篇全篇与小节审查，长篇黄金三章、慢热铺垫与卷级周期不适用。

## 导语与冷开场

- [ ] 导语 150–300 字直接抛核心冲突、人设反差、高能奇观或底牌信息差，不写「导语」二字。
- [ ] 前 100 字内直入冲突、异常或对话，零纯景物/背景说明书铺垫；首节体量可略拉长（约 1300–1500 字）立住仇恨或核心钩子。
- [ ] 商业爆款开局范式只要赌注具体、人设鲜明即不因「套路化」扣分。

## 付费卡点与推进节奏

- [ ] 全文约 30%–40% 免费末节卡在未完成动作、底牌将亮、身份将揭、高张力台词或两难危机上，核心大爽点不在免费段放完。
- [ ] 每节有 2–3 个具体微节拍（冲突动作、对白刺点或局势翻转），非末节节尾有明确勾手，不把单一平淡事件注水成千字。
- [ ] 约 40% 起持续交付连环打脸、反制、掉马、反差爽点或剥洋葱反转，不拖到 80% 才动。

## 人设、对话与竖屏网感

- [ ] 默认第一人称「我」在场叙述（另有设定照设定），允许口语吐槽、主观审判与信息差剧透。
- [ ] 竖屏一句一段或紧凑短段为主（中位约 20 字），对话独立成行并驱动主要推进（参考 30%–40%），避免连续 >80 字大段书面叙述。
- [ ] 高辨识度标签人设、直球交锋、围观震惊、反派自爆与明确触发下的快速心死/翻脸属短篇常规引擎；仅悬疑推理题材按公平线索与逻辑链严审。

## 清算收尾与审查输出合同

- [ ] 终局明账清算（反派付实质代价、主角高位/畅快退场、火葬场悔疯或强后劲反转），不强行洗白，不用空泛哲理或模糊留白草草收口。
- [ ] 阻断项和高风险项须给出可定位原文、阅读后果与最小修法（改哪一节、补哪拍冲突或前移卡点），同类症状合并根因、不重复计数。
