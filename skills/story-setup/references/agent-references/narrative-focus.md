# 叙事用笔：让篇幅落在值得经历的地方

本文件检查场景与段落组的详略。表达修法见 [expression.md](expression.md)，需要改变事件或人物选择时见 [story-logic.md](story-logic.md)。取舍服从 [style-resolution.md](style-resolution.md) 的文风裁决。

## 从场景作用找到重心

通读一场连续的戏，用一句话说明它要让读者经历什么：一次选择、交涉转向、关系变冷、发现误会，也可以是生活处境、松弛、氛围或余韵。只作为本次判断依据，不强制生成逐段标签或新附件。

沿正文找最需要被经历的地方：人物何时改变判断，哪句话使交涉转向，犹疑怎样走到决定，某个日常细节怎样拉近或拉开关系。对照实际篇幅，指出具体的过详或过略。场景重心没有展开时，先检查原文、前后文或已定设计是否已有过程，不能用一批感官细节顶替。

| 问题 | 看什么 | 怎么处理 |
|---|---|---|
| 次要过程占住篇幅 | 开门、倒水、赶路、逐件清点被连续展开，却不改变人物处境或读者感受 | 压成必要承接，留能建立空间、声口、关系或氛围的细节 |
| 关键过程被概述吞掉 | “商量妥了”“三言两语解释清楚”“她终于想通了”替代选择或交锋 | 展开已有条件、试探、判断和反馈；依据缺失时转故事诊断，不编造说服理由 |
| 同类对象平均用力 | 三个人、四件物品各给同样篇幅，读者找不到重心 | 围绕此场作用分配；重要对象展开，其他对象概括或略过，不规定递减次数 |
| 状态原地打转 | 反复写害怕、愤怒、沉默，人物的理解和行动始终相同 | 合并复述，保留会改变下一步或积累体验的过程 |
| 只见结果、不见过渡 | 上句拒绝、下句答应；情绪突然抵达 | 找回已有承接；若成立条件从未设计，提出故事修法 |

“平”可能来自重心写薄，也可能来自故事没有足够的变化。先判断是哪一种，避免把所有慢场景都压短。

## 删除、压缩、展开各有检验

**删除测试**：删去后，是否损失事实、伏笔、因果、空间方向、人物声口、关系、情绪持续时间或审美体验？没有损失可以删除，包括整段；有损失则保留有效部分或压缩表达。无须给每个细节编出后续情节用途。

**压缩测试**：用一句概述替代后，读者是否只知道结果，却无法体会人物怎样走到这里？如果丢掉必要的犹疑、交锋或情绪抵达，就保留展开。事实未丢只是一项检查，不能据此抹平生活质感。

**展开测试**：新增的每一轮有没有使信息、处境、判断、关系或感受发生变化？同一情绪可以持续，停顿也有时间感；只换措辞强调强度的反应链应收拢。原文已有的分阶段变化可以分段演出，不因相邻出现动作、感知、反应就判重复。

重排后通读整场：读者还能知道谁在哪里、为什么停下、下一步为何发生吗？删过头导致电报体时，恢复必要的主体、连接和承接，不恢复模板解释。遵守作者字数范围；若有效内容不足以满足下限，报告缺口，不用微动作或新事件补齐。删改比例只描述实际变化，不决定哪些废话必须保留。

## 细节要服务这场戏

- **动作**：保留带来阻碍、失败、选择、关系或人物习惯的动作。没有必要逐次记录伸手、拿起、放下、转身；打斗、追逐、操作步骤若承担真实空间和因果信息，可以细写。
- **心理**：保留新判断、误判、回忆、权衡与自我欺骗。准确直写能承担过渡；反复翻译刚发生的事、总结同一情绪则压缩。不能把内心活动一律改成身体反应。
- **对话**：看双方各自争取什么、什么不愿说、哪次回应改变了局面。关键处展开，其余可用叙述带过，不把原文每个“他说/她说”都改成一行台词。对白、叙述和心理共同承接这场戏，不用整齐的一问一答代替场景。不要求每句答非所问，也不靠加粗话提高烈度。
- **环境和物件**：观察应贴人物此时的注意力。可以建立生活质感、时间感、审美和关系；不要求每件东西都成为线索。逐件同精度陈列、通用天气和无功能装饰应压缩。
- **群像反应**：人物因立场不同改变行动，值得分开；全体轮流手抖、后退、吃惊只是在重复烘托。判断和分量可以由有立场的人给出，不强行给所有人台词。

## 信息交付与收尾

新人物、新物件或新设定出现时，让读者知道当前行动所需的身份、作用或限制。已有场内载体和简明叙述都可使用，不强迫改成手机、账单或办事卡点。必要解释可以直说；读者暂时不知道答案时，至少要知道自己正在等哪个问题。

分清角色已知、读者已知与仍待揭露的信息。故意留下的悬念不补答案，必要承接不删成生词清单。事实依据与揭露时机的核查见 [story-logic.md](story-logic.md)。

结尾检查最后一拍带来了什么：行动未完、关系变化、一次兑现、尚未解决的问题或情绪余韵都可以。动作、对话、心理和带立场的叙述均可收尾；清理重复复述、空泛哲理与没有具体对象的预告。短篇的主观审判、心死判词和火葬场预告按本书卖点取舍，保留并不等于放过重复。

## 同一事实怎样换用笔

以下为合成示例。已定事实：余舟要送信过溪，先试石墩，第二块松动后退回；他改从上游的倒树过，把信袋挂在颈前，终于到了对岸。

**用笔失衡**：溪边有三棵树，两棵树皮灰白，一棵长了苔。树下散着石子，近处圆一些，远处扁一些。余舟想了几个办法，费了一番工夫，终于把信带过溪。

**重心恢复**：

> 余舟踏上第二块石墩，石头往下一沉，他赶紧退回岸边。
>
> 上游横着一棵倒树。他沿溪走过去，把信袋挂到颈前，空出手扶着树干，一点点挪到了对岸。

这里只把已定的试探和换办法写出来，没有新加救援者、工具或意外。如果资料只说“费了一番工夫”，连尝试和办法都没有，就不能照本例编石墩和倒树。

**会改坏的方向**：只写“他从倒树过了溪”，试探和换办法都被压没；逐一罗列抬脚、落脚、换手，无差别的动作又会抢走注意力。

**该保留的慢处**：老人收起亡妻的茶具，先按她原来的位置放好，再取下来包纸。多停留的这一会儿可以让读者经历习惯与失落。可以修机械句式，不能仅以“事件推进少”删掉。
