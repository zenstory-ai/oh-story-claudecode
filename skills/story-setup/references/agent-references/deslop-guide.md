# 网文去 AI 味三层指南与定点范围

> 谁读：去味、审稿或写手执行三层诊断与定点改稿时读；表达先按 [style-resolution.md](style-resolution.md) 裁决，短篇同时必读 [short-deslop.md](short-deslop.md) 并以其规则覆盖为准。

核心原则：**保留网文竖屏节奏、直给情绪与爽虐张力，只清真 AI 腔（公文推导、翻译腔、套词/比喻堆砌、空泛说教、同义复述与因果断层）**。不以传统严肃文学、慢热环境烘托或强行合长句为目标。

## 一、表达层：保竖屏节奏，清真 AI 腔

1. **分清竖屏短段与机械电报体**：网文（尤其短篇及番茄/七猫长篇）默认竖屏短段（中位约 20–27 字），意思走完的一句一段、对白、吐槽、反转与爆点保留独立成段，不强行合并成书面长复句。只有把同一连贯动作硬劈成三五字残句、缺主语或像工单逐项播报时，才按行动主干接顺因果。
2. **用词与句式按语境判**：词表（[banned-words.md](banned-words.md)）仅作线索，不逐词照删。
   - **优先改写（Tier 1 真 AI 腔）**：无靶子的「不是 A，而是 B」「没有 X，没有 Y，只有 Z」；「这意味着/由此可见/真正重要的是」类公文推导链；「带着一丝不易察觉」「声音不大，却不容置疑」「平静得像在念」万能声线；给普通名词滥加引号强调；「命运的齿轮/这一夜注定/潮水般涌来」抽象大词与模板比喻。
   - **语境保留**：有明确纠错对象的对比、递进排比、角色身份决定的口语/术语、准确直写情绪（「他听烦了」「我彻底死心」）与角色利害算账。
3. **身体反应删除测试**：只标注情绪、不改变选择、关系或物理后果的微动作（「指尖轻叩、指节泛白、摩挲杯沿、视线停半秒」）直接删或改直写情绪/台词，不换部位轮换；伤势、动作失败与常规情绪短语按语境和题材保留。
4. **声口与叙述者**：对白按身份、场合与意图区分；直球摊牌、狠话与吐槽符合网文处境时保留，不把直白交锋改晦涩。删除脱离角色视角的纯说明文解说；短篇第一人称审判与剧透预告按 `short-deslop.md` 保留。

## 二、用笔层：篇幅落在爽点、交锋与关键变化上

通读一场戏，先定它要让读者体验什么（打脸、反制、升温、立钩、破局或关系翻转），再按重心调详略：

| 问题 | 看什么 | 怎么处理 |
|---|---|---|
| 过场水戏占篇幅 | 赶路、寒暄、办手续、无关景物连续展开，不改处境或情绪 | 压成 1–2 句带过，不以「生活质感」硬留无冲突慢戏 |
| 关键交锋被概述 | 「三言两语谈妥」「众人纷纷震惊」「她彻底想通了」吞掉过程 | 展开已有筹码、台词交锋、分层围观反应与落点 |
| 情绪原地打转 | 连续三段换词复述同一委屈、愤怒或恐惧，无新信息/动作 | 删复述，保留推动下一步选择或行动的一拍 |
| 只见结果不见触发 | 态度或决定突兀翻转、缺少前因触发 | 恢复原文已有承接；依据未设计则转故事层提方案 |

**网文前后对照（合成示例）**：
- **长篇爽点（番茄/起点）**：原句「他一掌击碎测力碑，声音不大却带着不容置疑的力量。所有人都震惊了，命运的齿轮开始转动。」→ 改后：「测力碑轰然裂成两半，铁屑飞了执事一脸。\n刚才还劝他认输的世家子弟脸白了，往后退了半步。\n高台上的长老猛地站起，茶盏翻在案上：『三寸透孔——他才炼气三层？』」（删音量反差与命运大词，落到物理后果与分层围观。）
- **短篇交锋（七猫/盐言）**：原句「丈夫神色平静得像在宣判一件早已定好的事，他不是不在乎她的感受，而是觉得妹妹更需要这笔救命钱，她感到一丝绝望涌上心头。」→ 改后：「丈夫把转账截图甩在桌上，头都没抬：\n『我妈的手术能等，晚晚的违约金今天必须交。』\n我盯着那串六位数的零，突然笑出了声。\n行。既然他们一家人都这么心疼她，这婚我也不用留着过年了。」（去书面长句与套词，用短段、直球台词和第一人称冷吐槽直给情绪。）

## 三、故事层与改稿权限

沿事件核对：行为依据、因果承接、人物立场、解法支撑、场后变化与知情顺序。**短篇高频引擎（偷听撞破、反派自爆、围观打脸、明确触发后快速决裂）与长篇金手指爽点属题材约定，不按办案或现实主义标准判假。**

| 普通去味可直接落改 | 须经作者授权（未授权只列最小方案） |
|---|---|
| 修表达、删水戏与复述、恢复已有前情承接 | 新增动机、证据、人物身份、能力或事件 |
| 展开已定交锋与反馈、修正可核实的指代/时序笔误 | 改变人物决定、胜负、关系走向、揭露时机或结局 |

审稿调用只报告不改文件；改稿调用直接落盘授权修改，回读整场确认事实、情绪与承接完好，不为凑字数灌水或强加冲突。

## 按检测类别或问题限定范围

独立去味未限范围时三层全检；调用方指定问题或检测类别时只修该范围（范围外明显设计缺口单列提示，不擅自重写）：

| 问题名 | 检查重点 |
|---|---|
| 套词、句式 | 表达层 Tier 1 句式与套词判断 |
| 情绪 | 用笔层去复述 + 表达层直写与删除测试 |
| 节奏 | 用笔层详略、过场压缩与交锋展开 + 表达层短段节奏 |
| 对话 | 用笔层筹码交锋 + 表达层声口差异 |
| 收尾 | 用笔层兑现/卡点落点 + 表达层去空泛总结 |
| 解释与安排感 | 表达层删推导腔 + 故事层因果与知情边界 |

## 脚本提示怎样进入语义判断

脚本只是定位线索，密度提示非词频配额，`advisory` 不作硬门槛；`review_required` 优先保功能改写，确有功能可说明理由保留或登记 `.deslop-whitelist`。加粗项在默认或高频时为 `review_required`（短篇 `--mode=short` 按 `short-deslop.md` 放宽）：

| 脚本提示类别 | 语义判断重点 |
|---|---|
| **`not-is-comparison`**、**`reverse-not-is`**、**`negation-parade`**、`negation-pair-tic` | 是否无靶子否定铺垫；有明确纠错、辩解或强烈情绪对比可留 |
| **`voice-contrast`** | 「声音不大…却」万能音量反差；删铺垫直接写台词分量或后果 |
| **`em-dash`**、`ellipsis-density-tic` | 长短篇标准 `——` 适量可留，旁白过密按功能改逗号、冒号或动作；旁白省略号禁刷屏 |
| **`trailer-ending`**、**`trailer-summary`** | 删「命运的齿轮/这一夜注定/才刚刚开始」空泛盖章；短篇具体信息差预告保留 |
| `formulaic-parallelism`、`quote-emphasis-tic` | 工整栏目与普通词加引号是否机械复述；讽刺/转述/递进可留 |
| `cliche-density-tic`、`metaphor-density-tic` | 套词与比喻是否堆叠同腔；保留有画面感与情绪功能的少数 |
| `stock-reaction-tic`、`micro-action-tic`、`action-list-tic` | 微动作是否只贴标签或流水账；有物理后果或打斗步骤可留 |
| `period-stutter`、`overcompressed-prose-tic`、`low-connective-density-tic` | 是否真缺主语/因果断裂；短篇与竖屏长篇正常短段不据此合长句 |
| `long-paragraph` | 单段是否过长挤垮手机阅读，按镜头/动作/对话断段 |
| `abstract-summary-tic`、`reasoning-chain-tic` | 删论文推导与作者盖章，保留角色当场利害算账 |
| `system-notice-formality-tic` | 系统/规则面板语域是否符合载体且让角色看懂后果 |

零命中不代表用笔与故事无问题；改后须回读确认爽感与流畅度。
