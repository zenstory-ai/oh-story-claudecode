# 短篇题材写作公式

> 谁读：构思时题材不在 10 个题材包里，主会话整份读；story-architect 辅助构思时读副本。写正文、精修不读，按 设定.md「这篇用的套路」记下的参照结构写。

> **节数**：公式节数是原作分节数。19 节放进 1 万字约每节 500 字；篇幅短时相邻节可合并，不是硬指标。

## 公式一：现代复仇/打脸短篇（6节）

| 节 | 节点 | 要点 |
|----|------|------|
| 1 | 当众背叛 | 主角当场冷静反击，暂胜 |
| 2 | 冷静处理 | 冻结/收回权力，交代背景 |
| 3 | 对方反扑 | 反派找上门，用证据打脸 |
| 4 | 揭示真相 | 监控/证据暴露反派真面目 |
| 5 | 对方求饶 | 展示更多证据，彻底碾压 |
| 6 | 最终加冕 | 新格局+隐藏真相揭露 |

**情绪**：愤怒→爽→紧张→更爽→极爽→余韵+震撼
**必选场景**：当众羞辱开场、冷静到可怕的反击（冷静靠选择和筹码体现）、逐层揭露证据、反派自曝、隐藏伏笔回收
**规则**：主角以冷静反击为主；情绪克制直写，不堆体感；用对方失控与主角选择形成反差，先让反派得意再翻转

---

## 公式二：古代宅斗/身份反转（8节）

| 节 | 节点 | 要点 |
|----|------|------|
| 1 | 被弃回归 | 亲生父母当众羞辱，主角冷观 |
| 2 | 后院交锋 | 被妹妹陷害被打，暗线启动 |
| 3 | 身份初露 | 关键人物关注，展示信物 |
| 4 | 被软禁 | 妹妹告密，陷入绝境 |
| 5 | 身份揭露 | 圣旨到，全场震惊 |
| 6 | 反击推进 | 查账，权贵站队 |
| 7 | 对方反扑 | 谣言+联合打压 |
| 8 | 最终碾压 | 面圣/真相大白，对方覆灭 |

**情绪**：压抑×3→释放→释放→短暂再压→终极释放
**必选场景**：回归羞辱、被冤枉被打、信物展示、身份揭露名场面、妹妹恶毒递进、父母偏心加码
**规则**：分步揭露身份，随身份与反击推进释放情绪；父母的恶写成“偏心”而非脸谱化的坏；妹妹的恶毒从阴阳怪气到陷害、再到动杀心层层加码

## 公式三：虐恋复仇/灵魂视角（7节）

| 节 | 节点 | 要点 |
|----|------|------|
| 1 | 死亡回溯 | 3年前被渣男害死，灵魂视角开启 |
| 2 | 虐待现场 | 渣男威胁家人，保镖打人 |
| 3 | 小三虚伪 | 小三装可怜，撕碎死亡证明 |
| 4 | 开棺/真相 | 开棺见骨，幼子指遗物喊妈，血书与定时证据公开 |
| 5 | 舆论反转 | 热搜+股价暴跌+小三被甩 |
| 6 | 崩溃现场 | 掐小三，家族问责 |
| 7 | 收尾 | 哥哥布局，渣男最后一句话 |

**情绪**：窒息→暴怒→冰冷→心碎→爽→快意→苍凉
**必选场景**：难产时渣男签"保小不保大"；家人被打vs渣男给小三买礼；幼子认出遗物击穿防线；定时发证据；开棺；渣男崩溃
**规则**：用魂魄飘在半空的视角写出“想拦却无能为力”的窒息感；当下惨状与三年前回忆交替；渣男替自己的恶找尽借口，小三句句话藏着软刀子

## 公式四：玄幻仙侠/重生逆袭（19节）

```
导语[前世被害全貌]→重生回到关键节点→故意不按前世行事→对手自疑自乱
→周围人不解→对手越陷越深→关键人物相助→逐步瓦解反派→最终决战→开放式HE
```

**情绪**：憋屈→爽→悬疑→更爽→紧张→温暖
**必选场景**：前世死亡详细残忍；重生后第一件事"反常"；对手自我怀疑是核心爽点；逐步揭露前世真相；关键助力者有排面；结尾留白暗示感情
**规则**：反着前世的路子走就是最大金手指；用反常举动拉出信息差；仙侠设定只服务情感与复仇线，不堆设定

---

## 公式五：年代重生/双重复仇（19节）

```
导语[前世被利用]→双重生→女主选完全不同的路→外传有隐疾的高位男主温柔护短
→揭发渣男前世罪行→渣男自以为赢→更多证据揭露→渣男崩溃
→男主真实身份揭露→华丽打脸→渣男后悔BE收尾
```

**情绪**：愤怒→解气→甜→紧张→极爽→余韵
新男主承接温柔与身份揭露线，渣男承接后悔收尾。
**必选场景**：前世付出导语交代清；双重生博弈；年代细节（的确良、大团结、赤脚医生）；新男主外传有隐疾或残废实则位高权重；渣男崩溃写足；结尾渣男视角后悔
**规则**：年代感靠真实历史物件托底；"替人顶罪"比"被出轨"更有冲击力；双重生打的是双向信息差；用渣男绝望反衬女主洒脱

---

## 公式六：宫闱宅斗/女帝逆袭（19节）

```
家族被害→被迫替嫁→表面顺从暗中布局→带走所有资源离开
→新势力中积蓄力量→发现更大阴谋→联合盟友→反攻京城→旧势力崩溃→称帝+改革+HE
```

**情绪**：悲愤→隐忍→悬念→爽→极爽→满足
**必选场景**：家族被害够惨；替嫁展示智慧；"带走家产"是转折点；每步布局有合理动机；反攻名场面；称帝后改革体现格局
**规则**：主角从不解释计划让读者自己猜；古文对话有古味但不太文言；布局有"回顾时恍然大悟"效果；反派是"利益驱动的冷漠"

---

## 公式七：现代悬疑/异能或规则反杀（12-18节）

```
设定[特殊感知/亡魂或规则身份]→被恶人当猎物骗入局→利用能力或规则信息差顺水推舟
→反制外围爪牙→摸清背后犯罪链与旧案死因→引幕后黑手入瓮→现实法律+规则反噬双重清算
```

**情绪**：好奇→紧张→爽→更爽→震撼→痛快
**必选场景**：特殊规则或视角一句话立清；被当作猎物入局却暗中反客为主；每次反制揭开一层旧案真相；反派发现踢到铁板时的破防；现实罪证与规则反噬双重结算
**规则**：用主角独有的感知或规则信息差制造反差（猎人变猎物）；悬疑查案线与复仇清算线交织推进；节尾落在反转、新发现、局部兑现或明确的下一步，不为逐节达标另造异常

---

## 公式八：架空历史/性别反转（19节）

```
被家暴/被误解→配偶偏心外人→失望到放弃→决定离开
→配偶不以为然→离开后变好→配偶后悔→配偶疯狂赎罪→主角不原谅→悲剧/开放式
```

**情绪**：憋屈→更憋屈→释然→轻松→暗爽→意难平
**必选场景**：开篇被冤枉/被打；"白月光"型情敌够白莲花；主角离开干净利落；配偶后悔递进；主角不原谅是全文态度；结局不HE更有余韵
**规则**：性别反转是外壳，核心是"不被珍惜的人选择离开"；每次"忍忍就好"都是对读者愤怒加码；配偶后悔越详细读者"不原谅"越坚决；悲剧性来自"来不及了"

---

## 公式九：重生复仇/离婚逆袭（10节）

```
前世被害→重生到关键节点→冷静接受离婚→拿走应得财富
→投资已知成功项目→系统学习提升→前夫后悔→前夫试图挽回→坚决拒绝→华丽蜕变
```

**情绪**：憋屈→释然→爽→更爽→极爽→满足
**必选场景**：前世死法和前夫直接相关；重生后第一反应"笑了"；离婚干脆要钱要利不要人；投资展示智慧；前夫后悔递进；最终蜕变有具体体现
**规则**："知道了结局，现在要改变过程"；冷静是最大武器；每个决定有前世记忆支撑；前夫带有"理所当然地忽视"的缺陷，避免纯坏；投资线和感情线分开

## 公式十：总裁豪门/白月光虐恋（8-11节）

```
1-2节 虐(建立矛盾)：伤害层层升级(言语→行为→身体)
3-4节 觉醒(心死离开)：临界事件(目睹背叛/身体极限)
5-6节 反转(真相揭露)：监控/证据/白月光自曝
7-8节 惩罚(追悔被拒)：渣男崩溃/反派落败
9-10节 治愈(新生活)：女主独立/新恋情
```

**情绪推进**：先让伤害递进压足委屈，临界事件触发心死离开，再亮证据完成打脸追悔，最后落在新生活（篇幅服从因果，不按固定比例切）
**虐三层**：言语伤害→行为伤害→身体伤害
**必选场景**：开篇信息炸弹；白月光以台词羞辱女主；临界事件（监控/母亲去世丈夫带秘书旅行）；渣男追悔被拒。死遁/消失、新恋情暗示按本篇设计选用
**规则**：本式默认第一人称；伤害性对话针对处境，避免只剩谩骂；用临界事件触发觉醒，再依次兑现反击与治愈

## 公式十一：女频 vs 男频复仇/打脸

### 女频常见路径
- **开头**：第一人称「我」；3句内建立核心矛盾；重生则150字内完成前世回顾
- **发展**：让反派施压、主角选择、信息差与局部反制沿因果链升级；连续多个叙事单元没有状态变化时再调整，不按字数配打脸
- **高潮**：终极真相、身份或关键证据在前因足以支撑时汇合；公开审判只在围观关系网能放大权力翻转时使用
- **收尾**：交代反派下场、主角选择与可感后果；温情段长度服从余波，不按固定字数截断

### 男频常见路径
- **开头**：第一段最大屈辱；不铺垫直接炸裂；关键数据具体
- **发展**：隐忍篇幅通常较短；靠行动而非心声展示能力
- **反击**：用选择、资源和行动形成碾压；公开场合只在关系网见证会改变结果时使用
- **高潮**：身份、实力或关键证据在前因足以支撑时汇合；称呼改变可作为关系翻转证据，不强配集体震惊
- **收尾**：反派覆灭后交代主角选择和余波；温情线长度服从结局职责

### 核心差异

| 指标 | 女频 | 男频 |
|------|------|------|
| 反转类型 | 信息差型（心声/真相） | 力量型（身份/实力） |
| 反派类型 | 渣男+绿茶+偏心父母 | 兄弟+老板+势利眼 |
| 复仇方式 | 信息差式（真相揭露） | 力量式（实力碾压） |

## 公式十二：宫闱宅斗/隐忍设局型（8节）

```
1 主动入局(明知夫君偏宠妾室/白月光仍嫁入掌家)
2 以退为进(处处大度成全→衬得情敌争宠失态)
3 借力打力(情敌装病或设小局诬陷→顺手留证让夫君自己撞破失望)
4 静待自毁(情敌在宗族或宴席场合越界闯祸→主角冷眼旁观)
5 顺势夺权(情敌丑事或私弊暴露→主角奉长辈之命接管中馈或抚养权)
6 釜底抽薪(剪除情敌外家依仗与心腹后路，坐稳当家主母位)
7 设局收网(借故离府腾出空当→诱情敌狗急跳墙犯下大忌→带长辈当场拿获)
8 终极反转(亮出全程诱导布局的暗棋→独掌大权与家产)
```

**情绪**：好奇→爽(情敌自毁)→更爽(主角不动声色)→震撼(结尾反转)
**必选场景**：开篇反常大度；情敌自毁三连（装病露馅→宴席失言→孤注一掷犯忌）；每次退让都是捧杀布局；结尾点破主角才是操盘人
**规则**：主角表面从不主动撕破脸，每次情敌犯错后主角都占尽理字与名分；结尾完成从“贤惠受气包”到“幕后做局人”的认知翻转

## 公式十三：追夫火葬场/不原谅型（8节）

```
1 发现真相(多年付出被当成理所当然，撞破妻子对白月光破例失态而非天性冷淡)→决定离婚
2 彻底死心(盘清过往付出与被拒屈辱)→办妥调任、股权切割或离婚手续
3 妻子失控(为维护白月光利益无视男主处境，变本加厉施压)
4 临界决裂(男主遇险或至亲病危求助，妻子却在陪白月光庆祝)→彻底斩断念想
5 决然离开(留下离婚协议与信物销户离开，妻子起初以为只是赌气)
6 丑闻曝光(白月光实力不济闯祸或为自保出卖妻子→妻子事业名声双崩)
7 重逢对照(妻子狼狈寻来→撞见男主已在新赛道站稳、身边有珍惜他的搭档)
8 不原谅(当面对峙苦求回头→男主平静冷拒，绝不回头)
```

**情绪**：绝望→平静→新生→痛快→苍凉
**必选场景**：具体付出数字与冷遇对比；撞见妻子对白月光破例；临界求助被拒；白月光反噬出卖；新生活对照；终局对峙平静冷拒
**规则**：男主越冷静克制越有力；妻子后悔与反噬写得越实，读者对“不原谅”越买账；不原谅比强行破镜重圆更有余韵

---

## 公式十四：年代重生/医术或手艺逆袭型（8节）

```
1 前世惨死(被极品亲属算计贱卖或榨干→绝境惨死)→重生回命运转折点
2 首秀破局(亮出医术/手艺/先知优势→当场化解眼前逼嫁或夺产危机)
3 借势立威(面对极品亲戚挑衅不内耗→凭真本事赢得关键贵人或重伤高干/军官信任)
4 筹码置换(治好或帮扶核心搭档→谈妥分成、名分、户口或庇护筹码)
5 步步为营(事业起步攒下第一桶金→与搭档双向护短、同盟升温)
6 暗线合流(查出家族或大房昔日加害内幕→与同样隐忍布局的搭档联手设套)
7 复仇收网(公开场合或关键节点人赃并获→仇人反噬入狱、家道败落)
8 结局落点(大仇得报、家业稳固→与搭档相守圆满，或搭档旧疾离世留下家业与余韵)
```

**情绪**：愤怒→爽→踏实→极爽→圆满或苍凉余韵
**必选场景**：前世被算计惨死的切肤之痛；重生后当场翻脸破局；医术或手艺专业细节展示；与搭档互换筹码结盟；联手设局清算大房/极品亲属
**规则**：年代质感靠工分、票证、医药器具等具体器物托底；医术或手艺步骤要写实；反派的恶行要落到吞没钱物、顶替名额等具体利益上

## 公式十五：灵魂视角家庭虐文（5节）

```
1 病中被虐(重病被逼做事→身体崩溃→灵魂飘起)
2 旁观真相(灵魂看到家人冷漠→配角拱火→母亲为"面子"变本加厉)
3 证据浮出(父亲发现→手机/日记/监控暴露真相→全家崩溃)
4 审判清算(逐出族谱→配角被惩→反派得报应)
5 重生暖心(投胎温暖家庭→温馨细节呼应前世缺失)
```

**情绪**：窒息→心碎→释放→痛快→治愈
**必选场景**：身体最脆弱时遭最大伤害（脊椎术后逼祭祖/剖腹产逼做饭）；"我的魂魄慢慢飘起"；配角拱火；母亲的"面子"执念；手机/日记作为证据；重生到温暖家庭
**规则**：灵魂视角能看到但无法阻止；身体细节必须具体（脊椎错位的脆响、护腰被扯下的刺啦）；母亲后悔写够（从"她最会装"到嚎叫崩溃）；重生结尾用对比；最后一句必须温暖

### 开头金句模板

| 模板 | 示例 |
|------|------|
| 病中被逼 | "我刚做完脊椎手术，医生再三嘱咐静养三个月。我妈却一把掀开被子：装什么娇气，祠堂等着开香堂呢，赶紧起来跪着！" |
| 产后被逼 | "我刚剖腹产七天，刀口泛着疼。老公推开门：今天家里来客，你去做几个菜。" |
| 过敏被锁 | "我花粉过敏喘不上气，刚摸到哮喘喷雾，就被表妹一把抢走：舅妈你看，她不想洗碗又在这儿装病！" |

## 公式十六：细节线索驱动型复仇

```
1 发现异常(微小细节→冷静应对)
2-3 暗中调查(职业优势系统收集证据→发现更大阴谋)
4-5 布局反击(法律文件→证据陷阱→第三方施压)
6-7 公开对峙(公开场合递交文件→对方崩溃→真相浮出)
8+ 连环反击(对方反扑→逐一破解→主角全新开始)
```

**情绪**：警觉→压抑→冷静→爽→极爽→豁达
**必选场景**：一个触发细节（月子中心钥匙扣/发票/香水味）；职业优势（法务/审计）；证据链构建；听丈夫撒谎时不吵不闹、笑着点头应下并转身取证；借小三家属或公司规则出手；把对方敷衍的话原样奉还收尾
**规则**：小节长短顺着查证与反击走；冷静落在布局和决断上；证据分批亮出，层层揭开背叛，用克制笔触写大情绪

### 调查链条模板
```
异常物件→搜索确认→实地调查→系统取证(银行/监控/社交)→布局反击→公开审判
```

## 公式十七：反套路嫁祸型重生（7节）

```
1 重生+假意顺从(知道遗产/婚约是巨坑→"你既然想要，就都给你吧")
2 暗中布局(确认继承人身份→准备移民→假意顺着渣男)
3 小试锋芒(不再替白月光兜底→反常退让制造悬念)
4 冲突升级(被陷害→用规则条件反手锁死对方)
5 身份揭露(权威人物认出主角才是真正家主→对方崩溃)
6 收网(给渣男"既要又要"的选择→看他自掘坟墓)
7 华丽退场(揭露真相→移民离开→头也不回)
```

**情绪**：了然→爽→更爽→极爽→痛快→豁达
**必选场景**：把藏坑利益拱手相让（"给你吧"时刻）；白月光三连试探（撒娇→哭闹→威胁）；渣男"既要又要"；身份揭露名场面；冷眼看对方接盘自毁；头也不回离开
**规则**："把坑让给你就是最好的惩罚"；前世记忆只在改变当下判断或选择时穿插，不按节配额；克制靠选择呈现，不套"苍凉的笑"；最大蔑视是漠视

## 公式十八：公开审判式打脸

### 核心场景设计
```
1 设定"竞技场"(股东大会/家族寿宴/公司大堂)——必须公开
2 反派先"赢"(当众宣布胜利、羞辱主角)
3 主角不慌(先让对方说完，再按顺序亮筹码)
4 逐层揭露(一张一张甩证据)
5 反派逐级崩溃(得意→慌张→绝望→崩溃)
6 标志性驱逐台词
7 背影离场(全场死寂中头也不回)
```

### 驱逐台词库

| 台词 | 场景 |
|------|------|
| "去人事把工牌和门禁卡交了，法务的追偿函明天到。" | 逐出公司 |
| "从今天起，这栋楼的门禁除名，她的东西让保安打包送出去。" | 永久驱逐 |

台词按人物、筹码和现场压力另写，库中示例只演示「权力宣告」，禁止照搬。冷静靠选择和筹码体现，不给主角配端水杯、整理西装这类固定动作。

## 题材牵引强度分级

> 强度描述题材期待，不是逐节配额。钩子落在读者预期、行动方向或关系判断发生变化的位置；连续多个小节只提问不兑现时再复核。

| 题材 | 牵引强度 | 偏好 |
|------|----------|------|
| 复仇/爽文 | 极强 | 打脸、底牌、代价 |
| 悬疑 | 强 | 信息差、倒计时、反转 |
| 情感/虐心 | 中强 | 情感、反差、余韵 |
| 古言/宫斗 | 中强 | 底牌、打脸、代价 |
| 年代/亲情 | 中 | 情感、反差、余韵 |
