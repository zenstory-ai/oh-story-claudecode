## 女频核心原则（长篇框架）

以下针对以女主成长、翻盘或关系兑现为承诺的长篇；先据目标读者与样本确定承诺，再用四条核对。

- **安全感优先**：女频读者要明确知道女主不会一直被虐。长篇尤其要在卷与卷之间给安全感锚点——每卷收尾女主必须有看得见的成长或翻盘，不能整卷只铺虐。开篇必须暗示结局会赢。
- **代入感优先**：女主的处境要让目标读者能投射进去。代入感低，女主做什么读者都不觉得爽。长篇里女主的每一次选择都在累积或消耗代入感。
- **女主主动性**：女主被动、被安排、毫无选择权会让读者弃书。长篇里"金手指/外挂帮她赢"不等于主动性，关键是女主自己做决定、自己推进；就算被宠，也要是她主动选择接受。
- **情绪即产品**：不论甜、虐、沙雕还是正剧，本质都是情绪产品。长篇的核心是一条主情绪贯穿到底（比如追妻文从被虐走到被深爱），小情绪都归拢到主情绪之下；情绪散乱是长篇崩盘的第一死因。

## 读者群体与深层需求

女频长篇常用情绪方向（是否流行需 scan/analyze 验证）：

| 情绪类型 | 代表题材 | 核心爽点 |
|----------|----------|----------|
| 反抗命运 | 年代重生、穿书觉醒 | 改变悲惨命运，打脸极品家人 |
| 事业独立 | 穿越经商、种田、娱乐圈 | 靠自己能力一步步做大 |
| 被宠爱 | 团宠、萌宝、先婚后爱 | 不用费力就被珍视 |
| 虐恋反转 | 追妻火葬场、强取豪夺 | 从被虐到被深爱 |
| 反差萌 | 沙雕修真、系统文 | 轻松里的意外爽感 |

深层需求落点：女频读者表面要"打脸/被宠"，深层要的是**被认可、被珍视、被尊重**。长篇要一直抓着这个深层需求不偏移。

## 女频题材框架

长篇选题第一关：题材要有**长线骨架**，能撑几十万字的主线（女频分题材的长线循环以下表为准）；一个反转、一次打脸这类短篇梗撑不起长篇。热度用 scan 验证。

| 题材 | 读者期待 | 长线骨架 | 卷级升级轴 |
|------|---------|---------|-----------|
| 追妻火葬场 | 从被虐到被深爱，男主活该又让人心疼 | 受冷→女主离开→男主追悔→拉扯→放下或接受 | 女主事业越做越大，男主越追越卑微 |
| 重生复仇 | 用前世记忆逐一清算 | 重生回伤害前→布局→逐个清算→改命 | 仇人分层，篇幅按 character-basics.md 反派层级表 |
| 小三/婚恋 | 发现背叛后觉醒、独立、惩恶 | 日常压迫→发现出轨或算计→离开→事业重建→反击→报应 | 渣男的恶行逐级加码，女主的筹码逐级加码 |
| 世情 | 老实人被欺压，恶有恶报 | 奇葩登场→欺压升级→第一次反击→反扑→打脸→报应 | 反派恶得越来越有创意，报应越来越重 |
| 霸总/甜宠 | 被强势专一的男主宠溺 | 相识→试探→确认→考验（家族、前任、商业对手）→定局 | 阻力升级但不过强，女主的独立闪光点越来越亮 |
| 先婚后爱 | 先结婚，再日久生情 | 联姻、换亲或契约婚→磨合→生情→外部危机→深爱 | 从各过各的到互相护短 |
| 强取豪夺 | 被掠夺后反向掌控关系 | 身份压制下被掠夺→抗拒→博弈→反向掌控 | 女主的筹码越来越多，主动权逐步转移 |
| 种田/经商 | 靠自己一步步做大 | 起点低→发现机会→做大→对照组被打脸 | 生意规模和身份逐级上升 |
| 宅斗/宫斗 | 低位女主识破阴谋步步上位 | 庶女或低位→识破阴谋→上位→掌权 | 对手层级随位置升高 |
| 年代 | 在年代里搞钱、改命、过好日子 | 穿越或重生到年代→搞钱→治极品家人→感情 | 家境和地位逐级改善 |
| 团宠/萌宝 | 不用费力就被珍视 | 身份被错认→真相揭开→全员宠 | 宠她的人越来越多、身份越来越高 |

人物弧线：

- 追妻：女主从隐忍付出到心死离开，再到独立成功、掌握主动；男主从高冷傲慢到卑微追悔。第二男主选配，制造男主的危机感，也给读者情感出口。
- 重生复仇：女主从前世天真到重生后腹黑，核心矛盾是会不会变成仇人那样的人；盟友或男主前世可能被误解，逐步取得信任。

长篇组合规则：

- 一本长篇最多叠 2-3 个核心梗，再多读者记不住、主线散
- 事业与感情双线定位时，先确定两线如何咬合，不把事业线写成孤立升级
- 追妻冷拒主线女主不回头；要写复合，开书时就定下来

阶段名、卷级位置、虐的剂量都以 [character-relations.md](character-relations.md)「感情线阶段」为准。女频长篇另加一条：本书文风允许多视角时，男女主视角交替，能放大长篇的拉扯感。

## 女频 vs 男频底层差异（长篇视角）

| 维度 | 女频 | 男频 |
|------|------|------|
| 核心驱动 | 情绪产品，几乎都含感情线 | 剧情爽感，纯感情线罕见 |
| 感情线本质 | "深化连接"——不可替代的偏爱与相知 | "展示优秀"——借优秀伴侣的认可印证主角价值，与主线破局互为助力 |
| 异性角色重视度 | 极高，男主人设决定留存 | 较低，女主功能性更强 |
| 虐的目的 | 制造情绪波动，虐完必有反转 | 升级打怪的前置铺垫 |
| 复仇方式 | 信息差式（真相揭露打脸） | 力量式（实力/身份碾压） |
| 长线主轴 | 感情线+成长线双轴咬合 | 实力升级单轴为主 |
| 反转类型 | 信息差型（心声/真相） | 力量型（身份/实力） |

本表概括情绪关系型女频与升级事业型男频的常见差异；具体取舍回到本书定位和样本，不由频道名推定。

## 质量检查清单

写女频长篇时逐项核对（§女频核心原则 安全感/代入感/主动性/情绪即产品 四条默认必过，以下查执行项）：

- [ ] **感情线双轴**：感情升级踩在事业/成长节点上，不是全书只谈恋爱？
- [ ] **感情线阶段**：按 character-relations「感情线阶段」排，每段虐后有反转或糖？
- [ ] **题材有长线骨架**：所选框架的读者期待、长线骨架、卷级升级轴都能落到本书，撑得起几十万字主线？
- [ ] **梗组合不超载**：核心梗不超过 2-3 个，主线没被叠梗冲散？
- [ ] **男主人设**：用细节描写加分（不只形容词），决定留存？
- [ ] **货板一致**：书名承诺的和正文交付的一致，没有货不对板？
