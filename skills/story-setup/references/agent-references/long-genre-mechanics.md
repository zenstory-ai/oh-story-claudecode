## 核心梗三层递进设计（表层卖点→深层爽点→长线钩子）

一本书通常有 2-4 条核心梗。三层按设定模板的三个字段填写：

### 三层怎么填

| 模板字段 | 是什么 | 怎么找 | 失败信号 |
|---------|-------|-------|---------|
| 表层卖点 | 这个题材独有的吸引力，用来筛读者、划边界、出氛围 | 看同题材火书靠什么卖、读者冲着什么进来 | 卖点偏到别的题材；书名暗示的和正文给的不一致 |
| 深层爽点 | 读者反复追的一条情绪链（期待→满足），如扮猪吃虎、弥补遗憾、莫欺少年穷；装逼打脸只是表现形式 | 从人人都有的情感里抽一种：推到极端（日常委屈推到生死或巨额对赌），并只咬住这一种贯穿全书，其他情绪都为它服务 | 情绪散乱、几条小情绪各走各的 |
| 长线钩子 | 支撑全书的目标或悬念，主线要落成一件事 | 用一句话写出主线事件（如「少年被当众退婚，立誓三年后上山讨回尊严」「巅峰选手被战队驱逐，从网吧重组草根队杀回总决赛」）；升级只是达成目标的手段；立意落在主角要证明什么 | 只有升级没有主线；没有立意，文字干巴巴 |

深层爽点还要写清运转方式：

- **可重复型**：每个剧情单元运行一次，变换场景、对象和条件（升级文、系统文、文抄娱乐）。
- **一次爆发型**：贯穿全书，只在最高潮爆发一次（追妻、掉马、禁忌之恋）。
- **长期铺垫型**：以期待点的形式贯穿全书（悬疑、复仇、解谜）。

第一个剧情单元就要运行一次核心梗，或完成它的首次铺垫。可以布两条线：一条重复运行核心梗，另一条不重复，两条交替推进。

- **每章循环与防断期待**：每章至少满足一项——有核心梗相关的期待点、有核心梗相关的爽点，或处在两者之间。若上一个爽点已结束、本章又没拉起新期待（**断期待**），读者会觉得书没了魂而弃书。

### 常见误区

- 核心梗太多等于没有核心梗。
- 只有装逼打脸，没有主题。
- 核心梗用完不升级。
- 挂羊头卖狗肉，书名暗示的和正文写的不一致。
- 偏离题材核心，比如都市高武写着写着变成和异界神比。
- **刀人是手段**——悲情靠挫折体现，不靠主角身边的人死绝；换地图不清空旧角色攒下的关系和资产；长段悲壮要穿插别的情绪。

## 金手指

### 选型与规则

金手指替掉故事流程里的哪一环，决定它怎么推剧情：

| 替掉的环节 | 写法 |
|-----------|------|
| 建立目标 | 系统发任务 |
| 克服困难 | 一键解决，但要付代价 |
| 准备过程 | 跳过苦熬，直接撞上阻碍 |
| 收获奖励 | 做 A 得 B，如做好事获利 |

- **三贴合**：贴职业处境（医术配医生，同能力升级衍生而非频繁换挂）、贴人设（冷酷配掠夺、搞笑配出糗换奖，金手指规则还能替性格找理由）、贴世界压迫度（强压迫配无条件加点，常规换图配碎片/解锁型，日常配人际/种田型）。
- **条件→反馈三档**：单条件单反馈（摸尸得宝）、攒点解锁阶段反馈（攒点开新功能）、可融合升级反馈（掠夺词条并融合）；逆向型单列（失去 X 换更强的 Y，如越惨越强、负债越多越有钱）。信息类最不易失控，加速升级类其次，物品调用类最易失控。

### 上限、成长路线与防战力崩坏

- **上限与代价**：金手指上限属「后面才揭开或用上的东西」，在 `设定/题材定位.md` 标最早用上的卷，具体数值先问作者；最好刚好解掉眼前矛盾并露出更大危机，不抢走主角的判断和选择。
- **四阶段成长**：基础（立核心作用）→ 发展（加新用法，至少词条/功能/品质两维同时长）→ 成熟（与世界观和其他体系联动）→ 升华（从个人扩到世界层级，需伏笔）。复杂能力可拆成碎片融进剧情，每拿一片解决一个冲突。
- **单元轮换与防崩**：每个剧情单元运行一次核心用法，相邻单元至少换对象、条件、代价或解法之一。天才流多设档位防过早到顶；无敌流把循环换成信息差。高等级者占高位，跨大境界对敌要给原因（代价、底牌或环境）；已亮明的上限、冷却与代价跨章一致。

## 微创新与差异化设计

创新只在人物、人物关系、情节三处做，最多 3 个点，不超出题材模板的边界。

| 切口 | 核心做法 | 示例 |
|------|---------|------|
| 身份反差 | 保留经典冲突框架，互换主角的起点身份或破局立场 | 退婚逆袭：从「被退婚的废柴少主苦修反击」换成「隐世强者主动退掉势利婚约，对方家族事后追悔莫及」 |
| 规则改写 | 给常见金手指加一条反直觉的触发条件或代价 | 系统奖励：不按战胜强敌发奖，改按「让对手主动认输且不伤性命」发奖 |
| 关系错位 | 把原本单一的对立或依附关系改成双向博弈 | 宿敌同盟：白日是朝堂死敌，夜间共用同一马甲查先帝旧案 |
| 跨类嫁接 | 以成熟题材为主基调，借另一题材的核心机制当破局工具 | 种田经商为主基调，接入「可回溯三次交易结果」的推演机制 |

### 冲突网络与跨题材缝合

- **冲突网络（定地图 → 定阵营 → 定角色 → 填矛盾）**：至少 3 层矛盾同时运作——纵向（上下级压制与反抗、师徒、君臣）、横向（平级理念、资源、同行、情敌）、交叉（A 与 B、B 与 C 的矛盾引出 A 与 C 的矛盾）。
- **跨题材元素缝合三步**：1. **立共同容器**（套同一套底层规则，如武侠与修仙统一为不同层级副本）；2. **拿门槛差当捷径**（旧体系卡主角的短板新体系不看重，新体系死穴靠常识绕开）；3. **借骨不照搬**（只取核心关系重塑，不照搬原名原事）。
- **谁先知道（信息差排法）**：排戏时问三件事——读者翻开前期待什么？看完设定知道什么？看完这段新知道什么？拉开信息差常用两招：把反派底牌提前亮给读者（造揪心感），或藏起主角刚做的布置（交手时再揭晓打脸）。

### 认知差异核心梗与爽点阈值递升

主角觉得寻常、旁人觉得惊人，借信息差拉出张力（两种搭法：世界相同而主角常识与众人不同；主角带读者常识进入穿越/末世/异世对抗世界）：

| 场景 | 主角视角 | 旁人视角 |
|------|----------|----------|
| 无敌流 | 死了复活没什么 | 这人比诡异还诡异 |
| 幕后流 | 随手布置 | 幕后大佬深不可测 |
| 迪化流（脑补拔高） | 想帮茶农卖茶或省钱 | 巧合掐中死穴，脑补他在下大棋 |

- **爽点阈值递升**：同类关键爽点在影响范围、人物层级、收获价值或认知颠覆上逐级递升，两次高潮间留喘息与关系戏；全书基调从头贯到底，金手指升级不破坏基调。
- **失效信号**：读者对相似规模的爽点不再有反应；主角升级后没有看得见的差异；人际网没随等级变化。
