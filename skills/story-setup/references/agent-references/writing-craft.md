# 写作技法：可执行指令集

> 谁读：主会话自己写正文、改稿时整份读；写手写正文读副本。

> 对话怎么写见 dialogue-mastery.md，第 1-3 章的开篇写法见 opening-design.md「开篇落笔」；正文格式按调用方指定的格式文件执行。
>
> 写法要求冲突时：作者这次说的＞本书文风（`设定/文风.md`）＞对标文风＞本文件默认。文风改不了细纲事件、已知事实和字数范围。

---

## 1. 情绪落地：不把身体微动作当默认答案

### 规则

情绪没有固定译法。上下文已经让读者感到，就不另补反应；情绪推动了剧情，就优先写角色的选择、台词、策略、关系变化、物件变化或实际后果；一句直写最准确时可以直写（"他听烦了"）。身体状态只是候选之一，只有它带来新信息、影响动作，或确实属于这个角色和这个场景时才写。

**同一规则适用于设定、能力与威胁。** 一样东西"危险""碰不得"不由叙述者断言，由一次有代价的试探演示：比如伸手一探就被弹开、掂量出还差多远，或是多看两眼便神思恍惚、忙退后绕开。旁白别急着下结论，让读者自己从试探过程看出来。

### 落地顺序

写到情绪节点时按下面顺序判断，不做“情绪词逐个替换”；同一节点只取最有信息量的一种，不把“动作 + 身体 + 比喻 + 心理解说”叠成四重注释：

1. **上下文已经成立**：前面的冲突、对话或结果足够让读者看懂，删掉补充说明，直接进入下一句对话或一句“他听烦了”带过。
2. **情绪改变下一步**：写角色因此说了什么、没说什么、选了哪条路、改了什么策略、付了什么代价（如愤怒使他撤回报价、叫停合作或当面追问，比攥拳更有信息）。
3. **场内事物能承载变化**：写正在处理的合同、药、饭、门、消息、工具出了什么变化；物件必须来自当前场景，不临时搬一只茶杯来表演情绪。
4. **身体确实受影响**：写动作失败、疼痛、失衡、伤势或实际后果（如笔尖划坏签名、钥匙插错锁孔）。只有“指尖动一下、指节白、嘴唇抿、目光移开、呼吸一顿”而没有后果，直接删，不要换部位或同义动作。
5. **直写更准更省**：低强度或过场情绪一句直写，不必为避开一个普通情绪词绕成三十字表演。

### 好细节的功能

| 情况 | 处理 |
|------|------|
| 上下文已显出不耐烦 | 直接进入下一句对话，或一句“他听烦了”带过 |
| 愤怒使谈判改变 | 写他撤回报价、叫停合作或当面追问；变化比攥拳更有信息 |
| 紧张妨碍正在做的事 | 可以写笔尖划坏签名、钥匙插错锁孔等具体后果 |
| 身体细节只是在句尾标注情绪 | 删除；不要换一套部位或同义动作 |

### 套式反应删除测试

逐章检查重点情绪段：删掉这处身体/语气细节，信息、选择、关系或物理结果有损失吗？换个人名或房间仍然成立吗？本章是否反复出现“部位 + 轻微动作/状态 + 一下”（指尖、指节、目光、嘴唇、呼吸、袖口），或同一情绪已被对话、上下文和动作重复解释？命中后整段重写或删除，不做同义词轮换，只留最有力的一处。

## 2. 贯穿道具：随情节改变意义

物件能承载关系或处境变化时，可选用贯穿道具；每次重现都应增加信息或改变意义（如偏心妈送的「纯金锁」：首次出现是二女儿贴身戴十年深信妈疼自己的信物 → 中段摔断掉漆露出便宜黄铜，颠覆为五十块假货 → 结尾连同催款账单一并退回断联）。

采用贯穿道具时，记下每次出现的含义变化，随交付申报：

```
物件：{名称}
| 章/场景 | 当次含义 | 新增信息或意义变化 |
|---|---|---|
| {位置} | {当次含义} | {首次建立/后续变化} |
```

| 类型 | 功能与示例 |
|------|------|
| 信物型 | 承载关系的象征物（如镀金长命锁，从母亲疼惜的信物变成哄骗寄钱的铁证） |
| 工具型 | 日常使用的功能性物件（如母亲记满二十年偏心支出的家庭旧账本，摊牌时成为断亲铁证） |
| 痕迹型 | 残留的身体/环境痕迹（如假扮外卖员的凶手左腕留着常年戴玉镯的浅白压痕） |
| 数字型 | 承载关系的具体金额/年限（如母亲记了二十年、逼女儿一笔笔还清的八万块抚养账单） |

## 3. 对话中的权力博弈

对抗场见 dialogue-mastery.md「权力博弈对话」（压制、反转、心死），把话语权翻转放在爽点或反转节点；同立场或日常闲聊见「潜台词与说话目的」，靠笨拙示好、打趣护短、认知反差或手头活计拉出温差。

## 4. 数字/金额作为叙事工具

### 规则

用具体数字替代模糊描述。数字承载情感重量、推动情节，张数、天数、重量须前后算得拢且合乎常识。

### 操作指令

| 场景 | 操作 | 示例 |
|------|------|------|
| 建立重量 | 用具体金额/年限替代「很久」「很多」 | 「成婚六年，他连我对花生过敏都记不住」不是「结婚很久」 |
| 伤害递增 | 数字随得寸进尺逐次放大 | 先借口忘带钱包让垫两百 → 接着每月要一千生活费 → 最后装病逼交五万奖学金 |
| 反差暴击 | 两笔悬殊数字并排算清利害 | 「我爸给弟弟买婚房眼都不眨掏了八十万，轮到我急性阑尾炎住院，他却为两千块手术费在走廊跟医生吵了半小时。」 |
| 时间重量 | 用年限托出付出与薄情的落差 | 「我在边关啃了十年干粮、拿命换了个将军，回京那天父亲却指着下人房说，我十年未归家尽孝，只配住这儿。」 |
| **折算成切身用度** | 数字不停在账面，在同一段顺手折算成正急用或刚出现过的开销 | 「卖了一千二百块，够妹妹交两学期住宿费了」（如凑不出妹妹六百块住宿费、师兄攒三个月才换一瓶丹药） |

## 5. 动静有起伏，不按场景配额

一章整体要有推进（冲突爆发、正面交锋、热火朝天的技艺劳作）与停顿（信息悬置、对话空白、环境压力、等待或必要的日常过程）的起伏，但不给每个场景设数量指标，停顿也不等于安排擦灰、理衣领一类微小动作。连续几个场景全「动」时复核是否暴力疲劳（追逐/战斗有意连续可保留）；全「静」时复核是否停滞（等待/压迫有意延长可保留）。情绪高低不对应固定动作类型：爆点可以突然安静，低谷也可以持续劳动。

## 6. 开头事件密度

压缩无功能背景（「在古代XX年间」「她是一个XX的女孩」），按题材和本章任务用行动、异常或具体处境建立阅读问题，让实际事件或信息变化推进目标、风险、关系或下一步行动：

```
❌ 低密度（1 件事/100 字）：
「她是尚书府的大小姐，从小聪明伶俐，深得父亲喜爱。这一天，家里来了一位传旨的太监。」

✅ 高密度（4 件事/50 字）：
「他替皇家当了七年人质，回京那天母后已经吊死冷宫，五岁幼子被亲弟弟打得痴傻，他提刀就闯进了东宫。」
（归朝 → 母死 → 子受虐 → 提刀闯宫，4 件事）
```

密度指一段里发生几件事，不是把一件事拆成一句一句、句句断开；上例用逗号把四件事连成一句，照样是高密度。

## 7. 场景偏短时怎么查

写完一个场景觉得偏短，按下表排查；不为凑字数加描写。

| 检查项 | 偏短原因 | 补救 |
|--------|----------|------|
| 关键子事件读得懂吗？ | 现场、因果或角色下一步缺了必要信息 | 只补真正缺失的信息，不为凑齐三维度硬塞感官或动作（见第8节） |
| 对话只有 1-2 轮？ | 缺少交锋或关系温差 | 对抗场补筹码拉扯，日常场补互动温差多推一轮（见第3节） |
| 情绪信息落地了吗？ | 只贴标签，或用无功能微动作重复解释 | 落到选择、台词、物件和后果，必要时直写（见第1节） |
| 仍偏短且关键情节点写薄？ | 冲突、选择、代价或关系变化没有演到位 | 回到细纲内已有事件补交锋与后果；没有内容就补纲，不拿感官/回忆注水 |

### 任务卡点：只在“办事本来会卡住”时使用

任务卡点不是为显得自然多写办事流程，而是角色本来就要办某件具体事，半路在某一步办不下去，借着被退回的文书、被扣住的物件或对方半截话这类具体凭据，逼他当场改策略、付代价、求助或硬闯，顺势带出新情报、关系冷暖或伏笔（不要把“为什么被卡住”解释成一段说明书）：

- **主事件是对抗**：卡点暴露对手权力、规则漏洞或隐藏后手。
- **主事件是查证**：卡点逼出新证据、新证人或新信息差。
- **主事件是关系推进**：卡点逼角色表态、帮忙、拒绝或背叛。
- **主事件是低压过场**：卡点只作轻阻力，服务关系、伏笔或生活质感，不喧宾夺主。

删掉后没有信息、关系、代价或伏笔损失，就不是有用卡点。

### 反注水规则

禁止为凑字数或“显得自然”加无关环境描写（"窗外阳光明媚"）、内心独白总结、无意义的流程细节，或重复已成立的情绪（见第1节）。给人物加层的段落（一次说岔了的关心、一个被误会的反应、一个空镜）不按“删掉无损就删”判，要问删掉之后谁少了一层；材料里长出来就留，不为每章凑一处。

## 8. 场景写法

### 从细纲到正文：把细纲要求演成场景，不照抄形状

细纲各字段是本章"要发生什么"的要求，**不是正文的形状**。照着细纲逐格填，就会写成一拍一句平推的电报体解说。

- 情节点序列与「这章怎么走」的五行（起因/发展/转折/高潮/结尾）是功能拆解，不是句子模板或五个自然段：不要一点一句按序平推，也不要把"谁做了什么"的概括句、"A→B→C"箭头链、"收束到什么状态"原样搬进叙述；把每个点演成角色此刻可感知的选择、动作、对话、物件、结果，同一场戏里的几个点可合并或互相打断（因果依赖或刻意停顿分隔才串行）。
- **状态变化要给出台阶，不只给前后。** 一样东西烧起来、一张脸沉下去、一个人的态度转过来，要写出"先怎样、跟着怎样、最后成了什么"的中间态；只给起点和终点是概述。台阶是步步递进的变化，不是把同一状态换十个词重复十遍。
- 同一要求在细纲各处重复出现时，写前合并成一处，不在正文里沿用提纲措辞重复交代。
- 章尾落在最后一个具体的动作、画面、台词或悬念上；细纲「结尾设定」不要在正文里写成"就这样……""他终于明白……"式的状态总结句。

### 视角：深度限知

默认锁死主视角角色的"此刻感知"，只写他此刻看到、听到、闻到、身体感到、脑中闪过的东西。这样既有代入感，也没有"作者在场"的说教腔。本书文风允许有限全知时，叙述者可补角色不知的事实，但不预告后面才发生的结果；不把视角限制当成通用去味法。

- **镜头不拉远、不俯瞰、不切他人内心**：别写"整个大厅陷入死寂"这种摄像机视角，写"她听见自己的心跳，旁边的呼吸声一下子全没了"。
- **读者与角色同步获知**：角色不知道的不写；不提前剧透，不补全背景。悬念来自"她也不知道"，不写"她不知道的是"这类提前剧透句。
- **念头是动作的一部分**：用半句的、被打断的、带情绪偏见的主观判断，不写完整理性的内心独白；不强配身体动作，情绪落地按第 1 节。
- **主观偏差代替客观叙述**：场景被角色情绪染色。她恨谁，谁就被写得可憎；她慌，光线就晃。但只能是她此刻带偏见的瞬间感觉，不能写成"像在宣判一件早已定好的事"这类客观盖棺断言。

### 句子节奏按题材借

先按本章情绪和本书文风写顺，再处理解释总结、过度压缩和比喻堆叠。男频、军旅可以借老网文连贯叙事的惯性，现代日常写普通的办事推进；古言世家与慢热日常可保留从容长句与礼数机锋，不必全切成短促碎句；悬疑、科幻、古代不要硬套老派玄幻的大段铺陈或第一人称声口，先读本书 `设定/文风.md`、对标拆文和匹配章摘要。不要把句子机械拉长或压短，也不要全局换成某本对标书的词法。

### 发生、感知、反应写进同一镜头

关键子事件不能只剩一句提纲概括。发生是主干；感知和反应只在提供新信息时加入，并与发生织进同一镜头，不按维度分段，也不要求三项齐全。上下文已经清楚的维度留空；过场、赶路、信息交代类子事件 1-2 句带过即可（见「疏密分配」），把字数让给情绪节点。

| 维度 | 内容 | 要点 |
|---|---|---|
| 发生 | 事情出现了 | 1-2句，包含一个具体细节 |
| 感知 | 主角注意到什么 | 只取会改变理解、判断或气氛的一处声音、物件、空间或身体感受，不按感官凑数；装饰性场景描写（"阳光洒在窗台上"）不算 |
| 反应 | 角色接下来怎么办 | 可以是选择、台词、策略、任务动作、明确感受或有后果的身体反应（见第1节） |

把三个维度分成三段依次写完，同一个动作就被掰开写了三遍：

> ❌ 林父低着头，左手把文书压住，右手拿笔，往纸上落。
>
> 手在抖。
>
> 手从肘到腕都在抖，笔尖在纸上停了停，写了一横，又停，那个"林"字的撇写歪了，他顿了顿，把笔往下压，重写，写完了，笔在手里还是没稳。

需要的维度融进同一段连续正文，读者读到一个完整瞬间：

> ✅ 林父左手压着文书，右手拿笔往纸上落，笔尖一触纸面就偏了，从肘到腕止不住地抖，那一横斜着拖出去。他顿了顿，把笔往下压住重写，写完的"林"字撇还是歪的，笔在手里始终没稳住。

「一……就」把落笔和手抖接成同一刻，结果并进同一句，「他顿了顿」后主语一路承接；手抖改变落笔结果，不是无功能微动作。

### 画面分段

断段按镜头和信息变化，不按维度变化，也不按字数。揉进解决"同一瞬间被拆成三段"，断段解决"手机阅读时一段过密"，两件事不冲突。

| 触发点 | 断段方式 |
|---|---|
| 换了人做事、换了地方、新物件/线索改变了局面 | 另起一段 |
| 直接引语出现 | 对话独立成段 |
| 同一人在同一处的一串动作、一个判断，或一条尚未结束的推理、氛围、情绪链 | 留在同一段，用虚词接成一口气（见「句子怎么连」） |

- 常规叙事段可短，但句子内部不碎；推理、压迫、情绪蓄积段只要在讲同一件事，可以稍长。混进几个人或几处地方才拆，完整镜头未完不硬拆，高压冲突、打脸、反转段也不靠拆碎提速。
- **全章最重的一两拍才单句成段**（底牌亮出、一句定生死的许诺、身份被说破）；其余重拍接在段里。长度表达绵延，不表达重量。

### 主语与名字节奏

角色名用来重置主语和强调，不给每句打标签：

- 段首、场景切换、多人同场、视角重置时，用主角名建立主语。
- 同一动作链/同一段内部，优先用“他/她”、动作承接或省略主语，让句子自然流动。
- 关键转折、情绪爆点、身份反差、读者需要重新盯住主角时，再点名强化。
- 反面信号：连续多句或连续多段都以同一主角名开头（中间无主语混淆、场景切换或强调需要），或为省主语把多人同场写到指代不清。

### 疏密分配

按这场戏要让读者经历什么分配笔墨，不要每个情节点一样长、一样细；平均用力读起来"哪都写得满、哪都不出彩"。

| 情节点类型 | 笔墨 | 写法 |
|---|---|---|
| 爽点/打脸/反转/情绪高潮 | 密（详写） | 感知、动作、对话交锋铺满，慢镜头逐拍展开 |
| 过场/赶路/信息交代/时间跳转 | 疏（略写） | 1-2 句带过，甚至一句概括，不展开 |
| 铺垫/日常/关系升温 | 中 | 挑一两个有代入感的细节写实，其余略 |

**同类并列项不平均用力。** 三样物件、四拨人马、五次出手，按这场戏的作用决定谁展开、谁概括、谁略过，不规定递减次数；被概括的仍各留一个不重复的区分点，否则是漏写。

**判为"密"的地方禁止量词加概括。** "一连七八下""斗了半晌""众人纷纷点头""交手数十回合"（把过程折叠成一个数字，是疏处的手法）。密处只有一种写法：挑出其中**具体的几下**，逐拍写。

### 句子怎么连

子事件之间按真实关系连接（因果、接招、新信息、空间移动、角色下一步），不为过渡另补身体动作。句子内部同样要连，不要罗列：

- **动作串分主次、带虚词**：一句里超过三个动作，用「就、才、又、便、却、倒、还、再、先……才」接出先后和因果，别写成逗号清单。❌「坛子挪到墙角，床板拿袖子擦了一遍，铺盖摊开。」✅「她先把坛子挪到墙角，拿袖子把床板擦了一遍，这才把铺盖摊开。」（三个动作共用主语「她」，「先……这才」接出先后。）
- **碎句并回一句**：❌「门开了。他进来。看了她一眼。没说话。」✅「门一开他就进来了，看了她一眼，一句话没说，径直往里间走。」（「一……就」接时间，后面几拍主语承接，并成一口气。）
- **少写没做的事**：「没A，也没B」「不A，也不B」只在排除猜测、写出落空时用，其余写人物做了什么。❌「她淋着雨求掌柜收留，掌柜没说让她住，也没说不让。」✅「她淋着雨站在门外求宿，掌柜掀着门帘看了一会儿，没轰她走，自己转身进里间去了。」
- **对话带口气**：人物说话按身份、年纪、地方和场合带「吧、呢、啊、嘛、哎」和口头的停顿；通篇对话都是不带口气的完整书面句时，回头按人物恢复，不给每人硬塞同一个口头禅。
- **比喻贴着人物**：取角色此刻熟悉、手边的东西，不造「嗓门比香味还亮」这类跨感官新搭配，也不用「如潮水般」「如沐春风」这类套话。

## 9. 语气标点谱系（标点跟着语气走）

标点承担语气、权力关系和情绪起落，写正文时先判断“这句话在场景里做什么”再定标点。对话里的犹豫、打断可用 `……`；本书文风没另说时，引号外的 `……` 和正文里的 `——`、`—`、`--` 改成逗号接上（必要时用句号）。精修时扫一遍句尾：一整段只剩句号时检查是否把质问、迟疑、爆点压平；满屏 `？`/`！` 时删到只留有功能的位置。

| 语气 / 功能 | 可用标点 | 怎么连 | 禁忌 |
|---|---|---|---|
| 压迫 / 冷静 / 克制 | 句号、逗号、冒号 | 不动声色的陈述，动作和判断用逗号接成一句，冒号落判断 | 不为“有变化”乱加 `！` |
| 质问 / 试探 / 反问 | 问号、逗号 | 关键问题用 `？`，追问接在动作或上一句后面 | 不要连续 5 句全是 `？` |
| 惊讶 / 爆发 / 打脸 | 少量感叹号 | 前因用逗号铺进同一句，峰值落句末，只用 1 个 `！` | 禁止 `!!!` 和整段喊叫 |
| 犹豫 / 未说完 / 心虚 | 对话里 `……`、逗号 | 话里的吞吐用 `……`；叙述里用逗号接上停手、改口 | 叙述里不用 `……` |
| 被打断 / 拖长音 | 对话里 `……`、动作 | 话收在 `……`，接一句截断它的动作（“他抬手截住她的话。”） | 不用 `——`/`—`/`--` |
| 信息揭示 / 判断落点 | 冒号、句号 | “证据只有一个：门锁从里面扣上了。” | 不写论文式长分号链 |

## 10. 在场者的账（镜头准入与衬托）

治的是"所有人一起转向、齐声承认"的场面（人都在场，却没有一个在为自己盘算）。

### 镜头准入：他在为自己争取什么

给在场配角镜头前先想清：**他此刻在保什么、算什么？** 同一场戏里，不同处境的人盯的东西不同：比如演武堂测力，主角一指击穿测力碑后，真气境执事冲上去摸切口，惊的是切口竟无内劲残留；刚劝主角退赛保体面的世家同辈脸色煞白，臊的是自己方才居高临下的姿态；外围学徒则是先被警报镇住，再顺着执事失态哗然。

- 判断方法：**遮住名字，能不能认出这句反应是谁的？** 认不出，说明几个人在替作者说同一句感叹。
- 反应要**分层**：全体折服最没张力，掌权的算利害、输家忙推责、死敌嘴硬换角度挑刺，场面才活。独角戏不用旁人衬托，写清主角这一步图什么即可。

### 说话权分级：惜墨表示地位

在场的人不是平权的。台词只给有立场、推局势的人，其余降为一个动作或眼神：地位越高动作越少，用惜墨显分量；同立场的路人合并成一句，不必挨个起名。**角色什么时候开口或干活，什么时候再点名**。

反面信号：五六个人各做一个等重量的小动作，镜头被平摊，谁也没立住。

### 衬托人：谁说这件事重要

"厉害／难得／要命"由**懂行或有利害关系的人**当场点出，不由叙述者自夸。四种落法：**内行估价**（老掌柜一眼认出刀口是失传锻法）、**强手失态**（稳坐钓鱼台的大人物不得不站起身或招架）、**打破常例**（考官失声说"往年从没人撑过三息"）、**点明代价**（交代旁人平常要拿什么苦功或家底才换得到）。

**难度和分量要在出手前或交锋当下立住**，同时先给一把比高低的尺子（前一个天才拼尽全力留半寸印，主角随手一击却是三寸透孔）。反面：懂行的人在场，却只写他"笑了笑，跟旁边说了句什么"，把最该点破分量的台词吞掉了。
