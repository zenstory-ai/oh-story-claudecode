# 正文格式与小节结构

> 本文件规定默认正文交付格式；用户或目标平台的明确要求优先。
>
> **适用范围**：段落格式（戏剧单元/镜头优先，短段为底色，长段用于完整推理、氛围和情绪链）和对话格式适用于所有体裁。小节结构仅适用于短篇；小节不设统一最低字数。长篇按 `visible_chars_v1` 测量同口径细纲 `字数目标`：内部带 ±12%，用户带 ±15%。

---

## 章节标记

按目标平台选择，未指定时用短篇默认格式：

| 格式 | 平台适用 | 示例 |
|------|----------|------|
| `###1.` | 短篇默认 | `###1.` `###2.` `###3.` |
| `###第一章` | 部分平台 | `###第一章` `###第二章` |
| `1.`（纯数字） | 知乎 | `1.` `2.` `3.`（无 ### 前缀） |

**规则**：全文统一一种格式，不要混用。短篇推荐 `###1.` 或纯数字，简洁高效。

## 段落格式

- **戏剧单元优先，紧密排列**：一段承载一个戏剧单元（动作链、线索发现、视线切换、心理判断或连续推理/氛围/情绪链）；新动作、新物件、新信息、新对话另起一段，同一瞬间的发生、感知、反应织在一起。相邻段落间**只允许一个换行符 `\n`**（禁空行 `\n\n`），无缩进（禁 `　　` 或空格）。
- **长短交错与疏密有别**：不按固定字数切段。高潮、打脸、反转落点可单句成段；完整推理、环境压迫、情绪递进保留稍长段；连续极短段若属同一镜头应合并。爽点与转折展开细节，过场简写。
- **主语与角色名节奏**：段首、转场、多人同场或易混淆时点名建立视角；同一动作链内混用代词、动作承接和省略，关键转折或情绪爆点再点名（仅连续句/段无主语重置却反复点名才算主语过密）。

## 对话格式

| 优先级 | 格式 | 适用平台 |
|--------|------|----------|
| 首选 | `“说话内容”` | 短篇默认、番茄、七猫、黑岩 |
| 平台/项目指定 | `「说话内容」` | 知乎盐言短篇、部分古言、日式或用户指定 |

- 对话**独立成行**，不嵌在叙述段中；默认用中文弯引号 `“…”`（内嵌 `‘…’`），盐言风格或项目指定时用 `「」`（`quote-mode keep` 时不得改掉）。
- 高频公式化标签（「他说」「她道」「他笑了笑说」）用上下文或有后果动作替代，不为省标签硬配端茶杯、挑眉等微动作；普通「说」低频可留，两人连续对话且说话人清楚时可省标签。

```
✅ 正确（独立成行，普通「说」低频可留）：
她把杯子放下。
“你走吧。”她说。
他没有动。
“我说，你走吧。”

❌ 错误（对话嵌在叙述段中）：
她把杯子放下，说道：“你走吧。”他没有动，她又说：“我说，你走吧。”
```

## 语气标点谱系

标点服务语气、人物声线和情绪节奏：

| 语气 / 功能 | 标点策略 | 防线 |
|---|---|---|
| 压迫 / 冷静 / 克制 | 短句、逗号、句号，必要时用冒号压出判断落点 | 不人工加感叹号；克制不是每句都平铺句号 |
| 质问 / 试探 / 反问 | 问号 + 短促追问片段，配合动作停顿 | 避免每句话都以 `？` 结尾 |
| 惊讶 / 爆发 / 打脸 | 真正爆点可用 1 个感叹号，连续爆发最多 1-2 处 | 禁止 `!!!`、整段喊叫式感叹 |
| 犹豫 / 留白 / 面板 | 对话吞吐、面板提示及偶发留白用 `……`；普通停手改口用逗号 | 旁白禁连刷省略号 |
| 被打断 / 拖长音 | 对话引号内收在 `——` 或 `……`，接截断它的动作 | 叙述旁白不用破折号，除非本书文风约定 |
| 信息揭示 / 判断落点 | 冒号、分号或单句成段制造落点 | 保持手机阅读友好，不写论文式分号串 |

- 强势角色常短句收束，试探角色多问号和半句，崩溃角色才用少量感叹/省略；叙述旁白默认不用破折号（——），省略号（……）不在旁白连刷（本书文风明确授权并入书级白名单的除外）。精修重点排查**通篇句号化**与**随机标点堆砌**。

## 小节结构（短篇）

- 用数字编号（`1` `2` `3`）分割小节，每节承载一个完整叙事节拍、推进一个明确情节点；小节数与长度服从叙事职责，不设统一最低字数。
- **跨节衔接**：节尾按小节大纲收束（过渡节可用局部兑现或下一步收住，不必每节强钩子）；下一节开头直接接续，情绪升温、缓冲与回落承接上节行动与后果。

### 小节内部结构

每个小节至少完成第 1 项，其余按本节职责选用：

1. **一个主事件** + **一个或多个真实推进**（风险、信息、关系、资源、决定、行动或读者理解至少改变一项；相关情节点可由同一动作链或对话同时兑现，不为数量新增阻碍、对话或冲突）
2. **情绪或压力落点**（确有变化时写清读者感受如何变化；任务、推理、手艺或等待链不强配情绪转折）
3. **读者模型或下一步变化**（新信息、旧信息改义、决定、行动或后果均可，不强配新事实）
4. **对白按功能使用**（需要时改变信息、策略、权力、关系或下一步行动；独自发现、核验证据、等待、手艺等场景可以无对白）
5. **推进单元按需揉进信息维度**：发生是主干，感知和反应只在提供新信息时织入同一镜头（参考 writing-craft.md 场景写法）

## 8 条格式规则

以下规则按文件开头的优先级执行；其中标点默认可由本书明确的文风约定覆盖：

1. **禁止机械按字数分段**：不要因为超过某个字数就强拆；先判断段落是否仍是一个完整戏剧单元。若混入多个动作/信息/视线切换才拆，完整推理、氛围、情绪链可保留稍长段
2. **禁止段间空行**：正文相邻段落之间只允许一个换行符 `\n`，不得出现空行或连续换行 `\n\n`
3. **避免对话标签机械化**：高频或公式化的「他说」「她道」「他笑了笑说」用上下文或有后果动作替代，不硬配端杯、挑眉等微动作；普通“说”可保留
4. **禁止缩进**：不使用 `　　`（全角空格）或半角空格缩进
5. **禁止正文段落 Markdown 渲染**：除统一的小节/章节标记（如 `###1.`）外，正文段落中不使用加粗 `**`、斜体 `*`、标题 `#`、分隔线 `---` 等 Markdown 语法
6. **默认停顿写法**：正文默认用句号、逗号、换行、动作停顿或短句承担停顿；对话引号内的 `……`、`——`（被打断或拖音）及系统面板、偶发有节制的叙述留白 `……` 可保留，其他功能性破折号/省略号按调用方文风与书级白名单保留。标点偏好不属于不可覆盖的文件结构协议。
7. **禁止通篇句号化或随机标点堆砌**：标点必须跟语气/人物声线/情绪功能匹配；该质问时用问号，该爆发时少量感叹；叙述旁白不用未授权 `——` 硬造停顿，也不在旁白连刷 `……`（对话里的 `……` / `——` 不在此列），不得无功能地乱撒 `？`/`！`
8. **禁止正文混入章节元信息**：章节号只允许出现在标题/小节标记/文件名/追踪记录中。正文叙述、对话、心理描写里不得出现 `第[一二三四五六七八九十百千万两0-9]+章|上一章|上章|前一章|本章|这一章|前文|后文|伏笔|细纲|读者` 这类写作工程词；要改成角色能感知的事件锚点或相对时间，例如把“比第一章那三秒开火更疼”改成“比那三秒开火更疼”。例外：角色在故事世界内真实阅读/讨论“第X章”文本，或真实身为作者/读者并谈论读者身份时，可保留相应词。
