# 正文格式与小节结构

> 本文件规定默认正文交付格式；用户或目标平台的明确要求优先。
>
> **适用范围**：短篇默认手机竖屏短段节奏与单文件小节结构；长篇按戏剧单元/镜头自然断段，字数以细纲「字数目标」（或作者指定的「字数范围」）为准，按非空白可见字符数验收。

---

## 章节标记

按目标平台选择，未指定时用短篇默认格式：

| 格式 | 平台适用 | 示例 |
|------|----------|------|
| `###1.` | 短篇默认、点众、黑岩兼容 | `###1.` `###2.` `###3.` |
| `###第N章` | 番茄、七猫、黑岩主力 | `###第1章` `###第2章` |
| `1.`（纯数字） | 知乎盐言 | `1.` `2.` `3.`（无 ### 前缀） |

**规则**：全文统一一种格式，不要混用。短篇推荐按目标平台选 `###1.`、`###第N章` 或纯数字，简洁高效。

---

## 段落格式

- **短篇竖屏短段**：短篇面向手机竖屏快读，动作提示与台词分行、狠话和情绪重锤句独行，普通叙述每段一两三句换气（连续动作因果自然合段，**不把短篇硬并成大段文字墙，也不拆成抽干内心的纯动作碎句**）。相邻段落间**默认只用单个换行符 `\n`**，无缩进（禁 `　　` 或空格）。
- **长篇戏剧单元优先**：长篇按戏剧单元/镜头断段，高潮打脸可单句成段，完整推理、环境压迫、情绪链可保留稍长段，不按固定字数机械切段。
- **主语与角色名节奏**：段首、转场、多人同场或易混淆时点名建立视角；同一动作链内混用代词、动作承接和省略，关键转折或情绪爆点再点名（仅连续句/段无主语重置却反复点名才算主语过密）。

## 对话格式

| 格式 | 适用平台 |
|------|----------|
| `“说话内容”` | 短篇默认、番茄、七猫、黑岩（首选） |
| `「说话内容」` | 知乎盐言短篇、部分古言、日式或用户指定 |

- 对话**独立成行**，不嵌在叙述段中；默认用中文弯引号 `“…”`（内嵌 `‘…’`），盐言风格或项目指定时用 `「」`（`quote-mode keep` 时不得改掉）。
- 高频公式化标签（「他说」「她道」「他笑了笑说」）用上下文或有后果动作替代，不为省标签硬配端茶杯、挑眉等微动作；普通「说」低频可留，两人连续对话且说话人清楚时可省标签。

```
✅ 正确（独立成行，普通「说」低频可留）：
她把杯子放下。
“你走吧。”她说。
他没有动。
“我说，你走吧。”

❌ 错误（对话嵌在叙述段中）：
她把杯子放下，说道：“你走吧。”他没有动，她又说：“我说，你走吧。”
```

## 语气标点谱系

标点服务语气、人物说话风格和情绪节奏：

| 语气 / 功能 | 标点策略 | 防线 |
|---|---|---|
| 压迫 / 冷静 / 克制 | 句号、逗号、冒号；动作和判断用逗号接成一句，冒号落判断 | 不人工加感叹号；克制不是每句都平铺句号 |
| 质问 / 试探 / 反问 | 问号 + 短促追问片段，配合动作停顿 | 避免每句话都以 `？` 结尾 |
| 惊讶 / 爆发 / 打脸 | 真正爆点可用 1 个感叹号，克制使用禁连刷 | 禁止 `!!!`、整段喊叫式感叹 |
| 犹豫 / 留白 / 面板 | 对话吞吐、面板提示及偶发留白用 `……`；普通停手改口用逗号 | 旁白禁连刷省略号 |
| 被打断 / 拖长音 / 转折拍 | 对话引号内收在 `——` 或 `……`；旁白仅在关键转折或系统提示处克制使用 `——`（短篇旁白尽量不用，长篇也克制少用） | 旁白 `——` 避免刷屏，畸形破折号须修正 |
| 信息揭示 / 判断落点 | 冒号、分号或单句成段制造落点 | 保持手机阅读友好，不写论文式分号串 |

- 强势角色常短句收束，试探角色多问号和半句，崩溃角色才用少量感叹/省略；长短篇均保留标准破折号 `——` 用于对话打断及旁白关键转折/系统提示（控制密度禁刷屏），短篇叙述平时用句号、少刷感叹号，仅对白交锋与情绪爆点自然使用 `！`/`？`；省略号（……）不在旁白连刷。精修重点排查**通篇句号化**与**随机标点堆砌**。

## 小节结构（短篇）

- 用统一小节标记（`###1.` / `1.` / `###第N章`）分割小节；150–300 字导语不写「导语」二字、开头一两段直入冲突——知乎盐言置 `1.` 前，七猫/黑岩/点众/番茄允许放首节前或在首章开头内嵌（后接 `……`/`1.` 切入正文）。
- **体量与卡点**：免费段（1–3 节）每节聚焦 1 个核心场、控制体量避免撑爆付费线；全文约三四成处（32%–44%）节末落付费强卡点；中后段按对应题材节奏推进（见短篇写作或质检表），终局善用首尾物件/台词呼应收尾。小节长度服从节拍，不设统一最低字数。
- **跨节衔接**：非末节节尾停在未完成动作、底牌将亮、狠话条件或突发异常上；下一节首句直接接住上一节结果，不写风景垫场。

### 小节内部结构

1. **明确推进**：每节包含清晰的冲突动作、对白刺点或局势翻转（改变风险、信息、关系或筹码；不按条数凑事件），禁前段纯回忆或原地车轱辘重复。
2. **对话驱动与直白情绪**：强冲突场多靠对话推剧情（知乎吐槽/悬疑可多写第一人称独白），核心交锋直进引号（禁「他说…」间接引语概括），夹带第一人称口语吐槽或利害算账；过场一句带过。
3. **竖屏短段呈现**：动作台词分行、狠话独行、普通叙述两三句换气，避免整块文字墙。

## 硬格式底线

以下规则按文件开头的优先级执行（标点偏好可由本书明确文风约定覆盖）：

1. **段间单换行与无缩进**：正文相邻段落默认只用一个换行符 `\n`（不留多余空行 `\n\n`，仅平台规范或刻意转场留白除外）；不使用全角 `　　` 或半角空格缩进。
2. **禁止正文 Markdown 语法**：除统一小节/章节标记（如 `###1.`）外，正文段落不用 `**`、`*`、`#`、`---` 等 Markdown 语法。
3. **禁止正文混入章节元信息**：章节号只允许出现在标题、小节标记、文件名或追踪记录中。正文叙述、对话、心理描写里不得出现 `第[一二三四五六七八九十百千万两0-9]+章|上一章|上章|前一章|本章|这一章|前文|后文|伏笔|细纲|读者` 这类写作工程词；改用角色能感知的故事内具体事件或相对时间（`男主人/女主人` 等正常生活称谓、穿书/系统语境讨论「主角/反派」或角色真实讨论章节/读者身份时按语境放行）。
