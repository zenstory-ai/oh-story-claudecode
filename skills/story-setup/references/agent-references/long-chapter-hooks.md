# 长篇章级钩子：章首/章尾选择与跨章期待

> 谁读：主会话自己出细纲读「章尾钩子 13 式」「章首钩子 7 式」，细纲任务包只带这两张表的名称与公式；写手、story-architect 读副本。

> 先按章节功能和跨章期待选类型，再决定落点与篇幅。示例取自长篇连载原文，只看停在哪一拍，不照抄句子形状。

---

## 什么时候读这份

### 章尾钩子：根据本章情绪选类型

| 本章情绪/阶段 | 推荐钩子 | 为什么 |
|-------------|---------|-------|
| 悬念/未知 | 突然揭示 / 神秘物品 / 留白 | 激发好奇 |
| 紧迫/危机 | 紧急危机 / 倒计时 / 未完成动作 | 制造焦虑 |
| 反转/真相 | 身份反转 / 隐藏含义 / 回声 | 颠覆认知 |
| 情感/关系 | 两难抉择 / 承诺威胁 / 情感转折 | 拉扯情绪 |
| 系统文特有 | 系统激活 / 选择型 | 期待金手指 |
| 氛围/日常 | 意象钩子 / 离奇消失 / 信息差 | 暗流涌动 |

### 章首钩子：根据开篇策略选类型

| 开篇策略 | 推荐钩子 | 为什么 |
|---------|---------|-------|
| 直接冲击 | 未完成动作开局 / 倒计时开局 | 即时紧迫感 |
| 制造好奇 | 悬念对话 / 闪前碎片 / 神秘独白 | 信息差驱动 |
| 对比冲击 | 反差场景 / 意象预示 | 反差吸引 |

### 钩子强度

| 故事阶段 | 推荐类型 | 强度 |
|----------|---------|------|
| 第 1 章 | 系统激活 / 截断 / 危机升级 | 必须强 |
| 2-3 章 | 选择 / 信息差 / 情感转折 | 强 |
| 大结局 | 时间跳跃 / 情感转折 | 收束 |

其余章按细纲标的这章松还是紧：紧的章停在危机、决定、发现或反转上；松的章留一个情绪钩子或下一步打算即可。

## 章尾钩子 13 式

| # | 名称 | 公式 | 示例 |
|---|------|------|------|
| 1 | 突然揭示 | 抛出改变全局的信息 | （主治医生满头是汗地跑来）“不可以，这个人的心脏没有了，现在只剩个快耗尽寿命的人工心脏啊！” |
| 2 | 紧急危机 | 下章必须回应的紧迫威胁 | （宣战书送到）三天后，城门前不死不休！ |
| 3 | 未完成动作 | 动作被新变量打断 | 刚要踏出主院，迎面却被一小丫鬟拦下。 |
| 4 | 身份反转 | 身份真相偏离读者预期 | “周总，你抱的好像是我老婆。” |
| 5 | 两难抉择 | 被迫在两个坏选项中选一个 | “我爸妈说了，给我两个选择，要么娶你，要么立马找个人订婚。” |
| 6 | 神秘物品 | 重要但含义未知的物件 | 谢知意的手包里敞开了口，露出了里面半截照片。 |
| 7 | 倒计时 | 时间不够用 | 距离月底还有不到十天的时间，让他上哪弄这一百万去？ |
| 8 | 承诺/威胁 | 有人宣布了行动意图 | 臭小子，你给我等着，总有你哭着求姐姐的时候。 |
| 9 | 离奇消失 | 不可能的消失 | 沐寒枫却不见了踪影。 |
| 10 | 隐藏含义 | 表面正常，实际暗藏信息 | 谢知意虽然抱着季修远哭诉，眼角的余光却一直锁定在自己身上。 |
| 11 | 意象钩子 | 反复出现的意象发生变化 | 雨夜中，银白蝴蝶逐渐消失，悬停的雨滴重新坠落，世界恢复了原本的模样。 |
| 12 | 回声钩子 | 章尾句呼应开头，关键细节变了 | 取本章开头的原话，只换一个关键细节 |
| 13 | 留白钩子 | 只展示反应，不揭示发生了什么 | （父亲质问后）叶良辰脸色平静，一言不发。 |

## 章首钩子 7 式

| # | 名称 | 公式 | 示例 |
|---|------|------|------|
| 1 | 悬念对话开局 | 直接从意味深长的对话开始 | “认识你这么多年，还是第一次看见你这样，怎么，因为宁淮初？” |
| 2 | 闪前碎片 | 先给结果碎片，再回正常叙事 | 本书文风允许回顾或全知视角时才用 |
| 3 | 倒计时开局 | 开头就建立紧迫感 | 时间一分一秒流逝，距离天黑仅仅剩下不到一个小时。 |
| 4 | 神秘独白 | 第一人称诡异内心独白 | 第一人称的书才用，独白里要有具体的人和事 |
| 5 | 反差场景 | 两个截然不同的场景并列 | 两处必须在本章接上 |
| 6 | 未完成动作开局 | 动作进行中被截断 | 她刚要张口，忽然眼前一暗。 |
| 7 | 意象预示 | 用环境意象暗示即将发生的事 | 环境变化直接卡住本章行动时才用，不写成天气开场 |

## 章尾实战模板

按本章停在哪一拍选，句子用本书自己的声口写：

| 类型 | 停在哪一拍 | 原文 |
|---|---|---|
| 系统激活型 | 主角正要做决定，系统给出新信息 | 陆晨思索片刻，正要答应，脑海中突然响起系统提示：“叮！危机感知：有人欲借考核加害于你。” |
| 悬念预知型 | 有人放话，结果留到下章 | （被追问清风长老之死）“明天你就知道了。” |
| 截断型 | 动作刚开头，新变量闯进来 | 正要吩咐阿蛮去摘，忽然听见远处传来一阵喧哗。 |
| 选择型 | 摆出两个都有代价的选项，不给结果 | 系统文常用奖励和代价并列的选项面板 |
| 危机升级型 | 平静被坏消息打断，下章必须处理 | 众人正热闹着，忽然一个女孩哭哭啼啼跑进来，对三婶道：“娘，大哥把老爷的牛摔死了，刚被老爷家人捆走了，说要给牛偿命呢！” |
| 身份即将揭露型 | 旁人猜到边上，主角还没认 | “我看这更像是一条机械龙，难道他就是那个机械掌控者？” |
| 情感转折型 | 一方示弱或求人，另一方还没回应 | 方雅琳看出来，也开口恳求，“大队长，求你救救他们！” |
| 信息差型 | 读者知道的比场内某人多，章尾提醒这张牌 | 落在知情者的一个具体动作上，不写“他不知道的是” |
| 对话悬念型 | 话说一半，后半句出乎预期 | 落在那句出乎预期的台词上 |
| 时间跳跃型 | 跳过过程，直接给出新进展 | 两天后，苏听岚接到了警察局的电话，让她去警察局一趟。 |

## 三种速写章末钩子

- **收获预告型**（副本/任务尾声）：行动接近完成，奖励比预期更大的迹象刚露出来。
- **反派逼近型**（铺垫段结尾）：主角这边照常，暗处的反派动了一步，这一步会碰到主角。
- **行动预告型**（装逼/打脸前）：主角做了决定和准备动作，不写结果。

## 质量检查

写完章首/章尾后对照：

- [ ] 章首尽早出现可识别的行动、异常或未闭合期待；不按固定百字位置机械卡点
- [ ] 章尾有让读者想翻下一页的东西
- [ ] 钩子强度与细纲标的松紧匹配（松的章不必强钩子）
- [ ] 连续两章不用同一种钩子
- [ ] 钩子没有为凑长度重复解释，落点与本章功能、下一章承接一致
