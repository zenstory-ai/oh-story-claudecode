# 长篇章级钩子：章首/章尾选择与跨章期待

> 谁读：主会话自己出细纲读「章尾钩子 13 式」「章首钩子 7 式」，细纲任务包只带这两张表的名称与公式；写手、story-architect 读副本。

> 先按章节功能和跨章期待选类型，再决定落点与篇幅。示例只看停在哪一拍，不照抄句子形状。

---

## 什么时候读这份

### 章尾钩子：根据本章情绪选类型

| 本章情绪/阶段 | 推荐钩子 | 为什么 |
|-------------|---------|-------|
| 悬念/未知 | 突然揭示 / 神秘物品 / 留白 | 激发好奇 |
| 紧迫/危机 | 紧急危机 / 倒计时 / 未完成动作 | 制造焦虑 |
| 反转/真相 | 身份反转 / 隐藏含义 / 回声 | 颠覆认知 |
| 情感/关系 | 两难抉择 / 承诺威胁 / 情感转折 | 拉扯情绪 |
| 系统文特有 | 系统激活 / 选择型 | 期待金手指 |
| 氛围/日常 | 意象钩子 / 离奇消失 / 信息差 | 暗流涌动 |

### 章首钩子：根据开篇策略选类型

| 开篇策略 | 推荐钩子 | 为什么 |
|---------|---------|-------|
| 直接冲击 | 未完成动作开局 / 倒计时开局 | 即时紧迫感 |
| 制造好奇 | 悬念对话 / 闪前碎片 / 神秘独白 | 信息差驱动 |
| 对比冲击 | 反差场景 / 意象预示 | 反差吸引 |

### 钩子强度

| 故事阶段 | 推荐类型 | 强度 |
|----------|---------|------|
| 第 1 章 | 系统激活 / 未完成动作 / 紧急危机 | 必须强 |
| 2-3 章 | 选择 / 信息差 / 情感转折 | 强 |
| 大结局 | 时间跳跃 / 情感转折 | 收束 |

其余章按细纲标的这章松还是紧：紧的章停在危机、决定、发现或反转上；松的章留一个情绪钩子或下一步打算即可。

## 章尾钩子 13 式

| # | 名称 | 公式 | 示例 |
|---|------|------|------|
| 1 | 突然揭示 | 抛出改变全局的信息 | 法医掀开白布，顿住了：“死者根本不是林家大少爷，他后背没有那道旧疤。” |
| 2 | 紧急危机 | 下章必须回应的紧迫威胁 | （宣战书送到）三天后，城门前不死不休！ |
| 3 | 未完成动作 | 动作被新变量打断 | 手刚碰到密室暗格，院外忽然传来急促的脚步声。 |
| 4 | 身份反转 | 身份真相偏离读者预期 | （酒局上对头正揽着女伴炫耀，主角推门）“周总，你抱的好像是我老婆。” |
| 5 | 两难抉择 | 被迫在两个坏选项中选一个 | （绑匪把刀架在两人颈间）“解药只有一贴，救你师父，还是救你师妹？” |
| 6 | 神秘物品 | 重要但含义未知的物件 | （情敌落下的手包敞口）露出半截男主与亡故白月光相似的旧照。 |
| 7 | 倒计时 | 时间不够用 | 距离月底不到十天，让他上哪弄这一百万去？ |
| 8 | 承诺/威胁 | 有人宣布了行动意图 | （被退婚的少年攥着碎裂婚书走出大门）“三年后的宗门大比，我会亲自上山讨回今日这拜。” |
| 9 | 离奇消失 | 不可能的消失 | （小队捏碎传送符脱险，清点人数时）唯独负责断后的大师兄不见了踪影。 |
| 10 | 隐藏含义 | 表面正常，实际暗藏信息 | 白月光抱着男主哭诉，背过他视线时，眼角余光却得意地瞥向女主。 |
| 11 | 意象钩子 | 反复出现的意象发生变化 | （师父留下的保命长明灯）灯火毫无征兆地灭了，灯座下裂开一道细缝。 |
| 12 | 回声钩子 | 章尾句呼应开头，关键细节变了 | 取章首原话只换关键细节（如章首“绝不退亲”，章尾查清后“明早就退亲”） |
| 13 | 留白钩子 | 只展示反应，不揭示发生了什么 | （老爷子扇耳光质问是否害死亲弟夺位）他擦去嘴角血迹，脸色平静，一言不发。 |

## 章首钩子 7 式

| # | 名称 | 公式 | 示例 |
|---|------|------|------|
| 1 | 悬念对话开局 | 直接从意味深长的对话开始 | （替身收支票走后，冷漠男主闷头灌酒，好友推门）“认识这么多年第一次见你失态，就因为刚走的那女人？” |
| 2 | 闪前碎片 | 先给结果碎片，再回正常叙事 | 本书文风允许回顾或全知视角时才用 |
| 3 | 倒计时开局 | 开头就建立紧迫感 | 时间一分一秒流逝，距离天黑仅剩不到一小时。 |
| 4 | 神秘独白 | 第一人称诡异内心独白 | 第一人称的书才用，独白里要有具体人和事 |
| 5 | 反差场景 | 两个截然不同的场景并列 | 两处必须在本章接上 |
| 6 | 未完成动作开局 | 动作进行中被截断 | （刚摸到密室门环想求救）她刚要张口，忽然眼前一暗，被人从身后捂住嘴。 |
| 7 | 意象预示 | 用环境意象暗示即将发生的事 | 环境变化直接卡住本章行动时才用，不写成天气开场 |

## 补充章尾模板

13 式之外常用的五种收尾落点，句子用本书自己的声口写：

| 类型 | 停在哪一拍 | 示例 |
|---|---|---|
| 系统激活型 | 主角正要做决定，系统给出新信息 | 他思索片刻，正要答应，脑海中突然响起系统提示：“叮！危机感知：有人欲借考核加害于你。” |
| 选择型 | 摆出两个都有代价的选项，不给结果 | 面板弹出两个选项：交出密令保住外门名额，或抗命受罚、解锁隐藏传承。 |
| 情感转折型 | 一方示弱或求人，另一方还没回应 | （丈夫进深山打猎彻夜未归，一向怯懦的妻子冒雪敲开大队长家门）她红着眼开口恳求：“大队长，求你带人进山救救他们！” |
| 信息差型 | 读者知道的比场内某人多，章尾提醒这张牌 | 落在知情者的一个具体动作上，不写“他不知道的是” |
| 时间跳跃型 | 跳过过程，直接给出新进展 | 两天后，她接到了派出所打来的电话，让她立刻过去一趟。 |

---

## 三种速写章末钩子

- **收获预告型**（副本/任务尾声）：行动接近完成，奖励比预期更大的迹象刚露出来。
- **反派逼近型**（铺垫段结尾）：主角这边照常，暗处的反派动了一步，这一步会碰到主角。
- **行动预告型**（装逼/打脸前）：主角做了决定和准备动作，不写结果。

## 质量检查

写完章首/章尾后对照：

- [ ] 章首尽早出现可识别的行动、异常或未闭合期待；不按固定百字位置机械卡点
- [ ] 章尾有让读者想翻下一页的东西
- [ ] 钩子强度与细纲标的松紧匹配（松的章不必强钩子）
- [ ] 连续两章不用同一种钩子
- [ ] 钩子没有为凑长度重复解释，落点与本章功能、下一章承接一致
