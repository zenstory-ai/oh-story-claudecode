# 开篇设计

> 谁读：出前 3 章细纲时读「开篇规划」（细纲任务包带入）；主会话或写手写第 1-3 章正文时读「开篇落笔」。

## 开篇规划

只定开局类型、三基点落在哪章、前三章各交代什么，不写句式骨架。开篇用哪种噱头（事件、金手指、人设）和对应的开篇流程，见 plot-core-methods.md「噱头分类与开篇流程」。

### 开局类型

| 开局 | 适合 | 第 1 章怎么起 | 注意 |
|---|---|---|---|
| 冲突开局 | 番茄、七猫；都市、系统、重生复仇、追妻、宅斗 | 第一场就是危机、反常或反转 | 卷纲给不出更高代价、更强对手或更深反转时别用强情绪开局；后面每个大节点至少在代价、范围、真相或关系上升一级 |
| 环境开局 | 起点慢热向；低位起步的玄幻、西幻、种田 | 从主角低位处境里的小压力写起，信息顺着主角的行动带出 | 不等于写风景；第 1 章结束前仍要立起一个让人追的问题 |
| 人设开局 | 晋江、女频细腻向 | 先用一场选择立住主角的魅力和处境 | 节奏可以慢，第 1 章结束前仍要立起一个让人追的问题 |

### 三基点与章位

| 基点 | 内容 | 最迟 |
|---|---|---|
| 切入点 | 主角遇到的第一个冲突或机遇，和主线强相关 | 第 1 章 |
| 人设 | 主角的核心性格和处境，靠一次选择立住 | 前 3 章 |
| 金手指 | 主角的独特优势首次起作用 | 前 3 章 |

困境型先立人设、再遇压迫，金手指在主角已经出手、能力不够时出现，初步解决后引出更大的问题；优势型先让被低估的优势在某个场合暴露，旁人认知被刷新，暴露引来更大的麻烦。第一个冲突写清解决了得到什么、不解决失去什么，由主角主动选择用金手指解决。

### 前三章交代什么

- 第 1 章：交代主角眼下要干什么（主要角色出场不超 3 个），核心卖点（金手指、玄学本事、系统、重生记忆、医毒手艺之类）当场亮一次、起一次作用，不压到后面几章才露。
- 第 2 章：矛盾加深。第 3 章：给出继续追读的理由。
- 前 3 章里至少有一次主角和对手的正面冲突：当面交锋、有来有回，不是只听说或隔着人转述；排进其中一章的情节点。
- 前 3 章立起够大的赌注：主角输了要失去的必须具体而重（性命、至亲、身份、全部家当、前程），一份药、几枚灵石撑不起开篇。
- 前 3 章点明全书主线目标，并定下基调：令人不安的处境、急待提升的地位、有希望的外挂、能看见的好结果，后面不中途改调。
- 读者站到主角这边之前，不把对手写得可怜。
- 有感情线的书，感情线对象在第一段剧情内出场。

### 开篇自查

- [ ] 书名、简介承诺的东西，开篇兑现了
- [ ] 创意落成了具体冲突，不只停在概念
- [ ] 背景和世界观没有排在冲突前面
- [ ] 第 1 章出场的主要角色不超过三个

## 开篇落笔

写第 1-3 章正文时读，按细纲定的开局类型和三基点章位落到纸面。

- 主角 300 字内出场并处在压力里；1000 字内出现第一个让人想往下看的点：反常、危机或筹码露头。
- 第一场从主角正在做的事写起，环境开局也一样；不以天气、风景、世界观或身世介绍开头，反差极大的景除外。
- 背景跟着冲突走，一次只放眼前这场戏用得上的一条，借对话、旁人反应和后果带出：先危机感，再人设，再金手指的暗示，世界观至少等第一个剧情单元收完。拿不准就往眼前的矛盾上连，隔好几层才连得上的删掉。
- 过去的事一两句带过，不单独写成回忆场；不写序章、楔子（短而直接接上第一章的除外），不插叙，不切到配角或反派视角，本书文风选了多视角的除外。
- 后文没戏份的配角不给名字。
- 金手指首次起作用时当场有看得见的变化；困境型放在主角已经出手、能力不够的时候。
- 主角做出一个能看出性格的选择；不写见美女紧张、无意义的内心戏这类拉低主角的段落。
- 第 1 章结束前，读者能说出主角眼下要干什么。
