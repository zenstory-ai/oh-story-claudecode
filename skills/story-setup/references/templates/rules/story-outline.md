# Story Outline Rules

用于长篇卷纲与章节细纲；短篇小节大纲按其写作 skill 执行。字段与写法以 story-long-write 出卷纲、出细纲时给的模板为准，有任务包时以任务包为准；这里只列落盘时不能少的部分。

## Rules

1. **卷纲**：按 story-long-write 的卷纲模板写，只有剧情段标题末尾写剧情段编号注释如 `<!-- L1-01 -->`，全卷的小节不写（老卷纲的 `<!-- 全卷 -->` 和老卷纲标题下一行的 `> 作用域：…` 照样认）；编号只在标题注释和伏笔表编号列里出现，卷纲正文和细纲提到剧情段写段名、提到伏笔写内容。写纲前查缺、写纲时补的写进书目录下的 `.story/排纲笔记/{剧情段编号}.md`（排纲自用，作者不用读），不进卷纲。

2. **细纲必填项**：每个细纲（细纲_*.md）必须包含当前“章节蓝图”：
   - 基础执行字段：核心事件、字数目标、属于哪段剧情（只写段名，如「第一段剧情：退婚风波」，不写编号）、目标情绪、主角目标/关键选择、章首钩子、爽点（七个必填字段；字数口径不用写，没写按默认口径）
   - 这章怎么走：起因 / 发展 / 转折 / 高潮 / 结尾——结尾写本章最后落在什么动作或画面上，不写状态判词
   - 情节安排（多线）：主线推进 / 辅线推进（写卷纲故事线表里的线名）/ 事件线或任务线 / 感情线或关系线 / 逻辑线
   - 人物关系和出场顺序：按实际出现顺序列角色/势力/关键物件，并写人物关系变化
   - 情节细化：情节点序列写成表格 `# | 情节点（谁做了什么） | 作用`（某个点确要限定写到什么程度时才在表末加「分寸」列），不填写逐点字数、不按 beat 数预测容量；并标 行动成本（可无）/收益归属，不硬造代价
   - 结尾设定和钩子：结尾设定（落到最后的具体动作或画面）、未解决问题、下一章推动力、章尾钩子
   - 可选（需要时再写，不写不拦）：这章不能说破（这章确有一件具体的事要压住时写一行，没有就不写）、字数范围（作者给了上下限才写，如 2000-2600）、阶段位置、松紧、本章结构公式、本章标价、闭环状态、可以放开写的地方、镜头准入、信息差触发点、情节点「分辨率」列；「有没有硬伤」只在这章让剧情段的判断变了时写

3. **缺项处理**：旧细纲缺章节蓝图字段不阻止续写，旧字段名（单元ID/位置、本章禁止提前释放、内容概括（五段式）、写手自由区、功能标签、执行边界、字数口径）照样认，回退读旧字段（核心事件、情节点序列、目标情绪、章首/章尾钩子、字数目标），只在明确补纲、改纲时按当前模板补齐；新建、补建、改纲的细纲必须补齐后再写正文。旧卷纲同样不阻塞，按字段结构回退读取，已写区间的卷纲不自动改写。材料确认不了的辅线、关系变化或代价收益写 `[待补充]`，不编造。
