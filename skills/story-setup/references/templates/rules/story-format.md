# Story Format Rules

正文格式规范。视角、对话落法与段落长短按作者要求和本书文风（设定/文风.md，没有就按当前请求）；标题、换行仍按下列格式。不用固定段数或字数当标准。

## 绝对禁止

1. **禁止机械分段或通篇大段**：段落按戏剧单元/镜头/一件事结束自然断开；不要按固定字数强拆，也不要把多个动作、线索、视线切换塞进一段。完整推理、氛围压迫、情绪变化链可保留稍长段。
2. **禁止段落间空行**：正文相邻段落之间只允许一个换行符 `\n`；不得出现空行或连续换行 `\n\n`。
3. **避免对话标签机械化**：高频或公式化的「他说」「她道」「他笑了笑说」用上下文或有后果动作替代，不为省标签硬配端茶杯、挑眉等微动作；普通「说」低频使用可保留。
4. **禁止大段描写堆砌**：描写要穿插动作、对话或新信息，不连着堆纯描写。
5. **遵守视角约定**：第一人称/限知第三人称场景内，不擅自切换到其他角色内心。
6. **禁止主语过密**：同一动作链内不要连续句/段无必要重复同一主角名；段首或主语重置时点名，段中用代词/动作承接/合理省略，关键转折再点名。

## 格式规范

- 对话独立成行，动作承接放在同一角色的话前后；引号未另约定时默认用中文弯引号 `“…”`（内嵌 `‘…’`），全书统一
- 段落以戏剧单元、镜头、情绪或动作为单位划分
- 章节标题服从项目既有格式，未指定时用 `## 第X章 章名`，标题后保留一个 Markdown 空行
- 章节之间不使用 `---`、水平分隔线或额外空白行

## Examples

### Correct — 按戏剧单元自然断段
```
沈栀抬手，灵力从指尖涌出。
面前的结界出现一道裂缝，碎纹像蛛网般蔓延开。
她咬紧牙关加大输出，整条手臂开始发颤。
```
每段只承载一个动作/信息变化，段落按戏剧单元自然推进，段与段之间只有一个 `\n`。

### Wrong — 多个拍点挤成一段
```
沈栀抬手灵力从指尖涌出面前的结界出现一道裂缝碎纹像蛛网般蔓延开她咬紧牙关加大输出整条手臂开始发颤最后结界轰然碎裂碎片向四周飞溅。
```
同一段混入多个动作、线索和结果，读者无法在关键变化处停顿。

### Correct — 对话用动作引出
```
沈栀将茶杯往桌上一顿。
“你到底想说什么？”
陆衍没接话，只是看着窗外。
```
对话通过动作和上下文引出，避免高频公式化标签。

### Wrong — 对话标签堆叠
```
沈栀将茶杯往桌上一顿。
她说道：“你到底想说什么？”
陆衍没接话，他轻轻叹道只是看着窗外。
```
同一段里连用「说道」「叹道」是公式化标签堆叠，应用动作替代。

### Correct — 章节标题后无多余空行
```
## 第二章 暗流

陆衍推开门时，屋内已经坐了三个人。
沈栀坐在最里面的角落，手里捏着一张纸条。
```
章节标题 `##` 与正文之间仅一个空行（Markdown 渲染需要），正文段落间无空行。

### Wrong — 段落间多余空行
```
## 第二章 暗流


陆衍推开门时，屋内已经坐了三个人。


沈栀坐在最里面的角落，手里捏着一张纸条。
```
段落之间出现多余空行（连续换行 `\n\n`），破坏紧凑节奏。
