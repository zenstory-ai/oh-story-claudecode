# 晋江：采集与分析

作者选了晋江才读本文。书店榜优先走下面的协议采集，不启动 Chrome，不下章节。原网页脚本仍可用：需先用 `/browser-cdp` 启动 Chrome。脚本两步走：① 列表页 `topten.php` 取频道分组与书名/作者，从书名链接取 `novelid`（排除「X 向《书名》投了 Y」霸王票记录）；② 进 `onebook.php?novelid=` 详情页补采核心指标。晋江是 gb18030 编码，脚本已按此解码；详情指标公开，无需登录。

## 协议采集

```bash
python3 bridge/rankmin_cli.py --out {输出目录} --limit 20 --jjwxc 月度排行榜·言情,月度排行榜·纯爱,新晋作者榜·言情,完结金榜·言情
```

别名是「榜名·频道」。收藏、营养液、积分、字数来自公开作品页上该指标自己的文本，没读到写 `[待补]`。`--limit` 默认 20。要更多本时提高 `--limit`，客户端翻页直到本数够、短页或重复页；到了 40 页上限仍满且本数不够，该榜失败。本数已经够时文件会写明后面可能还有。作者积分榜和 TOP100 没有频道分页，命令失败。依赖是 Python 标准库。任一榜失败退出码 2，已经写出的文件保留。

## 榜单与命令

URL `jjwxc.net/topten.php?orderstr={榜单ID}&t={频道ID}`（t=0 全站）。orderstr：收入金榜 12 / 月榜 7 / 季度榜 8 / 完结金榜 14 / 新手金榜 15 / 千字金榜 17。

```bash
node scripts/jjwxc-rank-scraper.js --type 12 --outdir {输出目录}        # 列表+详情（默认每频道前 10，详情上限 100）
node scripts/jjwxc-rank-scraper.js --type 12 --top 15 --detail-limit 60  # 调整每频道本数/详情总量
node scripts/jjwxc-rank-scraper.js --type 12 --list-only                 # 只采列表（快，无核心指标）
```

默认组合：收入金榜 + 月榜。

## 字段与硬性要求

频道（聚合时当题材）、排名、书名、作者、novelid、收藏数（核心，聚合的热度口径）、营养液、积分、字数、状态、作品页链接。必须有详情页核心指标（收藏、营养液或积分、字数）：用了 `--list-only` 或文件头标 `[仅列表-无核心指标]` 的数据撑不起下面的分析，视为不合格，要重采。
