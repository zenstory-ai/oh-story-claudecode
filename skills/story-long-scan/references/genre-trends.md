# 内置题材候选

无实时榜单时使用。这里的题材、流派和书名来自历史样本，只能当候选假设；可行性最高给"中"，并列出要复扫的榜单。

## 新元素分三级

| 级别 | 频率 | 怎么对待 |
|------|------|----------|
| 新题材 | 极少 | 跨榜单、跨作者都出现重复样本才算趋势，否则只当观察项 |
| 新金手指 | 较少，多是翻新 | 适合低成本验证，但题材外壳和情绪触发都要变化 |
| 新噱头 | 常见 | 同质化风险高；没有差异化机制就降低优先级 |

## 男频题材候选

| 题材 | 候选方向 |
|------|----------|
| 都市 | 重生、种田、娱乐、都市高武；重生能和多数元素融合 |
| 玄幻 | 极道流、加点横推这类反馈直接的优先；传统玄幻近期样本少就标高风险 |
| 仙侠 | 先查脑洞融合路线的近期样本；纯传统路线要另行验证受众 |
| 历史 | 秦、唐、明、宋、三国；穿越改命、争霸 |
| 诸天无限 | 同人副本和原创副本分开看，看世界规则能不能持续兑现核心期待 |
| 科幻 | 末世为主，常混脑洞、种田、游戏设定 |
| 悬疑灵异 | 恐怖灵异、奇门秘术、侦探推理 |

常见流派：极道流（属性加点、横推）、凡人流（小人物攀爬、精打细算）、巫师流（知识体系加实验升级）、种田流（经营反馈推进）、盘点文、模拟文、两界穿梭。同人仅在作者明确目标作品、平台允许且近期样本有效时列。

## 长篇书名写法

七猫书库存量长篇（80 万字以上）常见书名写法占比（仅作存量起名参照，新书起名以本次新书榜常见词为准）：

| 写法 | 男频 | 女频 |
|------|------|------|
| 书名带「我」 | 35% | 22% |
| 冒号分前后两段（「大明：开局小县令，红温朱元璋」） | 28% | 19% |
| 带「重生」 | 7% | 9% |
| 带「开局」 | 9% | 不到 1% |
| 「从…开始」 | 6% | 不到 1% |
| 带「总裁 / 大佬 / 霸总」 | 2% | 13% |
| 带「离婚」 | 2% | 5% |
