# 番茄：采集与分析

先用 `/browser-cdp` 启动 Chrome。

## 默认命令

`--channel` 按 Phase 1 的频道取：1=男频、0=女频、all=男女都采。

```bash
node scripts/fanqie-rank-scraper.js --channel all --type 2 --outdir {outdir}   # 男女频阅读榜
```

作者要看新书里在冒头的，再加新书榜和书库「最热」：

```bash
node scripts/fanqie-rank-scraper.js --channel all --type 1 --outdir {outdir}             # 男女频新书榜
node scripts/fanqie-rank-scraper.js --source library --channel all --outdir {outdir}     # 书库：连载中、30 万字以下，男女各前 3 页
```

## 可选参数

- 排行榜：`--type 2` 阅读榜、`--type 1` 新书榜、`--type all` 两个都采。脚本按题材采集，每类取前 20 本（`--top N` 可调），每个频道写一份 `番茄{频道}{榜单}_全题材_{日期}.md`。
- 书库「最热」：每页 18 本，按热度排。`--channel mix` 不分男女，`--pages N` 改页数，`--stat 1|0|any`（连载中/已完结/不限）、`--count 0-4|any`（30 万字以下、30-50 万、50-100 万、100-200 万、200 万以上/不限）改筛选。只有默认筛选（连载中、30 万字以下）在列表名里带「新书」，按新书样本计。

## 字段与热度口径

排名、书名、作者、题材、状态、在读（核心指标，聚合的热度口径）、字数、标签（简介开头的 `【种田+慢热+西幻】`，题材细分的真实信号）、最新更新、作品页链接、简介。页面没有评分。

**每题材等额采样**：排行榜每个题材都取前 20 本，题材本数和占比受采样上限影响，不代表题材大小；聚合会注明。题材冷热看热度中位和平台 P75，新风向看新书榜和书库新书。

## 采不到时

文件头「数据质量」标 `[标题解析异常]`（书名多为 `（标题待解析）`）：多半是被登录或验证页拦住，或页面改版。在已登录的 Chrome 里手动打开任一 `https://fanqienovel.com/page/{bookId}`，确认页面正常、不是验证页；报 `CDP 无响应` 就按 browser-cdp 重新启动 Chrome。确认正常后重采。

## 分析维度

| 维度 | 看什么 |
|---|---|
| 阅读榜 vs 新书样本 | 阅读榜看存量读者规模（在读数）；新书榜与书库最热看新题材样本，同口径前后对比才算起量 |
| 在读差距与标签热词 | 同题材头部与腰部的流量差；`【】` 内标签组合揭示细分卖点 |

## 本平台读者

免费阅读，读者面广。要快节奏、强爽感、目标与因果清楚，爽点偏打脸、装逼、获得机缘；雷区是目标迟迟不明、长期虐主、解释压过剧情。脑洞和强情绪题材多，同质化也重，选题要写清差异化。
