# 反派设计与真相揭露

> 谁读：构思时有反派或真相揭露，主会话整份读；写正文不读，按 设定.md 写。

---

## 1. 反派设计模板

### 人设模板

填写以下模板，写进 设定.md「构思要点」，替换“反派：没有”那一行（一字段一行）：

```
反派：
- 身份：{与主角的关系}
- 动机：{自洽的作恶逻辑：贪婪/嫉妒/控制欲/报复/自保}
- 作恶方式：{具体手段：言语打压/经济控制/社交孤立/人身伤害/法律构陷}
- 致命弱点：{可被主角利用的弱点：贪婪/傲慢/秘密/依赖/恐惧}
- 报应：{与恶行对应的结局}
```

### 嚣张度递增阶梯

按前因与损失加重反派行为，避免重复同一种恶行：

| 级别 | 行为类型 | 示例 |
|------|----------|------|
| 小恶（开局） | 言语打压、冷暴力 | 「你嫁进来就算烧高香了」 |
| 中恶（中段） | 经济/社交伤害 | 偷拿存折、在外败坏名声、挑拨关系 |
| 大恶（后段） | 人身/法律伤害 | 下药、构陷、逼死、拐卖 |

### 5 种反派类型速查

| 类型 | 特征 | 常见作恶方式 | 致命弱点 |
|------|------|--------------|----------|
| 操控型 | 打着为你好控制一切 | 妈借“存嫁妆”收走女儿工资卡，全贴给儿子买房 | 流水经不起当面核对 |
| 贪婪型 | 得寸进尺、无底线索取 | 彩礼谈拢二十万，临上婚车又加价十万“下车费” | 被当场退婚并起诉追回 |
| 伪装型 | 靠假身份或假怀孕设局 | 拿假孕检单骗家里掏空积蓄买房的相亲对象 | 医院复查即露馅 |
| 嚣张型 | 仗势欺人、有恃无恐 | 部门主管抢下属方案署名，还当众逼人辞职 | 不知大老板是下属亲属 |
| 软刀型 | 装弱博同情、暗中吸血 | 当二女儿面哭诉受大姐气，背地拿她的钱贴大姐 | 私下分钱被在门外听见 |

## 2. 真相揭露机制

### 4 种揭露方式

| 方式 | 机制 | 落地示例（铺垫 → 揭露 → 后果） |
|------|------|-------------------------------|
| **证物揭露** | 铺垫段埋平常物件/文件，当场验真伪翻转认知 | 妈炫耀姐姐送的「两万金镯」骂妹妹小气 → 摔断去金店修验出是几十块镀金假货 → 妈当众出丑反找姐姐大闹 |
| **证人揭露** | 知情边缘角色（保姆/邻居/经手人）关键节点交出实情与物证 | 辞退多年的老保姆偶遇主角欲言又止 → 交出录音与药瓶证明亡母犯病时继母藏起救心丸 → 家族宴当场报警揭穿继母 |
| **偷听/撞见** | 设计折返或意外在场契机，亲耳听见私下算计 | 拆迁款到账日妈接电话总躲阳台 → 去收衣服听见妈对姐说「八十万只跟她报三十万」 → 次日一早将拆迁专户挂失锁死 |
| **延迟剥洋葱**（设定.md 写「一层层揭开」） | 每层占一节且比上一层更残酷；下一层揭开前人物先按上一层答案行动 | 第1层查出准弟媳律所工牌造假拦下彩礼 → 第2层查出婚恋诈骗案底与假孕检单报警赶往租屋 → 第3层租屋仅剩当日出境回执（已把弟弟骗去境外抵债） |

### 揭露节奏：按真相有几层定

- **只有一层真相**：一节内揭完，证据、反应和后果都落在本节，不拖到下节。
- **多层真相**：用延迟剥洋葱，每层占一节并在本节揭完。
- 题材包写了揭露方式时按题材包。常见对应：

| 题材包 | 常用方式 | 节奏 |
|------|----------|------|
| 追妻火葬场、世情打脸 | 偷听/撞见、证物 | 一次砸下，砸完就是心死或反击的起点 |
| 宅斗宫斗、复仇打脸 | 偷听/撞见；当众翻案用证人 + 证物 | 心死靠偷听一次砸下；翻案时先让证人铺垫，再用证物一锤定案 |
| 总裁豪门 | 物证慢推，最后偷听或物证齐全 | 物证逐件出现，分几节坐实；真相齐全的那一节一次心死 |
| 甜宠、双男主 | 证物（马甲、本子、未送出的信） | 一次揭开，揭开后转成糖或关系兑现 |
| 悬疑 | 延迟剥洋葱、证人 | 一层一节，最后一块拼图可以留给读者自己拼 |
| 民俗怪谈 | 延迟剥洋葱 | 一层一节，最后一层落在人心 |

## 3. 反派报应设计

报应须与恶行对等反弹（2-3 句交代清楚因果结果即可，不拉长描写）：

### 对应原则

| 恶行 | 报应 | 对应逻辑 |
|------|------|----------|
| 逼死在冷宫 | 自己住进冷宫 | 因果轮回 |
| 偷拿存折 | 账户被冻结，一分拿不到 | 偷失去的，连自己的也失去 |
| 以爱为名操控 | 被所有人抛弃 | 假爱真控，最终无人可控 |
| 诈骗钱财 | 被更狠的人骗进园区 | 骗子被更高级骗子收割 |

### 4 种报应模式

- **法律制裁**（现代触法恶行）：报警、起诉、判决或追缴脏款，简短几句落定。
- **社会性死亡**（虚伪 / 操控型）：当众公开录音流水，让其身败名裂、众叛亲离。
- **因果轮回**（古言 / 复仇 / 设局）：施加给主角的手段原样落回自己身上。
- **精神崩溃**（虐心 / 追悔向）：反派机关算尽得到一切，却永远失去唯一真心待他的人。
