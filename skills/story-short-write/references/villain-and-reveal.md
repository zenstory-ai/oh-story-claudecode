# 反派设计与真相揭露

> 谁读：构思时有反派或真相揭露，主会话整份读；写正文不读，按 设定.md 写。

---

## 1. 反派设计模板

### 人设模板

填写以下模板，写进 设定.md「构思要点」，替换“反派：没有”那一行（一字段一行）：

```
反派：
- 身份：{与主角的关系}
- 动机：{自洽的作恶逻辑：贪婪/嫉妒/控制欲/报复/自保}
- 作恶方式：{具体手段：言语打压/经济控制/社交孤立/人身伤害/法律构陷}
- 致命弱点：{可被主角利用的弱点：贪婪/傲慢/秘密/依赖/恐惧}
- 报应：{与恶行对应的结局}
```

### 嚣张度递增阶梯

按前因与损失加重反派行为，避免重复同一种恶行：

| 级别 | 行为类型 | 示例 |
|------|----------|------|
| 小恶（开局） | 言语打压、冷暴力 | 「你嫁进来就算烧高香了」 |
| 中恶（中段） | 经济/社交伤害 | 偷拿存折、在外败坏名声、挑拨关系 |
| 大恶（后段） | 人身/法律伤害 | 下药、构陷、逼死、拐卖 |

### 5 种反派类型速查

| 类型 | 特征 | 常见作恶方式 | 致命弱点 |
|------|------|--------------|----------|
| 操控型 | 以关爱或规矩控制一切 | 继后表面送汤药，实则长年下慢毒逼死先皇后 | 经年作案必留物证或经手人 |
| 贪婪型 | 得寸进尺、无底线索取 | 准儿媳进门掏本子打分，扣一分加一万彩礼 | 被对方用同一套规则反扣 |
| 伪装型 | 靠假身份或假怀孕设局 | 假装怀孕骗弟弟掏空家底的诈骗女友 | 假证明经不起当面核验 |
| 嚣张型 | 仗着得势有恃无恐 | 以为兄长是无权质子、当众拿其幼子取乐的新太子 | 不知主角握底牌，踢到铁板 |
| 软刀型 | 装软弱博同情、暗中吸血 | 表面受大女儿欺负、实则拿五十块假金锁哄二女儿挣钱的妈 | 私下算计被主角在病床前听见 |

## 2. 真相揭露机制

### 4 种揭露方式

#### 证物揭露

物理证据一锤定音。

操作：在铺垫段埋入「看似无关紧要的物件/文件」，揭露时翻转其意义。

```
铺垫：妈总戴着姐姐送的"两万块金镯"四处炫耀
揭露：搭扣断了去金店焊，火枪一烧发黑，锉开是黄铜胎
暴击：妈宝贵了三年，洗澡都不摘
```

#### 证人揭露

第三方视角打破谎言。

操作：安排一个边缘角色（仆人/邻居/同事），在关键时刻说出主角不知道的信息。

```
铺垫：先皇后旧婢周嬷嬷总欲言又止
揭露：周嬷嬷临终交出先皇后血书，写明继后长年下慢毒
暴击：继后早知血书外流，一直在搜捕周嬷嬷灭口
```

#### 偷听/撞见

主角获取隐藏信息。

操作：设计一个「主角不该在场的场景」，让主角无意中看到/听到真相。

```
铺垫：拆迁款到账那天，妈接电话总往阳台躲
揭露：收衣服时听见妈对姐说「共八十万，跟她只报三十万，余下明早给你交首付」
暴击：电话那头是姐姐
```

#### 延迟剥洋葱（设定.md 里写「一层层揭开」）

一层真相引出更深真相。

操作：每层占一节，每层比上一层更残酷；下一层揭开前，人物先按上一层的答案做出行动。

```
第1层：查出准弟媳的律所工牌是假的 → 拦下彩礼转账，逼弟弟当面核对
第2层：查出她有婚恋诈骗案底、孕检单也是买的 → 立刻报警并赶去弟弟租屋
第3层：租屋已空，桌上只剩当日出境回执 → 她图的不止彩礼，已把弟弟骗去境外抵债
```

### 揭露节奏：按真相有几层定

- **只有一层真相**：一节内揭完，证据、反应和后果都落在本节，不拖到下节。
- **多层真相**：用延迟剥洋葱，每层占一节并在本节揭完。
- 题材包写了揭露方式时按题材包。常见对应：

| 题材包 | 常用方式 | 节奏 |
|------|----------|------|
| 追妻火葬场、世情打脸 | 偷听/撞见、证物 | 一次砸下，砸完就是心死或反击的起点 |
| 宅斗宫斗、复仇打脸 | 偷听/撞见；当众翻案用证人 + 证物 | 心死靠偷听一次砸下；翻案时先让证人铺垫，再用证物一锤定案 |
| 总裁豪门 | 物证慢推，最后偷听或物证齐全 | 物证逐件出现，分几节坐实；真相齐全的那一节一次心死 |
| 甜宠、双男主 | 证物（马甲、本子、未送出的信） | 一次揭开，揭开后转成糖或关系兑现 |
| 悬疑 | 延迟剥洋葱、证人 | 一层一节，最后一块拼图可以留给读者自己拼 |
| 民俗怪谈 | 延迟剥洋葱 | 一层一节，最后一层落在人心 |

## 3. 反派报应设计

### 规则

报应须与恶行及其后果对应，让读者看清反派为何承担这一代价。

### 对应原则

| 恶行 | 报应 | 对应逻辑 |
|------|------|----------|
| 逼死在冷宫 | 自己住进冷宫 | 因果轮回 |
| 偷拿存折 | 账户被冻结，一分拿不到 | 偷失去的，连自己的也失去 |
| 以爱为名操控 | 被所有人抛弃 | 假爱真控，最终无人可控 |
| 诈骗钱财 | 被更狠的人骗进园区 | 骗子被更高级骗子收割 |

### 4 种报应模式

| 模式 | 适用场景 | 操作 |
|------|----------|------|
| 法律制裁 | 现代背景，恶行触犯法律 | 报警/起诉/判决，用简短几句交代 |
| 社会性死亡 | 虚伪型/操控型反派 | 真相公开，所有人看清真面目 |
| 因果轮回 | 古言/复仇题材 | 做过的事回到自己身上 |
| 精神崩溃 | 虐心/意难平题材 | 反派得到一切却发现失去了唯一重要的东西 |

### 报应强度校准

- 按恶行、受害后果与本篇情绪决定报应强度，避免轻轻放过或无因夸大
- 不写长段报应描写，2-3 句带过，留白给读者
- 报应的「爽」来自因果对应，不靠拉长描写
