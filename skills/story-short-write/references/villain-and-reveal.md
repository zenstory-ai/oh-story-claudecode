# 反派设计与真相揭露

> 谁读：构思时有反派或真相揭露，主会话整份读；写正文不读，按 设定.md 写。

> 反派设计模板、真相揭露方式、报应设计。

---

按题材决定反派的恶行与关系压力，再用以下模板记录身份、动机、手段、弱点与报应。

---

## 1. 反派设计模板

### 人设模板

填写以下模板，写进 设定.md「构思要点」，替换“反派：没有”那一行（一字段一行）：

```
反派：
- 身份：{与主角的关系}
- 动机：{自洽的作恶逻辑：贪婪/嫉妒/控制欲/报复/自保}
- 作恶方式：{具体手段：言语打压/经济控制/社交孤立/人身伤害/法律构陷}
- 致命弱点：{可被主角利用的弱点：贪婪/傲慢/秘密/依赖/恐惧}
- 报应：{与恶行对应的结局}
```

### 嚣张度递增阶梯

按前因与损失加重反派行为，避免重复同一种恶行；下表展示一种升级路径：

| 级别 | 行为类型 | 示例 |
|------|----------|------|
| 小恶（前 1/3） | 言语打压、冷暴力 | 「你嫁进来就算烧高香了」 |
| 中恶（中段） | 经济/社交伤害 | 偷拿存折、在外败坏名声、挑拨关系 |
| 大恶（后段） | 人身/法律伤害 | 下药、构陷、逼死、拐卖 |

### 5 种反派类型速查

| 类型 | 特征 | 代表作 | 致命弱点 |
|------|------|--------|----------|
| 操控型 | 以爱为名控制一切 | 王氏（《皇弟欺负幼子》） | 控制欲导致行事留下证据 |
| 贪婪型 | 无底线索取 | 准儿媳（《准儿媳打分》） | 贪心过度暴露真面目 |
| 伪装型 | 隐藏真实身份/目的 | 女友（《重生弟弟》中的诈骗犯） | 身份经不起调查 |
| 嚣张型 | 仗势欺人，有恃无恐 | 萧琅（《皇弟欺负幼子》） | 傲慢导致不看身后 |
| 软刀型 | 示弱博同情，暗中操控 | 妈妈（《姐夫捎路要奶粉钱》） | 假面被证据击碎 |

## 2. 真相揭露机制

### 4 种揭露方式

#### 证物揭露

物理证据一锤定音。

操作：在铺垫段埋入「看似无关紧要的物件/文件」，揭露时翻转其意义。

```
铺垫：妈妈脖子上总戴着一把金锁，说是姐姐送的
揭露：打开金锁，里面刻着「金包铜」三个字
暴击：她从来没打开过这把锁
```

#### 证人揭露

第三方视角打破谎言。

操作：安排一个边缘角色（仆人/邻居/同事），在关键时刻说出主角不知道的信息。

```
铺垫：周嬷嬷总是欲言又止
揭露：周嬷嬷临终前交给主角一封信——先皇后的供状
暴击：王氏知道这封信的存在，所以一直在找周嬷嬷
```

#### 偷听/撞见

主角获取隐藏信息。

操作：设计一个「主角不该在场的场景」，让主角无意中看到/听到真相。

```
铺垫：妈妈每次接电话都走到阳台上
揭露：主角路过阳台，听到妈妈说「那个金锁是假的，她到现在都不知道」
暴击：电话那头是姐夫
```

#### 延迟剥洋葱（设定.md 里写「一层层揭开」）

一层真相引出更深真相。

操作：每层占一节，每层都比上一层更残酷；下一层揭开前，人物要先按上一层的答案做出新行动。

```
第1层：弟弟的女友不是她说的那个人
第2层：女友是诈骗犯，有犯罪记录
第3层：怀孕是假的
第4层：弟弟已经被骗到电诈园区
```

### 揭露节奏：按真相有几层定

- **只有一层真相**：在一节内揭完。证据、人物反应和后果都落在这一节，不把半句真相拖到下一节。
- **真相有好几层**：用延迟剥洋葱，每层占一节，每一层也在它那一节内揭完。
- 题材包写了揭露方式时按题材包。常见对应：

| 题材包 | 常用方式 | 节奏 |
|------|----------|------|
| 追妻火葬场、世情打脸 | 偷听/撞见、证物 | 一次砸下，砸完就是心死或反击的起点 |
| 宅斗宫斗、复仇打脸 | 偷听/撞见；当众翻案用证人 + 证物 | 心死靠偷听一次砸下；翻案时先让证人铺垫，再用证物一锤定案 |
| 总裁豪门 | 物证慢推，最后偷听或物证齐全 | 物证逐件出现，分几节坐实；真相齐全的那一节一次心死 |
| 甜宠、双男主 | 证物（马甲、本子、未送出的信） | 一次揭开，揭开后转成糖或关系兑现 |
| 悬疑 | 延迟剥洋葱、证人 | 一层一节，最后一块拼图可以留给读者自己拼 |
| 民俗怪谈 | 延迟剥洋葱 | 一层一节，最后一层落在人心 |

## 3. 反派报应设计

### 规则

报应须与恶行及其后果对应，让读者看清反派为何承担这一代价。

### 对应原则

| 恶行 | 报应 | 对应逻辑 |
|------|------|----------|
| 逼死在冷宫 | 自己住进冷宫 | 因果轮回 |
| 偷拿存折 | 账户被冻结，一分拿不到 | 偷失去的，连自己的也失去 |
| 以爱为名操控 | 被所有人抛弃 | 假爱真控，最终无人可控 |
| 诈骗钱财 | 被更狠的人骗进园区 | 骗子被更高级骗子收割 |

### 4 种报应模式

| 模式 | 适用场景 | 操作 |
|------|----------|------|
| 法律制裁 | 现代背景，恶行触犯法律 | 报警/起诉/判决，用简短几句交代 |
| 社会性死亡 | 虚伪型/操控型反派 | 真相公开，所有人看清真面目 |
| 因果轮回 | 古言/复仇题材 | 做过的事回到自己身上 |
| 精神崩溃 | 虐心/意难平题材 | 反派得到一切却发现失去了唯一重要的东西 |

### 报应强度校准

- 按恶行、受害后果与本篇情绪决定报应强度，避免轻轻放过或无因夸大
- 不写长段报应描写，2-3 句带过，留白给读者
- 报应的「爽」来自对应感，不是来自描写长度
