# Phase 3：短篇逐场景写作

> 谁读：写正文时主会话整份读；构思、精修不读。

本文件中的 `scripts/` 与 `references/` 路径均相对本 skill 根目录。

**格式规范（最高优先级）**：正文只存 `正文.md`，主会话与写手同一套格式：段间只允许一个换行符、不留空行，小节标记与引号全篇统一，按 `设定.md`「平台基调」；没写时沿用 `正文.md` 已有的写法，还没有正文就用 `###1.` 与 `“…”`；子代理输出不一致时按此重排。

**构思完成检查**：写前先跑 `node {skill 根}/scripts/check-phase2-contract.js --json {短篇目录}`；未返回 exit 0 时，告诉作者设计还缺什么，请其回到构思补完。

**本时刻只靠落盘文件承接构思**：`设定.md`（核心框架、平台基调、这篇用的套路、情绪设计、文风约定、作者已定、反转与揭露、反复出现的物件、参考的书、构思要点；旧书叫「题材招式」「贯穿道具」「对标摘要」「Phase 2 设计校验」「反派与揭露方式」「反转铺垫」的，按旧名读）与 `小节大纲.md` 为 Phase 2 产出，`正文.md` 为本阶段产出。反转、反派、揭露、付费点与平台基调以两份设计文件为准，不重读构思方法论（workflow-design、short-reversal、submission-craft、villain-and-reveal、冷门题材公式全文）；作者在对话里改过、设计文件还没写的，先写回 `设定.md` 再动笔。

**导入的书**：`设定.md` 有「已写部分的写法」（旧书叫「本书续写基线」）时先读，用于保持已写内容连贯和写法一致；它不是参考的书，不参与对标，也不复制到 `对标/`。正文从第 N+1 节接着写，已写各节不改。

> 下文的五「段」指开头、铺垫、升级、反转、结尾等结构部分，各含若干数字编号的「小节」；场景内按情节节点安排动作与情绪变化。

**写前加载**：按 SKILL.md「写前必读」写正文一行读，题材包取 `设定.md`「构思要点」写的题材。冷门题材按「这篇用的套路」记下的参照结构写，腔调按 `short-craft.md`。去味到精修时再做，初稿先通过完成门槛的 AI 腔检测。

**交付参数先锁定**：用户明确的字数范围优先，严格采用其最小值/最大值与节数；只给单一目标时用目标的 95%-105%；都未给时用 `设定.md` 的目标字数和大纲节数。

**写前参数验收（锁定后、写 `正文.md` 前必跑）**：`node {skill 根}/scripts/check-delivery-contract.js --json --check-contract --min-chars {MIN} --max-chars {MAX} --sections {N} [--min-section-chars {用户逐节下限}] {短篇目录}`。exit 0 只说明参数能同时满足，不算交付；exit 2 即冲突，停在写前，用中文告诉用户字数范围与节数哪里对不上，请其选择调整项，不代改用户约束。

**写前准备**：每个场景动笔前必须完成两步：
1. **记忆+召回**：确认本场目标情绪；有对标时，从 `设定.md`「参考的书」召回 1-2 条与本场功能相关的写法（如开篇钩子、信息差投递、反转铺垫、对话推拉）。`设定.md` 摘要够用就不重读整套拆文；要细看时只查主要参考 `对标/{书}/写作手法.md` 或 `拆文库/{书}/` 对应条目；顺带参考的书只用构思时登记的那一两条，不读其文风和原文。
2. **指令确认**：将召回的技法融进写作指令，明确本场用什么技法、落在哪个位置；有任务卡点时，明确该任务带来的情绪变化或新证据。

**写作指令**：写法按 short-craft「情绪落地」「叙述姿态」与 scene-craft「场景写法」「疏密分配」，段落与标点按 short-format，不照搬大纲腔。情绪烈度按 `设定.md` 与题材包的腔调，没写时默认宁烈不温（冲突前置、爽点具体、台词带刺）；任务卡点必须直接加重羞辱、误会、背叛、证据、反击或心死节点，删掉无损就压缩。

#### 分批写与子代理

主会话默认按 2-3 节/批写正文，不要求单次 agent spawn 写完 8000+ 字。

- 要换对话、或上下文快满时，才在短篇目录下写 `.story/work/已写小节摘要.md`（3-5 条：已揭示信息、情绪位置、未回收伏笔、下一批衔接句），新对话靠它接上，交付后可删。
- 下一批先读 `正文.md` 尾部 300-500 字（有摘要时连摘要一起）再续写。
- 只有用户明确要求子代理、主会话上下文不足，或需要隔离试写时，才检查 narrative-writer agent（查找顺序见顶部），可用时按 [agent-calls.md](agent-calls.md)「写正文」派出。
- 无论谁写，写入 `正文.md` 前都按同一格式规范重排，保证主会话与子代理输出一致。

⚠️ **硬约束只作用于整篇交付范围，不设统一逐节最低字数或行数**。
写完每批后去掉 `--check-contract` 重跑上面命令，取其非空白字符数作整篇累计值（未写完 exit 1 属正常），各节分布按 `short-format.md`「字数统计」；不自写 Python 计数。某节偏短、节数和字数怎么算完成，按 SKILL.md「小节完整性流程」与「Phase 3 完成门槛」。
**⚠️ 字数没落进锁定范围就不算写完，不能越界交稿；字数不够只扩写已有情节点，超了只压缩重复解释，不能在修字数时加删关键剧情。**

按以下结构写作，占比仅参考，以小节大纲为准。无反转篇按设计写报应兑现或甜度递进；反转线索、误导与揭露要求仅用于有反转的篇目。反派与反复出现的物件仅在设计中选用时执行相应要求。各节情绪按 `设定.md`「情绪设计」的整体走向起落，不另设逐节递增。

#### 第一段：开头（前 300-500 字）

- **先写导语**：按 `设定.md`「平台基调」与 `小节大纲.md` 执行（旧项目未记时写 150-300 字；停在当下则第 1 节顺接，已写到结局/后果则第 1 节倒回讲经过）。开头密度与赌注按题材包「开篇范式」或 short-craft「开头事件密度」。
- **开头零环境规则**（默认适用；悬疑、惊悚、民俗怪谈、灾难等强氛围题材可例外，但环境须带威胁或异常）：
  - 前 3 句禁止无事件承载的环境描写（灯光、天气、气味、温度、装修）
  - 前 3 句必须是：事件、对话、动作、规矩或信息炸弹
  - 环境细节只能在后续句子中揉进动作和感知里带出，不能独立成句做铺垫
  - 任务卡点可以作为动作/事件钩子，但必须立刻带出赌注或矛盾，不能先写流程再解释意义
  - 检查方法：标出前 3 句的主语，如果主语是无事件承载的纯环境（灯光/走廊/房间/天气），重写；承载冲突的物件（如离婚协议、棺材、红灯）可用

| 开头技巧 | 说明 | 示例 |
|------|------|------|
| 冲突前置 | 第一句就是矛盾 | 「离婚协议放在桌上，他已经签了。」 |
| 信息差钩 | 给读者一个角色不知道的信息 | 「她不知道，对面那个男人已经在计划第三次了。」 |
| 反常行为 | 用一个不合常理的行为引起好奇 | 「她把订婚戒指冲进了马桶。」 |
| 重生反常 | 重生后做前世绝不会做的事 | 「再睁眼回到选亲这天，我把上一世争破头的太子婚约让给庶妹，转身指向角落里坐轮椅的病弱世子：我嫁他。」 |
| 超自然身份 | 开篇揭示非人类身份 | 「我是世上仅存的红衣厉鬼。我不知自己是怎么死的。」 |
| 灵魂旁观 | 以灵魂视角描述死亡现场 | 「我的尸体躺在透明棺材里，三个哥哥在外面笑着说：她演得真像。」 |
| 悬念句 | 抛出一个需要解释的事实 | 「我死后的第三天，老公发了一条朋友圈。」 |
| 替嫁被弃 | 被迫接受不公正的命运 | 「三个月后，我代替皇后的嫡亲公主坐上了去漠北和亲的轿撵。」 |
| 代入式提问 | 直接让读者产生共鸣 | 「你有没有在深夜接到过一个不该接的电话？」 |

#### 第二段：铺垫

- 用物件/数字/习惯建立羁绊（见 emotional-methods.md「羁绊铺设」）；有反转时把真相线索拆散藏进日常细节，无反转时铺垫因果或关系变化。
- 节尾按小节大纲「节尾停在哪」落地；反派作恶按阶梯递增（小恶→中恶）；**选用了反复出现的物件时，第一次出现必须在此段完成**。

#### 第三段：升级

- 冲突在强度、范围或代价上升级并服务主矛盾；插入倒计时或代价钩子，用具体数字/金额累加替代模糊描述。
- 按因果交替使用行动、对质、亮证据、受阻或关系抉择推进，避免连着几节同一种场面；有反转时埋入误导信息。

#### 第四段：反转

- 按 `设定.md`「反转与揭露」揭露真相（单层在一节内揭完，多层剥洋葱每层一节、最后一层落在本段），确保前文线索可回溯；**反复出现的物件第二次出现（意义被颠覆）在此段完成**。

#### 第五段：结尾

- 收在悬念或安静细节余韵上（见 short-craft「收尾」与 emotional-methods.md「余韵钝痛」），不写大段抒情；**反复出现的物件第三次出现（回扣暴击）**。

| 结尾类型 | 效果 | 适合情绪 |
|------|------|----------|
| 余韵式 | 不说完，让读者自己想 | 意难平 |
| 呼应式 | 首尾的物件、动作或话语形成呼应闭环 | 治愈、成长 |
| 开放式 | 留下悬念 | 细思极恐 |
| 反转再反转 | 结尾再来一个小反转 | 震惊 |
| 金句式 | 一句话点题 | 共鸣 |

写作中及进入精修前，执行 [SKILL.md](../SKILL.md) Phase 3 的「小节完整性流程」与「完成门槛」。
