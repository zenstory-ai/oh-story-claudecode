# 流派包：悬疑

> 适用平台：知乎盐言、黑岩、七猫、点众、番茄。涵盖两大分支：**现代悬疑/推理/家庭惊悚/直播逼供** + **民俗怪谈/规则怪谈（冥婚、纸人、头七、捞尸、行当禁忌）**。
> **核心权限声明：本包是 12 份流派包中【唯一】授权使用「公平推理线索埋设」「多层剥洋葱误导」「冷静克制报告体」与「细思极恐留白收尾」的流派！**

## 1. 读者爽点与核心人设标签

- **核心情绪账**：**「猜不到，但回头每条细节全对上」的智力快感 + 后背发凉的悚然体感**；现代惊悚可叠「直播逼供/当众拆穿凶手」的强爽感，民俗怪谈叠「破规矩者必遭报、守规矩者险死还生」的战栗爽感。
- **主角标签**：第一人称「我」（冷静查案的受害者家属 / 发现亲人变异的独居者 / 接阴人·扎纸匠·捞尸人·老仵作 / 凶手叙述者——只记动作不撒谎、尾节亮动机）。刑侦推理分支允许第三人称或双视角。
- **反派/异象标签**：① **笑面伪装真凶**（最亲近的配偶、热心邻居、陪你报警的闺蜜）；② **全员口径一致的合谋者**；③ **不信邪的破戒蠢人/恶亲戚**（在民俗分支负责以身试法验证规矩）。
- **声线**：**冷静报告体**（现代悬疑）或**乡土行话白描**（民俗怪谈：邪性、晦气、讲究、子时、头七、纸人点睛）。恐怖靠「平淡语气写极反常事件」的反差压出来，恐惧爆发只给短促一拍（「那一瞬间，我浑身血液冻住了」），立刻切回查证与自救！

## 2. 导语冷开场公式（150–300 字）

导语用「正常世界 + 一个不可能细节」或「铁规矩 + 当场实锤破戒」3 句钉死悬念：

1. **不可能细节炸弹式**：「丈夫失踪第三天，我在自家冰柜最底层翻出他的防水手表——表盘玻璃内侧，竟贴着一张裁成圆片的我昨晚熟睡小照。」
2. **全员否定/存在抹除式**：「除夕夜我提着年货敲开家门，对门邻居拉开一条门缝像见了鬼：『小姑娘，那套房你一个人住了三年，哪来的爸妈？』」
3. **民俗铁规矩+破戒实锤式**：「我干了十年捞尸人，行规是逆流漂上来的红鞋浮尸绝不下钩。可富商非要拿十万块逼我捞——刚解开麻绳，那具泡发三天的女尸自己站起来跑了。」

## 3. 节奏骨架与 30%–40% 付费卡点设计

- **第 1 节（1,200–1,500 字，异常/规矩落地）**：把导语的异常或民俗规矩演成现场，给出第一个看似合理的解释（或首个破戒蠢人发出狂话），悄悄埋下第 1 处微物证（黑皮筋、裙摆起皱、镯痕、门锁记录）。
- **第 2 节（免费升级）**：第一个合理解释被新异常彻底击碎；民俗线首个破戒代价应验（尸象加重、死亡进度条爬升）；微物证继续露面，撒谎者露出微小破绽。
- **第 3–4 节（30%–40% 付费卡点）**：主角陷入「全员否定」至暗点或帮手突然反水（守村老道反锁院门/热心闺蜜锁死铁门），**给出一个看似能自圆其说的「假底」结论**（自杀/意外/闹鬼/主角疯了）——**付费点卡在**：一件不起眼的微物证突然推翻假底，或血字/监控/电话录音里传来那个绝不可能出现的声音！
- **第 5–7 节（40%–85% 剥洋葱真反转与生死博弈）**：每节剥开一层更残酷的真相（现代线：证词对质、直播/审讯室当面逼供、时间线重排；民俗线：翻出上辈族谱旧账「人比鬼狠」、卡子时/天亮前生死破局）。
- **第 8–9 节（85%–100% 回溯摊牌 / 细思极恐留白收尾）**：逐条收回前文所有微物证，拼出完整作案链或阴间账本；收尾二选一——彻底法办/规矩清算，或留一句细思极恐的画面留白。

## 4. 专属公平推理、误导与怪谈招式

1. **公平性铁律（本包专属）**：反转依赖的每一件证据，摊牌前必须在正文露过面，且**关键词原样复现**（加粗黑皮筋/左腕镯痕，禁止同义替换），**严禁旁白撒谎骗读者**；误导靠「真实动作 + 视角偏见误读」完成。
2. **双层剥洋葱反转**：先给一个能暂时结案的「阶段答案 B」，让主角按 B 采取真实行动，再揭出同时解释 A 与 B 的深层真相 C（如以为妹妹自杀，实为姐姐杀妹顶替身份，却因忘掉妹妹洁癖习惯露馅）。
3. **规矩三段式 + 死亡进度条（民俗分支）**：开头借行家嘴明说禁忌（原话在告诫、破戒、应验时重复三次制造仪式感），恶人破戒后代价可视化爬升（尸斑每时辰长一寸、眼缝从一条线撑到能塞筷子），恶人遭报写足悚然与痛快。
4. **邪祟家常话 + 恐怖复沓**：邪祟开口越客气家常越瘆人（「二叔，奶奶问她陪葬的金镯戴着沉不沉？」）；血字或录音允许复沓（「救救我放我出去救救我放我出去」）。
5. **直播/审讯室当众拆穿（现代爽感悬疑）**：把收集好的微物证与时间线差在审讯室或全网直播间一条条甩出来，把伪善凶手逼到当场破防认罪。

## 5. 清算收尾模板

- **回溯摊牌法办**：凶手在铁证面前彻底崩溃伏法，前文埋的 3 处伏笔全部咔哒合拢，智力爽感拉满。
- **细思极恐留白（本包独享权限）**：不替读者说破，收在一个毛骨悚然的画面——「收留我的热心大姐转身锁死铁门，轻轻哼起了死者求救录音里那首童谣。」
- **债清物留/循环闭合（民俗/循环线）**：事了人走，但点过睛的纸人仍面朝村口站着；或病床醒来，手臂上又多出一道新的「正」字刻痕。

## 6. 原创真网感示范切片

### 切片一：导语 + 现代悬疑不可能细节（~220字）

丈夫失踪第七天，警察说他在跨江大桥跳河自杀了，只捞上来一只旧皮鞋。
我不信，因为他从小恐高，连二楼阳台都不敢靠近。
当晚我翻遍书房，没找到遗书，却在冰柜最底层摸到他常戴的那块防水机械表。
我擦掉表盘上的霜，整个人瞬间头皮发麻——
表盘玻璃内侧，竟然贴着一张裁成圆片的薄相纸。
照片上，是我昨晚熟睡在卧室床上的侧脸。
拍摄角度，正对着我们家从来打不开的那扇衣柜门缝。
下一秒，卧室方向突然传来「咔哒」一声轻响。
衣柜门，开了。

### 切片二：民俗怪谈立规矩 + 破戒惊悚（~225字）

我爷爷是十里八乡出了名的扎纸匠，临终前死死攥着我手立下铁规矩：
「给死人扎纸马纸人，万万不能用真朱砂点睛，一旦点睛，它第一眼瞧见谁，就拿谁当替身！」
我守了十年，直到今晚村首富二叔把五万块摔在我供桌上，满脸横肉冷笑：
「都什么年代了还信老黄历？我爹生前爱排场，今天这纸童子的眼珠你点也得点，不点我砸了你破铺子！」
我拦不住，眼睁睁看着他抢过朱砂笔，往纸人眼眶里狠狠点了两下。
纸人脸上那抹腮红，好像突然活了过来。
二叔得意大笑，转身刚迈出门槛，身后却响起一声脆生生的童音：
「二叔，你手腕上戴的，是老爷子陪葬那块金表吗？」

### 切片三：公平微物证回溯 + 细思极恐留白（~215字）

审讯室里，我把那张妹妹生前最后的画室照片推到「妹妹」面前。
「你说案发当晚你在画油画，可死者妹妹有重度洁癖，画画从不沾颜料，也从不穿皱巴巴的裙子。」
她下意识低头摸了摸起皱的裙摆，脸上完美的微笑第一次裂开了缝。
「更巧的是，走廊监控里拖走行李箱的人，习惯用左手刷门禁——你们全家，只有双胞胎姐姐是左撇子。」
她盯着我看了整整五秒，忽然歪过头，露出一抹令人毛骨悚然的笑。
「警察同志，你这么聪明，怎么没查查——是谁给姐姐寄的那把备用钥匙？」
我手里的笔猛地顿住。
门外玻璃窗上，我那位一直陪我查案的未婚夫，正隔着玻璃冲我温柔招手。

## 7. 流派专属禁区与雷区

- **禁机械降神 / 摊牌掏新证据**：悬疑反转绝对不许最后一节凭空冒出前面没提过的证人或密室机关，每一块拼图必须前文露过面。
- **禁自造玄学体系、符咒套符咒**：民俗怪谈只用大众秒懂的现成意象（头七、糯米、红烛、黄符、纸人点睛、子时鸡鸣），把重心放在「守规矩求生」与「人心比鬼狠」上。
- **禁成段哭诉宣泄**：本流派压低情绪成语与连环反问，用冷静短促的直白叙述托住恐怖和推理张力。
