# 题材风格包：悬疑 / 惊悚 / 细思极恐

> 七猫 / 黑岩 / 知乎盐言通俗短篇。先读 `short-craft.md` 底座，本包覆盖该题材调性；构思时全文悬念承接见 `hooks-chapter.md`，线索、误导与回收见 `short-reversal.md`，写正文按小节大纲执行。
> 一句话定位：**现代悬疑 / 侦探推理 / 惊悚 / 细思极恐。信息差驱动，层层揭底，结尾反转必须能回溯；细思极恐型收尾把最后一块拼图留给读者。** 读者要的是「猜不到，但回头全对上」的智力快感，加上后背发凉的体感。

---

## 叙述腔调

第一人称**冷静报告体**为主：叙述者用记流水账的平静口吻，陈述极不正常的事（分尸、循环、亲人被抹除），恐怖靠「语气与内容的反差」压出来；异常暴露时可短写恐惧，随即回到判断应对，不强配体感。与追妻 / 复仇的宣泄腔相反：全程克制，不哭诉、不控诉、不连环反问。

- 清理完现场后，我将带血的旧冰柜重新上锁封死；第二天打开地下室，封条完好，冰柜里却传出第二个人平稳的呼吸声。
- 保险起见，就当纸条上的警告全是真的，我必须按上面的规矩活过今晚。

**第三人称与多视角在本题材是允许的例外**：侦探推理型可用第三人称跟警探走办案程序，或第一人称业余侦探与第三人称现场交替。

叙述者**可以隐瞒，不可以说谎**：第一人称凶手 / 共谋叙述者如实记录自己做了什么，把动机留到揭底时再交代（如「我」全程陪闺蜜查案，动机捂到最后一节才亮牌）。

## 开篇范式

导语用「正常世界 + 一个不可能细节」迅速立住悬念；第 1 节直接进异常，背景随查证补入。

| 开篇式 | 范例 |
|--------|------|
| 冷静自白+不可能细节 | 丈夫失踪第三天，我在自家冷柜最底层翻出了他的防水手表——表盘玻璃内侧，却贴着一张我昨晚熟睡时的自拍。 |
| 民俗规矩卡+轮到我 | 村里有个古怪的习俗：被洞神选中的年轻女子会不吃不喝直至死去，死后面容安详。我原本是不信的，直到我的阿姐被选为今年的「洞女」。 |
| 身上的自我留言 | 醒来撸起长袖，我看见自己的右手臂上用圆珠笔刻着密密麻麻的一行字；在这行字的下面，歪歪扭扭地划了三个「正」字。 |
| 亲人一夜变异 | 高烧退去后，六岁的妹妹冲我们弯起嘴角笑了一下，我们却听得浑身发寒——她说话的语气和眼神，根本不像是六岁的小姑娘。 |
| 存在被抹除 | 除夕夜我提着年货敲开家门，对门邻居拉开一条门缝，表情像见了鬼：「小姑娘，那套房你一个人住了三年了，哪来的爸妈？」 |
| 死亡通知反转句 | 「你丈夫呢？他今天没在家吗？」「警官，死在客房里的那个人就是他。」 |
| 挑衅读者前瞻钩 | 正文第一句：你以为自己看到的证词就是真相吗？ |

## 钩子母题与密度

密度看信息有没有持续变化：新异常、新证据、证词矛盾、旧线索翻出新意思，或是查证碰壁，都能往前推；连着几节都没改变读者对真相的判断时，再排查是不是停滞了。钩子来自「已知与未知的落差」不断扩大或转向。

- **不可能细节**：正常场景里一个可验证、无法解释的小事实（多出的尸块、太新的手机），比大场面吓人。
- **全员口径一致的否定**：亲人、邻居、警察统一说你疯了，越整齐越让读者怀疑有人组织。
- **规矩三条，必破一条**：民俗 / 规则怪谈型先立规矩，让读者从立规矩那刻起等哪条会破。
- **微物证与知情者微反应**：轻描淡写埋下物证（裙子起皱、手腕镯痕、门把皮筋）与撒谎者被戳中时的小动作（下意识掏烟、突然挂电话），摊牌时逐一收回。
- **自我留言接力**：循环 / 失忆型给下一轮的自己留证据，且留言可能被篡改。
- **一句式前瞻钩**：「然而事实证明，有些事情确实拖不得。一拖，就出事了。」只预告有事，不说破。

## 情绪烈度与模式（烈度 6）

恐惧短促直写，情绪成语全篇最多一两处；主角越冷静越可怕。爆发只给一瞬，马上压回冷静分析。

- 恐惧多为一句直写（我不敢动 / 我怕了）；体感（头皮发麻 / 汗毛竖立 / 浑身血液冻住）全篇两三处，短促一拍，独立成段。
- 恐惧与理智交替：一拍之后立刻回到「我必须弄清楚」的分析态。
- 若写情绪崩溃，全篇至多一次，放在「全世界都否定我」的至暗点且哭完立刻捡起新线索；冷硬侦探或凶手视角可全程克制不崩溃。

范例：

- 那一瞬间，我浑身的血液都像冻住了。
- 看着妹妹一脸乖巧地说出这么冰冷的话，我顿时头皮发麻。
- 巨大的恐慌涌上来，我关掉客厅的灯退到门后，重新核对手机里的通话记录。

## 对话风格与金句

对白承担证词、试探、隐瞒和口径矛盾；调查、观察、核验和推理链可少或无对白，不设全文占比。四类高频台词：

**① 否定式对话（世界合谋否认）**
- 找你丈夫和儿子？可户籍档案上显示你一直未婚单身啊。
- 小姑娘，那套房你一个人住三年了，哪来的爸妈？

**② 试探与验证对话（一问一答暴露破绽）**
- （家人怀疑高烧后性情大变的妹妹被人调包，故意拿她五岁生日的积木试探）「这套积木还是你五岁生日那天，姐姐送给你的礼物呢。」「才不是，这套积木明明是爸爸给我买的。」
- （双胞胎姐姐杀害有重度洁癖的画家妹妹并顶替其身份，刑警故意指着她的裙摆试探）「你的裙子皱了。」（她只微笑着寒暄却不低头整理，暴露并非妹妹本人）

**③ 揭底摊牌对话（只收旧账）**
- （审讯室里将死者生前最后一张生活照推过去）「你说案发时你在外地出差，可这张照片背景的落地镜里，映出了你左腕那道烫伤疤。」
- 「从头到尾在背后引导我查案的人，原来是你！」

**④ 凶手 / 怪物的平静狠话（价值观翻脸）**
- 爸爸妈妈对花生严重过敏，只要他们永远睡过去，就没有人逼我背琴谱当神童了。
- 你们是真的蠢到相信这世上有洞神杀人？
- 这不是我想要的结果，是她自己非要查下去的。

## 招式库

| 招式 | 怎么用 | 示例 |
|------|--------|------|
| 不可能细节炸弹 | 正常场景放一个可验证、无法解释的小事实 | 独居公寓的智能门锁显示整晚无人进出，次日清晨玄关地垫上却多出一双带河泥的湿脚印 |
| 微物证伏笔 | 关键物证提前轻描淡写露面，摊牌收回 | 第 1 节顺口提到挂在卧室门把手上的加粗黑皮筋，末节揭底「我弯腰取下死者腕上的加粗黑皮筋，轻轻带上了门」 |
| 假底翻真底 | 先给能自圆其说的假结论，再用微物证掀翻 | 现场密室与遗书让全队认定是「作家姐姐畏罪自杀」，次日幸存的「画家妹妹」突然宣布因手伤永久封笔，暴露真凶其实是不会画画、杀妹顶替身份的姐姐 |
| 全员否定阵 | 亲近者统一口径否认主角记忆 | 旅游回来后丈夫和儿子人间蒸发，母亲、婆婆和物业却异口同声说「你一直单身独居」 |
| 规矩三条必破一 | 立规矩即立倒计时，破哪条读者猜不到 | 替嫁避祸的喜棺封钉前，祖母塞给我一张字条：「子时前棺材万一开了，无论如何也不要出棺！」下一节棺外却传来弟弟拼命砸棺的哭喊：「姐快出来！棺材里点的是迷魂香，不打开你才会没命！」 |
| 自我留言接力 | 循环 / 失忆下给自己留证据并防篡改 | 手臂上刻着「正」字，衣兜纸条写着：「有人在篡改我的记忆，不要相信任何人，包括录音里的我自己！」 |
| 身份调包 | 双胞胎 / 顶替换命，靠改不掉的身体习惯露馅 | 审讯室递白纸测出嫌疑人是左撇子，而走廊监控里假扮外卖员潜回行凶的人，左腕同样留着常年戴玉镯的浅白压痕 |
| 知情者微反应 | 撒谎者的小动作当路标，不点破先攒着 | 问起为什么认识疗养院院长时，平时只有说谎心虚才摸打火机的父亲在饭桌上筷子一顿，左手下意识伸向裤兜 |
| 民俗表象人祸底 | 神怪现象一路加码，揭底全是人的算计 | 所谓「洞神选女」其实是村长勾结外人拐卖年轻女子的遮羞布，祠堂里的异香则是让人产生幻觉的迷药花粉 |
| 凶手叙述者 | 第一人称只记录动作不写动机，尾节亮牌 | 「我」全程热心陪闺蜜报案、梳理死者社会关系，最后一节才揭晓「我」正是为了替妹妹报仇而设局的真凶 |
| 反常安抚句 | 所有人劝同一句话，这句话本身成为线索 | 父母、心理医生、片警全都用一模一样的句式劝我：「听话，早点放下你妹妹的事吧。」 |

## 节奏骨架

```
导语（正常世界 + 一个不可能细节）
→ 第 1-2 节 异常落地，给出第一个「合理解释」
→ 合理解释被新异常打破（至少两轮）
→ 中段让查证、反常与旧线索改义交替前推；完整调查链可连续展开
→ 至暗点（全世界否定我 / 调查被断）
→ 假底：能自圆其说的结论（自杀 / 意外 / 我疯了）
→ 微物证触发真反转
→ 摊牌回溯：前文伏笔逐一收回
→ 收尾（回溯型 / 留白型二选一）
```

疏密：取得新证据、改变判断的查证过程展开写，重复流程可一句带过（「警方的调查效率很高」）；异常暴露与摊牌处慢放。有明确时限时，用寅时、验货日、零点钟声推进倒计时。

**回溯是硬约束**：反转依赖的每个证据，摊牌前必须在正文露过面；摊牌只准收旧账，不准掏读者没见过的新证据。

## 收尾范式

- **回溯型摊牌**：揭底后逐条对应前文微物证。例：审讯室里将前文顺口提过的反常门锁记录、外套袖口的颜料渍与通话时间差逐一摊开，拼出完整作案链。
- **细思极恐留白**：不写完整解释，用一个动作或一句话把最后一块拼图留给读者。例：结尾不点破真凶，只写收留我的热心大姐转身锁死铁门，哼起了死者在求救录音里听见的那首童谣。
- **循环闭合**：结尾回到开头画面，多一个记号，暗示又一轮开始（如再次在病床上睁眼，看见手臂上多了一道新的「正」字刻痕）。
- **惨胜收尾**：真相大白但主角付出实际代价，不写全员圆满（如拐卖团伙伏法，但主角为取证身受重伤、同伴入狱）。
- **番外余波**：主线收束后加半页，暗示恶未除尽（如祠堂被查封后，几百里外的深山村落又响起了同样的请神山歌）。

## 该题材专属调校（与通用去 AI 规则的偏差）

这些在别的语境是 AI 味，在本题材是卖点，**别误删**：

- **冷静报告体的平白陈述**：叙述异常事件时语气不起波澜，用连贯句子平铺直叙；保留克制的腔调，避免堆修辞或断成电报体。
- **关键词原样复现**：微物证的叫法（加粗皮筋 / 划痕 / 裙子皱了）每次出现用同一个词，禁止同义替换，否则读者回溯不起来。
- **恐怖复沓**：血字重复、咒语式排比（「救救我放我出去救救我放我出去」「我不服！！我就是不服！！」）是体裁内故意重复，别当冗余删。
- **节尾自问句**：「被我锁进冷柜的，到底是谁？」保留，这是信息差钩子；只删不制造信息差也不推进的空转设问。
- **一句式前瞻钩**：「一拖，就出事了」可用；只许预告有事，不许说破是什么事。

反向要求（与追妻等情感题材相反）：

- 情绪成语（心如死灰 / 泪如雨下）本题材用得少，但不是禁用词。
- 成段宣泄独白和连环反问压到最低，用理智分析型独白替代（通用套话见 `short-craft.md`，标点见 `short-format.md`）。

## 配套结构公式（按篇幅选）

> 悬疑钩子密度、超自然真假按下列分型选择；`genre-writing-formulas.md` 公式七是异能或规则反杀的 12-18 节结构，不套给下列推理 / 惊悚分型。

- **现代悬疑标准型（8-12 节）**：1 节不可能细节落地 → 2-3 节两轮「合理解释被打破」 → 4-6 节查证与新信息差交替，至暗点收在全员否定 → 7-8 节假底成立 → 微物证触发真反转 → 末节摊牌回溯。第一人称冷静报告体。
- **细思极恐短打型（5-8 节）**：异常 → 试探验证并留实物证据（口红写字 / 录音 / 刻字） → 半揭底 → 结尾不摊牌，一个动作留最后拼图。全篇不判定超自然真假。
- **侦探推理型（8-12 节）**：案发与现场微物证清单 → 证词矛盾 → 假结论（自杀 / 意外） → 一个小破绽触发重查 → 审讯摊牌逐条收证。允许第三人称 / 多视角；守公平性，读者能看到侦探看到的一切。
- **民俗悬疑型（8-12 节）**：民俗规矩卡 → 轮到我或我的亲人 → 神怪表象层层加码 → 人祸真相 → 惨胜加番外余波。神怪氛围可以留，作案手法必须落地（致幻花粉、买通、装神）。
