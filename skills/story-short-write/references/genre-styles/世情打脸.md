# 题材风格包：世情打脸 / 家庭伦理因果报应

> 番茄 / 七猫 / 黑岩通俗短篇。先读 `short-craft.md` 通用底座，本包在其上覆盖该题材专属调性。
> 一句话定位：**用草根第一人称写现实生活中的欺压与因果报应：婆媳、极品亲戚、吸血父母、白眼狼儿女、出轨枕边人、职场恶人，把恶意藏在一双鞋、一张车票、一句规矩里，累积到当众打脸、报应落地。** 读者要的是「我家那点糟心事被写出来了」的代入 +「恶人当众被戳穿、账一笔笔算清」的解气。
>
> 与「复仇打脸」的分工：复仇打脸卖极端作践 + 身份底牌碾压 + 反杀执行（恶意造黄谣、断肢、摄政王、判官）；本包卖**日常之恶的累积与当众清算**，恶小而密，打脸靠证据、账本、法律、舆论落地，主角以老实人草根为主，隐藏身份只用于文末变体。与「追妻火葬场」的分工：追妻重在被珍视感剥夺；本包重在付出被吸血、好心被践踏，恶人可来自亲人 / 姻亲 / 枕边人 / 同事。

## 叙述腔调

第一人称「我」是儿媳、女儿、女婿、丈夫、嫂子、下属等日常角色。**中老年「我」是本题材的常见叙述者**：婆婆、丈母娘、奶奶、老母亲的自述，自带「一辈子付出被辜负」的重量。

用过日子的口吻，记账般交代金额、年限、物价和次数；多用冷幽默自嘲（「我差点气笑了」「就是觉得你们不去说相声，真是屈才了」）。声线从陪笑忍让，转到看清后的荒唐和心寒，最后平静地一笔笔算账。

主角必须是先忍后爆的老实人：前期真心付出有实据（帮还赌债、带娃三年、月月转账），爆发才有分量。

## 开篇范式

正文最前面放**结果倒序的导语**（接法和字数按 `设定.md`「平台基调」记下的导语写法）：日常之恶现场 + 帮凶站队 + 主角的反常反应或决裂动作预告。恶要具体到物件和金额，不写抽象的「他们对我不好」。

| 开篇式 | 范例 |
|--------|------|
| 日常小事即刀 | 我爸住院这天，我特意推了千万的合同赶来陪床。他看着我手里不小心削断的苹果皮，突然冷哼了一声：“其实你挺虚伪的。” |
| 规矩习俗当众打劫 | 结婚那天，我跪在地上给婆婆敬茶。她手上的改口费红包放在我手里拍完照，一秒后又抽了回去：“按老家规矩，这钱得先放妈这儿替你们攒着。” |
| 荒诞要求清单化 | 为了省钱补贴小叔子买房，婆婆立下家规：热水器每天只准开十分钟，空调超过三十八度才准开，多用一度电就要从我的嫁妆卡里扣五百块。 |
| 隔门 / 刷手机撞破真相 | 刷同城视频时，屏幕上一个叫“孝心小哥”的账号头像正是我儿子——视频里他哭诉我卷走家里存款不管瘫痪老伴，而他三分钟前刚从我这拿走三万块说去交进修费。 |
| 恶人自虐表演 + 帮凶动手 | 我不过拒绝把陪嫁房过户给小叔子，婆婆忽然“扑通”一声朝我跪下，抱住我的腿边哭边扇自己耳光；刚进门的丈夫问都不问，抬手就甩了我一巴掌。 |
| 决裂动作前置吊回看 | 婆婆把老家十几个亲戚塞进我刚装修好的婚房那天，我把签好的离婚协议挂在大门把手上，拖着行李箱直接住进酒店。次日清晨，我被丈夫兴师问罪的电话吵醒。 |

## 钩子母题与密度

让恶行按「小事试探、得寸进尺、踩到底线」持续递进；连着几节既没新恶行、新证据、新应对也没清算进展时，再检查是否停滞。**恶必须小而具体：钱数、物件、一句话，不用绑架灭门。**

- **规矩 / 习俗 / 孝道武器化**（头号母题）：改口费、见面礼、跪着吃饭、坐月子规矩、断亲费，把打劫包装成传统。例：「一百万上车礼寓意着我妈长命百岁，这是我们村的习俗，你不会看不起农村人吧？」
- **「一家人」道德绑架三件套**：孝道、面子、一家人。恶人话术永远理直气壮带糖衣，帮凶跟着和稀泥。例：「行了，先忍忍吧，他们就是嘴毒了点，人还是好的。」
- **偏心对照组**：同一件东西两种待遇，一格画面写尽不公。例：我女儿穿表姐退下来的旧运动鞋，鞋底磨平了还在穿；丈夫给白月光的女儿在商场买裙子，「除了这几件，当季新款全都包起来」。
- **生活账本堆叠**：手术费五万、菜钱三万二、尾款8999、车费两百，金额本身就是钩子，也是后面清算的弹药。
- **日常渠道撞破真相**：门缝、朋友圈、抖音直播、监控、小号。例：帮女婿垫付完肇事赔偿的第二天，我刷短视频听见女儿连线法律博主：「怎么操作才能把责任全推给我妈名下，让我老公全身而退？」
- **恶人先告状 + 网暴反转**：恶人先把主角挂上网卖惨，舆论一边倒骂主角，主角甩证据后全网倒戈，形成两段反转。
- **长辈血包觉醒**：中老年「我」被儿女吸血（拿走存款、造谣、算计遗产），觉醒后改遗嘱、报警、断亲。例：儿子儿媳为了腾出我的老宅给孙子当学区房，找了个所谓大师指着我说：「家里老人住主卧越健康长寿，就越吸小辈的考运！」

## 情绪烈度与模式（烈度 7-8）

比追妻 / 复仇低半档：恶行单件看似都「不至于闹翻」，累积到临界才爆发，以憋屈带出**心寒和荒唐感**。

- 心寒时刻用「轻」写：疼是小的、钝的，杀伤力在于看清。例：我冒雨送去熬了一下午的暖胃汤，母亲当着表妹的面随手倒进洗碗池：“放凉了腥气，别占着保温桶。”看着水槽里冲走的汤渣，我忽然就觉得没什么意思。
- 荒唐感代替嚎啕：被气笑、想笑、觉得陌生。例：看着镜头前哭得一把鼻涕一把泪控诉我不慈的儿子，我忽然觉得眼前这个人陌生得可怕。
- 身份句定格：一句话给自己在这个家的位置盖章，独立成段。例：原来在这个家里，懂事就是原罪。／你们爱的不是我，是那个随叫随到的血包和不用密码的银行卡。
- 直给情绪词仍可用（心彻底凉透、心沉到谷底），但频率低于追妻；需要展开时偏向冷静盘算，不逐句配反应。
- 憋屈的物理感：例：除夕夜我忙活一桌子菜，上桌时连双属于我的碗筷都没有，我端着锅里仅剩的半碗残羹怔在厨房门口。

## 对话风格与金句

对白重点是把规矩话术、帮凶立场、证据和关系翻转落到场内；不设全文占比。四类高频台词：

**① 恶人理直气壮的日常之恶（钩子本体，恶话必须裹着为你好 / 规矩 / 一家人的糖衣）**
- 你懂事点，亲戚大老远来一趟不容易，主卧让给大伯哥，你今晚在阳台搭个行军床将就下。／听妈的，别那么矫情。
- 你推了工作来医院守着，不就是想让我们觉得亏欠你，好分我那套老房子吗？
- 咱们把头等舱退了换给表叔一家吧，你爸妈坐五十个小时硬座打打牌就过去了，老人家坐飞机耳膜受不了。
- 妈，视频剧本效果好就行，您看那条控诉您的视频现在多少播放量了，都破百万了，带货佣金分您成还不成吗？
- 我在楼下等你加完班顺路坐你的车回去，也算陪你熬夜了，这趟加班补贴你不该分我一半吗？

**② 帮凶和稀泥（本题材特有声部：家里人劝忍，比恶人本人更诛心）**
- 行了，咱们忍着点，怎么说也是长辈，传出去让人笑话。
- 闺女啊，你爸就是刀子嘴豆腐心，他骂你也是怕你骄傲。
- 妈，他已经知错了，您非要报警把他送进去，传出去我以后在婆家还怎么抬得起头啊？

**③ 主角冷账句（打脸金句，报数字、指规则，不骂街）**
- 酒店套房谁住的谁结账，地毯和红酒谁弄脏的谁赔偿。这八万块账单，我不付。
- 这车落地价八十万，原厂车漆补一块一万二。你甩过来的那两百块，连洗个轮毂都不够。
- 刚才交进住院部的那五万手术费，就当是我还清你们的生养之恩。
- 那是你爸留着做搭桥手术的救命钱，你没资格动。
- 他们是手断了还是腿瘸了，有手有脚的成年人还要朝我们伸手讨钱？

**④ 恶人内讧互咬（清算后必有，比主角骂十句都解气）**
- 婚礼现场录像放出来后，婆婆当场扑上去撕扯小叔子：「都怪你非要让我加码要那三十万改口费！就差一步她就签字陪嫁了！」
- 父亲偏心弟弟一辈子，把老宅过户给弟弟的第二天就被赶出家门，弟弟隔着防盗门冷笑：「正因为你是我老子，这套房才本来就该归我，至于养老，你找你那孝顺闺女去啊！」

隔壁床大叔、律师、网友等外人的声音可少量点缀，替读者说出「这不对」。

| 招式 | 怎么用 | 示例 |
|------|--------|------|

| 恶人内讧狗咬狗 | 利益断了，恶人阵营当众互撕 | 得知房产被收回还要背违约金，婆婆和小叔子在售楼处当众扭打在一起，互相指责是对方出了馊主意 |
| 荒诞对等回敬 | 用恶人的逻辑造一个对称的难堪 | 女上司非要蹭我的车去峰会，还嫌车里有味、只甩两百块打发人，我干脆花两百块叫了辆拉生鲜的货车送她到酒店正门 |

## 节奏骨架

```
导语（日常之恶现场 + 帮凶站队 + 决裂预告）
→ 第1节按导语停处顺接或倒回，补满恶行的对话与物件细节，帮凶合围
→ 心寒定格（身份句 / 荒唐感），不吵，开始蓄证
→ 恶行加码（要钱升级 / 挂网卖惨 / 道德绑架亲友团）
→ 摊牌清算（账本 / 录音 / 法律文书当众落地）
→ 舆论倒戈 + 恶人内讧
→ 报应清单 + 主角平淡新生活
```

打脸不必集中在一场：可把怼一句、算一笔等小反制分散在升级链里，大清算放到因果和证据汇合处。恶行现场和摊牌现场详写慢放，蓄证过程按新信息价值取舍；不为逐节配额另造恶行或反制。

## 收尾范式

- 报应清单：「听说体」逐个交代恶人下场，落到具体生计（送外卖、房被法拍、捡废品、进去了），不写主角施暴。
- 阶层对照定格：一个画面写两种人生，不说教。例：咖啡厅落地窗外，前夫正顶着烈日给路人发传单；我平静地收回视线，端起面前的咖啡抿了一口。
- 物件闭环：贯穿物件最后一次出现，完成告别。例：我把那串替婆家操持十年、磨得发亮的钥匙留在玄关鞋柜上，拉着行李箱反手带上了门。
- 不恨式放下：例：我不爱你了，也不恨你了，往后是死是活都与我无关。
- 平淡新生活：开小店、带爸妈定居、猫和阳光，日子本身就是打脸。例：断掉那群吸血亲戚的来往后，妈妈的气色肉眼可见地好了起来。

## 该题材专属调校（与通用去 AI 规则的偏差）

这些在别的语境是 AI 味，在本题材是卖点，**别误删**：

- **金额物价逐项精确**（两百块车费、8999 尾款、三十元一双袜子、五万手术费）：保留，这是真实感和清算爽感的底座，不是流水账。
- **恶人台词的理直气壮加糖衣**（为你好 / 规矩 / 一家人）：保留，越顺理成章越诛心；别改写成脸谱化叫骂，恶人自认有理才像身边人。
- **帮凶和稀泥声部**（「忍忍吧」「都是一家人」）：保留，憋屈感一半来自帮凶；别删成主角单挑恶人。
- **中老年「我」的回忆插叙**（拉扯儿子长大、捡垃圾供学的往事）：保留，是付出与辜负的对照弹药；控制在每次三五句。
- **「听说体」报应清单收尾**：保留，是本题材标配的因果闭环，不是烂尾。
- **主角冷幽默自嘲**（「我差点气笑了」「真是屈才了」）：保留，用荒唐感写心寒。

本题材额外要避免的两条：恶人恶得没有生活逻辑（上来就喊打喊杀，没有糖衣）；清算只靠主角开骂，没用证据和规则落地。通用套话见 `short-craft.md`，标点见 `short-format.md`。

## 配套结构公式（按篇幅选）

- **草根实证清算型（8-12 节，婆媳 / 亲戚 / 职场欺压）**：1-2 节日常之恶现场 + 帮凶合围 → 3 节心寒定格、开始蓄证（录音 / 记账 / 备份）→ 4-6 节恶行加码、恶人挂网卖惨 → 7-9 节摊牌：证据 + 法律文书当众落地、舆论倒戈 → 恶人内讧 → 报应清单 + 新生活。全篇用第一人称；恶要写得细碎密集，清算走规则和证据，不靠对骂。
- **长辈觉醒断亲型（婆婆 / 丈母娘 / 老母亲「我」）**：儿女 / 儿媳的孝顺人设开场 → 日常渠道撞破真面目（短视频账号 / 直播连线 / 存折余额）→ 不动声色反制：存定期、改遗嘱、报警 → 儿女下跪打感情牌被拒 → 撕户口页 / 过户给真心人。回忆插叙撑付出与辜负的对照。
