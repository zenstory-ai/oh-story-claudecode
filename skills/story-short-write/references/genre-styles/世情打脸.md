# 短篇题材包：世情打脸

> 适用平台：七猫、点众、黑岩、知乎盐言。核心卖点：用同账对比把日常「糖衣小恶」（婆媳算计、重男轻女断亲、职场抢功、直播网暴）写到极实，再靠账本、录音、监控与法律文书剥皮清算；上知乎宜叠第一人称松弛吐槽或强法律反杀破红海内卷。

## 1. 故事线设计

- **核心情绪账**：不写空泛委屈，直接用「同一场景两笔明账」把双标压到极限，再凭实证与断供反杀，让吸血者狗咬狗互撕。
- **五段节奏与 35%–42% 付费卡点**：
  1. **第 1 节（1,300–1,600 字，当下现场直切）**：一顿饭、一笔菜钱、一张报销单或一台手术直接引爆双标不公，帮凶立刻和稀泥逼主角低头。
  2. **第 2 节（免费升级）**：同账对比拉满仇恨；主角经门缝、小号、后台日志或连线，撞破恶人私下盘算榨干自己的实话。
  3. **第 3–4 节（35%–42% 付费卡点）**：主角停止争辩、暗中存证/挂失副卡/公证断亲/留原始工程底稿；**付费点卡在**恶人把主角挂上网网暴、逼签过户或抢台汇报时，主角微笑点开云端监控、大屏投屏或律师函。
  4. **第 5–7 节（40%–85% 账本+舆论+法律连环清算）**：当众逐笔报账甩流水 → 舆论倒戈冲烂恶人账号与单位 → 断供撤回赠与、停付彩礼/医药费，恶人失去血包立刻内讧互撕。
  5. **第 8–9 节（85%–100% 清算收尾）**：二选一——① 痛快「听说体」报应清单 + 阶层对照（前夫被辞退与婆婆挤隔断间摔碗互骂、小叔子被催债跑路）；② 现实亲情线可选「克制边界 + 微光回甘」（绝不圣母原谅，护住底线与小店，收在母亲朋友圈一句「我女儿开的店」或一颗削好的苹果回旋镖）。

## 2. 常见剧情设计

- **导语冷开场（150–300 字）**：恶必须落到具体金额、同账对比、荒诞规矩或直播画面：
  1. **规矩打劫+同账对比**：「大年初一我挺着孕肚做完十二道菜，婆婆一把抽走我椅子塞给小叔子：『老家规矩，孕妇上主桌冲财神，端碗去灶台吃。』我笑了，这桌菜两千八是我刷的卡，这套房房产证写的也是我一个人的名。」
  2. **职场抢功/报销反杀**：「熬三个月通宵替公司拿下两百万盈利，发奖金那天经理却把我的名字划掉，塞进关系户：『年轻人重在历练，别计较这两万块。』我笑着交辞职信，顺手把客户回访录音发进大老板邮箱。」
  3. **直播卖惨/医疗反杀**：「刚给儿子转完三万手术费，转头就在同城直播间刷到他哭诉『亲妈卷走拆迁款不管老伴』，十万网友正骂我老不死——我点开连麦，把三年银行流水直接怼上屏幕。」
- **中后段核心打脸招式**：
  - **同账对比一秒建仇**：并排亮两笔账（弟弟八万金镯 vs 我磨平旧鞋；关系户拿五万奖金 vs 我倒贴两千交通费）。
  - **规矩回旋镖**：坐月子逼喝白粥称「太娇气折福」，婆婆住院点名喝鸡汤时原话奉还一碗清汤白粥。
  - **留底等自爆**：表面笑脸交接方案或病历，暗留带时间戳的原始文件、监控与签字记录，等对方在领导或记者面前演砸一锤钉死。
  - **微脑洞现实杠杆（知乎/七猫破同质化）**：给极品算计绑定单一荒诞回报（如每次遭背刺卡里自动到账五十万），主角笑眯眯拱火攒钱反杀。
- **剧情红线**：禁前 2–3 节写童年回忆流水账（旧账只用 1–2 句穿插对照）；导语立下的查账、投屏、报警必须现场演完，禁导语诈骗。

## 3. 人物设计

- **主角定位**：真付出过的老实儿媳、懂事大女儿、退休母亲、扛下大促反被踢出局的骨干打工人或冷静医生；撞破算计后果断止损，握着实打实的钱权筹码（房产证、流水、原稿、公证）冷笑收网。
- **反派梯队与自私反咬**：
  - **糖衣恶人**（婆婆/亲妈/经理）：掠夺总挂着「一家人」「老规矩」「锻炼年轻人」的体面算盘，利益受损绝不乖乖认栽，会立刻撒泼网暴、找亲戚施压或动用人脉反咬。
  - **和稀泥帮凶**（丈夫/亲爸/圣母亲戚）：一句「忍忍吧，都是一家人」既省自己力气又稳既得利益，必须写活其声部，禁为了省事砍掉。
  - **拱火吸血精**（妈宝小叔子/关系户/卖惨儿女）：一断供最先翻脸甩锅，触发狗咬狗内讧。
- **关系张力与口吻**：台词带足烟火气、市井算计与真实数字明细；全篇亲戚称呼、金额数字与人物姓氏严格前后统一。

## 4. 正文技巧

- **视角与平台适配**：默认第一人称「我」；七猫/点众/黑岩用 `“”`、冲突标题与首节导语接 `……`，知乎用 `「」`、短标题与紧凑切段；中段清算可短切恶人尴尬反应拍子，但主镜头稳锁主角。
- **叙事节奏与对话**：核心对峙直进引号短打，禁满篇摘要转述，亦禁单口 70–90 字诉状演讲台词（拆成抢话短刺）；保留自然口语的因果粘连与心里盘算，禁机械四连短句碎切。
- **物件为刀**：只抓直接扎进账本与礼法的硬物件（账单、存单、房产证、原始底稿、监控截图），绝不堆砌无关穿搭、家具材质或灯光贴纸。

### 避坑对照（烂写法 → 高分改写法）

- ❌ 烂写法：「我从小到大都受尽了爸妈偏心，十岁那年……十五岁那年……他们对我一点也不好，我心里彻底凉透了。」（前几节回忆流水账 + 空泛怨气，拖死开局）
- ✅ 高分改写法：「大年初一饭桌刚摆齐，高明把微信收款码拍在转盘上：『姐，我订婚差十八万，你先转过来。』他腕上四万金表晃得人眼花，我把房产抵押通知书滑到他手边：『巧了，下周一收房，这桌菜钱你先结吧。』」（当下现场同账对比，一秒立仇并亮反击）

## 5. 案例片段

### 切片一：婚宴坐地起价：2688涨8888当场反掀桌（293字）

半年前就定好的婚宴，五一前一周，酒店经理突然坐地起价。
“沈小姐，酒店五一临时调价，你定的2688婚宴酒席要涨价到8888。”
我脸色变了：“钱经理，我二月就交了定金，合同草案双方都签字了，你现在要翻三倍？！”
“你懂不懂法啊？草案又不是正式合同，正式合同价是8888。”
我压下脾气：“钱经理，这个价格我接受不了，能不能谈谈？”
钱经理笑了一下：“没钱结什么婚？”
“我们酒店五一爆满，一共定出去了八场婚宴。”
“万科的张总，儿子五一结婚都没位置，愿意出四十万包30桌我都没答应。”
“你不定，有的是人排着队抢！”
我冷笑一声，“行，那这婚宴我不定了。”
“对了，不止我不定了，另外那七场婚宴也不定了。”

- **学什么**：五一前涨三倍+嘲草案不算合同，经理自曝八场婚宴递把柄，末尾“另外那七场也不定了”一刀掀桌。

### 切片二：婆媳双标与和稀泥：六十六万三十年存单（202字）

结婚前，我妈当着婆婆面给我一张卡：“六十六万，给两个孩子过日子。”
婆婆笑得合不拢嘴，当场许诺：“我们出同等彩礼！”
婚礼当晚，婆婆塞给我一个密码箱，说：“现金不安全，这是等额存单。”
户名是老公和她两人的名字，存期三十年，提前支取需双人签字。
面对我的质问，她一脸无辜：“我是怕你年轻乱花钱，先帮你存着，等我老了以后还不是留给你们的？”
老公也和稀泥，“我妈也是为我们好，她养大我不容易，你多体谅体谅她老人家。”

- **学什么**：娘家六十六万现卡撞三十年双签存单，再补老公和稀泥帮凶声部，血压瞬间拉满。
