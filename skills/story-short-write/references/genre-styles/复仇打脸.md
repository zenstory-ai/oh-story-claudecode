# 题材风格包：复仇打脸 / 爽文逆袭

> 番茄 / 七猫 / 黑岩通俗短篇。先读 `short-craft.md` 通用底座，本包在其上覆盖该题材专属调性。
> 一句话定位：**主角被至亲 / 枕边人极端作践（恶意造黄谣、开盒社死、碾压断手、判死刑），靠藏着的身份底牌或重生 / 死遁 / 判官设定翻盘，当众撕穿、回旋镖反杀、让对方亲口认栽。** 读者要的是「作践有多狠，碾压就有多爽」+「身份揭晓那一刻的颅内高潮」。

与「追妻火葬场」的分工：追妻卖**被珍视感的剥夺 + 心死离场**，男人事后追悔；本包卖**主动复仇 + 当众打脸 + 身份碾压**，重点写反杀过程，让加害者当场社死、自食恶果。

---

## 叙述腔调

第一人称「我」全程主导，声线随受害与反杀切换：前段受作践时直白宣泄（疼、恶心、心沉到谷底），撞破后立刻切冷，**心死之后就亮底牌、动手、看对方表情**。用「我就看着他们咎由自取」式剧透和「我真的很期待他们脸上的表情」式快意预告勾追读。

男频自救文（舔狗 / 被女总裁害的副总 / 被竹马算计的男主）也吃这套，用男「我」，腔调更冷更狠。穿书 / 系统设定的篇目用**弹幕插入**当外部审判声。

## 开篇范式

正文最前面先放**结果倒序的导语**：把作践全貌 + 反杀手段 + 身份底牌 / 重生节点一次性剧透，专卖追读；第 1 节按导语停在哪里顺接或倒回，补满作践现场的对话体感和心死，导语字数按 `设定.md`「平台基调」。

| 开篇式 | 范例 |
|--------|------|
| 社死现场即炸弹 | 未婚夫为了帮假妹妹拿下首席设计师的位置，在庆功宴大屏幕上公放我十年前做心理创伤治疗的保密录像，污蔑我精神失常、作品全是抄袭。 |
| 身份底牌反差 | 他们不知道，当年那个被他们推出去替假千金顶罪的弃女，如今已经是手握西域兵权的摄政王。 |
| 极刑设定自陈 | 当右手的手套在庭审席上被我一点点取下时，露出来的是一截冷硬的义肢——三年前，正是我那位好丈夫亲手签下了截肢同意书。 |
| 重生 / 死遁回档 | 母亲为了骗取高额保险金给弟弟还赌债，趁我不备将我推下天台。再睁眼，我回到了她笑吟吟端着安眠药汤让我签投保单的那天。 |
| 判官 / 死人设定 | 被亲生父母一碗绝命汤送走后，我在阴司执掌生死簿，成了百年难遇的铁面判官。 |
| 男频自救反差 | 给拜金未婚妻当提款机的三年里，她为了竹马拿退婚威胁了我九十八次；第九十九次，我当场收回副卡，转头娶了暗恋我五年的死对头千金。 |

## 钩子母题与密度

密度极高：导语集中亮出作践事件与反杀预告，正文让作践升级、取证、决断和反杀一路往前推；连着几节处境都没动静时，再排查是不是停滞了。**阶梯式作践：道德羞辱 → 经济掠夺 → 极端虐心（碾压 / 断肢 / 判死刑）。**

- **门外偷听撞破真相**（头号导火索）：去找加害者时隔着门 / 隔着窗听见他和同伙的真心话，作践动机一次性砸下。例：站在包厢门外，我听见未婚夫对兄弟们冷笑：「先把她名声搞臭，等她被行业封杀，她手里的专利就只能乖乖转给晚晚。」
- **隐私曝光 / 当众社死**：把人的隐私武器化当众处刑，比如在庆功宴大屏幕上公放受害者的病历或伪造录音当众羞辱。
- **次数累积**：把作践 / 投入做成可计数的进度条，临界一节清零或反弹。99次表白、戏弄98次、替人顶包第9次。
- **身份底牌反差**：主角藏着碾压级身份（摄政王 / 监管负责人 / 首席律师 / 集团实控人 / 判官），最狼狈时亮出。例：恶邻擅自砸穿承重墙把我的婚房改成日租民宿，还叫嚣自己在消防和市监有人，我亮出巡查组组长工牌：「巧了，今天带队查违建的就是我。」
- **回旋镖反杀**：加害者的招式原样砸回他自己（伪造证据被反追刑责、行车记录仪 / 指纹反指认、假古董当众露馅）。
- **重生 / 死遁 / 假死前瞻**：重生线先交代前世死法与凶手，再回到关键节点，做「前世绝不会做的事」；死遁 / 假死线预告离场后的复仇。

## 情绪烈度与模式（烈度 9-10）

比追妻更生猛：作践有物理极刑档（碾压手 / 断肢 / 判死刑），所以宣泄要够痛，反杀要够冷。**两段声线，靠亮底牌 / 重生那一拍翻转。**

- 受作践段可以直接写浓烈情绪：心沉到谷底、万念俱灰；让羞辱与处境支撑，不固定叠身体反应。
- 心死转冷的快意预告：让读者知道主角已备好反杀，加害者仍不知情。
- 极刑反衬：写极痛时用一句冷到反常的句子收（「幸好我已经死了，感受不到痛了」），痛感与冷意对撞。

范例：

- 随着我被伪造的受贿账目被他扔在会议桌上，我的心也彻底沉到了谷底。
- 我紧紧抿着嘴唇，直到尝到血腥味，才勉强找回一丝清明。
- 我悲哀地笑出了声，笑着笑着，眼角渗出了泪。
- 看着被砸毁的琴房和废掉的右手，那一刻，我万念俱灰。
- 幸好我已经死了，再也感受不到那碗毒药烧穿五脏六腑的痛了。
- 笑吧，多笑会儿，过了今天，你们就再也笑不出来了。

## 对话风格与金句

对白在施害、审判和公开翻盘场景可以密，调查、取证和行动链可以少或没有；不设全文占比。口语、狠，关键句可独立成段。四类高频台词：

**① 施害者道德踩踏狠话（钩子本体，越理直气壮越好）**
- 现在全行业都知道她是个抄袭狗了，除了我肯收留她当枪手，谁还敢用她？
- 你从小在乡下长大没见过世面，替你妹妹去联姻吃点苦怎么了？
- 你一个替罪坐过牢的弃女，还敢大摇大摆走侯府的正门？你不要脸我们还要脸呢！
- 能给大小姐当垫脚石是你的福气，你该珍惜这个留在豪门的机会。

**② 白月光 / 反派娇弱软刀（装委屈倒打一耙）**
- 姐姐能平反回来就好，以前你误会我偷改数据的事，我从来都没怪过姐姐。
- 姐姐，我都把主创署名让给你了，你怎么还是这么容不下我？
- 看来姐姐还是嫌我碍眼，我这就递辞呈走人，再也不会出现在你们面前。

**③ 主角亮底牌 / 当众审判金句（截图传播的高光）**
- 这笔血债，咱们的账一笔一笔慢慢算。
- 当年你们为替她扫清障碍废掉我弹琴的右手，今天她抄袭败露被终身禁赛，这不叫报复，这叫物归原主。
- 你那套以德报怨的戏码，留着去感动你自己吧。
- 这么可笑的问题，就留给你进去跟法官慢慢解释吧。
- 你们刚才说认识总部的神秘投资人？巧了，刚签下撤资令的人就是我。

**④ 弹幕 / 外部审判声（穿书 / 系统篇）**
- 【给女主点赞，这波录音反杀太爽了，千万别心软原谅！】
- 【一家子吸血鬼还真把自己当盘菜了，坐等开庭！】

冲突靠对话长度反转标记权力易主：加害方前期长篇 PUA / 颐指气使，主角后期一句话冷怼定生死。

## 节奏骨架

```
导语（结果倒序 + 反杀手段 / 身份底牌 / 重生节点预告）
→ 第1节按导语停处顺接或倒回，补满作践现场的对话体感与社死
→ 门外偷听 / 撞破真相一次砸
→ 心死定格 + 反杀决意（亮底牌前瞻预告）
→ 逐节反击升级（回旋镖 / 次数清零 / 当众揭穿）
→ 身份底牌揭晓，全场表情逆转
→ 加害者社死 / 自食恶果 / 求饶被冷拒
```

让新信息与反杀沿因果链持续兑现；节尾可落在新信息、局部反杀、关系变化或明确的下一步，不要求每节同一种炸点。作践、亮牌、打脸处详写慢放，过场按新信息价值压缩。

## 收尾范式

- 当众打脸定格：身份揭晓那一刻全场鸦雀无声 / 加害者酒杯落地，主角一句冷话收。
- 自食恶果：加害者落得当初施加给主角的下场（入狱、社死、反被碾压），主角已无波澜。
- 漠视离场：把对方留在悔恨里，自己头也不回，漠视比报复更狠。
- 男视角反衬（追悔火葬场）：偶尔插一句加害者失去后的崩溃当余韵。

范例：我看着被法警带走的他微微一笑：「这么可笑的问题，就留给你进去慢慢思考吧。」／当庭宣判那一刻，他跪在被告席上嚎啕大哭，而我只是合上卷宗走出了法庭。

## 该题材专属调校（与通用去 AI 规则的偏差）

这些在别的语境是 AI 味，在本题材是卖点，**别误删**：

- **快意剧透 / 亮底牌前瞻预告**（「过了今天，你们就再也笑不出来了」「我真的很期待他们脸上的表情」）：保留，这是吊住读者期待的招牌写法，只删「泄了悬念又不勾人看」的随手全知剧透。
- **次数 / 金额 / 年限的逐项枚举**（第七次、第三十七次、第九十九次）：保留，这是递进式累积爽点，不是凑字排比。
- **弹幕 / 外部审判声**（穿书 / 系统篇）：保留，用外人的反应放大爽感。
- **极刑 / 社死场面的直写**（断肢、当众羞辱）：保留情绪烈度，不做文学化淡化；只呈现剧情后果，不细化可照做的伤害步骤。
- 情绪成语直写、审判金句收尾的保留边界，以及通用套话与标点要求见 `short-craft.md`。

## 配套结构公式（按篇幅 / 设定选）

- **现实社死复仇型（8-11 节，造谣污蔑 / 开盒 / 恶邻 / 白眼狼亲属）**：1-2 节社死作践（隐私武器化 + 门外偷听撞破动机）→ 3 节心死 + 亮底牌前瞻 → 4-6 节回旋镖反杀 / 物证翻盘 / 走法律 → 7-8 节身份揭晓当众打脸 → 加害者自食恶果。全篇用第一人称；社死要落到具体平台和物证上，反杀靠规则和证据碾压，不搞口头对骂。
- **重生 / 死遁 / 假死型**：重生线先交代前世死法与凶手（碾压、判死刑、被害流产），再回到关键节点，主动把利益推给反派；死遁 / 假死线以离场布局复仇。两者都在临界点亮底牌反杀，落到加害者悔疯。
- **身份底牌 / 古言女强型（摄政王 / 判官 / 律师）**：开篇即归来 + 受当众羞辱 → 隐忍蓄势、暗线铺底牌 → 反派步步加码作践 → 一招亮牌全场逆转 → 九族清算 / 加害者跪地。男频自救型（舔狗 / 副总 / 被竹马算计）同骨架，换男「我」，反杀更冷、靠继承家产 / 小青梅资源 / 商战清算收口。
