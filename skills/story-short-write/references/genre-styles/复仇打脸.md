# 流派包：复仇打脸

> 适用平台：知乎盐言（大女主主力赛道）、七猫、黑岩、点众、番茄。核心分工：聚焦**女频大女主高烈度主动复仇**——开局被至亲/枕边人/闺蜜极端作践（造黄谣、开盒社死、废手、顶罪坐牢、夺专利、推下天台），凭隐藏碾压级底牌、云端铁证、假死布局或重生判官设定，**当众撕穿、回旋镖反杀、让仇人亲口认栽进局子**（男频请选 `男频都市反杀.md`，日常亲戚算计请选 `世情打脸.md`）。

## 1. 读者爽点与核心人设标签

- **核心情绪账**：**「前期作践有多狠，后期反杀就有多解气 + 身份底牌揭晓那一刻的颅内高潮！」** 主角绝不原谅、绝不圣母，仇恨必须十倍奉还。
- **主角标签**：第一人称「我」（隐忍蓄力的真千金 / 被抢署名却握有核心底稿的首席设计师 / 出狱归来的复仇大女主 / 手握兵权或资本的隐藏大佬）。受作践时敢直喊痛，切冷后步步杀招、出手见血。
- **反派标签**：① **恶毒闺蜜/假千金**（惯用隐私武器化、大屏公放、全网造黄谣踩着主角上位）；② **助纣为虐的未婚夫/极品家人**（把主角当替罪羊或血包，嚣张至极）；③ **趋炎附势的围观名流/媒体**（前期跟着嘲讽唾骂，反转后瞬间膝盖发软集体倒戈）。
- **声线**：烈度拉满（9–10 级）！允许快意剧透与亮底牌预告（「笑吧，多笑会儿，过了今天你们就再也笑不出来了」「我真的很期待他们待会儿的表情」）。

## 2. 导语冷开场公式（150–300 字）

开篇第一段必须砸下可量化、能截图的**命级或社死级赌注**：

1. **大屏社死开场**：「庆功宴上，未婚夫为了帮假妹妹抢走金奖，在大屏幕公放我十年前做心理创伤治疗的保密录像，污蔑我精神失常、抄袭成性——他不知道，今晚颁奖的总部董事长是我亲舅舅。」
2. **极刑断肢/出狱归来开场**：「庭审席上，我一点点摘下右手手套，露出一截冷硬义肢——三年前，就是我那位好丈夫亲手签下了截肢同意书，只为给小青梅腾出首席小提琴位。」
3. **次数清零/假死反杀开场**：「替假千金顶罪坐牢三年，出狱那天亲爹嫌我晦气让我走后门，却不知当年那个被他们推出去挡灾的弃女，如今已经是全行业求着合作的神秘投资人。」

## 3. 节奏骨架与 30%–40% 付费卡点设计

- **第 1 节（1,300–1,600 字，开局入局）**：直接把最狠的当众羞辱现场演足（大屏公放/撕设计稿/泼酒逼跪），反派口出狂言，围观人群拍照起哄，仇恨值一节拉满。
- **第 2 节（免费升级）**：门外偷听或拿到核心暗线，撞破这帮人连三年前的灾祸都是蓄意谋害，作践升级到想把主角彻底灭口或赶出行业。
- **第 3–4 节（30%–40% 付费卡点）**：主角擦干血迹/眼泪一秒切冷，不再辩解，启动暗中早已备好的云端备份/资本撤资/刑事报案——**付费点卡在**：反派在最高光场合（颁奖礼/上市敲钟/订婚宴）洋洋得意宣布彻底踩死主角时，大门轰然推开，主角盛装入场或大屏画面突然切成了反派犯罪铁证！
- **第 5–7 节（40%–85% 阶梯式回旋镖连环反杀）**：每节撕碎反派一张依仗——① 云端监控/原稿时间戳当众打假，舆论瞬间倒戈；② 身份底牌揭晓（幕后大老板/评委主席/法政权威亲自向主角鞠躬），全场鸦雀无声；③ 断财路、废婚约、反派窝里反互相甩锅爆出更大丑闻。
- **第 8–9 节（85%–100% 彻底清算收尾）**：反派亲口认栽、被戴上手铐带走或身败名裂倾家荡产，主角一句居高临下审判金句盖棺，昂首离场。

## 4. 反派压迫与 40%+ 连环打脸招式

1. **隐私/伪证武器化 + 云端秒反杀**：假千金当众撕毁纸质原稿得意冷笑，下一秒全场大屏自动切出她半夜撬锁偷拍原稿的红外监控。
2. **回旋镖原样奉还**：反派怎么造谣网暴主角，主角就用实名铁证让全网把反派冲烂；反派当年怎么废了主角前程，今天就让对方终身禁赛/蹲大牢。
3. **身份底牌压轴炸场**：反派还在叫嚣「我认识总部的神秘投资人，一根手指就能碾死你」，门口保镖分列两旁，负责人一路小跑冲主角弯腰：「大小姐，撤资令已经签好了。」
4. **围观三层震惊放大**：普通路人倒吸冷气 → 懂行大佬当场识破真伪变脸 → 反派原本巴结的大人物反手抽反派耳光撇清关系。
5. **次数/血债逐笔清算**：把三年牢狱、九十九次退让、每一笔被吞的专利费当众一条条念出来，按着反派的头连本带利讨回。

## 5. 清算收尾模板

- **当庭宣判/戴铐带走**：反派在被告席嚎啕大哭求签谅解书，主角合上卷宗淡淡一笑：「进去慢慢跟法官解释吧。」
- **彻底剥夺+高位加冕**：主角拿回属于自己的一切（奖项、公司、名声、继承权），反派在悔恨和负债里烂透，主角头也不回。

## 6. 原创真网感示范切片

### 切片一：导语 + 当众社死炸弹（~225字）

国际珠宝设计金奖颁奖礼现场，大屏幕突然切掉我的参赛作品，换上了十张不堪入目的合成艳照。
全场记者疯了似的狂按快门，闪光灯晃得我睁不开眼。
假千金林薇挽着我未婚夫的手走上台，红着眼假惺惺劝大家：「别拍了！姐姐只是压力太大才走偏了路，那张设计图确实是我画的，我替姐姐向大家道歉！」
未婚夫一把扯掉我胸前的参赛牌狠狠砸在地上：「江月，抄袭还搞这种下作勾当，滚出设计界吧！」
台下嘘声震天。
我弯腰捡起摔碎的铭牌，冷笑一声。
笑吧，趁现在多笑会儿。
三分钟后，等主办方放完真正的云端录像，看谁先哭着跪下来求饶！

### 切片二：云端铁证 + 身份亮牌炸场（~230字）

林薇得意地伸手去接金奖奖杯，嘴角压都压不住。
就在她指尖碰到奖杯那一秒，头顶巨幕突然黑屏，随即响起一道清晰的录音——
「找两个修图师把江月的脸P上去，等会儿直接投大屏，我要让她今晚就身败名裂！」
林薇的笑容瞬间僵在脸上，手一抖，奖杯「咣当」砸碎在舞台上！
紧接着，视频切出她昨晚潜入我工作室偷拍底稿的高清监控，连她手机转账给水军的流水单都一清二楚！
全场瞬间死寂，下一秒记者镜头齐刷刷怼向林薇惨白的脸。
未婚夫慌了神，冲我嘶吼：「江月你敢搞鬼？我认识这次大赛的幕后金主顾总，我马上封杀你！」
后台大门轰然推开，顾氏掌权人带着一排保镖快步走上台，恭敬朝我欠身：「小姨，撤资令和律师函都备好了，警察已经在楼下候着。」

### 切片三：法庭清算与冷怼盖棺（~200字）

三个月后，庭审现场。
林薇因为商业窃密和诽谤罪被判五年，当庭腿软瘫在被告席上，哭着朝我伸手：「姐！看在一场姐妹份上，求你签谅解书啊！」
前未婚夫家族资金链断裂破产，跪在法院门口拦住我疯狂磕头。
我居高临下看着这两个曾经趾高气昂的人，连脚步都没停。
「你们跪着求饶的样子，比当年抢我作品时好看多了。」
「这不叫报复，叫物归原主。」
