# 题材风格包：双男主 / 宿命羁绊

> 知乎盐言特色大类。先读 `short-craft.md` 通用底座，本包在其上覆盖该题材专属调性。
> 一句话定位：**两个男人之间的羁绊与撕扯，以宿敌 / 知己 / 救赎 / 亏欠牵动关系，浓烈感情落在兄弟情、宿命感和占有欲上。** 读者要的是「一冷一热的温差对撞」+「嘴上势不两立、底下命都交出去」的错位快感。

---

## 叙述腔调

第一人称主导，「我」经常是**关系里主动、强势或占有的那一方**：把弟弟养在身边的哥、把对方当狗玩的重生者、冷淡履约的契约丈夫。另一方的滚烫与卑微靠对话和动作反衬出来。

腔调建在**口是心非**上：想的和说的相反，嘴上刻薄、心里在意。刻薄内心吐槽（「死对头明明有异能却不用——可能是脑子有病」）和冷叙述（「对于他的死，我也没有什么感觉」）都高频。开口常带同性羁绊的称呼锚点：「我哥」「继弟」「死对头」「宿敌」「暗卫十七」。

允许**双视角 / 暗恋视差插叙**：在「我」的叙述里，穿一段另一方隐秘的付出（偷偷记的本子、透支换来的巧合、未送出的信），读者比「我」先知道对方爱得多深。这是本题材最抓人的地方，不算全知剧透腔。

---

## 开篇范式

同样先放**结果倒序的导语**，剧透**两人错位的关系底牌**（而非背叛全貌）：谁在暗恋、谁欠了谁、谁会毁掉谁、火葬场追悔预告。第 1 节按导语停在哪里顺接或倒回，把这层错位落到具体场景里，导语字数按 `设定.md`「平台基调」。

| 开篇式 | 范例 |
|--------|------|
| 死讯倒叙 + 不解 | 宿敌死在我们平定北境的第三年，死讯传回京城那天，我握着他留下的半枚虎符枯坐了一整夜。 |
| 互殴定敌 + 埋暗流 | 我和他是基地最水火不容的死对头，末世前针锋相对，末世后却被分进同一支搜救队。 |
| 占有宣言（兄长 / 义弟） | 我恨我那位名义上的兄长，恨他把所有危险都独自扛下，却连一句实话都不肯告诉我。 |
| 契约枷锁开场 | 他曾说：「三年期满，你想走我放你走。」可三年后我递上解约书才知，他从未打算放我离开。 |
| 重生 / 穿书预知死局 | 重生回十八岁，我知道那个被全族排挤的质子义兄，五年后会因我一句无心之言踏平王城。 |
| 沙雕反差钩 | 新帝贴皇榜招暗卫，月俸五十两包吃住；可我进宫领到的差事，却是每天监督这位厌食症暴君喝药。 |
| 亏欠倒叙 + 确诊反击 | 我名义上的兄长是圈里最清冷的掌权人，我是他资助的继弟；确诊绝症那天，我当面撕了副卡搬出老宅。 |

## 钩子母题与密度

密度高，顺着**两人越来越难分开的关系**层层升级：从对峙到被迫共处，从共处到互相亏欠，再从亏欠走到谁也走不了。连着几节既没温差碰撞、视差揭露，也没选择或关系变化时，再排查是不是停滞了。

- **暗恋视差**（头号母题）：表面恨 / 斗 / 淡漠，底下一方偷偷爱着。隐秘爱意揭穿的那一刻是最大爽点。
- **契约 / 欠债 / 联姻强绑**：助手协议、欠条、联姻、暗卫合约，把两个本该分开的人硬拴在一起，制造无法逃离的共处。
- **救赎与被救赎**：一方陷在泥潭、脏钱、自毁或末世透支里，另一方伸手相救，也可能在相处中得到救赎。
- **亏欠反转（追夫火葬场变体）**：一方把另一方当工具 / 漠视 / 背叛，被弃者决绝离场（带走资产、假死脱身或改换门庭），漠视者卑微追悔。
- **宿命预知**：重生 / 穿书知道对方未来会自杀 / 黑化 / 毁掉自己，主角逆天改命。
- **身份反差硬碰**：高岭之花×隐忍继弟、暴君×老实暗卫、少将军×落魄质子、两个强手互不相让（双强）。
- **信物 / 记录承重**：偷记的本子、未送出的信、唯一的合照、旧伤疤，把没说出口的感情具象成物件。

## 情绪烈度与模式（烈度 8）

用**双轨温差**写两人的情绪：一方冷、嘴硬、克制、口是心非；另一方滚烫、卑微、偏执、豁出去。两人的反差与回应推动情绪，常以 HE（圆满结局）/ 救赎收束。

- **冷轨**：直写「没有感觉 / 不在意 / 只觉得烦」，越平越反衬后面的痛。例：听到他调任边关时，我面上毫无波澜，照常批完公文。
- **热轨**：卑微、偏执、追悔的滚烫台词，独立成段砸。例：他冒雨拦在我车前，声音嘶哑：「哥，我错了，你别不要我。」
- **冷轨中的别扭**：想的和说的相反，嘴上越刻薄越藏着在意（如嘴上嘲讽死对头多管闲事，转身却把仅剩的血清塞进对方包里）。
- **反差痛**：把冷叙述和一个滚烫细节并置，越平的口吻托越重的内容。例：我像处理公务一样替他收拾遗物，直到在箱底翻出那沓写满我名字却从未寄出的信。

范例：

- 我当时还不知道，死对头嘴里每一次顺路救我的巧合，都是他异能透支换来的结果。
- 他高烧昏迷中死死攥着我的手腕，还在哑声呢喃：「别走……我能护住你……」
- 我以为他厌极了我这双沾血的手，直到看见他守在我的衣冠冢前，用豁了口的佩刀一点点刻我的名字。

## 对话风格与金句

对白偏密，用来呈现嘴硬、偏执与契约立场，关键句可独立成段。三类高频台词：

**① 嘴硬 / 攻击性对手台词（表面势不两立）**
- 谁稀罕你多管闲事？把你的脏手从我领口拿开！
- 少拿他跟我比，一点小伤就到处嚷嚷，我看着都嫌烦。
- 刀都握不稳还敢上校场？滚回去再练三百遍挥刀！

**② 卑微 / 偏执的滚烫（隐忍 / 执念 / 追悔）**
- 哥，我错了，你别赶我走，让我留在你身边做什么都行。
- 哪怕你一辈子恨我，我也绝不会放手。
- 只要你肯留下来，这身家业、这柄帅印，你要什么我都双手奉上。
- 别丢下我一个人……

**③ 契约 / 立场台词（宿命枷锁）**
- 白纸黑字签了三年，期满之前，你连死都得死在我眼皮底下。
- 救你可以，但这笔账你要用一辈子来还。
- 开个价吧，怎样你才肯留在北境帮我？

冲突靠**两人的温差**呈现关系变化：前期一方长篇挑衅、另一方冷淡不理；后期冷的一方破防、嘴硬的一方卑微。谁先服软，谁就露了心。

## 招式库

| 招式 | 怎么用 | 示例 |
|------|--------|------|
| 暗恋视差揭穿 | 叙述里插一段对方隐秘的付出，读者先于「我」看到爱之深 | 翻开死对头锁在柜里的笔记本，扉页写着「讨厌他的理由」，第67条「讨厌他总是受伤」被用力划掉了三遍 |
| 契约锁死关系 | 助手 / 欠条 / 联姻 / 暗卫合约，把两人强绑进无法逃离的共处 | 我以为攒够五百万违约金就能两清，递交支票那天，他却当面买下了我外婆住的疗养院 |
| 温差对撞放电 | 一冷一热、口是心非，冷的越平热的越滚烫 | 无论我怎么冷言赶他走，他都不反驳，只是红着眼眶默默替我包扎好伤口 |
| 救赎拉拽 | 一方将另一方从泥潭 / 自毁 / 疯魔里拉出来 | 我夺下他手里带血的匕首，攥住他手腕：「从今天起你的命归我管，我不准你死！」 |
| 亏欠追悔（火葬场） | 一方漠视 / 背叛，被弃者决绝离场，前者卑微追回 | 我搬空公寓留下一纸解约书消失那天，向来高高在上的他却疯了一样满城找我 |
| 宿命预知逆写 | 重生 / 穿书知道对方会自杀 / 黑化 / 毁掉自己，逆天改命 | 穿书后得知我是反派义兄黑化的垫脚石，这一世我赶在他受罚前直接劫了法场 |
| 身份反差硬碰 | 高岭×隐忍继弟、皇帝×暗卫、将军×质子，落差本身就是钩 | 暴君屏退左右，把玩着玄铁令牌低声道：「做朕的影卫，命归朕，人也归朕。」 |
| 义亲 / 师门名分张力 | 名义兄长 / 师徒称呼承重，用名分压住越界暗流 | 他扣住我整理衣领的手，退后半步声音沙哑：「别乱动……记住你的身份，我是你哥。」 |
| 生死契 / 同命羁绊 | 借同命蛊 / 精神力绑定设定，把感情具象成共生共痛 | 他替我挡下致命一击后，锁骨下的同命印记渐淡，我才惊觉他早已单方面解开了痛觉共享 |
| 信物翻意义 | 信 / 诗 / 本子 / 合照 反复出现、意义反转，落到和解 | 整理旧物时翻出少年时唯一的并肩合照，背面写着一行褪色小字：「愿岁岁并肩。」 |
| 反差喜剧钩 | 两个宿敌阴差阳错凑一对，误会当笑点 | 我明明只是顺手帮宿敌挡了杯酒，他却连夜翻遍兵法，坚信我在用苦肉计向他示好 |

## 节奏骨架

```
导语（结果倒序 + 暗恋 / 亏欠 / 宿命的关系底牌剧透）
→ 第1节按导语停处顺接或倒回，写互殴 / 契约 / 占有场景，立敌意 + 埋暗流
→ 关系锁扣收紧（被迫共处 / 契约 / 宿命枷锁）
→ 温差一次次放电（嘴硬 vs 滚烫，错位加压）
→ 视差 / 隐情揭穿（本子 / 透支 / 未送出的信曝光）
→ 危机或亏欠爆点（送死 / 背叛 / 漠视 / 黑化）
→ 双向奔赴 或 追悔火葬场
→ HE 收束（宿命和解 / 救赎闭环）
```

让新错位和新揭穿沿关系链持续兑现；节尾可落在错位、局部确认、关系变化或明确的下一步，不要求每节同一种钩。温差放电、视差揭穿、危机爆点处详写慢放，共处日常按关系变化价值取舍。

## 收尾范式

- **双向奔赴**：嘴硬的一方终于承认，冷轨破防，温差归零。
- **救赎闭环**：一方将另一方从深渊拉出，两人从「两不相欠」走到「两相依」。
- **追悔火葬场（亏欠子类）**：漠视者卑微追回，被弃者冷拒或有条件回头。
- **宿命反写（重生 / 穿书）**：改掉前世的死局，这次不走了 / 你不许死。
- 主流以 HE、和解或救赎收束；亏欠子类可让被弃者冷拒，对应下方追夫火葬场公式。

情节概述：竹马不告而别的第三年，一张旧合照牵出重逢与当年被迫顶罪的隐情。／ 重生改写死对头为护我力竭早逝的死局，把人强留在身边，讨回前世没敢宣之于口的执念。

## 该题材专属调校（与通用去 AI 规则的偏差）

这些在别的语境像 AI 味或用力过猛，在本题材是卖点，**别误删**：

- **双视角 / 暗恋视差插叙**：在「我」的叙述里剧透另一方的隐秘付出，保留。这是拉起共鸣的核心写法，不算全知剧透腔。只删「泄了底又不勾人看」的随手全知。
- **口是心非的傲娇内心独白**：想的和说的相反，保留，别抹平成前后一致。
- **卑微 / 偏执 / 追悔的滚烫台词**：执念、救赎、火葬场的表白，保留，别当「用力过猛」删。
- **契约 / 宿命的前瞻剧透**：有意识地向前吊「三年后 / 后来他后悔了 / 未来他会毁掉我」，保留（通用套话见 `short-craft.md`，标点见 `short-format.md`）。

## 配套结构公式（按篇幅选）

- **宿敌暗恋 / 双向奔赴型（8-11 节）**：1-2 节互殴立敌 + 埋暗流 → 3-4 节被迫共处 / 契约绑定 → 5-6 节视差揭穿（一方隐秘曝光） → 7-8 节危机送命 / 破防表白 → 双向奔赴 HE。视角可单可双；全靠两人的冷热温差拉扯，冷的那个越晚破防越好。
- **救赎 / 现代情感型**：一方在深渊（脏钱 / 契约 / 自毁 / 末世透支） → 另一方拉拽 → 前世 / 契约枷锁把人锁死 → 打破枷锁走到两相依。冷叙述打底，反差细节扎心。
- **亏欠追夫火葬场型**：一方漠视 / 背叛（继弟 / 伴侣被当工具） → 确诊 / 心死 → 决绝离场（带走资产 / 假死脱身 / 改换门庭） → 漠视者卑微追回 → 冷拒或有条件回头。刀口精准，别谩骂。
- **古代权谋双强型**：帝王将相 / 兄弟养成，重生或穿书预知死局 → 逆写宿命 → 囚 / 救 / 亲 → 江山与人都要。权谋线和感情线互为筹码。
