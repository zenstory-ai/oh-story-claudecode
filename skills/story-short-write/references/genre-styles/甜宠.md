# 题材风格包：甜宠恋爱线

> 番茄 / 七猫 / 知乎盐言通俗短篇。先读 `short-craft.md` 通用底座，本包在其上覆盖该题材专属调性。
> 一句话定位：**甜宠恋爱线：纯甜双向奔赴 / 先虐后甜 / 暗恋成真 / 先婚后爱 / 救赎，以 HE（圆满结局）收尾。** 读者要的是「被偏爱的例外感」+「嘴硬心软的拉扯」。用密集甜点和「糖里带钩」留住读者，虐段为后续的甜蓄势。

---

## 叙述腔调

第一人称「我」（多为女主）主导，轻快、自嘲、口语。主要看点是**内心吐槽小剧场**：表面言行与心理活动的反差制造喜感，嘴上「关你什么事」，心里「这人今天是怎么了？吃错药了？」。允许沙雕自称（本小姐 / 本公主 / 本喵）。心动瞬间可以切慢镜头，放大关系变化或有信息的细节。

先虐后甜 / 救赎支线的前段用压抑克制腔，留白、少解释（如被问起旧伤时只淡淡答一句「早不疼了」，转身把止痛药塞回包底）；转甜后切回轻快，让甜成为熬过压抑的奖赏。

男主可以是冰块脸 / 毒舌 / 病弱伪装，关键处用短台词撩拨或露出反差。

---

## 开篇范式

导语抛出「关系错位 + 一句杀伤力台词」，让读者立刻看懂误会。可以剧透他有多宠、他其实是谁，把两人怎么走到一起留给正文；接法和字数按 `设定.md`「平台基调」记下的导语写法。

| 开篇式 | 范例 |
|--------|------|
| 误发消息 / 打错电话 | 电话那头传来低沉又戏谑的声音：「看清楚，我是你死对头，你刚发的那条撒娇语音是准备发给谁的？」 |
| 荒诞事件牵线 | 闺蜜拉我去医院探望她那个因为抗拒相亲被亲爹打断腿的哥哥；推开病房门我才发现，病床上打着厚石膏的人，正是昨晚刚加我微信的相亲对象。 |
| 修罗场 + 对照组 | 订婚宴上未婚夫为了安抚哭闹的前女友当众丢下我，我踩空高跟鞋，一头撞进主位上那位从不近女色的小叔怀里。 |
| 强设定自白 | 我是大周朝赫赫有名的混世小郡主，全京城的媒婆见了我都绕道走。 |
| 闯祸定终身 | 退婚买醉那晚，我不小心把家里新招的病弱账房给扑倒了；第二天清晨，他裹着外袍堵在我房门口，咳着嗽要我负责。 |
| 重逢式 | 男人转过身来的那一瞬，我整个人都麻了——这位空降公司的新任总裁，竟然是被我单方面拉黑了六年的前男友。 |

## 钩子母题与密度

甜宠的钩子是一颗**悬着的糖**：让心动、试探、选择和关系变化一路往前推；连着几节没动静再排查停滞。节尾可留疑点吊住情绪，或给阶段性甜头。

- **马甲 / 身份错位**（头号母题）：双马甲互撩、隐藏大佬、认错人、网恋对象是身边人。每次触碰都应改变判断或关系，不逐节重复“差点戳穿又滑走”。
- **例外感投喂**：冰块男主只对女主破例。热橙汁、剔好刺的鱼、一支簪子。物件越小，例外越大。
- **强制同框装置**：赐婚 / 联姻 / 提亲堵门 / 病房陪护 / 住进同屋，把两人锁在同一空间日常发酵。
- **吃醋触发器**：前任、旧情传闻、男模。情敌只是催化剂，逼出占有欲和委屈，不构成真威胁。
- **「他好像瞒着我什么」**：深夜电话、被删的朋友圈、叫他爸爸的孩子。虐钩短用，真相必须洗白。
- **危机见真心**：挡箭、发烧、受伤。嘴硬由行动戳破。

## 情绪烈度与模式（烈度 6）

日常轻快，心动瞬间拉高再速降（若叠沙雕吐槽风，尴尬场先用钝感吐槽接招，男主破例或直球逼近那一拍吐槽骤停、切慢镜头）。峰值落在试探、意外回应或身体细节上：

- 心跳系：我愣在原地，心跳漏了一拍。
- 温度系：耳朵烫得要命，我几乎是从椅子上弹了起来。
- 被抓包系：他似笑非笑地看着我：「哦？那你耳朵红什么？」我下意识捂住耳朵，才发觉自己上了当。

先虐后甜段烈度可短暂到 8，一次到位就转场，不反复碾（如撞见他深夜替别人奔走以为自己只是替身，下一节即揭开他是在暗中替女主查清家族旧案）。

## 对话风格与金句

对白在试探、暧昧和关系博弈场景可以密，行动照顾、物件投喂和等待场景可以少或没有；不设全文占比。话轮长短随筹码变化，不把女主固定成话痨、男主固定成一句收网。四类高频台词：

**① 男主反差撩 / 占有宣言（低频高杀伤）**
- 「放心，我对你没兴趣。」「不过刚才缠着你的那小子，确实配不上你。」
- 「夫人，这剑太凉，仔细冻着手。」（装病弱的夫君被刺客长剑架在脖子上，还在朝女主卖弱）
- 「我不凶的，别怕我，离他远一点好不好？」（外人眼里冷戾果决的掌权人低声哄人）
- 「还能再见到你，真好。」

**② 女主嘴贫 / 口不择言（高频铺糖）**
- 「看在我通宵改完方案的份上，能摸一下腹肌充充电吗？」
- 「你求我啊。」（逼出高冷死对头低声说出一句「求你。」）
- 「大人若是笑一笑，可比现在板着脸好看多了。」

**③ 委屈小狗 / 吃醋台词**
- 「我和你那个白月光前任，到底哪里像了？」「我又哪点不如他了？」
- 「那些日夜的陪伴、你对我的撒娇，难道都只是拿我当挡箭牌？」

**④ 心动确认句（一句定格，独立成段）**
- 「不丑，而且这只最好吃。」（男主面不改色地夹起女主包得歪七扭八的饺子）
- 「等我回来。」
- 「这不是你的错，以后有我兜着。」（救赎线的落点句）

## 招式库

| 招式 | 怎么用 | 示例 |
|------|--------|------|
| 误发消息开局 | 错发消息 / 错认对象建立关系，错位即钩 | 误把老板当闺蜜小号吐槽后拉黑，早会老板盯着我委屈问：「我哪句话说错了，为什么要把我拉黑？」 |
| 例外感投喂 | 只对女主破例，用小物件写大偏爱 | 把面前的热橙汁转到我手边：「喝这个。」／把挑净鱼刺的糖醋鱼夹进我碗里 |
| 嘴硬心软 | 好意配一个不领情的理由 | 替我挡下劝酒，转头却冷着脸说：「我只是不想下属醉倒影响项目进度。」 |
| 弱势伪装 | 病弱 / 无害人设藏大佬底牌，揭底即爽点 | 我那走两步都要喘气的病弱夫君，夜里单手把翻墙的刺客头领按在地上揍 |
| 强制同框 | 赐婚 / 提亲 / 陪护，把两人锁进同一空间 | 「从今日起他就是你的贴身侍读，督促你背满三卷策论！」我两眼一黑 |
| 撩拨反杀 | 女主长期撩不动，男主某天突然接招反压 | 平时逗一下就耳红的人突然扣住我手腕：「不是说想检验健身成果吗？怎么躲了？」 |
| 吃醋修罗场 | 情敌 / 前任出现，男主发疯或秒变委屈 | 见合作方才俊给我递名片，他表面镇定，散会后却把名片抽走换上自己的私人号码 |
| 心动打卡 | 身体微反应记录心动进度，不连用同一处 | 他指尖擦过我手背的瞬间，我握着汤匙的手一顿，半天没敢抬头 |
| 危机见真心 | 挡箭 / 发烧 / 受伤，行动戳破嘴硬 | 暗箭破窗射来，刚才还在拌嘴的将军一把将我护在怀里，用后背硬接一箭 |
| 认知错位萌 | 非人 / 天真视角误读人类常识，糖从误读里长 | 小师妹不懂情爱，见师兄靠近她就耳根通红脉搏加快，紧张地掏出银针：「师兄是不是中了火毒？我给你扎两针！」 |
| 马甲揭穿名场面 | 面具 / 身份当众掉落，糖与爽同发 | 兼职唱见的我在庆典后台碰掉面具，前排的冷面老板声音发抖：「你就是我追更三年的那个歌手？！」 |
| 撕剧本宣言 | 穿书 / 弹幕流：当众推翻既定命运，转头选自己人 | 弹幕让我按剧情给渣男送伞，我一把将伞塞给淋雨的反派：既然我是女主，喜欢谁由我说了算 |
| 虐钩短用 | 「他瞒着我什么」造短虐，真相揭开糖翻倍 | 隔着玻璃见男孩喊他「爸爸」，当晚他拿出一等功勋章与战友遗孤抚养证明 |

## 节奏骨架

```
导语（高概念误会 + 杀伤力台词）
→ 第1节按导语停处顺接或倒回，坐实错位
→ 强制同框装置上线
→ 日常糖点与关系选择交替推进，避免同一种心动微事件循环
→ 吃醋 / 情敌小高潮
→ 误会爆发 / 危机（虐段，短）
→ 真相揭开 + 告白（糖峰值）
→ 确认关系 + 补糖收尾
```

疏密：心动瞬间慢放（动作、对视、一句台词拆三行），日常过场一句带过。纯甜线的虐段总量不超过全篇三成，不连排两节虐，误会当节或下节解开；先虐后甜线的压抑段按下方对应公式分配。

---

## 收尾范式

- 告白 + 马甲 / 误会全部揭开，当面兑现，不留暗线。
- 男主视角番外：把前文的糖回放加浓，交代他从何时沦陷。例：番外里揭开其实三年前那场暴雨里的解围，他就认出了她。
- 婚礼 / 领证 / 回归日常斗嘴定格，用一句拌嘴而非抒情收束。
- 危机化解型：误会解开或伤愈出院当天，两人立刻回到日常拌嘴撒糖。

HE 是硬约束：不开放式、不 BE、不留第三者复活的口子。

## 该题材专属调校（与通用去 AI 规则的偏差）

这些在别的语境是 AI 味，在本题材是卖点，**别误删**：

- **内心吐槽小剧场 / 自问自答**（「吃错药了？」「几个意思？」）：保留，这是制造喜感与代入感的主力写法。
- **网络语与流行梗**（已读乱回、I 人、磕 CP、PTSD）：现代篇保留，是口语质感的一部分；古代篇禁用，换成「本小姐」式的俏皮自称。
- **心动微反应重复打卡**（耳朵红 / 心跳漏拍）：保留复现，让读者察觉心动进度；不连续两节用同一处。
- **男主金句式短台词**：保留「一句收网」，哪怕显得戏剧化；别为自然感把它稀释成长段解释。

本题材额外要避免「宠溺地笑」「一股甜蜜涌上心头」这类空转套话；通用套话与标点要求见 `short-craft.md`。

## 配套结构公式（按篇幅选）

- **纯甜双向奔赴型（8-12 节）**：误会开局 → 强制同框 → 糖点循环 4-6 节 → 吃醋小高潮 → 短危机 / 误会 → 告白 HE。全程轻快，虐不过夜。
- **先虐后甜 / 破镜重圆型**：前三到四成篇幅压抑（误会 / 隐瞒 / 前尘旧账），真相一次炸开，之后每颗糖按双倍浓度发。虐是糖的杠杆：读者忍多久，糖就多甜；但虐因必须能洗白（任务 / 苦衷 / 错认），不能是真背叛。
- **先婚后爱型（古代居多）**：被迫成婚（赐婚 / 提亲计 / 联姻）→ 婚内日常破冰 → 例外感堆叠 → 旧情传闻 / 情敌测试 → 互揭心迹。张力来自「名分先行、真心后至」的时间差。
- **救赎型**：天真强者 × 满身伤痕者。认知错位萌铺糖，危机互救见真心，落点是「这不是你的错」式的接住；被救的一方要先为对方破一次例。
