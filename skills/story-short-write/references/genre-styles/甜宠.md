# 流派包：甜宠

> 适用平台：知乎盐言（甜宠/校园高热赛道，轻快吐槽向）、番茄、七猫、黑岩。涵盖：**纯甜双向奔赴、先婚后爱、死对头真香、暗恋成真、先虐后甜（虐因必可洗白）**。硬底线：**必须圆满 HE**，读者要的是「高冷大佬只对我破例的偏爱感」+「嘴硬心软的高密拉扯糖」。

## 1. 读者爽点与核心人设标签

- **核心情绪账**：反差糖 + 例外感！外面人眼里冷若冰霜/毒舌暴躁/高不可攀的男主，背地里偷偷给女主挑鱼刺、记忌口、吃闷醋、被女主一句直球撩得耳根通红。
- **主角标签**：第一人称「我」（嘴贫机灵、内心小剧场刷屏的直球女主 / 误打误撞撩动冰山的小太阳）。表面嘴硬「关你什么事」，心里疯狂吐槽「这人今天吃错药了吧？」。
- **男主标签**：① **冰山反差撩 / 毒舌死对头**（嘴上嫌弃「蠢死了」，手已经在帮她系鞋带/挡酒）；② **病弱伪装大佬**（在女主面前咳两声求抱抱，背地单手按死刺客/收拾情敌）；③ **蓄谋已久暗恋者**（所有巧合都是他步步为营）。
- **声线**：轻快、俏皮、高密度口语对话推拉；心动峰值切慢镜头定格 1–2 句（耳朵发烫、心跳漏拍、突然凑近的呼吸），其余时间靠嘴贫和反差制造笑感。

## 2. 导语冷开场公式（150–300 字）

导语抛出**「社死/错位误会 + 男主一句高杀伤反差台词」**，立刻把糖钩挂上：

1. **误发消息/社死抓包式**：「把新来的高冷总监当成闺蜜小号，连发十条语音吐槽他『长得帅但肯定不行』后顺手拉黑。第二天早会，他把手机推到我面前，低笑：『林小姐，昨晚的评价，需要我亲自证伪吗？』」
2. **修罗场转嫁大佬式**：「订婚宴上未婚夫抛下我去哄白月光，我提着裙摆走到主位，冲他那位从不近女色的小叔勾勾手：『小叔，侄子不要我了，你收不收？』满场死寂里，他扯松领带起身：『等这句话三年了。』」
3. **荒诞牵线/马甲错位式**：「被亲妈逼着去相亲，我故意素颜穿大花裤衩想吓退对方，推开包厢门却傻了——对面端坐着的，是我昨晚在游戏里一口一个『好哥哥』骗走十万装备的榜一大佬。」

## 3. 节奏骨架与 30%–40% 付费卡点设计

- **第 1 节（1,200–1,500 字，开局入局）**：把误会/错位现场演足，男女主嘴炮交锋第一轮，男主甩出一句看似冷淡实则暗藏偏爱的反差动作。
- **第 2 节（免费升级）**：**强制同框装置上线**（联姻同居/赐婚/出差合住/项目绑死），日常发糖+女主内心吐槽小剧场，埋下「他好像早就认识我/瞒着我什么」的甜钩。
- **第 3–4 节（30%–40% 付费卡点）**：情敌挑衅或前任纠缠触发**吃醋修罗场**，男主表面淡定实则占有欲瞬间爆发，或男主马甲/暗恋秘密露出一角——**付费点卡在**：男主突然反客为主把女主堵在墙角，哑声问出一句直球撩拨或醋意炸裂的台词！
- **第 5–7 节（40%–85% 高浓度发糖 + 短促危机破冰）**：例外感投喂升级（只为她破例、公开场合护短打脸奇葩前任/绿茶）；安排一次不超过 1 节的短促误会或危机（挡箭/生病照顾/误以为替身），当节或下节立刻洗白并爆出他蓄谋已久的暗恋证据！
- **第 8–9 节（85%–100% 告白确认 + 补糖番外收尾）**：双向直球告白、马甲全掉、所有误会清零；可附 300 字男主视角甜番外（揭晓他多早就沦陷），回到日常斗嘴撒糖定格。

## 4. 反派压迫与 40%+ 撒糖护短招式

1. **例外感小物投喂**：冰山男主从来不吃甜食，包里却常年揣着她最爱的草莓糖；开会冷着脸批下属，转头顺手把剔净刺的鱼肉夹进她碗里。
2. **撩拨反杀**：平时都是女主嘴贫占便宜，某天男主突然反扣手腕逼近，一句话把话痨女主撩到当场结巴耳红。
3. **打脸奇葩前任/情敌只当发糖催化剂**：奇葩前任酸溜溜说「他不过玩玩你」，男主直接甩出结婚证或当众低头亲她额头护短，爽甜双收。
4. **暗恋实锤掉马**：意外翻到男主锁在抽屉里的旧车票/高中合照/写满她名字的笔记，读者瞬间磕疯！
5. **嘴硬心软推拉**：嘴上嫌她麻烦「只是顺路」，结果绕了大半座城专门给她买排两小时队的糖炒栗子。

**高频发糖台词库（按需化用）**：
- 男主低频反差撩：「放心，我对你没兴趣——不过刚才缠着你的那小子，确实配不上你。」「别怕我，离别的男的远一点好不好？」
- 女主嘴贫直球：「看在我通宵改方案的份上，能摸一下腹肌充充电吗？」「陆总，您这耳根红得快赶上红灯笼了。」
- 委屈吃醋/心动定格：「我和你那个白月光前任到底哪点像？」「不丑，你包的歪饺子最好吃。」「这不是你的错，以后有我兜着。」

## 5. 清算收尾模板

- **日常斗嘴定格**：领证/婚礼/同居日常，男主一句低沉宠溺台词接女主一句俏皮吐槽，甜度爆表。
- **男主视角补糖番外**：用他视角回放前文 2–3 个名场面（「其实她不知道，早在五年前暴雨夜她把伞塞给我时，我就栽了」），把甜度再拉高一档。

## 6. 原创真网感示范切片

### 切片一：导语 + 社死错位开场（~215字）

我喝断片那晚，错把死对头陆沉当成网约车司机，抱着他脖子嚎了一路：「师傅，陆沉那个狗东西天天在会议室挑我刺，肯定是嫉妒我长得比他好看！」
第二天醒来，我摸着发痛的额头刚想溜，卧室门推开了。
陆沉系着围裙端着醒酒汤走进来，眼神似笑非笑：「醒了？陆沉那个狗东西给你熬的汤，喝完再走。」
我整个人当场石化！
脑子里疯狂刷屏：现在跳窗还来得及吗？二楼摔下去应该只是骨折吧？
他把碗放床头，俯身撑在我两侧，声音低得发哑：「昨晚亲了我三口就想跑，许小姐，这笔账怎么算？」

### 切片二：嘴硬吐槽 + 吃醋直球反杀（~225字）

公司团建，隔壁部门帅哥端着果汁过来找我搭讪，顺手想帮我拎包。
我正笑眯眯准备客套两句，斜刺里突然伸出一只骨节分明的大手，直接把我的包拎走了。
陆沉面无表情站我身侧，语气冷得掉冰渣：「她手腕上周扭伤了，包重，不劳费心。」
帅哥尴尬摸摸鼻子走了。
我憋着笑戳他胳膊：「陆总监，我手腕早好了，你是不是吃醋啦？」
他耳朵尖肉眼可见地红了一截，偏偏绷着脸硬扛：「我只是怕下属工伤影响季度业绩。」
我刚想吐槽他死鸭子嘴硬，他突然低头凑到我耳边，热气扫得我心跳猛漏一拍。
「行，我吃醋了。」
「以后离别的男的远点，行不行？」

### 切片三：护短打脸 + 暗恋掉马 HE（~210字）

聚会散场，渣前任堵在门口阴阳怪气：「许眠，陆沉那种大人物也就图个新鲜，你别真当自己是阔太太了。」
我还没张嘴，陆沉直接把一件西装外套披我肩上，当众从大衣内袋掏出两本红彤彤的结婚证拍在桌上。
「不好意思，领完证了，合法夫妻。」
前任脸绿得像苦瓜，灰溜溜滚了。
回家路上，我翻他外套口袋找糖，却摸出一张泛黄的大学校园卡——照片里，是七年前扎着马尾在操场大笑的我。
我愣住了，转头看他。
陆沉单手握着方向盘，耳根微红，嘴角却扬得老高：「藏了七年，终于让我名正言顺把人拐回家了。」

## 7. 流派专属禁区与雷区

- **禁假甜真虐 / BE / 开放式结尾**：甜宠核心承诺是 HE，纯甜线虐段绝不超过 1 节且当节洗白；先虐后甜线的虐因必须是误会/苦衷，严禁真出轨或真践踏。
- **禁空转套话**：别反复堆砌「宠溺地笑」「一股暖流涌上心头」，甜靠具体反差动作、嘴硬台词和小心机细节落地。
- **允许项**：允许女主高频内心吐槽小剧场、允许适度现代网络梗（古代篇禁用）、允许男主短句直球撩拨与心动细节复现。
