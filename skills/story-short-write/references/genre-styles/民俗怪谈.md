# 题材风格包：民俗怪谈

> 番茄 / 七猫 / 黑岩 / 盐言通俗短篇。先读 `short-craft.md` 通用底座，本包在其上覆盖该题材专属调性。
> 一句话定位：**民俗规矩与乡土怪谈（冥婚 / 纸人 / 风水 / 头七 / 喜丧 / 出马仙），规矩即命门：破规矩者遭殃、守规矩者活命。** 读者要的是「差一点就」的战栗 + 身边人变异样的悚然 + 恶人破戒遭报的爽。

---

## 叙述腔调

用第一人称亲历视角，主角常是接阴人 / 扎纸匠 / 冥婚媒婆 / 捞尸人 / 法医，开口自报行当和铁规矩。口吻冷静克制，以白描写见鬼经历；恐惧落在异常线索、禁忌和进退选择上，也可直写或用影响行动的身体反应，少用哭诉。乡土口语加行话打底：十里八乡、邪性、晦气、脏东西、讲究、忌讳、吉时、脏了手。

两种主导腔调，按主角站位选一：

- **破戒 / 旁观者腔**：我或身边人犯了忌讳，我一边怕一边补救，全篇靠恐惧推着走。
- **持规矩者腔**：我就是规矩本身的执行人，冷静到吓人（如法医立规矩只验三天内的尸体、扎纸匠绝不给纸人点睛）。悚然感来自我的平静。

长辈 / 行家的告诫全用直接引语，且常故意说一半就断。

## 开篇范式

导语先把最关键的规矩、破戒或超自然实锤演成现场，确认怪事真实发生。这就是正文的第一场；第 1 节接着写异象造成的行动或后果，随处置过程补入行当与规矩，不重演导语。

| 开篇式 | 范例 |
|--------|------|
| 俗谚开局即实锤 | “正月不剃头，剃头死舅舅”的俗谚，原来都是真的。 |
| 家规自陈 | 我家有个传了三代的规矩：祠堂里的长明红烛必须彻夜常亮，一旦熄灭，全家人都不准出屋。 |
| 行当自报+一单异常 | 我做了十年捞尸人，见惯了浮尸；可那天雨夜捞上来的女人不一样——刚解开麻绳，她自己站起来跑了。 |
| 长辈告诫开场 | “娃子，记住喽，过了子时进老林子，听见有人喊你全名千万莫回头。” |
| 白事现场即炸 | 头七这晚，停在堂屋的棺材板突然从里面叩响，逼全家晚辈轮流上前哭丧。 |
| 仪式异样细读 | 迎亲队吹着唢呐穿过浓雾这天，风掀开轿帘一角，我才看清那顶花轿居然是纸扎的。 |
| 铁规矩自立+当场拒单 | 我是镇上的老仵作，规矩是只验三天内暴毙的尸首；可今晚送来的这具，已经入土七年了。 |

## 钩子母题与密度

密度高，核心节拍是**立规矩、有人破戒、当场或次日应验**。开场先让规矩、异常或代价落地一项，只有核心悬念必须靠死人立住时才尽早见血。往后让异象、查证、破戒和代价持续升级；完整的应验过程可以连着展开，不用在每节末尾硬塞新怪事。

- **规矩三段式**（核心母题）：规矩先明说，读者从明说那刻起就在等应验。破戒的多是主角身边的蠢人 / 恶人（堂弟偷吃供品、老板强逼点睛、堂妹哭丧不掉泪），主角旁观代价再轮到自己。
- **尸象异常清单**：指甲乌黑、眼睛合不拢、嘴角带笑、尸体竖在水里、寿衣沾泥。一条条摆，逐节加重（眼缝从一条线撑到能塞筷子）。
- **身边人变异样**：嘴角咧到耳根、眼白无瞳、影子拖着尾巴、说话声从别处响起。恐怖来自熟人脸上的陌生东西。
- **帮助者有价**：神婆 / 半仙 / 师父能救你，但要钱、要替身、甚至要你的命。
- **阴间账本**：拿过死人的钱、金牙、风水好处，阴间记着账，迟早连本带利讨回（如头七夜按生前所欠上秤清算）。
- **差一点就**：刀尖快碰到喉咙时鸡鸣、火光庇护、香灰糯米压住。救命的窗口永远只差一秒。
- **人比鬼狠**（世情底色）：鬼守规矩，人不守。尸体一女卖三家、同行媒婆见财起杀心、亲长辈卖晚辈换寿。真相层常落在人心上。

## 情绪烈度与模式（烈度 7）

恐惧型烈度：意象狠、叙述稳。避免长段心理自剖，恐惧可以通过感知、判断或选择呈现。

- 恐惧以直写为主；体感（后颈发凉 / 如坠冰窟）全篇两三处，一句到位不叠形容。
- 恐怖靠熟悉物变样，不靠血浆：那件旧蓝布棉袄挂在空仓房里，「每逢雪夜就窸窸窣窣地响，像有东西在里头试衣裳。」
- 悚然的最高级是轻描淡写：前头刚抬走被害死的原配，他只皱皱眉吩咐下人：「晦气，趁天黑抬去后山埋了吧。」
- 惨烈描写只给破戒者遭报的时刻，此处放开写，其余时候收着。
- 邪祟开口要家常、要软：「后生……外头雪大，帮婆婆找件合身的衣裳吧……」越客气越瘆人。

## 对话风格与金句

对白主要承担立规矩、诱导破戒、证词矛盾或代价确认；观察、查验、仪式和应验链可以少或没有对白，不设全文占比。三类高频台词：

**① 规矩告诫（长辈 / 行家口，保命符兼死亡预告）**
- 记住，夜路走过后山乱葬岗，无论谁在背后叫你名字，都绝不能回头！
- 镇尸的黄符千万别揭！天亮之前谁敢动那张符，神仙也救不了！
- 今晚守灵，所有人都不能出堂屋。门窗封死，长明灯不能灭，香火不能断。天亮鸡叫之前，不管听见门外谁在喊开门，都不要应声。
- 记住，听见头遍鸡叫前，千万别掀开红盖头。
- 遇到逆流漂上来还穿着红绣鞋的浮尸，千万别下钩子去捞。

**② 破戒者狂话（不信邪 / 钱大过天，说完必遭报）**
- 都什么年代了，还信这些老黄历？／什么狗屁忌讳，老子偏不信这个邪！
- 今天这纸人的眼睛你点也得点，不点我就砸了你这扎纸铺！／出了事我担着，用不着你操心！
- 不过是一尊破泥像，砸了就砸了，它还能半夜爬起来找我索命不成？

**③ 邪祟与规矩的家常话（越家常越瘆人）**
- （头七夜纸人站在床尾，直勾勾盯着偷拿了陪葬金镯的二叔）二叔，奶奶问她镯子戴在你手上沉不沉？
- （三年前被害死配冥婚的阿姐，在迎亲夜从喜轿帘子后探出半张脸）妹妹别怕，当年我出嫁的胭脂，还是你亲手替我抹上的呢。
- 你爷爷当年从河里捞走的那笔横财，今夜该由你这个孙子来还了……
- （误入半夜才开的鬼市当铺，掌柜敲着算盘冷冷抬眼）新客进了门要守规矩。要么买件货走，要么……留下身上一件东西抵债。

## 招式库

| 招式 | 怎么用 | 示例 |
|------|--------|------|
| 规矩前置当保险丝 | 开头借行家嘴明说禁忌和后果，读者等应验 | 扎纸匠叮嘱：「纸人绝不能点真朱砂睛，一旦点睛就能看路，第一眼看见谁就拿谁当替身。」 |
| 导语剧透超自然实锤 | 导语直接放怪事结果，不留科学解释余地 | 铜镜里的自己正举着剃刀朝脖子上比划——可镜外的我，分明两手空空 |
| 尸象异常渐进 | 同一处异常逐节加重，当恐怖进度条 | 棺木里的眼缝从初一的「按了三次都合不拢，露着一条缝」，到初三夜里「撑开到能塞进一根筷子」 |
| 死亡进度条 | 破戒代价可视化，随情节推进爬升 | 偷拿陪葬金镯后手腕浮现青黑尸斑，每过一时辰往上爬一寸，漫过心口就没命了 |
| 行当讲究罗列 | 干活前把流程讲究一条条摆出来压场 | 下水前撒香灰问路、长竹竿轻探三次、捞尸钩避开肩膀免得尸首倒立怨气不散 |
| 帮助者反转有价 | 救你的人也在算计你，救命法本身是坑 | 塞给我护身木牌的守村老道突然锁死院门：「老夫替这口凶井镇了三十年煞，终于等到八字合拍的替死鬼了。」 |
| 阴间账本 | 生前占的便宜死后按规矩清算，逐人执行 | 灵堂摆着老铜秤：「生前昧下老爷子多少棺材本，今晚就得往秤盘放多少带血物件平账。」 |
| 二次破戒 | 赔罪成功后又作死，代价翻倍收走 | 恶霸惊扰古墓烧纸赔罪侥幸逃生，见坟头露金器又半夜去刨坟，当晚被塌方封土活埋 |
| 死去亲人暗中指路 | 至亲亡魂借声音报信给唯一干净的后辈 | 红烛熄灭瞬间，耳边响起已故奶奶焦急的耳语：「傻丫头，快把供桌下的糯米撒在门槛上！」 |
| 世情垫恶再清算 | 先用家长里短立恶人（偏心、抢钱、吃绝户），邪祟只收有罪的 | 大伯假意护堂妹后退，却趁乱扯走她脖子上保命的玉观音：「小孩子戴这个不稳妥，大伯替你收着！」 |
| 器物 / 异类视角 | 梳子、老宅物件当叙述者，旁观人心 | 我是一把陪嫁的百年檀木梳，在妆台上看了这家三代人是怎么害死原配的 |
| 数字压秤 | 规矩全带具体数字，越具体越可信 | 守灵必须守满七七四十九个小时，红烛不能断一寸，酬金只要四万九千块 |

## 节奏骨架

```
导语（先呈现关键规矩、破戒或应验实锤，作为正文第一场）
→ 第1节 承接异象后果，在处置中立规矩（长辈告诫 / 行当自报）
→ 破戒引出明确代价（导语已写过应验时，继续追查或呈现后续代价）
→ 异象、查证与代价沿因果链升级：尸象异常 → 身边人变样 → 邪祟上门
→ 中段翻旧账：规矩的来历（族谱 / 旧案 / 上辈孽债）
→ 帮助者给保命法（有价或有坑）
→ 卡时辰决战（子时 / 头七 / 天亮前）
→ 债清 / 换命 / 审判收口
```

用时辰和日期推进倒计时：白天缓、入夜炸，子时、头七、鸡鸣、正月十五都可成为期限。立规矩和应验时刻详写慢放，赶路过场一句带过；异象围着同一条规矩升级，避免一节换一个新怪物。

## 收尾范式

- 债清物留：事了人走，但物件还在原地（如全村搬空后，祠堂供桌上那对点过睛的纸人依然面朝村口站着）。阴冷余韵优于大团圆。
- 规矩审判收口：破规矩者死透，守规矩者活命并拿到真相；最后一刻再翻主角自己的旧账做终反转（如账册翻到末页，露出主角当年为自保沉默的签名：「当年替他们锁上柴房门的人，不正是你自己吗？」）。
- 换命 / 替身完成：代价式收尾，活下来的人身上留了记号。
- 温情变体（民间奇闻线）：善行得封、恩义两清（如黄仙向弥留的母亲讨封“你看我像人还是像仙？”，母亲把幼子推到它面前托孤：“你像他的娘！”）。
- 收在具体画面上就停，删去结尾的民俗知识小作文和点评式结语。

## 该题材专属调校（与通用去 AI 规则的偏差）

这些在别的语境是毛病，在本题材是卖点，**别误删**：

- **规矩句式的重复**：同一条规矩原话多次出现（告诫时、破戒时、应验时各一遍），这是仪式感，不按冗余删。
- **行话与讲究罗列**：成段列流程、列忌讳、列尸象，操作感就是可信感，别压缩成一句概述。
- **告诫直接引语 + 说一半就断**：「要么买件货，要么……」断在刀口上，别补全。
- **导语剧透超自然实锤**：别改成「留悬念」的暧昧写法，读者要先确认有鬼才肯进来。
- **具体数字**：七七四十九小时、四万九千块、三更梆子、子时十二点，别泛化成「很久」「一大笔钱」。

本题材额外要避免的：

- 主角成段心理独白和情绪自剖（简短判断或直写恐惧可以）。
- 自造玄学体系。民俗名词用现成的：头七、往生咒、糯米、黄符、生辰八字、讨封、点睛。
- 不断堆叠新怪物、符咒套符咒，让规矩失去作用（通用套话与标点要求见 `short-craft.md`）。

## 配套结构公式（按篇幅选）

- **破戒惊悚型（8-12 节）**：立规矩 → 身边人破戒 → 首个代价应验（题眼依赖死亡时见首命）→ 尸象逐节升级 → 翻旧账（族谱 / 上辈孽债）→ 帮助者给法（有价）→ 卡时辰决战 → 债清物留。主角全程只犯一次错或不犯错，靠守规矩活到最后。
- **规矩审判型（6-10 节）**：白事现场规矩显形（哭丧 / 守灵 / 上秤）→ 恶亲戚逐个被清算，每人清算前先亮一宗世情罪（抢玉、拔金牙、藏私房钱）→ 主角以为自己无辜，或有亡魂指路 → 终反转翻主角自己的账 → 审判收口。爽点结构同复仇文，执行人换成规矩本身。
- **行当奇谭型（8-12 节）**：行当自报 + 铁规矩 → 接到异常一单 → 讲究罗列压场 → 异常升级牵出旧案 → 真相落在人心（人比鬼狠）→ 归行当收尾。冥婚 / 出马仙母题可走惊悚也可走脑洞温情，按平台调性选：七猫黑岩偏惊悚实锤，盐言可加大女主 / 温情浓度。
