# 题材风格包：沙雕脑洞

> 番茄 / 七猫 / 黑岩通俗短篇。先读 `short-craft.md` 通用底座，本包在其上覆盖该题材专属调性。
> 一句话定位：**沙雕喜剧与脑洞设定流：反套路解构、弹幕文、系统流、偷听心声、高概念一句话梗。笑点靠预期违背和人物一本正经地荒诞，脑洞靠「设定推到极致会怎样」。** 读者要的是「笑出声的爽」+「设定还能这么玩的惊喜」+「玩梗玩到最后突然给一口真情」。

---

## 叙述腔调

第一人称「我」用吐槽体全程主导，以**钝感吐槽压低情绪反应，一本正经地执行荒诞设定**。

- 天塌下来先接一句吐槽：主角遭遇再惨，反应永远比事件低一档。被反派魔头掐住脖子，出口是「不是，哥们你手劲怎么这么大，考没考过按摩师证啊」；看恶毒女配哭天抢地抢未婚夫，内心点评「这精神状态，不去演话剧真是屈才了」。
- 一本正经地荒诞：角色不知道自己好笑，严肃地执行离谱设定：在恐怖副本认真送外卖求五星好评，用家规教条收拾极品全家还引经据典。叙述时保持这份认真，不自评「好笑」。
- 现代话语错位：把打工人 / 甲方 / 画饼 / 业绩指标这套职场语言原样搬进修真、后宫、末世。例：在惊悚副本里感叹「这年头连鬼怪冲业绩都要搞末位淘汰了」；在宫斗戏里谢恩「打工人谢老板赏赐，祝您皇业兴隆，年底多发点年终奖」。
- 标点可以当台词：「我：……？」「少年：？」可独立成段。
- 弹幕 / 系统 / 心声都是有人格的说话者，别写成冷冰冰的信息板：会吵架、会怂、会磕 CP、会被主角气到死机。

## 开篇范式

导语先演示设定最好笑的用法（好坏消息对仗、系统对话、弹幕闯入），不藏梗。这就是正文已经发生的第一场；第 1 节接着写这个梗造成的新状况、选择或反应，用新的对话立住设定规则，不重演同一个梗。

| 开篇式 | 范例 |
|--------|------|
| 好坏消息对仗 | 好消息：我穿书后绑定了无敌系统！坏消息：系统绑错到了反派家的看门狗身上…… |
| 系统给 A/B，主角选 C | 系统问我要穿成受气包女主还是恶毒女配，我当机立断：「我要当发盒饭的围观群众！」 |
| 弹幕打断关键动作 | 我正提笔要签和离书，半空中突然飘过一排排大字：【别签别签！王爷表面冷着脸，其实私库房契全都写成你的名字了！】 |
| 高概念职业自陈 | 熬夜加班猝死后，我穿进无限流惊悚游戏里，成了一名受平台超时扣款约束的专职外卖员。 |
| 咸鱼身份 + 降格梦想 | 修真界底层外门炼丹师，五灵根废柴，苟了一百年，毕生最大的梦想就是攒够退休金去凡间盘个煎饼摊。 |
| 能力开局即翻面预告 | 直到看见丈夫书房里的假账本我才明白，原来这三年我听见的「装穷心声」，全是他和婆婆联手演给我看的杀猪盘。 |

## 钩子母题与密度

密度看设定能不能持续玩出新用法、新误解、新代价或关系变化；连着几节既没把设定往前推、也没抖出有效笑点时，再排查是不是停滞了。节尾钩子可以来自设定的新状况，也可以落在阶段性兑现或明确的下一步上。

- **设定推到极致**（核心母题）：一句话设定立住后，逐节问「这设定还能怎么用」，一次比一次离谱。例：外卖员能无视结界穿梭惊悚副本，就顺路帮无头鬼校长把掉在一楼的脑袋捎上楼（「校长，您的麻辣烫到了，顺便在楼梯口捡到了您的头，一起挂门把手上哈，记得给个五星好评」）。
- **信息差喜剧**：我知道你不知道（听心声 / 看弹幕 / 知剧情），错位反应制造笑点。高级版是双向反转：能力本身是局，对面知道你听得见，故意喂假心声。
- **反套路第三选项**：面对套路里的固定角色分工，主角拒绝进场。不当女主不当女配当路人甲；全网弹幕叫她远离反派，她偏要去抱反派大腿。
- **恶意顺从**：把规则 / 教条按字面执行到荒诞。系统要求「凡事顺从家人心意」，假千金妹妹哭喊「你干脆逼死我算了」，主角立刻认认真真替她联系哭丧队：「既然妹妹有此诚心，做姐姐的这就成全你。」
- **弹幕当活人配角**：弹幕分几股互相吵、预警、磕 CP、说虎狼之词，主角边看边被带节奏或反着来。
- **梗的本地化**：网络梗改造后嵌进情节，由设定长出来（如「吃人么」副本外卖平台，具体谐音改名见下方招式库）。
- **数字梗与计数器**：第九十九次翻牌子、功德值 +100、干满五百年享受定制化投胎服务。荒诞承诺配精确数字。

## 情绪烈度与模式（烈度 4）

**吐槽压着写，烈度让给反差**。

- 崩溃事件用流水账降格处理：我：「等等，我真不是同伙——」关门，拉响警报，送进治安署。行吧，至少今晚包住。
- 荒诞事实平静陈述，比惊叫好笑：睁眼就是钢筋水泥的废墟，三米高的变异蜥蜴正在啃公交车轮胎。我默默咽回起床气，扭头就跑。
- 倒霉写成自查流程：我翻了翻储物袋，空的；再翻一遍，还是空的。我想起来了，昨晚饿急眼，把师尊留给我保命的九转金丹当麦丽素嚼了。
- 真情或心动集中在关键处一两拍：平时用钝感吐槽降格，切入真情或甜宠直球反杀时当场收起吐槽、空白半拍，朴素写：这本破书的剧情是假的，可他替我挡下的那一剑是真的。
- 爽点段（打脸 / 反杀）可短暂拉到烈度 7-8，收梢回到吐槽泄压，打完接一句钝感点评。

## 对话风格与金句

对白在错位反应、弹幕和规则交锋场景可以密，设定演示与行动链可以少或没有；不设全文占比。短、快、口语。三类高频台词：

**① 一本正经的荒诞宣言（笑点本体）**
- 厉鬼大哥，您要掐我脖子能先扫码签收一下这单黄焖鸡吗？超时两分钟扣我五块钱呢。
- （继母冲进来扇我耳光，系统命我打不还手，我掏出新手礼包送的纯金“母慈子孝”铁匾挡在脸前，继母一掌拍肿手背）这匾是实心的，手骨再硬也硬不过咱家的家风啊。
- 皇上，既然姐姐说她昨晚梦见先帝托梦，那臣妾昨晚还梦见太祖皇帝让我掌管凤印呢，要不咱俩今晚请道士来对对账？
- 刺客大哥，绑架归绑架，能麻烦把绳子往上提一提吗？勒着我刚垫的硅胶下巴了。

**② 主角吐槽 / 接梗（钝感降格）**
- 不是姐妹，这男人连早餐煎蛋都要跟你AA，你为了抢他跟我翻脸？
- 不是，哥们你手劲怎么这么大啊……我感觉肋骨都要被你拍散架了。
- （皇上翻了我的牌子，我内心哀嚎）快说你奏折没批完龙体欠安，苍天啊，我今晚只想在偏殿烤红薯，真的不想加班侍寝啊！
- 穿成炮灰女配怎么了？虽然没继承到男主的爱，但继承到了男主给的五千万分手费，知足了。

**③ 弹幕 / 系统人格化台词**
- 【别看王爷现在板着一张死人脸，其实袖子里手心都紧张出汗了！】【装装装，接着装，再装媳妇真提桶跑路了！】【太甜了，快给朕拿点胰岛素来！】
- 系统瑟瑟发抖：【完了完了，宿主你把尚书府大门拆了，这怎么算温良恭俭让啊！】
- [我：……谈感情可以，先结一下出场费。] [系统：警告！再讨价还价扣光你的新手积分！！]
- 【女主快跑！这反派疯起来明天就会把你关进书房抄十遍《清心咒》！】我：……？

对话的权力标记与虐文相反：谁先绷不住谁输。主角靠不接情绪、只接字面意思掌控场面。

## 节奏骨架

```
导语亮高概念（把设定最好笑的用法先演一遍）
→ 第1节承接导语造成的新状况、立设定规则
→ 设定用法沿后果升级（同一设定可反复开发，但每次须改变用法、代价或关系）
→ 中段信息差反转（能力被反用 / 设定背后另有真相 / 弹幕情报有假）
→ 高潮：设定与主线宿怨相撞（副本 boss 是未婚夫；心声骗局当众拆穿）
→ 真情收口，或爽点落地后用一句吐槽泄压
```

疏密：设定演示与笑点段慢写足对话细节；过场和情绪一句带过。弹幕刷屏可连排 3-5 条不嫌多，解释性叙述越少越好。笑点之间不留超过一屏的干燥说明。

## 收尾范式

- 沙雕转真情：收起全部梗，集中写一次真情。例：皇帝坦白自己也是穿书者，她笑着回「臣妾早从你背不出古诗看出来了」，此前的插科打诨在这里显出两人相依为命的分量。
- 设定闭环：能力 / 弹幕在故事讲完时消失或回收。例：大婚礼成那一刻，半空中的弹幕渐渐淡去，属于我们自己的日子才真正开始。
- 反套路归于平凡：本该杀疯的角色选小日子。例：攒够赏银后我干脆利落地辞去女官差事，在江南盘下一间小茶楼过起了退休日子。
- 爽点收口 + 吐槽泄压：反杀完成后不煽情，用一句钝感点评落地（姐凭实力爆红了。／我可真是天选打工人。）。

## 该题材专属调校（与通用去 AI 规则的偏差）

这些在别的语境是 AI 味 / 水字数，在本题材是卖点，**别误删**：

- **网络梗与流行语**：保留，但要求化用不搬运。梗要嵌进情节、由设定长出来（「吃人么」平台是副本界的外卖软件；发疯台词是系统逼的），别让叙述者随口复读热词。原样整段抄流行语超过一句就是搬运。
- **标点台词与单字成段**：「我：……？」「少年：？」「行吧。」「关门。送警局。」保留，这是节奏，不算残句。
- **弹幕块【】连续刷屏、同款句式复读**：这是合唱效果，别当冗余合并或精简。
- **系统面板 / 规则列表的说明文腔**：保留，煞有介事的格式感本身是笑点载体，别改写成流畅叙述。
- **底座「情绪宁烈不温」在本题材反着执行**：保留吐槽体的克制钝感，只在集中写真情时放开情绪。

本题材额外要避免：解释笑点（梗抛完再补一句为什么好笑）、跳出视角总结人物性格、无信息量的口水吐槽连刷（每句吐槽必须带出新信息或新反应）、把钝感写成愤怒宣泄。通用套话见 `short-craft.md`，标点见 `short-format.md`，「我：……？」这类标点当台词照用。

## 配套结构公式（按篇幅选）

- **信息差型（弹幕 / 心声 / 知剧情，8-12 节）**：获得能力（第 1 节内完成）→ 第一次使用立规则 → 依赖升级、靠能力连收好处 → 中段双向反转（能力被反用 / 情报有假）→ 借能力完成当众反杀或误会大和解 → 能力闭环消失 + 真情收口。
- **高概念职业 / 穿书型（8-11 节）**：演示设定 → 三次升级使用（一次比一次离谱，各给一节）→ 设定与旧怨相撞（故人进入副本 / 原剧情追杀主角）→ boss 或幕后是旧识 → 翻面收口，留一句吐槽泄压。
- **恶意顺从复仇型（7-10 节）**：荒诞规则立起 → 逐个对象「字面满足」各给一节（每节一个可视化计数：功德值、热搜、赏钱）→ 对手识破规则想反用 → 主角用规则的最终解释权完成大招 → 规则来源揭底。
