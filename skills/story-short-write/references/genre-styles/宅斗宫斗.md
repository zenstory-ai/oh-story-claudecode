# 流派包：宅斗宫斗

> 适用平台：知乎盐言（古言权谋/大女主高热赛道）、七猫、黑岩、点众、番茄。核心卖点：**嫡庶尊卑/假千金夺位/贬妻为妾/守寡多年被弃 → 借宗法礼制、嫁妆实权、圣旨底牌或捧杀设局，把偏心夫君、毒辣白月光与吸血宗族一锅端**。

## 1. 读者爽点与核心人设标签

- **核心情绪账**：古代礼法越讲体面与尊卑，撕破虚伪面具时的爽感越烈！主角受尽苛待却握紧真正筹码（十里红妆嫁妆单、兵权/母族、御赐恩典、幕后操盘布局），一朝翻脸按家法宗规或圣旨狠狠清算。
- **主角标签**：第一人称「我」（守活寡多年的世子妃/被认回却遭嫌弃的真嫡女/冷眼看戏的掌家主母/从边关归来的女将军）。前段不哭闹失仪，看透后一句半文半白冷话定生死。
- **反派标签**：① **薄情夫君**（得胜归朝/高中状元就要抬外室或白月光做平妻，嫌糟糠妻粗鄙善妒）；② **白莲假千金/柔弱表妹**（满口「姐姐莫气」「妹妹愿做小」，暗地泼热茶、下药栽赃）；③ **势利婆母/偏心亲爹妈**（一边花着主角嫁妆，一边踩主角出身低）。
- **声线**：**白话为底、半文半白点睛**（用「六载」「明媒正娶」「抬平妻」「和离书」「以儆效尤」「恩断义绝」立住古言气场，但句式必须短平快、口语顺滑，严禁生僻文言堆砌和散文腔）。

## 2. 导语冷开场公式（150–300 字）

1. **年限锚+贬妻抬平妻式**：「替夫君守了六年活寡、拿嫁妆填平侯府亏空，他凯旋那日却牵着边关医女进门，当着满堂宾客命我自请降妾。」
2. **真假千金认回羞辱式**：「流落乡野十五年被认回侯府，春宴上假千金故意打翻滚茶哭倒在地，亲爹不问青红皂白抬手抽我耳光，骂我野丫头丢尽满门清流。」
3. **和离/圣旨底牌预告式**：「状元郎大婚迎平妻那日，我当众烧了婚书，抬走全府八成家产——他们不知道，这侯府能撑到今天，全靠我当年救过太后一命。」

## 3. 节奏骨架与 30%–40% 付费卡点设计

- **第 1 节（1,300–1,600 字，开局入局）**：寿宴/请安/凯旋宴等满堂宾客在场的公开场景，夫君与白月光联手施压（抢院子、扣嫁妆、逼敬茶、贬妻为妾），亲人全员拉偏架。
- **第 2 节（免费升级）**：白月光软刀栽赃（装烫伤、污蔑偷窃、假滑胎），夫君不信主角辩解直接动家法或禁足；主角暗中翻出账册或隔屏风撞破婆母与夫君吞嫁妆的真心话。
- **第 3–4 节（30%–40% 付费卡点）**：主角亲手剪碎/摔断定情信物，停止争宠，微笑交出掌家钥匙或应下「大度成全」——**付费点卡在**：白月光得意接手管家或逼主角跪递休书时，门外突然传来宫中传旨太监高唱/嫁妆掌柜当众亮出全府欠条！
- **第 5–7 节（40%–85% 借礼法与底牌连环清算）**：① 当众点清嫁妆一针一线抬走，掏空侯府门面让债主堵门；② 捧杀反制，坐看白月光不懂规矩在贵人宴上丑态百出、自毁名声；③ 亮出真正底牌（和离懿旨/亲王撑腰/自己才是手握重权的暗主），按宗法家规杖责恶奴、剥夺爵位。
- **第 8–9 节（85%–100% 抄家夺爵与火葬场收尾）**：侯府败落、假千金露馅被发卖、薄情夫君雪地跪拦马车追悔莫及，主角掀帘冷看一眼，头也不回奔赴荣华高位。

## 4. 反派压迫与 40%+ 连环打脸招式

1. **花着我的钱踩我脸**：全府上下吃穿用度全靠主角嫁妆贴补，嘴上还嫌主角一身铜臭；清算时把铺面地契和借款字据一抽，全府瞬间揭不开锅！
2. **信物当面损毁的物理爽点**：把亲手绣的香囊一剪两半、把定情玉佩当堂摔碎，动作干脆，彻底斩断旧情。
3. **以礼法压礼法（借刀杀人）**：不泼妇骂街，直接搬出嫡庶尊卑、宗族家规或皇家规矩——「妾室冲撞正妻，掌嘴二十，以儆效尤！」
4. **捧杀让情敌自爆**：表面大度把掌家对牌和重要宴席让给白月光，背地掐断老管事配合，让对方在太后/权贵面前捅出灭顶大篓子。
5. **圣旨/权贵降维打击**：反派正叫嚣主角下堂后无人敢娶，内侍捧着太后懿旨或镇国公聘礼跪满一院子，全场鸦雀无声。

**高频半文半白台词库（按需化用）**：
- 婆家/夫君踩踏：「你在乡野粗鄙惯了，怎配走侯府正门？」「她救过我的命，你既占着正室位，抬她做平妻你该感念大度才是！」
- 假千金/白月光软刀：「姐姐莫气，若一杯热茶能让姐姐消气，便是十杯妹妹也受着。」「我充其量是个外人，这就离府绝不碍姐姐眼。」
- 主角审判盖棺：「我是父母明媒正娶的嫡女，她不是；这侯府库房十有八九是我的陪嫁，今日一针一线，都得给我点清抬走！」

## 5. 清算收尾模板

- **十里红妆抬空侯府**：带着圣上恩准的和离旨意，连库房里最后一件陪嫁都装车抬走，留给婆家一座空壳破院。
- **夺爵抄家+雪地跪求**：渣夫被削爵贬庶，跪在城门外雪地里死死攥着断簪求回头，主角马车连停都没停。
- **自立登顶**：或改嫁真心敬重她的权臣，或执掌皇商/封一品诰命，侯府荣辱自此再无干系。

## 6. 原创真网感示范切片

### 切片一：导语 + 凯旋抬平妻炸弹（~225字）

替夫君守了六年活寡，我掏空十里红妆才填平侯府的烂账。
他得胜归朝那日，却当着满堂宾客牵起一位白衣女子。
「清欢在边关救过我的命，我已请旨抬她做平妻。」
「你占了六年主母之位，把正院和掌家对牌让给她，也算尽一份贤德。」
那女子怯生生福身，眼眶微红：「姐姐莫怪，我原不求名分，只是世子非要给我个体面。」
婆母立马冷哼：「听见没？别摆出一副妒妇嘴脸，丢尽侯府颜面！」
我低头看着满桌用我嫁妆银子置办的珍馐，忽然笑出声。
「好啊。」
「正院归她，侯府的十万两外债，也一并归她吧。」

### 切片二：信物摔碎 + 礼法反压（~220字）

次日请安，柳清欢故意将一盏滚茶泼在自己手背，尖叫着跌坐地上：「姐姐，我不过来奉茶，你何苦如此狠毒！」
谢凛一脚踹开房门，扬手就要扇我：「毒妇！你竟敢当众伤她！」
我没躲，反手一巴掌先抽在柳清欢脸上，清脆响彻正厅！
全场瞬间死寂。
谢凛目眦欲裂：「沈微，你疯了？！」
我慢条斯理擦净指尖，从袖中抽出一卷明黄圣旨高高举起，冷眼扫过跪了一地的奴才。
「睁大你的狗眼看清楚！」
「我是陛下亲封的郡主，她是尚未过门的野丫头——冲撞皇室宗亲，按律当杖责三十！」
「来人，给我按住往死里打！」

### 切片三：抬空嫁妆 + 雪地火葬场（~215字）

三日后，圣上恩准和离的旨意送进侯府。
我带了三十辆大车，照着当年的嫁妆单子，把侯府库房、铺面契书甚至正厅摆的紫檀屏风，一针一线全抬了个精光。
债主们闻风涌进大门，婆母当场急晕过去，柳清欢连夜卷走最后几件首饰跑了。
出城那日大雪纷飞，谢凛疯了似的拦在马车前，满眼血丝嘶吼：「微儿，我错了！我把爵位、把命都赔给你，别走！」
我掀开车帘一角，扔下那枚摔成两半的定情玉佩。
「谢公子，慢走不送。」
「侯府满门荣辱，自此与我再无干系。」

## 7. 流派专属禁区与雷区

- **禁把古言写成「红楼散文/考据论文」**：不要花大段描写建筑雕花、茶道礼仪、四季风景，所有古代细节只当「打脸道具」和「尊卑武器」。
- **禁主角只在心里默默决裂**：古代决裂必须有实打实的文书与仪式落点（当堂和离书、圣旨、抬走嫁妆单、杖责恶奴），否则不够解气。
- **禁混入现代网络热词**：除非明确走「古言穿书/脑洞」，主流宅斗宫斗保持干净干脆的半文半白口语，不掺「PUA」「CPU」「退退退」。
