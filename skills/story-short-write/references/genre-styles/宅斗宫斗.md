# 题材风格包：宅斗宫斗 / 古言重生

> 番茄 / 七猫 / 黑岩通俗短篇。先读 `short-craft.md` 通用底座，本包在其上覆盖该题材专属调性。
> 一句话定位：**夫君与婆家 / 父母为白月光 / 假千金牺牲主角（正妻 / 真千金 / 嫡女 / 糟糠妻）；主角撞破真相后和离休夫、净身出户或死遁重生，亮出底牌时，加害者已追悔莫及。** 读者要的是「被算计到底的窝囊」+「一纸休书 / 重生翻盘的扬眉吐气」。
> 子型：宅斗宫斗 / 古言重生（和离休夫 · 假千金夺位 · 白月光夺爱 · 年代重生 · 沙雕脑洞）。

---

## 叙述腔调

以受害者第一人称「我」全程主导，贴着体感和心跳写。撞破前隐忍委屈、为家族颜面把苦往肚里咽；撞破后切成冷静、居高临下的审判腔，一句话定生死。**文白夹杂是古言线的招牌声线**：用「嫁与」「六载」「明媒正娶」「割袍断义」「各自珍重」托住宫闱质感；年代重生线则用「员工宿舍」「家属房」「万元户」「的确良衬衫」等年代口语。两条线都可用成段宣泄独白和连环反问，**鼓励向前剧透「他后来悔疯了」的火葬场结局来吊人。**

开口就用带占有 / 身份关系的称呼：「我夫君 / 我丈夫 / 我的太子殿下 / 我老公」，外加一个时间锚（成婚第七年 / 认回侯府第五年 / 守了六年活寡）。

---

## 开篇范式

正文最前面先放一段**时间锚定 + 剧情与结局剧透的导语**：用「第 N 年 / 第几载」开篇，把背叛全貌、心死与「可他后来后悔了 / 重金悬赏寻我」一起剧透。第 1 节按导语停在哪里顺接或倒回，随行动补背景，不照抄导语原句（导语字数按 `设定.md`「平台基调」）。重生线先交代前世死法与凶手，再回到关键节点。

| 开篇式 | 范例 |
|--------|------|
| 时间锚定 + 背叛 | 和夫君成亲的第七年，他从边关带回了一个女子，是他的白月光。 |
| 守活寡年限锚 | 嫁与王爷六载，成婚当日他便披甲出征，我生生守了六年活寡。 |
| 认回 / 替嫁年限锚 | 认回侯府的第五年，假千金为了顶替我嫁入东宫，在春宴酒水里下药毁我名节。 |
| 第一句即丑闻炸弹 | 京城侯府出了桩丑闻：二公子在长兄战死后竟看上了寡嫂，逼正妻同日进门做平妻。 |
| 剧情与结局剧透 + 火葬场预告 | 状元郎大婚抬平妻进门当日，我留下一纸和离书悄然离京。可后来，他却散尽家财、举全城之力，红着眼四处打探我的下落。 |
| 重生反向送嫁开篇 | 重生回到议亲那天，我亲手把掌家对牌塞进表妹手里：「这侯府主母的位置归你，世子也归你。」 |
| 文白宫斗倒叙 | 我死在冷院的第三年，出征的夫君终于得胜归朝。他曾起誓要立下不世之功，求一道诰命圣旨给心上人至高的体面；可惜他来得太迟，连我的灵位都已落满了灰。 |

## 钩子母题与密度

密度极高：导语集中亮出背叛或算计，正文让算计、取证、决断和后果一路升级；连着几节局势都没动静时，再排查是不是停滞了。**阶梯式背叛：道德 → 经济 / 身份 → 生命（孩子）。**

- **白月光 / 假千金触发链**（核心母题）：夫君有个白月光 / 小青梅 / 义妹，或家里塞进个假千金，关键时刻全家偏帮她、牺牲主角。她们多用「娇弱委屈」当软刀。
- **偷听 / 撞破真相一次性砸**：密林、佛寺、茶馆里撞见夫君与白月光 / 假千金的真心话，连「当初的海誓山盟都是假的」全盘砸下，是心死导火索。
- **婆家 / 父母合谋**：不只渣男一人，公婆 / 亲生父母也知情包庇，「父母之爱子，则为之计深远，只是这个孩子不是我」。
- **信物当刀**：定情簪 / 玉佩 / 同心结 / 香囊被白月光抢走或被主角亲手撕毁砸碎，意义反转。
- **数字 / 年限承重再清零**：成婚七年、守寡六年、认回第五年、征战十年——堆出投入再一句话清零。
- **火葬场前瞻预告**：导语结尾提前透露对方日后的追悔，即读者等待的情绪兑现（重金悬赏、悔疯、亮底牌时人已走 / 已死）。

## 情绪烈度与模式（烈度 8）

爽虐双轨：撞破前直白宣泄 + 撞破后冷静审判（钝刀转冷刀）。纯虐重生支线（手刃薄情郎 / 死遁）可到 9。

- 直接命名情绪并加重：心如死灰、心如刀割、伤心欲绝、泪如雨下、心沉到谷底——通篇高频直给。
- 情绪可以直写；需要展开时用礼制、关系、选择或物件的变化承载，不逐句补动作。
- 心死后转冷反衬：审判时无波澜，连最毒的话都激不起情绪。

范例：

- 听见父母在屏风后商议让我替假千金顶罪，我心如刀割。
- 巨大的悲伤将我淹没，将这桩桩旧账翻到明面上时，我的心早已冷透。
- 怒火和心痛在胸腔翻涌，我鼻头一酸，抬手将那枚定情玉佩摔得支离破碎。
- 我和祖母在祠堂外紧紧相拥，泪如雨下，膝头跪在青石板上的剧痛远不及此刻锥心刺骨的悲凉。
- 我心如死灰，当着夫君的面将和离书投入火盆，转身走出侯府大门。
- 在父母眼里，假千金妹妹是侯府的锦绣前程，而我只是锦绣上的一处破洞。

## 对话风格与金句

对白在请安、审问、道德绑架和当众翻盘场景可以密，查账、布置与行动链可以少或没有；不设全文占比。口语、狠、半文半白，关键句可独立成段。三类高频台词：

**① 施害者 / 全家道德踩踏狠话（钩子本体，越理直气壮越好）**
- 你在庄子上粗鄙惯了，怎配顶着嫡女的名头走侯府正门？莫丢了咱们满门清流的人！
- 一个乡野长大的丫头，离表妹远些，仔细弄脏了她的苏绣衣裙。
- 你既伤了身子不能生育，她肯进门替你延续香火，你该感念她的恩德才是。
- 你在边关十年未曾回府晨昏定省，既不曾尽孝，这嫡女的院落自然该让给你妹妹住。

**② 白月光 / 假千金娇弱软刀**
- 姐姐，我知道同我一起进门委屈了你，你心中有气妹妹明白。只是一杯热茶而已，若能让姐姐消气，便是十杯、二十杯，我也愿意受着。
- 姐姐，我知道你不喜欢我，你与世子自幼定亲，我充其量就是个外人，我这就走，再也不会打扰你们。
- 不过姐姐能回府就好，以前那些误会，我从来都没怪过姐姐。

**③ 主角心死后冷静审判金句（半文半白盖棺）**
- 夫君若想去看顾妹妹，便去吧，不必再往我这院里跑了。
- （夫君带回的表妹仗势冲撞正室，女主按宗族家规当众处置）此人不循尊卑、冲撞主母，按家法杖二十，以儆效尤。
- 我是父母明媒正娶所出的嫡女，她不是；我是东宫册宝认证的太子妃，她也不是。
- 我累了，不愿再与你们纠缠血脉恩怨，自此割袍断义，各自珍重。
- 这侯府的体面你们自己留着享，我的嫁妆单子，一针一线都得当场点清抬走。
- 笑吧，多笑会儿，等圣旨到了前厅，你们就再也笑不出来了。

冲突靠对话长度反转标记权力易主：渣男 / 全家前期长篇贬损，主角后期一句话冷怼。

## 节奏骨架

```
时间锚定 + 剧情与结局剧透导语（含火葬场预告 / 前世死法）
→ 第1节按导语停处顺接或倒回，补足对话体感
→ 背叛沿因果链升级（道德→经济身份→生命）+ 白月光软刀栽赃
→ 偷听 / 撞破真相（连父母婆家也知情）
→ 心死定格
→ 信物撕毁 + 冷静审判 + 和离休夫 / 净身出户 / 死遁
→ 亮底牌强势回归 / 重生翻盘
→ 渣男追悔发疯 / 重金悬赏（火葬场）+ 金句盖棺
```

让新信息沿算计链持续兑现；节尾可落在新信息、局部反制、关系变化或明确的下一步，不要求每节同一种炸点。撞破、打脸、撕信物、亮底牌处详写慢放，过场按新信息价值压缩；单节长度服从该场职责。

## 收尾范式

- 火葬场反转：主角走后渣男后悔莫及 / 发疯 / 重金悬赏，主角已无波澜，对方的委屈也换不回关系。
- 亮底牌碾压：受辱者其实是摄政王 / 女王座上宾 / 万元户，强势回归把全家踩在脚下。
- 重生反向送嫁 / 死遁：把前世拼命争的丈夫房子主动塞回去，转身开新人生。
- 金句盖棺：一句反讽 / 审判定性收口，截图传播的高光。

范例：

- 重逢时，我已成了富甲一方的皇商，前夫却红着眼拦在马车前：「夫人，你当真不要我了吗？」
- 向来喜怒不形于色的小将军，却在城门外疯了般拦住我的去路，哑声求我再看他一眼。
- 他跪在空荡荡的正院雪地里，怀里死死护着我当年随手丢弃的半截断簪。
- 侯府满门的体面与荣耀，自此与我再无干系。

## 该题材专属调校（与通用去 AI 规则的偏差）

这些在别的语境是 AI 味，在本题材是卖点，**别误删**：

- **文白夹杂措辞**（嫁与 / 六载 / 明媒正娶 / 割袍断义 / 各自珍重 / 不循尊卑 / 以儆效尤）：古言宫斗的招牌声线，保留。别因为「像文言」就改白话，也别因为「像翻译腔」就删；年代线对应保留年代口语（家属房 / 的确良 / 万元户）。文白夹杂不等于堆砌生僻文言，仍以朴素为底。
- **信物撕毁的物理动作 + 主观定性**（亲手绣的，也该亲手了结）：保留，撕毁 + 心理落点是本题材的爽点本体。
- **沙雕脑洞子型的轻喜剧 / 网络化俏皮腔**：仅在该子型内放宽，可用反差 / 吐槽腔；主流宫斗 / 重生线仍走朴素中文，不掺现代网络梗。
- 情绪成语直写、导语向前剧透、审判金句收尾的保留边界，以及通用套话见 `short-craft.md`，标点见 `short-format.md`。

## 配套结构公式（按篇幅选）

- **宅斗宫斗 / 古言打脸型（8-12 节）**：导语剧透 → 1-2 节白月光 / 假千金软刀栽赃、全家偏帮 → 3-4 节撞破真相（父母婆家也知情）→ 心死定格 → 5-6 节撕信物 + 和离休夫 / 割袍断义 → 7-8 节亮底牌强势回归 / 渣男追悔被拒。审判台词半文半白、一句见血；觉醒是撞破那一瞬。
- **古言 / 年代重生型**：导语先交代前世死法 + 凶手（白月光夺位 / 假千金害死孩子）→「再睁眼」回到关键节点 → 做前世绝不会做的事（反向把丈夫房子送给白月光、决绝死遁、拒绝肩挑两房）→ 渣男 / 全家在底牌揭开时追悔莫及。全篇用第一人称；重生后步步算计、不再隐忍，爽点按顺序释放。
- **沙雕脑洞型**：离谱设定开局（系统绑定 / 先帝转世 / 全员演戏）→ 主角顺水推舟把规则玩崩 → 在轻喜剧节奏里完成打脸 / 翻盘。情绪烈度可降，用新反差、规则后果或关系变化持续推进。
