# 题材风格包：总裁豪门 / 现代言情虐

> 番茄 / 七猫 / 黑岩通俗短篇。先读 `short-craft.md` 通用底座，本包在其上覆盖该题材专属调性。
> 一句话定位：**豪门妻 / 联姻太太被丈夫为「白月光 / 小三」背叛，逐件物证坐实出轨，将主角折磨到心死；主角从发疯闹转为冷处理离场，也可借弹幕 / 系统 / 重生外挂获得「不必再舔」的清醒理由，最后净身出户、经济反杀，渣男追悔火葬场。** 读者要的是「被珍视感剥夺」+「道德绑架被一句话戳穿」+「清醒后扬眉吐气」。

与「追妻火葬场」共用白月光 / 偷听 / 心死 / 火葬场，突出写**渣男的道德绑架、逐件核验的物证、从发疯到冷处理的转变，以及外挂带来的清醒、豪门经济 / 身份反制**。

---

## 叙述腔调

第一人称「我」豪门妻 / 未婚妻全程主导，贴体感和心跳走，疼就说疼。开口带占有称呼：「我老公 / 我丈夫 / 我未婚夫」，并嵌豪门设定锚（集团、股东大会、联姻、恩情、京圈、继承权）。

前段常用**真发疯**宣泄委屈：当众开撕、网上对线、砸东西；撞破真相后切成**冷处理**，不闹、应一声「好」、看戏、记账，用大量反讽和吐槽延续情绪。

带外挂时多一条**吐槽声线**：弹幕 / 系统 / 脑海声音 / 重生记忆插话，帮主角作出清醒判断，也给读者爽点；口语、有网感、可以贱，别雅化。

允许并鼓励向前剧透「火葬场」结局来吊人。

## 开篇范式

正文最前面先放一段**结果倒序的导语**，把背叛全貌 + 心死 + 「可后来他后悔了 / 他疯了」一次性剧透；第 1 节按导语停在哪里顺接或倒回，补满对话体感，导语字数按 `设定.md`「平台基调」。本题材导语常多塞一层「外挂 / 身份底牌」当钩。

| 开篇式 | 范例 |
|--------|------|
| 灾难求救被道德绑架 | 我突发高烧哮喘给丈夫打急救电话，他却在慈善晚宴上替女伴挡酒，不耐烦地训我：「能不能懂点事，她第一次出席名流酒会，你装病抢什么风头？」 |
| 身份自陈 + 契约反差 | 结婚三年，外人都羡慕我是风光无限的豪门少奶奶，只有我知道自己是他拿来应付家族联姻的挡箭牌。 |
| 冷战分手后渣男普信通知 | 分手三年后，突然收到前男友的消息：「三年了也该消气了，今晚我回国你来接我，带上你爸妈，我们商量一下领证时间。」 |
| 物证开篇（明知过敏还送花） | 情人节收到丈夫同城闪送来的鲜花礼盒，里面却塞着一张买满三千才送的女士丝巾赠品卡——而我身上没有这条丝巾，而且他明知道我对花粉严重过敏。 |
| 重生 / 外挂自陈 | 重来一世，我刚在离婚调解书前坐下，眼前突然飘过几行弹幕：【别签净身出户！他昨晚刚把婚内海外信托偷偷转到了小秘书名下！】 |
| 豪门股权局开场 | 我住院病危后，集团立刻召开股东大会准备走股权交接。丈夫却带着一个二十岁的女孩出现，大言不惭地说当年其实我生的是双胞胎。 |

## 钩子母题与密度

密度极高：导语集中亮出背叛，正文让背叛、取证、决断和后果一路升级；连着几节关系和处境都没动静时，再排查是不是停滞了。**阶梯式背叛：道德 → 经济 → 生命**，本题材尤其爱把「经济」做足（集团、股权、继承权、净身出户）。

- **道德绑架链**（核心母题）：渣男把背叛包装成「你该大度 / 她可怜 / 你欠她 / 你该感激我」，越理直气壮越是钩。
- **白月光 / 小三触发链**：丈夫有白月光 / 小青梅 / 战友之女 / 学妹，关键时刻为她牺牲妻子；白月光用「娇弱委屈」当软刀，常配当众晕倒 / 见血反咬。
- **物证慢推坐实出轨**：干花 / 杯中倒影 / 香水味 / 一根头发 / 不该有的试用装逐件出现，读者陪主角一步步验证，钝刀更疼。
- **朋友圈 / 大屏配文当刀**：甜蜜配文 + 信物错位（主角送丈夫的表戴在白月光腕上 / 两人上了演唱会大屏），配文越深情，刀越钝越疼。
- **灾难期求救反被辱**：火灾 / 脑溢血 / 丧父时求救，换冷漠或「我在开会」「家属请回避」。
- **数字 / 年限 / 恩情承重再清零**：结婚五年、在一起八年、三年协议、用恩情绑架——堆出投入再一句话清零。
- **外挂给清醒理由**：弹幕 / 系统 / 重生 / 脑海声音，给主角「这次不舔」的依据，兼供吐槽。
- **火葬场前瞻预告**：导语结尾或男视角提前透露对方日后的追悔，即读者等待的情绪兑现（「他却在某个深夜，疯了一样砸开我的公寓」）。

## 情绪烈度与模式（烈度 9，双段：发疯 → 冷处理）

本题材心死开关有明确两段，烈度全程不降，只换形态。

- **前段（发疯 / 宣泄）**：直白命名情绪并加重，眼泪不争气、心如死灰；可以当众开撕、网上对线、砸东西。反应按人物与场景选择，不固定叠加身体细节。
- **后段（冷处理 / 审判）**：撞破真相后切冷，不闹、应一声好、看戏，用反讽、吐槽、记账延续烈度。心死后的平静反衬伤害：「这些话已经激不起我任何波澜」。
- 外挂带来的清醒，让后段冷得有理有据，不显突兀。

范例：

- 看见他签下那份把我母亲疗养院停药的授权书时，我的眼泪止不住往下砸，浑身冰冷。
- 我脊背发凉，指甲掐着掌心压住颤抖，拨通了那个没有备注的电话。
- 从那天起，我好像心不再那么疼了，心里某个地方彻底安静了下去。
- 我从一开始的歇斯底里，到后来连他彻夜不归都懒得问一句，甚至平静地帮他把行李寄去那个女人的公寓。

## 对话风格与金句

对白在道德绑架、权力交锋和当众翻盘场景可以密，核验证据与行动链可以少或没有；不设全文占比。口语、狠，关键句可独立成段。四类高频台词：

**① 施害者道德绑架金句（钩子本体，越理直气壮越对）**
- 你在公司群里乱发什么，知不知道她刚毕业心理承受力差，现在整个部门都在背后议论她！
- 出席家宴的时候收敛点脾气，别在董事们面前丢集团的脸。
- 一场阑尾炎手术而已，我让特助去签字，你别拿这种小事耽误我陪晚晚过生日。
- 逢场作戏而已，你占着总裁夫人的位置还不知足吗？
- 如今你家已经败落，圈子里除了我谁还愿意娶你，你应该感激我！
- 我在外面有人还不是因为你这个工作狂？你根本不关心家庭，没有尽到做妻子的义务！
- 作为主刀医生，我要避嫌，家属请回避。

**② 白月光 / 小三娇弱软刀**
- 对不起姐姐，都怪我非要拉着总裁陪我去瑞士看雪，害你们错过结婚纪念日了。
- 叔叔，这样不好，还是让姐姐继承公司吧，我什么都不懂……
- 你别怪他，他们男人就是这样粗心。他心里还是有你的，我只要能留在他身边当个普通秘书就够了！
- （当众装委屈，私下发彩信挑衅）姐姐守着一张结婚证有什么用，他昨晚可是一整夜都陪着我呢。

**③ 主角心死后冷静审判 / 反讽金句**
- 这世界上没有谁非谁不可！更何况三年过去了，我早已结婚生子。
- 脑子是个好东西，建议你出门前先找大夫看看。
- 我只有一个女儿。
- 你是当股东们瞎还是当我傻？当年产检建档和出生证明上只有我一个女儿。
- 想要位置可以，先把他挪用集团公款的那三千万窟窿补上。

**④ 外挂吐槽声线（弹幕 / 系统 / 心声，网感、可以贱）**
- 【快醒醒！别再拿你家的核心专利补贴这个白眼狼了！】
- 【这男主也太普信了吧，长嘴不如不长。】
- 【渣男配绿茶，天生一对锁死，别来沾边！】
- 系统提示：【检测到宿主已彻底放弃挽回渣男，离婚反击任务正式开启，奖励集团百分之十隐名股权！】

冲突靠对话长度反转标记权力易主：渣男前期长篇道德绑架 / 普信车轱辘话，主角后期一句话冷怼。

## 节奏骨架

```
导语（结果倒序 + 外挂 / 身份底牌 + 火葬场预告）
→ 第1节按导语停处顺接或倒回，补满道德绑架对话与体感
→ 物证慢推 / 灾难求救让背叛逐步坐实（道德→经济升级）
→ 偷听 / 物证齐全，真相全揭
→ 心死定格（开关从发疯切到冷处理）
→ 冷处理审判 + 净身出户 / 经济反制 / 亮身份
→ 渣男追悔发疯（火葬场）
```

让新信息沿利益和关系链持续兑现；节尾可落在新信息、局部反制、关系变化或明确的下一步，不要求每节同一种炸点。物证验证、道德绑架、当众反转处详写慢放，过场按新信息价值压缩。

## 收尾范式

- 火葬场反转：主角走后渣男后悔莫及 / 砸门 / 发疯找人，主角已无波澜或冷拒。
- 净身出户 / 经济反杀：签好协议递过去、掏空集团成全「负翁」、亮股权或 CEO 身份碾压。
- 转身改嫁 / 已婚生子：渣男普信归来才发现主角早结婚生子。
- 漠视收尾：应一声好、不再纠缠，比报复更狠。

范例：

- 直到我签好离婚协议，安静地消失在他的世界。
- 董事会上我亮出百分之五十一的股权代持协议，微笑着请这位前夫哥立刻腾出总裁办公室。
- 可后来我却听说他把那间空置的婚房反锁了三年，逢人便说他太太只是出差还没回来。
- 可后来，他红着眼眶翻遍了整座城市，再也找不到我回头的那条路。

## 该题材专属调校（与通用去 AI 规则的偏差）

这些在别的语境像 AI 味或可删冗余，在本题材是卖点，**别误删**：

- **道德绑架金句**：理直气壮、逻辑越离谱越对（「她心理脆弱你要大度」「我出轨是你工作狂逼的」）。别改顺、别加旁白替读者点破——读者要的就是看渣男自己说出口。
- **物证侦探式内心推理段**：放大照片、核对专柜赠品规则这类「自证不是多想」的独白，是把猜疑一层层推实的写法，别当啰嗦删；删了刀就钝了。
- **弹幕 / 系统 / 心声吐槽**：网感、口语、可以贱（「长嘴不如不长」），别雅化、别统一成书面语。
- **普信渣男的车轱辘话与重复**（「我娶的是你，她只是需要我照顾，你还要怎样」反复说）：是刻意的，体现 PUA 钝刀和主角的无力感，别当重复冗余砍。
- 情绪成语直写、导语向前剧透、审判金句收尾的保留边界，以及通用套话与标点要求见 `short-craft.md`。

## 配套结构公式（按篇幅选）

- **出轨坐实 / 不原谅型（8-11 节）**：1-2 节物证慢推 + 道德绑架（花 / 杯影 / 香水 / 头发逐件坐实）→ 3-4 节灾难求救被辱 + 白月光当众反咬 → 5 节真相齐全、心死定格 → 6 节开关切冷处理 → 7-8 节净身出户 + 经济 / 身份反制 → 渣男追悔被拒。全篇用第一人称；道德绑架要写得理直气壮，不写粗俗谩骂；觉醒可以在撞破那刻完成，也可以由外挂点醒，爽点按顺序释放。
- **外挂清醒型（弹幕 / 系统 / 重生）**：先交代前世死法 / 系统任务 / 重生节点 → 外挂上线给清醒与吐槽 → 主动做「上一世绝不会做的事」（把集团 / 白月光 / 名分主动送出去，或决绝拉黑离场）→ 渣男从普信到发疯追悔。外挂声线全程吐槽吊读。
- **豪门股权 / 身份反杀型**：开局股东大会 / 联姻 / 恩情绑架定局 → 渣男携私生女 / 白月光夺产 → 主角早已掏空 / 握底牌 / 真身份反转 → 当众图穷匕见后一击翻盘 → 漠视离场。
