# 短篇题材包：年代重生打脸

> 适用平台：七猫、点众、黑岩、番茄、知乎盐言。核心卖点：重生回七零/八零/九零命运分叉口（换亲、兼祧两房、冲喜、高考、西北调令），笑眯眯把「假宝真坑」拱手相让，凭先知、手艺与护短搭档发家登顶，坐看极品自跳火坑。

## 1. 故事线设计

- **核心情绪账**：抢吧，你抢走的正是上辈子害死我的大坑！不苦大仇深硬杠，而是手握前世全知视角顺势让坑，抓紧高考、调令、手艺变现或潜力股搭档起飞。
- **五段节奏与 35%–42% 付费卡点**：
  1. **第 1 节（1,300–1,600 字，入局让坑）**：前世惨死 100 字内痛透，立刻切回分叉口；埋一枚年代信物（铜顶针、招工表、西北调令信封、断亲红手印纸），痛快让出烂坑、选走看似倒霉的好牌。
  2. **第 2 节（免费升级）**：极品嘲笑主角傻、等着看笑话；主角借先知或真手艺（摆摊卖成衣、重启调令、放废申请表钓鱼）赚到第一沓大团结，先给上门占便宜的亲戚一记小打脸。
  3. **第 3–4 节（35%–42% 付费卡点）**：反派抢来的「好亲事」露裂缝，或寡嫂婆家设局逼交钱；**付费点卡在**主角带街坊邻里踹门抓奸实锤，或大队部/家属院门口伤愈归队的退伍兵/县委领导亲自撑腰亮底牌。
  4. **第 5–7 节（40%–85% 双向对照打脸）**：主角考重点大学、开厂成万元户、新家护短；反派落榜家暴、兼祧败露遭公社通报、吸血爹妈认亲被按断亲书轰出。
  5. **第 8–9 节（85%–100% 现场对照清算 + 回旋镖收尾）**：必须演当面重逢对照（坐桑塔纳回乡偶遇拦车堂妹，把旧铜顶针放回她掌心；或渣男伏法、吸血父母堵门被亮断亲书关门），禁靠外人来信草率播报下场。

## 2. 常见剧情设计

- **导语冷开场（150–300 字）**：前世死法 2–3 句痛透，立刻切「再睁眼」反常选择：
  1. **双重生换亲**：「上辈子我熬夜织毛衣供知青丈夫考大学，最后却被他和堂妹推进冰湖。再睁眼回到说亲这天，堂妹抢先扑过去抱住知青喊非他不嫁——我差点笑出声，没了我爹留的染织秘方，这货就是个家暴赌鬼。」
  2. **新婚兼祧/西北调令**：「新婚夜，丈夫为了给寡嫂留后，当众逼我签字同意兼祧两房，婆母还让我跪祠堂学规矩。我笑着把红盖头一扯，转头找老支书重启了去西北研究院的调令。」
  3. **拒冲喜/高考反杀**：「八三年高考前夜，亲妈为给弟弟凑彩礼偷烧我准考证，还要逼我嫁给冲喜公鸡。再睁眼回到交表那晚，真准考证早缝进了帆布包夹层，桌上留给她的只是我随手抄的废纸。」
  4. **感官恢复/信物错位识破**：无需死后重生，如阅读障碍或耳疾痊愈当天读懂情书原是写给白月光的道歉信，撕信重启八零高考。
- **中后段核心打脸招式**：
  - **双重生信息差反杀**：对手抢走主角前世富贵，却不知渣男前世全靠主角手艺与托举，没了血包立刻原形毕露。
  - **钓鱼抓奸 + 大队广播社死**：放假申请表或假存折引极品上钩，算准时辰带村口八婆与大队书记踹门抓现行，借大喇叭全公社通报。
  - **年代硬通货直打**：甩出凤凰牌自行车、缝纫机、一沓大团结、重点大学录取通知书、八十年代末桑塔纳，在全村围观下直观炸场。
  - **冷面搭档护短反差**：传闻伤退的退伍兵养好伤一身笔挺军装走出院门，当着吸血娘家把津贴存折拍进主角手里。
- **剧情红线**：禁「阿姨来信播报反派下场」草率收尾，禁第 8 节硬塞绝症虐恋换赛道；发家底牌与人脉须在前 3 节埋草蛇灰线；严守年代常识（77 恢复高考、78 年底后放开个体户、85 后量产桑塔纳）；前世苦限 150 字内，重生后绝不连忍五节。

## 3. 人物设计

- **主角定位**：被重男轻女压榨的长姐、遭双重生堂妹抢亲的姑娘、新婚夜拒兼祧的清醒新妇；重生一秒清醒、嘴利心稳，靠手艺、知识或调令实打实立身。
- **反派梯队与自私反咬**：双重生抢亲的堂妹/寡嫂（图坐享其成、算盘落空便造谣偷东西或抢存折反咬）、重男轻女吸血爹妈与恶婆母（打亲情孝道牌道德绑架、上门撒泼）、画大饼吃软饭的知青/凤凰男前夫；各有现实私欲，落魄仍会堵门闹事。
- **关系张力与口吻**：台词带鲜活干脆的年代俚语与烟火气；婆家、娘家与配角姓氏全篇严格统一，绝不前写林家后写沈家。

## 4. 正文技巧

- **视角与平台适配**：第一人称「我」为主；七猫/点众/黑岩用 `“”`、第一人称冲突标题与首节导语接 `……`，知乎用 `「」` 与短名。
- **叙事节奏与对话**：分家、抓奸与大队部对质直进引号短打，保留口语里的算账因果与年代烟火感，禁机械短句连拍，亦禁大段回忆冲淡当下爽感。
- **物件为刀**：年代元素必须直接服务冲突与对照（铜顶针、缝纫机、的确良衬衫、准考证、断亲红手印纸、津贴存折），不堆无关土墙煤油灯等年代风情贴纸。

### 避坑对照（烂写法 → 高分改写法）

- ❌ 烂写法：「年底姨妈寄来一封信，说冯建国早进了局子，堂妹穷困潦倒，我叹了口气，决定原谅爸妈。」（来信草率播报 + 圣母原谅，爽感归零）
- ✅ 高分改写法：「桑塔纳刚过镇口供销社，满脸淤青的姚玉兰扑上来拍打车窗哭喊：『姐，上辈子他明明发财了，怎么换我嫁他就天天打人？』我降下车窗，把那枚旧铜顶针放回她掌心：『上辈子撑起染坊的人是我，不是他。』」（现场双线对照 + 物件回旋镖闭环）

## 5. 案例片段

### 切片一：知青返城冷开场：苦等五十年后重生独自抽身（191字）

接到返城的调令时，知青丈夫只带走了两个人。
一个是我们的儿子周子彦，另一个则是他的白月光沈小琴。
儿子是他的骨肉，他不会让孩子留在农村受苦。
白月光是他的救命恩人，他要履行当年报恩的承诺。
唯独我，他说。
“同玉，咱们夫妻一场，等我安顿好了，就接你来城里和我们团聚。”
前世因为这句话，我苦等了五十年。
最后等到孤独终老、含恨而终，也没等到他的消息。
这一次，不等他安排，我便收拾好行李，独自离开。

- **学什么**：返城调令带走儿子与白月光、留原配一句空头承诺苦等五十年，重生零秒抽身不纠缠，年代痛点极准。

### 切片二：1988大院烟火感：给憨秘书亲爹当僚机（253字）

我爹是大院里的憨秘书，一辈子连一句我爱你都没说过。
我妈是文工团的台柱子，爱穿高跟爱洒香水，总说我爹就是个老古董。
他俩冷脸了一辈子，直到某天我回到了1988年，成了大院里收发报纸的小通讯员。
见老爹还在校对那份臭长臭长的发言稿，我直接抢了过来。
“陆秘书，今晚文工团汇演，你得穿上那件的确良衬衫去献花！”
我爹眼皮都不抬：“胡闹！明天省里要开大会，哪有闲工夫？”
我真是无语：“会是明天开，但未来媳妇要是跟人跑了，你就等着哭吧！”
“我可听说今天有个华侨，带了99朵红玫瑰和法国香水，要约李晓燕去吃西餐，准备表白呢！”

- **学什么**：文工团台柱子、小通讯员、发言稿、的确良衬衫与99朵红玫瑰自然融进冲突，年代轻喜活灵活现。
