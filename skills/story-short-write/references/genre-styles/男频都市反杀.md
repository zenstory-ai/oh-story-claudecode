# 流派包：男频都市反杀

> 适用平台：七猫（都市男频核心赛道，以第一人称与明账清算为主流）、黑岩男频、点众、番茄。核心卖点：**男主前期隐忍付出或手握实打实底牌（技术/账本/供应链/隐藏资方，亦可选退伍护短支线），惨遭拜金未婚妻、忘恩老板、势利岳家或背刺兄弟当众羞辱踩脸 → 一节内果断翻脸断供/甩铁证账单 → 全程冷狠不憋屈，靠真本事、硬合同与现实利益链碾压，让所有狗眼看人低者当众认栽求饶**。

## 1. 读者爽点与核心人设标签

- **核心情绪账**：**「压得极短、反击极快、杀伐极果断！」** 男频短篇读者零容忍窝囊受气——受辱绝不超过第 1 节，立刻甩协议、断供停账、亮出核心底牌，用实打实的工价账本、技术授权、人脉资源把势利眼按在地上摩擦。
- **主角标签**：**第一人称男「我」**（替小厂/家族公司扛了五年活却被踢出局的核心技术骨干 / 垫资跑车队、做汽修或包工却遭欠薪算计的实在老师傅 / 拿捏原始财务账本与大客户的实干主管 / 默默托举岳家却被嫌穷的隐忍女婿）。腔调冷硬、干脆、少废话，一句冷笑接雷霆手段。
- **反派标签**：① **拜金双标未婚妻/忘恩女老板**（拿着主角撑起来的利润养白月光小鲜肉，转头骂主角没出息）；② **草包关系户/嚣张富二代**（拿着主角的客户和钱装大款，当众羞辱主角）；③ **势利岳母/大舅哥/黑心包工头**（看碟下菜，见风使舵）。
- **声线**：短句、利落、爷们口语，**首对话极快（~60–70 字内即开口交锋）**，直给痛点与明细账目，少用空泛「战神/百亿」大词，多落到真实工价、欠条、合同和货款上。

## 2. 导语冷开场公式（150–300 字）

第一段直接砸下「量化付出 + 极致羞辱 + 当场断供/亮牌预告」：

1. **技术骨干被卸磨杀驴式**：「替妻子熬了五年通宵，把濒临倒闭的机械厂做到年产值过亿。庆功宴上，她当众把我的总工位置送给刚回国的白月光竹马，还把一万块甩我脸上骂我土包子——我笑着接过钱，转头给三大核心供货商发消息：『下月备件全停。』」
2. **蓝领/账本实业反杀式**：「替舅哥垫了三年工程款，跑废两辆货车，结算那天他却在饭桌上甩给我两万块打发叫花子，未婚妻还笑话我一身机油味配不上她——他们忘了，整套工地原始对账单和塔吊租赁合同，签的全是我一个人的名字。」
3. **退婚/势利岳家打脸式**：「婚礼现场，岳母拦住婚车临时加八十八万下车费，未婚妻挽着富二代冷笑：『掏不出就滚！』我当场撕了请柬，拨通银行信贷部发小和材料商电话：『苏家那笔三百万过桥贷我撤担保，明天收货。』」

## 3. 节奏骨架与 30%–40% 付费卡点设计

- **第 1 节（1,400–2,000 字，首章拉长，当场翻脸）**：前百字直接进婚礼/庆功宴/工地结算羞辱现场；反派加码踩脸、关系户拱火；**本节末尾主角直接完成第一轮止损反击**（撤担保、交工牌辞职、冻结副卡或锁死核心设备授权），绝不窝囊拖延！
- **第 2 节（免费升级）**：反派笃定主角在装腔作势，带着竹马和亲戚继续嘲讽、甚至动用小权势打压主角（拉黑行业、克扣尾款、炫耀新单子）；主角暗中调动真正底牌（原始结算单、婚前专利、核心客户群或对家老板高薪挖角）。
- **第 3–4 节（30%–40% 付费卡点）**：反派迎来最重要的一场大场合（验货签约/工程验收/寿宴/行业峰会），得意洋洋要把主角踩进泥里——**付费点卡在**：真正的大甲方或质检主管进门，反派满脸谄媚迎上去，对方却越过反派直奔主角，当众递上聘书或验收单喊出主角真实分量！
- **第 5–7 节（40%–85% 实力与利益链连环碾压）**：① 称呼瞬间翻转（从「穷打工的/废物」到「陈总工/陈老板」），围观人群三层震惊倒戈；② 供应链/资金精准抽薪：核心客户只认主角、生产线停摆、草包竹马算错账捅出巨额违约窟窿；③ 反派阵营狗咬狗，岳家与竹马互相推责撕破脸。
- **第 8–9 节（85%–100% 跪求冷拒 + 新局落地收尾）**：前任/忘恩老板破产追悔、堵在厂门口或雨夜求原谅；主角冷漠拒绝，账目清缴完毕、签下千万级新单，反派赔光家底或吃官司。

## 4. 反派压迫与 40%+ 连环打脸招式

1. **花我的钱装大款 + 当场停账社死**：绿茶男竹马拿着主角担保的信用额度在酒楼大宴宾客、嘲讽主角穷酸，结账时卡被冻结、货款催收电话当场打爆。
2. **核心资源抽离（离了我你啥也不是）**：老板以为订单全靠自己面子，主角一走，老师傅团队、核心图纸和上游供货商当天齐撤，三天就把公司打回原形。
3. **原始账本与合同实锤**：蓝领/实业线直接拍出盖红章的结算单、银行流水、质检报告与垫资收据，每一笔钱算到百位数，反派赖都赖不掉。
4. **权威称呼翻转 + 围观三层震惊**：路人傻眼 → 懂行老板惊呼「这批高精度件全城只有他调得出！」→ 原本踩主角的岳家/老板吓到腿软求饶。
5. **不废话直接走狠手**：报警查挪用公款、法院申请财产保全、上游断供追违约金，每一下都砸在反派最疼的钱袋子和面子上。

## 5. 清算收尾模板

- **当众清场+绝不回头**：前妻工厂被对家低价接盘，她声音发哑拦在车间门口求复合，主角头都没抬叫保安：「把无关人员请出去。」
- **阶层彻底拉开**：昔日踩主角的岳家和竹马因骗贷/欠薪吃官司或背一身债，主角站在新厂房窗前签下千万级新单，身边已有踏实并肩的新搭档。

## 6. 原创真网感示范切片

### 切片一：导语 + 庆功宴当场翻脸（~225字）

替妻子苏晴熬了五年车间，把濒临倒闭的盛华做到年产值过亿。
庆功宴上，她却当众撕了我的总工聘书，笑着递给刚回国的竹马林哲。
“陈默，阿哲留过洋，比你懂管理。”
“你去仓库看大门吧，别占着位置拖后腿。”
高管们一阵哄笑，林哲拍拍我肩膀：“默哥别多心，不懂的随时问我。”
我看着妻子冷淡的脸，笑了。
我摘下沾着机油的工牌，连同那本写满成本底价的工艺台账，一把拍在桌面报销单上，震翻两只酒杯。
“不用调岗，辞职信放你桌上了。”
“明早九点，全线数控机床的校模参数到期，密码只在我脑子里。”

### 切片二：核心抽薪 + 全场震惊反转（~225字）

第二天上午九点零一分，盛华六条产线全线报错停机，大客户催货电话打爆总裁办。
林哲盯着满屏红字冷汗直冒，折腾半小时连后台门都摸不着。
苏晴急疯了，冲进楼下早餐铺一把拽住我袖子：“陈默！你敢留后门？赶紧滚回去修！”
我咽下嘴里半个肉包，反手把一份专利证书拍在油腻的木桌上。
“看清楚，这套程序是我婚前独立写的。”
“以前免费借你用，现在不借了。”
门口停下一辆黑色轿车，业内最大汽配集团的董事长快步进门，当着苏晴的面朝我伸手：“陈总工，五千万订单和技术入股协议备好了，现在签？”
苏晴僵在原地，手里的豆浆杯“啪”地砸了一地。

### 切片三：破产跪求与冷狠清算（~200字）

半个月后，盛华违约金滚到三千万，银行抽贷、厂房查封，正式破产。
林哲卷走账上最后两百万跑路，半道就在高铁站被经侦拷走。
苏晴穿着皱巴巴的旧风衣，顶着大雨堵在我新厂大门口，扑通跪在积水里哭得嗓子劈叉：“陈默，我错了！厂子全靠你撑着，再给我一次机会！”
门卫刚要拦，我摆摆手走近两步，低头看她一眼。
“苏小姐，撕我聘书的时候，不是挺威风吗？”
“起来滚吧，别挡货车进院。”

## 7. 流派专属禁区与雷区

- **禁受虐超过 1 节（防憋屈毒点）**：男频读者最讨厌主角前四节一直在挨骂挨打还不还手！第 1 节必须亮态度或出手反击，第 3 节前必须让反派先吃一次硬亏。
- **禁悬浮口嗨装逼**：少靠「百亿/战神/黑卡」空喊压人，主角底牌必须落到实锤支撑（原始结算账本、婚前专利、真手艺、核心供货商与客户），每笔账都看得见摸得着。
- **禁心软吃回头草**：背叛过主角的拜金前任/忘恩老板绝不原谅、绝不复合，哪怕跪死在雨里也要冷漠走过。
