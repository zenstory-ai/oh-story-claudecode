# 题材风格包：追妻火葬场 / 虐恋意难平

> 番茄 / 七猫 / 黑岩通俗短篇。先读 `short-craft.md` 通用底座，本包在其上覆盖该题材专属调性。
> 一句话定位：**最亲密的人（丈夫 / 未婚夫 / 父母）为「白月光」牺牲主角，将主角一步步折磨到心死；主角冷静决裂离场，施害者后悔莫及，进入追悔火葬场。** 读者要的是「被珍视感的彻底剥夺」+「心死后的扬眉吐气」。

---

## 叙述腔调

以受害者第一人称「我」全程主导，贴着体感和心跳写：疼就说疼，心死就说心死。前半段用口语化的内心独白和反问宣泄委屈，撞破真相后切成冷静、反讽、居高临下的审判腔。**允许并鼓励向前剧透「火葬场」结局来吊人。**

开口就是带占有关系的称呼：「我老公 / 我丈夫 / 我未婚夫」。

---

## 开篇范式

正文最前面先放一段**结果倒序的导语**，把背叛全貌 + 心死 + 「可后来他后悔了 / 他疯了」一次性剧透，专卖追读；第 1 节按导语停在哪里顺接或倒回，补满对话体感，导语字数按 `设定.md`「平台基调」。

| 开篇式 | 范例 |
|--------|------|
| 关系+年限锚点 | 陪他从地下室打拼到上市敲钟的第七年，他在庆功宴上当众宣布把我的创始股份转给刚回国的初恋。 |
| 第一句即背叛炸弹 | 第一次发现丈夫和别人滚在床上，是在我们的婚房里。 |
| 身份+反差自陈 | 我是他结婚证上的合法妻子，也是他口中用恩情绑架婚姻的女人。 |
| 灾难求救被辱 | 老公怕我打搅他跟小秘书看演唱会，将我反锁在家里；厨房起火浓烟灌进卧室时，我打电话向他求救，只换来一句「能不能大度点」。 |
| 反差身份钩 | 直到看见他书房暗格里的旧照片，我才知道自己给他当了八年替身。 |

## 钩子母题与密度

密度极高：导语集中亮出背叛，正文让背叛、心死、抽身和后果一路升级；连着几节关系和处境都没动静时，再排查是不是停滞了。**阶梯式背叛：道德 → 经济 → 生命。**

- **白月光触发链**（核心母题，几乎每篇都有）：男人有个白月光 / 小青梅 / 前妻 / 义妹，关键时刻为她牺牲妻子。白月光多用「娇弱委屈」人设当软刀。
- **偷听 / 撞破真相一次性砸**：无意听见渣男和同伙 / 白月光的真心话，全盘真相一次性砸下，是「心死」的导火索。
- **灾难期求救反被辱**：火灾 / 地震 / 绑架 / 早产时向丈夫求救，换来冷漠或咒骂，一步坐实「他根本不爱你」。
- **朋友圈配文当刀**：渣男 / 白月光发的甜蜜配文被主角刷到，配文越深情，刀越钝越疼。
- **数字 / 年限承重再清零**：结婚七年、陪你十年、八年替身，堆出投入再被一句话清零。
- **火葬场前瞻预告**：导语结尾或男视角提前透露日后的追悔，即读者等待的情绪兑现（「我还不知道，他正发疯似的在国内找我」）。

## 情绪烈度与模式（烈度 9）

前半直白宣泄 + 撞破真相后冷静审判（钝刀转冷刀）。

- 直接命名情绪并加重：心如死灰、心彻底凉透、伤心欲绝、泪如雨下、如遭雷劈，通篇高频直给。
- 情绪可以直白浓烈；已有背叛与处境支撑时直接写，不固定叠加身体反应。
- 内脏 / 心脏拟痛：「巨大的悲痛在一点点啃食我的心脏，痛到不能呼吸」。
- 心死后转冷反衬：「这些话出自最亲密的人之口，却已经激不起我任何波澜」。

范例：

- 我的眼泪不争气地往下掉，分不清是委屈还是烧伤的疼。
- 即使早已心死，心脏依然狠狠抽痛。原来在他心里，我连白月光养的一只猫都不如。
- 随着他把偷拍我的病历照片扔在茶几上逼我给白月光献血，我的心也彻底沉到了谷底。

## 对话风格与金句

对白在伤害、心死和追悔交锋场景可以密，离开、取证和新生活行动链可以少或没有；不设全文占比。口语、狠，关键句可独立成段。三类高频台词：

**① 施害者道德踩踏狠话（钩子本体）**
- 她胆子小，一个人住急诊观察室会害怕。你不过是术后拆线，自己打车回去就行，老婆，你不会怪我的，对吗？
- 演得像一点，别在长辈面前丢我家的脸。

**② 白月光娇弱软刀**
- 对不起姐姐，都怪我非要让他陪我去看演唱会。

**③ 主角心死后冷静审判金句**
- 结婚七年，你连我对海鲜过敏都记不住，再在一起也没必要了。
- 如你所愿，我把位置腾出来了。
- 既然你觉得她那么离不开你，那以后我就不打扰你们锁死了。

冲突靠对话长度反转标记权力易主：渣男前期长篇 PUA，主角后期一句话冷怼。

## 节奏骨架

```
导语（结果倒序 + 火葬场预告）
→ 第1节按导语停处顺接或倒回，补满背叛经过的对话体感
→ 逐节背叛升级（道德→经济→生命）
→ 偷听 / 撞破真相
→ 心死定格
→ 冷静审判 + 净身出户 / 反击
→ 渣男追悔 / 发疯（火葬场）
```

让新信息沿背叛与追悔链持续兑现；节尾可落在新信息、局部反制、关系变化或明确的下一步，不要求每节同一种炸点。背叛、打脸、反转处详写慢放，过场按新信息价值压缩。

---

## 收尾范式

- 火葬场反转：主角走后渣男后悔莫及 / 发疯 / 求原谅，主角已无波澜或冷拒。
- 转身求婚 / 改嫁他人，当众完成关系翻转。
- 带孩子 / 带资产一去不归，开启新人生。
- 反讽对位：用渣男视角写他失去后的崩溃，漠视比报复更狠。

范例：我摘下婚戒扔进垃圾桶，绕开他们头也不回地走向机场安检口。／ 多篇导语定式收口：可后来，他却后悔了。

## 该题材专属调校（与通用去 AI 规则的偏差）

这些在别的语境是 AI 味，在本题材是卖点，**别误删**：

- **第一人称成段宣泄独白 + 连环反问**：保留，这是拉起代入与共鸣的主力写法。
- 情绪成语直写、导语向前剧透、审判金句收尾的保留边界，以及通用套话与标点要求见 `short-craft.md`。

## 时代变体（现代 / 古代 / 民国）

骨架不随时代变（虐、心死、决裂、火葬场照走），换的是身份词、背叛载体和离场的仪式。时代细节只做刀和道具，不做背景科普。

| 维度 | 现代 | 古代 | 民国 |
|------|------|------|------|
| 身份词与称呼 | 我老公 / 我未婚夫；总裁、白月光、小三 | 夫君 / 殿下 / 将军；正妻、妾室、外室、通房 | 少帅 / 大帅 / 留洋先生；发妻、姨太太、女同窗、名伶 |
| 背叛载体 | 朋友圈配文、转账记录、演唱会门票、恶意造谣 | 贬妻为妾、纳外室、装穷试妻、当众折辱护白月光 | 兼祧两房、假结婚证、拿新思想贬旧式妻子、送精神病院 |
| 决裂与离场 | 签离婚协议、拉黑、出国、转身改嫁 | 递和离书、进宫面圣求旨、远嫁和亲、随商队走大漠 | 骗签离婚协议、要求登报正名、出海远航、改嫁懂她的人 |
| 专属招式 | 朋友圈冷评论、审判金句 | 摔碎定情信物、拿圣旨礼法当武器 | 报纸舆论当刀、洋文方言当众打脸 |

- 古代的决裂必须有文书或仪式落点（和离书、面圣、当堂摔信物），只在心里决裂不算数。
- 民国的核心刀是新旧夹层：他拿「新思想」贬她（旧式包办、封建糟粕），她被时代当牺牲品；反击也借时代工具（登报、洋文、出海经商）最顺手。

范例：

- 现代：结婚五周年纪念日，我的丈夫包下全城大屏替刚回国的初恋庆生，而我独自在医院签下了流产手术单。
- 古代：陛下，五年之期已满，臣妇求您赐一纸和离书。
- 古代：嫁给江南首富之子八年，他一直对我哭穷，连我母亲病重抓药都说账上没银子，转身却在京城买下整座园林博外室一笑。
- 民国：外人面前他只唤我名字，却偏偏唤他那位留洋女同窗为「夫人」。
- 民国：酒会上他端着香槟对朋友嗤笑：「娶她不过是父母之命，你认为我一个接受过新思想的人会对旧式包办的女人感兴趣吗？」

## 流派分支（小三文学 / 死人文学）

两个分支共用「背叛」内核，各自的腔调和爽点兑现如下。

### 小三文学（正妻视角：发现、取证、捉奸决裂）

这一分支从头冷到尾：发现出轨后不哭不质问，表面如常，暗地取证，证据齐备后才摊牌。主角追求「智斗全胜」，渣男的哀求只作失败后果。

开篇用钥匙扣、短信、账单等反常小物撕开假面，迅速点破矛盾：结婚三周年那天，我在丈夫的车座缝隙里摸到一个私立月子中心的钥匙扣。我们明明没有孩子，可他却面不改色地说是同事落下的。我笑着点头，转头就开始查他的资金流水。

| 招式 | 怎么用 | 示例 |
|------|--------|------|
| 假面维持 | 知情后照常盛汤问工作，读者知她已布局 | 查出他给外室买房那天，晚饭时我照常给他盛汤：「项目谈得怎么样？」 |
| 物证链取证 | 逐件收集预约单、转账、监控、打卡记录，积累摊牌证据 | 私立医院的产检建档单，丈夫签字预付了八万定金 |
| 职业技能反杀 | 用本职当武器：法务写举报信、经商断财路 | 他挪用公司公款给第三者买豪车，我整理好全套审计底稿递交集团监察部 |
| 战场外包 | 让小三家属、舆论、公司规则替自己出手 | 把丈夫与同部门实习生的开房及转账记录同步寄给对方父母：「她的父母是我联系的，礼尚往来。」 |
| 原谅权收回 | 渣男代小三求原谅时当场掀翻 | 她开车撞我害我流产，谁允许你替我签谅解书了！ |

金句：你碰过她的手，别碰我。／在丈夫心里，他的红颜知己不能被坏了名声丢工作，而我这个妻子可以。

收尾：人财两空 + 主角事业新生，不写破镜重圆。镜像变体（小三视角忏悔流）：小三第一人称回看自己被渣男哄骗利用，少见，没把握别选。

### 死人文学（主角已死，灵魂旁观）

主角开场已死，第一人称灵魂跟着骨灰 / 遗物旁观。核心情绪是「来不及」：他后悔时一切不可逆。语气平静带自嘲，痛点靠细节不靠喊；全篇压强来自「说什么没人听见，做什么碰不到」。

开篇范式：第一句锚定死亡加时间，渣男不知道或不信「我死了」，信息差吊全篇。例：我死后的第三年，出征的夫君得胜归朝，还以为我在冷院里等着给他腾正妻之位。／急诊室盖上白布的时候，我的手机还在响，丈夫在电话那头骂我又拿装病骗他回家，可是他不知道我已经死了。

| 招式 | 怎么用 | 示例 |
|------|--------|------|
| 死亡信息差 | 渣男把死讯当卖惨伎俩骂 | 医院打去电话通知领遗体，他却在酒局上冷笑：「告诉她，这套装死争宠的把戏我早看腻了！」 |
| 无力干预 | 想抱抱不住、喊话没人听见，虐点全在旁观 | 看着年幼的女儿独自守在太平间外发抖，我多想再抱抱她，可我的手只能穿过她的肩膀 |
| 遗物遗体当刀 | 骨灰坛被摔、日记被迟读、生前信物被毁 | 我生前亲手栽在院子里的那株并蒂莲，被他下令连根铲掉，改种他心上人喜欢的牡丹 |
| 连累幼子旧仆 | 苦难转嫁到孩子或忠仆身上，死者灵魂只能干看着 | 女儿哭红了眼，跪在雪地里求他去见我最后一面，却被他一脚踹开 |
| 迟到的真相 | 渣男从日记、凶手、旁人口中得知真相，悔到发疯 | 他颤抖着翻开我锁在抽屉最底层的晚期病历本，一页一页看着上面的止痛药记录 |

金句：可惜他来得太迟了，我的尸骨都凉透了。／他……原来也会因为我死了而哭吗？

收尾是真相大白、渣男疯 / 跪 / 烧纸，死者仍无法归来。若用复活或重生改变结局，便转入重生线；保持灵魂旁观时，主角连离场都不能选，渣男要带着真相度过余生。

## 配套结构公式（按篇幅选）

- **现代追妻 / 不原谅型（8-11 节）**：1-2 节虐（伤害言语→行为→身体升级）→ 3-4 节心死离开（临界事件）→ 5-6 节真相 / 反转 → 7-8 节渣男追悔被拒 → 治愈 / 新生活暗示。全篇用第一人称；伤人的话要往痛处扎，不写泼妇骂街；觉醒只在一瞬间完成，爽点按顺序释放。
- **重生 / 死遁型**：重生线先交代前世死法与凶手，再回到关键节点，做「前世绝不会做的事」（主动把丈夫 / 房子送给白月光，或决绝死遁）；死遁线从决绝离场推进，两者都落到渣男追悔。
