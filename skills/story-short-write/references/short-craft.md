# 短篇写作通用方法

> 谁读：构思、写正文时主会话整份读。

> 适用于番茄、七猫、黑岩、知乎盐言等平台的通俗短篇。
> 写法要求冲突时：作者这次说的＞设定.md「文风约定」「作者已定」＞作者记忆里的习惯＞题材包＞本文件默认。文风改不了大纲事件、已知事实和字数范围。
> 本文件是默认写法；题材包（`genre-styles/`）的腔调、开篇与情绪烈度覆盖这里（如悬疑冷静克制）。冷门题材没有题材包，按本文件的默认写法，加上 设定.md「题材招式」记下的公式要点。
> **默认总原则：情绪宁烈不温。短篇是情绪产品，靠直白共鸣留人，不靠克制留白。**

---

## 1. 人称与腔调：第一人称主导，按题材定声线

- **默认第一人称「我」全程主导**。亲历视角让读者直接代入处境；他人视角只作**追悔、得意或视差的补刀短插**，不平分篇幅（允许第三人称的按题材包）。
- **虐爽类走双轨腔调，靠「心死」开关切换**（甜宠、沙雕、悬疑、民俗、双男主按题材包腔调，不硬套心死开关）：

| 阶段 | 声线 | 怎么写 |
|------|------|--------|
| 受虐段 | 直白宣泄 | 喊疼、喊委屈，眼泪不争气，心如死灰。成段内心独白和连环反问 |
| 反击 / 反转段 | 冷静审判 | 抽离、反讽、居高临下。见血、不铺陈，「呵」「我纯粹觉得你比较可笑」 |

- 「心死定格句」是切换枢纽：撞破真相后用一句独立成段的心死宣告（「那一刻，我的心彻底死了」），从委屈隐忍切到冷静决裂，后续行为全由它翻转。

---

## 2. 情绪落地：直接写情绪与利害算账，多种落点平级选用

情绪词与当下的利害盘算、内心吐槽可以直接写出，常见落法：

| 落点 | 示例 |
|------|------|
| 融进动作句作状语 | 听着电话那头她冷漠推卸责任的声音，我绝望地闭上了双眼。 |
| 当对话提示语 | 我无奈道：「那我只好起诉离婚了，理由就是你长期转移夫妻共同财产。」 |
| 情绪句到此结束，下一句直接换事 | 结婚这三千多个日日夜夜，大半的时间我都在内耗与崩溃里度过。第二天一早，我独自去了律所。 |
| 后接此刻手里、眼前的具体东西 | 看着桌上那份已经签好他名字的离婚协议，我彻底死心，拿起笔在女方栏签了字。 |

通用生理反应按功能取舍，不设次数上限。伤势、动作失败、人物习惯等有信息的身体细节可留；不在每个情绪词后固定接攥衣角、咬唇、鼻头一酸或指甲掐掌心。

**要删的两种：**

1. 脱离上下文、没有新增信息的空泛情绪总结句（「一丝悲伤涌上心头」「仿佛整个世界失去了颜色」），以及通用套话（映入眼帘、心中暗道、沉声道、嘴角微扬、目光如炬、不难看出、由此可见）。
2. 同一个情绪反复写、写完再补一句解释它多疼。情绪已成立就往下走。

---

## 3. 叙述姿态：在场叙述者

短篇叙述者可以**带着主观立场评论**，跳出当下定性、剧透、下判词或预告火葬场，让读者期待后续兑现。

- 留：第一人称主角的**主观审判句**（「原来我以为的爱只是一场笑话」）、**复仇者剧透勾子**（「他们不知道，我已经是西域摄政王」）、**火葬场前瞻预告**（「我还不知道，他正发疯似的找我」「可后来他后悔了」）。
- 删：真·中立全知摄像机腔——和角色情绪无关、纯交代背景的作者解说。

判断跳出当下的句子时，保留有具体对象、能强化追读的主观审判或预告，删除中立且无情绪作用的作者讲解。

---

## 4. 小节结构：每节围绕一个主问题

单节长度不设硬线，服从动作链是否完整；节尾按小节大纲「节尾停在哪」写（落点见 hooks-chapter「2. 节尾」），单场疏密见 `scene-craft.md`：

- **一节一变**：每节围绕一个主问题推进，让背叛升级、态度反转、读者新获知信息、行动或后果至少发生一项真实变化。
- **情绪落在家常细节**：委屈、心死、释然靠一两个日常物件或动作撑住（一顿饭、一件旧物、一通电话），前后呼应；账目和来龙去脉一节只给最要紧的一两条。
- **查证与急事受阻服务冲突**：打脸、世情篇取证最多占一节里的一段，当场拿来用（悬疑按题材包展开调查链）；急事受阻直接带出背叛升级或新信息，不空写排队办手续。
- **兑现当面发生**：打脸和反转让对手在场、当众拆穿，写足对方反应和围观变化；核对材料、报警、开会等程序只用一两句交代结果，不用公文通报腔。

---

## 5. 钩子：高密度推进，按题材拉满张力

- 导语塞进 3-5 个事件或反转，长度和第 1 节怎么接按 设定.md「平台基调」；正文让爆料、态度、行动或后果一路往前推，不必为逐节打卡硬塞阻碍。
- **虐爽与打脸类走阶梯式升级**：从道德踩踏到经济掠夺、再到害命，越揭越大；一页里敢叠多重雷（绝症骗局 + 当众拥吻 + 孩子药引…），别单点反复抒情。甜宠、沙雕、悬疑、民俗等非虐爽题材按题材包推进关系升温、反差笑点或异常线索，不硬造背叛。
- **爽点与期待持续前推**：每隔几拍就要让读者看到反打、行动、亮牌、升温或新线索，别久停在同一处情绪里打转。
- **虐爽类用当众围观放大羞辱与反打**：把背叛 / 打脸放在有外人见证的场合（宴席、股东会、群聊截图、请安），用众人的起哄 / 鄙夷 / 沉默放大屈辱与出气感；私密情感或悬疑拉扯按场景选在场人数。
- **共通钩子母题（题材包细化）**：白月光 / 小青梅触发背叛、偷听 / 撞破真相一次性砸、灾难期求救反被辱、朋友圈 / 物证坐实、数字 / 年限承重再清零、身份反差底牌、当众羞辱 + 反转倒计时。

---

## 6. 对话：按场景功能调节

- 对白驱动的关系博弈、审判和打脸场景可以密；抒情、心死、证据核验、手艺、等待或悬疑观察场景可以少或没有对白。全文不设占比目标，只保留会改变信息、策略、权力、关系或行动的台词。
- 虐爽类常用三类台词并靠对话长度反转标记权力易主（详见 `dialogue-mastery.md`）：① 施害者前期长篇道德踩踏 / PUA 狠话（越理直气壮越好）；② 白月光「娇弱委屈」软刀（对不起 / 都怪我）；③ 主角心死后一句话冷静审判冷怼。

---

## 7. 收尾：火葬场预告 / 审判金句 / 漠视离场

按本篇情绪与人物选择收口：

| 收口式 | 例 |
|--------|-----|
| 火葬场反转 | 主角走后施害者悔疯 / 悬赏寻找，主角已无波澜或冷拒（「你真的不要我和孩子了吗？」） |
| 审判 / 反讽金句盖棺 | 「迟来的深情比草还贱」「这七年的真心，就当喂了狗」 |
| 转身离场 / 净身出户 | 签离婚协议、改嫁、带孩子一去不归、亮身份碾压 |
| 漠视收尾 | 「那是他们的故事了，与我再无瓜葛」——比报复更狠 |

- 删：空洞哲理升华（「人生就是这样」「她终于明白了」）。
- 留：第一人称复仇预告 / 审判金句 / 心死余韵——这是读者截图传播的高光。

---

## 8. 句段节奏

- 手机阅读以短段、完整句为主，句子常在 20 字上下按意思停顿（动作串怎么连、碎句留给哪一拍见 `scene-craft.md`；标点见 short-format「标点」）。
- 三连排比（「在暴雨夜、在手术室门口、在我父亲的葬礼上」）：**有功能的递进 / 枚举保留**，只砍无信息量的纯修辞凑数。

---

## 9. 开头事件密度

开篇前百字迅速甩出核心冲突与处境。删掉背景介绍（「她是 XX 的女孩」「在古代 XX 年间」），第 1 句就是事件、对话、反常动作或信息炸弹，不写纯静态描述。

**虐爽题材的开篇第一段要砸下一个可量化、能截图的「命级 / 羞辱级」赌注**（甜宠、沙雕等题材包「开篇范式」另有写法时按题材包）——救命钱、被打掉的孩子、当众社死的实锤——不要慢热内心铺垫、不要单点反复抒情。赌注与细节要有**不可替换的辨识度**（具体到独特的数字 / 物件），别写换个名字就通用的桥段。

- 示例：我捐完半块肝脏从麻药里醒来，病房电视正直播丈夫携白月光出席慈善晚宴；护工递来他留下的信封，里面一分营养费都没留，只塞着一份签好字的净身出户协议。
- 选题里最狠的那一场（当众认亲、对质、出事那一刻）可以直接拿来开场，主角之前的布局、来历用倒叙补；别按时间顺序从头铺到高潮。
