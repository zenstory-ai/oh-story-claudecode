# 短篇正文格式

> 谁读：写正文、精修时主会话整份读；交给写手时，主会话把本文件与 设定.md「平台基调」的要点摘进 prompt。

> 只管硬格式：小节标记、段落、对话、字数统计、标点、书级白名单与工程词。用户或平台明确的交付要求优先；情绪、钩子、反转与收尾按 `short-craft.md` 及题材包。

---

## 小节标记

全文统一一种，不混用。用哪种、引号用哪种，按 `设定.md`「平台基调」；没记时沿用 `正文.md` 已有的写法，还没有正文就用 `###1.` + `""`。

| 格式 | 示例 |
|------|------|
| `###1.` | `###1.` `###2.` `###3.` |
| `###第N章` | `###第一章` `###第二章` |
| `1.`（纯数字，无 `###`） | `1.` `2.` `3.` |

---

## 段落：两套模板

按平台选择段落形态，再按 `short-craft.md` 分配详略。**不设统一的「每段 ≤ 3 句」「800-1500 字 / 节」硬线**，各节长度服从其内容。

### 黑岩：一句一段，留白快读

- 一句一段为主，靠频繁断行制造下坠和停顿感（段间仍只留一个换行符 `\n`），单句成段是常态，不焊回长段。
- 小节体量偏小；节尾可用未完成动作、新信息、局部兑现或明确下一步承接，不强制每节另造悬钩。

```
###1.

我们家有个规矩，每年清明节都要拜"福祸盘"。
一个盘子，一半装着山珍海味，一半盛着清汤寡水。
哥哥抽中了肉，爸妈奖励他一个大红包。
轮到我，我再次抽中了那碗清汤。
```

### 番茄 / 七猫：短段为底色，叙述交织对话

- 短段为底色，**允许多句回溯叙述段和对话交织**（古言 / 世情可写更长叙述段承载情绪链）。
- 一段只写一件事（一个动作链、一句话加反应、或一层信息，九成段落在 36 字以内）；爽点、打脸、反转处压短（可单句成段），过场一句带过。

```
###第一章

我把热汤端到他面前的时候，他正低头看手机，屏幕亮着白月光的名字。三年了，我以为熬过了最难的日子，原来熬的只是我自己。
"以后这种事不用你做。"他头也没抬，"她不喜欢闻油烟味。"
我端起碗转身倒进了水槽。
```

### 两套共同的硬约束（所有平台）

- **单换行无空行、无缩进、禁正文 Markdown**：相邻段落间只允许一个 `\n`（禁 `\n\n` 空行）；不用全角/半角空格缩进；小节标记外不用 `**`、`*`、`#`、`---`。
- **长短交错**：忌把每段切成同一字数。

## 对话

### 引号

按 `设定.md`「平台基调」，没记时默认半角 `""`；知乎盐言或用户指定时用 `「」`，全篇统一。

### 规则

1. 对话**独立成行**，不嵌在叙述段落里。
2. 少用「他说」「她道」「他笑了笑说」，改用顺手动作带出，不为省标签硬配挑眉、顿手；普通的「说」按语境可留。
3. 两人连续对话省略标签，靠内容区分说话人。
4. 台词贴合身份与处境：争执、求人、翻脸时短促带口语，打趣、试探或古言机锋按题材包。查账、维权、走程序时别说「请核实授权」「请在邮件里说明」「我需要书面材料」这类公文话，换成当面追问或狠话；程序结果在叙述里一句交代。

```
✅ 正确（对话独立成行）：
她把杯子放下。
"你走吧。"
他没有动。
"我说，你走吧。"

❌ 错误（对话嵌在叙述段里）：
她把杯子放下，说道："你走吧。"他没有动，她又说："我说，你走吧。"
```

## 字数统计

整篇字数只认交付检查（`scripts/check-delivery-contract.js`）报的非空白字数，不自写计数，不要模型估算。要找哪节明显偏短时，用下面的命令逐节报非空白字符数：

```bash
for PYBIN in python3 python py; do "$PYBIN" -c "" 2>/dev/null && break; done
"$PYBIN" -c "
import re
from pathlib import Path
pat = re.compile(r'###\s*\d+\.|###\s*第[一二三四五六七八九十百千万两〇零0-9]+章|\d+\.')
cur, buf, out = None, [], []
for line in Path('正文.md').read_text(encoding='utf-8').splitlines():
    if pat.fullmatch(line.strip()):
        out.append((cur, buf)); cur, buf = line.strip(), []
    else:
        buf.append(line)
out.append((cur, buf))
for name, body in out:
    n = len(''.join(''.join(body).split()))
    if name is not None or n:
        print(name or '导语', n)
"
```

分布只用来定位异常节：某节明显短于相邻节时，回大纲核对该节批准的情节点、动作和后果是否已经写完；写完就保留，不为拉齐长度补戏。

先按上面的 `python3→python→py` 探测可用解释器，避免直接调用 Windows 的 Microsoft Store 占位程序；禁止用统计字节的 `wc -c`。交付检查跑不了时声明“未完成机器字数验证”，不得声称通过。

## 标点

标点跟着语气走，不当装饰：先判断这句话在场景里做什么，再选句号、逗号、问号、感叹号或冒号。本节是短篇标点的唯一出处，题材包和别的文件只指到这里。

- `——`、`—`、`--` 不用；`……` 只留在引号里，给人物说话的犹豫、打断，叙述和心理描写不用。标点脚本照这条整理。
- 作者在 设定.md「文风约定」明确允许的写法照文风，登记见下方「书级白名单」；题材范例保留原文标点，落到正文时按本节改写。

| 语气 / 功能 | 可用标点 | 怎么连 | 禁忌 |
|---|---|---|---|
| 压迫 / 冷静 / 克制 | 句号、逗号、冒号 | 动作和判断用逗号接成一句，冒号落判断 | 不人工加感叹号，也不通篇句号化 |
| 质问 / 反问 | 问号、逗号 | 关键问题用 `？`，追问接在动作或上一句后面 | 别每句都以 `？` 结尾 |
| 爆发 / 打脸 | 少量感叹号 | 前因用逗号铺进同一句，峰值落句末；连续爆发最多 1-2 处 | 禁 `!!!`、整段喊叫 |
| 犹豫 / 未说完 / 哽咽 | 对话里 `……`、逗号 | 话里的吞吐用 `……`；叙述里用逗号接上停手、改口 | 叙述里不用 `……` |
| 被打断 | 对话里 `……`、动作 | 话收在 `……`，接一句截断它的动作（“他抬手截住她的话。”） | 不用破折号 |
| 信息揭示 / 判断落点 | 冒号、句号 | “证据只有一个：门锁从里面扣上了。” | 别写论文式分号串 |

## 书级白名单 `.deslop-whitelist`

检测器不懂作者意图。作者明确采用、有功能的写法被报警时，登记在书目录（`正文.md` 所在目录）下的 `.deslop-whitelist`：

- UTF-8，一行一个原文字面片段；空行和 `#` 开头的整行忽略；不支持正则或通配符；不向父目录找，不跨书继承。
- 对话里的 `……` 本来就能用，不用登记；本书文风明确允许破折号或引号外省略号时，才登记 `——` 或 `……`。具体修辞登记允许保留的完整原句，不登记「不是」「没有」这类泛词来关掉整类检查。
- 每项上一行写 `# 来源：…；用途：…`，注明作者哪次要求或文风哪一条。只为执行作者已明确的选择登记，不因脚本报警自己放行；作者这次禁止某写法时删掉相冲突的条目；一次性保留只登记那一句。
- 深扫、标点整理和写后检查读同一份白名单。豁免只影响对应片段的写法检查；事实、字数、占位、工程词、截断和文件结构检查照查。

## 禁正文混入章节元信息

章节号、写作工程词只允许出现在标题 / 小节标记 / 文件名 / 追踪记录里。正文叙述、对话、心理描写中**不得出现**：

```
第[一二三四五六七八九十百千万两0-9]+章 | 上一章 | 上章 | 前一章 | 本章 | 这一章 | 前文 | 后文 | 伏笔 | 细纲 | 读者
```

要改成角色能感知的事件锚点或相对时间。例：「比第一章那三秒开火更疼」改成「比那三秒开火更疼」。

例外：角色在故事世界内真实阅读 / 讨论「第 X 章」文本，或角色真实身为作者 / 读者并谈论读者身份时，可保留。

## 写完每段快速检查

- [ ] 段落形态贴合目标平台（黑岩一句一段 / 番茄系短段交织叙述），长短交错？
- [ ] 相邻段落之间只有一个 `\n`，没有 `\n\n` 空行？
- [ ] 对话独立成行、引号统一（盐言 `「」` 合法）、标签不机械？
- [ ] 没有缩进空格？
- [ ] 正文内没有 `**`、`*`、`#`、`---` 等 Markdown 符号？
- [ ] 标点符合本文件「标点」规则（破折号禁用，`……` 只留引号内）？
- [ ] 正文没有混入 `第N章` / `上一章` / `本章` / `前文` / `后文` / `伏笔` / `细纲` / `读者` 等元信息词？
