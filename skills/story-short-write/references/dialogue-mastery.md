# 对话设计操作手册

> 谁读：写手写或改正文、本章有对话时读副本；短篇写作读自己的副本。

> 按角色关系、场合和目的选择写法。

---

## 什么时候读这份

| 你的对话场景是 | 用这种模式 | 操作 |
|-------------|---------|------|
| 主角碾压/打脸 | 压制模式 | 对方长篇大论 → 主角简短回应 |
| 主角亮底牌/反转 | 反转模式 | 对方嚣张 → 主角一句话事实 → 对方沉默 |
| 关系破裂/心死 | 心死模式 | 对话越回越短：从辩解 → 沉默 → "随意" |
| 日常互动/立人设 | 日常模式 | 借活计、习惯反差或打趣互动，不让主角独白 |
| 群众震惊/弹幕 | 弹幕模式 | 递进：普通人震惊 → 专业人士分析 → 特殊身份者反应 |
| 信息展示/世界观 | 信息嵌入 | 用角色语气带出信息，别生硬念设定 |
| 情绪拉扯/虐心 | 情绪推动 | 上行下行交替，像拉锯拉升期待 |

### 对话模式选择补充

| 对话类型 | 常见问题 | 修正操作 |
|----------|---------|---------|
| 问答式 | 通篇一问一答像审讯 | 让一方主动说，另一方通过台词、动作或心理作出回应 |
| 冲突式 | 语气与矛盾程度不符 | 按处境选择委婉拒绝、命令、操控或直接侮辱 |
| 日常对话 | 无信息或关系变化 | 用互动展示人物，删去无效寒暄 |
| 多人对话 | 人物功能和说话人不清 | 写前明确谁提供信息、加剧情绪或制造冲突 |

## 对话核心规则

一段对话至少承载以下一项，都不承载就删，或用叙述带过：

1. **推进剧情**：透露新信息、推动事件发展
2. **增加期待感**：暗示即将发生的事、制造悬念
3. **展示人设**：通过语言风格传递角色性格

到了情绪紧绷处，每句台词都要**接住上一句的情绪**（顺接、岔开、顶回或退缩）；只顾轮流报信息、没有情绪拉扯，读着就像审讯笔录。

### 绝对禁止

| 禁止 | 理由 |
|------|------|
| 配角无脑夸主角 | 缺少立场与事实依据 |
| 互相解释读者已知信息 | 水字数 |
| 大段说明文式对话 | 对话停止交锋，只剩讲解 |
| 所有角色说话方式一样 | 遮住名字便分不出说话者 |
| 无依据便被说服 | 转变应有新信息、利益或处境变化支撑 |
| 情绪无故转向 | 转向前要有触发的事或话 |
| 捧哏工具人、鹦鹉复读对方原话 | 配角只剩接话功能 |
| 高位者长篇自证、说话不分场合 | 身份和处境塌了 |
| 情绪水肿咆哮、生死场景嘴碎 | 越吵越不紧张 |
| 悬念正攒着就被台词说破 | 期待提前泄掉 |

## 权力博弈对话

对话长短能体现主动权：掌局者只给结果或事实，被动者急于解释或叫嚣。

### 压制模式（对方倚老卖老施压 → 主角用已落地的处置一句封死）

```
老掌柜拍着账册冷笑："你才接手铺子三天，账房、伙计哪个不是我带出来的？没我点头，你连库房门都进不去，还敢查我的账？"
少东家合上账本："库房卯时就换了锁，周账房刚把你那本私账交出来。"
```

### 反转模式（对方仗势叫嚣 → 亮出他依仗的筹码本在主角手里）

```
小姑子晃着购物袋："我刷我妈给的副卡买个包，花你这当嫂子的一分钱了？轮得到你管？"
"你妈给你那张副卡挂在我主卡名下，十分钟前停了。"
```

### 心死模式（已撞破真相，不再接对方借口，回话越缩越短）

```
丈夫追到玄关解释："妈病危那天我是真碰上急诊会诊，不是故意留你一个人签手术单。"
"嗯。"
"你不信我现在调排班表给你看，真不是为了去陪她。"
她把签好的离婚协议放上鞋柜："随意。"
```

- 亮底牌直接给出改变局势的事实；被动方的处境靠辩解、失态或沉默呈现，不按字数硬分话轮。

## 潜台词与说话目的

### 潜台词规则

- 潜台词是「心里真想达成的事」与「嘴上借用的由头」之间的落差：动笔前先想清角色心里图什么、嘴上拿什么话开口；坦白、求救、紧急告知可直接说目的。

### 说话目的与各自盘算

每个角色开口都有自己的盘算：想从这场对话里拿到什么，又想藏住什么。

- **对手交锋与套话博弈**：各自护底牌、抓破绽，把试探藏在顺口闲聊里，算盘撞在一起才有交锋。
  - ❌ **改前（直白捅破目的，一上来就吵穿）**：妻子发现丈夫发来的酒店照片酒杯上映出女人身影，立刻打电话质问：“你酒杯里映出来的女人是谁？你是不是借出差在外面有人了？”丈夫矢口否认，两人大吵一架再无下文。
  - ✅ **改后（借家常话藏住试探，逼对方自己露馅）**：妻子看清酒杯里的长发倒影，拨通电话只笑着打趣：“哟，一个人在国外还摆两只酒杯过节呢？”丈夫得意哄她：“酒店送的欢迎酒，我后天一早就飞回来陪你。”可挂断没两分钟，做贼心虚的丈夫就撤回照片，连夜回电改口：“老婆，这边会提前开完，我明早就飞回来陪你。”（不点破照片破绽，用顺水推舟的闲聊逼出他撤照、改口的心虚动作）
- **同立场、熟人日常与暧昧升温**：不靠套话算计，而是把不好意思直说的关切藏在公事由头、嘴硬心软（嘴上嫌弃，实则替对方挡难处、递台阶）或手头活计里；也可借脑回路错位制造轻喜反差（如导演示意炒CP，嘉宾认真回“粉丝让我讲高数题”），避免两人顺着同一句意思来回复述。

### 语气由三要素决定

人物关系、说话场合和开口目的，三样合起来决定口气：

| 场合 | 特点 | 适合内容 |
|------|------|----------|
| 私人（单对单） | 深入、感情流露透彻 | 内心剖白、密谋、表白 |
| 公众 | 需顾体面，措辞收敛 | 要冲击力时可打破（如当众翻脸） |
| 熟人（朋友/同门） | 深度居中 | 轻松互动和信息交换 |

私密的话在公众场合说才有冲击力。对话外的信息靠动作、神态、环境补足。

## 情绪推动对话

### 强情绪对话

- **命令式+否定式施压**：“我说的还不够清楚吗？”（适合上位者强压或翻脸）
- **裹着关心外衣的嫌弃（适合写偏心亲人或伴侣道德绑架，让人憋屈窝火）**：
  - ❌ **改前（脸谱化叫骂）**：“你这个自私恶毒的姐姐，快把保送名额让给你妹妹！”
  - ✅ **改后（句句讲体谅，句句逼人让步）**：母亲叹着气拍她的手：“妈知道这名额是你熬三年挣来的，可你妹妹身子弱经不起复读，你从小最懂事，总不能眼睁睁看她钻牛角尖吧？”
- **直接否定（适合在主角真心付出后一刀斩断指望，比含蓄暗示更伤人）**：主角冒雨送去熬了一夜的药，对方只扫了一眼：“倒了吧，闻着犯恶心。”

### 情绪连续性

情绪转变要有触发依据。新证据、决定或关系变化可以造成骤变；没有触发便突然改变态度时，补清原因，不强行写满每一级情绪。

### 情绪与行动的因果检查

1. 遇到事件（失衡状态）
2. 情绪反应（可以直写，也可以体现在语言、选择或有功能的动作中）
3. 内心思考（只写影响理解的判断；鲁莽可以直接体现在行动里）
4. 采取行动（基于前三步结果回应）

用于检查转变是否成立，不要求逐步写满；上下文已清楚的反应或思考无需补写。

## 信息展示与世界观引出

- 大量信息通过对话展示会显得啰嗦，部分信息转化为情节、心理描写、旁白、环境、动作
- **角色不当"科普嘴"**：按角色当下的语气、立场和知情边界带出信息，用到哪带哪点，不生硬念设定或讲全前因后果；熟人之间不互相科普双方早知道的家事或行规

### 信息拉扯示例（以"主角新书起飞了"为例）

| 角色 | 台词 | 功能 |
|------|------|------|
| 甲 | 后台首订数据刚出来。 | 悬念拉期待 |
| 乙 | 就他那冷门题材，能破五百都算烧高香！ | 下行唱衰 + 拉大反差 |
| 甲 | 你凑过来数数首订那栏后面的零。 | 上行推高期待 |
| 乙 | 首订……一万三？！ | 亮出核心数字 + 达成爽点 |

上行和下行交替，情绪像拉锯不断拉升期待。

## 人物语言差异化

每个角色都要有贴合身份与性格的说话方式：

| 差异化维度 | 操作 |
|------------|------|
| 惯用语 | 有身份或经历来由才给，不给每人硬配口头禅 |
| 说话节奏 | 长篇大论 vs 短句连击 |
| 信息偏好 | 技术型带专业术语，江湖人带切口 |
| 立场固定 | 某角色永远从某个角度发言（悲观派/乐观派/务实派） |
| 身份影响措辞 | 老者/少年/贵族/市井，身份不同则措辞、自称、敬谦词不同 |
| 性格影响语气 | 智谋型话里有话；鲁莽型想到什么说什么；冷静型措辞精确，偶尔情感外露反而有冲击 |
| 关系与知情度 | 初见/熟悉/对立/亲密，以及谁刚得知、谁还蒙在鼓里，决定了口气深浅与说出口的信息量 |

## 弹幕/群众对话

三大核心作用：剧情推进（透露主角不知道的信息）、增加期待感（悬念、猜测）、情绪渲染（群众震惊/激动/愤怒传染读者）。锦上添花，不代替主线。

### 设计过的弹幕 vs 没设计的

- 没设计：只有"卧槽好厉害"，单调、浪费
- 设计过：普通人震惊 → 专业人士分析 → 特殊身份者反应 → 情感升华

### 操作要点

- 不同人格化语气，不能每条都一个味
- 短小精悍，每条不超过一句话核心信息
- 善用递进：从最初震惊到逐渐认识全貌
- 可出现"反转"角色：看似路人一句话改变所有人认知
- 不用每章都写，关键爽点/燃点/泪点前后集中使用

## 节奏控制

### 大量对话保持节奏

- 不要删掉表现人物性格的语气助词来"精简"
- 对话段落间穿插动作描写、环境变化、心理活动调节节奏
- 紧张段落对话短促，舒缓段落可以长一些
- 关键信息放对话开头或结尾，中间用于拉扯情绪

### 动作和表情处理

- 刻意给每句对话配挑眉、勾唇、顿手等小动作会让行文机械
- 动作和表情放在关键转折处，或借角色手头正在做的事（算账、择菜、收拾物件）带出停顿，不需要每句都配
- 语气平淡场景（喝茶、散步）用顺手动作和沉默体现氛围

### 对话的呼吸感

- 连续多轮对话后需要"换气"，插入环境描写或角色心理
- 适当停顿（话里的 `……`、插一个动作）比连续输出更有张力
- "你确定？"比长篇解释更有压迫感

---

## 篇幅控制

### 对话过多时

- 读者已知信息的对话用叙事一句话概括："她把进城的缘由说了一遍，表姐听完直皱眉"
- 能用突发状况替代的对话段落直接替换
- 要是把语气词一删整段话就干巴巴的，说明台词本身没干货，得重写

### 对话过少时

- 能用其他人物对话讲出来的东西，不要让主角旁白平铺直叙
- 引入配角参与冲突和对话，但新人物必须安排主线戏份

## 以梗填充对话

### 梗式 vs 普通

- 普通："兄弟别灰心，你一步步走到今天我全看在眼里，这点挫折算什么？早晚能熬出头！"
- 梗式："兄弟别灰心，听哥一句，咱早晚有人头落地……不对，出人头地的那天！反正就那四个字，你懂我意思吧？"
- 梗式用嘴瓢或半截话把劝慰说活，比干喊口号更贴熟人语气

### 操作

- 在轻松或日常对话中融入俏皮话，特别是主角或重要配角的熟人互动，可用口头幽默强化记忆点
- **分清场合（人物声口给场面气氛让路）**：高压、生死、悲痛或庄重关头，爱插科打诨的配角也要收起玩笑和口头梗，改用短促、有分量的反应托住气氛；抖机灵只留在安全或松口气的空当，会让人出戏就删。

## 质量检查

- [ ] 权力博弈：话轮长短、回应方式与人物掌握的筹码相符，不写没筹码支撑的空头狠话
- [ ] 潜台词与说话目的：博弈时表面说辞与真实盘算有反差；日常同立场对话有温差或打趣，不来回复述
- [ ] 人物差异化：遮住角色名后能否区分是谁在说话（按上表各项）
- [ ] 弹幕递进：普通 → 专业 → 特殊身份，是否有层次感
- [ ] 对话推动剧情：每段对话结束时，剧情是否往前推了一步、结尾能否预示接下来的节奏变化
- [ ] 篇幅控制：按场景职责判断是否过长，删去复述和无效往返，不按固定占比分配
