# 短篇场景写法

> 谁读：写正文时主会话整份读；构思不读。

按场景组织信息并分配详略。

## 1. 场景写法：三维度揉进

写关键子事件时，从发生、感知、反应中取有新信息的内容，**织进同一段连续正文**；上下文已交代清楚的维度可以省略：

| 维度 | 内容 | 要点 |
|------|------|------|
| 发生 | 事情出现了 | 1-2 句，含一个具体细节 |
| 感知 | 主角注意到什么 | 只取会改变理解、判断或气氛的声音、物件、空间或身体感受，不按感官凑数 |
| 反应 | 角色接下来怎么办 | 直接情绪、利害判断/盘算、选择、台词、任务动作或有后果的身体变化（见 `short-craft.md`「情绪落地」），不用手眼/道具小动作顶替 |

禁止按三个维度依次另起三段，重复叙述同一件事。

- 正确（揉进式）：我以为丈夫是真心跟我道歉，但摸到那碗凉掉的排骨汤时，我的心更冰冷了。上面还浮着凝固的油，根本喝不了。（摸汤、凝固的油、心冰冷揉在一段里）

**句子要连**：角色算账与动机直接用「因为、所以、既然、省得、偏偏」接清因果，不拆成摸杯沿、垂眼等小动作；一句里超过三个动作，用「就、才、又、便、却、倒」接出先后，别写成逗号清单；「没A，也没B」式否定排比全篇至多一两处；对话按人物身份带「吧、呢、啊、嘛」这类口气；单独成行的碎句只留给钩子、反转和情绪峰值。

**画面分段**：按新动作、新物件、新信息、新对话或视线转移断段。一段承载一个画面变化，或一条连续的推理、氛围、情绪链。

**对决场景**：比赛、赌局或正面交锋，先交代输赢得失、对手优势和主角可利用的条件；以小搏大要写出独有手段及取胜过程，不靠对手突然降智。

## 2. 疏密分配 + 动静起伏

**疏密**：按情节节点的作用分配笔墨，避免每处同样长、同样细。

| 节点类型 | 笔墨 |
|---|---|
| 爽点 / 打脸 / 反转 / 情绪高潮 | 密（详写，感知动作对话铺满，写足过程） |
| 过场 / 赶路 / 信息交代 / 时间跳转 | 疏（1-2 句带过，不展开三维度） |
| 铺垫 / 日常 / 关系升温 | 中（挑一两个有代入感的细节写实，其余略） |

**动静有起伏**：整篇要有推进与停顿，但不要求动作冲击后固定接一段安静感知。停顿可以是信息悬置、对话空白、等待或环境压力，不用微动作填格。避免长时间全动造成疲劳，也避免长时间全静造成拖沓。

**主语节奏**：段首 / 场景切换 / 多人同场用主角名建立主语；同一动作链内用代词 / 省略流动；关键转折再点名。避免连续多句都以同一主角名开头。
