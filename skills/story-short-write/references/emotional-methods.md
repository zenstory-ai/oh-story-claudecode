# 情感设计方法：三板斧 + 拉扯节奏 + 失败模式

> 谁读：构思时主会话读「情感拉扯节奏设计」定整体走向；写正文写羁绊或余韵时读「情感虐心三板斧」对应一斧；story-architect 辅助构思时读副本。

> 全篇情绪怎么走只在本文件「整篇弧线与转折位置」定，构思时选一种写进 设定.md「情绪设计」，写正文照它安排。

---

## 情感虐心三板斧

### 第一斧：羁绊铺设（前 1/3）

用具体数字立时间（「相恋八年」「守了六年活寡」）、具体物件承感情、重复动作立习惯，少写「他们很相爱」空话（温情甜宠写到偏爱与回馈即可，虐心向靠羁绊为撕裂蓄力）：

- **省吃俭用立讨好**：女大生穿姐姐旧衣二十年，家教费每月只留三百饭钱、省下一千贴补家里，把十岁时妈送的长命锁贴身戴十年当偏爱证据。
- **三年苦等立痴情**：未婚夫说要出家清修，女主连着三年冬天上山替他抄经祈福、双手冻满疮，后面撞破他是为躲婚陪白月光，心死才立得住。

---

### 第二斧：情感撕裂（中后段）

借反差（先暖后冷）、错位（以为是爱实则是算计）或延迟揭底，颠覆前文认知：

- **信物翻面揭穿假慈母**：女主被姐姐推伤住院，病房外听见一向装心疼她的妈劝姐姐：「当年给她那长命锁就是个五十块的镀金假货，哄她给家里当牛做马的！等她毕业每月还得给你三四千呢。」她刮开表面金漆露出黄铜，回家还清抚养账彻底断联。
- **温柔体贴实为骗签担保**：丈夫连月亲自下厨、陪她回娘家尽孝，她感动之下签了「购房补充协议」，直到法院查封通知上门，才知那是替他白月光公司兜底的千万连带担保书。

---

### 第三斧：余韵钝痛（结尾）

不用大哭大闹，把留白落在日常动作和前文物件上，写人物做了什么，不替读者解释：

- **断联后的平静日常**：拉黑吸血母姐办好留学后，不写大段感慨，只写花一百块买新行李箱、五十块买新短袖，「我的手机清净了不少。那些困扰我很久的麻烦，在一瞬间变得很小」。
- **把爱转给值得的人**：老两口被儿子儿媳联手算计婚房、赶出家门；起诉收回房产后，去福利院收养了被嫌笨拙的小女孩，「她会每天笑着迎接我们回家，问我累不累、渴不渴。我知道，这一次我没选错」。

## 情感拉扯节奏设计

```
温暖 → 残忍 → 善意 → 真相 → 原谅 → 来不及 → 释然 → 细节暴击
```

按本篇题材的节奏骨架选用需要的转折：情绪、期待或压力须随具体触发事件持续变化（甜宠可沿甜度递进，报应型可沿反制升级，不强插负向回落；爽文允许快速反弹，虐文拉长前期投入），连续多节无新信息、选择或后果时检查停滞，反转后只写兑现与余韵。

### 整篇弧线与转折位置

| 走向（设定.md 写左列的说法） | 适合 | 转折与兑现怎么落 |
|---|---|---|
| 先压后扬（V形） | 虐后翻盘、破镜重圆 | 压到退无可退再翻盘，留足反击与结算 |
| 先甜后崩（倒V形） | BE、信任崩塌 | 甜到信任最满处崩塌，跌比升快，结尾不加糖 |
| 几起几落（W形） | 追妻拉扯、多反转 | 两三次起伏，峰逐次加重，终峰落在总清算处 |
| 一路上扬（渐进形） | 打脸爽文、层层揭秘 | 借阶段反制一路推高，大底牌留在终局亮出 |
| 憋到最后爆（延迟满足形） | 隐忍复仇、身份揭秘 | 前段蓄压攒证据，终局集中引爆 |
| 最后急转（急转弯形） | 细思极恐、动机反转 | 前段按常规推进，终局前亮出反常急转 |

反转或兑现节是全篇的峰（倒V形在中段）；各节按所选走向起落，不要求逐节递增。

## 常见失败模式

| 失败模式 | 识别方法 | 修正方向 |
|----------|----------|----------|
| **太平** | 连续多节无情绪、期待或压力变化 | 检查事件是否带来新信息、选择或后果 |
| **太赶** | 重大转折缺铺垫 | 补清关系积累与触发事件 |
| **假虐** | 读者不心疼，只是看着难受 | 检查羁绊铺设是否具体 |
| **割裂** | 开头承诺、中段升级与结尾脱节 | 让升级、反转和结局回答开头同一困境 |
| **烂尾** | 反转后还在补交代、新开事件 | 反转后只写兑现与余韵 |
| **人设崩** | 关键时刻行为不合前面人设 | 回顾人设，确保行为逻辑一致 |
