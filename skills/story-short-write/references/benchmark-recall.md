# 短篇对标发现与语感切片召回

> 谁读：仅在项目有 `对标/`、`拆文库/` 或作者给了参考小说时读取；平常不读。

参考书不只是「套路证据」：**同题材对标书的竖屏段长、口语节奏、对话密度与情绪落点，可以直接作为本篇的语感锚点**；不同题材对标书只借结构与卡点节奏，不改变本篇流派腔调。

> **目录约定**：项目根 `拆文库/{书名}/` 存拆文产出；`{短篇目录}/对标/{书名}/` 存本篇选用的副本。读取时先查 `对标/`，没有再查 `拆文库/`。

## 1. 筛选与匹配

1. **列候选，排除本书**：检查 `拆文库/` 与本篇 `对标/`，排除与当前书名同名或来自当前 `正文.md` 的目录。导入流程生成的本书拆文只作已写节基线，不列入对标。无可用候选则直接按流派包写。
2. **按题材对表**：读 `_meta.json` 的 `genre_detected`（缺失时从 `拆文报告.md` 判断），对照下表映射 12 个流派包；一致标「同题材」，否则标「不同题材」：

| `genre_detected` | 对应流派包 |
|---|---|
| 追妻火葬场 / 追妻 / 小三 / 死人文学 | `追妻火葬场.md` |
| 总裁豪门 / 豪门 | `总裁豪门.md` |
| 世情打脸 / 世情 | `世情打脸.md` |
| 宅斗宫斗 / 宫斗宅斗 | `宅斗宫斗.md` |
| 年代重生打脸 / 年代重生 | `年代重生打脸.md` |
| 脑洞设定流 / 沙雕 / 脑洞 | `脑洞设定流.md` |
| 复仇打脸 / 重生复仇 | `复仇打脸.md` |
| 甜宠 | `甜宠.md` |
| 男频都市反杀 | `男频都市反杀.md` |
| 双男主 | `双男主.md` |
| 悬疑 / 民俗 | `悬疑.md` |
| 通用短篇 / 仙侠 / 通用 | `通用短篇.md` |

3. **请作者拍板**：列出候选书与「不用，直接按流派包写」。选定的书写入 `设定.md`「参考的书」，并把 `拆文库/{书名}/` 复制到 `{短篇目录}/对标/{书名}/`。多本对标时只定 1 本「主要参考」，其余作「顺带参考」只借 1–2 条结构做法。

## 2. 提取量化数据与原文语感切片

读主要参考的 `拆文报告.md`、`情节节点.md`、`写作手法.md`、`_meta.json`（`情节节点.md` 看每个节点的位置、功能和情绪。`_meta.json` 看 `genre_detected` 与 `structure_counts.reversal_type`；仅有原文时提醒先跑 `/story-short-analyze`；作者要直接继续则从原文手抽切片）：

1. **记节奏目标**：从 `写作手法.md`「量化网感体检表」（旧报告则快速目测原文）记下：中位段长、单句成段率、对话占比、首冲突字位、付费卡点所在节、结局清算方式，写进 `设定.md`「参考的书」。
2. **抽 2–3 段 150–250 字原文切片**（同题材对标必做）：优先直接取 `写作手法.md` 里的「原文语感切片」，没有就从 `原文/` 摘 3 段最抓人的现场——① 导语/开篇冲突 ② 高压对话交锋或反派压迫 ③ 付费卡点或高潮打脸清算——贴进 `设定.md`「语感参照切片」。
3. **防抄袭红线**：在切片上方写死提醒——**只模仿断段节奏、句长、口语网感、情绪直给与对白推拉；严禁复用人名、独特物件、标志性台词或具体桥段顺序**。

## 3. 落稿时怎么用

Phase 3 每写新一批（开篇、中段、高潮）前，扫一眼对应那 1 段语感切片，先对齐段长与口语温度再下笔；不回头重读整套拆文报告。
