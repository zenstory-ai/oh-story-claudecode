# 短篇对标发现与语感切片召回

> 谁读：仅在项目有 `对标/`、`拆文库/` 或作者给了参考小说时读取；平常不读。

参考书不只是「套路证据」：**同题材对标书的竖屏段长、口语节奏、对话密度与情绪落点，可以直接用来校准本篇语感**；不同题材对标书只借结构与卡点节奏，不改变本篇流派腔调。

> **目录约定**：项目根 `拆文库/{书名}/` 存拆文；`{短篇目录}/对标/{书名}/` 存本篇副本，先查 `对标/` 再查 `拆文库/`。

## 1. 筛选与匹配

1. **列候选，排除本书**：查 `拆文库/` 与 `对标/`，排除本书及导入自拆目录；无候选则按流派包写。
2. **按题材对表**：读 `_meta.json` `genre_detected`（缺失看 `拆文报告.md`），对表映射 14 包（一致标「同题材」，否则「不同题材」）：

3. **请作者拍板**：列出候选书与「不用，直接按流派包写」。选定的书写入 `设定.md`「参考的书」，并把 `拆文库/{书名}/` 复制到 `{短篇目录}/对标/{书名}/`。多本对标时只定 1 本「主要参考」，其余作「顺带参考」只借 1–2 条结构做法。

## 2. 提取节奏做法与原文语感切片

读主要参考的 `拆文报告.md`、`情节节点.md`、`写作手法.md`、`_meta.json`（`情节节点.md` 看每个节点的位置、功能和情绪。`_meta.json` 看 `genre_detected` 与 `structure_counts.reversal_type`；仅有原文时提醒先跑 `/story-short-analyze`；作者要直接继续则从原文手抽切片）：

1. **提炼节奏做法与避坑**：从 `写作手法.md`「核心手法拆解」「避坑提醒」（旧报告对照 `拆文报告.md`「源文短板」）记下**可学做法**（首冲突入局、付费卡点节位与钩子、对白推拉与结局清算）与**源文短板避坑**写入 `设定.md`「参考的书」；**不把裸统计数（中位段长/单句率/对话占比）当死命令**。
2. **抽 2–3 段原文参考片段**（同题材必做）：优先取 `写作手法.md`「原文语感切片」，否则从 `原文/` 摘导语冲突、高压对白交锋、高潮清算三段贴进 `设定.md`「参考的书」下的「参考片段」。
3. **防抄袭红线**：切片上方注明——**只学断段、口语网感、情绪与对白推拉；禁复用人名、物件、台词或桥段顺序**。

## 3. 落稿时怎么用

Phase 3 每写新一批（开篇、中段、高潮）前，扫一眼对应那 1 段语感切片，先对齐段长与口语温度再下笔；不回头重读整套拆文报告。
