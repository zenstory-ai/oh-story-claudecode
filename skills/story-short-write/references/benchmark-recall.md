# 短篇对标发现与召回

> 谁读：构思时本篇有对标、项目有拆文库或作者提到参考小说，主会话整份读；写正文不读，只用 设定.md「参考的书」。

本篇有 `对标/`、项目根有 `拆文库/`，或作者提到参考小说时，按以下流程处理。题材包由作者选的题材决定；对标书只提供套路证据，不换题材包，也不改本篇腔调。

> **目录关系**：项目根 `拆文库/{书名}/` 保存拆文产出；`{短篇标题}/对标/{书名}/` 保存本篇选用的副本。读取时先找 `对标/`，没有再找 `拆文库/`。

1. **列候选，排除本书**：用 `ls 拆文库/` 和本篇 `对标/` 列书目。按当前项目目录名和 `设定.md`「基本信息」识别本篇标题，排除同名或来源指向当前 `正文.md` 的 `拆文库/{当前书}/` 与历史误建的 `对标/{当前书}/`。story-import 生成的本书拆文只作已写部分的写法参考，不列入对标。排除后没有书，就不用对标，按题材包写。
2. **判断相关性**：逐本读 `_meta.json` 的 `genre_detected`，按下表确定对应题材包；和本篇题材包相同记「同题材」，否则记「不同题材」。元数据缺失时从拆文报告判断，判断不了标「待定」。

   | `genre_detected` | 对应题材包 |
   |---|---|
   | 追妻（现代 / 古代 / 民国）、小三 / 死人文学 | `追妻火葬场.md` |
   | 世情 / 打脸爽文 / 家庭伦理 | `世情打脸.md` |
   | 重生复仇 | `复仇打脸.md` |
   | 豪门 / 总裁（豪门联姻虐恋） | `总裁豪门.md` |
   | 宫斗宅斗 / 宫斗 / 宅斗 / 古言重生 | `宅斗宫斗.md` |
   | 民俗 / 怪谈 / 灵异 | `民俗怪谈.md` |
   | 悬疑 / 推理 / 惊悚 | `悬疑.md` |
   | 甜宠 / 先虐后甜 / 先婚后爱 | `甜宠.md` |
   | 双男主 | `双男主.md` |
   | 沙雕 / 脑洞 / 弹幕 / 系统 | `沙雕脑洞.md` |
   | 仙侠 / 通用 / 其他 | 无对应包：和本篇冷门题材相同记同题材，否则记不同题材 |

3. **请作者选**：向作者推荐（有选项工具时用选项），列出候选书和「不用，按题材包写」。选定的书写入 `设定.md`「参考的书」作主要参考，并把 `拆文库/{书}/` 复制到 `{短篇标题}/对标/{书}/`。作者指定的参考小说也这样登记。
4. **读产物**：读该书的 `拆文报告.md`、`情节节点.md`、`写作手法.md`、`_meta.json`，用法见下方「拆文产出怎么用」。只有原文、没有拆文报告时，提示作者先运行 `/story-short-analyze`；作者仍要继续，只把原文作弱参考。
5. **写摘要**：把报告里的结构段落、情绪曲线、反转位置、铺垫方式、句式节奏和可借鉴技法，与本篇题材包的套路对应，用原篇证据判断套路在本篇怎么用，写进 `设定.md`「参考的书」的「能学的写法」。写正文时每个场景从中召回 1-2 条。
6. **多本对标**：主要参考只选一本；其余记作顺带参考，不读它的文风，每本只取一两条能学的写法写进「参考的书」那一行。写正文不再新增。

#### 拆文产出怎么用

`拆文库/{书名}/` 下有 `原文/`、`拆文报告.md`、`情节节点.md`、`写作手法.md`，还可能有 `_meta.json`。

- `_meta.json` 可选，缺了不挡写作。`structure_counts.reversal_type` 是反转类型（视角/身份/动机/时间线/信息/认知/无反转），按它在 `short-reversal.md` 选反转骨架；其余计数（结构段 `beats`、钩子 `hooks`、反转铺垫线索 `setup_clues`、有反差的人物 `character_archetypes`、可复用手法 `reusable_structures`）只作对照，不当指标
- `情节节点.md` 看每个节点的位置、功能和事件，给新故事排节奏
- `写作手法.md` 与 `原文/` 只学写法（对话调子、节奏、画面感），不抄具体情节
