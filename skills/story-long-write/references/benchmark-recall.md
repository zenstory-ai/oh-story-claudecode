# 长篇写前召回

> 谁读：主会话写一章、日更时召回降档不成立才整份读。

怎么读对标资料只在本文件定义；承接 workflow-chapter「写前准备」，文件位置见 [project-files.md](project-files.md)。

- **对标书路径**：优先 `{项目}/对标/{书名}/`，不存在则回退 `拆文库/{书名}/`（首次引用的复制规则见 workflow-setup.md「对标发现」）。先按目录名、`.active-book` 与本书设定排除本书自己（导入时拆文库里与本书同名或来源指向本书正文的那份）。
- **无对标**（唯一定义）：题材定位「对标登记」写了「主对标书：无」，或没有登记、`对标/` 与 `拆文库/` 排除本书后也没有别的书。此时跳过 (a)(b)(e)(f)，不报缺失；(c) 照常；(d) 有 `设定/文风.md` 就用，没有按作者当前请求和默认写法；情绪与节奏取细纲与剧情段卡。
- **主对标**：取登记的「主对标书」；没填或指向本书时用 `对标/` 下字典序第一本（没有再看 `拆文库/`），并提示作者补登记。登记了的书目录里找不到，停下核对书名，不换书。
- **权威顺序**：`剧情/情绪模块.md` 管读者需求与情绪引擎，`剧情/节奏.md` 管信息推进与爆发；对标 `文风.md` 只管句法、标点、对话与锚点，不覆盖这两份；章节摘要是证据，`拆文报告.md`、`剧情/故事线.md` 是摘要，与这两份冲突时以它们为准并记 `conflict`。本书 `设定/文风.md` 高于对标文风。
- **缺资料**：角色、普通剧情单元、设定子目录缺了就跳过该模块；情绪模块、节奏见 (a)(b)，文风见 (d)，题材卡见 (c)。
- **召回降档**：本书有自定义文风（或无对标）、题材卡有内容，且细纲目标情绪与剧情段卡的情绪、节拍都有效时，跳过 (a)(b)(e)(f)，情绪和节奏取细纲与剧情段卡，(c)(d) 照常，(g) 输出缩减集。组装脚本判定并写进核对报告；不成立走全量召回。降档不查对标主产物，代价是没有匹配章技法与原文锚点；目标情绪敷衍时不得降档。
  - (a) **情绪模块**：读 `{对标书路径}/剧情/情绪模块.md`，选 1 个与本章目标情绪最贴近的 `selected_emotion_module`（读者想看什么、情绪链、戏剧单元、可替换项、不可照搬）。缺失时设 `missing_primary_contract: true`，返回明确 `repair_action` 后停止准备
  - (b) **节奏**：读 `{对标书路径}/剧情/节奏.md`，选 1 条 `rhythm_reference`（关键信息 → 扩写方式 → 情绪触动点 → 爆发点 → 余波/冷却）。缺失处理同 (a)
  - (c) **题材正文提示卡**：优先读 `设定/题材正文提示卡.md`；还没有时按 genre-prose-cards.md「全书题材正文提示卡」一节生成（用核对报告「题材卡」行点名的卡；匹配不到时那一行点名的是流派兜底卡），落盘后后续章直接读
  - (d) **文风**：先读 `设定/文风.md`：有可执行表达要求就算本书自定义文风（不设最低字数；空白、纯标题、待补充不算），写作与去味都传全文路径，`_文风摘要.md` 只作索引；对标只补它没写的维度。没有自定义文风时读主对标 `{对标书路径}/文风.md`，路径和本章要用的要点填进写手 prompt 的「文风」块。主对标缺文风文件 → 停下报错：「对标书《X》还没有文风分析。请用 `/story-long-analyze` 给《X》补上文风分析，再写这一章。」不当场生成（全量召回时情绪/节奏缺失仍独立阻塞）
  - (e) **匹配章节**：从 `{对标书路径}/章节/*_摘要.md` grep `基调：(紧张|轻松|悲伤|热血|爽|甜|温馨|恐怖|压抑|其他)`（全角冒号），按本章目标情绪挑章 K——多章同基调时先比爽点类型，再比情节点数与字数，最后取章号最小者；必读 `第K章_摘要.md`，有 `第K章_深度拆解.md` 就加读，否则回退黄金三章深度拆解或文风文件里的可借鉴技巧，不因缺深度拆解而失败
  - (f) **结构化模块**：从对标的角色/剧情/设定子目录按本章情节检索相关模块，冲突按权威顺序
  - (g) 输出「主对标召回摘要 + 副对标召回摘要 + selected_emotion_module + rhythm_reference + genre_prose_card + 文风要点 + 原文锚点片段引用」交写手。多本对标时副对标的取法与预算见 [cross-book-recall.md](cross-book-recall.md)，副书文风和原文不进写手。
- **story-explorer 快捷路径**：降档不成立且已部署时，可按 agent-calls.md 一次召回文风/模块材料，返回的 `gaps` 这样处理：`no_benchmark` → 有自定义文风就按 `设定/文风.md` 写、情绪/节奏取本书材料，否则标「无对标参考」；`missing_primary_contract` → 按 `repair_action` 修复（重跑拆文或导入）并停止，自定义文风不豁免；`benchmark_book_missing` → 停下核对登记名，不换书；`conflict` / `module_rhythm_conflict` → 在意图里说明并按情绪模块/节奏执行；`profile_missing` → 有 custom_style 就用本书文风继续，否则停止；`profile_degenerate` → 有本书文风就用，没有回默认；`tone_match_failed` → 只用整书文风。其余字段原样进写手 prompt。
