## 主会话：出细纲步骤与汇报

1. **只取本段卷纲**：跑 `{skill 根}` 脚本目录 `outline_view.js --unit {单元编号} {卷纲路径}`（先 `--toc`），不整读卷纲；按需定点读 `设定/` 与 `追踪/上下文.md`。
2. **派发或自排**：已部署 `story-architect` 时跑 `build_architect_brief.js --project {书目录} --task outline --chapters {A-B}`（单批 ≤10 章，见子代理派发手册）；无子代理先给本批提案，作者确认后落盘。
3. **收回验收**：每章写入后跑 `check-outline-contract.js --json --project {书目录} --chapter {N}`。exit 1（`hard_failures`：可读、字数目标、`目标情绪`/`主角目标/关键选择`实质内容）补齐重验（≤2 轮）；`soft_warnings` 按需修补。
4. **中途补纲/扩纲**：只补点名范围，**已写正文细纲锁定不改**。新剧情段按 `flow-opening-plan.md` 往卷尾追加新卡，规划事件不进 `追踪/`。
5. **向作者汇报**（开书/大纲/卷纲/细纲通用；只用故事话）：

## 排纲方法

### 黄金三章规划（含第 1–3 章必读）

**番茄/七猫禁慢热**（仅起点/晋江指定才缓铺）。底线：Ch1 首段 **≤45 字**、前百字禁纯景物、**≤300 字见对话**（独白/奇观可至 500–650 字）、**≤400 字入冲突**、主出场 ≤3 人；前 3 章**章末全强钩**；站队前不把对手写可怜。选 1 种引擎跑透：

| 开篇引擎 | 第 1 章 | 第 2–3 章推进 | 适用题材 |
|---|---|---|---|
| **打脸翻盘** | 直抛羞辱/死局并亮底牌，给小反馈+强卡点 | 当面正面交锋+切身赌注 → Ch3 首轮打脸、实利落袋+大舞台钩子 | 传统玄幻、高武、宅斗、历史爽文 |
| **三章压弹簧+阶梯垫脚石** | 播报/奇观立压迫+选反常识底牌但蓄而不发 | 普通人→天才依次立战力刻度拉满压迫 → Ch3 末出招瞬间卡断、Ch4 初爆 | 序列高武、玄幻脑洞、末世升级 |
| **真实痛点+微量化养成+死党对照** | 现实窘境/亲情锚点+系统微量化正反馈（零反派亦可） | 小数点级成长+同桌/青梅/死党镜像对照稳留存+阶段小目标 | 都市日常、听劝养成、校园/种田 |
| **强概念+双视角脑补/弹幕** | 直抛高辨识奇观/职业现场/穿书反差，即刻入局 | 场景级切对手/恋人/大人物视角脑补震撼，或用弹幕剧透+吐槽调频 | 甜宠脑洞、双男主、谍战、悬疑、迪化 |

### 批次边界与写纲前查缺

- 未指定范围时一批 ≈ 一段剧情（≤10 章；开书默认前 10 章）；指定范围不擅扩批。
- 每批前查 5 项记进 `.story/排纲笔记/{剧情段编号}.md`：① 本批对手（对抗段别隔 2 章无对手）；② 未来 3 章新角色卡；③ 能力/金手指规则一致；④ 物价、等级等刻度有据（缺则按「新增物三级」补档或问作者）；⑤ 禁连两段同场景/同对手/同破局手段。
- **细纲后补档**：新出现会复用的角色/势力/跨章规矩，及时建 `设定/角色/`、`设定/势力/` 或 `设定/世界观/`（一次性路人不建）。

### 爽点倒推与高潮构建（博弈阻力，禁打卡送脸）

- **立真冲突，禁套路打卡**：围绕六类爽点（破局碾压/达成/实利变现/利害改口/掉马/破例护短），**先定各方真实私心与底牌，再推碰撞与反咬——禁「倒推谁来送脸」、反派遇证秒招自爆、双重巧合或唯一神医式天降喂饭**。
- **每场必有阻力与代价**：主角须有误判、软肋或实感代价，对手会狡辩/设阻/反制；每章聚焦 2–3 个演透的硬场面，含至少 1 处**意外阻滞或反预期实招**；松章须留进度/关系钩，无阻力水过场直接并章。
- **三线期待接力**：短（2–3 章）、中（5–8 章）、长弧（整卷）接棒，旧期待兑现前先让下条线拱半步，**严防断期待**。

### 高频章首 / 章尾硬钩子（日更 ≥70% 章末带钩，黄金三章 100%）

| 位置 | 实战钩子类型 | 停在哪一拍（写场面落点与意图，不写类型名） |
|---|---|---|
| **章首** | 承接炸点 / 冲突对话 / 反常动作 / 倒计时 | 紧接上章尾结果或一句直切新麻烦，禁天气空景开章 |
| **章尾·危机打断** | 突发危机 / 动作截断 / 来人来电 | 刀将落、门刚推开、系统急报、大敌/权贵突降 |
| **章尾·亮牌反转** | 身份揭露 / 奖励超预期 / 信息差落子 | 测力碑炸裂、隐藏大奖刷出、对手得意却不知底牌已落（可切镜交代幕后） |
| **章尾·选择逼迫** | 两难抉择 / 期限倒计时 / 宣战赌约 | 必须二选一、限时三日、当众立对赌或退婚誓言 |
| **章尾·女频情绪悬崖** | 刀子物件斩断 / 破例偏爱 / 退路试探 | ① 改局实证一拍斩断（退还婚书/账册压桌，不堆器物装饰）；② 高位者暗中破例偏爱；③ 信息差误解或递退路卡点（「现在后悔还来得及」） |

- 细纲钩子优先写功能意图与落点，少填整段原话，免正文复写触发照搬复核（必照搬句另填「原样出现的原话」）。

### 感情线五阶段与女频 CP 四拍推拉（有感情线时对照）

| 阶段 | 好感门槛 | 允许互动 | 节奏与 CP 四拍（试探→克制→破防→上位者低头） |
|---|---|---|---|
| 相识 | 零或负 | 初印象反差、利益交锋、看穿表象 | 首段出场；先立双方对等筹码与不卑不亢立场 |
| 试探 | 单方半好感 | 行动护短、嘴硬心软、跨章推拉 | 男频借危局同行升温；女频走**试探→克制**（人前克制人后破例、暗戳戳开屏） |
| 确认 | 双方半好感+ | 破防认错、递退路托举、吃醋护短 | 踩事业/高潮节点兑现**破防→上位者低头**（撇开视线秒认错、给足选择权） |
| 考验 | 双方满好感 | 联手抗外阻、舍利托底 | 虐不过三章必有反制或高糖，禁真出轨/暴力强行洗白 HE |
| 定局 | 满 | 默契对外、日常发糖 | 落定后不硬塞毒闺蜜或烂俗情敌水字数 |

- 章节标题：12 字内取冲突或梗（金句/案号可放宽），禁「开始/觉醒」空词，不剧透。

### 中后期换卷与长跑红线（≥50 章或跨卷必查）

- **百章四件套**：① 换图回扣旧敌旧账、带 ≥2 老熟人升级目标（禁清零重开）；② 特色配角扛喜剧/潜伏高光破疲劳；③ 松章用互损带实账、章末挂旧危机或硬锚；④ 切大格局借弹幕减压再落烟火。
- **战力与财富四阀**：定体系硬顶、旧技二创破局、补支出代价、用物价刻度保实感（禁百亿失感）；每 3–5 紧章配 1 实心松章。
  - ❌ 飞升上界旧友清零，又从杂役被骂起。→ ✅ 携旧部旧账闯上界，落地即遭前卷死敌通缉堵门，直接转猎杀反杀。
