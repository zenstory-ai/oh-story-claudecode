# 长篇章节质量检查清单

> 谁读：主会话写完一章、排查具体问题时读，不预读。

只查写好的这一章。维度与 workflow-chapter「质量检查」一致：情绪交付、钩子与爽点、技术质量。严重度同写章流程：必须修、建议看、仅提示。去味按检测器提示处理；要完整三层去味走 `/story-deslop`。字数出了范围按 workflow-chapter「检测收口」处理，不在这里另判。

## 单章检查

### 章节结构
- [ ] 开头有钩子（不是天气/风景/日常开场）；第 1-3 章另按 opening-design「开篇落笔」查
- [ ] 中段有推进（快节奏题材要有具体事件；慢热题材状态变化即可）
- [ ] 局势有变化（读完这章，世界跟之前不一样了）
- [ ] 结尾落在变化上（不是总结）

### 章节推进
- [ ] 本章至少改变目标 / 风险 / 信息 / 关系 / 资源 / 身份 / 情绪立场七类状态之一；快节奏（番茄/爽文）应有具体事件或爽点，慢热/情感文才可只靠低压小变化达标，不强求每章高潮
- [ ] 不是水字数（删掉这章会损失哪项状态变化？答不出才需压缩）
- [ ] 任务卡点有用：卡住之后是否带来上述状态变化？
- [ ] 推进强弱是否符合本书已建立的题材、兑现节奏与对标，而非套固定通用字数
- [ ] 兑现或高潮之后，是否允许短暂低压和实在的小收获，不生硬地立刻加危机？

### 信息传递
- [ ] 没有大段设定说明文
- [ ] 信息跟着冲突走（通过事件传递设定）
- [ ] 设定量可控（一章不超 3 个新概念）

### 场景检查
- [ ] 场景有目标（人物要什么）
- [ ] 场景有阻碍（什么挡着）
- [ ] 场景有变化（结束后跟之前不同）
- [ ] 心理段写的是新判断、误判或决定，不是反复翻译同一情绪
- [ ] 删掉某段后，事实、因果、声口、关系或情绪延续都没有损失，才删

### 章尾
- [ ] 钩子强度按细纲标的这章松还是紧核对：紧的章、推进章有危机/决定/发现/反转之一；松的章留阶段目标或情绪钩子即可
- [ ] 不是总结式结尾
- [ ] 拉住读者翻下一页

### 语言
- [ ] 没有空洞的抒情段落
- [ ] 对话符合人物身份（不同人说话方式不同）
- [ ] 情绪词有落点（融进动作句、当对话提示语、结句后直接换事或接场内物件），不是接更多情绪
- [ ] 标题行以外没有章节/写作元信息（词表见 long-format，检测器会报）；需要承接前文时改成角色能感知的事件锚点或相对时间

### 连载连续性
- [ ] 没有遗忘之前的承诺/伏笔
- [ ] 没有突然塞入大量新设定
- [ ] 主角行为符合人设，反派逼格匹配当前阶段
- [ ] 对照本章批准细纲核对新增物：闲话、即时反应和服务既有情节点的微连接不算；补上并记下：本章写出的新关系、承诺、后续义务要在申报表里列出，由主会话处置；只有与细纲或已登记事实冲突的才是必须修

### 水（filler）检测
以下信号出现 = 可能水了：
- 全章对话没有任何新信息
- 同一情绪反复写，人物的理解和行动始终没变
- 大段场景描写不推进剧情、人物或氛围
- 角色回忆之前发生的事但没有任何新视角
- 删掉无损的流程细节 / 任务卡点 = 水；压缩或删除
