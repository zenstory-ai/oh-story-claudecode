# 正文存储配置

首次建书请作者选择不分卷或分卷，登记到书目录 `.story/storage.json`，不存入跨书偏好。仅规划时可暂不登记，生成正文任务前必须确定。老书缺配置按下文自动登记，之后直接读取。大纲、设定、追踪、对标等目录固定，不开放自定义。

不分卷：

```json
{"schema_version": 1, "body_layout": "flat"}
```

分卷（章号全书连续，范围来自作者确认的卷纲）：

```json
{
  "schema_version": 1,
  "body_layout": "volumes",
  "volumes": [
    {"directory": "卷一_重生归来", "first_chapter": 1, "last_chapter": 30},
    {"directory": "卷二_新的开始", "first_chapter": 31, "last_chapter": 60}
  ]
}
```

卷目录只允许一层 `卷序号_卷名`，章节范围不能重叠；未覆盖的章号报错，不能擅自写进最后一卷。续写未规划章节前先与作者确定范围。配置文件的其他键会被拒绝，不能自定义正文根目录或其他工程目录。

使用宿主可用的 Python 解释器（依次探测 python3、python、py；下文 `{PYTHON}`），先将已确认配置保存为书目录 `.story/storage-proposal.json`，再执行：

```text
{PYTHON} <skill根>/scripts/storage_layout.py --project <书目录> init --config <书目录>/.story/storage-proposal.json
{PYTHON} <skill根>/scripts/storage_layout.py --project <书目录> show
{PYTHON} <skill根>/scripts/storage_layout.py --project <书目录> resolve --chapter 31 --title 新的开始
```

`init` 校验正文位置和重复章号后写配置，不创建正文、不移动文件、不覆盖配置；通过后可删提案。更改布局或范围须走带备份的迁移流程；本阶段先列路径方案，不手改配置绕过校验，不自动创建 Git 分支。

读取已有章节和确定新章落点共用配置，按全书章号数值排序。已有章节保留原文件名，避免修订时另建同章文件；新章生成 `第NNN章_章名.md`。任意两个卷或直属目录存在同章号都报错，不能静默取第一份。配置与真实位置冲突时先解决迁移，不回退搜索其他目录。更深层目录不参与章节枚举。

老书缺配置时，`show` 或首次确定新章落点会检查现有正式章节：全部直属正文则自动登记 flat；全部位于规范的一层卷目录且卷范围不交错则登记 volumes，范围仅取各卷已存在章节的最小和最大章号。不创建空章节，不移动正文，不猜未来卷范围。没有正式章节、混合布局、卷名不合规或重复章号时先询问作者；已存在但损坏的配置不自动覆盖。自动登记后向作者说明识别结果；未覆盖的新章先确定归属，不擅自延长最后一卷。

已接入写作组装、导入、审稿与字数工具；宿主 hooks 按一层分卷识别，配置位置校验与可恢复迁移待接入。

目录读取失败返回诊断，由 Agent 重试；不能当作没有章节。配置与实际位置不符或章号重复时，列出冲突，先询问作者，按决定修正，不自动移动、删除或改配置。新章路径未确认前不生成正文。

默认排除点号目录、“备份/临时/草稿”开头的目录、`backup/backups/bak/tmp/temp/draft/drafts`（可带前缀 `_`、后缀 `_说明`、空格或短横线说明），以及含 `_原稿_` 的目录和章节文件。隐藏按名称判断，不指 Windows 隐藏属性。作者明确要求时可单独读取备份或临时稿；恢复须先确认位置与同章号文件的处理方式，一次查看不永久纳入扫描。
