# 项目文件与产物协议

> 谁读：主会话缺文件要修、或要找某类产物放哪时读。

#### 项目文件结构

需落盘时在用户指定目录按下表组织；只讨论不建工程，仅规划只创建本次产物所需目录，不为凑齐目录树生成正文或追踪：

```
{书名}/
├── 设定/
│   ├── 世界观/
│   │   ├── 背景设定.md        # 时代背景、地理、历史
│   │   ├── 力量体系.md        # 修炼/能力/等级体系
│   │   └── ...
│   ├── 角色/
│   │   ├── 沈栀.md            # 每个人物一个文件，文件名用角色名
│   │   └── ...
│   ├── 势力/
│   │   ├── 天机阁.md          # 每个势力/组织一个文件
│   │   └── ...
│   ├── 关系.md                # 角色关系映射
│   ├── 题材定位.md            # 题材核心梗+读者期待+对标+后面才揭开或用上的东西
│   ├── 全书梗概.md            # 主角最终要什么、最大阻碍、前几次大转折、结局设想（可空）
│   ├── 文风.md                # 本书自定义文风（可选，导入时作者同意才建）
│   └── 题材正文提示卡.md       # 题材正文核心：边界/期待/爽点/节奏/禁漂移
├── 大纲/
│   ├── 大纲.md                # 全书卷级结构
│   ├── 卷纲_第一卷.md         # 每卷一个：读者期待+故事线+各段剧情+情绪弧线+人物弧线+伏笔+反转
│   └── 细纲_第001章.md        # 每章一个：七个必填字段+四个小节+结尾设定和钩子
├── 正文/
│   ├── 第001章_章名.md
│   └── ...
├── 对标/                          ← 拆文产出的结构化资产
│   └── {对标书名}/
│       ├── 原文/第001章_章名.md
│       ├── 章节/第K章_摘要.md
│       ├── 角色/                  ← 从拆文库/结构化输出同步
│       │   └── {角色名}.md
│       ├── 剧情/                  ← 从拆文库/结构化输出同步
│       │   ├── {剧情单元名}.md
│       │   ├── 故事线.md
│       │   ├── 节奏.md             # 关键信息推进 + 情绪触动点 + 爆发节奏（权威节奏索引）
│       │   └── 情绪模块.md         # 读者需求/情绪引擎 + 可复现模块（权威模块索引）
│       ├── 设定/                  ← 从拆文库/结构化输出同步
│       │   ├── 世界观/{主题}.md
│       │   └── 势力/{势力名}.md
│       ├── 文风.md
│       └── 拆文报告.md
├── 追踪/
│   ├── _tracking-state.json        ← 唯一结构化底账
│   ├── 上下文.md                  ← 自动生成的续写状态卡（固定 7 栏）
│   ├── 逐章记录/第NNN章.md          ← 未来相关紧凑记录
│   ├── 角色状态/{角色名}.md         ← 自动生成的核心角色当前快照
│   ├── 伏笔.md                    ← 自动生成的伏笔当前视图
│   └── 时间线/{作者真相.md,读者已知.md}
├── 参考资料/
│   └── {topic}.md             # story-researcher 输出的研究资料
├── .story/排纲笔记/L1-01.md    ← 每段剧情一份排纲自用底稿：写纲前查缺+写纲时补的（作者不用读；老书在 大纲/排纲笔记_ 或 排纲底稿_）
├── .story/work/第NNN章/        ← 本章临时文件（分组 segment、prompt 留档、事务 JSON），提交后自动删除
```

**关键产物读取与更新边界**（创建模板见 [references/artifact-protocols.md](artifact-protocols.md)；`追踪/` 体积上限见 tracking-transaction.md）：

- **设定与大纲**：`设定/关系.md` 仅在按需查询或审稿时读，不在每章写作回路里逐章读；`设定/题材正文提示卡.md` 按 `genre-prose-cards.md`「全书题材正文提示卡」在首章写前生成；`大纲/卷纲_第X卷.md` **一律走 `outline_view.py --chapter/--unit/--contract/--toc` 取段，禁止整读**；`.story/排纲笔记/{剧情段编号}.md` 仅在排纲/补纲时读。
- **追踪视图**：`追踪/_tracking-state.json` 在首次写正文前初始化（规划阶段不建），不进正文 prompt；`追踪/上下文.md` 日更每章整份读；`伏笔.md`、`时间线/`、`角色状态/`、`逐章记录/` 默认不整读，缺项时按 ID 或角色名定点查。
- **对标资产**：`/story-long-analyze` 产出在 `拆文库/`，首次引用时同步到项目 `对标/`；对标资料权威顺序与缺失处理见 benchmark-recall.md。每章正文写完直接写入 `正文/` 目录，不要先输出到对话。
