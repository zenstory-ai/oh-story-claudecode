# workflow-volume.md：出卷纲

> 谁读：主会话出卷纲时整份读；「排纲方法」一节进 story-architect 卷纲任务包。

主会话自己排，或 story-architect 按任务包排，都照「排纲方法」执行。

## 主会话：读取、分工与汇报

**读取**：参考文件按 SKILL.md「写前必读」总表「出卷纲」一行读。项目资料：设定从 `设定/` 读，不回翻对话，`设定/全书梗概.md` 是分卷的底子；有主对标时按「对标节奏迁移」读主对标的 `剧情/节奏.md`；只交付卷纲时不读细纲文件。

**谁来排**：已部署 story-architect 时，卷纲在它的新上下文里出，调用见 [agent-calls.md](agent-calls.md)；主会话拿到后跑 `outline_view.py --check --strict {卷纲路径}`（往旧卷纲追加剧情段时去掉 `--strict`），按排纲自查四项的结论汇报。没有子代理时，主会话按「排纲方法」自己排：先把分卷和本卷走向作为提案给作者，确认后落盘；主线事件整体放进提案，价格、数值这类刻度留空，写「到该章问作者」。

**汇报**：按 workflow-outline.md 的汇报模板（开书、大纲、卷纲、细纲、补纲、改细纲共用这一份）。排纲自查是内部核对，只把结论翻成故事话；要问作者的缺口，以及设定互相冲突的情况，都作为「要你定的事」问。没有子代理时，出完卷纲最后一句建议新开对话说「出第1-10章细纲」。

## 排纲方法：交付、自查与对标迁移

卷里放什么、怎么设计，以及章数字数怎么估、关键点放哪、每章松还是紧，都在 outline-methods「卷纲排法」；本节说明交付物、自查和对标迁移。本节以下全部进入排纲任务包。

### 交付物与锁定

按本次交付范围建以下文件（模板见 [artifact-protocols.md](artifact-protocols.md)）：

- **大纲/大纲.md**：分卷表，每卷一行；当前卷写全，后续卷只写功能、核心事件、字数区间，照 `设定/全书梗概.md` 的大转折分卷。
- **大纲/卷纲_第X卷.md**：读者期待、本卷故事线、各段剧情、全卷规矩、情绪弧线（含每章松紧）、人物弧线、伏笔、反转、照对标排的关键位置，不适用的写「无」。
- **追踪不在规划阶段初始化**：开书、大纲、细纲、补纲都不建 `追踪/`；首次进入正文时由 workflow-chapter 处理缺 state（无正文初始化第 0 章，事务 JSON 放书目录 `.story/work/`），核心角色动态快照在首次正文事务中创建。

只交付大纲或卷纲时，完成排纲自查四项和上面的文件后停止，不进细纲。

**卷纲锁定**：某卷一旦有正文章节，该卷已写区间对应的剧情段与对标关键位置就锁定，未经作者确认不改；允许在卷尾**追加**新剧情段（只增不改）。追加只在作者明确要求补纲、扩纲时发生，日更和写正文不自动追加。例外只有一条：正文里新长出的伏笔，由主会话登记时分配下一个编号并追加进本卷伏笔表，不算改卷纲（规则见 SKILL.md「新增物三级」）。workflow-daily 各处「锁定卷纲绝不自动修改」都按这个定义执行。

### 排纲自查

每卷、每批细纲设计前答一遍，逐章不重答：

1. **这卷让读者图什么**：本卷交付什么情绪、靠什么剧情模式交付、核心冲突是什么？每段剧情按 outline-methods「剧情单元设计」排「这段让读者图什么」、过合理性五问，再做两个删除检验：删掉题材核心的对象、关系或问题，或者删掉主角，情绪兑现还基本成立，就说明没立住，先修。
2. **节奏与松紧**：哪段加速、哪段减速；每章松紧有高有低（见 outline-methods「每章松还是紧」）；1/4、中点、3/4 各锚一个关键情节，中途追加剧情段按段内的 1/4、中点、3/4，不改已锁定的卷尺度关键位置。
3. **伏笔与阶段边界**：本卷新埋哪些伏笔，上一卷待收的怎么处理；本卷在全书哪个阶段，可以揭开、用上什么，必须压住什么（全卷压住的写进卷纲「这卷先不能揭开、不能用上的」；某一章确有一件具体的事要压住，才在那章细纲写一行「这章不能说破」）。
4. **四个排纲问题**：按 `references/reader-contract-and-progression.md` 逐段剧情过一遍，把「没问题 / 要补 / 有硬伤」写进剧情段的「有没有硬伤」；有硬伤先修纲，要补就补交换、铺垫或代价，两种都在汇报里告诉作者。不要求主角亲自完成每个动作。

进入细纲层时，每批先按 workflow-outline.md「写纲前查缺」查一遍。

### 对标节奏迁移

有主对标书时，卷纲定稿前做一次。读主对标 `对标/{书}/剧情/节奏.md`；资料缺了怎么办按 benchmark-recall.md。对标登记 ≥2 本时读 `references/cross-book-recall.md`，用副对标 `章节/*_摘要.md` 和 `剧情/*.md` 召回卷级节奏。未登记主对标但有同题材候选时，先回 workflow-setup Phase 1；确实没有对标，就按 outline-methods「常见的八步结构」自排，爽点密度仍按「每章松还是紧」。

1. **选段（以剧情段为单位）**：在主对标里圈出本卷要对标的剧情序列，单位就是拆文产出的 `剧情/{剧情标题}.md`。先读主对标 `剧情/README.md`「剧情单元清单」，有清单就按「类型 / 桥段标签」直接命中同类；没有清单就在 `剧情/*.md` 里按「类型」行（第一键，必填枚举）和「桥段标签 / 套路框架位置」行（第二键）圈同类；仍无命中就按章节范围圈段，全程不阻塞。本卷对标几段剧情 ≈ 本卷字数 ÷ 每段体量（见 outline-methods「排纲刻度」）。
2. **标关键点**：看这几段剧情在 1/4、中点、3/4 各放了什么，判为逆转、转折或激励。摘要里「类型=转折点」的情节点加上基调突变（如温馨转压抑）可以定位候选，再核对它的因果作用；对标剧情的「结构分布」与「情节点索引」也是确定的锚。
3. **换素材**：保留对标的情绪链和功能位，人物、场景、事件全换成本书的，按本书人设重建因果，不照搬具体桥段。功能位清单取 `剧情/情绪模块.md` 的可替换项。
4. **修正硬伤**：换素材前比对 `拆文报告.md`「不建议模仿」。对标在某个关键点处理得弱（慢热留白、主角长期旁观这类已知硬伤），迁移时就在该位置补上缺的关键情节，或把后面的关键情节前置，不把弱处理一起搬过来。
5. **排章、落卷纲**：把换好的关键情节落到本卷相同的相对位置。这里的 1/4、中点、3/4 是卷尺度（总章数×0.25、×0.5、×0.75）；卷里每段剧情内部另有自己的铺垫、逆转、收尾，别和卷尺度的关键点混在一起。关键点之间用普通推进章过渡，每个关键点之后按需插一章呼吸或关系章；写进卷纲「照对标排的关键位置」与情绪弧线的松紧列，细纲承接时每章可标松紧。选中的对标剧情以 {书名}《剧情标题》写入剧情段的「参考对标书哪段剧情」。

例子（demo《让你管账号，你高燃混剪炸全网》）：对标的 1/4 是“小人物拿出粗糙作品，无人看好”，中点是“作品爆火，体制内外同时关注”，3/4 是“专业力量进场替代，反而证明主角不可复制”。换到江晨的军宣线，1/4 是他用手机拍《诸君，且听龙吟》，画质粗糙却拍出了军魂；中点是视频引爆全网和参军热潮；3/4 是专业团队高清重拍，被周薄森指出“缺了灵魂”，最终仍用手机原版。保留“轻视→市场验证→权威替代失败→价值坐实”的情绪链，素材和人物关系都来自本书。
