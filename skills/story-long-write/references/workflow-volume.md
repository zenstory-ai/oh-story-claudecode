# workflow-volume.md：出卷纲

作者要定本卷怎么走时读本文件。主会话自己排，或 story-architect 按任务包排，都照「排纲方法」执行。

## 主会话：读取、分工与汇报

**读取**：[artifact-protocols.md](artifact-protocols.md) 的「大纲/大纲.md」「大纲/卷纲_第X卷.md」两节（含段位契约）；`references/outline-methods.md`「卷纲排法」；`references/reader-contract-and-progression.md` 第 0–3 节与第 5 节（契约四问、核心概念、机构设计、风险三级、续接与换书债，不含第 4 节示例）。有主对标时按「对标节奏迁移」读 `剧情/节奏.md`。设定从 `设定/` 读；只出卷纲不读细纲。其余按下列条件只读点名小节：

- 没有主对标：outline-methods「八节点故事结构」
- 卷纲里有自创单元：outline-methods「情绪模块公式」
- 本卷换大地图或开新地图：outline-methods「换地图」
- 情绪弧线选型拿不准：`references/emotional-arc-design.md`「六种弧线速查」
- 本卷规划了反转：`references/long-reversal.md`「反转类型」
- 对标登记 ≥2 本：`references/cross-book-recall.md`
- 本书有感情线：`references/character-relations.md`「感情线阶段」

**谁来排**：已部署 story-architect 时，卷纲在它的新上下文里出，调用见 [agent-calls.md](agent-calls.md)；主会话拿到后跑 `outline_view.py --check --strict {卷纲路径}`（往旧卷纲追加单元时去掉 `--strict`），按排纲自查 1–4 的结论汇报。没有子代理时，主会话按「排纲方法」自己排：先把分卷和本卷走向作为提案给作者，确认后落盘；主线事件整体放进提案，价格、数值这类刻度留空，写「到该章问作者」。

**汇报**（开书、大纲、卷纲、细纲、补纲、改细纲都用；按 SKILL.md「面向作者的汇报」）：排纲自查、建纲批末复核是内部核对，只把结论翻成故事话；「先问作者」的缺口，以及设定互相冲突的情况，都作为「要你定的事」问。出完卷纲，最后一句建议新开对话说「出第1-10章细纲」，技术备注放在它后面。

## 排纲方法：刻度、交付与对标迁移

卷里放什么、怎么设计见 outline-methods「卷纲排法」；本节说明刻度、交付物、自查和对标迁移。

### 排纲刻度

单章字数按题材节奏档：快节奏（番茄、七猫、男频爽文）约 2000 字，均衡档（起点、晋江）约 3000 字；本书细纲已有惯例的按惯例换算。

| 刻度 | 体量 | 用法 |
|---|---|---|
| 剧情单元 | 1.5–3 万字，约 5–15 章；开篇单元偏短，但要讲完首个矛盾的因果 | 一个矛盾从起到收；单元里有两个以上独立高潮就拆成两个，不按字数拆 |
| 单元兑现 | 每单元一次，从起势到兑现约 3–6 章 | 兑现后可排 1–2 章低压过渡 |
| 大高潮 | 一次从起势到兑现，快节奏约 14–20 章，均衡档不超过约 10 万字 | 拖久了会掉追读；落在卷的 1/4、中点、3/4 和卷末 |
| 卷 | 约 4 个大高潮周期，50–80 章；超过 100 章先拆卷；作者已定卷数就在卷内分上下篇 | 只精排当前卷，后续卷写功能、核心事件、字数区间 |
| 全书 | 卷数 × 卷字数 ≈ 目标字数 | 不预排全书章号，不定全书阶段比例 |
| 打脸小节拍 | 男频打脸文开篇或上架前约 5 章（立人设 1、铺垫 2、打脸 1、反响 1），上架后可拉到 8–10 章 | 单元里的常见节拍，不硬套；不靠打脸推进的书不用 |
| 爽点密度 | 高压章约 15–20%（快节奏可到 30% 以上）；大爽点即单元兑现，不另设章数周期 | 逐章分配见「章节定位与张弛」 |

### 交付物与锁定

按本次交付范围建以下文件（模板见 [artifact-protocols.md](artifact-protocols.md)）：

- **大纲/大纲.md**：分卷表，每卷一行；当前卷写全，后续卷只写功能、核心事件、字数区间。
- **大纲/卷纲_第X卷.md**：本卷故事线（L 编号）、剧情单元卡、情绪弧线（含章节定位）、人物弧线、伏笔、反转、对标结构坐标，以及**刻度台阶、打脸债、压力线轮转**三表，不适用的写「无」。
- **追踪不在规划阶段初始化**：开书、大纲、细纲、补纲都不建 `追踪/`；首次进入正文时由 workflow-chapter 处理缺 state（无正文初始化第 0 章，事务 JSON 放书目录 `.story/work/`），核心角色动态快照在首次正文事务中创建。

只交付大纲或卷纲时，完成排纲自查 1–4 和上面的文件后停止，不进细纲。

**卷纲锁定**：某卷一旦有正文章节，该卷已写区间对应的剧情单元卡与对标结构坐标就锁定，未经作者确认不改；允许在卷尾**追加**新剧情单元卡（只增不改）。追加只在作者明确要求补纲、扩纲时发生，日更和写正文不自动追加。workflow-daily 各处「锁定卷纲绝不自动修改」都按这个定义执行。

### 排纲自查

每卷、每批细纲设计前答一遍，逐章不重答：

1. **情绪引擎**：本卷交付什么情绪、靠什么剧情模式交付、核心冲突是什么？每个单元按 outline-methods「剧情单元设计」排情绪引擎、过合理性五问，再做两个删除检验：删掉题材核心的对象、关系或问题，或者删掉主角，情绪兑现还基本成立，就说明引擎没立住，先修。
2. **节奏与定位**：哪段加速、哪段减速；章节定位有高有低（见「章节定位与张弛」）；1/4、中点、3/4 各锚一个关键情节，中途追加单元按单元内的 1/4、中点、3/4，不改已锁定的卷尺度坐标表。
3. **伏笔与阶段边界**：本卷新埋哪些伏笔，上一卷待收的怎么处理；本卷在全书哪个阶段，可释放什么、必须压住什么（压住的写进细纲「本章禁止提前释放」）。
4. **契约四问**：按 `references/reader-contract-and-progression.md` 逐个剧情单元过一遍，把 契约安全 / 需补强 / 契约破坏 写进单元卡「契约风险」；契约破坏 先修纲，需补强 补交换、铺垫或成本，两种都在汇报里告诉作者。不要求主角亲自完成每个动作。
5. **供给**：进入细纲层时按 workflow-outline.md 批次步骤 3 做供给自查。

### 关键点法

任意尺度（全书、卷、剧情单元、支线、章）都有五个关键点：开场、1/4、中点、3/4、结尾，其中 1/4、中点、3/4 放关键情节。关键情节分三类：

| 类型 | 含义 |
|------|------|
| 情节逆转 | 发展在读者意料内，主角的解决方式让人叫好（装逼打脸、英雄救美） |
| 情节转折 | 意料之外（身份反转、敌变友、局势骤变） |
| 激励情节 | 全书或一卷第一个、和核心主线直接相关的命运改变时刻 |

不必每个尺度都填满三处，但一卷至少在 1/4、中点、3/4 各放一个关键情节，免得全程一个力度。付费平台的第一卷先定上架卡点的高潮，从它倒推开头剧情；卡点前不写和它无关的装逼打脸，核心反派围绕卡点设计。

### 对标节奏迁移

有主对标书时，卷纲定稿前做一次。读主对标 `对标/{书}/剧情/节奏.md`；资料缺失时设置 `missing_primary_contract` 并停止，不得以摘要、故事线或报告代替。对标登记 ≥2 本时读 `references/cross-book-recall.md`，用副对标 `章节/*_摘要.md` 和 `剧情/*.md` 召回卷级节奏。未登记主对标但有同题材候选时，先回 workflow-setup Phase 1；确实没有对标，就按 outline-methods「八节点故事结构」自排，爽点密度仍按「章节定位与张弛」。有 `灵感库/` 时可另按「适用阶段=卷纲」召回 Top 8 active CBA 辅助结构选型，零命中不阻塞。

1. **选段（以剧情单元为单位）**：在主对标里圈出本卷要对标的剧情单元序列，单位就是拆文产出的 `剧情/{剧情标题}.md`。先读主对标 `剧情/README.md`「剧情单元清单」，有清单就按「类型 / 桥段标签」直接命中同类；没有清单就在 `剧情/*.md` 里按「类型」行（第一键，必填枚举）和「桥段标签 / 套路框架位置」行（第二键）圈同类；仍无命中就按章节范围圈段，全程不阻塞。必备权威文件 `剧情/节奏.md`（爆发密度、爽点循环）缺失时，先修复或重跑拆文 Stage 3，不从摘要猜节奏。本卷对标几个剧情单元 ≈ 本卷字数 ÷ 单元体量（见「排纲刻度」）。
2. **标关键点**：看这几个剧情单元在 1/4、中点、3/4 各放了什么，判为逆转、转折或激励。摘要里「类型=转折点」的情节点加上基调突变（如温馨转压抑）可以定位候选，再核对它的因果作用；剧情单元的「结构分布」与「情节点索引」也是确定的锚。
3. **换素材**：保留对标的情绪链和功能位，人物、场景、事件全换成本书的，按本书人设重建因果，不照搬具体桥段。功能位清单取必备权威文件 `剧情/情绪模块.md` 的可替换项；文件缺失时先修复，不生成替代清单。
4. **修正硬伤**：换素材前比对 `拆文报告.md`「不建议模仿」。对标在某个关键点处理得弱（慢热留白、主角长期旁观这类已知硬伤），迁移时就在该位置补上缺的关键情节，或把后面的关键情节前置，不把弱处理一起搬过来。
5. **排章、落卷纲**：把换好的关键情节落到本卷相同的相对位置。这里的 1/4、中点、3/4 是卷尺度（总章数×0.25、×0.5、×0.75）；卷里每个剧情单元内部另有自己的铺垫、逆转、收尾，别和卷尺度的关键点混在一起。关键点之间用普通推进章过渡，每个关键点之后按需插一章呼吸或关系章；写进卷纲「对标结构坐标」与情绪弧线的章节定位列，细纲承接时每章标章节定位。选中的剧情单元以 {书名}《剧情标题》写入剧情单元卡「对标剧情参照」。

例子（demo《让你管账号，你高燃混剪炸全网》）：对标的 1/4 是“小人物拿出粗糙作品，无人看好”，中点是“作品爆火，体制内外同时关注”，3/4 是“专业力量进场替代，反而证明主角不可复制”。换到江晨的军宣线，1/4 是他用手机拍《诸君，且听龙吟》，画质粗糙却拍出了军魂；中点是视频引爆全网和参军热潮；3/4 是专业团队高清重拍，被周薄森指出“缺了灵魂”，最终仍用手机原版。保留“轻视→市场验证→权威替代失败→价值坐实”的情绪链，素材和人物关系都来自本书。

### 章节定位与张弛

一卷里章的压力本就该有高有低。压力级指爆发和冲突的烈度（1 微 / 2 小 / 3 中 / 4 大 / 5 极），和情感烈度分开：关系回收、泪目这类章可以压力低而情感强度顶满，情感烈度由卷纲情绪弧线的「情绪基调 + 强度」承载。章节定位由本章在所属剧情单元里的位置决定，不另贴标签：单元首章多为铺垫或共情，中段承载逆转，收尾爆发收束；黄金开篇、高潮结算加温情这类章可以复合标注（如「高压 + 关系」）或留空。

| 章节定位 | 功能 | 压力级 | 卷内占比（均衡档基线，非硬配额） | 钩子要求 |
|------|------|--------|--------------------------|----------|
| 高压章 | 打脸 / 掉马 / 反转 / 高潮；关键情节落点 | 4-5 | 约 15-20% | 章尾强钩子；承载逆转 / 转折 |
| 普通推进章 | 主线推进、冲突升级、剧情单元中段 | 2-3 | 约 40-50% | 章尾中钩子；至少一个小爽点或期待递进 |
| 修炼试错章 | 实力 / 资源积累、能力铺垫、失败试错 | 2 | 约 5-10% | 进度钩子（差一点 / 即将突破），可无反转 |
| 关系回收章 | 感情线兑现、关系转折、身边人日常 | 2-3 | 约 5-10% | 情感钩子；拉扯仍和主线相关 |
| 低压生活章 | 高潮后喘息、关系升温、张弛调节 | 1-2 | 不超过约 10% | 允许弱钩子或仅情绪钩子；不强求反转 / 爽点 |
| 信息整理章 | 转场、设定交代、时间缝合 | 1 | 不超过约 5%，能并章就并章 | 允许无显性爽点；信息用「表演」承载；结尾给下一段目标 |

两条底线：

- **期待不断，爆发要分散**。低压章可以没有爽点和反转，但每章都要给读者一个往下看的理由（微好奇、阶段目标、暧昧期待）。降的是爆发烈度，往前的拉力不能降，番茄追读尤其看重这点。
- **情绪母题不扎堆**。连续多章同一情绪母题高位运行（如连五章家国、泪目），章节定位分得再开也会疲劳。排情绪弧线时逐行看相邻 3-4 章的情绪基调，同一母题别连超 2-3 章；靠换情绪、换钩子方式、多线穿插拉开差异，不靠砍钩子。

题材分档：番茄短平快和男频事业线，高压可到 30% 以上，呼吸章压到 5% 上下都正常，别拿基线去补呼吸、砍高压；女频、世情、追妻的人设关系容量大，关系章和低压章可以更多，但仍走情绪折线，不必每章三折。低压章和关系章本身是看点（主角身边人的日常就是订阅点），不当填充写。

章节定位决定情节点的功能与展开取舍，不把情节点换算成固定字数，也不靠加点凑目标。写后由程序按双层长度带验收：明显欠长先查已批准的义务是否没写到，容量不足就和作者商量自然长度、补纲或改目标，不自动补写；明显超长可做一次不新增语义、保留批准情节点与章尾钩子的净删型压缩，复检仍在带外就停下。
