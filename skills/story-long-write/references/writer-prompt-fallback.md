# 写手 prompt 手动组装

仅当组装脚本不可运行或用户指定不用脚本时加载。数据缺失导致 exit 2 应修数据后重跑。

   - **prompt 第一行固定，逐字照抄、只替换 `{}`**：`本次任务：{写／续写／补写／重写／就地改}第 {N} 章，范围 {全章／哪几点、哪几段，范围外一字不动}。开始前先按「参考文件体系」逐行独立判定命中并读取，命中即必读，未命中不预加载；交付摘要里报出读了哪几个。`
     - 动作写动手方式、不写「首稿」这类阶段名；退回补写、退化重写、自查返工都照实重填。
     - 这行是**指令**不是材料栏目。**交付摘要没有读取清单 = 这行没传，重 spawn。**
   - 第二行起传本章必需材料：
     - 项目目录、章节、细纲文件（**只给路径，不给全文**）、上一章结尾切片（按整行回退约 400 字，**不给路径**）、输出路径与标题行字面量（使用当前平台的原生路径分隔符，章名从细纲 `### 第 N 章：章名` 解析，标题行形态照既有章）。
     - 写前准备输出：本章意图、本节速记、情绪目标、涉及角色、参考技法、必读设定（**直接写出那几句，不给路径**）。
     - 主对标/拆文路径、主/副对标召回摘要。
     - `selected_emotion_module`、`rhythm_reference` 及来源路径。
     - `genre_prose_card`（题材正文提示卡摘要，只含本章相关条目）。
     - 文风路径、文风召回指令、原文锚点片段。
     - `author_preferences`：作者记忆 `query` 结果中匹配本章的 `prose_style` / `story_design` 项；无则不传，禁止把完整画像或待确认项塞进 prompt；作为低优先级倾向自然吸收，不逐条展示或最大化命中，不牺牲连贯、节奏和字数。
     - 阶段位置、本章结构公式、本章可释放信息、本章禁止提前释放信息。
     - 字数目标、`visible_chars_v1` 口径、格式硬约束；默认两组交付并由主会话测一次 checkpoint；用户明确要求一次成文时才写全章。字数目标按整章分量刻度使用，疏密自行分配，不填写逐情节点配额。
     - **agent 定义里已有的不重述**，只留一行指针：细纲优先边界＝铁律 1、正文形状＝铁律 2、新增物三档＝铁律 3、阅读体验字段（本章标价／闭环状态／信息差触发点／镜头准入档位／情节点分辨率列／执行边界「放」半边）＝铁律 4、交付三附件（时空表／新增申报表含末行「本章没写成的」／参考文件读取清单）＝被调用协议。申报表与「没写成的」行的去向见步骤 12 与 workflow-setup「按剧情批出细纲」步骤 3。
