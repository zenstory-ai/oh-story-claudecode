# 跨书召回

跨书机制与主对标原文分成两条通道：

- `灵感库/`：只提供抽象机制，由带标签的跨书聚合卡统一入口。
- `对标/{主对标书}/`：只提供本书级全局分析、结构块和定点原文证据/文风样本。

当前导入书自身必须从两条通道的对标候选中排除；`拆文库/{当前书}/` 是本书分析，不是外部对标。

## 1. 标签查询

每次设定、卷纲、细纲或正文任务先生成需求标签：

| 轴 | 取值来源 |
|---|---|
| 题材 | `设定/题材定位.md` |
| 读者需求 | 本书读者契约与当前期待债 |
| 情绪 | 本阶段/本章目标情绪 |
| 关系动作 | 当前角色关系要发生的动作，可空 |
| 剧情功能 | 开篇立约、升级兑现、关系翻转、信息揭示、高潮结算等 |
| 节奏位置 | 黄金三章、前期、中段、卷末、高潮前/后，可空 |
| 适用阶段 | 设定、卷纲、细纲或正文 |
| 风险 | 当前要避开的同质化、失衡、铺垫不足、角色降智、兑现拖延等 |

从当前工作区向上定位最近的 `灵感库/灵感索引.csv`。只筛：

- `layer=跨书灵感聚合`
- `status=active`
- 至少命中一个核心轴

精确轴值命中优先，按匹配分、`novel_count`、`atom_count`、CBA ID 稳定排序。读取 Top 3–8 张完整 CBA；候选不足时如实少读，不用 IA/NM 凑数。

## 2. 公共层边界

写作模块只读取命中的 CBA 全卡，不沿来源链接读取 IA/NM。CBA 必须自包含机制链、可变参数、成立条件、反例、不可照搬边界与风险；来源链接只供灵感库维护和审计，不进入写作上下文。CBA、IA、NM 都不作为文风样本，也不触发副书原文读取。

输出 `selected_inspiration_aggregates`：CBA ID、命中标签、机制链、可变参数、成立条件、风险、来源数量。它只影响设计选择，不覆盖细纲事实、项目设定或自定义文风。

## 3. 主对标通道

主对标书最多 1 本，从 `设定/题材定位.md` 读取；字段缺失时从排除当前作品后的候选中稳定选择并报告 `gaps.main_benchmark_unspecified: true`。

1. `全局分析/爆款机制.md` 与 `六维拆书.md` 的“三维节奏”章节提供本书级机制/节奏证据。
2. `structure_blocks.csv` 按目标剧情功能、情绪类型和三维强度选 1 个候选块。
3. 五列 `chapter_index.csv` 只把候选块章号映射到 `source_locator`。
4. 只读取主对标命中的 1–2 章原文，提炼临时风格和锚点；副对标原文不读。
5. 自定义 `设定/文风.md` 含实质内容时仍是最高风格优先级；灵感卡和主对标都不能覆盖。

缺 `爆款机制.md`、`六维拆书.md`（或其中“三维节奏”章节）、`structure_blocks.csv`、五列 `chapter_index.csv` 或主对标原文时，按主契约 fail-fast；不能从索引标题、历史逐章摘要或 CBA 反推原文风格。

## 4. 阶段预算

| 阶段 | CBA 上限 | 主对标原文 |
|---|---:|---:|
| 设定 | 8 | 0 |
| 卷纲 | 8 | 0–1 章 |
| 细纲 | 6 | 0–1 章 |
| 正文 | 3 | 1–2 章 |

## 5. 输出

```markdown
## 跨书灵感召回
| CBA | 命中标签 | 来源小说数/原子数 | 本次用途 | 风险 |
|---|---|---:|---|---|

## 主对标证据召回
- 主对标：
- 结构块：
- 原文章节与 locator：
- 临时文风来源：
- gaps：
```

若不存在公共灵感库，记录 `gaps.inspiration_library_missing: true`，不阻塞无灵感库项目；继续使用本书细纲与主对标通道。若存在但零命中，记录 `gaps.inspiration_tag_no_match: true`，不扩大到 IA/NM 全量读取。
