# 回炉诊断：从症状找原因

> 谁读：大修时作者只说读者反应（「中间拖了」「主角憋屈」「卡住写不下去」）、没指出改哪儿，主会话读。

按症状挑最可能的一两条原因，对照卷纲、细纲和正文找出问题章列给作者选；选定后回 workflow-revision.md 逐章改。问题出在选材或剧情设计时回设定或大纲改，不只润句子。

## 症状对照

| 作者或读者说 | 先查 | 常见原因 | 改法 |
|---|---|---|---|
| 拖、水、不知道这几章在干嘛 | 每章有没有期待点或爽点；剧情期待、每章甜头、新鲜感哪项断了 | 上一个期待兑现了，下一个还没立起来；兑现拖得太久；过渡章没有在推进的线 | 兑现前一两章埋下下一个目标；过渡章至少留一条在推进的线；拖太久的兑现前移；砍掉不服务核心梗的支线。急救：反派新动作、意外、配角陷险、超预期收获 |
| 爽不起来、「就这？」 | 兑现章前后的压与放 | 压得不够或放得太轻 | 兑现前补压力或代价，兑现时写足旁人和局面的变化 |
| 「又是这一套」 | 最近几个单元的核心梗 | 同一个梗连着几次没有变化 | 按 outline-methods.md「剧情单元设计」重构：保留读者要的情绪和功能位，人物、场景、事件、手段全换 |
| 换地图后没意思了 | 新地图前几章 | 旧期待跟着旧地图一起丢了 | 让一条旧目标、旧关系或旧仇跨地图延续 |
| 变味了、不是想看的 | 本单元爽点满足的是哪种需求 | 爽点偏到别的题材的卖点上 | 拉回开书承诺的那种情绪 |
| 主角憋屈、毒、圣母 | reader-contract-and-progression.md 的四个排纲问题 | 叙事立场没站在主角一侧；主角因可避免的蠢事闯祸再由别人收拾；连着几次打破读者期待 | 补主角的筹码、因果权或结算；按题材的读者期待判断，不一刀切成「主角不能吃亏」 |
| 目标有了但读者不在乎 | 目标有没有变成期待 | 只写了要做什么，没写达成后会怎样 | 写清得失和落差；爽文看点放在怎么赢 |
| 卡文，不知道下一步 | 题材、金手指、主角身份 | 三者对不上，循环转不起来；升级后没给新挑战 | 先把三者对齐，再按 outline-methods.md「题材单元循环」选循环；每次提升后马上给新目标 |
| 没人看，说不清好坏 | 写给谁看、他们想看什么、本书给了哪些 | 有一问答不上，或题材选错 | 回 workflow-setup.md Phase 1 或先扫榜，不靠改章解决 |
| 开头留不住人 | 前 3 章 | 开局类型、三基点或背景顺序出了问题 | 按 opening-design.md「开篇落笔」重写；开局本身选错先按「开篇规划」改细纲 |

## 按症状找技法

单元平→`outline-methods.md` 中段加压；打脸不爽、装逼尴尬→`style-combat-face.md`；反转没冲击→`long-reversal.md`；悬念散→`long-suspense.md`；感情线没进展→`character-relations.md`；战力崩→`long-genre-mechanics.md`；情绪写空→`emotional-methods.md`；对话平→`dialogue-mastery.md`；钩子弱→`long-chapter-hooks.md`；AI 味→走 `/story-deslop`。想借同类书重排一段：取对标同类矛盾的情绪链和功能位，按 workflow-volume.md「对标节奏迁移」换成本书的。
