## 第1节：主角卡

### 填空模板

```text template=主角卡
姓名：
性别：
角色定位：（一句话说清主角在故事中的功能）
身份标签：（如：废柴大学生、前特种兵、落魄皇子）
外貌特征：（3-5 个关键词，要有记忆点）
  例：瘦高、总穿旧夹克、左手有疤、眼神懒散
性格关键词：（3-5 个，必须有矛盾面）
  例：嘴毒心软、看似冷漠实则护短、冲动但有底线
核心目标：（全书终点想达成什么）
核心动机：（必须达成的理由——情感驱动，非理性驱动）
致命弱点：（让角色犯错的性格缺陷，非能力缺陷）
口头禅/标志动作：（让读者秒认的标签）
```

### 设计要点

- 动机落在具体情感上——"为母亲复仇"优于"要成为最强"
- 弱点会在关键情节导致犯错，否则不算弱点
- 外貌和口头禅是读者认人的锚点，必填
- 起名贴合时代、地域和文化，别用与设定冲突的现代或政治化名字；写同人或既有世界观时，原著角色沿用官方名，新角色顺原著同地域命名风格，同一地域不混语系

## 第2节：配角卡

### 填空模板

```text template=配角卡
姓名：
性别：
角色功能：（导师/盟友/情报源/牺牲品/镜像对照）
与主角关系：
核心特质：（1-2 个关键词）
标志性特征：（一句话让读者记住）
退场方式：（何时/如何退出故事）
```

### 设计要点

- 每个配角有明确功能——没功能的角色不出场
- 配角退场主动规划，不写着写着忘掉
- 同场配角不超过 3 个有台词
- 起名贴合时代、地域与文化；同人或既有世界观的新配角顺原著同地域风格，不混语系、不塞违和名字

## 第3节：反派设计

### 3.1 反派层级表

按反派要撑多长的剧情选层级，按表格要求设计。

#### 小反派（一个剧情单元内解决）

| 维度 | 要求 |
|------|------|
| 功能 | 一个剧情单元的障碍 |
| 设计 | 1-2 个鲜明特征即可（嚣张/贪财/欺软怕硬） |
| 退场 | 被打败或被揭穿，干脆利落 |

#### 中等反派（一卷的主对手）

| 维度 | 要求 |
|------|------|
| 功能 | 一卷的主要对手 |
| 动机 | 为什么跟主角作对（不能是"纯粹的坏"） |
| 手段 | 武力/权谋/资源 |
| 逼格 | 至少赢主角一次，让读者恨得牙痒 |
| 退场 | 被主角正面击败，要有爽感 |

#### 大弧Boss（一卷或数卷）

| 维度 | 要求 |
|------|------|
| 功能 | 代表一个阶段的核心矛盾 |
| 经历与转变 | 有独立的目标、过往成因与处事逻辑 |
| 冲突 | 与主角有理念冲突（不只是利益冲突） |
| 对决 | 至少一场让主角陷入绝境 |
| 侧面 | 有一个让读者"恨不起来"的侧面 |
| 退场 | 有仪式感的终战 + 有余味的落幕 |

#### 最终Boss（全书）

| 维度 | 要求 |
|------|------|
| 功能 | 全书核心矛盾的具象化 |
| 伏笔 | 从第一章就有 |
| 对立 | 与主角的目标/动机直接对立，代表故事主题的反面 |
| 实力 | 碾压主角，主角必须突破底牌或实力上限才能赢 |
| 信念 | 有信念，不是纯粹的疯子/怪物 |

### 3.2 反派设计铁律

- 反派的智商和实力决定主角获胜的含金量，对手太菜赢了也没味
- 反派的行为必须有内在逻辑（从他的视角说得通）
- 不要让反派降智来给主角送赢

### 3.3 反派建立四要素

按顺序操作，缺一不可：

1. **实力展示**——出场就展示实力或手段
2. **动机可信**——从反派视角看行为说得通
3. **真实威胁**——至少赢主角一次
4. **终极意图时机**——真实目的留到关键反转点

### 3.4 反派性格确立四步法

| 步骤 | 怎么写 |
|------|------|
| 1. 立反派自己的目标 | 在反派眼里他是做正事的人，写清他要保住什么利益或秩序 |
| 2. 补一笔过往成因 | 交代他吃过什么亏、怕掉进什么处境，让狠辣有来处 |
| 3. 让依仗或性格缺陷成死穴 | 顺境靠什么压人（权势、规矩、算计），逆境就因迷信这一招或放大多疑自负而踩空 |
| 4. 与主角形成对照 | 反派精算计或守旧规，刚好撞上主角重情或破局的底线 |

### 3.5 反派分量怎么写出来

- 阻碍顺着反派职位和利益长出来（如掌管考评的人顺手卡资格），别让他干损人不利己的蠢事。
- 先让反派做成一件事（压服旁人或赢主角一局），再让主角抓他赖以压人的规矩、底牌漏洞或内部矛盾反制，不靠反派降智送赢。
- 给核心反派单列目标与筹划，不让他只在主角出场时才动。
- **先让配角试出深浅**：主角对上反派前，先写有本事的配角全力出手仍落败，立实压迫感。
- **换地图不贬旧角色**：进高级地图时，让旧前辈留下的信物、名号或招式依然管用，别靠把旧角色写成废物来抬新地图。

## 第4节：动机设计

### 4.1 动机链模板

```
起因 → 角色经历了什么
意图 → 角色想做什么
约束 → 什么在阻碍他
风险 → 失败的代价是什么
```

**示例**：
```
起因：母亲被仇家杀害
意图：找到凶手并复仇
约束：凶手是当朝权臣，主角只是平民
风险：复仇失败会被灭门，复仇成功会失去所有现有生活
```

### 4.2 动机链设计要点

- 起因必须具体——"被欺负"不够，"在众目睽睽下被打耳光"才行
- 约束必须有力——否则主角一路碾压没有张力
- 风险必须真实——读者要相信主角真的可能失去重要的东西
- 动机可以随剧情演变，但不能说变就变
- 起因从三处找：世界压迫（没实力就自保不了）、金手指带来的利益、亲友的遭遇
- 外力动机之外再给一个内在梦想；目标要贴身份，宗门圣女想救宗门可信，杂役弟子想救宗门就缺说服力

### 4.3 动机冲突类型

遇到角色需要内心挣扎时，从下表选一种冲突类型：

| 类型 | 定义 | 示例 |
|------|------|------|
| 目标 vs 道德 | 想做的事和应该做的事冲突 | 复仇但不想伤及无辜 |
| 情感 vs 利益 | 感性和理性的拉扯 | 知道对方不可靠但放不下 |
| 短期 vs 长期 | 眼前利益和远大目标的矛盾 | 妥协保命 vs 坚持原则赌未来 |
| 自我 vs 他人 | 个人需求和他人期望的冲突 | 想过平静生活但背负家族使命 |

## 第5节：角色塑造方法速查

### 5.1 角色塑造核心原则

**主角行为三必须**：
1. **可理解**——读者明白他为什么这么做
2. **可共鸣**——他的盘算和情绪读者能代入
3. **可接受**——他的底线读者能接受

**展示优于告知**：
- 目的 → 靠行动展示，不靠旁白解释
- 行动 → 写具体动作和决定，不堆形容词
- 态度 → 靠对话和反应体现，不靠独白说明

### 5.2 反差设计

给每个重要角色填三层标签，至少一层和另两层相反：

| 层 | 含义 | 例 |
|---|---|---|
| 身份 | 外界看到的身份 | 豪门弃妇 |
| 表现 | 他展现给外界的行为 | 被骂不还口，被赶不反抗 |
| 内核 | 真实的打算和性格 | 悄悄录音、收证据、提前转走财产 |

- 反差用行为对照写出来，不靠旁白点明；内核留到关键抉择时亮出来，亮得越晚越震撼。
- 找反差可以让外表、身份、爱好、性格两两错位：看着凶实际心软、杀手擅长插花、豪门子弟住地下室。
- 主角和核心配角给一层强反差；功能性配角贴一两个标签就够，不强行立体。要保持神秘和压迫感的高手可以留扁平，写透来历和软处反而显弱。
- 反差太大会劝退一部分读者，按本书读者口味控制尺度。

### 5.3 展示人物特质的方法

| 方法 | 怎么写 | 示例 |
|------|------|------|
| 碰痛处看反应 | 旁人提到痛处时，写他打岔、背身或动作骤停 | 被问脸上巴掌印，少年背过身攥紧课本说“走路摔的” |
| 写他刻意回避什么 | 写他宁可绕远路或说冷话推开好意，也绝不碰某事 | 宁可打黑拳也不让父亲低头求人，立住护短与自尊 |
| 先立闪光点再露短板 | 先写一件让人佩服或心疼的事，再露性格毛病 | 先写深夜苦练护家，再写嘴硬不肯服软 |

### 5.4 配角用法

- 嘴替：主角不便说的话、不便发的狠、不便吃的瘪，交给一个忠心配角或伙伴，主角的逼格不掉。
- 以旧带新：新配角优先从已有角色的亲友、同门或宿敌关系里顺势带出，少凭空天降路人；阶段功能走完的配角及时退场。

### 5.5 配角执念设定法

快速让读者记住支线配角：

- 给角色一个执念，言行喜好围着它转；平时不必句句提，不写违背它的举动，关键时刻亮出来。
- 执念过狠时补一处家常喜好或软肋（如满脑子复仇的刀客路过栗子摊必买一包），方便读者共情。
- 适用：支线配角，不适合高频出场的主要配角。

### 5.6 人物行为重复点设计

维持长篇人设不歪的手法：

- 抓住一个标志性举动，换着场景反复演出来。
- 主线办正事时顺手带出他的习惯动作或怪癖，让推主线和显个性穿插出现。
- 反派和配角也留专属习惯动作，读者一见就认得出。

### 5.7 围绕人设写行为

行为、语言、思维围着人设转。某段剧情逼角色干出违背人设的事，先改剧情，不硬掰人设。

### 5.8 人推事件 vs 事件推人

| 驱动方式 | 怎么写 |
|---------|------|
| 人推事件 | 主角因护短、贪财或执念主动去招惹是非、定下计划 |
| 事件推人 | 天降横祸或仇家上门堵死退路，逼平时藏拙的主角亮出底线 |

## 第6节：主角特殊问题

### 6.1 主角逼格

- 主角必须有逼格——这是读者的代入基础
- 不要写太多降智的内心戏和爆粗口
- 主角可以不完美，但不能让人看不起
- 被挑衅时的反应随实力和阅历变：实力高就轻描淡写，实力不够就隐忍蓄力；气急败坏地反击是毒点

### 6.2 主角红线

以下类型的主角绝对不要写：

| 禁止 | 说明 |
|------|------|
| 圣母型主角 | 以德报怨、拿自己人的利益换好名声，读者要的是痛快；守底线、行善后有回报不算圣母 |
| 无脑战斗机器 | 难以产生情感共鸣 |
| 内核邪恶 | 读者无法代入 |
| 因蠢、圣母心或与实力不符的低级失误犯错 | 读者无法原谅；因不可抗力或信息差犯错可以 |
| 自暴自弃 | 比被欺负更让读者厌恶 |

### 6.3 主角调子起太高怎么办

**危害信号**：能力或地位过早到顶，变成机械秒杀，失去悬念。

**化解方法**：
- **用软肋或规矩束手脚（降调不降人）**——不削战力和尊严，改用亲友安危、身份保密或出手代价限制他，不能无脑平推。
- **错开短板维度**——武力无敌就卡情报、财力或名分，逼他在短板处动脑破局。
- **明面小赚、暗地大赚**——旁人以为给的是寻常赔礼，主角到手却触发独有用途，实际大赚。
- 紧张题材（极道、末世、悬疑）别给随时兜底的靠山，免得消掉危机。

### 6.4 主角开篇立人设

- 人设靠选择立：开篇让主角做一次选择，读者从选择里看出他是什么人。
- 无敌流、认知差这类开局，靠主角怎么用力量的选择立人设，不靠战力展示本身。
- 行动力从三处显：做别人不敢做的事、做别人做不到的事、做别人没想到能这样做的事；行动要有人设上的缘由，不为制造意外崩人设。
- 主角有不讨喜的一面（好色、贪财、记仇）要在开头亮明，后面别突然转性。
- 爽文与升级文开场立住核心人设，全书变化主要放在实力、地位、筹码和关系上，不硬套性格蜕变；追妻、复仇、虐恋等靠关系翻盘的题材，可在关键变故处写出清晰的态度决裂与立场转向。

### 6.5 主角目标独立性

- 主角的目标得是自己的，不能只替别人办事当工具人。就算接别人的差事也要转成自身利益，比如平叛是为了自保、拿认可或资源。
- 自检：随便看一章，主角在主动追什么？说不出来，主角就成了别人的棋子。

### 6.6 穿书、穿游戏的角色选择

- 主角对原世界要相当熟悉，这是最核心的期待感来源；穿进哪个世界一两句交代清楚，不能过了一章还不知道身在何处。
- 选穿越后有强戏剧性、强矛盾的身份（如恶毒女配）。
- 在原世界基础上留信息差给主角探索，可以用原世界知识卡 bug 拿超额收益。

## 质量检查清单

设计完角色后，逐项检查：

### 主角检查

- [ ] 动机是情感层面的（不是"要成为最强"这种空话）
- [ ] 有致命弱点，且会在关键情节导致犯错
- [ ] 外貌有记忆点（3-5 个关键词）
- [ ] 有口头禅或标志动作
- [ ] 逼格在线——不会让读者看不起
- [ ] 没有触碰红线（圣母/无脑战斗机器/内核邪恶/因蠢犯错/自暴自弃）
- [ ] 核心目标和全书主线对齐，而且是主角自己的目标，不是替别人办事
- [ ] 主要角色有三层标签，至少一层反差，用行为对照写出
- [ ] 影响剧情走向的设定（实力、钱、人脉、背景）至少 3 项，爱好只做记忆点

### 配角检查

- [ ] 有明确功能（导师/盟友/情报源/牺牲品/镜像对照）
- [ ] 核心特质 1-2 个关键词能概括
- [ ] 有标志性特征让读者记住
- [ ] 退场方式已规划
- [ ] 同一场景不超过 3 个配角有台词

### 反派检查

- [ ] 按层级表设计，篇幅与层级匹配
- [ ] 出场展示了实力或手段
- [ ] 动机从反派视角说得通
- [ ] 至少赢主角一次（中等反派及以上）
- [ ] 没有降智送赢
- [ ] 大弧Boss有理念冲突（不只是利益冲突）
- [ ] 最终Boss从第一章就有伏笔

### 动机检查

- [ ] 起因具体（不是"被欺负"这种模糊说法）
- [ ] 约束有力（主角不能一路碾压）
- [ ] 风险真实（读者相信主角可能失去重要东西）
- [ ] 动机演变有铺垫，没有说变就变

### 塑造检查

- [ ] 角色目的通过行为展示，不是旁白解释
- [ ] 行为/语言/思维围绕人设展开，没有为剧情改人设
- [ ] 主要角色有行为重复点，维持长篇一致性
- [ ] 配角与主角有明确联系，不会抢主角风头
- [ ] 内核标签在关键抉择时亮出，没有提前用旁白交代
