# 长篇题材包：女频末世天灾囤货

> **核心卖点与分流**：专攻女频重生囤货、多轮天灾、居家美食反差、无 CP 双女主基建及星际向哨/未来科幻；男频战力与规则副本用 `末世规则科幻.md`。

## 1. 故事线设计

- **四大核心主轴**：
  - **倒计时狂囤 + 精准验真双女主**：变现房产退婚追债狂囤衣食医油与防爆改装；无 CP 线可用「一小时后盛夏降雪」等精准气象预言验真，拉过命闺蜜合体扫货。
  - **多轮天灾 + 雇团队建城基建**：极寒 → 洪涝 → 极热 → 酸雨接力；中后期跳出单人囤货上限，雇工程、农学与安保团队建基地护城，匿名易物换硬通货。
  - **领地种田 / 空间通末世**：天灾后期藏锋借势拿下低污染宝地开荒；或现代空间连通末世以食药换黄金双线暴富。
  - **女频星际向哨 / 未来科幻**：穿成低级向导遭压制或流放荒星，借精神海疏导破狂化危机，与高冷哨兵强强互托、零低级雌竞。
- **卷级推进与防崩**：变现狂囤建安全屋或荒星脱险（1–15 章）→ 首轮极寒反杀白眼狼亲戚与渣前任（16–50 章）→ 灾变升级、换防线建基地或星际战区破局 → 灾后安居。

## 2. 常见剧情设计

- **黄金三章切口**：第 1 章砸前世冻死惨剧或 7 天倒计时，速激活空间退婚变现追债，章末卡在首笔货款到账推开冷库门；第 2 章沉浸式实数囤货（现炖卤味、五百袋大米、医药与女性用品、防爆门与太阳能板）并给极品埋回旋镖；第 3 章安全屋完工，渣前任嘲讽她疯，章末预警拉响、暴雪或黑雨骤降。
- **博弈循环与章末断章**：`新天灾预警 → 业主群恐慌 → 女主暖屋吃热饭 → 白眼狼道德绑架或拉人撬门 → 监控防爆门冷静反杀 → 易物换金升级防线`。高频断章：① 室外零下四十度大伯母砸门要米，女主隔对讲端羊排汤掐电源；② 一桶水换金条，空间活水泉冒芽；③ 极寒刚退酸雨砸穿雨棚。
- **毒点红线**：① **禁套男频打怪升级壳**（拒“SSS 异能/战力暴涨”）；② 禁圣母收留白眼狼亲戚前任；③ 禁空间无限后丧失外部生存压力；④ 开书标清无 CP 或 1v1。

## 3. 人物设计

- **主角反差与底线**：女主冷静务实、爱惜自己、有美食执念；对白眼狼心硬如铁，对真善意独居老人留底线。可无 CP 独美，或配情绪稳定、动手能力强的退伍军人/医生/高冷哨兵搭伙，拒绝爹味说教。
- **反派梯队（现实求生私心）**：拿血缘道德绑架的亲戚与吃绝户渣前任（会煽动邻居合围逼捐）→ 业主群带头抢物资的恶霸 → 有组织武装劫匪与基地黑心管事。
- **关系与对话声线**：利落松弛，穿插业主群短行刷屏放大恐慌；星际向哨轨重嘴硬狂化反差与危机互托。

- **视角与切镜**：第三人称贴身女主限知；每轮新灾必做「窗外酷烈 ↔ 室内暖食」双屏反差，借业主群短消息推进群体压迫。

### 切片 A：末世前车行改装（加固越野与百万预算盘算）

```text
末世之后虽然是零元购的天堂，但是大多数的车子都是没有进行过改装的，更何况大部分车进口国内都会进行一些功能上的阉割版，去4S店一百万远远不够，但是去二手车行就不一定了。
顾瓷一到车行，车行老板迎了上来，“小姑娘要修车啊？”
顾瓷摇头，“我想买台越野，价格在50万左右，车架还有车身做加固。”
“这是要改装车啊？”老板有些惊讶，“这可是要报备的。”
顾瓷微笑，“当然，下个星期就去报备。所以你们这里有这种车吗？”
“有一辆，”老板皱起了眉，“但是价格可能比你预期的要贵点，阿尔法罗密欧Stelvio售价一百万，改装费也是不小一笔钱，保守估计也是十万起步。”
```

- **学什么**：从“进口阉割”“车架车身加固”“报备”到一百万售价加十万改装费，用行话实数拍出末世囤货安全感。
