# 长篇流派包：历史架空 / 权谋军史与历史脑洞

## 1. 定位、平台与读者期待

- **一句话定位**：现代人（特种兵/工程师/历史迷/寒门学子）穿越架空或历史节点，沦为忠烈孤子、冷宫废皇子、边关小卒或落魄庶子，靠**现代降维认知、工业科技、诗词才华、权谋算计或历史天幕**绝境翻盘、封侯拜相乃至改写王朝命运。
- **平台倾向**：七猫男频与番茄历史脑洞主力赛道，默认第三人称贴身限知，单章 2150–2500 字（起点可 3000 字），痛快杀伐与家国情怀并重。
- **读者期待**：现代常识碾压古人时的智力爽感 + 忠烈遗孤洗冤反杀奸臣的燃爽 + 练强军、造重器、富一方的基建掌控感。

## 2. 核心梗 / 金手指公式与卷级升级轴

- **四大子路**：① **军史杀伐**（以少胜多、火器/特种战术破敌、杀穿贪腐勋贵）；② **科举文抄/朝堂权谋**（诗词震场、算计政敌、一步步入阁掌权）；③ **种田攀科技**（精盐/肥皂/水泥/火药/商队，拿真金白银换兵权）；④ **历史天幕/直播脑洞**（空中光幕盘点历代帝王或曝光真相，古人集体震撼破防）。
- **卷级升级轴**：保命翻案（县城/宗族/军营）→ 执掌一方（封地基建/边关建功）→ 朝堂清君侧（斗世家/宰执）→ 拓土称霸/工业兴国。**红线**：以读者爽感为先，架空降低考据门槛，历史人物评价遵循当代主流共识。

## 3. 黄金三章打法

- **第 1 章**：首段直接把主角扔进必死绝境（满门忠烈遭抄家、新婚夜被夺兵权逼退婚、边关死士营明天充当炮灰），300 字内交代清楚时代身份与眼下杀机（给不熟历史的读者一句话讲清处境，禁大段史书科普），第 1 章内亮出主角反杀手段/现代底牌并破掉第一道杀局，章末卡在更大权贵压境或圣旨突降。
- **第 2 章**：当众立威！用现代破局法（一首震世词/一招现代练兵法/一场精准反诬）把上门欺辱的世家子弟或贪官当场按翻，赢得首位核心部将/贵人刮目相看。
- **第 3 章**：拿到第一笔立足本钱（封地/兵权/免死诏/第一桶金），同时亮出幕后真正害死家族的朝堂巨鳄。

## 4. 卷内爽点循环与高频章末断章

- **循环节奏**：`朝堂/边关困局（旁人断言必败）→ 主角用现代认知/黑科技悄悄布局 → 公开场合（诗会/大朝会/城头血战）逆转全场 → 皇帝/名将/老儒失态改口 → 升官赐爵拿实权 → 引出更大派系反扑`。
- **高频章末断章**：① 城外十万敌骑压境，主角点燃第一门红衣大炮引线；② 朝堂弹劾声一片，主角当殿甩出贪腐密账；③ 皇帝冷脸拆开边关八百里加急捷报，手猛地一抖；④ 退婚的世家女刚放完狠话，封侯圣旨已抵门前。

## 5. 人设反差、反派梯队与对话声线

- **主角人设**：表面纨绔/废柴/落魄寒门，实则杀伐果断、懂人心算大账；对忠良袍泽护短重义，对奸佞世家斩草除根。
- **反派梯队**：贪婪宗亲/恶奴县令 → 骄横世家嫡子/克扣军饷的监军 → 权倾朝野的奸相/胡虏可汗。
- **对话声线**：半白半古、铿锵有力（禁用生僻文言晦涩词，也禁满嘴「OMG/yyds」出戏梗），朝堂机锋句句见血，军中对话粗犷热辣。
