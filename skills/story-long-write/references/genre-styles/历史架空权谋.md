# 长篇题材包：历史架空 / 权谋军史 / 历史脑洞与谍战

> 穿越架空王朝、历史节点或民国谍战暗线，凭反骨掀桌胆魄、科技情报优势、天幕脑洞或深潜智谋绝境翻盘；底线是行军原料与程序闭环、敌人不降智、朝堂文斗短台词见血。

## 1. 故事线设计

- **核心爽点主轴**：即刻掀桌爽 + 科技/情报降维智斗爽 + 高位反派自我脑补吓出冷汗的掌控感。
- **四大主力引擎**：
  - **杀伐即刻掀桌型**：反骨主角绝不窝囊受气，恶兄欺仆、假道学亲爹设套或世家逼杀时当场翻脸算血账，先立血性再入朝堂军营。
  - **历史脑洞 / 天幕 / 错位帝王系统**：空中光幕曝光历代真相（善用反系统推荐高难选题升维情绪）、老迈帝王绑幼崽系统造反差喜剧，或攀工业科技树让帝王将相破防。
  - **朝堂老六要兵权与民生基建**：老六借忠义大话反绑帝王要实权，百章靠宿敌后怕复盘保鲜；慢热长青可走赋税户籍制度、铁匠基建与克制居家烟火。
  - **民国 / 抗战谍战潜伏**：金手指严控为弱辅助，不给超能武力、不降敌人智商；靠职业壁垒欲擒故纵（海关账目、双人签字、货单暗号留接头空窗），让多阵营按利益理性互验。
- **卷级升级与中后期防崩**：绝境保命翻案 → 执掌一县/封地或潜伏站稳 → 朝堂清君侧/敌后大案反杀 → 拓土兴国或决战收网。严禁前期升级过快（如二十章登基）导致后续无戏可写。

## 2. 常见剧情设计

- **黄金三章切口**：
  - **第 1 章**：极速扔进必死绝境（忠烈孤子遭退婚、寒门庶子入死局、沦陷区账房撞见军火密单、天幕突降长安），简笔立处境（禁史书科普与大脑寄存处），当章亮出反杀手段或脑洞异象，章末卡在权贵压境、圣旨突降或敌特起疑。
  - **第 2 章**：当众掀桌立威，用现代破局法（当殿验盐、引火逼宫、借假密电反扣内鬼）按翻首个中层对手，赢得部将或贵人侧目。
  - **第 3 章**：拿到立足本钱（兵权、盐铁契或核心潜伏身份），切入更高层权贵或敌酋视角，亮出本卷大棋局。
- **卷内博弈与高频断章**：按 `死局逼近 → 现代认知/科技/情报暗中落子 → 公开场合逆转或敌方入套 → 帝王/敌酋失态脑补 → 升官赐爵或暗线升迁 → 更大派系反扑` 推进。高频章末断章：① 敌骑压境，主角点燃改良震天雷引线；② 天幕血字点名功臣将反，满殿骇然；③ 边关捷报送到，皇帝手猛地一抖；④ 敌方探长盯着提单怀疑起最信任的副手。
- **核心毒点雷区**：① 禁前期升级过快崩盘；② 禁朝堂文斗变砖块说教或搬公式，须短台词过招；③ 禁同章串名与男频抗战谍战混流女频民国宅斗。

## 3. 人物设计

- **主角人设与底线**：表面纨绔、落魄或温良守规矩，实则杀伐果断、懂算大账；对忠良袍泽护短重义，对奸佞汉奸斩草除根。
- **反派梯队（各自私心与有效反制）**：贪婪宗亲、恶仆县令与疑心特务（借律法程序与盘查设卡，绝非降智送脸）→ 骄横勋贵、克扣军饷监军与敌伪站长（有派系靠山与反咬手段）→ 权倾朝野奸相、胡虏可汗与敌方最高情报头子。
- **关系张力与说话声口**：半白半古、铿锵短促（禁生僻文言堆砌，禁现代网络热词出戏）；谍战台词冷峻克制、字字双关。

## 4. 正文技巧

- **视角与切镜**：默认第三人称贴身限知，权谋与谍战善用「整场切反派/帝王/敌酋视角」借对手理性脑补拉满心理压迫与爽感。
- **叙述呼吸与对白短打**：朝堂交锋与审讯试探走净白短台词乒乓过招；纯叙述保口语因果与筹码权衡，谍战潜伏章允许低对话但必须写透心理博弈，严禁干硬动作报幕；行军日程与科技原料（轻骑行程、硝石硫磺来源）须交代闭环。
- **刀子物件原则**：只细写折色账册、盐引、提单、军令、印泥等改局实证，严禁堆砌无功能紫檀家具、茶碗材质与庭院风月闲笔。
- **❌ 烂写法**：`他引经据典讲了三百字明朝盐法制度，又喊出“王侯将相宁有种乎”，满堂文官震惊跪服。`
- **✅ 高分改写法**：`韩伯庸把官盐折色册往樊知府案前一推，指节敲在朱批缺口上：“去岁官盐少报三万引，差银全进了盐运司私库。”樊知府茶盏微晃，韩伯庸已掏出印泥放好：“大人，这笔亏空您现在画押补账，还是我明日递京？”`

## 5. 案例片段

### 切片 A（抗战谍战）：职业边界欲擒故纵

```text
“谁是家属？”
“我！我兄弟怎么样了？”一个满脸横肉、穿着灰色长衫的中年男人立刻上前。
林言扫了他一眼，目光掠过对方腰间不自然的隆起，又瞥见走廊里或站或坐、同样装束的另外七个人。
党务调查处。
他们连装都懒得装了。
“命保住了。”林言语气平淡，“识字吗？这里有一份术后注意事项，看完签字。之后若因你们照看不周导致伤势恶化，医院概不负责。”
男人一把抓过那张纸，扫了两眼，勃然变色：
“不能随意移动？那他妈不就是得在你们这儿躺着？老子今天偏要带他走！”
“请便。”林言脱下沾血的手套，递给一旁的护士，“签完字，人你就可以带走。他的死活，与我无关。”
说完，他转身就走。
这叫欲擒故纵。
你越拦，他们越疑心。
你放手，他们反而不敢动了。
```
- **学什么**：用外科医生的冷漠职业边界打欲擒故纵，零硬刚反夺特务主动权。

### 切片 B（朝堂老六权谋）：当殿主动求死镇群臣

```text
云铮将这帮混蛋记在心中的小本本上，又向文帝躬身，大声道：“儿臣自知罪孽深重，请父皇赐罪！”
“赐罪？”
文帝眼中寒芒闪烁，“那你倒是说说，你该当何罪？”
“死罪！”
云铮不假思索，躬身道：“求父皇赐儿臣一死！”
轰！
随着云铮的话音落下，殿内顿时鸦雀无声……
赐死？
云铮竟然主动要求文帝将他赐死？
这是把脑袋吓坏了吧？
所有人的脑袋发懵的看着云铮。
谁都没想到，云铮竟然开口就是求死。
连徐实甫和淑妃兄妹俩都被彻底搞懵了。
```
- **学什么**：反派齐奏贬为庶人，老六皇子直接掀桌求赐死，以反常理重注打乱朝堂节奏、反将群臣一军。
