# 长篇题材包：豪门虐恋追妻

> **核心卖点与底线**：围绕契约联姻、穿书反撩或清醒抽身展开，虐后必有反击或高糖，绝不整卷纯受气。

## 1. 故事线设计

- **三条情绪主轴**：
  - **契约婚 / 穿书保命反撩**：女主为防清算「保命式对你好」或凭务实手艺物理反制（退贵礼留纸条、抠轮椅电池），冷面男主越脑补越自我攻略沦陷，去油不降智。
  - **清醒抽身 / 追妻火葬场**：纪念日冷落或白月光作妖 → 女主心死止损、亮出硬核专业底牌 → 旧日付出与误解延迟曝光 → 男主失态追妻 + 优质男二刺激 → 清算绿茶，按约定独美或高代价复合。
  - **强取豪夺 / 熟男熟女推拉**：地位不对等下的利益博弈与极限拉扯 → 女主借规则与底牌反客为主，主动权翻转。
- **卷级推进与防崩**：婚内错位或痛点破冰（1–30 章）→ 事业掉马、感情拉扯与反派升级（31–80 章）→ 豪门旧账、股权商战与白月光彻底清算（81–150 章）→ 掌权圆满或独立新生。中后期严禁原地反复吵架，须靠事业格局与旧账真相推高矛盾。

## 2. 常见剧情设计

- **黄金三章切口**：
  - **轻喜契约轨**：第 1 章生活对话冷开场，速交代联姻或穿书死局，女主立做反常识务实反制，章末切男主视角释放脑补反差；第 2 章高甜拉扯落地；第 3 章补上独立技能首秀。
  - **追妻抽身轨**：强冲突型直砸偏心现场，用撤担保、财产保全或律师函反咬；体面抽身型先克制搬离并埋旧账暗钩，第 2–3 章重拾硬手艺掉马，让男主摸到旧付出线索失态。
- **常见博弈与章末断章**：绿茶借舆论或长辈施压 → 女主以白纸黑字合同、见证签字或账面实权反设局 → 对手按私心反咬再被封死退路。高频断章：① 晚归男主以为她连夜搬走，推门见她正核对清算单；② 宴会绿茶炫耀赠礼，女主递出财产保全单；③ 散场后男主翻出尘封旧回单/病历，看清当年真正救他的人。
- **毒点红线**：① 严禁无底线虐女主超 15 章不反击，追悔线女主视角戏份 ≥60%；② 严守《民法典》，协议离婚须满 30 天冷静期、次日（第 31 天）方能领证，当场抽身写搬离、起诉或财产保全；③ **严禁男主真出轨或冷暴力羞辱后硬洗白复合**（真出轨一律男二上位或独美）；④ 开书透明排雷（双洁/男二上位/隐婚）。

## 3. 人物设计

- **主角反差与底线**：女主清醒松弛、有独立事业或手艺底牌，止损干脆绝不反复心软；男主前期精明算大账、闷骚克制，破防后迅速认错、唯独对她破例低头。
- **反派梯队（严禁蠢反派递话筒）**：装弱抢功且懂得借规矩/舆论反咬的白月光与绿茶（有真实名利诉求，拆穿时会变招搅局）→ 势利算计的豪门长辈/吸血娘家 → 觊觎股权与承销大盘的商战死敌。
- **关系推拉与声线**：克制锋利、靠短问与停顿拉张力；轻喜轨带娇气吐槽，追妻轨心死后用一句账面实话封喉，绝不喊口号骂街。

## 4. 正文技巧

- **视角与切镜**：默认第三人称贴身女主限知，**关键爽点或散场离去后短切男主视角**释放脑补或旧账破防反差，严禁同场无过渡跳视角。
- **对白短打与叙述呼吸**：纯叙述保留主角内心盘算与口语因果（因为/偏偏/说白了/省得），杜绝摄像头分镜报幕；对白净白短打，不给每句台词硬捆端杯撩发等微动作。
- **刀子物件原则**：每场只细写 1 件能改局、露破绽或翻旧账的关键物件（合同、担保解除函、旧回单），彻底删清骨瓷杯、磨砂门、熨帖西装、咖啡机嗡鸣等无功能贴纸，禁油腻物化称呼（「小女人/小白兔」）与「眸色一暗/喉结轻滚/指节泛白」堆砌。
- ❌ 烂写法（油腻强压 + AI 恋爱套词）：`祝衡眸色一暗，喉结轻滚，骨节分明的大手将舒禾抵在墙角，声音低哑带着宠溺：“小女人，招惹了我还想跑？”舒禾耳尖泛红、指节泛白，彻底软了腿。`
- ✅ 高分改写法（上位者低头 + 真实博弈反咬）：`祝衡降下车窗催她上车，顺手拿公事压人：“城西那份并购底稿今晚得复核，别耽误团队进度。”舒禾直接点开群里刚撤回的排班表递过去：“排班表您十点才改的，上周庆功宴还说公私分明，祝律怎么亲自来堵我？”向来寸步不让的男人卡了半拍，把备用的项目门禁卡推过来：“门禁卡忘还你了，上周那句不算。”`
