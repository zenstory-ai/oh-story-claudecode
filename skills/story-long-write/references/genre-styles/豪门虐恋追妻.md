# 长篇题材包：豪门虐恋追妻

> **核心卖点与底线**：围绕契约联姻、穿书反撩或清醒抽身展开，虐后必有反击或高糖，绝不整卷纯受气；严守《民法典》30 天离婚冷静期，男主真出轨一律男二上位或独美。

## 1. 故事线设计

- **核心爽点路线**：看的是身份差里的「上位者低头」与「清醒反客为主」——前期男主越冷淡精明，后期被女主用真本事、干脆抽身或反套路拿捏得自我攻略、失态追妻，读者越上头。哪怕写追妻虐恋，女主也必须有底牌，绝不让人整卷看受气。
- **三大主流写法**：
  - **契约婚 / 先婚后爱 / 穿书保命反撩**：女主为拿钱或防穿书清算，用「保命式对你好」或反常识务实做派（如退贵礼留账单、按契约明算月钱），冷面霸总越脑补越自我攻略。
  - **清醒抽身 / 追妻火葬场**：纪念日冷落或白月光作妖 → 女主心死止损、亮出专业底牌 → 旧日付出与误解延迟曝光 → 男主失态追妻加优质男二刺激 → 清算绿茶，按开书约定独美、男二上位或高代价复合。
  - **强取豪夺 / 熟男熟女推拉**：地位不对等下的利益博弈与极限拉扯，女主借商业规则与自身底牌反客为主，夺回主动权。
- **分卷换地图与中后期防崩**：婚内错位破冰 → 事业掉马、感情拉扯与反派升级 → 股权商战与白月光清算 → 掌权或独立新生。

## 2. 常见剧情设计

### 黄金三章怎么写

- **第 1 章**：
  - **追妻抽身流**：撞上纪念日冷落或医院偏心白月光，女主不嘶吼，当晚搬离并递撤担保函、冻结共同账户或启动 30 天冷静期，章末切男主推门见空屋与婚戒。
  - **轻喜契约流**：短对话切进闪婚领证或穿书死局，女主立刻明算月钱、退贵礼留账单，章末切男主视角放出意外与自我脑补反差。
- **第 2 章**：

  - **追妻抽身流**：业内小掉马亮本事，同时男主从旧抽屉或回执摸到她当年默默付出的首条线索，骄傲首裂。

### 常见毒点 / 劝退点

- **整卷受气不反击**：绝不能连虐十几章不还手；追悔阶段也以女主视角为主，别写成男主忏悔背景板。
- **无视现实法律与行业常理**：协议离婚须满 30 天冷静期，当天抽身改写搬离、到期拒续或财产保全；商战与行业细节须合基本常理。
- **真出轨或羞辱后硬洗白复合**：身体或精神真出轨、联手害过女主一律男二上位或独美，绝不强行复合。
- **中后期原地反复吵架**：别靠白月光碰一下就吵架水几十章，靠掉马、旧账翻盘与股权商战往上抬。

```text
“对，我就是在审问你，我很好奇，当年你怀着七个月的身孕去医院打胎，究竟是哪个医生同意给你打胎，还是说那孩子根本就没有打掉，而是被你在Y国生下，养在Y国，刚刚那个喊妈咪的小孩子，是不是就是当年那个孩子?”
陆隽深提出的每一个疑问都让夏南枝心惊胆跳。
因为他都猜对了。
```

- **学什么**：借电话里一声「妈咪」引爆审讯，短问层层剥开谎言，「撒谎眼睛乱飘」把旧情熟悉感变成锋利压迫。
