# 长篇流派包：悬疑灵异 / 民俗怪谈与推理破案

> **流派特权**：本流派是长篇唯一授权使用「公平线索回溯」「剥洋葱多层反转」「克制冷静报告腔」与「细思极恐留白」的专属区；其余爽文流派不套用本包公平推理约束。

## 1. 定位、平台与读者期待

- **一句话定位**：围绕「诡异异常 + 严密线索/民俗铁规矩 + 层层剥皮反转」展开，涵盖民俗怪谈（冥婚/纸人/捞尸/盗墓）、刑侦法医破案（含女频探案）与规则/诡异复苏脑洞。
- **平台倾向**：番茄悬疑脑洞与灵异 / 七猫 / 起点。第三人称贴身限知或第一人称冷静亲历均可，单章 2150–2600 字，氛围紧绷、细节精准、线索可回溯。
- **读者期待**：「差一秒就出事」的战栗压迫 + 「回头一看前文全埋好了」的智力快感 + 破戒恶人遭报或凶手伏法的畅快感。

## 2. 核心梗 / 机制公式与卷级升级轴

- **双引擎选型**：
  - **民俗/灵异规则引擎**：`行当铁规矩（3 条明示禁忌）→ 蠢人/恶人破戒 → 异象渐进应验（尸象/身边人变异）→ 翻旧账查源头 → 卡时辰（子时/头七/鸡鸣）破局`。
  - **公平推理/悬疑反转引擎**：`不可能细节落地 → 假结论看似自圆其说 → 微物证（划痕/时间戳/习惯动作）掀翻假底 → 剥洋葱揭露更深黑手`。
- **卷级升级轴**：单元奇案/怪谈串联（每 8–15 章结一个完整案子/诡事），底层由一条跨卷暗线（失踪至亲/十年前旧案/诡异源头组织）串起，每结一案撕开主线一块拼图。

## 3. 黄金三章打法

- **第 1 章**：首段直接砸下「正常日常 + 一个不可能的诡异细节」或「行当铁规矩 + 违规一单」（如捞尸人只捞三天内浮尸，今晚捞上来的死人却已经下葬七年），300 字内立住悚然悬念，不空写阴森环境废话；章末卡在首个不可解释的恐怖异象或死者遗物惊现熟人名字。
- **第 2 章**：展开首轮查证或首次规矩应验（破戒者遭殃/关键证人口径离奇一致），第一个「合理解释」被新证据当场砸碎。
- **第 3 章**：主角凭专业本事（法医/仵作/扎纸匠/特殊感知）锁定首个致命破绽，化险为夷的同时，发现这桩诡事背后竟直指自己或更大阴谋。

## 4. 卷内爽点循环与高频章末断章

- **循环节奏**：`异常入局 → 查证碰壁/口径矛盾 → 假底成立（放松半拍）→ 微物证反杀翻盘 → 凶手破防/邪祟伏诛 → 留下指向主线旧案的新疑点`。
- **高频章末断章**：① 监控/照片角落多出一张不该存在的脸；② 刚锁进柜子的东西位置变了；③ 尸检报告/族谱末页翻出主角自己的名字；④ 一直热心帮忙的盟友背过身露出一抹诡异弧度。

## 5. 人设反差、反派梯队与对话声线

- **主角人设**：极度冷静、观察入微、有职业铁律或异于常人的钝感勇气（越冷静越衬得诡异可怕）；女频探案可配冷面/傲娇搭档并肩破案。
- **反派梯队**：见财起意的破戒蠢人（前期炮灰）→ 藏在熟人里的真凶/邪祟（单元 Boss）→ 操控连环旧案的幕后黑手（全书 Boss）。
- **对话声线**：平实冷静、信息密度高；民俗行家告诫用直接引语且常留半句（「过了子时莫回头」），邪祟开口越家常客气越瘆人。

### 切片 A：黄金开篇（第 1 章前 230 字，铁规矩 + 不可能细节）

```text
我做了十年捞尸人，规矩只有一条：
子时不入水，红衣不打捞。
可今晚十一点半，渡口的老茶馆被人一脚踹开，两个西装男把一只沉甸甸的黑箱子砸在了桌上。
拉链拉开，全是崭新的红票子。
“五十万，现在跟我们下河，捞我妹妹。”
领头那人眼里布满血丝：“她穿着红裙子跳下去的，已经漂到回水湾了。”
我端着茶碗没动：“规矩不能破，另请高明吧。”
那人冷笑一声，从兜里摸出一张湿漉漉的身份证拍在我面前。
我扫了一眼，端碗的手猛地一僵。
照片上那个穿红裙子的女孩，正冲镜头笑——
可她分明三年前就已经火化了，那场葬礼，还是我亲手抬的棺！
```

## 7. 公平反转铁律（本流派专属）与毒点红线

- **公平反转四条**：
  1. **绝不对读者撒谎**：误导来自视角局限、真动作套假原因或只露半截实情；
  2. **摊牌只收旧账**：反转依赖的微物证摊牌前必须已露过面，且关键词前后名称统一（禁同义替换导致回溯失败）；
  3. **假底先促成行动**：第一层假答案必须足够可信并让角色据此行动，再被第二层推翻；
  4. **红鲱鱼必须推剧情**：假线索须推动一段真实支线，不只当空幌子。
- **毒点红线**：① 严禁机械降神（结尾凭空冒出没提过的新凶手或新法宝）；② 严禁一卷换八种新怪物把既有规矩全作废；③ 严禁为了恐怖写无意义血浆堆砌，恐怖来自熟人/日常器物变样与逻辑闭环。
