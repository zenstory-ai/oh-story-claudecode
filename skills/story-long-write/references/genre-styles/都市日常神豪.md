# 长篇流派包：都市日常 / 神豪 / 下山高手与赘婿

## 1. 定位、平台与读者期待

- **一句话定位**：两条高频分支共用都市强代入底座——① **神豪/下山高手/隐藏身份**：满级身份回归都市（神医/战神/隐世大佬/重生商战），护妻宠娃、顺手碾压势利眼与权贵；② **都市日常/经营种田**：重生或凭独门手艺经营小店/赶海/带娃/职场逆袭，日常烟火里高频藏爽点。
- **平台倾向**：七猫男频主力（都市生活与商战）+ 番茄都市日常核心赛道。第三人称贴身限知，单章 2100–2400 字，段均 24–27 字，生活颗粒扎实、接地气。
- **读者期待**：看得懂的真实生活场景 + 身份反差掉马时的极致痛快 + 护短家人/攒钱买房/扬眉吐气的实在踏实感。

## 2. 核心梗 / 金手指公式与卷级升级轴

- **核心公式**：
  - 隐藏身份/神医/战神：`满级底牌藏在平凡皮囊下（外卖员/上门女婿/乡下医生）→ 岳家或权贵极度轻视 → 关键时刻出手救大人物或亮底牌 → 称呼与地位瞬间颠倒`。
  - 重生经营/日常：`时代信息差或一手绝活（厨艺/鉴宝/医术/搞钱眼光）→ 拿具体账单和物价对比算清收益 → 从小摊做到行业标杆，势利亲戚眼红倒贴`。
- **卷级升级轴**：家庭与熟人圈（岳家/亲戚/旧同学）→ 市级商圈与名流圈（豪门/医院/商会）→ 省城乃至国级顶层资源网。

## 3. 黄金三章打法

- **第 1 章**：首段直接把主角钉在「极不公平的现实羞辱或急迫生计」里（离婚协议甩脸上、妹妹急需手术费、老店被房东逼退），300 字内进尖锐对话，第 1 章内亮出主角的真实底牌或独门本事并解决第一个燃眉之急，章末卡在更有分量的大人物登门或对手准备加倍刁难。
- **第 2 章**：正面交锋！让势利岳家/恶霸同行亲自撞在主角底牌上，当场小翻盘（一针救活老总/一道菜惊艳食评家/一通电话叫来顶级大佬）。
- **第 3 章**：收下第一笔硬通货回报（豪宅钥匙/千万诊金/首桶创业金），同时引出压在头上的更大豪门势力或商业对手。

## 4. 卷内爽点循环与高频章末断章

- **循环节奏**：日常烟火（护短/做饭/带娃/算账）与公开打脸（家宴/同学会/拍卖会/病房抢救）交替推进；每 3–4 章必有一次「旁人看走眼 → 大人物弯腰敬茶」的身份落差爽，或「账面真金白银入账」的经营爽。
- **高频章末断章**：① 门外豪车排成长龙、首富亲自下车鞠躬；② 岳母刚撕掉主角送的礼盒，懂行亲戚尖叫那是千万孤品；③ 手术室灯灭、专家束手无策时主角推门；④ 对手放话封杀，主角亮出更高一层人脉电话。

## 5. 人设反差、反派梯队与对话声线

- **主角人设**：表面随和低调甚至有点懒散，碰到底线和家人立刻冷硬果决；绝不窝囊受气超过一章。
- **反派梯队**：拜金岳母/攀比大舅哥/势利同学（前期高频仇恨靶）→ 嚣张富二代/黑心竞争对手（中段打脸对象）→ 地方豪门/幕后财团（卷末 Boss）。
- **对话声线**：浓浓市井烟火气与职场直白口吻；反派势利眼越理直气壮越好，大人物改口称呼（「叶先生」「老神仙」）要干脆利落。

## 6. 真·网文原文语感切片（动笔前校准段长、口语与标点）

### 切片 A：黄金开篇（第 1 章前 220 字，当众羞辱 + 底牌反差）

```text
“签了吧，林渊。”
寿宴正中，岳母王桂兰把离婚协议拍在转盘上，声音亮得全厅听见。
“在苏家白吃白喝三年，除了买菜洗碗还会啥？”
周围几桌亲戚爆出一阵低笑。
大舅哥翘着腿剔牙：“山上下来的高人，兜里有两千块吗？”
林渊没急着拿笔，平静看了眼主座上脸色发灰的老爷子。
“苏老，您心口那股寒气子时前压不住，神仙难救。”
“放屁！”王桂兰拍桌，“敢咒老爷子？保安，轰出去。”
话音未落，老爷子捂住胸口，一口黑血喷在桌布上。
```

```text
“九转回阳针？”

满厅刹那安静，连筷子都没人动。
大舅哥张大嘴，手里的茶杯啪嗒砸在地上：“不可能，他就是个乡下泥腿子！”
下一秒，宴会厅大门被人猛地推开。
江城首富顾振邦一路小跑进来，看都没看苏家人，朝林渊深深弯下腰。
“林神医，您终于下山了！”
```

## 7. 流派专属技法与毒点红线

- **专属技法**：善用具体物价/账单折算生活重量（五百块菜钱 vs 五千万地契）；写好「称呼三级跳」（废物 → 林先生 → 林爷/林神医）。
- **毒点红线**：① 战神/神医文严禁主角一直藏着底牌挨巴掌超过 2 章（变成憋屈虐主）；② 日常经营文严禁流水账记做菜/进货过程，每个动作必须连着赚钱数额、熟客口碑或对手挑衅；③ 女主/家人态度要跟上打脸结果，别主角横推全城了岳母还在无脑骂废物。
