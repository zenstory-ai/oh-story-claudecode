# 长篇题材包：古言宅斗重生

> **核心卖点与底线**：在礼教、嫁妆账本、宫规位分与朝堂权谋网里，借规矩一招毙命反杀偏心婆家与政敌，拿回实权与体面。

## 1. 故事线设计

- **三条主轴模式**：
  - **清醒和离 / 换亲转嫁 / 将门窃功掀桌**：看透夫君偏心宠妾、庶妹抢亲或全家窃取女扮男装军功，不哭闹争宠，盘清嫁妆、借更高皇权或官府先占舆论高地再登门清算，顺势转嫁权臣（真偏心羞辱一律男二上位，不原谅前夫）。
  - **后宫位分晋升**：低位选侍/采女 → 贵人/嫔 → 主位妃 → 贵妃/皇后；可走遭算计逼殉节后反手借高位破局入宫复仇，靠宫规、份例与实绩坐稳主位，不泼茶扯头花。
  - **朝堂女帝 / 双强权谋**：将门孤女、宗室女或寒门女官从查盐引、办军需、立书院切入，借科举党争、兵权粮道与外戚博弈步步掌印，与权臣势均力敌交锋或直指登极。
- **卷级推进与换图**：内宅/低位止损（护嫁妆、立实权靠山）→ 宗祠公堂、宫宴晋位或京城勋贵圈翻盘 → 牵出母族旧案与朝堂党争 → 封诰命、执凤印或登基掌局。民国旧影/督军府宅斗沿用后院博弈与高位护短节奏。

## 2. 常见剧情设计

- **黄金三章切口**：第 1 章极速入局（遭算计逼让嫁妆当场借势暗留物证，或寒冬见夫君双份聘礼羞辱彻底心死定和离），章末亮第一手筹码或搭上高位权臣；第 2 章面对婆母克扣、宠妾栽赃，搬大周律例、嫁妆总簿或官印契书当众回击；第 3 章收回首批嫁妆铺子或拿住阴阳私账，与男主结成利益同盟，引出家宴或御前对质悬念。
- **博弈循环与章末断章**：`礼法施压/软刀栽赃 → 暗留物证或先占贵人舆论高地 → 请安/宗祠/宫宴人证物证齐出反杀 → 反派借家法或宗族反咬再被更高实权压死`。高频断章：① 婆母刚要动家法，内侍捧太后懿旨进门；② 账房跪捧阴阳账册；③ 前夫拦车求回头，车帘挑开露出镇北王冷冽眉眼。
- **毒点红线**：① 严禁女主只靠现代口号硬怼古人（须借律例、宫规与权谋筹码破局）；② 严禁违背古制硬写「女身封摄政王」，女强登极须走女官、监国、太后垂帘或直称女帝；③ 严禁写完爽点后心软原谅真背叛前夫；④ 严禁与男频谍战或女频修仙混流。

## 3. 人物设计

- **主角反差与底线**：女主表面温婉守礼、进退得体，骨子里清醒冷硬、算账精准、拿得起放得下；男主外冷内狠、谋略深沉，唯独对她放低姿态递刀撑腰。
- **反派梯队（各有私心与实操反制）**：护短贪财的婆母与擅借家法立威的宠妾（前期会抢先扣「不敬公婆/挪动公账」大帽）→ 既要体面又贪嫁妆的虚伪前夫与抢姻缘庶妹（中段借姻亲舆论反扑）→ 谋害生母或牵涉朝堂旧案的幕后勋贵（卷末掌权 Boss）。
- **关系与对话声线**：自然半文半白（嫁妆总簿、中馈、体面、和离、且慢、莫怪），忌晦涩生僻文言与现代网络烂梗；上位者端架子绕弯子，女主关键处一句律例礼法直接戳破假面。

## 4. 正文技巧

- **视角与切镜**：第三人称贴身女主限知，关键反杀或放话离场后可借下人递话、宗亲旁观短切前夫/白月光破防瞬间，放大隔空压迫感。
- **对白短打与叙述呼吸**：礼法交锋走简洁对白来回过招，纯叙述保留女主的局势盘算与口语因果，忌空泛心理总结断章与干硬动作报幕。
- **刀子物件原则**：嫁妆总簿、官印契书、族谱、份例、兵部底簿与圣旨是古言硬武器；每场只留 1 件改局势的物证，禁堆雕花器物、茶盏衣饰与庭院光影闲笔。
- ❌ 烂写法（空总结断章）：`谭昭退掉与钱启文的婚约，改嫁镇北侯世子荀晏。她知道，崭新人生即将拉开序幕，负心人终将付出代价。这一夜，注定无人入眠。`
- ✅ 高分改写法（反派设扣 + 礼法反咬）：`钱启文先发制人把休书压在宗亲面前：“她私动公中银两，今日不磕头认错，谭家也别想落个好名声。”谭昭压根没接休书，反而请两位族老当场核对她三年前添妆的六家铺子契约：“夫君说我挪公账，可这六张官印契书挂的都是我母家户头，这三年替钱府填的七千两亏空，宗亲要不要一并算清？”话音刚落，门房便报镇北侯府派人送来清账帖，替她撑住娘家体面。`

## 5. 案例片段

### 切片 A：将门嫡女反杀（借亡兄血衣逼养妹磕头）

```text
长公主：“你要为她求情？”
许靖央抱着那血衣和红缨。
“柔筝既已经被父母收养，便是我的二妹妹，父亲说得对，我理应为二妹妹求情。”
“不过，这次回来，我还带着引领阿兄亡魂归家的使命，二妹妹那一身大红色，确实不妥。”
“所以我想了个折中的办法，就让二妹妹对着阿兄的衣冠，磕满九十九个响头。”
许柔筝猛地出声：“什么？”
许靖央语气柔和，仿佛充满悲悯。
“这样阿兄泉下有知，能感慨你的一片诚心，便不会怪你穿错衣裳了。”
许夫人几乎要跳起来，都有些破音地说：“我的寒儿统领千军万马，绝不会为了一件衣服，就这么刁难自个儿的妹妹！”
```

- **学什么**：顺着父母的话假意求情，反手借亡兄血衣定九十九个响头，礼法柔和却把偏心生母逼至破音。

### 切片 B：清醒断情（前夫与白月光齐破防）

```text
墨雨抬头回道：“姜小姐没来，她说，世子若是想见她，先往将军府下帖再说。”
沈律初气笑了，“我去见她，还需要下帖？她在这摆什么谱？”
墨雨看了看自家主子，虽然笑着，但眸光幽的神色，欲言又止：“姜大小姐还说，还说……”
“她还说什么？快说！”沈律初冷声道。
墨雨无法，只得回道：“姜小姐还说，说她要成亲了……”
“她要成亲了？！！”
沈律初和苏梨落异口同声，打断了墨雨的话，两人脸上都是震惊和不可置信。
墨雨点了点头：“是的，姜小姐说她要成亲了，还说让世子爷你自重，不要再去打扰她。”
```

- **学什么**：借下人递话写人不在场的压迫，一句“先下帖”接“她要成亲了”，让傲慢世子当场失态。
