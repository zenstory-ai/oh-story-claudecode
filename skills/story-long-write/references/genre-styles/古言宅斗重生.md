# 长篇流派包：古言宅斗 / 宫斗权谋与古言重生

## 1. 定位、平台与读者期待

- **一句话定位**：侯府嫡女、落魄正妻或前世惨死重生的主母，在礼法、嫁妆、嫡庶名分与朝堂权谋的规矩网里，以**清醒算计、借规矩反杀、掌中馈收嫁妆、和离改嫁更高位权臣**，把偏心婆家、白莲表妹与薄情夫君踩进泥里。
- **平台倾向**：七猫女频核心主力赛道 + 番茄古言。第三人称贴身限知，单章 2100–2400 字，礼法规矩感与情绪张力并重。
- **读者期待**：「规矩之内一招毙命」的智斗解气 + 嫁妆/账本/名分寸步不让的大女主掌控感 + 与权臣/世子/冷面王爷强强联手的双向护短。

## 2. 核心梗 / 情绪引擎与卷级升级轴

- **三大高频模式**：
  - **重生宅斗 / 换亲换嫁**：前世被庶妹/表妹抢姻缘、掏空嫁妆惨死，重生回到议亲或洞房日，主动把烂亲事推给仇人，自己选外传病弱/克妻实则手握重权的高位男主，看仇人跳进火坑自毁。
  - **和离掌家 / 世情打脸**：寒冬大雪看透夫君偏心表妹，不再争宠哭闹，暗中盘清嫁妆账本、拿捏婆家把柄、谋求一纸和离书，离开后开铺行商/攀上更高位，前夫全家火葬场。
  - **宫斗上位 / 权谋女强**：低位嫔妃或落魄皇女借宗室规矩、太后/帝王猜忌连环设局，步步上位执掌凤印或江山。
- **卷级升级轴**：内宅止损（查账/护嫁妆/拆表妹小局）→ 宗族公堂/侯府翻盘（拿和离书/夺中馈/反手送仇人入坑）→ 京城勋贵与朝堂权谋（与男主结盟查旧案/斗皇室）→ 封诰命/执掌大局。

## 3. 黄金三章打法

- **第 1 章**：首段直接砸下最具刺骨寒意的宅斗现场（寒夜独守空房夫君去陪寒疾表妹、重生回到庶妹求换亲当日、婆母当众逼交十里红妆库房钥匙），300 字内进机锋对话，第 1 章内女主即完成清醒决裂或反常破局决定（不再隐忍，定下和离/换亲/查账之计），章末卡在女主冷眼亮出第一手筹码或反常应下仇人算计。
- **第 2 章**：首次实战交锋！针对婆母克扣、表妹装病栽赃或恶奴欺主，女主不吵不闹，直接搬出宗法、嫁妆单子或人证当众反打，让对方偷鸡不成蚀把米。
- **第 3 章**：收紧第一个筹码（收回嫁妆铺子/拿住府中致命私账/与高位权臣男主建立首次利益交集），同时婆家或仇敌反扑升级，甩出宗族大宴或御前对质悬念。

## 4. 卷内爽点循环与高频章末断章

- **循环节奏**：`礼法名分施压/软刀栽赃 → 女主借规矩顺水推舟暗留物证 → 公开场合（请安/家宴/宗祠/宫宴）人证物证齐出反杀 → 长辈改口/恶人受罚/嫁妆名分回手 → 权臣男主暗中递刀护短升温`。

## 5. 人设反差、反派梯队与对话声线

- **主角人设**：表面温婉端庄、守礼知进退，骨子里极度清醒冷静、算账精准、睚眦必报，拿得起放得下。
