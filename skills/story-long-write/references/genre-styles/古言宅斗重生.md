# 长篇题材包：古言宅斗重生

> **核心卖点与底线**：在礼教、嫁妆账本、宫规位分与朝堂权谋网里，借规矩一招毙命反杀偏心婆家与政敌，拿回实权与体面；真偏心羞辱一律男二上位，绝不原谅渣前夫。

## 1. 故事线设计

- **核心爽点路线**：古言宅斗权谋看的是「借礼教规矩反杀」——对手拿孝道、家法和名声逼人，女主不哭闹也不喊现代口号，顺着对方的规矩反手甩出嫁妆总簿、官印契书或皇权懿旨，把偏心婆家和政敌踩进泥里。
- **三大主流写法**：
  - **清醒和离 / 换亲转嫁 / 将门窃功掀桌**：看透夫君偏心宠妾、庶妹抢亲或全家窃取女扮男装军功，盘清嫁妆、借更高皇权或官府占住舆论高地再登门清算，顺势转嫁权臣（真偏心羞辱一律男二上位，不原谅前夫）。
  - **后宫位分晋升**：低位选侍/采女 → 贵人/嫔 → 主位妃 → 贵妃/皇后；也可遭算计逼殉节后反手借高位入宫复仇，靠宫规、份例与实绩坐稳主位，不泼茶扯头花。
  - **朝堂女帝 / 双强权谋**：将门孤女、宗室女或寒门女官从查盐引、办军需、立书院切入，在科举党争、兵权粮道与外戚博弈里步步掌印，与权臣势均力敌或直指登极。民国旧影、督军府宅斗沿用后院算账与高位护短节奏。
- **分卷换地图与中后期防崩**：内宅止损 → 宗祠宫宴或勋贵圈翻盘 → 母族旧案与朝堂党争 → 封诰命、执凤印或登极。

## 2. 常见剧情设计

### 黄金三章怎么写

- **第 1 章**：
  - **当场心死掀桌**：切进寒冬见夫君给外室置聘礼、花轿换亲或婆家逼让嫁妆，女主不哭闹，暗藏红契账册定和离，章末亮底牌或搭上权臣。
  - **归家立威**：选在忌日受辱或将门凯旋遭窃功，一句礼法顶回偏心生母，章末甩出遗物或战报原件震住全家。
- **第 2 章**：
  - **嫁妆规矩首战**：婆母克扣月例、宠妾装晕栽赃，请族老或府医验查，搬本朝律例与母家铺契让婆家首踢铁板。
  - **借势换靠山**：出府理账或入宫赴宴，替太后、长公主或权臣解隐秘麻烦，换来压得住内宅的令牌或清账帖。
- **第 3 章**：
  - **实利落袋**：收回旺铺或揪出阴阳私账，与权臣定下同盟，章末抛寿宴发难或宗祠公审预告。
  - **名声翻盘**：拆穿毁誉谣言泼回脏水，章末从旧物暗格抖出涉朝堂旧案密信。

### 常见剧情类型库

#### 一、开局破局与止损

1. **换亲改嫁截胡好亲事**
   - **起局**：庶妹或嫡母大婚前暗换庚帖，抢走「金龟婿」，把女主塞给传闻冷厉病弱的权臣，赌她顾名声忍气吞声。
   - **拉扯**：娘家演戏劝她大局为重，庶妹穿嫁衣炫耀；女主暗把母族田契并入嫁妆，顺水推舟让媒婆写死婚书防反悔。

### 常见毒点 / 劝退点

- **现代口号硬怼古人**：不借本朝律例、契书账目与宫规，靠喊「独立女性」怼宗族。
- **违背古制硬写「女身封摄政王」**：女强掌权或登极须走女官、县主诰命、监国、垂帘或女帝。
- **写完爽点心软原谅渣前夫**：真偏心羞辱或谋夺嫁妆后绝不复合，一律男二上位或独美。
- **中后期困在后院扯头花**：不能连写上百章仍只争宠克扣炭火，须抬进田产旧案与朝堂实差。
- **跨题材串味**：把古言宅斗写成了男频谍战或修仙神通。

## 3. 人物设计

- **主角反差与底线**：女主面上温婉知礼、下手按礼法与账册直戳要害；男主宜带朝堂权臣的克制分寸与暗中托底。
- **反派梯队**：护短贪财的婆母与擅借家法立威的宠妾（先扣「不敬公婆/挪公账」大帽）→ 既要体面又贪嫁妆的虚伪前夫与抢姻缘庶妹 → 谋害生母或牵涉朝堂旧案的幕后勋贵。
- **关系拉扯与说话语气**：自然顺口的半文半白（嫁妆账册、中馈、体面、和离、且慢、莫怪），忌晦涩文言与现代烂梗；上位者爱绕弯子，女主关键处一句律例礼法直戳假面。

## 4. 正文技巧

- **人不在场的压迫感**：反杀或离场后，可经转场借下人递话、宗亲旁观短切对手破防，放大「未露面已压得失态」的爽感。
- **古制与证物落地**：重生前世今生时序、衙门职权与公私印信（红契、嫁妆总簿、当票、官印文书）效力须合古制。
- **❌ 烂写法（空总结断章）**：`谭昭退掉与钱启文的婚约，改嫁镇北侯世子荀晏。她知道，崭新人生即将拉开序幕，负心人终将付出代价。这一夜，注定无人入眠。`
- **✅ 高分改写法（反派设扣 + 礼法反咬）**：`钱二夫人先发制人把账册摔在堂上：“库房少了三百两例银，今日不交出对牌，谭氏便别管中馈了。”谭昭不急不慌，反手递上一张城南聚宝斋死当票：“二婶说库房亏空，可这张典当先夫人御赐白玉镯的当票，画押分明是您陪房签的，这笔账要不要请族老一并核清？”话音刚落，门房便报国公府管家捧着官府核验文书登门问话。`

```text
许夫人几乎要跳起来，都有些破音地说：“我的寒儿统领千军万马，绝不会为了一件衣服，就这么刁难自个儿的妹妹！”
```

- **学什么**：顺着父母的话假意求情，反手借亡兄血衣定下九十九个响头，语气柔和礼法周全，却把偏心生母逼到破音。

### 切片 B：清醒断情（前夫与白月光齐破防）

```text
墨雨抬头回道：“姜小姐没来，她说，世子若是想见她，先往将军府下帖再说。”
沈律初气笑了，“我去见她，还需要下帖？她在这摆什么谱？”
墨雨看了看自家主子，虽然笑着，但眸光幽的神色，欲言又止：“姜大小姐还说，还说……”
“她还说什么？快说！”沈律初冷声道。
墨雨无法，只得回道：“姜小姐还说，说她要成亲了……”
“她要成亲了？！！”
沈律初和苏梨落异口同声，打断了墨雨的话，两人脸上都是震惊和不可置信。
墨雨点了点头：“是的，姜小姐说她要成亲了，还说让世子爷你自重，不要再去打扰她。”
```

- **学什么**：借下人递话写人不在场的压迫感，一句「先下帖」接「她要成亲了」，让傲慢世子与白月光当场失态。
