# 长篇流派包：传统玄幻 / 东方仙侠与凡人修仙

## 1. 定位、平台与读者期待

- **一句话定位**：主角遭退婚、夺骨、废灵根或身处残酷底层（杂役/散修/没落世家），凭独门机缘（神秘玉佩/残破小鼎/异火功法/谨慎心性）夺资源、破境界、杀穿宗门与万界。
- **平台倾向**：七猫男频核心大类 + 番茄/起点长青盘。第三人称贴身限知，番茄/七猫单章 2150–2400 字快节奏，起点可 3000 字扎实推进。
- **读者期待**：「莫欺少年穷」的逆袭憋屈释放 + 境界突破与越级斩敌的酣畅感 + 斗法斗智的想象力与逼格。

## 2. 核心梗 / 金手指公式与卷级升级轴

- **分支公式**：
  - **传统升级玄幻**：低谷受辱 + 成长型至宝/传承 → 夺宝/大比/秘境 → 破境越级反杀 → 换更高阶地图。
  - **凡人流 / 长生流**：灵根平庸、资源紧缺 → 极度谨慎、暗藏底牌、算清利弊（打不过就跑，出手必绝后患）→ 靠时间差、阵法丹药或隐藏小鼎以弱胜强。
- **卷级升级轴**：家族/小城（炼气/淬体）→ 宗门外门与内门（筑基/灵境）→ 州府王朝/秘境（金丹/宗师）→ 中州圣地/上界飞升。每卷围绕 1 条清晰境界跃迁 + 1 处核心资源争夺展开。

## 3. 黄金三章打法

- **第 1 章**：直接切入最刺痛的压迫现场（退婚羞辱、灵根被夺、外门管事克扣月例、师兄杀人夺宝），300 字内亮出矛盾与切身赌注，第 1 章内让至宝/传承苏醒或让主角用狠辣果决的手段完成首次反制（起点凡人流可先用一次冷静避险立人设，最迟第 2 章亮机缘），章末卡在更大危机或宗门大比期限。
- **第 2 章**：首次实战/试药验证金手指威力，修为松动或反杀一名追兵，缴获第一份关键修炼资源。
- **第 3 章**：正面回应第 1 章的看轻者（或立下三年/三月之约），当众展露惊人锋芒，顺势带出宗门秘境或幕后黑手悬念。

## 4. 卷内爽点循环与高频章末断章

- **循环节奏**：`受压缺资源 → 冒险/算计夺宝 → 闭关破境（写出脱胎换骨实感）→ 公开比试或生死战越级打脸 → 战利品清点（一样即用、一样换钱、一样留底牌）→ 引出更大敌手`。
- **高频章末断章**：① 雷劫/异象突降宗门震动；② 仇敌带筑基长老杀上门，主角刚出关眼底精光一闪；③ 秘境石门轰开，绝世传承现世；④ 斩杀强敌后从储物袋摸出指向幕后大人物的令牌。

## 5. 人设反差、反派梯队与对话声线

- **主角人设**：小德可缺（记仇、爱财、护短、该补刀绝不留情），大义不失；凡人流讲究「嘴上低调、出手绝户」。
- **反派梯队**：势利同辈/外门管事（小反派）→ 傲慢真传/偏心长老（中反派）→ 敌宗老祖/幕后魔修（卷级 Boss）。
- **对话声线**：带克制古韵但不堆文言辞藻，宗门长辈惜字如金、年轻天骄傲慢张扬、主角出手前话少且句句带杀意。

## 7. 流派专属技法（战斗描写三板斧）与毒点红线

- **战斗描写三板斧（本流派专属）**：
  1. **标准爽战结构**：`气势对拼 → 一句硬话 → 敌人出绝招（铺足威力）→ 主角破招碾压 → 懂行长老/强敌失态点破分量`。
  2. **修仙逼格四锚**：时间尺度（苦修一甲子）、可感规模（一剑断三里江）、无形化有形（抽漫天剑意凝雷）、用典立名（借上古残篇让内行变色）。
  3. **以巧破力三法**：物极必反（冰阵最脆处点阳火）、借力反噬（毒入替身反伤本体）、逆捅阵枢；**每回合只出一招，大招首秀详写，重复招式一笔带过**。
- **毒点红线**：① 严禁开篇前两章一口气塞进 5 个境界、8 个宗门、3 段上古编年史；② 严禁主角战斗靠嘴炮感化或等反派放完大招才动手；③ 严禁无成本连续越两个大境界乱杀导致体系崩盘。
