# 长篇题材包：传统玄幻 / 东方仙侠与凡人修仙

> 遭退婚、夺骨、废灵根或身处底层杂役散修，凭独门机缘与稳健狠劲夺资源、破境界、越级斩敌；底线是战力有标尺、破境有实感、绝不无成本跨境崩盘。

## 1. 故事线设计

- **核心爽点主轴**：「莫欺少年穷」的逆袭释放 + 境界跃迁与越级反杀的酣畅感 + 斗法斗智的想象力与逼格。
- **三轨核心引擎**：
  - **传统废柴大比流**：低谷受辱 + 成长型至宝/传承 → 夺宝/大比/秘境 → 破境越级反杀 → 换更高阶地图。
  - **凡人稳健算账流**：灵根平庸、资源紧缺 → 极度谨慎暗藏底牌，凡事算清利弊后患（打得过补刀绝户、打不过果断遁走）→ 靠时间差、阵法丹药或隐藏小鼎以弱胜强。
  - **道心反诘 / 古典重走流**：重走西游/封神等古典劫数，以严密逻辑当殿反问神佛与宗门潜规则，靠高频辩道交锋立顶级格调。
- **卷级升级与中后期防崩**：家族/小城（炼气/淬体）→ 宗门外门与内门（筑基/灵境）→ 州府王朝/秘境（金丹/宗师）→ 中州圣地/上界飞升。每卷围绕 1 条清晰境界跃迁 + 1 处核心资源争夺展开；换图回扣旧敌旧账、保留老熟人与支出代价，严防战力膨胀或换图清零重开。

## 2. 常见剧情设计

- **黄金三章切口**：
  - **第 1 章**：废柴流直切刺痛压迫现场（退婚羞辱、夺草、克扣月例），速亮赌注并在首章内至宝苏醒完成首次反制；凡人流先用一次冷静避险或残酷修仙法则立稳心性，至宝最迟第 2 章亮出，章末卡在更大危机或期限死局。
  - **第 2 章**：首次实战或试药验证机缘威力，借助普通修士或同阶对手立清战力标尺，完成首杀并缴获第一份关键修炼资源。
  - **第 3 章**：正面回应看轻者或当众展露锋芒（留一半底牌蓄力），顺势带出宗门秘境或幕后黑手悬念。
- **卷内博弈与高频断章**：按 `受压缺资源 → 冒险算计夺宝 → 闭关破境（写出脱胎换骨实感）→ 公开比试或野外生死战越级打脸 → 战利品清点（一样即用、一样换灵石、一样留底牌）→ 引出更大敌手` 循环。高频章末断章：① 雷劫/异象突降宗门震动；② 仇敌带筑基长老杀上门，主角刚出关迎面撞上；③ 秘境石门轰开，绝世传承现世；④ 斩敌摸尸翻出指向幕后大人物的令牌。
- **核心毒点雷区**：① 禁开篇堆空景、全章孤闭打坐签到或前两章灌世界编年史；② 禁嘴炮感化或站桩等反派放大招；③ 禁无成本连越两境致战力崩盘。

## 3. 人物设计

- **主角人设与底线**：小德可缺（记仇、爱财、护短、该补刀绝不留情），大义不失；凡人流讲究「嘴上低调、出手绝户」，遇袭先盘算退路、底牌与灭口成本。
- **反派梯队（各自私心与有效反制）**：势利同辈/外门管事（贪扣资源、善用宗门律条与信息差堵死退路，严禁蠢反派无脑送脸）→ 傲慢真传/偏心长老（护短占名额、借大比规矩压人）→ 敌宗老祖/幕后魔修（布长线杀局与利益网）。
- **关系张力与说话声口**：带克制古韵但不堆生僻文言，长辈惜字如金、天骄傲慢张扬、主角出手前话少且句句见锋，底层杂役散修带实在市井算账气口。

## 4. 正文技巧

- **视角与叙述呼吸**：默认第三人称贴身限知，允许独立切镜展露对手设局或懂行长老震撼；叙述段须揉入主角利害权衡与口语因果（因为/可是/偏偏/省得），禁抽干内心写干硬镜头报幕，对白净白短打不句句捆绑微动作。
- **刀子物件原则**：只细写改局、要命或定身家的法器、灵草、账册与令牌；严禁为显古风硬塞紫檀算盘、黄铜库匙、窗外寒风等无功能材质与空景贴纸。
- **战斗描写三板斧**：① 标准爽战结构：`气势对拼 → 一句硬话 → 敌人出绝招立标尺 → 主角破招碾压 → 懂行长老/强敌失态点破分量`；② 逼格四锚：时间尺度（苦修一甲子）、可感规模（一剑断三里江）、无形化有形（抽剑意凝雷）、用典立名；③ 以巧破力（物极必反、借力反噬、逆捅阵枢），每回合只出一招，大招首秀详写、重复招式一笔带过。
- **❌ 烂写法**：`演武场一片死寂，长老捏碎茶杯怒喝：“炼气三层的废物！”少年突然黑鼎一震，太古剑气破体而出！`
- **✅ 高分改写法**：`青石台前，赵管事把茶碗往案上一顿：“炼气三层也配领丙字药田？滚去挑水！”林砚没争辩，只从袖里摸出执法堂朱漆腰牌往案角一压，抬眼道：“上月失踪的三株血灵芝，王执事让我顺路查账，管事现在带路，还是我请堂里来人？”`

## 5. 案例片段

### 切片 A：道心反诘与古典重走（连续短问立格）

```text
“南赡部洲众生苦难，佛祖念诸众生皆是其子，这是菩萨亲口所言。”
“佛祖神通无量，既有真经妙法，又视众生为子，为何不派菩萨送经东来？为何不亲自传法度人？”
“跋涉十万八千里，历经千难万险，去'求'取真经？”
“皆因法不可轻传乎？”
“众生愚昧，便应受苦吗？”
“若贫僧取不回真经，那南赡部洲便永无正法吗？”
“为佛岂可端坐莲台之上，任世人受苦？”
玄奘的声音陡然拔高：
“这是度人，还是戏人？”
“这是慈悲，还是傲慢？”
```
- **学什么**：不靠挥拳与旁白解说，单句成行连发短问直击神佛潜规则，零动作也能压出顶级逼格。

### 切片 B：凡人底层人情与亮财转折

```text
他赶紧拿着钱跑到隔壁李叔叔家。
此刻，李民正在教训李月月，“你个小屁孩，还知道偷钱了！谁教你的！”
“没人教，我就是不想平安哥挨打。”李月月小手攥在一起，泪水汪汪。
“你……”李民拿起棍子想打，但见李月月可怜兮兮的样子，最终没下去手。
同时，他也看到了门口的江平安。
李民冷声道：“滚。”
江平安赶忙说道：“李叔叔，我是来还钱的。”
“不用，赶紧滚。”李民继续呵斥。
他家里不富裕，被搜刮了几次，没剩下多少东西，可是他知道江平安更穷。
李民既可怜对方，又不想与对方有太多联系，承担更多责任。
江平安没有离开，反而摊开手，里面出现五枚铜币。
“一枚还你们，剩下四枚，我想买四个馒头。”
李民愣住，“你怎么会有这么多钱？”
```
- **学什么**：先用邻里「可怜又怕担责」的冷硬现实压住凡人底色，再亮五枚铜币买馒头钩出金手指悬念。
