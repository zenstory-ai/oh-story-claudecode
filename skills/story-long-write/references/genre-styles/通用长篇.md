# 长篇流派包：通用长篇兜底（冷门 / 跨题材缝合）

> 什么时候读：本书题材不在其余 15 个主力流派包内，或属于高度小众/跨题材缝合时读本包；同时建议优先拆 1 本同赛道对标书补齐语感样本。

## 1. 定位与跨题材缝合原则

- **适用范围**：非主流职场专业文、奇闻民俗经营、冷门历史/科幻/职业幻想、多流派嫁接创新书。
- **缝合铁律**：**主基调定 1 个，副元素只当金手指或外衣**。例如「古风破案 + 系统」，主基调是探案，系统只做线索提示工具；补足两个世界之间的因果衔接，避免塑料拼贴感。单书微创新点不超过 3 个。

## 2. 通用核心梗与卷级升级轴

- **三层骨架**：表层卖点（一眼看懂的职业/身份/设定反差）→ 深层爽点（持续交付的 1 条核心情绪链：专业碾压 / 经营壮大 / 揭秘破局 / 关系升温）→ 长线目标（清晰终局大事）。
- **卷级阶梯**：每卷升级 1 个舞台层级（小圈子/小城 → 行业/州府 → 顶层/全国），每 15–20 章安排一次阶段大高潮，卷末留 1–2 条悬念钩子牵引下卷。

## 3. 黄金三章通用打法

- **第 1 章**：首段 ≤45 字直接把主角丢进当前职业或处境的具体麻烦里（禁大段设定科普、禁纯景物开篇）；300 字内进对话，400 字内亮明核心冲突与切身赌注，第 1 章内亮出主角的独特本事或金手指并给出看得见的局部结果，章末留强断章钩子。
- **第 2 章**：安排一次正面交锋或高难度实操破局，让原本质疑主角的旁人或对手当场吃瘪。
- **第 3 章**：收下首份实在收益（钱/资源/名声/关键盟友），顺势引出卷级主线大目标。

## 4. 卷内爽点循环与章末断章

- **循环节奏**：`具体困境/轻视 → 主角凭独特本事或信息差破局 → 内行与有利害者震撼改口 → 实利落袋 → 新舞台或更高层对手上门`。每 2–3 章一次小兑现，每 8–12 章一次中兑现。
- **高频章末断章**：突发危机打断、关键结果只露半角、大人物意外登门、倒计时逼近或对手暗中落子。

## 5. 真·网文通用竖屏语感切片（校准段长、对话与节奏）

### 切片 A：黄金开篇（直抛处境 + 专业/异能破局）

```text
“林师傅，这幅明代古画要是在今晚拍卖前修不好，咱们画廊就得赔三百万违约金！”
修复室里，老板急得满头大汗，手都在抖。
画案上，那幅价值千万的《秋山行旅图》正中间被人恶意划开了一道半尺长的口子。
旁边高薪请来的老专家摇着头摘下手套：“撕到了命脉画心，神仙来了也补不回原样，准备破产吧。”
林砚站在桌边没说话，只是伸出指尖轻轻拂过画纸边缘。
下一秒，一缕旁人看不见的淡金微光顺着裂口缓缓游走——
画纸背后四百年前画师落笔的每一道走向，在他眼前清晰浮现。
林砚拿起细毫笔，神色平静。
“把门锁上，闲杂人等出去。”
“三个小时，我不仅能把画修好，还能把里面藏着的另一幅真迹起出来！”
```

### 切片 B：打脸交锋与章末卡点

```text
三小时后，拍卖厅后台挤满了鉴定界的泰斗。
那位老专家抱着胳膊冷笑：“年轻人哗众取宠，别把千万古画修成废纸！”
林砚掀开防尘布。
灯光照下的一瞬，满屋专家齐齐倒吸一口凉气！
画心裂痕消失得无影无踪，更骇人的是，旁侧空白处竟多出一枚若隐若现的御赐暗印！
老专家眼镜差点滑落鼻梁：“夹层画？！失传百年的宫廷暗款竟然藏在里面？！”
老板激动得差点跳起来：“三百万违约金不用赔了，这画估价直接翻三倍！”
掌声刚起，林砚手机却突然震动，弹出一条匿名彩信——
照片里，是一把带血的裁纸刀，配文冰冷刺骨：
“画修好了？那下一刀，就划在你妹妹脸上。”
```

## 6. 通用雷区

- ① 严禁冷门题材写成科普论文或百科说明文（专业细节只写能推进冲突和打脸的那 1–2 步）；② 严禁开篇前 500 字铺陈世界观编年史；③ 严禁因为小众就放慢竖屏节奏，保持 ~24 字中位短段、20–35% 对话密度与章末硬钩子。
