# 长篇题材包：幻想言情仙侠

> **核心卖点与底线**：主打退宗换师门团宠、女频迪化显圣与都市玄学直播，靠阶层翻转、护短撑腰与旁观大佬疯狂脑补出爽，拒写枯燥的境界百科。

## 1. 故事线设计

- **核心爽点路线**：女频仙侠玄学不拼境界设定百科，读者追的是「被偏心旧宗赶出门反被顶级新师门宠上天」的阶层翻转、「自己只想蹲山头啃零嘴保命却被大能脑补成绝世高人」的迪化喜感，以及「下山直播算命当场联动警方破邪」的痛快打脸。
- **三大主流写法**：
  - **退宗换师门 / 反替身白月光内卷**：核心是护短团宠加打脸旧宗。偏心旧宗夺机缘便果断碎玉退宗，拜入穷酸却全员大佬的新师门；或全员宠她的早死白月光觉醒掀桌内卷、锤醒冤种师兄，截断替身剧本。
  - **女频迪化显圣**：死守「少开口、不解释、务实保命」铁律，炖汤、挪破法器、喂寻常灵兽等日常小动作在大能眼里全是无上布局，靠信息差脑补稳坐神坛。
  - **古言 / 都市玄学神算**：山门传人或真千金下山直播算命打假、拆穿借运换命，**首秀必拿警方或官府核实背书**撑起硬核可信度。
- **分卷换地图与中后期防崩**：退宗或玄学获官方背书 → 大比重案扬名、旧宗惨败对照 → 秘境血脉旧案 → 镇压邪修。

## 2. 常见剧情设计

### 黄金三章怎么写

- **第 1 章**：
  - **退宗/迪化显圣流**：切进刑堂逼挖灵根、旧宗逼让机缘，或蹲院煮面遭嚣张长老堵门现场，短对话干脆碎玉退宗或无意引动古宝，章末卡强援登场或大能石化。
  - **玄学直播流**：真千金被塞杂物间开播赚香火钱遭群嘲，首卦三句点破连麦人家藏血案，章末卡屏幕露马脚喊「反锁门打 110」。
- **第 2 章**：
  - **退宗/迪化流**：兑现阶层翻转与脑补——穷酸新师门隐世大佬抢塞灵矿法宝，或炼丹长老把她随手动作脑补成上古秘法奉厚礼。
  - **玄学直播流**：警方核实抓人发通告，弹幕秒变跪求算卦，豪门与同行震动，首笔卦金落袋。
- **第 3 章**：
  - **退宗/迪化流**：借测灵碑炸裂或丹炉异象坐实名声，短切旧宗震惊不信视角，抛宗门大比打脸悬念。
  - **玄学直播流**：寿宴或旧宅正面破邪拆穿假千金借运局，打脸偏心父母并锁定幕后邪修。

### 常见毒点 / 劝退点

- **退宗后心软替旧师尊挡刀解毒**：前头碎玉断亲后头圣母回头，读者立刻弃文。
- **前三章堆砌修炼境界百科**：开篇抄一大篇灵气体系与宗门史，剧情原地不动极劝退。
- **空口神棍缺实证**：玄学算命不落具体因果与警方/官府核实，显得假水。
- **迪化女主多嘴解释破梗**：大能正脑补精彩，女主硬解释「我是普通人」砸烂喜感。
- **护短团宠把女主写成挂件**：大佬撑腰给底气，关键破局与打脸必须由女主亲手出彩。

## 3. 人物设计

- **主角反差与底线**：女主惜命务实、碎玉断亲绝不圣母回头；男主可带清冷仙尊或偏执魔尊气场但守平视分寸；护短师门众师兄与灵宠各有鲜明腔调。
- **反派梯队**：装弱抢功且善借宗规舆论扮可怜的绿茶小师妹或假千金 → 嘴上大义实则贪图灵脉气运的偏心旧师尊与豪门父母 → 幕后布借运大阵或操控邪魔的高阶黑手。
- **关系拉扯与说话语气**：修仙线清雅利落忌晦涩古文；玄学线接地气直球配简短 `【弹幕】`；迪化高人台词越短、留白越多，越方便旁人脑补。

## 4. 正文技巧

- **脑补反应层与旧宗对照**：爽点落地时紧跟两三句大能脑补或弹幕震惊放大逼格；退宗流中后期定期切回旧宗惨败对照。
- **迪化留白**：迪化线女主少解释、多留白，把「解说」交给旁观大能与弹幕。
- **❌ 烂写法**：`她面无表情不说话，周身散发淡淡白光，大魔头一看便误以为她是神女，吓得茶杯粉碎。`
- **✅ 高分改写法**：`祝明月蹲在炭火边心疼刚滚了一层灰的烤红薯，顺手把角落那口裂纹残剑匣拉过来挡风：“早知道不贪便宜买这破铁盒了。”来寻衅的岳长老刚迈进院门，盯着匣面上陡然亮起的金纹剑阵，脚步僵在青石阶上，脸色发白，反手一掌把身旁叫嚣的内门弟子按跪在地：“孽徒无状，还不给前辈磕头赔罪！”`
