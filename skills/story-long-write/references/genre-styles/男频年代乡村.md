# 长篇题材包：男频年代 / 赶山打猎与渔村致富

> 重生回六零至九零年代农村、林区或渔村，凭赶山打猎、赶海摸鱼、老手艺或时代眼光弥补亏欠、硬刚村霸与极品、把妻女养得红润富足；底线是年代物价合规、妻女防备有台阶、绝不当憋屈傻孝子。

## 1. 故事线设计

- **核心爽点路线**：「前世亏欠妻女 → 今生第一口肥肉塞进妻女嘴里」的踏实暖爽，配上进山打大货、退潮捞海产的寻宝发财爽，加上干脆分家、踩实极品亲戚与黑心贩子的解气感，三条爽感交替推进。
- **三大主流写法**：
  - **悔悟护妻宠女流**：开局立刻扭转混账窝囊烂名声，该分家就断亲、该扯花布买零嘴就舍得花钱。关键要把妻女对浪子骤变的警惕写实——先疑「事出反常必有妖」，再靠不逼迫和实在行动一步步化开心防，忌一键原谅。
  - **硬核赶山 / 赶海实操流**：无金手指或弱外挂也照样抓人追读。东北赶山靠下套、辨踪、挖山珍药材换票证；海边赶海靠看潮汛、辨水温找鱼群、挑流刺网规格与光诱集鱼，出货必须走供销社、外贸站或国营饭店，避开投机倒把红线。
  - **九零下岗创业流**：趁下岗潮和改开风口开电脑房、网吧或抢硬件与网游代理，善用父子斗嘴或家庭信息差造轻喜反差。
- **分卷换地图与中后期防崩**：解决温饱与分家立户 → 打通供销社与县城外贸站 → 承包山林渔场或南下办厂；家境改善后让媳妇管账撑场面。

## 2. 常见剧情设计

### 黄金三章怎么写
- **前 3 章人物交集**：护妻或家庭线前 3 章须落夫妻或家人正面交集，忌光顾打猎算账。
- **第 1 章（两条开局）**：
  - *重生救妻止损*：切最戳心年代窘境（妻女啃冻薯、逼典嫁妆、小妹险换亲），抄家伙护短止损，章末卡拎野味进门或拍桌分家。
  - *硬核赶山赶海 / 九零创业*：踩雪林脚印、退大潮险礁或九八下岗现场，亮辨踪看潮土法或先知眼光抢首单，章末卡撞大货或极品上门。
- **第 2 章（分家与暖心防）**：
  - *大队部算账分家*：请大队长族老算清工分口粮旧账，签字搬进破屋，绝不当憋屈傻孝子。
  - *冷灶炖肉破防备*：炖油水肉汤，面对媳妇警惕绝不硬逼，靠守夜护娃、主动担活、把肉留给妻女等实在举动一点点化心防。
- **第 3 章（变现与财路展开）**：
  - *反杀贩子搭国营线*：识破二道贩子压秤，直敲国营饭店外贸站现结大团结、扯花布白面。
  - *引村霸与大货线索*：家境转红引村霸举报，套出深山珍稀药材、暗礁名贵海鱼或县城风口财路。

### 常见剧情类型库（排大纲 / 细纲直接挑选组合）

#### 一、开局起势与立威

1. **重生护妻与大队部算账分家**
   - **起局与赌注**：前世信偏心老娘和懒兄嫂害死妻女，重生回抢媳妇月子鸡蛋这天，不分家注定再被吸干骨髓。
   - **铺垫与拉扯**：老娘哭闹孝道，嫂子造谣，媳妇护紧孩子怕再挨打；主角请大队长会计族老把三年工分口粮账拍炕桌。
   - **爆发与爽点落地**：账清全村看懂兄嫂吸血，大队长主持签字分家；主角搬破屋当晚炖野鸡蘑菇汤馋得兄嫂摔碗，媳妇红眶盛热汤。
   - **防俗变体与承接**：不写老娘天天堵门骂街，改成兄嫂断饭票偷偷给村霸递话害主角。

2. **雪夜深山辨踪搏野猪王掘山珍**
   - **起局与赌注**：大雪封山快断顿，老猎人放风黑松林有伤人三百斤野猪王，主角急换棉袄粮票背土铳套索进山，失手即丧命。
   - **铺垫与拉扯**：懒汉笑送死；主角亮真土法——看雪痕断重、捻树蹭痕辨公母、逆风架滑扣绊索掩体，雪窝死盯两钟头。
   - **爆发与爽点落地**：一枪封眼借绊索绊倒补刀放血，歇脚在老松根认出五品叶百年老山参系红绳起出；扛大货回村轰动全队，肉香飘半屯。
   - **防俗变体与承接**：平价匀大队部几十斤肉换合法山货证明，整支山参进县城变大钱。

3. **退大潮险礁掏大黄鱼与青蟹窝**
   - **起局与赌注**：渔村家只剩漏水破舢板，渔霸霸好渔场嘲不懂潮汛，不冒险凑不齐旧账与媳妇药钱。
   - **铺垫与拉扯**：初一大退潮渔民守平滩，笑主角钻「鬼牙暗礁」找死；主角凭看水色辨水温老经验掐四十分钟低潮窗，带钩竿密网进沉船礁缝。
   - **爆发与爽点落地**：电筒一照满窝肥青蟹与金黄野生大黄鱼，连拉两网装三桶踩头浪撤回；码头掀席满场惊呼、渔霸眼红，高价抢货声震天。
   - **防俗变体与承接**：留两尾最肥海鱼拎镇水产站，搭上跳过渔霸直供县外贸冷库的门路。

#### 二、中期核心大高潮与变现

4. **识破压秤直敲国营饭店现结**
   - **起局与赌注**：扛活山鸡海货进镇，车站二道贩子看衣裳补丁唱双簧压秤给半价，不卖天黑货死更亏。
   - **铺垫与拉扯**：贩子胡扯品相差严查无人收，帮闲起哄；主角瞥秤砣底吸铁石暗记扎袋就走，贩子放话离他卖不出。
   - **爆发与爽点落地**：直敲国营饭店后厨掀背篓青苔，急缺硬菜大厨高价现结大团结另塞全国粮票肉票求长供；切贩子追来被厨师长轰走。
   - **防俗变体与承接**：顺口打听供销社下月紧缺干货药材，散卖变长期包销。

5. **村霸借投机倒把扣货亮公章反杀**
   - **起局与赌注**：家底刚厚，村霸勾结眼红族亲或贩子半路拦截，扣「投机倒把」帽子强没收整车山货干货，扣即血本无归。
   - **铺垫与拉扯**：帮闲堵路、乡亲捏汗；主角不动声色，等对方真动手强扣、把柄坐实才开口。
   - **爆发与爽点落地**：亮出盖红大印的县外贸站或供销社公账统购单，反逼对方在扣押条上签字担阻挠公家采购的责；村霸腿软缩手，反被公社撤职记过。
   - **防俗变体与承接**：借机拿红头批文成全乡首个合法承包荒山滩涂带头人。

6. **县城摆摊或九零创业反打假**
   - **起局与赌注**：改开风口或九八下岗，摆摊或开首家电脑房网吧爆火，隔壁同行连环举报「无证假货」，停业即血本无归。
   - **铺垫与拉扯**：工商税务突击查账，同行街对面冷笑，老爹拍腿怪瞎折腾；主角开业头天已把进货发票、检疫证与执照原件裱框备齐。
   - **爆发与爽点落地**：摊开全套票证项项合规，反递同行店公证买的贴牌假货请领导抽查；切同行被查封罚半年利润，趁势盘下对面黄金铺扩店。
   - **防俗变体与承接**：穿插父子斗嘴轻喜——老爹前秒骂不务正业，见百元大钞秒改口帮看店。

#### 三、节奏调剂与副线爽点

7. **供销社扯花布交账本化心防**
   - **起局与赌注**：前世亏欠太深，媳妇仍偷把零钱缝鞋底防主角犯浑，夫妻间隔最后一层薄冰。
   - **铺垫与拉扯**：逛供销社遭售货员冷眼、长舌妇讥讽打肿脸充胖子；主角拍大团结扯碎花布抱麦乳精奶糖，冷脸护短呛懵长舌妇。
   - **爆发与爽点落地**：骑新二八大杠风光进村，关门把存折粮票结款单全交媳妇「往后进出账归你管」；媳妇攥账本泪落彻底交心。
   - **防俗变体与承接**：媳妇不沦为端饭木偶，心细识字很快查出收购账目动脚猫腻。

8. **城里势利亲戚看轻反被大佬敬重**
   - **起局与赌注**：进城赴寿宴提顶级野菌海味礼盒，遭势利大舅哥嫌土味塞到门边吹风角落桌。
   - **铺垫与拉扯**：亲戚炫耀进厂当干事，把土特产塞桌底嘲讽媳妇嫁错人；主角护妻女安稳吃饭，门清对方厂里急求自己供货。
   - **爆发与爽点落地**：国营食品厂厂长拎礼登门，绕开满屋亲戚直奔角落桌握主角手致谢，笑称大舅哥转正全看主角面子；亲戚涨红脸抱回礼盒赔笑，媳妇扬眉吐气。
   - **防俗变体与承接**：厂长透露省城展销会下月开幕，引主角迈出乡县。

#### 四、换地图与中后期破局

9. **修路办加工厂用分红砸碎谣言**
   - **起局与赌注**：盖首栋青砖瓦房成万元户，有人造谣吸村里血不管大伙，且雨季泥路陷车卡死出货。
   - **铺垫与拉扯**：提合股修路办干货厂，泼皮造谣卷款致几户半夜闹退股；主角退钱贴息自己垫资买机器，留十几户老实人干。
   - **爆发与爽点落地**：腊月二十八出口结款，晒场摆八仙桌唱名发分红，钞票比种三年地还多；切退股泼皮兄嫂悔拍大腿求入股，修水泥路成带头人。
   - **防俗变体与承接**：加工厂红火动县城垄断大户奶酪，掀起货源战。

10. **承包荒山大渔船硬刚垄断大户**
    - **起局与赌注**：招标千亩荒山或远海大渔船，县城黑心垄断大户抬门槛放话抢标就封杀冷库车队。
    - **铺垫与拉扯**：合伙亲戚吓撤资，大户假笑劝回村打猎；夫妻盘资产凭省外贸三年保底意向书办农行贷款，约邻县回程国营车队绕封锁。
    - **爆发与爽点落地**：大户压管理费想白捡便宜，主角亮高价、育林休渔方案与授信夺标；大户封杀却见邻县车队排长龙装货气铁青，主角晋全县实业大户。
    - **防俗变体与承接**：收编被克扣的老船长林场技术员，建闯省城硬核班底。

11. **进城建厂跑南下商路坐稳体面人家**
    - **起局与赌注**：八九十年代大潮涌来，县城见顶；夫妻进省城建标准食品厂南下考察，直面沿海大厂外商，走错即赔光家底。
    - **铺垫与拉扯**：省城展销会麻袋样品遭冷眼挤厕所拐角；媳妇连夜设计原产地礼盒，主角开水现场冲煮凭野生硬品质香翻半厅客商。
    - **爆发与爽点落地**：闭幕签百货大楼与南方出口百万大单，买院楼送女读名校；切昔日势利眼看电视领奖新闻失语，夫妻补完前世亏欠。
    - **防俗变体与承接**：致富不忘根，反哺老家建希望小学与养殖合作社，烟火格局兼得。

### 常见毒点 / 劝退点
- **憋屈傻孝子**：分家还被老娘哭两声拿捏，反复贴补吸血兄嫂。
- **物价穿帮大厂词**：六七十年代写几万块巨款，或满嘴「商业帝国」。
- **无视时代红线**：六七十年代私卖统购物资不走供销社公账；**83–84 后已包产到户取消公社工分，改现金与收购站磅单，勿把工分套进八十年代中后期**。
- **妻女一键原谅变木偶**：一碗肉立刻毫无防备，后期只剩端饭抹泪没成长。
- **赶山写成百科**：光科普习性参数，不折算成锅里肉香与手里大团结。

## 3. 人物设计

- **主角人设与底线**：对外粗粝狠辣、算账精明，对妻女护短担当，绝不拿妻女委屈换名声。同时保留啃凉馍馋肉、被媳妇戳穿偷藏私房钱就认怂的烟火反差，和前世亏欠妻女的揪心苦处。
- **反派梯队**：前期是拿孝道和村里名声绑架的偏心爹娘与贪心兄嫂（开局三章内干脆割席）→ 中期是拿「投机倒把」「村规」扣货卡人的黑心贩子与村霸 → 后期是垄断县城货源的黑心大户。
- **关系拉扯与说话语气**：浓厚乡土烟火口语（称呼「媳妇」「大队长」「同志」「大团结」），吵架呛人短促带劲，对妻女少喊肉麻情话、多办实事，严禁现代网络热词出戏。

## 4. 正文技巧

- **实物换算与土法实感**：收获直接落到五花肉、麦乳精、新棉袄与大团结，赶山辨踪、赶海看潮与计量称重贴合生活常理。
- **❌ 烂写法**：`佟大力霸气说道：“我要打造全国最大的农产品商业帝国！”村里人纷纷佩服。`
- **✅ 高分改写法**：`张二赖横在村口拿村规卡人：“私拉山货算投机倒把，这车干蘑菇先扣大队部！”佟大力先不争辩，等他伸手碰麻绳才慢悠悠掏出县外贸站公账收购单：“二赖子，这趟走外贸出口统购，你扣公家货得先写扣押条，敢不敢签字？老姜带联防队就在前头候着。”张二赖瞄见红章，讪讪缩手让开半步。`

## 5. 案例片段

### 切片 A：深山打货换粮 · 六零乡土物价烟火气

```text
“婶子，是我，赵叔在家吗？”周苍一边往里走一边问道。
“在呢！没吃饭呢吧，快上炕一块吃点！”炕上一个中年男人道，正是赵开山。
“不吃了，赵叔，我打了几只野鸡，想跟队上换点粮食，您看？”周苍看着炕桌上的饭菜，几个苞米面饼子，白菜汤，一碟子大酱。看来这年头生产队长家也没啥油水。
“行啊，以前你爹也经常用山货来队上换东西，你想换点啥？”赵开山一边问一边拿起两个饼子递给周苍。他的两个儿子盯着野鸡直吞口水，狠狠咬着饼子。
“这是四只野鸡，一公三母，您看看给我换点粮食土豆啥的吧。”周苍没接饼子，指着地上的野鸡说道。
“行，那给你十斤高粱米，半袋子土豆，再拿两颗白菜，咋样？”
```
- **学什么**：用苞米面饼子配大酱和小孩盯野鸡吞口水写实饥荒年代，四只野鸡直换十斤高粱米，实物换算接地气又抓人。

### 切片 B：前世混账重生 · 系腕红绳破媳妇防备

```text
许正给李清鱼擦拭完身体，而李清鱼怀里的小九也吃饱喝足沉沉睡去。
刚生完孩子的李清鱼早已精疲力尽有了困意，但她害怕自己睡着之后，许正或者许母会偷偷把孩子丢了，所以一直强打起精神不敢睡着。
许正也明白李清鱼的担心，他先是把盆里的水端了出去，随后他拿着一个绳子回到屋子内。
在李清鱼警惕和不解的眼神中，许正把绳子的两头分别系在李清鱼和孩子的手腕上。
做完这些许正道：“这下你和孩子绑在一起了，如果有什么动静，你肯定会醒过来，现在你好好休息一下吧，我去给你弄点吃的。”
```
- **学什么**：忌一碗肉一键原谅，用「绳子系住母女手腕」的实在动作化开心防，写出浪子回头的踏实温度。
