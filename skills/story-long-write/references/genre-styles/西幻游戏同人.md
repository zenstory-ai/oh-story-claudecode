# 长篇流派包：西幻 / 游戏电竞与动漫同人衍生

## 1. 定位、平台与读者期待

- **一句话定位**：覆盖番茄与起点三大特色高热垂类——① **动漫/N次元同人衍生**（番茄高频热门垂类）：携系统/先知进入已知热门 IP 世界，截胡机缘、弥补意难平悲剧、当众改写名场面；② **游戏体育/电竞网游**：全息游戏卡 bug 首杀、职业赛场绝境翻盘、体育系统登顶世界之巅；③ **西方奇幻/骑士领主**：魔法/魔药/骑士晋升/领地种田，用异界规则与智谋攀爬神座。
- **平台倾向**：番茄男频动漫衍生与游戏体育增速极快，起点西幻/同人基本盘深厚。第三人称贴身限知，单章 2150–2600 字，节奏明快、名场面冲击力强。
- **读者期待**：「已知世界闯入新变量后，原著强者集体震惊」的蝴蝶效应爽感 + 电竞/网游「全服公告首杀 + 弹幕爆炸」的热血燃感 + 西幻低位崛起的奇幻沉浸感。

## 2. 核心梗 / 机制公式与卷级升级轴

- **三大垂类核心引擎**：
  - **同人衍生**：`明确穿入世界与精准时间锚点（1-2句交代清，照顾没看过原著的读者）+ 专属金手指/新身份变量 + 改写原著意难平名场面（救下必死人气角色/截胡顶级战力）`。**爽感优先于死抠原著考据**，但原著角色沿用官方本名、守住核心性格底色。
  - **游戏电竞/体育**：`清晰数值/操作/战术壁垒（前世记忆/神级反应/隐藏职业）→ 赛场/副本绝境逆风翻盘 → 全服系统公告/解说失声/直播弹幕狂潮`。
  - **西幻骑士/领主**：`魔法、血脉、神权契约真正影响角色选择（不只把修仙换皮成魔法词）→ 低位起步（马奴/边境落魄男爵）→ 靠奇观魔法/领地基建/骑士晋升步步封公称王`。
- **卷级升级轴**：新手村/次级联赛/初入原著剧情节点 → 全服争霸/国际赛场/主线核心大战改命 → 跨越阵营/融合多世界/登顶巅峰传奇。

## 3. 黄金三章打法

- **第 1 章**：首段直接切入最具辨识度的名场面或竞技现场（如「再睁眼，正站在木叶/海贼/诡秘关键剧情前夜」「全息网游开服一秒，直奔前世无人发现的唯一隐藏职业」「赛点局被战队当背锅侠踢出首发」「边境冷堡里即将被恶毒叔叔夺爵」），300 字内立住冲突与目标，第 1 章内亮出金手指/前世情报并拿到第一个超预期先机，章末卡在首场硬仗或全服/原著强者侧目。
- **第 2 章**：实战兑现！拿下全服唯一首杀、当众在训练赛打穿新首发、用现代战术/隐藏魔法反杀轻视自己的骑士长，或提前截住原著即将领盒饭的关键角色。
- **第 3 章**：全服公告炸屏/直播间弹幕狂飙/原著顶流大佬亲自登门招揽，收割第一波实打实声望与核心装备，同时引出下一阶段强敌或大赛。

## 4. 卷内爽点循环与高频章末断章

- **循环节奏**：
  - 同人：`熟悉名场面逼近（读者提前紧张）→ 主角凭变量截胡改命 → 原著人物从质疑变震撼动容（震惊熟人最带感）→ 收获超额羁绊与实力`。
  - 电竞/游戏：`对手嘲讽/赛前唱衰 → 主角掏出绝活套路或神级微操逆风翻盘 → 解说吼破音 + 弹幕满屏问号 + 俱乐部疯狂加价`。
- **高频章末断章**：① 金色全服公告连刷三条，各大公会会长齐齐变色；② 比赛决胜团战只剩一丝血，主角嘴角勾起「该收网了」；③ 原著中本该在此刻黑化/惨死的核心角色，突然挡在主角身前；④ 异界神殿钟声骤响，尘封百年的骑士契约苏醒。

## 5. 人设反差、反派梯队与对话声线

- **主角人设**：操作犀利、脑子极活、敢打敢拼（电竞/游戏带点骚话和极强胜负欲；同人主角懂梗又护短；西幻主角沉稳隐忍有野心）。
- **反派梯队**：傲慢俱乐部经理/抢功队友/原著经典反派/贪婪大贵族 → 国际卫冕冠军/顶级公会霸主/异界教廷与魔王。
- **对话声线**：电竞网游极度口语化、节奏疾快，穿插解说与弹幕烘托现场燃度；西幻保留清爽优雅的异界腔但**绝不写晦涩翻译腔**；同人贴合原著角色经典口吻。

## 7. 流派专属技法与毒点红线

- **专属技法**：同人文重点写「改写悲剧后原著人物的情绪震动（激动/愧疚/释然）」而不只喊「好强」；电竞/网游把关键操作拆成 3–4 拍短促动作 + 实时弹幕/解说；西幻起名统一语系不混搭。
- **毒点红线**：① 同人严禁假设所有读者都背过原著设定（1–2 句顺手补足当前处境）；② 游戏文严禁连贴三大屏属性面板和装备词条；③ 西幻严禁满篇生硬欧美翻译腔（「噢，我亲爱的老伙计，见鬼的！」）。
