# 长篇流派包：年代重生 / 随军致富与女频种田经商

## 1. 定位、平台与读者期待

- **一句话定位**：女主重生或穿书到七八十年代（或古代荒年/流放路上），手撕重男轻女的吸血娘家与极品婆家，凭**先知眼光、灵泉/物资空间或一门手艺**搞钱致富、养崽护短，顺手拿下高冷军官/糙汉/潜力股男主，把日子越过越红火。
- **平台倾向**：七猫女频与番茄女频稳定主力赛道，默认第三人称贴身限知，单章 2100–2300 字，烟火气足、账目清晰、打脸极品干脆痛快。
- **读者期待**：「从一穷二白被欺负 → 偷偷数钞票/屯满粮食 → 极品亲戚眼红干瞪眼」的发家踏实感 + 军官/糙汉男主在外冷硬、回家洗尿布交存折的极致反差甜。

## 2. 核心梗 / 金手指公式与卷级升级轴

- **两大分支引擎**：
  - **七零八零年代文**：`前世被吸血/顶替名额惨死 → 重生回下乡/嫁人/分家节点 → 断亲分家不内耗 + 空间/时代信息差（倒腾布料/考大学/开饭馆/摆摊）+ 随军大院护短日常`。
  - **古代种田/流放逃荒**：`开局抄家流放/旱灾断粮 → 随身空间/现代农商技术 → 荒野吃肉喝汤气哭仇人 → 安家开荒建作坊成皇商`。
- **卷级升级轴**：分家立户/手撕极品（挣到第一笔百元/千两，解决温饱）→ 镇上/县城/军区大院站稳脚跟（开小店/考学/打脸对照组）→ 进军省城/京城实业做大（时代风口爆发、极品亲戚彻底落魄求上门被冷拒）。

## 3. 黄金三章打法

- **第 1 章**：首段 ≤40 字直接切入最窝火的年代/种田绝境（亲妈抢回城名额给懒弟弟、极品婆家把女主和病娃赶进漏雨柴房、流放路上官差抢干粮），300 字内进尖锐吵架或断亲交锋，第 1 章内女主立住泼辣清醒人设并激活空间/亮出先知反手一击（绝不憋屈挨打），章末卡在拿到分家字据/意外发现巨款或军官男主归来。
- **第 2 章**：火速完成第一次搞钱或改善伙食（黑市换粮票/卖卤肉大爆/空间拿出精米白面给娃补身子），肉香味飘满院子馋哭隔壁极品亲戚！
- **第 3 章**：极品上门找茬抢东西被女主和男主（或大队长）当众联手打脸，拿到第一份硬通货存款（如大团结三百块），引出随军/进城摆摊或更大发家商机。

## 4. 卷内爽点循环与高频章末断章

- **循环节奏**：`极品亲戚/对照组看扁挑衅 → 女主靠手艺/空间/眼光低调发大财 → 当众掏钞票、盖青砖瓦房、穿的确良、考状元狠狠打脸 → 极品贪心抄作业翻车自毁 → 回家和男主/萌娃数钱吃肉温馨发糖`。
- **高频章末断章**：① 极品大嫂笃定女主卖卤肉要亏本，下一秒国营饭店采购经理亲自上门包圆；② 随军大院里有人造谣女主是乡下村姑，团长丈夫当众提着菜篮子低头认错求回家；③ 抄家流放途中荒山断水，女主悄悄在空间里挖出甘甜山泉；④ 高考恢复/改革开放风声传来，女主早已囤下第一批紧俏货。

## 5. 人设反差、反派梯队与对话声线

- **主角人设**：泼辣爽利、护短精明、极度会过日子算细账，对家人掏心掏肺，对极品一毛不拔。男主多为硬朗沉默糙汉/高冷军官，嘴笨手勤，津贴存折上交、外头护妻第一名。
- **反派梯队**：重男轻女亲妈/偷懒吸血哥嫂/刻薄婆母（前期必打脸）→ 抢功劳的堂姐/大院嘴碎对照组（中段对照爽）→ 黑心倒爷/觊觎生意的奸商恶霸（后期商战打脸）。
- **对话声线**：地道鲜活的市井乡土口语（工分、粮票、大团结、的确良、缝纫机、供销社、三转一响），句句算钱算粮，鲜活不土尬。

“林晚，把你那份供销社售货员的工作名额让给你弟！”
一九七八年深秋，堂屋里烟雾缭绕。
亲妈王翠花一巴掌拍在八仙桌上，理直气壮得像在施舍。
“你一个丫头片子迟早要嫁人，留着铁饭碗干啥？你弟下个月娶媳妇，没正式工作人家女方不肯过门！”
旁边，游手好闲的弟弟林宝根翘着二郎腿磕瓜子：“就是，姐，你明天去镇上把字签了，顺便把你攒的那八十块津贴也拿出来，我要买块上海牌手表。”
刚从末世带着百平百货空间穿过来的林晚，听得直接气笑了。
前世原主就是心软让了工作，最后被卖给邻村老光棍换彩礼，活活折磨死！
林晚一把抓起桌上的搪瓷缸，哗啦一声泼在林宝根裤裆上！
“想要我工作？行啊，拿五百块买断钱，再请大队长写份断亲书！”
“不给？那我现在就去公社举报你家偷倒粮票！”
