# 长篇流派包：现言脑洞 / 快穿 / 穿书读心弹幕

## 1. 定位、平台与读者期待

- **一句话定位**：女主穿进虐文/贵族学院/豪门狗血书，或绑定快穿/弹幕/心声/奇葩直播系统，拒绝按原剧情当受气包炮灰，靠**反套路吐槽、信息差拆台、沙雕发疯或花式攻略**把原书男女主与反派玩崩，拿满事业收益与双向偏爱。
- **平台倾向**：番茄女频核心增量（快穿/现言脑洞/弹幕读心），默认第三人称贴身限知（穿书吐槽也可第一人称），单章 2100–2300 字，段中位 ~23 字，轻快爽脆、网感极强。
- **读者期待**：打破虐文窝囊套路的解压感 + 「弹幕/全家偷听女主内心疯狂吐槽」的反差笑点 + 既赚大钱又顺手拿捏高冷大佬的双重满足。

## 2. 核心梗 / 金手指公式与卷级升级轴

- **三大核心引擎**：
  - **全家读心 / 吃瓜系统**：女主以为自己在心里偷偷吐槽真假千金/渣男出轨/反派下场，不知全员都能听见她的心声，原本偏心的父母哥哥瞬间倒戈护短、提前反杀白莲花。
  - **弹幕剧透 / 穿书撕剧本**：眼前飘过剧透弹幕，女主果断选第三选项（不争渣男，直接收分手费抱反派大腿或专心搞钱），弹幕从骂她恋爱脑变成全员跪舔磕 CP。
  - **快穿炮灰逆袭**：每 15–30 章一个小世界（校园/豪门/古言/末世），每个世界立清原主死局与爽点目标，通关拿积分强化主线马甲，主线穿插同一灵魂切片男主。
- **卷级升级轴**：撕烂原定炮灰剧本（保命拿钱）→ 拆穿真假千金/白莲花连环局（全家/全网倒戈）→ 事业破圈与反派大佬双向奔赴 → 揭开穿书/快穿底层真相。

## 3. 黄金三章打法

- **第 1 章**：首段 ≤35 字直接甩出穿书/快穿炸裂开局（如正在签净身出户协议、正要被假千金推下楼梯、眼前突然飘过剧透弹幕），300 字内亮出金手指（吃瓜系统/弹幕/心声泄露）并立刻制造**第一场反套路爆笑打脸**，章末卡在反派或高冷男主听见女主离谱心声后瞳孔地震。
- **第 2 章**：趁热打铁！女主按系统提示或吃瓜信息反手拿捏第一个极品（当众揭穿假怀孕/把巨坑转给白莲花），拿第一笔真金白银或关键靠山。
- **第 3 章**：全员态度开始剧烈反转，女主以为自己只是苟命拿钱，高冷大佬/原本厌恶她的哥哥却开始反常投喂，同时冒出原书更大剧情杀危机。

## 4. 卷内爽点循环与高频章末断章

- **循环节奏**：`原书毒剧情/反派作妖逼近 → 女主心里疯狂吃瓜吐槽或卡系统 bug → 听见心声的众人当场变脸替她撑腰/提前拆穿反派 → 弹幕刷屏沸腾 + 女主收钱搞事业 → 顺手撩得大佬耳红破防`。
- **高频章末断章**：① 女主心里刚骂完某大佬暗恋自己十年，一抬头正撞上对方死死盯着她的幽深眼神；② 吃瓜系统突然弹出惊天大瓜【叮！今天宴会上有人要炸真假千金的 DNA 报告！】；③ 快穿任务倒计时仅剩一小时，原书反派却提前黑化堵门。

## 5. 人设反差、反派梯队与对话声线

- **主角人设**：表面乖巧/咸鱼/只想拿分手费躺平，内心弹幕机、吃瓜一级选手、三观极正且绝不内耗。
- **反派梯队**：茶艺假千金/普信原男主（高频搞笑打脸靶）→ 吸血亲戚/幕后操盘原女主（中段升级对手）→ 试图纠正剧情的世界意识/快穿幕后黑手（卷末 Boss）。
- **对话声线**：鲜活现代网感口语；心里吐槽可以贱、可以沙雕，弹幕用 `【……】` 拟人化吵架磕 CP，和外部正经豪门/古风场景撞出强烈喜剧感。

## 7. 流派专属技法与毒点红线

- **专属技法**：保留 `【弹幕/系统】` 人格化吐槽与心里小剧场反差；脑洞规则推到极致（每隔 3–5 章玩出新吃瓜场景或新反套路用法）；快穿每个世界收尾干脆利落，不拖泥带水。
- **毒点红线**：① 严禁女主明明手握读心/弹幕外挂却还傻傻中反派低级圈套；② 严禁搞笑吐槽后突然硬拗沉重说教大道理；③ 严禁搬运过时冷梗超过两句不嵌进剧情。
