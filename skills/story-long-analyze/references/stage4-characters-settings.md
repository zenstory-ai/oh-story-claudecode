# Stage 4：角色、设定与关系

Stage 4 时刻读本文件与 [synthesis-inputs.md](synthesis-inputs.md)（取料、证据等级、阶段标记与事实保真）。

## 归一与建档规则

从 `digest --part chapters --fields 涉及,状态变化` 和批次 `关系变化` 归一人物，结合 Stage 3 剧情单元建档（跨章人物合并与别名均在此做）。按作用分级（不唯出场数；拿不准归低一级）：

| 定位 | 标准 | 建档深度 |
|---|---|---|
| 主角 | 推动主线、贯穿全书 | 完整档案＋成长弧线＋动机链 |
| 反派 | 与主角对立推动核心冲突（无固定反派可无） | 完整档案＋动机链 |
| 核心配角 | 推动重要支线，或反复直接互动/关键导师 | 完整档案＋关系 |
| 功能角色 | 提供信息、道具或一次性互动 | 简化档案：功能＋首出场章 |
| 不建档 | 一次性无台词路人、群体称呼及非固定指代泛称 | 跳过 |

- **一人一实体与别名**：不同人不合并，拿不准分开建；仅本名与有明确同指证据的绰号/带名职务合并（主条目用首次正式名，别名注依据）。
- **金手指**：相互关联的能力合为一个，独立来源分开写；写清获取、机制、进化史（无则注明）。
- **人物关系**：只从已提取情节点与 `关系变化` 整理，不重读原文；有向关系分开记（甲保护乙≠乙依赖甲），主记录留最新状态、附演变轨迹（`第N章：状态A → 第M章：状态B｜触发｜情感转变`）。无直接互动仅凭第三方评价标 `B`/`C`；主角/核心配角关系 <3 查漏、>10 查重，不凑数。

## 输出模板

按主题拆文件与导入/长篇写作对齐；硬事实核对批次证据，原文未给写「原文未明确」：

- `角色/{角色名}.md`：定位｜200–500 字档案（身份→时序经历→性格→能力→人际→成长）｜3–5 个关键转折｜成长弧线（或「稳定人设，无明显弧线」）｜别名及依据。
- `设定/世界观/背景设定.md`：世界类型、核心规则、特殊设定，以及不足 200 字无法独立成文的体系/地理/势力（现实题材写「无特殊世界观设定」）。
- `设定/世界观/力量体系.md` / `地理.md` / `设定/势力/{势力名}.md`：各 ≥200 字且成体系时独立建档，否则并入 `背景设定.md` 不丢信息。
- `设定/世界观/金手指.md`：类型（系统/空间/重生/穿越/特殊体质/神器/血脉/其他）｜名称｜300–600 字能力/获取/机制/进化史｜核心机制｜当前能力（无则写「本书无明显金手指设定」）。
- `角色/角色关系.md`：
  `| 关系ID | 主体 → 客体 | 关系动作/类型 | 表面关系 | 真实关系 | 触发事件 | 双方得失 | 变化后状态 | 证据等级 | 证据 |`
  （动作写保护/控制/欺骗/竞争等，类型写家人/师徒/敌人/恋人/上下级等；证据等级 `A/B/C`，保留最新状态与历史演变。）

## 人物关系图

只从 `角色/角色关系.md` 生成，不手画：

```bash
for PYBIN in python3 python py; do "$PYBIN" -c "" 2>/dev/null && break; done
"$PYBIN" "{story-long-analyze skill 根}/scripts/render_relation_chart.py" --root "{拆文目录}" --png
```

固定输出主产物 `人物关系图/人物关系图.md`（Mermaid＋中文清单）；有 matplotlib 且中文字体齐全时另出 `核心人物关系.png` 与 `关键关系演变.png`（不画表情符号，字体不全不出拼音版，把 `author_message` 转告作者）。
