# Stage 0–1：概要初稿与黄金三章

开头时刻（Phase 1 到 Stage 1 停下来问）读本文件。作者读到的 `快速预览.md` 与停下来问的话术见 [author-facing.md](author-facing.md)。

## Stage 0 机械索引与概要初稿

全新和部分完成且要读原文时先建索引（原文放置见 SKILL.md「运行约定」）：

```text
"{PYTHON}" "{story-long-analyze skill 根}/scripts/build_chapter_index.py" --source "{拆文目录}/原文/原文.txt" --output "{拆文目录}/chapter_index.csv" --locator-path "原文/原文.txt"
```

完整旧成果直接使用或纯增强时不建索引。原文变化或章号对不上时脚本会停下并返回 `author_message`，按 [index-rebuild.md](index-rebuild.md) 处理。

概要初稿只基于章节标题、卷段结构和抽样开头/结尾，写约 200 字，不写 500–1000 字的剧情与因果——读取范围不足，完整版由 Stage 5 覆盖（见 [stage5-report.md](stage5-report.md)「完整概要」）。逐章标题和字数在 `chapter_index.csv` 里，概要不列。

```markdown
# 概要：{书名}

总章数：{N}
总字数：{X}万
题材：{类型}

| 卷/段 | 章节范围 | 章数 | 预估字数 |
|-------|----------|------|----------|
| {卷名} | 第1-X章 | {N} | {W}万 |

## 首版概要

{约 200 字：从章节标题和第 1 章、末章抽样归纳出的核心驱动、主角名、大致设定，不硬凑剧情转折}
```

「总章数：N」逐行写，检查器靠这一行认总章数。Stage 5 只替换「首版概要」一节，基本信息和卷段表保留。

## Stage 1 黄金三章

黄金三章拆为三个单章文件，每章一个：`章节/第1章_深度拆解.md`、`章节/第2章_深度拆解.md`、`章节/第3章_深度拆解.md`。每个文件按以下模板输出。

字数约{X}字 | 核心事件：{一句话}；原文不足三章时只拆已有章节，不补造缺章。

**开篇钩子**（第1章看前500字）：类型{悬念/冲突/反差/信息差/代入感} | 手法{描述} | 效果{强/中/弱}—{原因}

**人物出场**：{列表} | 主角塑造{直接描写/对话/行为/他人评价} | 第一印象{描述}

**世界观铺设**：透露{信息} | 隐藏{信息} | 方式{对话/旁白/事件}

**结构拆解**：| 段落范围 | 功能{铺垫/冲突/爽点/收尾} | 字数 |

**爽点分析**：类型{装逼打脸/逆袭反转/获得机缘/信息差碾压/情感满足/扮猪吃虎/经营破局/悬念钩沉} | 铺垫{X}字 / 释放{Y}字 / 铺放比{Z:1} | 情绪曲线

**反应层拆解**（如有）：

| 层级 | 角色 | 反应 | 篇幅 |
|------|------|------|------|
| 质疑/轻视 | | | |
| 震惊/打脸 | | | |
| 强者重评 | | | |
| 扩散传播 | | | |

反应篇幅比{N:1}（仅公开打脸/展示实力场作参考，以展示篇幅为分母，1.5 为常见经验值；悬疑、日常或私密对手戏无围观反应时填“无”）

**释放后追证**（如有）：爽点释放后对手或关键方真实态度？{行为+原文引用}

**冲突升级**（如有）：{行为} | 升级层级{如口头→利益→生死，或试探→拉扯→摊牌} | 对角色画像影响

**背景信息揭示**（如有）：揭示{什么} | 叙事功能{推翻预设/重新解读/铺垫新线/认知偏差} | 对主线影响

**章尾钩子**：类型{悬念/反转/新信息/新角色} | 内容{描述} | 期待度{强/中/弱}

**可借鉴要素**：{可复用技巧}

> 第二、三章额外关注：信息密度 / 冲突升级(vs上章) / 节奏变化 / 爽点间隔字数。
> 反派若为非人形（灵气复苏/末世/国运等抽象对抗型），在「爽点分析」处改用抽象对抗型路由：核心对抗面{描述} | 紧迫感来源{描述} | 升级机制{描述} | 叙事替代{用什么替代传统打脸}。
> 感情流、女频（言情、宅斗、甜宠等）在「爽点分析」处改用关系路由：情感张力来源{误会/身份差/旧怨/契约等} | 关系推进一步{从什么到什么} | 虐甜安排{先虐后甜/甜中藏刀等} | 读者期待{想看谁对谁表态}；「反应层拆解」改看旁人对这段关系的反应。快速预览的「爽点设计」一项按情感兑现打分。

同一次黄金三章阅读优先另写 `_style-sample.txt`，减少 Stage 6 的定点取样；旧项目没有该缓存时，Stage 6 仍可按索引选择 4–6 章并只读取对应行段：

```text
<!-- STYLE_SAMPLE:v1 -->
## 片段 A
source_locator: 原文/原文.txt:L{起始行}-L{结束行}
基调: {紧张/压抑/轻松/温馨/热血}
示范点: {句长节奏/标点/对话潜台词/动作与反应等}
{300—500字连续原句}
```

共选4—6段，允许同章多段，但范围不得重叠；只保留用于表达分析的最小样本，不建立第二套剧情事实。

## 题材爽点形态

铺垫层制造情绪缺口，释放层负责兑现，反应层记录旁人反应；衔接层及完整拆法见 Stage 3 节奏一节。

| 题材 | 释放层形态 | 反应层来源 | 铺垫层缺口 |
|------|-----------|-----------|-----------|
| 玄幻/修仙 | 实力碾压/境界突破 | 同门/对手/长老震惊 | 功法残缺/资源匮乏/血脉压制 |
| 都市 | 预测准确/身份揭露 | 商业对手/前女友/权贵 | 破产/被辞/被退婚 |
| 系统文 | 解锁稀有技能/任务奖励 | 系统稀有度标注 | 任务失败惩罚/技能冷却 |
| 历史 | 以弱胜强/先知优势 | 谋士/帝王/敌将震惊 | 信息不对称/身份低微 |
| 悬疑 | 真相揭露/反杀 | 被揭穿者崩溃/读者恍然 | 线索误导/嫌疑人洗白 |
| 言情/宅斗 | 当众表态/护短/真相大白 | 情敌/长辈/旁观者 | 误会/身份差/被轻视 |
