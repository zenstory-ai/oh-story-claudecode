# Stage 3：剧情、节奏与情绪模块

Stage 3 时刻读本文件与 [synthesis-inputs.md](synthesis-inputs.md)（取料、证据等级、阶段标记与事实保真）。

## 核心规则

- 剧情点按「起始目标与阻碍 → 改变局面的选择/行动/外部事件 → 局面变化与得失 → 后续影响」合并。
- 全阶段只维护**两套可复用编号注册表**：`剧情/节奏.md`（`RH-*` 爽点循环、`TR-*` 情绪触动点）与 `剧情/情绪模块.md`（`EM-*` 可复现模块卡）；不再另建 `EV/RV/AX` 体系，关键信息差与伏笔直接并入 `节奏.md`「关键信息推进表」和「伏笔跨章地图」。
- 情绪模块卡至少展开全书最强 3 个（不足按实际，值得复现不设上限），其余进「其他机制索引」。
- 产出顺序：故事框架 → 剧情单元 → 故事线 → `剧情/README.md` → `剧情/节奏.md` → `剧情/情绪模块.md` → 散落情节与自检；两份权威文件落盘后按 synthesis-inputs 标 `stage3`。

## 1. 故事框架识别

用 `digest` 取前 3 章与后 3 章概要及关键事件，结合 `概要.md` 判断核心驱动写进 `剧情/故事线.md` 顶部（有卷/部/篇优先按原书划分）：升级流（按境界）、复仇线（按复仇阶段）、日常/单元（按卷/单元）、多线交织（按线索标交叉点）、蜕变成长（按成长阶段）、感情流（按相识→试探→确认→危机→和解）。

```markdown
## 故事框架

| 项目 | 内容 |
|---|---|
| 框架类型 | {升级流/复仇线/日常单元/多线交织/蜕变成长/感情流/混合} |
| 核心驱动 | {全书持续推进的根本动力} |
| 主轴矛盾 / 升级机制 | {贯穿全书矛盾}｜{力量/地位/关系递进方式，无填“—”} |
| 叙事节奏模式 / 判断依据 | {铺垫→冲突→爽点→新悬念 典型周期}｜{支撑章节/情节点} |
```

单元数参考（查粒度异常用，不凑数）：<30 章 3–6 个，30–100 章 5–15 个，100–300 章 10–25 个，>300 章 15–40 个。

## 2. 剧情单元

**切单元与分情节点**：从批次剧情点与逐章摘要合并独立剧情，每条须具备可衡量核心目标、具体冲突/阻力、相对独立角色群与完整弧线（过细单一事件并入所属剧情，过粗跨百章主题拆开，大段重叠或首尾附庸降为阶段）。用 `digest --part chapters --points brief` 按目标与因果分配情节点（先定起终点再补过渡），分主线、支线、补充三层覆盖。跨批次合并仅针对相邻批次边界剧情对，须同时满足同目标、同主角群、自然延续且非独立因果（不同阶段/地图/目标不合并）。

输出 `剧情/{标题}.md`：

| 项目 | 内容 |
|---|---|
| 标题 / 类型 | {≤15字}｜{主线/爱情/成长/复仇/寻宝/悬疑/战斗/权谋/修炼/危机/谜团/日常/其他} |
| 概要 | {150–250字，按时序写起承转合、核心角色、关键道具及影响} |
| 因果链 | {起始目标 → 阻碍 → 关键选择/行动/外部事件 → 局面变化与得失 → 后续影响（未完标 open）} |
| 读者需求与信息 | {读者期待的满足点 ＋ 获得/等待/误判的关键信息} |
| 情绪模块ID / 桥段标签 | {引用 `情绪模块.md` 的 EM-001}｜{命中桥段逗号分隔，无则留空} |
| 主题 / 章节范围 | {≤3个主题}｜第{X}-{Y}章（共{N}章，约{M}万字） |

文末附结构分布（铺垫/发展/高潮/收尾期章段）与情节点索引（`| 序号 | 章节 | 描述 | 归入把握（明确/待复核） |`）。常用桥段参考：打脸、扮猪吃虎、掉马、追妻火葬场、废柴逆袭、越级反杀、先知破局、信息差反转、规则怪谈、签到面板、前世复仇、反杀极品、直播整活（可补充表外项）。

## 3. 故事线与剧情目录

多条剧情聚合成故事线接在 `剧情/故事线.md` 故事框架后：`| 标题/类型 | 描述（250–500字，按 3–8 个转折阶段写冲突/角色/演进/伏笔回收） | 情绪与套路运行（1–2句指模块ID） | 主题/包含剧情/模块引用（EM-001等） |`，并标线间关系（并行/交织/依赖）。

`剧情/README.md` 轻量索引：

```markdown
# 剧情目录索引

| 文件 | 权威范围 | 下游用法 |
|---|---|---|
| `节奏.md` | 关键信息推进、爽点循环、情绪触动点、爆发节奏 | 产出 `rhythm_reference` |
| `情绪模块.md` | 读者需求、情绪引擎、套路框架、可复现模块卡 | 产出 `selected_emotion_module` |
| `故事线.md` / `拆文报告.md` | 故事框架与人类阅读报告 | 投影摘要，不覆盖权威文件 |

冲突时以 `节奏.md` / `情绪模块.md` 为准；两份文件用 RH/TR 与 EM 编号互指。

## 剧情单元清单
| 剧情单元 | 类型 | 桥段标签 | 章节范围 | 体量 |
|---|---|---|---|---|
| `{标题}.md` | {类型} | {桥段标签} | 第{X}-{Y}章 | 共{N}章，约{M}万字 |
```

## 4. 节奏.md

输入：批次跨章观察、逐章事实、剧情单元与故事线。只登记影响主线、关系、风险或读者判断的关键节点；每条 `RH-*`/`TR-*` 回指章节或情节点，未展示写「文本未展示」。爽点循环拆铺垫层（缺口/误判）、释放层（打脸/兑现）、反应层（男频「轻视→震惊→强者重评→扩散」，感情流「冷待→动摇→维护→公开」，公开打脸反应篇幅比参考 1.5）与衔接层（新钩子）。

```markdown
# 节奏索引：{书名}

> 权威范围：关键信息推进、信息差与伏笔、爽点循环、情绪触动点与爆发节奏。`拆文报告.md` 只引摘要。

## 全书情绪节奏总览

- 情绪折线：{压抑/期待 → 加压 → 爽感/反转 → 余波/新危机；标章段}
- 爽点频率与高潮分布：{每 N 章小爽点 / 每 M 章中高潮 / 大高潮第 X 章}
- 冲突升级路径：{低级 → 中级 → 高级 → 终局矛盾；标触发章}
- 伏笔跨章地图：{伏笔/秘密 | 客观发生与第X章埋入 → 第Y章揭晓与信息差效果；仅跨 2 章以上或主线伏笔}

## 循环单元

- 小循环（2–4章）：{缺口/误判 → 加压试探 → 释放与新钩子}
- 中循环（5–10章）：{阶段目标 → 多轮阻碍 → 反转爽点 → 更大问题}
- 大循环（12–25章）：{卷内目标 → 资源/敌手升级 → 核心爆发 → 余波转场}

## 关键信息推进表

| 章节/范围 | 关键信息 | 扩写方式 | 读者与角色信息差 | 推进功能 | 节奏效果 | 关联剧情/模块 |
|---|---|---|---|---|---|---|
| 第{N}章 | {读者获得/误判/等待的信息} | {对话交锋/事件验证/围观反应/延迟揭示/回扣} | {读者已知 vs 角色未知；无写无} | {立目标/加压/释放/转场/埋钩} | {加速/减速/蓄力/爆发/冷却} | {剧情标题 / EM-001} |

## 爽点循环索引

| 循环ID | 章节范围 | 铺垫层 | 释放层 | 反应层 | 衔接层/新钩子 | 强度递进 |
|---|---|---|---|---|---|---|
| RH-001 | 第{X}-{Y}章 | {压抑/误判/缺口} | {打脸/掉马/兑现} | {谁震惊/后悔/重评} | {旧爽点后的新期待} | {比上轮强/弱在哪} |

## 情绪触动点索引

| 触动点ID | 章节 | 触发事件 | 目标读者情绪 | 爆发点 | 余波/冷却 | 复现提示 |
|---|---|---|---|---|---|---|
| TR-001 | 第{N}章 | {触发情节} | {期待/心疼/愤怒/爽/甜/热血/恐惧} | {最高句/段或事件} | {反应/关系变化/新悬念} | {留情绪链，不搬事件} |

## 爆发节奏总结

- 爆发密度与形态：{每N章/N字一次；递进/延迟满足/W形/阶梯/单元循环}
- 长间隔风险与写作提醒：{过稀区间靠什么撑住；新书每章/卷如何排触动点与断章钩}
```

## 5. 情绪模块.md

输入：故事框架、剧情单元、`节奏.md` 与桥段标签。先抽象「读者追着等什么兑现」，再抽成情绪链与功能位，关联 `RH/TR` 或章节证据。禁把原书专名、事件顺序、标志台词写成模板。

```markdown
# 情绪模块：{书名}

> 权威范围：读者需求 / 情绪引擎 / 套路框架运转 / 可复现模块。禁止照搬原书具体桥段。

## 读者需求 / 情绪引擎

| 读者需求 | 本书满足方式 | 证据章节/情节点 | 持续追读机制 | 可迁移边界 |
|---|---|---|---|---|
| {优越感/安全感/替代复仇/关系补偿/认知惊喜} | {持续交付方式} | {第N章/Px} | {下层期待怎么立} | {留情绪逻辑，换设定/人物/事件} |

## 故事框架与套路运行图

| 框架/套路 | 位置 | 运行方式 | 有效原因 | 失效风险 |
|---|---|---|---|---|
| {退婚打脸/升级/追悔/掉马/以小搏大/修罗场} | {章节/单元} | {铺垫→加压→释放→余波} | {对应读者需求} | {照搬雷同/人设错位/铺垫不足} |

## 其他机制索引

标题保留字面量 `## 其他机制索引`。除完整卡外只列：机制ID｜名称｜用途｜适用章节｜证据引用。

## 可复现模块卡

### EM-001 {模块名}

`读者想看什么`、`情绪链`、`戏剧单元`、`可替换项`、`不可照搬` 为下游必读字段，按原名填写；多行值可改用 `- **字段**：` 列表（字段名行不写值）。`可替换项` 写「功能位→任意X」，不写原书专名。

| 字段 | 内容 |
|---|---|
| 读者想看什么 | {一句话抽象读者期待} |
| 情绪链 | {缺口 → 加压 → 触发 → 爆发 → 余波} |
| 戏剧单元 | {去素材后的核心结构，如“被轻视者在公开场合用结果反证引爆围观重评”} |
| 可替换项 | {角色身份、场景、道具、对手类型、触发证据、目标结果} |
| 不可照搬 | {原文专名、具体事件顺序、标志性台词、独特设定} |
| 关联节奏 | {`剧情/节奏.md` RH-001 / TR-001} |
| 证据来源 | {剧情单元、章节与原文定位；旧资料写路径与证据等级} |

## 重组与复现指南

1. 先定读者需求与模块卡再套新书人设，不从原书桥段倒抄。
2. 留情绪链与功能位，彻底换人物、冲突对象、证据、道具与余波方向。
3. 人设与模块冲突时以人设为准重构，不为凑套路扭曲角色。
```

## 6. 散落情节与收尾自检

用 `digest --part chapters --points brief` 收集未归入单元的情节点：孤立点 <5% 直接记入 `剧情/散落情节.md` 标「少量散落，无需再归类」；目标因果明确者归入单元标 `[孤立情节归入]`，弱相关标 `[低置信归入]`，同主题满 5 点聚成候选单元标 `[聚类生成]`，其余按章留存说明原因。

全部落盘后自检（不落盘）：归入率 85%–95%（<30 章单主线可近 100%）、跨单元共用 ≤1/3；无过细/过粗/重叠附庸；只保留 `RH/TR` 与 `EM` 两套编号，每条均可回指章节或情节点。
