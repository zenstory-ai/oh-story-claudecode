# Stage 6：文风档案生成与单独重建

完整管道收尾或单独补缺失的 `文风.md` 时读本文件。单独补文风不触发 Stage 1–5。`拆文库/{书名}/文风.md` 由本 skill 独占写入；书被选为另一项目的对标时，由 story-import 或 story-long-write 首次引用时复制到 `{项目}/对标/{书名}/文风.md`。

## 原则

1. 文风档案描述作者实际写法，不评价作者水平。
2. 情绪和节奏意图以 `剧情/情绪模块.md`、`剧情/节奏.md` 为准，文风只管表达层。
3. 已有完整 `文风.md` 时原样保留；用户明确要求增强时才更新。
4. Stage 6 不重扫全书，只允许按索引行号定点回读 4–6 段原文。
5. 摘要措辞不能冒充作者原句；缺少原文和有效样本时报错。

## 来源顺序

1. 既有 `文风.md`；
2. 项目内非空且含连续原文的 `_style-sample.txt`；
3. `章节/第1章_深度拆解.md`–`第3章_深度拆解.md` 中带定位的短引和写法证据；
4. `_analysis_cache/批次-*.md`、`章节/*_摘要.md` 与 `拆文报告.md` 的结构层观察；
5. 仍缺锚点时，读 `chapter_index.csv`，按“覆盖主要基调”选 4–6 章，再按 `start_line/end_line` 定点读原文片段。

旧项目缺索引时可单独建索引，不写 `_progress.md` 或启动其他阶段。

## 单独重建文风

当 story-long-write 或用户发现 `文风.md` 缺失时：

1. 运行检查器，确认其他拆文成果可用且 `stage_repairs` 包含 `stage6_style` 或 `stage6`；
2. `_style-sample.txt` 有效就直接用；
3. 样本不足时确认 `chapter_index.csv` 与原文存在。缺索引时只运行：

   ```text
   "{PYTHON}" "{story-long-analyze skill 根}/scripts/build_chapter_index.py" --source "{拆文目录}/原文/原文.txt" --output "{拆文目录}/chapter_index.csv" --locator-path "原文/原文.txt"
   ```

4. 从索引选 4–6 章，覆盖已有资料能确认的不同基调；每章按行号取一段 300–500 字连续原句，写入或更新 `_style-sample.txt`；
5. 按下方模板生成 `文风.md`；
6. 落盘后运行：

   ```text
   "{PYTHON}" "{story-long-analyze skill 根}/scripts/manage_analysis_run.py" mark-stage --root "{拆文目录}" --stage stage6 --output "文风.md"
   ```

索引、原文和有效样本都不存在时停止，返回“无法取得可验证文风锚点”，不得生成锚点全空的可用文风。

## 报告回填

完整管道或续跑中，文风落盘后、标记 `stage6` 前，检查 `_progress.md` 受管阶段表：`stage5` 为 `completed`、产物为 `拆文报告.md`，且报告「文风一句话」仍待补时，用 `文风.md` 补齐该段。已有简述保留；单独补旧项目文风不改已有报告。

## 篇幅与可信度

总上限 4000 字：描述部分（整体语感、对话技法、情绪交替模式、可借鉴技巧、分层模仿建议）≤1800 字，原文锚点 4–6 段、每段 300–500 字、合计 ≤2100 字，生成记录与不建议模仿合计 ≤100 字。

每项结论后写一行「依据」，用下面三种说法之一：

| 依据 | 什么时候写 |
|---|---|
| 已有资料 | 从既有拆文成果读出，如章基调序列从逐章摘要的基调行统计 |
| 原文锚点 | 从 4–6 段原文锚点归纳，锚点覆盖三种以上基调 |
| 样本不足 | 锚点不到 4 段、只覆盖一两种基调，或只能依据摘要措辞 |

句长、标点、段落节奏都是看锚点归纳出来的，最多写「原文锚点」。

## 模板

```markdown
# {书名} 文风

## 生成记录
- 参考资料：拆文报告.md、黄金三章深度拆解、章节摘要
- 抽样章节：第 {K1}/{K2}/{K3}/{K4}[/{K5}/{K6}] 章（每章取 300-500 字连续行段）
- 生成时间：{date}
- 适用对标书路径：拆文库/{书名}/
- 文风可用：是  # 没有可核验的原句锚点时写“否：原因”；原文文件缺失但已有有效样本时仍可使用

## 整体语感
- 句长分布：{短句多还是长句多、长短怎样交替、什么场面用短句，附 1-2 个原文短例。一句概括语感。}
  - 依据：原文锚点 / 样本不足
- 标点习惯：{破折号/省略号/句号/感叹号/分号 的高频用法。附 2-3 个原文短片段示例。}
  - 依据：原文锚点 / 样本不足
- 段落节奏：{平均段长、单段单动作还是多动作堆叠、断行习惯。}
  - 依据：原文锚点 / 样本不足

## 对话技法
- 潜台词模式：{2-3 种典型潜台词手法（问非所答 / 语气反差 / 信息隐瞒等），每种附 1 段原文示例。}
  - 依据：已有资料 / 原文锚点 / 样本不足
- 对话标签习惯：{说话动词多样性、动作替代说话标签的频率、对话与动作的穿插比例。}
- 角色语气区分：{主角和 1-2 个核心配角的句式、称呼或潜台词差异（有固定口头禅时记口头禅，原书无固定口头禅时如实记无），引用原文样本句。}

## 情绪交替模式
- 章内基调切换：{按情节点基调序列看典型章节是否在 紧张↔轻松 或 热血↔温馨 之间切换、每章切换几次。}
  - 依据：已有资料 / 原文锚点 / 样本不足
- 跨章基调周期：{已拆范围内前 20 章的章基调序列；不足 20 章用实际章数并注明范围，识别“虐 3 章爽 1 章”之类周期。}
- 基调急转手法：{轻松→沉重、日常→惊变等急转用了什么手法，举 1-2 个原文锚点；原书平缓推进无急转时写“无明显急转”。}

## 可借鉴技巧（从 拆文报告.md 直接引用）
- 写法技巧 Top 5：
  1. {技巧名}：{一句话用法说明}
  2. ...
- 可借鉴套路 Top 3：
  1. {套路名}：{适用场景}
  2. ...

## 分层模仿建议
- 基础层（必学）：{词汇偏好、句式节奏、对话标签、描写重心中最容易迁移的 3-5 条；只学表达习惯，不复制原句}
- 进阶层（结构）：{节奏推进、伏笔埋回、视角切换、场景衔接中最值得复用的 3-5 条；替换人物/场景/道具后再使用}
- 适配层（适合当前项目）：{哪些技法适合、哪些会导致人设/题材错位；不搬运专名、标志性台词、独特桥段和事件顺序}
```
