# Stage 6：文风档案生成与单独重建

完整管道收尾或单独补缺失 `文风.md` 时读本文件（单独补文风不触发 Stage 1–5）。`拆文库/{书名}/文风.md` 由本 skill 独占写入，被选为对标时由下游首次引用复制。

## 原则与来源顺序

1. 如实刻画作者的竖屏网文写法与量化特征，不用文学评论话术替代实测指标；情绪与节奏权威以 `剧情/情绪模块.md`、`剧情/节奏.md` 为准，`文风.md` 只管语言节奏、对白口吻与原文语感切片。
2. 已有完整 `文风.md` 原样保留（用户要求增强才更新）；不重扫全书，最多按索引行号定点读 4–6 段原文；缺原文和有效样本时报错停止，不生成空锚点文风。
3. 来源优先级：① 既有 `文风.md` → ② 非空 `_style-sample.txt`（Stage 1 已预存 2–3 段）→ ③ 黄金三章深度拆解短引 → ④ 批次缓存、摘要与 `拆文报告.md` → ⑤ 不足 4–6 段时按 `chapter_index.csv` 挑覆盖高频基调的章，按行号各取 200–300 字（最长不超过 400 字）连续原文补齐 `_style-sample.txt`。

## 单独重建与报告回填

1. 跑检查器确认 `stage_repairs` 含 `stage6_style` 或 `stage6`；`_style-sample.txt` 已有 4–6 段有效原文直接用，不足且缺索引时单建索引（不写 `_progress.md`），再跑 `prose-stats` 确定性出数（**严禁目测估算**）：
   ```text
   node "{story-long-analyze skill 根}/scripts/build_chapter_index.js" --source "{拆文目录}/原文/原文.txt" --output "{拆文目录}/chapter_index.csv" --locator-path "原文/原文.txt"
   node "{story-long-analyze skill 根}/scripts/manage_analysis_run.js" prose-stats --root "{拆文目录}" --file "_style-sample.txt"
   ```
2. 按模板落盘 `文风.md`（总上限 3,600 字：量化与技法 ≤1,400 字，4–6 段 200–300 字原文锚点 ≤2,100 字，记录与不建议模仿 ≤100 字），再标记完成：
   ```text
   node "{story-long-analyze skill 根}/scripts/manage_analysis_run.js" mark-stage --root "{拆文目录}" --stage stage6 --output "文风.md"
   ```
3. **报告回填**：完整管道/续跑中，标 `stage6` 前若 `stage5` 已完成且报告「文风一句话」仍待补，用 `文风.md` 补齐；单独补旧项目文风不改旧报告。
4. **依据口径**：每项结论标 `已有资料`（摘要/拆文统计）、`原文锚点`（4–6 段覆盖 ≥3 基调的原文，量化指标与对白口吻最高写此项）或 `样本不足`。

- 段落与断行：段长中位数 {N} 字｜≤50 字段占比 {X}%｜单句成段率 {Y}%｜>80 字长段占比 {Z}%（断行习惯＋1–2 短例）

## 对白推拉与打脸反应模式
- 对白推拉方式：{反派挑衅施压怎么开口、主角反怼定调怎么接招、回合长短与信息推进，附 1 段短例}
