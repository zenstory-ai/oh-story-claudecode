# 写给作者看的话

对话回复与落盘文件（`快速预览.md`、`拆文报告.md`、`人物关系图/人物关系图.md`）均按本文件写。

## 总规则

1. **说书，不说系统**：讲剧情、读者爽点与怎么借用；进度说「拆到第几章 / 共几章」，不提阶段、批次或命令。
2. **零工程痕迹**：不写脚本名、命令、JSON、状态值、内部文件、hash、质量指标名或证据字母；脚本带 `author_message` 时按原意转述（不改事实、不删选项）。
3. **编号带人话名**：情绪模块或节奏编号不裸出，写成「退婚当众打脸」（情绪模块卡 EM-003）；关系写「主角 → 师姐：由信任到反目（第9章宗门大比）」。
4. **证据强弱说人话**：原文直写直接说；多处推断写「从第3、5章看，大概率……」；不足写「推测，待回原文核实：……」。
5. **需要拍板时**：一次只问一个具体问题并给推荐选项与理由；不加技术尾注（排障需要时文末限一行白话）。

## 对话话术

### 开头三章拆完、停下来问

```text
《{书名}》开头三章拆完了，速览写在 快速预览.md。
一句话判断：{开篇怎么抓人、主角和卖点怎么立住}。最值得学的一点：{最可复用的网文写法}。

要继续把后面 {剩余章数} 章拆完吗？我建议{继续 / 先拆到第一卷末 / 只拆第 X–Y 章 / 到此为止}，因为{理由}。
继续的话默认每次同时拆三段（每段最多三章），约 {轮数} 轮；跨段称呼和未收尾剧情汇总时统一。是否继续，等你决定。
```

### 作者问起怎么拆（不主动列，问起再给）

```text
有三种拆法：1. 按顺序逐段拆（接续稳、等待久）；2. 每次同时拆三段（默认，汇总统一）；3. 同时拆更多段（最快，限流自动放慢）。
```

### 拆的过程中报进度（约每拆一成报一次；重试仍败才报）

```text
《{书名}》拆到第 {已拆章} / {总章数} 章（约 {百分比}%）。刚拆完看点：{一句}。接下来拆第 {起章}–{止章} 章。
失败提示：第 {起章}–{止章} 章拆两次未成（{白话原因}），先继续往后拆，这几章{稍后单章重试 / 请核对原文}。
```

### 全部拆完（只拆部分时「去哪看」仅列本次新增/更新文件）

```text
《{书名}》拆完了：共 {总章数} 章、约 {总字数} 万字，{全部拆完 / 第 {x}–{y} 章未拆成：{原因}}。

最值得学的{一到三}点：1.{开篇钩子与亮牌} 2.{核心爽点兑现} 3.{节奏与断章卡点}
可直接借用的套路：- {套路名}：{适用场景与起效方式}
不建议学的：{一条＋原因}

去哪看：
- 总报告：拆文报告.md｜黄金三章：章节/第1章_深度拆解.md–第3章_深度拆解.md
- 节奏与爽点：剧情/节奏.md｜可复用套路：剧情/情绪模块.md｜主线与各段：剧情/故事线.md 与 剧情/
- 人物与设定：角色/、人物关系图/人物关系图.md、设定/｜语感与原文切片：文风.md｜单章查：章节/第N章_摘要.md
{需拍板问题＋推荐选项；无则不写}
```

### 停下来或出错时（先说影响再给出路）

```text
没找到目录：「没找到 拆文库/{书名}，书名或路径对吗？」
原文变了：「原文和上次不一样了（{改了哪几章/换文件}）。已拆章不动，只重读改动章{有楔子加：；楔子照样并进第1章}。按新原文继续吗？（推荐：继续）」（重建前段错位则转述脚本说明与两选项，推第一项）
认不出章节：「原文认不出章节标题（如“第1章”“楔子”），能看一下开头格式吗？」
旧拆文章号错位：（转述脚本说明与选项：有楔子三选推「按旧章号继续」；无楔子两选推「换新目录」）
选题决策缺栏目：「选题决策.md 缺「能爆的原因」，先不回填；想回填请重做长篇扫榜选题决策。」
关系图画不出中文：「{照转原因}，已写成 人物关系图/人物关系图.md，用 Markdown 编辑器即可看中文。」
文风没生成：「文风没生成：{缺原文/样本太少}。其他结果可用；补足后可单独补文风。」
```

## 拆文报告.md

## 人物与关系
